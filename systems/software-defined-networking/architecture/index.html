Northbound clients are untrusted and cross the API gateway's AuthN/AuthZ/audit boundary before touching controller internals (§22 T1-T2). The controller cluster is the sole writer of desired state; it is a Raft-replicated quorum so no single node's crash loses acknowledged intent (I3-I4). The persistence layer and event journal are two views of the same append-only discipline: the WAL is the durability primitive, the journal is the replay/debugging primitive; both are populated inside the same transaction boundary (ADR-16). The southbound session layer is a hard protocol and trust boundary — every message is length-framed, versioned, and validated before it can reach flow-table-engine state (§22 T3-T5). The dataplane runs one packet-worker per core with NUMA-aware queue partitioning (§4); it is intentionally the least "smart" component — correctness lives in the controller, the dataplane executes what it is told and reports what it observed.

8. Domain Model — Protocol & Forwarding State

Switch identity. A switch is identified by an immutable (datapath_id, generation) pair; the generation increments only on controller-initiated re-registration (never on transient link flap), preventing a stale switch record from being mistaken for a live one after a reconnect. Capability bitmaps are negotiated once per session and quarantined under I9.

Flow rule model. A flow rule is scoped to (table_id, priority) and carries match fields, an ordered instruction list, a cookie (operator-assigned correlation token, not a security token), and independent idle/hard timeouts. Priority resolves overlapping matches within a table; goto-table instructions chain rules across tables and must not cycle (checked at compile time by flow-compiler, §20).

Match fields (subset of OpenFlow 1.3): ingress port, Ethernet src/dst, VLAN ID, IPv4 src/dst, TCP src/dst port, UDP src/dst port, IP protocol number, and one 64-bit metadata register for cross-table pipeline state. Each field is independently maskable (wildcard match).

Action semantics: output(port), drop, set-field(field, value), push-vlan(tpid), pop-vlan, goto-table(id), group(id). Actions execute in list order within an instruction; goto-table must be the terminal instruction in its list (enforced at parse time, not runtime branching — a static structural check, §14).

            emit reconciliation warning (metrics-runtime)
