32. Back-of-Envelope Capacity Model

  • C1 — Controller RSS Budget. 500 switches × 4 MB metadata = 2,000 MB + 250,000 flows × 512 B = 128 MB + ~500 MB baseline runtime = 2.63 GB, inside the 8 GB soft ceiling (§4) with 3× margin.
  • C2 — Flow-Table Capacity Ceiling. 2 GB switch-runtime hard ceiling (§4) minus 500 MB packet-buffer/parser-scratch reservation = 1.5 GB ÷ 512 B/flow = 2,929,687 theoretical max; the 250,000-flow target (§4) leaves headroom for group-table and index overhead.
  • C3 — Southbound FD Budget. 10,000 sessions × 2 FDs (socket + WAL handle) = 20,000 + ~1,000 northbound listener FDs = 21,000, inside the 65,536 FD budget (§4) with 3× headroom.
  • C4 — WAL Write Rate. 1 KB logical payload/event × 1.3× checksum/framing overhead (§4) = 1.3 KB on-disk/event; at 50,000 flow-mods/sec (§4) sustained = 65 MB/sec raw WAL write rate.
  • C5 — Snapshot Recovery Time. 250,000 flows × 512 B = 128 MB + 500 switches × 4 MB = 2,000 MB (dominant term) = ~2.13 GB total ÷ 500 MB/s disk read = 4.3 s decode, inside the 60 s target (§4) with >10× margin for validation/index-rebuild overhead.
  • C6 — Reconciliation Concurrency. 250,000 ops/minute (§4) ÷ 60 = 4,167 ops/sec sustained; at a 200 ms p95 diff-cycle (§4), naive per-flow single-threaded diffing would need 4,167 × 0.2 s = 833 concurrent in-flight diffs, met via batched dirty-set diffing (§16.7) rather than per-flow loops.
  • C7 — Cluster Replication Bandwidth. 3-node quorum, 50,000 flow-mods/sec × ~200 B compact log entry = 10 MB/sec leader-to-follower stream × 2 followers = 20 MB/sec aggregate, negligible against a typical intra-DC 10+ Gbps link (§4's 0.5-5 ms RTT assumption confirms same-DC placement).
  • C8 — Metrics Cardinality Ceiling. 200,000 active series/node (Prometheus-recommended ceiling) ÷ ~20 label combinations/family = 10,000 metric-family budget, which is why per-flow_id labels (FM-10) are rejected outright rather than budgeted against.
