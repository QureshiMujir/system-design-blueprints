Mental Models & First Principles

MM1 — A semantic cache is a statistical decision, not a lookup. Insight: classic caches answer a boolean ("is key present?"); a semantic cache answers a probabilistic question ("is there a stored entry close enough to be correct?") with bounded error. It predicts: false-hit rate is a first-class output, not a side-effect. Bug class without it: treating the cache as correct-by-construction, shipping no false-hit measurement, and learning about errors from users. Applied: §4 System Constraints (false-hit SLO); Phase 4 (calibrate.rs); Failure Modes (false-hit SLO breach).

MM2 — The store is truth; the index is a derived view. Insight: Helland's "Immutability Changes Everything" — append-only records + derived views decouple durability from query structures. The WAL + value store are immutable truth; the HNSW graph is a derived index rebuilt from them. It predicts: index loss ≠ data loss; index bugs don't corrupt responses. Bug class without it: persisting the index as truth → a corrupt index requires rebuilding responses from an unavailable source. Applied: Design Principle 2; Phase 3 (rebuild path); ADR-008; I6.

MM3 — Calibration is the ROC curve applied to a gate. Insight: threshold selection is a precision-recall tradeoff from binary classification. A similarity threshold τ moves along the ROC curve: lower τ = more HITs (higher recall) + more false hits (lower precision). The SLO is a precision floor; τ is set at the Pareto point. It predicts: any threshold change moves hit rate and false-hit rate in opposite directions. Bug class without it: setting τ by feel, overshooting hit rate, shipping a false-hit rate 5× the SLO. Applied: Phase 4 (calibrate.rs, τ sweep, held-out split); §4 false-hit SLO; MM8.

MM4 — Epoch reclamation: defer freeing until readers drain. Insight: lock-free concurrent data structures defer memory reclamation until no thread holds a reference to an old version. In HNSW, a reader traversing a graph node must finish before a writer reclaims that node. Crossbeam-epoch implements this via pinned readers + per-epoch garbage lists. It predicts: without epoch, a reader following a pointer to a reclaimed node crashes or reads garbage. Bug class without it: use-after-free under concurrent insert/compact. Applied: Phase 2 (sc-index/epoch.rs); I8; ADR-009; Phase 9 (COW swap).

MM5 — Write-ahead: the log is the source of truth for durability. Insight: ARIES WAL: append the intent before mutating state; replay the log on recovery; an fsync'd WAL record guarantees the mutation survives a crash. The store is reconstructable from the log. It predicts: any mutation visible before the WAL record is fsync'd can be lost on crash. Bug class without it: write-behind store → crash drops acknowledged writes. Applied: Phase 3 (wal/log.rs, write path I9); I5 (idempotent replay); ADR-007; Design Principle 11.

MM6 — Admission is expected-value filtering, not a heuristic. Insight: cache only when E[cost_saved] > E[storage_cost + false_hit_penalty]. P(reuse) is estimated from frequency sketches; false_hit_penalty is the SLO-weighted cost of a wrong answer. This model predicts: unique prompts (P(reuse)≈0) have negative expected value and should be rejected. Bug class without it: always-cache bloats the index with one-offs, raises false-hit risk, and yields zero savings per stored byte. Applied: Phase 7 (sc-admit/cost.rs); I15; Design Principle 9.

MM7 — Embedding version partitions the similarity space. Insight: cosine similarity is meaningful only within a fixed embedding function. Two embeddings from different model versions are not comparable — their inner product has no semantic interpretation. The keyspace is partitioned by (Namespace, embed_ver); cross-version comparisons violate geometry. It predicts: mixing embed versions silently degrades recall or produces false hits with no metric signal. Bug class without it: routing queries to a mismatched index partition after a model upgrade. Applied: I1; Design Principle 3; Phase 1 (version routing); Phase 4 (τ per (ns, embed_ver)).

MM8 — You cannot observe false-hit rate online; you must measure it by probe. Insight: on a HIT, you return a cached response to the caller without calling upstream — so you never know if the cached answer was correct. The only way to estimate false-hit rate is to occasionally force an upstream call for a served HIT, compare outcomes, and sample the ratio. This is reservoir sampling applied to a latent variable. It predicts: a cache without probing cannot report its false-hit rate; operators are blind to the central correctness SLO. Bug class without it: shipping a threshold that is quietly 5× the SLO. Applied: Phase 10 (sc-observe/reservoir.rs + probe.rs); I14; Design Principle 8; §4 false-hit SLO.

Required reading (§5)

Books

  • Manning, Raghavan, Schütze, Introduction to Information Retrieval (2008) — Ch. 6 (vector space model, cosine), Ch. 7 (scoring/efficiency). Similarity semantics + why cosine, and ranking efficiency. Applied: §8.5 similarity semantics; Phase 4 (threshold gate, τ selection).
  • Aumüller, Bernhardsson, Faithfull et al. — ann-benchmarks methodology writeups — recall/QPS tradeoff measurement; how to report ANN quality. Extract the recall@k vs latency protocol. Applied: Phase 2 (HNSW recall@10 target); Phase 10 (recall gate, Phase 12 drift gate).
  • Pat Helland, "Immutability Changes Everything" (CIDR 2015) — append-only + immutable records; informs WAL + rebuildable-index design (store = truth, index = derived). Applied: Design Principle 2; Phase 3 (WAL + I6 rebuildable index); ADR-008.
  • Petrov, Database Internals (2019) — Part I (B-Trees/LSM/WAL/recovery): WAL, checkpointing, crash recovery. Applied: Phase 3 (sc-store WAL, group-commit, checkpoint, recovery); I9.
  • Cormen et al., CLRS, 3e — Ch. 11 (hashing) for prompt-hash + value-store buckets; Ch. 6 (heaps) for top-k; priority-queue search frontier in HNSW. Applied: Phase 0 (CacheKey hashing); Phase 2 (HNSW beam-search candidate heap).
  • Klabnik & Nichols, The Rust Programming Language — ownership, Send/Sync, lifetimes for index arena + WAL segment ownership; unsafe boundaries. Applied: ADR-001 (language rationale); Phase 2 (epoch reclamation, I8); Phase 3 (WAL segment lifetime).
  • Drepper, "What Every Programmer Should Know About Memory" (2007) — cache lines, prefetch; HNSW link-list layout + distance-kernel cache locality. Applied: Phase 2 (distance kernel SIMD, packed neighbor lists); Performance Engineering section.
  • Kleppmann, Designing Data-Intensive Applications (2017) — Ch. 3 (storage/retrieval), Ch. 5 (replication), Ch. 11 (stream processing): caching, invalidation, versioning intuition. Applied: Phase 6 (eviction, TTL, invalidation); Compatibility Guarantees; Scalability Analysis.
  • McSherry / streaming-statistics literature (reservoir sampling, t-digest) — sampling false-hit probes + latency quantiles without storing everything. Applied: Phase 10 (sc-observe/reservoir.rs, sc-observe/tdigest.rs); I14 (seeded probe sampling).
  • Tukey / calibration & ROC primers (any applied-stats text, e.g. Elements of Statistical Learning Ch. 4.4) — threshold selection, precision/recall, calibration of a similarity score → decision. Applied: Phase 4 (calibrate.rs; τ sweep; false-hit SLO); Mental Models & First Principles (MM3).

Glossary · 45 terms · site-wide glossary

Semantic cache
Cache keyed by similarity of prompt meaning (embedding), not exact bytes.
HIT
A cached response is returned because a stored entry is similar + valid enough.
MISS
No suitable cached entry; the backing model is called (and the result possibly stored).
False hit
A HIT that returns a wrong answer (a close-but-different prompt matched). The cardinal error.
False miss
A MISS where a correct cached answer existed but wasn't matched (lost savings).
Embedding
Dense vector representation of text; the fuzzy cache key (L2-normalized).
embed_ver
Embedding-model version; partitions the keyspace (entries/queries must share it).
ModelVersion
Generation (LLM) model version; part of the exact CacheKey scope.
Namespace
Logical partition (tenant / use-case) with its own index + threshold + budget.
Cosine similarity
Dot product of L2-normalized vectors ∈ [−1,1]; the similarity score gated against τ.
Threshold (τ)
Per-(namespace, embed_ver) cosine cutoff; sim ≥ τ → candidate HIT.
Margin
Band below τ where candidates are treated as marginal → conservative MISS (or verify).
ANN
Approximate Nearest Neighbor search — fast, recall < 1.0.
HNSW
Hierarchical Navigable Small World graph ANN index (primary).
IVF-PQ
Inverted-file + product-quantization ANN index (memory-efficient alternative).
Recall@k
Fraction of true k-nearest neighbors the ANN index returns vs exact kNN.
ef
HNSW search beam width; higher = better recall, slower.
Tombstone
Soft-deleted index node, skipped in search, reclaimed by compaction.
Compaction
Physically remove tombstones + relink the index; reclaim memory.
Rebuild
Reconstruct the index from the store (the universal index repair, I6).
Cross-encoder
A model scoring query↔candidate jointly; high-precision HIT verification.
Re-rank
Re-order ANN candidates with a more precise scorer (exact re-score / cross-encoder).
Verification
Second gate after threshold: re-score / cross-encoder / faithfulness before HIT.
Calibration
Offline selection of τ from labeled pairs to meet the false-hit SLO.
Admission control
Cost-benefit + cacheability decision on whether to store a MISS's response.
Cacheable
A response that is deterministic + reusable + has no one-shot side-effect.
Eviction
Remove entries under memory pressure (LRU/LFU/ARC + semantic cluster prune).
Semantic cluster prune
Evict redundant near-duplicate entries, keeping a cluster representative.
TTL
Time-to-live; expired entries are never served (I10).
Invalidation
Explicit removal by key / namespace / model-version.
Backpressure
Bounded queues; full downstream throttles upstream.
Load shedding
Under pressure, reject admissions then bypass the cache (degrade savings).
Bypass / passthrough
Forward to upstream without caching (on fault or under load); the request never fails (I12).
WAL
Write-ahead log; durable record of store mutations, replayed on recovery (I9).
Checkpoint
Periodic store snapshot + index manifest; truncates WAL prefix.
Exactly-once Put
Put(EntryId) is idempotent under replay/retry (I5).
Source of truth
The value store + WAL; the index is derived/rebuildable (principle 2, I6).
Epoch reclamation
Lock-free read scheme: defer freeing until readers drain (I8).
False-hit probe
Seeded sampled HIT also sent upstream to label true/false (measures false-hit, I14).
Threshold drift
Slow change in served-similarity distribution / false-hit rate over time.
Deterministic replay
Re-feeding a captured trace yields identical decisions + mutations (I2).
Cost saved
Token / dollar cost avoided by serving from cache instead of upstream.
Latency saved
Model-call latency avoided by a HIT.
EntryId
Dense id joining a vector-index node to its CacheEntry (I7).
CacheKey
Hash of (namespace ‖ model-version ‖ canonical params); the exact-match scope.
