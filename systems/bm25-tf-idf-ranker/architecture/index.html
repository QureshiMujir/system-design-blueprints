  Trust boundary: HTTP API is only external entry point.
  Persistence boundary: WAL + immutable segment files.
  Concurrency boundary: indexer owns mutable state; query engine reads snapshots.

Document Ingestor — field extraction, schema validation, monotonically increasing DocId (u64) assignment. Feeds indexing pipeline via channel.
Tokenizer — UAX #29 Unicode word-break segmentation; emits Token with ByteOffset for highlighting.
Normalizer — NFKC decomposition + Unicode case-folding + optional accent stripping. Non-Latin scripts pass through for future extension.
Stemmer — Porter2 (Snowball) via rust-stemmers; pure &str → String with no internal state.
Stop-Word Filter — configurable per-field; position gaps preserved (not renumbered) to maintain phrase distance semantics.
Index Builder — accumulates postings in DRAM; at 256 MB flush threshold, sorts by (term_id, doc_id), builds skip pointers, writes immutable segment.
Term Dictionary — Phase 0: HashMap<String, TermId>; Phase 4+: fst finite-state transducer for O(len(term)) lookup with minimal memory.
Doc Store — per-document: field lengths (tokens), stored field content for snippets, avgdl contribution.
Postings Builder — serializes (delta_doc_id, tf, [positions]) tuples compressed with VByte (Phase 0) or PFOR-delta (Phase 6+).
Segment Store — N immutable on-disk segments + WAL. SegmentId = UUID v4. Background MergeManager applies tiered policy to bound segment count.
Query Parser — recursive descent over EBNF grammar (§8); lowered to QueryPlan.
Scorer — Scorer trait: TfIdfScorer, Bm25Scorer, Bm25fScorer. Generic over scoring model.
Top-K Heap — min-heap of K highest-scoring ScoredDoc entries; WAND uses per-term upper-bound scores to skip entire postings blocks.
Result Formatter — loads stored fields for top-K, extracts 150-char highlight windows, serializes to JSON.

8. Domain Model

Information Retrieval Fundamentals

An IR system answers queries over a corpus (collection of documents) by computing a relevance score for each document with respect to each query and returning the top-K documents by score.

Document := { id: DocId, fields: Map<FieldName, String>, metadata: DocMeta }
Query    := { terms: Vec<Token>, operators: QueryOp, boost: Map<FieldName, f32> }
Result   := { doc_id: GlobalDocId, score: f32, snippets: Vec<Snippet> }

TF-IDF Scoring Model

score(d, q) = Σᵢ TF(tᵢ, d) × IDF(tᵢ)

TF variants:
  Raw:       count(t, d)
  Log:       1 + log(count(t, d))   [if count > 0, else 0]
  Augmented: 0.5 + 0.5 × count(t, d) / max_count(d)
  Boolean:   1 if count > 0, else 0

Smooth IDF: log((N + 1) / (df(t) + 1)) + 1
  [+1 outside log guarantees IDF > 0 for all terms; Lucene variant]

N = total document count. df(t) = documents containing term t. Smooth IDF prevents negative weights for high-frequency terms (unlike classic log(N/df) which turns negative at df > N/e).

BM25 Scoring Model

score(d, q) = Σᵢ IDF(tᵢ) × [tf(tᵢ,d) × (k1+1)] / [tf(tᵢ,d) + k1×(1−b + b×|d|/avgdl)]

Robertson IDF: log((N − df(t) + 0.5) / (df(t) + 0.5) + 1)
  [always positive; standard BM25 IDF]
  
BM25+ variant: add δ to numerator: [δ + tf×(k1+1)] / [tf + k1×(1−b+b×|d|/avgdl)]
  [guarantees positive contribution for any tf ≥ 1]
  
Parameters:
  k1 ∈ [1.2, 2.0]  (TF saturation; k1=0 → binary; k1→∞ → raw TF)
  b  ∈ [0.0, 1.0]  (length normalization; b=0 → none; b=1 → full)
  δ  = 0.0 (BM25); δ ≈ 0.5 (BM25+)

Inverted Index Data Model

TermDictionary:  term_string → TermId
PostingsList(t): [(DocId, TermFreq, [Position...])] sorted by DocId
SkipPointer:     every SKIP_STRIDE=64 entries → (doc_id_at_pos, byte_offset)

Segment:
  term_dict   : TermDictionary (HashMap Phase 0; FST Phase 4+)
  postings    : compressed binary file (VByte Phase 0; PFOR Phase 6+)
  doc_store   : field lengths + stored fields per document
  delete_bitmap: RoaringBitmap of deleted DocIds
  corpus_stats: CorpusStats {N, total_tokens, avgdl, df per term}

Query Grammar (EBNF)

query       ::= disjunction
disjunction ::= conjunction ("OR" conjunction)*
conjunction ::= negation ("AND" negation)*
negation    ::= "NOT" primary | primary
primary     ::= phrase | term | "(" query ")"
phrase      ::= '"' term+ '"' ("~" INT)?
term        ::= WORD ("^" FLOAT)? | WORD "~" INT
WORD        ::= [^\s"()^~]+
FLOAT       ::= [0-9]+("."[0-9]+)?
INT         ::= [0-9]+

Fuzzy suffix ~INT is PhaseDeferred("§36 — Fuzzy query").

Query AST

QueryNode :=
  | TermNode    { term: String, field: Option<FieldName>, boost: f32 }
  | PhraseNode  { terms: Vec<String>, field: Option<FieldName>, boost: f32, slop: u32 }
  | AndNode     { children: Vec<QueryNode> }
  | OrNode      { children: Vec<QueryNode> }
  | NotNode     { must_not: Box<QueryNode>, filter: Box<QueryNode> }

Query Execution State Machine

State Event Next State Action
Parse Valid query string Plan Build QueryNode AST
Parse Syntax error Error Return RankerError::QueryParse
Plan Terms resolved Execute QueryPlan built; terms sorted by ascending df
Plan All terms unknown EmptyResult Return empty result set
Execute WAND threshold updating Execute Advance iterators; update K-th score
Execute All iterators exhausted Rank Sort heap, format results
Rank Snippet requested Done Load stored fields; highlight

TREC Evaluation Metrics

Precision@K = |relevant in top-K| / K
AP          = mean Precision@K for each K where rank K is relevant
MAP         = mean AP across all queries
MRR         = mean of 1/rank(first relevant) across queries
DCG@K       = Σᵢ₌₁ᴷ rel(i) / log₂(i+1)
NDCG@K      = DCG@K / IDCG@K   [IDCG = ideal (sorted) DCG]

Malformed Input Examples

  • Empty query string → EmptyPlan → empty result set (no error).
  • Query consisting entirely of stop words → EmptyPlan after analysis.
  • Query with unmatched parentheses "((unclosed" → RankerError::QueryParse{pos, msg}.
  • Document with NUL bytes → NUL stripped before tokenization.
  • Postings block with non-monotonic doc_ids → RankerError::Codec on decode.
