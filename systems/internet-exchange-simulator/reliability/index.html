I6By default, a route learned from member A is not exported to member B in a way that gives B transit through A via the IXP.Preserves settlement-free contract; prevents liability and route leaks.ixp-policy — default export filter blocks re-advertisement creating transit paths; ixp-routeserver per-member export pipeline.Scenario: A announces 10.0.0.0/8; C does not peer with A; assert C does not receive 10.0.0.0/8.unintended_transit_candidates, leak_event_count.Policy fix required; no automatic recovery.Run assert_no_transit scenario clause; dump per-member export decisions.
I7Exported routes obey the member's ExportFilter; imported routes obey its ImportFilter, at every quiescent sim step.Ensures policy is applied consistently, not only at session establishment.ixp-policy — filter evaluated per-UPDATE on import and per-advertisement on export.Quiescent check: walk Loc-RIB for all members; assert each route passed import filter; assert export queue routes pass export filter.import_filter_drops, export_filter_drops counters.Re-evaluate filters on policy change; withdraw non-compliant routes.Compare Loc-RIB contents against filter specification; use assert_rib_contains / assert_rib_excludes.
I8RS per-member Loc-RIB reflects exactly that member's policy view; no other member's policy affects it.Member isolation: a Restrictive member cannot silence routes to an Open member.ixp-routeserver — RouteServer::rib_per_member keyed by MemberId; no shared mutable state.Scenario: change member X policy; assert member Y's Loc-RIB unchanged. Mutate one Loc-RIB entry; assert others unmodified.rib_isolation_violations: u64.Bug: structural fix required.Snapshot all Loc-RIBs before/after member X policy change; diff all others.
I9A downed port flushes its learned MAC entries and resets all BGP sessions established over that port.Prevents stale MAC entries causing misdelivery; prevents sessions hanging in Established over a dead link.ixp-fabric — port_down() flushes MAC entries; ixp-peering — PortDown event triggers NOTIFICATION to session FSM.Inject PortDown event; assert MAC entries for that port removed; assert all affected sessions → Idle.port_down_events, sessions_reset_on_port_down, mac_entries_flushed_on_port_down.Automatic MAC flush + session reset; re-establishment follows standard FSM ConnectRetry.Trace PortDown event handling across ixp-fabric and ixp-peering; verify MAC flush then session reset cascade.
I10Next-hop of a route advertised by the RS is the originating member's LAN address, not the RS's address.Data-plane correctness: receiving member must send frames to announcer's MAC, not RS's MAC.ixp-routeserver — RouteServer::advertise() preserves RsRoute.next_hop = origin_member's LAN IP.Parse next-hop attribute of every RS UPDATE; assert equals announcer's peering LAN IP; assert != RS LAN IP.next_hop_rewrite_violations: u64.Bug: structural fix in advertisement path.Dump RsRoute entries; compare next_hop field against RS LAN IP and member LAN IP tables.
I11Given an identical scenario configuration and RNG seed, two independent simulation runs produce a bit-identical SimEvent sequence and final RIB/MAC/counter state (P8).Determinism is the precondition for CI regression testing and for trusting any conformance or soak result.ixp-sim — (time_ns, seq) total order (ADR-06); SmallRng seeded from scenario config (ADR-26); no wall-clock reads in the hot path.CI runs every scenario twice with the same seed; diff event log, RIB snapshot, and MAC-table snapshot; any diff fails the build.determinism_violations: u64; replay_diff_bytes gauge in CI artifact.None automatic — a violation is a structural bug in event ordering or an uncontrolled entropy source.Bisect the first diverging SimEvent by binary search over the replay log; audit for HashMap iteration or Instant::now() misuse.
I12A session held in FlapDampState::suppressed does not re-attempt ConnectRetry until its penalty decays below reuse_threshold.Prevents a flapping member from generating a reconnect storm that starves the event queue for well-behaved members.ixp-policy::flap — FlapDampState penalty/decay math gates ixp-peering's ConnectRetry scheduling.Scenario: 3 rapid up/down cycles; assert SessionState remains Idle and no ConnectRetry timer is scheduled while suppressed == true.flap_suppressed_sessions gauge; flap_penalty{member} gauge.Automatic: penalty decays on its half-life; session resumes reconnect attempts once below threshold.Plot flap_penalty over sim-time against the suppress/reuse thresholds; confirm no ConnectRetry events during the suppressed window.
