Decisions (§9) · 28 ADRs

ADR-01

Implementation language

Chosen

Rust stable, edition 2021

Rejected

Go, C++, Python

When the rejected choice is right

Go wins when contributor velocity trumps determinism; C++ wins to reuse an existing BGP/router codebase; Python wins for a throwaway teaching prototype

Why: Memory safety without GC; deterministic performance; ownership model enforces RIB mutation discipline; no data races by construction

ADR-02

Build system

Chosen

Cargo workspace, single root Cargo.toml

Rejected

Bazel, Buck, CMake

When the rejected choice is right

Bazel wins for a polyglot monorepo needing hermetic remote caching across languages

Why: Native Rust tooling; workspace unifies all 10 crates; incremental per-crate compilation; no foreign build graph

ADR-03

Crate decomposition

Chosen

10-crate workspace matching locked spine

Rejected

monolith, 3-crate split

When the rejected choice is right

A monolith wins for a tiny prototype; a coarse 3-crate split wins for a small team avoiding boundary overhead

Why: Crate boundaries enforce dependency discipline; ixp-core has zero sim deps; each crate independently testable

ADR-04

Dependency policy

Chosen

Minimal curated [dependencies]; all from crates.io; Cargo.lock committed; cargo audit in CI

Rejected

vendored tree, git deps

When the rejected choice is right

Vendored/git deps win when you must patch an upstream crate or pin to an unreleased fix

Why: Reproducible; no supply-chain surprises; floating git deps break determinism (P8)

ADR-05

Concurrency / async model

Chosen

Single-threaded discrete-event loop; no async runtime in sim core

Rejected

Tokio, async-std, Rayon

When the rejected choice is right

Tokio/Rayon win when simulating independent partitions needing no global event order, or for a real (non-deterministic) emulator

Why: Deterministic event ordering (P8) requires serial dispatch through a global priority queue; parallelism in post-processing only

ADR-06

Event priority queue

Chosen

BinaryHeap<SimEvent> (std) via Reverse wrapper for min-heap

Rejected

priority-queue, keyed-priority-queue crates

When the rejected choice is right

A keyed priority queue wins when events must be cancelled or rescheduled by key (e.g. frequent timer cancellation)

Why: Zero external dep; (time, seq) total order sufficient; no key-update needed in sim loop

ADR-07

Virtual time representation

Chosen

u64 nanoseconds via VirtualClock newtype

Rejected

wall-clock f64, u128, Duration

When the rejected choice is right

An f64 wall-clock wins for a soft real-time emulator tied to actual time; Duration wins when interoperating with std timer APIs

Why: Covers >584 years; no float precision drift; newtype prevents accidental wall-clock mixing

ADR-08

Serialization: scenario / config

Chosen

serde + toml crate (TOML files)

Rejected

YAML, RON, HOCON

When the rejected choice is right

YAML wins when scenarios are generated by existing network-automation tooling; RON wins for hand-authored deeply-nested Rust structures

Why: TOML is human-authored; standard Rust ecosystem config format; serde derive; IDE LSP support

ADR-09

Serialization: trace / RIB output

Chosen

serde + serde_json (NDJSON / JSONL)

Rejected

Protocol Buffers, MessagePack, SQLite, Parquet

When the rejected choice is right

Protobuf/Parquet win when traces are huge and consumed by analytics pipelines needing columnar scans

Why: Streamable; grep/jq-compatible; no schema migration; readable in CI logs; one event per line

ADR-10

BGP wire representation

Chosen

Internal Rust enums / structs; custom PDU types in ixp-peering

Rejected

bgpkit-parser, zettabgp, live TCP

When the rejected choice is right

bgpkit-parser / live TCP win when interoperating with real routers or replaying real-world MRT dumps

Why: Simulator, not a router; no kernel networking; full control over malformed-PDU fuzz targets; hermetic

ADR-11

RPKI validation

Chosen

Compiled Vec<Roa> fixture (prefix + origin + max_len) loaded at scenario init

Rejected

RTR protocol, routinator RPC, rpki-client

When the rejected choice is right

Live RTR/routinator wins when the simulator must reflect current real-world RPKI state, not a reproducible fixture

Why: No live daemon; reproducible; ROA fixture checked in as test data; keeps sim hermetic (P8)

ADR-12

IRR as-set expansion

Chosen

Pre-expanded HashSet<Asn> loaded from fixture at startup

Rejected

live WHOIS queries, bgpq4 subprocess, NRTM

When the rejected choice is right

Live WHOIS/bgpq4 wins when modeling current IRR data rather than a checked-in fixture

Why: Reproducible; no external I/O; fixture diffable in version control

ADR-13

Logging

Chosen

tracing crate; tracing-subscriber with EnvFilter

Rejected

log + env_logger, slog

When the rejected choice is right

log + env_logger wins for a minimal tool not needing span context or virtual-time fields

Why: Span context carries virtual-time + member_id; structured fields; compatible with tracing-flame for perf analysis

ADR-14

Metrics export

Chosen

In-process counters (u64 fields in ixp-metrics); JSON snapshot to file at sim-end or per tick

Rejected

Prometheus push, statsd, OpenTelemetry OTLP

When the rejected choice is right

Prometheus/OTLP win when the simulator becomes a long-running service scraped by monitoring infrastructure

Why: No external infra dependency; metrics are simulation observables (P9); snapshot diff-able in CI

ADR-15

Unit + integration testing

Chosen

cargo test; per-crate tests/ modules; proptest for property tests

Rejected

When the rejected choice is right

Benchmarking

When the rejected choice is right

CI/CD

GitHub Actions; matrix: stable + MSRV (1.75); jobs: fmt, clippy, test, fuzz (nightly), audit

When the rejected choice is right

GitLab CI wins on self-hosted GitLab; Jenkins wins for complex on-prem pipelines with custom runners

Code style

Rejected

When the rejected choice is right

A custom rustfmt config wins only when a strong, agreed house style diverges from defaults

ADR-20

Linting

Chosen

clippy with #![deny(clippy::all, clippy::pedantic)] in each lib.rs

Rejected

When the rejected choice is right

dylint/custom lints win when enforcing project-specific API rules clippy cannot express

ADR-21

Containerization

Chosen

Multi-stage Dockerfile: builder=rust:1.78-slim, runtime=debian:bookworm-slim; non-root process

Rejected

Alpine (musl compat issues), distroless, Nix

When the rejected choice is right

Alpine wins for smallest images when musl compat is fine; distroless wins for minimal attack surface; Nix wins for full hermeticity

Why: glibc compat for cargo-fuzz; small final image; digest-pinned base for reproducibility

ADR-22

Packaging / distribution

Chosen

cargo install-compatible binary via ixp-cli; library crates not published to crates.io in v1

Rejected

Homebrew formula, .deb, .rpm

When the rejected choice is right

System packages (.deb/.rpm/Homebrew) win when distributing to users without a Rust toolchain

Why: Target audience has Rust toolchain; cargo install --path ixp-cli sufficient; no system pkg infra

ADR-23

Reproducibility

Chosen

Cargo.lock committed; Docker base pinned by digest; RUSTFLAGS in .cargo/config.toml; explicit RNG seed in scenario

Rejected

floating deps, no lock file

When the rejected choice is right

Floating deps win only in early prototyping where velocity beats reproducibility

Why: Deterministic replay requires bitwise reproducibility of event sequence (P8)

Licensing

Chosen

MIT OR Apache-2.0 (dual)

Rejected

GPL-2, BSL, SSPL

When the rejected choice is right

GPL/BSL/SSPL win when the project must prevent proprietary forks or closed SaaS reuse

Why: Rust ecosystem convention; compatible with all crates.io deps; no copyleft constraint on integrators

ADR-25

Scenario DSL execution

Chosen

Interpreted at runtime by ixp-scenario; TOML files with [[assert]] closures registered by name

Rejected

compiled DSL, embedded Lua, embedded Python

When the rejected choice is right

Embedded Lua/Python win when scenarios need real control flow and computation beyond declarative asserts

Why: No FFI or compile step; TOML parsed by serde; asserts are Rust closures registered at scenario-load time

ADR-26

RNG for traffic generation

Chosen

SmallRng (from rand crate) seeded from scenario config field seed: u64

Rejected

thread_rng, OS entropy (OsRng)

When the rejected choice is right

OsRng/thread_rng win when modeling true randomness (e.g. security simulations), not reproducible regression

Why: Same seed → same traffic patterns → deterministic regression (P8); seed stored in trace header

ADR-27

MSRV policy

Chosen

Rust 1.75 (stable, Dec 2023); enforced via rust-version in root Cargo.toml

Rejected

latest-only, nightly

When the rejected choice is right

Nightly wins when a critical unstable feature (e.g. portable SIMD) is required; latest-only when no CI matrix is maintained

Why: Stability for CI matrix; 1.75 provides let-else, impl Trait in fn return, needed derive features

ADR-28

Error handling

Chosen

thiserror in library crates for typed errors; anyhow in ixp-cli for ergonomic context

Rejected

failure, error-chain, bare Box<dyn Error>

When the rejected choice is right

A bare Box<dyn Error> wins for a quick script; error-chain/failure win only for compatibility with legacy codebases

Why: thiserror gives typed invariant-violation errors; anyhow gives CLI error context chains

Alternative Architectures (Roads Not Taken)

Alt-A — Real-time emulator over a network namespace / container fabric.

each member = container running a real BGP daemon <--veth--> linux bridge (the "fabric")

Wins when: you need behavioural fidelity to real daemon bugs, kernel forwarding, and real timing. Embodied by: GNS3, Containerlab, Kathará. Rejected because: real time and real sockets destroy determinism (MM1–MM2) and reproducible regression; this project's value is replayable, assertable scenarios.

Alt-B — Analytical / steady-state model (no event simulation).

topology + policies --> solve for converged RIB state directly (fixed-point), no event timeline

Wins when: you only care about the final converged state, not the transient (route-leak reachability analysis). Embodied by: Batfish-style configuration analysis. Rejected because: convergence dynamics, withdrawal propagation, and fault timing (MM6) are core teaching goals that a steady-state solver hides.

Alt-C — Parallel/distributed discrete-event simulation (PDES).

partition members across worker threads; synchronize via conservative/optimistic time windows (Time Warp)

Wins when: a single core cannot sustain the event rate for very large N (millions of nodes). Embodied by: ROSS, ns-3 MPI. Rejected because: PDES synchronization reintroduces ordering complexity and threatens determinism (MM2) at the N≤1000 scale this targets, where a single core suffices (§4.1).

Alt-D — Packet-level simulation (model every frame/packet).

generate individual packets; simulate queues, serialization delay, drops per link

Wins when: you study congestion, queueing, and microburst behaviour at the data plane. Embodied by: ns-3 packet mode, OMNeT++/INET. Rejected because: the focus is the control plane (BGP/RIB/policy) and L2 reachability, not data-plane queueing; packet-level detail would explode event counts beyond the ≥ 1 M events/s budget without serving the goal.
