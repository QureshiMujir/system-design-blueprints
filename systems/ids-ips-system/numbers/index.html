4. System Constraints

Metric Target
Line rate inspected 10 Gbps sustained, 14.88 Mpps at 64B frames; burst-tolerant to 25 Gbps for ≤5s
Per-packet inspection budget ≤67 ns amortized at 10G/64B (derived in §34 C1, gated as §30 M1)
Added latency, inline IPS, p50 <80 µs
Added latency, inline IPS, p95 <400 µs
Added latency, inline IPS, p99 <2 ms
Detection latency (packet to alert) <150 ms p95
False-positive rate ≤0.01% of inspected connections at default rule set
False-negative rate on known-signature corpus ≤1%
Rule-set size 50k-150k active signatures
Match throughput ≥8 Gbps sustained against a 100k-rule set (Aho-Corasick, ADR-08)
Flow-table size 10M concurrent flows, bounded eviction
Reassembly buffer bound ≤8 MB per flow, 16 GB aggregate ceiling
Anomaly-baseline window rolling 24h with a 7-day seasonal reference
Alert rate sustainable to 50k alerts/minute before correlator backpressure
Evasion-resistance coverage 100% of Ptacek-Newsham fragmentation/overlap/TTL classes (Phase 11 gate)
RTO <5 minutes sensor restart with warm rule cache

Operational assumptions: Linux kernel 6.x; cgroup v2; hardware RSS available; PTP/NTP time sync enabled; NIC supports AF_PACKET fanout (DPDK optional, see §30).
