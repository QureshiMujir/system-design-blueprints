Core schema & types (§11)

PodSpec / Workload
  fields: pod_id, namespace, priority, resource_request, affinity, anti_affinity,
          tolerations, topology_spread_terms, gang_id (optional)
  ownership: submitted by client, owned by queue until Bound
  mutation: immutable after admission
  concurrency: read-only during scheduling cycle
  persistence: durable in state store from submission
  serialization: JSON/protobuf-compatible dict
  compatibility: additive-only field evolution (§27)

PodId: opaque string, unique within namespace

ResourceRequest
  fields: cpu (float, cores), memory (int, bytes), extended (dict[str, float])
  ownership: part of PodSpec, immutable

ResourceList: alias for a resource vector (used for allocatable, requested, limits)

Node
  fields: node_id, labels, taints, allocatable, zone/topology_labels, heartbeat_epoch
  mutation: CAS-protected updates only
  concurrency: read via snapshot, written via state store

NodeId: opaque string, unique cluster-wide

Allocatable: ResourceList representing capacity minus system-reserved overhead

NodeInfo
  fields: node (Node), bound_pods (list[PodId]), reserved (ResourceList)
  derived: fits(pod) -> bool
ClusterSnapshot
  fields: epoch, nodes (dict[NodeId, NodeInfo]), built_at
  ownership: owned by Scheduling Cycle for its duration
  mutation: immutable once built (I7)
  persistence: not persisted; rebuilt each cycle interval

SchedulingQueue
  fields: heap (priority-ordered), backoff_table
  concurrency: single-writer (leader scheduler), thread-safe enqueue

QueuedPod
  fields: pod (PodSpec), enqueued_at, attempt_count, next_eligible_at

Backoff
  fields: base, multiplier, max, jitter
  invariant: interval never decreases across consecutive failures (I12)

FilterPlugin (interface)
  method: filter(pod, node_info, snapshot) -> bool
  purity: pure function of inputs

ScorePlugin (interface)
  method: score(pod, node_info, snapshot) -> int (0-100)
  purity: pure function of inputs

Predicate: alias for FilterPlugin's boolean check

Score: int in [0, 100]

Priority: int, higher preempts lower

Toleration
  fields: key, operator, value, effect

Taint
  fields: key, value, effect (NoSchedule, PreferNoSchedule, NoExecute)

Affinity
  fields: required_terms (hard), preferred_terms (soft, weighted)
TopologySpread
  fields: topology_key, max_skew, label_selector

SchedulingCycle
  fields: pod, snapshot, stage (enum per §8 state machine), result
  ownership: one per pod per attempt

SchedulingResult
  fields: outcome (Bound | Unschedulable | Requeued), node_id (optional), reason

Binding
  fields: pod_id, node_id, epoch, committed_at
  persistence: durable in state store (I3)

Preemptor
  fields: pending_pod, candidate_nodes, victim_sets

Victim
  fields: pod_id, node_id, priority

Gang
  fields: gang_id, member_pod_ids, admit_deadline

DrfShare
  fields: tenant_id, dominant_resource, share (float)

Quota
  fields: tenant_id, resource_limits (ResourceList)

StateStore (trait)
  methods: read_nodes(), read_bindings(), cas_bind(pod_id, node_id, expected_epoch),
           watch(callback)
  concurrency: CAS is the only mutation path (I3)
  persistence: authoritative; scheduler process holds no independent durability

SchedulerError (taxonomy)
  variants: FilterRejected, BindConflict, QuotaExceeded, GangTimeout,
            DisruptionBudgetViolation, SnapshotStale, StoreUnavailable
  fields: retryable (bool), reason (str)
