3.2 Subsystem Descriptions

CLI / API (§12). Deterministic entry point: configuration loading, telemetry init, replay-seed activation, benchmark integration, artifact emission. Trust boundary: accepts untrusted source paths and CLI flags; owns no network surface in the primary deployment.

Lexer (§13). Transforms UTF-8 source into a stable, span-tracked token stream. Concurrency boundary: single-threaded per compilation unit; arena-allocated tokens are immutable after lexing and shared with the parser by index, never by pointer.

Parser (§14). Recursive-descent parser producing an arena-owned immutable AST. Owns synchronization-set-based recovery so one malformed pattern does not abort the whole compilation unit. Persistence boundary: AST nodes are never independently serialized; only the downstream pattern-ir snapshot is.

Type Resolver (§15). Assigns constructor identity, variant compatibility, wildcard typing, and tuple/slice arity. This is the semantic binding boundary — after this stage, pattern identity is closed over resolved constructor IDs (I3), not source text.

Pattern Normalizer (§16). Canonicalizes user-facing syntax (flattens OR-patterns, expands implicit captures, normalizes ranges) into the PatternMatrix form matrix decomposition requires. This is the last stage that touches surface syntax.

Pattern Matrix Builder / Specializer (§17). Implements Maranget-style specialization and default-matrix construction. Concurrency boundary: matrices are immutable snapshots; parallel specialization across independent constructor branches is permitted (ADR-08).

Exhaustiveness Analyzer (§18) / Redundancy Analyzer (§19). Both consume the same PatternMatrix snapshot and must agree on reachable constructor space (I2) — this is the system's core correctness fork; divergence between them is a P1-class defect.

Decision Tree / DAG Compiler (§20). Lowers the analyzed matrix into an acyclic decision DAG (I6) with dominance-based node merging.

Optimization Pass Pipeline (§20). Branch factoring, constructor factoring, guard hoisting, dead-test elimination, constant folding, jump threading — all semantics-preserving rewrites over the DAG produced above.

Backend Layer (§21). Two independent backends (C source emitter, bytecode emitter) consuming the same optimized DAG — the protocol boundary between compiler and runtime. Differential testing between them is the system's strongest defense against semantic drift.

Runtime / Conformance / Replay Harness (§21, §26). Executes generated artifacts, captures telemetry, validates semantics against reference behavior (rustc/OCaml fixtures), and replays any compilation deterministically from its event log (§23).

8. Domain Model — Pattern Matching Semantics & Matrix Representation

8.1 Pattern Categories

Supported pattern forms: wildcard, literal, constructor (ADT variant), tuple, slice, range, binding, OR-pattern, guarded-pattern.

8.2 Core Grammar (EBNF)

Pattern     ::= Wildcard | Literal | Constructor | Tuple | Slice
              | Range | Binding | OrPattern | GuardedPattern
Constructor ::= Ident "(" PatternList? ")"
Tuple       ::= "(" PatternList ")"
Slice       ::= "[" PatternList ("," "..")? "]"
Range       ::= Literal ".." Literal
OrPattern   ::= Pattern ("|" Pattern)+
GuardedPattern ::= Pattern "if" Guard
PatternList ::= Pattern ("," Pattern)*

8.3 Example Matrix (match value { Some(0) => A, Some(x) => B, None => C })

Row Constructor Field0 Guard Arm
0 Some 0 — A
1 Some x (binding) — B
2 None — — C

Specialization on Some yields the sub-matrix { Field0: 0 -> A, Field0: x -> B }; the default matrix (constructor None excluded) yields { None -> C }. This is the row-major representation matrix-compiler (§17) operates over.

8.4 Decision-Node State Space

State Meaning
TestConstructor evaluate variant tag against expected constructor ID
TestLiteral compare scrutinee against a literal value
BindValue store a capture into the arm's binding environment
EvaluateGuard execute a guard predicate (I5 purity-checked)
Fail fall through to the next specialization/default branch
Match emit terminal branch result (arm index)

8.5 Recovery Example

Malformed input Some((x, (unterminated tuple inside a constructor pattern) triggers: emit a partial-tuple diagnostic at the unterminated-paren span, then resynchronize the parser at the next => or | token boundary (§14 recovery, I4-consistent span emission) so the remaining match arms still parse.
