32. Back-of-Envelope Capacity Model

  • C1 — ROB memory footprint. RobEntry ≈ 32 B (rob_slot 2 B + uop_ref 8 B + ready 1 B + exception 1 B + branch_mask 8 B + completion_cycle 8 B, padded) × 4,096 max ROB entries (§4) = 131,072 B = 128 KB per core, inside the 8 GB §4 single-core ceiling by more than four orders of magnitude.
  • C2 — LSQ memory footprint. LSQ entry ≈ 40 B (address, value, age, flags) × 2,048 max entries (§4) = 81,920 B = 80 KB per core, negligible against the 8 GB ceiling.
  • C3 — Physical register file. 256 physical registers × 8 B/register = 2,048 B = 2 KB, three orders of magnitude smaller than the ROB footprint (C1), confirming register state is never the memory-budget driver.
  • C4 — Event queue sizing. p95 enqueue latency budget < 2 µs (§4) at peak 50,000,000 instr/sec (§4): 50,000,000 × 2×10⁻⁶ = 100 events in flight at the p95 boundary, rounded up to a 128-entry bounded queue per subsystem (ADR-10).
  • C5 — Raw trace write bandwidth. 64 B/instruction × 50,000,000 instr/sec (§4) = 3,200,000,000 B/sec = 3.2 GB/sec raw; with the §4 persistent-trace-amplification ceiling: 3.2 GB/sec × 1.8 = 5.76 GB/sec sustained replay-log write bound before compression.
  • C6 — Research-mode per-trace budget. 32 GB research ceiling (§4) ÷ 64 max concurrent traces (§4) = 512 MB per trace context, covering ROB (C1) + LSQ (C2) + cache state + predictor tables for one simulation instance.
  • C7 — FD budget per trace context. 4,096 FD budget (§4) ÷ 64 max concurrent traces (§4) = 64 FDs per trace context, covering the trace file, the replay log, the snapshot file, and the telemetry socket per instance with headroom.
  • C8 — Checkpoint payload size. ROB (C1, 128 KB) + LSQ (C2, 80 KB) + rename-map snapshot (256 entries × 2 B = 512 B) = 128 KB + 80 KB + 0.5 KB ≈ 208.5 KB per checkpoint.
  • C9 — Checkpoint write bandwidth. 50,000,000 instr/sec (§4) at ≈1 IPC ≈ 50,000,000 cycles/sec ÷ 100,000 cycles/checkpoint (§4) = 500 checkpoints/sec × 208.5 KB (C8) = 104,250 KB/sec ≈ 101.8 MB/sec, well inside the C5 5.76 GB/sec replay-log bandwidth ceiling.
  • C10 — Replay-validation CRC budget. p99 replay-validation latency < 10 ms (§4) over one checkpoint payload (C8, 208.5 KB): 208,500 B ÷ 0.01 s = 20,850,000 B/sec ≈ 20.85 MB/sec minimum required CRC throughput, orders of magnitude below commodity CRC32 throughput (multiple GB/sec).
