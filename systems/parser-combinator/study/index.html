33. Mental Models & First Principles

  • MM1 — A parser is a function from input-state to (output, new-state) or failure. Predicts: any two parsers compose via bind without special-casing success/failure threading (Hutton & Meijer 1996). Bug class without it: hand-threading position/ remaining-input manually, causing off-by-one span bugs. Applies in §11 (Parser/ IResult), §13 (Phase 1).
  • MM2 — Ordered choice is a function, not a set union. alt(a,b) is deterministic and directional (Ford 2004). Predicts: reordering alternatives changes which one wins on overlapping input. Bug class: assuming alt commutes like the CFG |. Applies in §14 (Phase 2), §6 (P6).
  • MM3 — Error vs. Failure is a commitment protocol, not a severity level. Error means "I haven't decided what I am yet"; Failure means "I know what I am and this input is wrong for it." Predicts where to place cut. Bug class: cutting too early (loses legitimate backtracking) or too late (garbage error messages, FM3). Applies in §17 (Phase 5), §7 (I2).
  • MM4 — Memoisation trades space for eliminating re-derivation, not for correctness. Packrat doesn't change what parses, only how fast (Ford 2002). Predicts: a grammar's result set is identical with or without memoize; only wall-clock changes. Bug class: assuming memoize fixes a semantically wrong grammar. Applies in §19 (Phase 7), §9 (ADR-05).
  • MM5 — Left recursion is a fixed-point computation. Seed-and-grow is iteration toward a least fixed point over "parse length" (Frost, Hafiz & Callaghan 2007). Predicts: growth is monotonic and terminates because input length is finite. Bug class: an empty- alternative left-recursive rule that never strictly grows (non-terminating fixed point). Applies in §19 (Phase 7), §7 (I6).
  • MM6 — A span is a claim about provenance, not just a range. Every ByteSpan asserts "this exact byte range produced this exact value" — the foundation of error messages and IDE tooling. Predicts: a combinator that discards spans downstream loses debuggability permanently. Bug class: writing a combinator that returns O without a span and being unable to add error-highlighting later without a breaking change. Applies in §11 (ByteSpan), §6 (P5).
  • MM7 — Streaming Incomplete is "not yet", never "no". The third IResult outcome is a temporal statement, not a correctness one. Predicts: a correct streaming driver never treats Incomplete as failure. Bug class: catching Incomplete in a generic error handler and surfacing it to the user as "parse error." Applies in §18 (Phase 6), §7 (I9).
  • MM8 — Monomorphisation vs. erasure is a compile-time/run-time cost swap, not a feature difference. Both produce identical parse results; only where the cost is paid differs. Predicts: a correctness benchmark comparing them is meaningless — only compile time and throughput differ. Bug class: choosing erasure "for safety" (there is no safety difference) instead of for compile-time relief. Applies in §23 (Phase 11), §9 (ADR-02, ADR-07).

Glossary (§39) · 52 terms · site-wide glossary

Parser combinator
a higher-order function that builds a parser from smaller parsers.
Stream trait
the input abstraction (§11.1); byte-slice, &str, and token-iterator backends all implement it.
IResult<I,O,E>
the canonical combinator return type: Ok, Err::Error, Err::Failure, or Err::Incomplete.
Err::Error
a recoverable parse failure; alt retries the next alternative.
Err::Failure
a committed parse failure; alt propagates it without retrying.
Err::Incomplete
a streaming-mode signal that more input is needed; not a failure.
Needed
the payload of Incomplete: Unknown or Size(n).
ParseError<I>
the structured error tree: position, expected set, context chain, kind.
ErrorKind
the closed (per-version) enum naming which leaf combinator failed.
Expected set
the deduplicated list of what would have made the current position succeed.
Context (label chain)
the stack of named rules a failure occurred inside, rendered as "while parsing X > Y".
cut
the combinator that converts Error to Failure, marking a commit point.
Commit point
the position past which a grammar is "known" and backtracking should not occur.
Ordered choice (PEG)
alt's deterministic, directional alternative-selection rule (Ford 2004).
Ambiguity
a grammar where more than one derivation matches the same input; deliberately out of scope here (§37 A4).
Backtracking
re-trying an alternative after a recoverable failure.
Packrat parsing
memoising every rule at every position for linear-time PEG parsing (Ford 2002).
Memoisation
caching a computation's result keyed by its inputs.
Left recursion
a rule that (directly or indirectly) calls itself as its first alternative.
Seed-and-grow
the algorithm that resolves left recursion inside a packrat parser (Frost, Hafiz & Callaghan 2007).
Head-set (Warth)
the tracked set of mutually left-recursive rules re-evaluated together during growth (Warth & Piumarta 2007).
Pratt parsing
operator-precedence parsing via binding powers (Pratt 1973).
Binding power
the pair of numbers (Power(left,right)) that determines operator precedence and associativity direction.
Associativity (Assoc)
whether repeated same-precedence operators group left, right, or not at all.
Fixity
whether an operator is prefix, infix, or postfix.
BoxedParser
the type-erased, dynamically-dispatched combinator wrapper (§11.8).
Monomorphisation
compiling a generic function once per concrete type instantiation.
Type erasure
hiding a concrete type behind a trait object (dyn), paying an indirect-call cost for compile-time/binary-size relief.
ByteSpan
a half-open byte range plus file identifier (§11.5).
FileId
an opaque handle identifying a source file within a MultiFileSource.
LineColumn
a 1-based line/column pair resolved on demand from a ByteSpan.
MultiFileSource
the shared source-text registry spans are resolved against.
recognize
the combinator returning the consumed slice instead of the inner parser's output.
flat_map
the monadic-bind combinator: the first parser's output selects the next parser.
map_res
maps a parser's output through a fallible function, preserving position.
Streaming mode
the combinator variant returning Incomplete on a partial buffer.
Complete mode
the combinator variant treating the buffer as final (Eof on shortfall).
Conformance suite
the corpus-driven test harness gating every combinator and shipped parser (§29).
Fixture
a named input/expected-output pair in a conformance corpus.
Snapshot testing
pinning a rendered output (e.g. an error message) and reviewing diffs explicitly (insta, ADR-15).
Fuzz target
an entry point cargo-fuzz drives with generated/mutated input.
recursion_limit
the configurable ceiling on nested combinator call depth (T1, C2).
rule_id
the integer key identifying a rule inside a MemoTable.
MemoTable
the per-invocation cache mapping (rule_id, position) to a cached IResult.
Generation counter
the Memo field tracking which seed-and-grow iteration produced an entry.
EBNF
Extended Backus-Naur Form, the grammar notation used throughout this document (§8.1).
parser! macro
the declarative grammar DSL that expands to plain combinator chains (§21).
Reference implementation
an existing, real library studied for lessons and pitfalls, not copied (§5).
Tail latency
the p99/worst-case latency tail, here derived from throughput rather than measured against a live SLO (§4 C9).
Throughput
bytes parsed per second, the primary performance axis for this library (§31).
Sealed
the release gate certifying all M-table targets, 30-day fuzz-clean status, and outside whitepaper review are met (§30).
Whitepaper
the outside-reviewed design document required for Sealed (papers/whitepaper/whitepaper-v1.0.md).
