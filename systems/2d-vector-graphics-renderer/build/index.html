⬜ Phase 0 — Repository Bootstrap + Core Geometry Types §12

Objectives
  • Initialize 2d-vector-graphics-renderer Cargo workspace with all 14 crates.
  • Implement Point, Vec2, Matrix (2×3), Rect, Transform stack with full affine math.
  • Establish CI: fmt, clippy, test, cargo-audit, cargo-deny.
  • vg-tool --version; golden-image harness skeleton (vg-diff).
Deliverable

Compilable workspace; all 14 crates build zero-warning; CI green. vg-tool --version prints. cargo test passes geometry tests.

Acceptance
  • Matrix::invert(M).map(|i| i.concat(&M)) ≈ identity within 1e-5 (I5).
  • Zero unsafe in vg-geom.
  • cargo clippy -- -D warnings clean; cargo audit clean.
  • 20+ unit tests pass; CI green on first PR.
Fixtures
  • conformance/fixtures/degenerate/singular_matrix.json — det≈0; expect MatrixError::Singular.
  • conformance/fixtures/degenerate/identity_map.json — points map to themselves.
  • conformance/fixtures/paths/rect_bounds.json — known rect bounds.
Pitfalls
  • f32 vs f64 in det: catastrophic cancellation near-singular; compute det in f64, threshold in f64; store f32.
  • Row-major vs column-vector convention: lock column-vector [x y 1]ᵀ (A29); a transposed convention silently mirrors output.
  • round_out half-pixel: device bounds must floor(x_min)/ceil(x_max) to fully contain AA edges; off-by-one drops edge pixels.
  • Transform stack leak: unbalanced save/restore corrupts later draws; assert stack empty at frame end (debug).

⬜ Phase 1 — Path Construction + Affine Transform Stack §13

Objectives
  • Implement PathBuilder (move/line/quad/cubic/close), Path (immutable, Arc-backed), subpath iteration, bounds.
  • Wire CTM stack into a minimal Canvas skeleton (no rasterization yet): save/restore/concat.
  • Reject non-finite points at build (PathError::PointNotFinite).
Deliverable

PathBuilder produces Path; vg-tool dump-path scene.json prints verbs/points/bounds; CTM stack save/restore balanced.

Acceptance
  • Round-trip: build path → iterate subpaths → reconstruct identical verb/point sequence (conformance/fixtures/paths/two_subpaths.json: exactly 2 subpaths recovered).
  • Non-finite point → PathError::PointNotFinite (no panic), verified on conformance/fixtures/degenerate/nan_point.json.
  • Bounds contain all control points (conservative): cubic control-point bbox ⊇ true curve bbox with 0 px missed control points, on conformance/fixtures/paths/cubic_bounds.json.
  • save/restore LIFO correctness over ≥8 nested save levels; restore underflow returns false (not a panic) on the 9th unmatched restore.
Fixtures
  • conformance/fixtures/paths/two_subpaths.json — verify 2 subpaths.
  • conformance/fixtures/paths/closed_triangle.json — Z cyclicity.
  • conformance/fixtures/degenerate/nan_point.json — expect PointNotFinite.
  • conformance/fixtures/paths/cubic_bounds.json — control-point-inclusive bounds.
Pitfalls
  • Implicit move_to: a line_to before any move_to must synthesize a move_to at origin (or error per policy) — pick one; document.
  • Arc clone cost: Path clone is pointer bump; do NOT deep-copy buffers.
  • Close without preceding move: ignore or error; lock behavior; affects stroke join continuity.
  • Bounds of empty path: define as empty Rect, not (0,0,0,0) which contains origin.

⬜ Phase 2 — Bézier Flattening (Adaptive Subdivision) §14

Objectives
  • Implement Flattener: quad/cubic → polylines within flatness ε in DEVICE space (P4).
  • Implement de Casteljau subdivision + Wang's-formula segment-count bound (P4, B4).
  • Handle cusps / near-degenerate curves without infinite recursion.
Deliverable

vg-tool dump-flatten scene.json --epsilon 0.25 prints polyline; segment count and max error reported.

Acceptance
  • Max chord deviation ≤ ε for all emitted segments (measured).
  • Segment count ≤ Wang's-formula bound + small constant.
  • Cusp curve (control points crossing) terminates; no stack overflow (depth cap, e.g. 24).
  • Device-space ε: scaling CTM 10× increases segments ~√10× (resolution-correct, P4).
Fixtures
  • conformance/fixtures/paths/quad_arc.json — flatten error ≤ ε.
  • conformance/fixtures/paths/cubic_loop_cusp.json — terminates; bounded segments.
  • conformance/fixtures/paths/scaled_curve.json — ε device-space behavior under CTM.
Pitfalls
  • Flattening in user space: ε then scales with CTM → facets when zoomed in. Always map control points first (P4).
  • Recursion depth blowup on cusp: subdivision never satisfies flatness near cusp; cap depth and fall back to chord.
  • Flatness metric choice: chord-distance vs control-hull; chord-distance underestimates for S-curves; use max control deviation.
  • Duplicate vertices at subdivision joints: emit shared endpoint once to avoid zero-length edges feeding raster.

⬜ Phase 3 — Coverage Rasterizer (Signed-Area Cells + Prefix-Sum AA) §15

Objectives
  • Implement the CORE: EdgeBuilder → sparse CellGrid(area,cover) → per-scanline prefix-sum → coverage spans (P2, P3, A04, A05).
  • Exact-ish analytic AA in a single pass; no supersampling.
  • Fixed-point Q24.8 accumulators; coverage clamp; area-conservation invariant (I3).
Deliverable

A8 coverage of a filled path written to surface; vg-tool render --coverage scene.json out.png shows AA grayscale. Area-conservation test passes.

Acceptance
  • Interior coverage = 255; exterior = 0; edges ∈ (0,255).
  • Area conservation: |Σcoverage/255 − analytic_area| ≤ ε·perimeter (I3).
  • Single pass: no per-pixel re-rasterization; complexity O(edges + touched cells).
  • Coverage ∈ [0,255] always (I2); no overflow on a 32k-edge star polygon.
  • Rasterize ≥ 40 M edge-cells/s (criterion).
Fixtures
  • conformance/fixtures/paths/aa_square.json — interior/edge coverage golden (A8).
  • conformance/fixtures/paths/aa_triangle.json — area conservation.
  • conformance/fixtures/paths/thin_sliver.json — sub-pixel sliver coverage < 1.
  • conformance/fixtures/paths/star_32k_edges.json — overflow/perf stress.
Pitfalls
  • Sign of cover: winding direction (edge going up vs down) sets sign; flipping it inverts inside/outside.
  • Cell at scanline boundary: an edge crossing an integer y must be split exactly there; mis-split double-counts area into the wrong scanline → bright/dark seams.
  • Fixed-point overflow: area accumulation for many overlapping edges in one cell can overflow i32; use i64 accumulation per cell OR saturate (I2); document the chosen bound.
  • Pixel-center vs corner sampling: coverage is area-based, not point-sampled; do NOT also point-sample (A29 consistency).
  • Empty span suppression: coalesce only coverage>0 runs; emitting zero-coverage pixels wastes compositing.

⬜ Phase 4 — Fill Rules (NonZero / EvenOdd) Integrated §16

Objectives
  • Integrate FillRule fold into the coverage sweep (NonZero winding, EvenOdd parity).
  • Emit final coverage spans honoring the rule; deterministic (I4).
  • Handle overlapping/self-intersecting subpaths correctly per rule.
Deliverable

vg-tool render scene.json fills with selectable rule; donut and figure-eight render correctly per rule.

Acceptance
  • NonZero: overlapping co-wound shapes → solid union; opposite-wound → hole.
  • EvenOdd: overlapping shapes → XOR; nested → alternating fill.
  • Determinism: identical path+rule → identical coverage (I4) across runs.
  • AA preserved at parity boundaries (EvenOdd edges still anti-aliased).
Fixtures
  • conformance/fixtures/paths/nonzero_union.json
  • conformance/fixtures/paths/evenodd_donut.json
  • conformance/fixtures/paths/figure_eight_nonzero.json
  • conformance/fixtures/paths/figure_eight_evenodd.json
Pitfalls
  • EvenOdd AA at crossings: naive parity (winding & 1) loses AA; must fold the FRACTIONAL winding via triangle wave, not integer parity.
  • Winding direction dependence (NonZero): subpath orientation matters; donut hole requires opposite winding — document that path authors control orientation.
  • Self-intersection at a vertex: edge ordering at shared vertex must be consistent; tie-break by deterministic ordering (I4).
  • Coincident edges (overlapping segments): cancel under NonZero if opposite-wound; ensure not double-emitted.

⬜ Phase 5 — Solid Paint + Porter-Duff Compositing (Premultiplied RGBA) §17

Objectives
  • Implement premultiplied RGBA8888 Surface + solid shader.
  • Implement all 12 Porter-Duff operators; coverage modulates source alpha (P1-table, A07).
  • First VISIBLE color output; scalar reference compositor (oracle for P14).
Deliverable

examples/hello_fill.rs renders an AA red triangle on a surface → PNG. All 12 Porter-Duff golden images pass.

Acceptance
  • Premul invariant: every output pixel r,g,b ≤ a (I1).
  • src-over identity: αs=0 span leaves dst unchanged (I11).
  • All 12 operators match golden PNGs (byte-exact for opaque cases; ≤1 LSB for blended).
  • Fill rate ≥ 200 Mpix/s scalar (baseline, pre-SIMD).
  • Coverage correctly modulates alpha (AA edge of red triangle blends, not binary).
Fixtures
  • conformance/fixtures/composite/src_over.json + golden PNG
  • conformance/fixtures/composite/{clear,src,dst,src_in,dst_in,src_out,dst_out,src_atop,dst_atop,xor,plus}.json
  • conformance/fixtures/composite/aa_edge_blend.json — AA edge over gradient bg
Pitfalls
  • 8-bit premul rounding: c*a/255 must round (+127), not truncate; truncation darkens over many composites.
  • Coverage applied twice: modulate αs once (in shade or composite, not both).
  • plus overflow: channels can exceed 255; clamp to ≤ ao after add.
  • Unpremultiply at α near 0: division explodes; guard α<eps → color=0.
  • Stride vs width confusion: write using stride for row stepping, width for pixel count; mixing corrupts rows.

Objectives

Deliverable

examples/gradient_card.rs: rounded rect filled with linear gradient → PNG. Radial/conic/spread goldens pass.

Acceptance

  • Radial: concentric rings; focal gradient matches reference.
  • Spread modes: pad clamps; repeat tiles; reflect mirrors — golden-verified.
  • Gradient transforms with CTM (rotate the canvas → gradient rotates).
  • Dithering: 8-bit gradient banding count below threshold vs un-dithered.
Fixtures
  • conformance/fixtures/gradients/linear_blackwhite.json
  • conformance/fixtures/gradients/radial_focal.json
  • conformance/fixtures/gradients/conic_sweep.json
  • conformance/fixtures/gradients/spread_{pad,repeat,reflect}.json
  • conformance/fixtures/gradients/transformed_linear.json
  • conformance/fixtures/gradients/dither_band.json
Pitfalls
  • Interpolation in sRGB vs linear: lerping sRGB-encoded values gives a different (often muddy) midpoint than linear; lock per color_space and document (P7).
  • Premul vs straight interpolation: interpolating premul colors avoids halo at transparent stops; straight causes dark/light fringes.
  • Radial degenerate (r1=0 or c0=c1,r0=r1): define behavior (solid last/first stop); avoid divide-by-zero.
  • Per-pixel sqrt cost (radial): incremental t or precomputed gradient LUT; naive sqrt tanks fill rate.
  • Stops not sorted / out of [0,1]: validate at paint build (StopsNotSorted), not per pixel.

⬜ Phase 7 — Stroking (Offset, Joins, Caps, Miter, Dashing) §19

Objectives
  • Convert stroke → fill outline (P10): offset segments ±w/2; joins miter/round/bevel; caps butt/round/square; miter-limit fallback.
  • Dashing: split path by dash-array + phase BEFORE offsetting.
  • Self-intersection resolved by NonZero fill of the outline (I7).
Deliverable

examples/stroke_dash.rs: dashed stroked curve with round caps → PNG. Join/cap/miter/dash goldens pass.

Acceptance
  • Stroked straight segment coverage = rectangle of exact width w (I7).
  • Miter limit: angle below threshold → miter; above → bevel (golden-verified).
  • Round join/cap = arc of radius w/2 (within ε).
  • Dashing: on/off pattern matches dash-array + phase.
  • Self-overlapping stroke (tight curve) fills solidly via NonZero, no holes (I7).
Fixtures
  • conformance/fixtures/strokes/line_width.json — exact band width
  • conformance/fixtures/strokes/miter_vs_bevel.json
  • conformance/fixtures/strokes/round_cap.json, square_cap.json, butt_cap.json
  • conformance/fixtures/strokes/dashed_curve.json
  • conformance/fixtures/strokes/tight_loop_selfoverlap.json
Pitfalls
  • Per-segment AA stroking double-blends: never raster each segment separately; assemble one outline, fill once (P10) — otherwise overlap regions are darker.
  • Miter spike at sharp angles: unbounded miter; enforce miter-limit fallback to bevel.
  • Normal direction at near-zero-length segment: undefined normal; skip degenerate segments; use neighbor normal for join.
  • Round join tessellation: arc flattened with same ε; coarse arcs show facets.
  • Dash phase wrap: phase modulo total dash length; off-by-one starts pattern wrong.
  • Closed vs open subpath: closed needs join at start/end vertex, open needs caps; mixing produces gaps.

Fill clipped to a circle shows AA clip edge; nested rect∩circle clip correct; save/restore balances clip.

Acceptance

  • Clip-path AA: clip boundary anti-aliased (clip coverage ∈ (0,1) at edge), composes by multiply (P6).
  • Nested clips: child ⊆ parent (monotonic shrink, I8); intersection correct.
  • restore returns to parent clip exactly.
  • Span x-range never exceeds surface ∩ clip (I9).
Fixtures
  • conformance/fixtures/clip/rect_clip.json
  • conformance/fixtures/clip/circle_clip_aa.json
  • conformance/fixtures/clip/nested_rect_circle.json
  • conformance/fixtures/clip/save_restore_clip.json
Pitfalls
  • AA clip composed by min instead of multiply: min is wrong for soft edges; two 50% clips should give 25%, not 50% (P6).
  • Clip mask resolution: mask must match surface device space exactly; mismatched origin shifts the clip.
  • Stack imbalance: clip_path inside save must be undone by restore; snapshot clip depth at save.
  • Rect clip not pixel-snapped for AA: clip-rect edges can themselves be AA (fractional rect) — decide: integer-snapped fast path vs AA rect via mask.
  • Empty clip: intersection empties; all draws become no-ops — short-circuit.

Deliverable

examples/blend_gallery.rs: all 16 blend modes side by side → PNG; goldens pass.

Acceptance

  • multiply(white) = identity; multiply(black) = black; screen symmetric.
  • Non-separable luminosity preserves dst hue/sat, takes src luma.
  • Partial-alpha blend matches full W3C equation (not just opaque case).
  • Blend composes after src-over by default; alternate operators still combinable.
Fixtures
  • conformance/fixtures/blend/separable_{multiply,screen,overlay,darken,lighten,colordodge,colorburn,hardlight,softlight,difference,exclusion}.json
  • conformance/fixtures/blend/nonsep_{hue,saturation,color,luminosity}.json
  • conformance/fixtures/blend/partial_alpha_multiply.json
Pitfalls
  • Blend on premul vs straight: blend formulae are defined on UNPREMULTIPLIED colors; blending premul values is wrong; unpremul → blend → repremul (P2/P7 interaction).
  • soft-light branch: W3C D(cd) is piecewise (cd≤0.25 special); a single formula is wrong near 0.
  • color-dodge/burn divide-by-zero: guard cs=1 (dodge) / cs=0 (burn).
  • Non-separable ClipColor clamp: SetLum can push channels out of [0,1]; ClipColor must scale toward luma, not naive clamp (shifts hue).
  • Double application with coverage: coverage modulates alpha, not the blend formula inputs.

⬜ Phase 10 — Color Management (sRGB ↔ Linear, F16, Dither) §22

Objectives
  • Implement sRGB↔linear transfer (table-based + exact); gamma-correct (linear-light) blending option (P7, A10).
  • F16x4 intermediate surfaces for linear compositing; convert to sRGB8 on store with dithering.
  • sRGB round-trip self-test at startup (I6).
Deliverable

vg-tool render --color-space linear scene.json: gradients/edges blend in linear light; F16 intermediate path; dithered 8-bit output.

Acceptance
  • sRGB round-trip ≤ 1 LSB @ 8-bit (I6); exact in F16.
  • Linear-light blend: 50% white-over-black edge ≈ 188 sRGB (linear midpoint), NOT 128 (sRGB midpoint) — verifies correct gamma.
  • F16 intermediate: no banding in smooth gradients; dither on final 8-bit store.
  • Startup self-test passes; fails fast if LUTs wrong.
  • Color-space selectable per canvas; sRGB path unchanged from earlier phases.
Fixtures
  • conformance/fixtures/color/srgb_roundtrip.json
  • conformance/fixtures/color/linear_vs_srgb_edge.json — gamma-correct AA edge
  • conformance/fixtures/color/f16_gradient.json
  • conformance/fixtures/color/dither_8bit.json
Pitfalls
  • Premultiply before or after gamma: premultiply in LINEAR space for correct compositing; premultiplying sRGB-encoded then linearizing is wrong (P7).
  • LUT precision for encode: 256-entry encode LUT is too coarse (banding); use ≥4096 or exact powf near 0.
  • F16 precision near 1.0: binary16 has ~10-bit mantissa; fine for [0,1] color; document limits.
  • Dither in wrong space: dither must be applied at quantization (linear→sRGB8), not in linear.
  • Double gamma: decoding an already-linear buffer darkens; track surface color space explicitly.

Objectives
  • Implement retained Picture (record DrawOps) + replay identical to immediate (P13, A15).
  • Conservative device-space bounds accumulation for culling.
  • SIMD span blend kernels (std::simd, target_feature dispatch) with scalar parity (P14, A09).
Deliverable

Picture records a scene; playback reproduces it pixel-identical to direct drawing; SIMD path ≥ 3× scalar fill rate; off-screen ops culled.

Acceptance
  • Record→replay surface == immediate surface (byte-exact) (P13).
  • SIMD == scalar bit-for-bit on 10k fuzzed spans (P14, I-parity).
  • Fill rate (solid src-over) ≥ 800 Mpix/s with AVX2 (≥ 3× scalar).
  • Bounds culling: ops fully outside clip/surface skipped (verified by counter).
  • Replay deterministic (I10).
Fixtures
  • conformance/fixtures/paths/record_replay_equiv.json — same scene, two paths, identical PNG
  • conformance/fixtures/composite/simd_scalar_parity.json — parity corpus
  • conformance/fixtures/paths/offscreen_cull.json — op outside surface skipped
Pitfalls
  • SIMD rounding differs from scalar: integer premul rounding must match exactly; use identical rounding (+127) in both (P14).
  • SIMD tail handling: span length not multiple of lane width; scalar tail or masked store; off-by-one on tail corrupts edge pixels.
  • target_feature mis-dispatch: running AVX2 code on non-AVX2 CPU = SIGILL; runtime detection mandatory.
  • Record/replay state drift: replay must reset CTM/clip per save/restore identically; snapshot semantics must match immediate.
  • Bounds too tight: conservative bounds must round-out (AA edges); tight bounds cull visible AA fringe.

Fixtures

All prior buckets re-validated. New:

  • conformance/fixtures/perf/reference_scene.json — 1280×720 mixed-paint scene; frame-time budget
  • conformance/fixtures/degenerate/full_sweep.json — every degenerate case in §8 in one run

Pitfalls

  • Reference oracle drift: scalar oracle must stay simple; any change re-reviewed against W3C/Porter-Duff math.
