Client / Host App — calls the Canvas immediate API (fill_path, stroke_path, clip, save/restore) or records a Picture for replay. vg-tool drives scenes from JSON and emits PNG/raw surfaces. All input is programmatic; no markup parsing.

vg-record — retained recorder; appends typed DrawOps to a DrawOpList; accumulates a conservative device-space bounding box; Replayer re-issues ops to a Canvas. Decouples scene construction from rasterization; enables culling and deferred batching.

vg::Canvas — orchestration layer holding the CTM stack and clip stack. Per draw op: maps path points through CTM, flattens curves, rasterizes to coverage spans intersected with the current clip mask, shades the spans via vg-paint, composites via vg-comp into the bound Surface. The only place rendering side effects occur.

vg-geom — Matrix (2×3 affine) compose/invert/map-point; Transform stack; Point/Vec2/Rect. All user→device mapping flows through here; perspective deferred.

vg-path — PathBuilder storing a verb stream + point array; subpath iteration; close semantics; conservative bounds. Immutable Path after build; cheaply clonable (Arc'd buffers).

vg-flatten — converts quad/cubic Béziers to polylines within flatness ε in device space (so tolerance is resolution-correct); de Casteljau subdivision bounded by Wang's formula; emits line segments to the edge builder.

vg-raster — the core. EdgeBuilder ingests polyline edges into a sparse CellGrid of (area, cover) per touched pixel; a per-scanline prefix-sum over cover produces accumulated winding, folded by FillRule into coverage ∈ [0,1]; SpanEmitter coalesces runs into Spans; clip mask multiplies coverage. Single pass, O(edges + touched cells).

vg-paint — Shader produces source premul RGBA per pixel of a span: Solid, LinearGradient, RadialGradient (two-circle/focal), ConicGradient, ImageShader (nearest/bilinear). Gradients evaluate in local space mapped through inverse CTM; spread modes pad/repeat/reflect; stop interpolation in chosen color space.

vg-color — Color, premultiply/unpremultiply, sRGB encode/decode (gamma transfer), F16 intermediate conversions, ordered dithering. Centralizes all color-space transforms so blending math is space-correct.

vg-comp — applies the Porter-Duff (Fa, Fb) factor pair, then (if a blend mode is set) B(Cs,Cd) before the over step; SIMD span kernels blend whole spans. Operates on premul RGBA (or F16 when color-correct blending is enabled).

vg-surface — owns pixel storage; formats RGBA8888-premul and F16; row stride (alignment + padding); clip-to-bounds; arena/bump allocators for transient cell grids and masks.

vg-clip — ClipStack of rectangles + coverage masks; clip-rect fast path intersects span x-ranges; clip-path rasterizes to an AA alpha mask; intersection is monotonic shrink (push narrows, restore widens).

vg-diff — offline: per-pixel + perceptual golden-image comparison; differential harness running scenes against a trusted reference rasterizer and asserting bounded coverage/color deltas.

8. Domain Model

Path Grammar (EBNF)

Path        ::= Subpath* ;
Subpath     ::= MoveTo Verb* Close? ;
Verb        ::= LineTo | QuadTo | CubicTo ;
MoveTo      ::= "M" Point ;            -- start new subpath at Point
LineTo      ::= "L" Point ;            -- straight segment to Point
QuadTo      ::= "Q" Point Point ;      -- ctrl, end (quadratic Bézier)
CubicTo     ::= "C" Point Point Point ;-- ctrl1, ctrl2, end (cubic Bézier)
Close       ::= "Z" ;                  -- segment back to subpath start
Point       ::= f32 f32 ;              -- user-space (x, y)

Storage: parallel arrays — verbs: Vec<Verb> (u8 tag) + points: Vec<Point> (consumed positionally per verb). Implicit MoveTo if first verb is a draw verb. Close makes a subpath cyclic for fill + join continuity in stroke.

Coordinate Spaces

Space Definition Transform in / out
User space API input coords (Point) × CTM → device
Device space Surface pixels; origin top-left, +y down rasterized here; ε measured here
Gradient/local space Shader-defined (gradient axis, image UV) device × CTM⁻¹ → local (per pixel)
Pixel-center sample device (x+0.5, y+0.5) sampling convention

Affine matrix (2×3, column-vector form): [x' y']ᵀ = [[a c e],[b d f]] · [x y 1]ᵀ. Compose M = A·B; invert via det = a·d − b·c, reject |det| < 1e-12 (I5). Map-point: x' = a·x + c·y + e, y' = b·x + d·y + f.

Pixel Formats

Format Layout Alpha Use
RGBA8888-premul 4×u8, R,G,B,A; premul premultiplied default surface + compositing
RGBA8888-unpremul 4×u8 straight API color readback only
F16x4 4×binary16; premul; linear-light premultiplied color-correct blend intermediate
A8 1×u8 coverage/mask clip masks, glyph coverage

Premultiply: (R,G,B,A) → (R·A, G·A, B·A, A) (A normalized [0,1]). Unpremultiply: divide by A (A>0); A=0 → color undefined (store 0).

Coverage Cell Model (core)

A Cell at integer pixel (x,y) holds two signed fixed-point accumulators:

  • cover — net vertical winding crossing the LEFT edge of the cell (Σ of edge dy fractions through this x-column at this scanline).
  • area — twice the signed trapezoidal area the edge covers INSIDE this cell (sub-pixel partial coverage).

Per scanline y, sweep x ascending maintaining acc = Σ cover[0..x]. Pixel coverage:

winding(x) = acc_before_cell + area(x) * sign / (2*ONE_PIXEL)
NonZero : coverage = clamp01(|winding|)
EvenOdd : w = winding mod 2 ;  coverage = clamp01(w > 1 ? 2 - w : w)

(ONE_PIXEL = fixed-point unit, e.g. 1<<8.) Output: contiguous Spans where coverage > 0.

Porter-Duff (premultiplied)

General: co = Cs·Fa + Cd·Fb, ao = αs·Fa + αd·Fb, where Cs,Cd are premul colors.

Operator Fa Fb
clear 0 0
src 1 0
dst 0 1
src-over 1 1−αs
dst-over 1−αd 1
src-in αd 0
dst-in 0 αs
src-out 1−αd 0
dst-out 0 1−αs
src-atop αd 1−αs
dst-atop 1−αd αs
xor 1−αd 1−αs
plus (lighter) 1 1

Coverage modulation: αs ← αs · coverage; premul Cs ← Cs · coverage (since premul, both scale together). plus clamps channels to ≤ ao.

Blend Modes (W3C L1)

Blend produces B(Cs,Cd) on UNPREMULTIPLIED colors, then composited (default src-over) and re-premultiplied. Separable (per channel):

Mode Formula B(cs,cd)
normal cs
multiply cs·cd
screen cs+cd−cs·cd
overlay hardlight(cd,cs)
darken min(cs,cd)
lighten max(cs,cd)
color-dodge cd==0?0 : cs==1?1 : min(1, cd/(1−cs))
color-burn cd==1?1 : cs==0?0 : 1−min(1,(1−cd)/cs)
hard-light cs≤.5 ? 2·cs·cd : screen(2·cs−1,cd)
soft-light piecewise (W3C); uses D(cd)
difference
exclusion cs+cd−2·cs·cd

Non-separable (operate on RGB triple via helpers Lum(C)=0.3R+0.59G+0.11B, Sat(C)=max−min, SetLum, SetSat):

Mode Definition
hue SetLum(SetSat(Cs, Sat(Cd)), Lum(Cd))
saturation SetLum(SetSat(Cd, Sat(Cs)), Lum(Cd))
color SetLum(Cs, Lum(Cd))
luminosity SetLum(Cd, Lum(Cs))

Premul interaction: with partial αs/αd the full L1 formula scales blend by (1−αd)·Cs + αd·B(Cs,Cd); implemented per W3C compositing equation.

Gradients

Type Parameter t(x,y) in local space
Linear `t = ((P−P0)·(P1−P0)) /
Radial (two-circle) solve `
Conic / sweep t = (atan2(y−cy, x−cx) + bias) / 2π

t then mapped through spread mode → stop lookup (binary search in sorted stops) → interpolated color. Stops: (offset∈[0,1], Color) ascending. Interpolation space: premul-vs-straight and sRGB-vs-linear configurable. Spread: pad (clamp), repeat (t mod 1), reflect (triangle wave). Dither applied on 8-bit output to suppress banding. Radial: incremental t evaluation avoids per-pixel sqrt along scanlines.

Worked Examples

Interior pixels coverage=1.0 → dst = red
Edge pixels coverage∈(0,1) → dst = lerp(bg, red, coverage)  (premul)
Σ coverage ≈ triangle area (3200 px²) within ±ε  (I3)

Linear gradient, pad

Gradient axis P0=(0,0)→P1=(100,0); stops [(0,black),(1,white)]
Pixel (50,y): t=0.5 → gray; (120,y): t=1.2 → pad → white

src-in compositing

src=opaque blue circle, dst=red square; op=src-in
result = blue where dst α>0, else transparent  (Fa=αd, Fb=0)

Degenerate / failure paths

- Empty path (no verbs): zero spans; surface unchanged.
- Subpath "M 5 5" only: no area; fill emits nothing; stroke emits a dot if round/square cap.
- Matrix det≈0 (collapsed CTM): reject map; raise MatrixSingular (I5).
- Cubic with coincident control points (cusp): flattening still terminates via Wang bound; no infinite recursion.
- NaN/Inf in points: rejected at PathBuilder (PointNotFinite); never reach raster.
- Coverage accumulator overflow (pathological huge winding): saturates to clamp01 (I2,I11).
- Gradient with 0 stops: error GradientNeedsStops; 1 stop: solid that color.
