Hard questions

Self-examination questions from the blueprint; each points at the section where the answer lives.

  1. The area-conservation invariant (I3) states Σ coverage ≈ analytic area ± ε·perimeter. Derive why the (area, cover) + prefix-sum formulation satisfies this invariant for a convex polygon, and explain under which geometric configuration the ε·perimeter slack is tight. What does that configuration imply about Phase 3's tolerance of the edge-walk DDA? (§8 Coverage Cell Model, §7 I3, Phase 3, ADR-A05)
  2. P2 states premultiplied alpha is canonical. Yet blend modes (Phase 9, §8 Blend Modes) require unpremultiplying before applying B(Cs,Cd). Explain the full round-trip: when is premul maintained, when must it be broken, and why does doing the blend on premul values give wrong results even for a fully-opaque source? (§6 P2, §8 Blend Modes, Phase 9, P1)
  3. ADR-A04 rejects active-edge-table + N× supersampling in favor of signed-area cells. For a scene consisting entirely of axis-aligned rectangles (the simplest possible path), compute the theoretical memory access ratio between the two approaches, and explain why the cell approach still wins even in this degenerate case. (§9 ADR-A04, §8 Coverage Cell Model, Phase 3, MM1)
  4. The flattening tolerance ε is measured in device space (P4, ADR-A06). A host application renders the same vg::Picture at two resolutions: 72 DPI (CTM scale 1×) and 288 DPI (CTM scale 4×). How does segment count scale between the two cases per Wang's formula, and what is the resulting ratio of rasterization work? At what point does the increased segment count become the bottleneck compared to the span-blend stage? (§6 P4, Phase 2, §4 Flatten tolerance, Phase 13, I3)
  5. I10 mandates bit-identical output across runs. The tile-parallel rendering model (ADR-A17) assigns independent tiles to worker threads. Prove or disprove that tile-parallel rendering satisfies I10, and identify the one step in the pipeline where non-determinism could be introduced even with independent tiles. (§7 I10, §9 ADR-A17, Phase 12, §6 P1)
  6. The scalar reference compositor (ADR-A20, P14) is the correctness oracle for SIMD kernels. If the scalar oracle itself has a one-LSB rounding error in (c*a+127)/255 premul, how does that propagate into the golden-image differential test in Phase 13? Should the oracle track the W3C specification exactly or match the hardware-optimized path? What is the standard industry resolution? (§9 ADR-A20, §6 P14, §7 I1, Phase 13, Phase 5)
  7. Clip composition uses alpha multiplication (P6, ADR-A14). Given three nested clip-paths each with 50% maximum edge coverage, compute the final edge coverage at the intersection boundary. Now explain how that number interacts with the premul representation at the compositor (Phase 8, Phase 5) and whether the result satisfies I1. (§6 P6, §7 I1, I8, Phase 8, ADR-A14)
  8. The Porter-Duff xor operator has Fa = 1−αd, Fb = 1−αs. For a fully-opaque red circle src-over'ed onto a fully-opaque blue dst, xor produces a transparent result. Explain why this is correct, then describe the scenario in which xor is the right compositing operator for a UI toolkit implementing focus-ring overlays. How does coverage modulation interact with xor at the AA fringe? (§8 Porter-Duff table, Phase 5, §6 P3, I1)
  9. §4 states the arena ceiling is 64 MB and allocation after warm-up is 0 in the hot loop (P5, ADR-A16). A host renders a 2000×2000 surface with a single path that touches every pixel at least once. Enumerate the three largest arena consumers, compute their peak sizes, and verify whether the 64 MB ceiling is respected. If not, which ADR governs the fallback? (§4 Cell-grid memory, §7 I12, Phase 3, Phase 8, ADR-A16, ADR-A17)
  10. EvenOdd fill requires folding fractional winding through a triangle wave to preserve AA at parity boundaries (Phase 4, §15.6). Integer parity (winding & 1) correctly classifies the interior but destroys AA. Explain the mathematical reason: what does the triangle-wave fold compute that integer parity does not, and what is the worst-case error in coverage if integer parity is used for a near-boundary pixel with winding ≈ 0.95? (§8 Coverage Cell Model, Phase 4, I2, I4, MM1)
  11. The gradient LUT (Phase 6, §18.7) precomputes color stops into a 256-to-1024-entry array. ADR-A12 defaults to premul-linear interpolation. A stop pair is (0, transparent-black) and (1, opaque-white). Compute the midpoint color in premul-linear space vs sRGB-straight space and explain which one is correct for CSS gradients and why the other produces a "dark band" at t=0.5. (§8 Gradients, §6 P7, Phase 6, ADR-A12, MM5)
  12. The SIMD kernel (Phase 12) must produce bit-identical output to the scalar oracle (P14, ADR-A09). AVX2 uses _mm256_mulhi_epu16 for 8-bit premul but the scalar path uses (c*a+127)/255. Derive whether these two formulas are bit-identical for all 256×256 input combinations and, if not, which ADR resolves the conflict and how. (§9 ADR-A08, ADR-A09, §6 P14, Phase 12, Phase 5)
  13. The stroke→fill conversion (P10, ADR-A13) resolves self-intersection via NonZero fill. A tight spiral path, when offset by w/2, produces a self-intersecting outline where the inner offset loops back and crosses the outer offset. Explain exactly how NonZero fill correctly solidifies this region, and identify the failure mode that occurs if EvenOdd is used instead. (§8 Stroking, §6 P10, Phase 7, I7, MM9)
  14. §4 states deterministic output requires no FP nondeterminism. The sRGB_to_linear table uses f32 values (ADR-A10). On x87 and SSE2 targets, intermediate 80-bit precision can cause encode(decode(x)) ≠ x at the 1-LSB level. How does the startup self-test (I6, Phase 10) detect this, what does the recovery path do, and what does ADR-A28 contribute to this guarantee? (§7 I6, §9 ADR-A10, ADR-A28, Phase 10, Phase 0)
  15. ADR-A04 states the signed-area cell approach is O(edges + touched cells). Construct a worst-case scene that degrades this bound toward O(surface area) and explain the architectural defense: which §4 constraint, which invariant, and which ADR bound the worst case. (§9 ADR-A04, §4 Cell-grid memory, §7 I12, ADR-A16, Phase 3, Phase 13)
  16. Non-separable blend modes (Phase 9) require SetLum which can push RGB channels outside [0,1]; ClipColor must then scale toward the luminance value rather than clamping per channel. Prove that naive per-channel clamping shifts the hue, and explain why the ClipColor scale-toward-luma approach preserves hue while satisfying r,g,b ∈ [0,1]. (§8 Blend Modes, Phase 9, I1, P2, MM2)
  17. The display-list bounds accumulator (Phase 12, ADR-A15) computes conservative device-space bounds for culling. Explain why it must round_out the bounds (as in §12.6 round_out half-pixel pitfall) and what class of visual regression occurs if bounds are computed tightly without rounding. Which phase gate catches this regression? (§12.6, §9 ADR-A15, Phase 12, I3, Phase 13)
  18. The sRGB encode LUT uses 4096 entries (§22.6). A 256-entry encode LUT produces banding visible as distinct luminance steps. Derive the maximum quantization error for a 256-entry LUT vs 4096 entries in the sRGB 0.01–0.1 range (where the curve is steepest), and explain how this interacts with the ordered dithering step (ADR-A11, Phase 10). (§4 Color round-trip error, Phase 10, ADR-A10, ADR-A11, I6, MM5)
  19. Tile-parallel rendering (ADR-A17) assigns tiles to independent workers. The clip stack at the time of a DrawOp may contain clip-path masks that were computed in a single-threaded phase. Describe the data-flow: when are clip masks computed, how do they get to each tile worker, and why does the immutable-scene constraint guarantee this is race-free? (§9 ADR-A17, Phase 8, §6 P1, I8, I10)
  20. Phase 13's differential harness compares this engine against an external reference (tiny-skia or Cairo offline, ADR-A20). Suppose a specific blend mode (e.g., soft-light) has a 2-LSB difference from the reference. Describe the decision tree: is this a bug in this engine, a difference in W3C interpretation, or a known rounding divergence? What artifact in the conformance suite resolves the ambiguity? (Phase 13, ADR-A20, Phase 9, §6 P14, §8 Blend Modes)
  21. §4 sets the surface max dimension at 32 767 px/axis because device coords are i16. The round_out in vg-geom uses f64 for the determinant (§12.6). Explain the precision chain from a user-space f32 point through the f32 CTM to the i16 device coordinate, and identify the step at which numerical precision is most at risk for coordinates near the 32k boundary. (§8 Coordinate Spaces, §11 Matrix, Phase 0, Phase 2, ADR-A05, I5)
  22. P13 (Retained and immediate share one path) requires that Picture::playback produces an identical surface to direct Canvas draws. Identify three state transitions in the Canvas that, if snapshotted incorrectly during record, would cause divergence on replay, and name the test in Phase 12 that catches each. (§6 P13, Phase 12, §7 I10, ADR-A15, Phase 13)
  23. The plus (lighter) operator clamps output channels to ≤ ao after addition (§8 Porter-Duff). Explain what visual artifact occurs if the clamp is omitted for two fully-opaque sources, and derive the maximum channel value before clamping in the all-ones (white over white) case. Why does this operator require a distinct clamp step that src-over does not? (§8 Porter-Duff table, Phase 5, I1, P2)

Mental Models & First Principles

  1. MM1 — The signed-area cell is an exact integral of edge coverage, not a sample. Predicts: why summing (area, cover) over a scanline equals the true geometric fraction of each pixel covered by the filled region. Without it: you add supersampling (4× memory, still aliased at high frequency) or misunderstand why the prefix-sum sweep works. Applied: §8 Coverage Cell Model, §3 (vg-raster), Phase 3.

  2. MM2 — Premultiplied alpha is the only representation that makes src-over a linear blend. Predicts: that compositing N transparent layers in premul gives the same result regardless of ordering (where correct), and that straight-alpha compositing introduces a nonlinear dark-fringe artifact on AA edges. Without it: you write dst = src*α + dst*(1−α) with straight values and produce visibly darkened fringe pixels at every partially-covered edge. Applied: §8 Porter-Duff, §6 (P2), Phase 5, Phase 9.

  3. MM3 — Bézier flatness error is a second-difference norm, not a chord-to-control-point distance. Predicts: Wang's formula and the correct recursion termination criterion; a control-hull check underestimates error for S-curves. Without it: you terminate subdivision too early on S-shaped cubics and produce visible facets; or you recurse forever on cusps. Applied: §6 (P4), Phase 2 (wang.rs, bezier.rs, ADR-A06).

  4. MM4 — Porter-Duff (Fa, Fb) factors are derived from the principle that no pixel is counted twice. Predicts: the full table of 12 operators from first principles by enumerating the four regions (src-only, dst-only, both, neither) and asking which survives. Without it: you memorize a table without understanding why src-in is Fa=αd, Fb=0 or how to derive a new operator. Applied: §8 Porter-Duff table, Phase 5, Phase 9 (W3C compositing equation).

  5. MM5 — sRGB is a perceptual encoding; blending in it computes the wrong midpoint. Predicts: that the 50% luminance midpoint between white and black is sRGB 188, not 128; and that AA-edge blending in sRGB-encoded space makes edges appear too dark. Without it: you blend in sRGB, gradients look muddy, and AA edges are perceptually too thin. Applied: §6 (P7), §4 (Color round-trip ≤1 LSB), Phase 10 (sRGB↔linear, F16 intermediate, ADR-A10).

  6. MM6 — Clip composition is multiplicative, not MIN. Predicts: that two 50%-transparent clip masks nested together yield 25% coverage, not 50%; and that min(a,b) is wrong for soft AA clips. Without it: you implement apply = min(draw_cov, clip_cov), overlapping soft clips are too bright, and nested clips do not correctly narrow the visible region. Applied: §6 (P6), §8 (Clipping), Phase 8 (ADR-A14, I8).

  7. MM7 — Device-space tolerance is the only resolution-correct criterion for flattening. Predicts: that flattening curves in user space under a 10× scale CTM produces visible facets (ε is 10× too large in device pixels); and that device-space ε self-corrects at all zoom levels. Without it: you flatten once in user space and get faceted curves when the canvas is scaled. Applied: §6 (P4), §4 (Flatten tolerance ε = 0.25 px device space), Phase 2.

  8. MM8 — The span is the correct SIMD granularity because it is a contiguous, homogeneous memory region. Predicts: that per-pixel virtual dispatch destroys throughput; that coalescing coverage runs into spans before blending is a strict prerequisite for SIMD efficiency; and that span length is the primary determinant of fill-rate headroom. Without it: you write a per-pixel compositor and observe 10× lower fill rate than the memory-bandwidth ceiling. Applied: §6 (P9), §4 (Fill rate ≥800 Mpix/s), Phase 12 (ADR-A09).

  9. MM9 — Stroke-to-fill conversion avoids double-blending at joins because the entire outline is one filled path. Predicts: that per-segment AA stroking darkens overlap regions at joins and caps; and that assembling the full outline and calling fill_path(NonZero) once is the only correct approach. Without it: you rasterize each segment with AA separately, overlapping strips at joins blend twice, and seam artifacts are visible at every corner. Applied: §6 (P10), §8 (Stroking), Phase 7 (ADR-A13, I7).

  10. MM10 — Determinism requires a fixed total order on every floating-point operation, not just an absence of data races. Predicts: that parallel tile reductions which sum coverage in non-deterministic order produce different output bytes across runs even with the same scene, breaking golden-image gates. Without it: you enable tile parallelism, the pixel hash varies between runs, and the CI golden gate fails spuriously. Applied: §6 (P1), §4 (Determinism: bit-identical), Phase 13 (I10, ADR-A17, ADR-A28).

Glossary · 52 terms · site-wide glossary

Path
Sequence of subpaths built from move/line/quad/cubic/close verbs in user space
Subpath
A connected run of segments from a move_to to the next move_to/close
Verb
Path command tag: Move, Line, Quad, Cubic, Close
Quadratic Bézier
Curve with 1 control point; B(t)=(1−t)²P0 + 2(1−t)t·C + t²P1
Cubic Bézier
Curve with 2 control points; flattened to lines for raster
de Casteljau
Recursive subdivision algorithm splitting a Bézier at parameter t
Flattening
Converting curves to polylines within a flatness tolerance
Flatness (ε)
Max allowed deviation of a polyline from the true curve (device-space px)
Wang's formula
Closed-form bound on subdivision segment count for a given ε
Affine matrix (2×3)
Linear+translation transform (a,b,c,d,e,f); maps user→device
CTM
Current Transformation Matrix; composition of stacked transforms
User space
API input coordinate space (before CTM)
Device space
Surface pixel space (after CTM); origin top-left, +y down
Fill rule
Interior test: NonZero (winding ≠ 0) or EvenOdd (parity)
NonZero
Pixel inside if signed winding number ≠ 0
EvenOdd
Pixel inside if crossing parity is odd
Winding number
Signed count of edge crossings around a point
Coverage
Fraction of a pixel covered by a shape ∈ [0,1]; drives AA
Signed-area cell
Per-pixel (area, cover) accumulator for analytic AA
area / cover
Sub-pixel trapezoidal area / net vertical winding crossing in a cell
Prefix-sum sweep
Left→right accumulation of cover converting cells to coverage
Span
Contiguous run of pixels on a scanline with coverage > 0
Anti-aliasing (AA)
Smoothing edges via partial pixel coverage
Premultiplied alpha
Color channels pre-scaled by alpha (c ≤ a); canonical compositing form
Porter-Duff
Algebra of 12 alpha-compositing operators (co=Cs·Fa+Cd·Fb)
Fa / Fb
Source / destination coverage factors per Porter-Duff operator
src-over
Default operator: source painted over destination
Blend mode
Per-pixel color combination (multiply, screen, ...) before compositing
Separable blend
Blend applied independently per RGB channel
Non-separable blend
Blend on the RGB triple (hue/saturation/color/luminosity)
SetLum / SetSat
Helpers adjusting luminosity/saturation of an RGB triple
Gradient
Spatially varying color: linear, radial, conic
Color stop
(offset, color) control point defining a gradient ramp
Spread mode
Behavior outside [0,1] gradient param: pad/repeat/reflect
Stroke
Outline of a path with a given width; converted to a fill
Join
Connection style between stroke segments: miter/round/bevel
Cap
End style of an open stroke: butt/round/square
Miter limit
Threshold past which a miter join falls back to bevel
Dashing
Splitting a path into on/off segments before stroking
Clip
Restriction of drawing to a region; an alpha mask multiplied into coverage
Clip stack
Nested clips intersected monotonically (push shrinks, restore widens)
Shader
Pure function mapping device coords to source premul color
sRGB
Standard perceptual color space with a gamma transfer function
Linear light
Linear (gamma-decoded) color space; correct space for blending
Gamma
Nonlinear transfer between perceptual and linear intensity
Dithering
Adding patterned noise to reduce 8-bit quantization banding
F16 (binary16)
Half-precision float used for linear intermediate surfaces
Display list / Picture
Retained record of draw ops for replay/culling
Arena allocator
Bump allocator reset between draws; bounds transient memory
SIMD
Single-Instruction-Multiple-Data; vector span blending (SSE2/AVX2/NEON)
Tile
Independent sub-rectangle of the surface for parallel rendering
Stride
Bytes per surface row (≥ width × bpp; may be padded)
