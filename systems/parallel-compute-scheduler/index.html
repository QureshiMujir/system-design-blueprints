3.2 Subsystem Descriptions

ThreadPool / pcs-pool. Central coordinator. Owns N worker thread handles, a global Injector<Task> for external/overflow submissions, PoolConfig (thread count, stack size, SchedPolicy, affinity), and the result of hardware topology detection (CpuTopology: core IDs, NUMA node membership, cache sizes). Data in: Task submissions from user code and from the Injector. Data out: tasks distributed to per-worker deques; wakeup signals to parked workers. Concurrency boundary: Injector is MPMC; topology is read-only after construction; worker handles are owned exclusively. No persistence boundary; pool state is purely in-process.

Worker / pcs-worker. One OS thread per worker, pinned to a physical core via CpuSet. Owns a ChaseLevDeque<Task> (local deque, private push/pop); holds an array of Stealer<Task> handles into every other worker's deque. Execution loop: pop own deque (LIFO) → try steal from a victim (FIFO, victim chosen by XorShift RNG biased to NUMA-local peers) → park (OS futex) on empty. Unparked by the thread that pushes a task. Thread-local CURRENT_WORKER: *const Worker for fast self-identification during recursive spawns. Concurrency boundary: deque Bottom is accessed only by owner; Top is contested by thieves via CAS.

ChaseLevDeque / pcs-deque. Lock-free circular buffer of task pointers. Bottom: AtomicUsize (owner's write cursor), Top: AtomicUsize (thieves' steal cursor, monotonically increasing). Owner push: write slot, Release fence, increment Bottom. Owner pop (LIFO): decrement Bottom tentatively, SeqCst fence to race with steals, CAS on Top only if single-element contention. Thief steal (FIFO): read slot at Top, CAS Top from old to old+1; fails → retry or abort. Growable: when Bottom - Top == capacity, allocate 2× buffer, copy, publish via AtomicPtr; old buffer deferred-freed when all stealers have passed the epoch. ABA prevented because Top is monotonically increasing (never wraps in practice for u64). Data in: Task pushed by owner or injected. Data out: Task popped by owner or stolen by thief.

pcs-graph / TaskGraph. Maintains a DAG of GraphNode entries. Each node: { task: Task, pending_deps: AtomicUsize, successors: SmallVec<NodeId> }. add_edge(pred, succ) increments succ.pending_deps. On pred completion, for each successor decrement pending_deps; if it reaches 0, push to the completing worker's local deque (locality hint). Cycle detection at add_edge time via DFS reachability check (offline, before execution). Completion latch signals when all nodes are Done. Data in: node insertion + edge insertion; task-done notifications from worker loop. Data out: Ready tasks pushed to worker deques.

pcs-parallel / Scope + Data-parallel. Scope<'s> borrows the calling stack frame's lifetime; spawn pushes a task carrying a 's-scoped closure; Scope::wait blocks until pending: AtomicUsize reaches 0 (using Latch). Panic in any scope task poisons the scope; wait re-raises via std::panic::resume_unwind. ParallelIterator wraps a Producer (range or slice) with split_at(mid) -> (L, R); recursive halving spawns right half, processes left half; leaf threshold controlled by SchedPolicy. Adaptive: if steal pressure is low (deque non-empty), split coarser. Data in: user closures + data ranges. Data out: tasks pushed to local deque; results collected into output buffer or reduction accumulator.

pcs-sync / Future + primitives. Promise<T> is the write end (fulfills one Future<T>). Future<T>::wait does not block the OS thread: it runs tasks from the local deque (work-helping) until the latch fires. Latch = AtomicUsize counting down to 0 with a parked-waiters list. Barrier coordinates N parties. WaitGroup tracks in-flight task count for pool quiescence. Concurrency boundary: Promise::fulfill is a once-write; Future::wait is poll-then-help loop with no spinlock.

pcs-sched / SchedPolicy. Stateless policy object consulted by the worker loop at three decision points: (1) victim selection order (random, NUMA-local-first, round-robin); (2) continuation disposition (work-first: push continuation, run child; help-first: push child, run continuation); (3) granularity threshold for splitters. Owns no mutable state; parameterized by PoolConfig::policy. SchedPolicy is chosen at pool construction time and does not change at runtime (no dynamic adaptation yet; deferred to Phase 7 adaptive tuning).

pcs-numa / NUMA domains. Groups workers into NumaDomain sets based on topology query (hwloc or /sys/devices/system/node). Each domain has its own sub-injector for locality-preserving overflow. Worker::steal tries within-domain stealers first (numa_local_stealers), then cross-domain (remote_stealers), reducing cross-socket cache-coherence traffic. Allocation hint: task closures allocated on the worker's NUMA node (numactl-style). Data flow: topology is immutable after pool construction; domain membership encoded in Worker::numa: NumaNode.

pcs-metrics / pcs-trace. SchedMetrics: per-worker StealStats (steals_attempted, steals_won, tasks_run, park_count, idle_ns) stored as AtomicU64; aggregated on demand via metrics_snapshot(). Per-task spans in pcs-trace capture (task_id, worker_id, enqueue_ns, start_ns, done_ns); written to a ring buffer; flushed to flamegraph JSON on demand. Sampling flag (TRACE_SAMPLE_RATE) controls overhead: 0 = disabled, 1 = every task, N = 1-in-N. Concurrency boundary: all metrics writes are atomic; trace ring buffer is per-worker (no contention on write path).

8.3 Chase-Lev Deque Memory Layout

  ChaseLevDeque<T>
  ┌──────────────────────────────────────────────────────┐
  │  bottom: AtomicIsize   (owner pushes here; wraps mod capacity) │
  │  top:    AtomicIsize   (thieves steal from here; monotonic)    │
  │  buf:    AtomicPtr<CircularBuf<T>>  (resized via new alloc)    │
  └──────────────────────────────────────────────────────┘

  CircularBuf<T>
  ┌──────────────────────────────────┐
  │  capacity: usize  (power of 2)   │
  │  data: [UnsafeCell<T>; capacity] │
  └──────────────────────────────────┘

Access semantics:

Operation Actor Order Returns Notes
push(t) owner Release on bottom () Grow if bottom-top >= capacity; allocate new buf, copy, swap ptr (Release), update bottom
pop() owner SeqCst on bottom decrement, Acquire-load top Option<T> LIFO; if bottom <= top after decrement, CAS top (last item race with thief)
steal() thief Acquire top, SeqCst CAS Option<T> FIFO; CAS top from observed to +1; fails if another thief wins or owner empties

ABA prevention: top is monotonically increasing (never reset); old top values cannot recur within a deque's lifetime.

Memory ordering matches Le et al. (PPoPP 2013): push uses Release on bottom; steal uses Acquire on top, SeqCst CAS; pop uses SeqCst on bottom to fence against concurrent steals.

Victim selection order (SchedPolicy):

  1. LocalityAware: own-NUMA workers (shuffled by XorShift RNG), then cross-NUMA workers.
  2. WorkFirst: random uniform over all workers.
  3. HelpFirst: prioritize workers with deepest queues (sample two, pick max).

8.5 Fork-Join Execution Model

join(a, b) — work-first semantics:

  thread T:  push(b) → run(a)
               │            │
               │         a done → pop(b) [if still on deque] → run(b)
               │                 OR b stolen by T' → T runs other tasks
               │                                    → T waits via Latch
               ▼
             join returns after both Done

Scope<'s> lifetime contract:

  scope_enter: allocate Scope on stack; latch count = 0
     │
     ├─ spawn(f): latch.increment(); push Task(f) to local deque
     │
     └─ scope_exit: latch.wait()
          → executing worker runs other tasks while waiting (no idle block)
          → last task Done: latch.decrement_to_zero() → unblock scope owner

Panic capture: each task's closure wrapped in catch_unwind; panic payload stored in Task.panic_payload: Option<Box<dyn Any>>; re-raised at scope_exit after all tasks terminate (I7, I8).

8.6 Task DAG Model

EBNF for DAG construction:

graph      ::= 'TaskGraph::new()' { node_decl | edge_decl } 'graph.submit(pool)'
node_decl  ::= 'graph.add_node(task_fn)' '->' 'NodeId'
edge_decl  ::= 'graph.add_edge(pred: NodeId, succ: NodeId)'

Internal node state:

GraphNode {
  task:         Task,
  pending_deps: AtomicUsize,   // decremented by each completing predecessor
  successors:   Vec<NodeId>,   // notified on this node's completion
}

Readiness propagation (per-node on completion): for each successor in the completing node's successors list, the runtime performs an AcqRel fetch_sub(1) on that successor's pending_deps. Whichever decrement observes the return value 1 (meaning it drove the counter from 1 to 0 — the last outstanding dependency) is the sole decrement that pushes the successor's task to a worker deque, preferring the completing worker's own deque for locality (MM8). All other decrements return a value greater than 1 and take no further action, so the push happens exactly once with no lock or secondary check.

Cycle detection: topological sort at graph.submit(); reject if no ordering exists (return Err(CycleError)).

Completion latch: TaskGraph owns a Latch; the final node's completion fires it; graph.wait() participates in scheduling while waiting.

8.7 Data-Parallel Splitter Model

  • Producer<T>
    • len() -> usize
    • split_at(mid: usize) -> (Producer<T>, Producer<T>) // must be cheap O(1)
    • into_iter() -> impl Iterator<Item=T> // leaf execution

Recursive halving: the splitter compares the producer's remaining length against the granularity threshold. At or below threshold, it runs the leaf sequentially by handing the producer's iterator directly to the user closure f. Above threshold, it splits the producer at its midpoint into a left and right half and recurses on both halves through join — the left half runs on the spawning worker (work-first, ADR-21) while the right half is exposed on the deque for stealing. Recursion bottoms out only when every leaf has reached the threshold, so the tree depth is O(log(total_len / threshold)).

Granularity threshold: max(MIN_GRAIN, total_len / (num_threads * OVERDECOMPOSE_FACTOR)); default OVERDECOMPOSE_FACTOR = 8 (P6).

Adaptive splitting: if steal pressure detected (steal_ratio > 0.5 in last epoch), lower threshold by 25%; if low pressure, raise by 10% (bounded by [MIN_GRAIN, MAX_GRAIN]).

Primitives and associativity requirements:

Primitive Combiner constraint Output
parallel_for none (side-effectful) ()
parallel_map none Vec<B>
parallel_reduce associative, identity required T
parallel_scan associative, identity required Vec<T> (prefix sums)

I9: parallel_reduce result equals sequential left-fold for associative operators; float reassociation documented as non-default.

8.8 Future / Promise Ownership Model

Promise<T>  ──write-once──►  inner: Arc<PromiseInner<T>>
Future<T>   ──read──────────►  inner: Arc<PromiseInner<T>>

PromiseInner<T> {
    value:   UnsafeCell<Option<T>>,
    state:   AtomicU8,          // 0=Pending, 1=Fulfilled, 2=Panicked
    waiter:  AtomicPtr<Latch>,  // registered by Future::wait()
    conts:   Mutex<Vec<Task>>,  // continuation tasks chained post-fulfill
}

Future::wait() contract: does not block the OS thread; instead, the waiting worker runs other tasks from its deque until the PromiseInner.state transitions to Fulfilled/Panicked (spin + park via the embedded Latch).

Continuation chaining: future.then(|val| ...) registers a Task in conts; on fulfillment all conts are pushed to the fulfilling worker's deque (locality).

8.9 Sync Primitives Semantics

Primitive Count direction Release trigger Wait behavior
Latch decrement to 0 count == 0 participating (runs tasks)
Barrier increment to N all N arrive participating
WaitGroup decrement to 0 count == 0 participating

"Participating wait": the blocking worker does not park the OS thread; it polls its local deque and attempts steals until the condition is satisfied.

8.10 NUMA Domain Model

NumaNode {
    id:        u32,
    workers:   Vec<WorkerId>,
    injector:  Injector<Task>,    // per-domain overflow queue
    memory:    MemoryBinding,     // OS NUMA memory policy handle
}

Steal order (I9 in context of Phase 9):

  1. Own worker's deque (local pop).
  2. Other workers in same NumaNode (local steal).
  3. Per-domain Injector (global domain queue).
  4. Workers in other NumaNodes (remote steal — last resort).

Memory binding: TaskData allocated via NumaAllocator that calls mbind/set_mempolicy on Linux to pin data pages to the local NUMA node.

8.13 Worked Example — Fork-Join Parallel Mergesort

The caller opens one scope (pool.spawn_scope) and spawns a single top-level sort task covering the whole array. That task's recursive step checks its own span against GRAIN: at or below the threshold it falls back to a sequential insertion sort and returns immediately; above threshold it computes the midpoint and issues one join of two recursive halves. Per the work-first policy (ADR-21), the left half's continuation is pushed to the local deque while the right half runs inline on the calling worker — so the pushed half is the one available for another worker to steal. After both halves of the join are Done, the task merges the two sorted halves in place. Every recursive call repeats this same check-split-join-merge pattern until all spans are at or below GRAIN.

Task tree (4-element, GRAIN=1, 2 workers W0/W1):

  W0 spawns split(0,4): pushes right(2,4), runs left(0,2)
    W1 steals right(2,4): splits → pushes (3,4), runs (2,3)
    W0 after left(0,2) done: pops (1,2) or steals if W1 took it
  → 4 leaf tasks, 2 internal merges per side, 1 final merge
  → W0 and W1 share work; no central lock

8.14 Failure-Path Example — DAG with Panicking Node

  graph:  A → B → D
              ↓
          C → D

  A panics:
    1. A.state CAS: Running → Panicked
    2. A's successors (B, C): pending_deps.fetch_sub(1) → B.pending = 0, C.pending = 0
    3. B and C become Ready; both execute
    4. B.run() → B detects A panicked via shared PanicFlag → B transitions to Panicked (propagation policy)
    5. D's pending decrements from both B and C; if policy=abort-on-first-panic, D is never pushed
    6. graph.wait() returns Err(PropagatedPanic { origin: A.id, payload: ... })

Alternative policy (best-effort): run B, C, D regardless; collect all panics; return Err(MultiPanic(vec)).

8.15 Edge Cases and Pitfalls

Scenario Risk Mitigation
Single-item deque: owner pop races with steal Lost task or double-run CAS on top by owner in pop() last-item path; loser retries or returns None
Buffer growth during steal Thief reads stale buffer pointer Buffer swap uses Release store; thief does Acquire load before reading slot
join(a,b) — b stolen before a finishes Owner has no work; may park Owner's park wakes on any unpark, including b's completion latch
Scope with 0 spawned tasks latch.wait() blocks forever Latch initialized to 0 → wait() returns immediately
DAG with 0-dep nodes all submitted at once Thundering herd on injector Distribute across per-NUMA injectors round-robin
parallel_scan with non-associative op Wrong prefix sums Static assertion / trait bound requiring Associative marker trait
Cancellation mid-steal Task stolen after cancel issued Cancellation token checked at task start; late steal sees token, drops task
All workers blocking in Future::wait() Pool deadlock Compensation thread injection (Phase 12); bounded at 2 × num_threads
TaskId overflow (u64 wrap) Duplicate IDs in trace Saturating counter + pool restart required (documented; ~10^19 tasks)
