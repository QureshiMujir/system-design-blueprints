3.2 Subsystem Descriptions

pqc-cli — Entry point. Parses subcommands (keygen, encaps, decaps, sign, verify, kat), reads/writes PEM-like or raw binary key/message/ciphertext/signature files. No cryptographic logic; delegates entirely to pqc-kem, pqc-sign, pqc-kat. Trust boundary: untrusted file input; validates before passing to scheme layer. No concurrency; sequential per invocation.

pqc-kem — Implements ML-KEM. Two layers: (1) CPA PKE (keygen, enc, dec) over Module-LWE using pqc-sample for key and noise polynomials, pqc-ntt for matrix-vector products, pqc-encode for Compress/Decompress and byte packing. (2) CCA2 KEM wrapping CPA PKE via the Fujisaki-Okamoto transform: encaps hashes message + pk-hash through G to get (K, r), calls enc(m; r); decaps decrypts, re-encrypts, performs constant-time ciphertext comparison (via pqc-ct), returns K or PRF(z, c). Secret: sk (s, pk-hash, z). Trust boundary: all ciphertext bytes treated as adversarial. No I/O; all data passed by value or slice.

pqc-sign — Implements ML-DSA. keygen expands A from rho, samples s1/s2 via pqc-sample, computes t = A*s1 + s2, splits t into (t1, t0). sign runs the Fiat-Shamir-with-aborts loop: sample masking y, compute w = A*y, derive challenge c from H(tr, msg, w1), compute z = y + c*s1, check norm bounds and reject if violated, compute hint h. verify recomputes w1' via UseHint, recomputes c', checks c' == c~ and norm bounds. Uses pqc-ntt, pqc-sample, pqc-encode, pqc-ct. Secret: sk (s1, s2, t0, y during signing). Signing loop is probabilistic; expected retries bounded by rejection probability.

pqc-sample — Stateless samplers driven by pqc-hash XOF output. cbd_eta(prf_stream, eta) — centered binomial: constant-time, output is secret. uniform_rej(xof_stream) — rejection sampling mod q for matrix A coefficients: variable-time (output is public). expand_a(rho) — generates the K×L public matrix A by calling XOF per (i,j). expand_s(sigma, nonce) — expands secret/noise vectors. Input: seed bytes. Output: Poly or PolyVec. No persistent state.

pqc-encode — Deterministic (de)serialization. ML-KEM: Compress_q(x, d) rounds x to d bits; Decompress_q(y, d) reconstructs; ByteEncode/ByteDecode at d bits/coefficient. ML-DSA: pack_t1, pack_t0, pack_s, pack_z, pack_h, unpack_*. All functions are pure (no side effects); input validation returns Err on wrong length. Roundtrip invariant: decode(encode(x)) == x for lossless cases; compression error bounded by FIPS spec.

pqc-ntt — Core multiplier. Precomputed twiddle-factor table ZETAS: [i32; 128] (primitive 256th root of unity mod q). Forward NTT: 7-layer Cooley-Tukey butterfly in-place; inverse NTT: Gentleman-Sande, includes the n^{-1} normalisation factor folded into the last layer. Pointwise multiplication: element-wise product in NTT domain with Montgomery reduction. Invariants I5. All arithmetic is data-independent; no secret values in this crate (A expansion uses it but A is public; KEM/sign pass NTT-domain polys without secret-conditional branching here).

pqc-poly — Reference ring layer. Poly.add, Poly.sub — coefficient-wise mod q. Poly.schoolbook_mul — O(n²) negacyclic multiply (X^256 = -1); used only for differential testing against pqc-ntt (P5). Poly.reduce_coeffs — ensures all coefficients in [0, q). PolyVec and PolyMat wrappers with vectorised add/inner-product. Domain enum tags each Poly instance.

pqc-hash — Keccak-f[1600] permutation, hand-unrolled for constant-time and performance; no lookup tables that could cause cache-timing leakage. Exports: sha3_256, sha3_512, shake128_xof, shake256_xof with streaming squeeze interface. Named functions per FIPS: G = SHA3-512, H = SHA3-256, PRF = SHAKE256, XOF = SHAKE128. Validated against NIST SHA-3 KAT vectors independently of pqc-kat.

pqc-ct — Constant-time utilities. ct_eq(a, b) -> u8 — returns 1 iff equal, no branch. ct_select(cond, a, b) — branchless mux. ct_cmov(dst, src, cond) — conditional copy. zeroize(buf) — compiler-barrier-guarded memory wipe. ct_compare_bytes(a, b) -> u8 — constant-time byte-slice comparison used by FO. This crate has no dependencies on other pqc-* crates; all others depend on it.

pqc-kat — KAT harness. Reads FIPS 203/204 ACVP JSON/text vectors (keyed by algorithm + parameter set). Provides a deterministic-RNG shim (seeds the samplers deterministically per KAT entry). Drives pqc-kem and pqc-sign through each test vector. Asserts byte-exact equality of public keys, secret keys, ciphertexts, shared secrets, and signatures. Enforces invariant I1. Fails immediately on first mismatch with a diff showing expected vs. actual hex.

8.3 Polynomial Ring R_q State Model

Poly states and legal transitions:
  [Allocated] ──sample/decode──► [Normal]
  [Normal]    ──forward_ntt──►   [Ntt]
  [Ntt]       ──inverse_ntt──►   [Normal]
  [Ntt]       ──pointwise_mul──► [Ntt]      (two Ntt-tagged polys only)
  [Normal]    ──compress──►      [Compressed bytes]
  [Normal]    ──encode──►        [Serialized bytes]
  [Serialized]──decode──►        [Normal]
  [Normal/Ntt]──zeroize──►       [Freed]

Invariant: the Domain tag is set at construction and flipped only by forward_ntt/inverse_ntt. Any function accepting two Poly arguments for multiplication must statically or dynamically assert both are Domain::Ntt.

8.4 ML-KEM Lifecycle State Machine

States: Unkeyed → Keyed → Encapsulated → Decapsulated

Unkeyed ──keygen(seed)──────────────────────────────► Keyed
          (A=ExpandA(rho), t=A*s+e, pk=(rho,t1), sk=...)

Keyed ──encaps(pk, m)──────────────────────────────► Encapsulated
        ((K,r) = G(m, H(pk)),  c = CPA_Enc(pk, m; r))

Encapsulated ──decaps(sk, c)────────────────────────► Decapsulated
               (m' = CPA_Dec(sk,c), re-encrypt c''=CPA_Enc(pk,m';r'),
                compare ct_eq(c,c'') → K or PRF(z,c))

Transitions failing ct_eq still return SharedSecret; never return an error or abort. Any path returning a distinguishable error breaks CCA2.

Sequence: Encaps/Decaps (happy path)

Alice (has pk)                     Bob (has sk, pk)
  m ←← random 32 B
  (K, r) = G(m, H(pk))
  c = CPA_Enc(pk, m; r)
  ─────── (K, c) ───────────────►
                                   m' = CPA_Dec(sk, c)
                                   r' = G(m', H(pk)).1
                                   c'' = CPA_Enc(pk, m'; r')
                                   K_out = ct_select(ct_eq(c,c''), K, PRF(z,c))
                                   ◄──── K_out ──────
  assert K == K_out   (honest)

Sequence: Decaps with tampered ciphertext (failure path)

Attacker sends c_bad ≠ c
  Bob:  m' = CPA_Dec(sk, c_bad)   (garbage plaintext)
        c'' = CPA_Enc(pk, m')      (re-encrypt → c'' ≠ c_bad with overwhelming prob)
        ct_eq(c_bad, c'') == 0
        K_out = PRF(z, c_bad)      (deterministic pseudo-random; not K)
  No timing difference between this path and the honest path (P1, P3, I4).

8.5 ML-DSA Signing State Machine

States: Unkeyed → Keyed → Signing (loop) → Signed

Unkeyed ──keygen(seed)──────────────────────────────► Keyed
          (A=ExpandA(rho), s1~CBD, s2~CBD,
           t=A*s1+s2, split(t) → t1,t0)

Keyed ──sign(sk, msg, rng)──────────────────────────► Signing (loop)

Signing (loop):
  y ←← uniform in (-gamma1, gamma1)^l   [masking vector]
  w = A*y
  w1 = HighBits(w, 2*gamma2)
  c_tilde = H(tr || msg || w1)
  c = SampleInBall(c_tilde)             [sparse ±1 challenge]
  z = y + c*s1
  r0 = LowBits(w - c*s2, 2*gamma2)
  IF ||z||_inf >= gamma1 - beta  → REJECT, resample y
  IF ||r0||_inf >= gamma2 - beta → REJECT, resample y
  h = MakeHint(-c*t0, w - c*s2 + c*t0, 2*gamma2)
  IF ||c*t0||_inf >= gamma2 → REJECT, resample y
  IF popcount(h) > omega → REJECT, resample y
  output (c_tilde, z, h)  ──────────────────────────► Signed

Expected iterations per sign: ~4 (ML-DSA-44), ~5 (ML-DSA-65), ~7 (ML-DSA-87). Rejection sampling is security-critical: I7, P4.

Sequence: Verification (happy path)

Verifier has (pk=(rho,t1), msg, sig=(c_tilde,z,h)):
  A = ExpandA(rho)
  c = SampleInBall(c_tilde)
  w1' = UseHint(h, A*z - c*t1*2^d, 2*gamma2)
  c_tilde' = H(tr || msg || w1')
  accept iff:
    c_tilde' == c_tilde      (challenge match)
    ||z||_inf < gamma1-beta  (z in bounds)
    popcount(h) <= omega      (hint count bounded)

Sequence: Verification (tampered signature — failure path)

Attacker flips a bit in z → ||z||_inf may exceed gamma1-beta → reject (I10)
Attacker flips c_tilde → c_tilde' ≠ c_tilde → reject
Attacker forges h with > omega 1-bits → reject on hint count
All rejections: deterministic, no branch on secret data.

8.6 NTT Domain Transition and Arithmetic Model

Twiddle factors (zetas) for ML-KEM (q=3329):

  • Primitive 512th root of unity: zeta = 17 mod 3329.
  • Precomputed: ZETAS[i] = Montgomery(zeta^(BitRev7(i))) for i=0..127.
  • Forward NTT: Cooley-Tukey butterfly, 7 layers, in-place on [i32; 256].
  • Inverse NTT: Gentleman-Sande butterfly, 7 layers, multiply by n^{-1} = 3303 mod 3329 at end.

Butterfly operations (signatures only, no bodies):

fn ct_butterfly(a: i32, b: i32, zeta: i32, q: i32) -> (i32, i32);
fn gs_butterfly(a: i32, b: i32, zeta: i32, q: i32) -> (i32, i32);
fn pointwise_mul_ntt(a: &PolyNtt, b: &PolyNtt) -> PolyNtt;
fn ntt(p: Poly<Normal>) -> Poly<Ntt>;
fn inv_ntt(p: Poly<Ntt>) -> Poly<Normal>;

Invariant I5: inv_ntt(ntt(p)) == p (coefficient-wise mod q). Verified by round-trip property test over 10,000 random polynomials and by diff-test against schoolbook.

NTT-based matrix-vector product (shape conventions):

ML-KEM keygen: t = A*s + e
  A: [K][K] polys (Ntt), s: [K] polys (Ntt), e: [K] polys (Normal→Ntt)
  t[i] = sum_j( A[i][j] * s[j] ) + e[i],  all in NTT; inv_ntt per component

ML-KEM encrypt: u = A^T * r + e1
  A^T[j][i] = A[i][j];  pointwise NTT mul, accumulate, inv_ntt, add e1

ML-DSA: w = A * y (K×L matrix times L-vec)
  w[i] = sum_j( A[i][j] * y_ntt[j] ); inv_ntt → LowBits/HighBits in Normal domain

8.8 Reduction and Modular Arithmetic Model

Montgomery reduction (q=3329, R=2^16):

Step Operation Range
Input a*b as i64 [0, q²·R)
m = (a*b mod R) * q_inv mod R lower 16 bits [0, R)
t = (a*b + m*q) >> 16 shift right by log2(R) (-q, q)
t += q if t < 0 conditional add [0, q)

Barrett reduction (q=3329): t = a - q·floor(a·k/2^26) with k=80635; range [0, 2q) → subtract q if t>=q.

For q=8380417 (ML-DSA): Montgomery with R=2^23; similar structure, larger shift. All intermediates use i64 to avoid overflow.

Centered binomial sampling (CBD_eta):

CBD_eta(b): read 2*eta bits = a[0..eta-1] XOR b[0..eta-1]; coeff = sum(a) - sum(b)
Range: [-eta, eta]; distributed as Binomial(2*eta, 1/2) - eta
Constant-time: no secret-dependent branches; XOR of uniform bits.

Rejection sampling for uniform mod q:

Read 3 bytes → 24 bits → two 12-bit candidates d1, d2 from SHAKE128 stream
Accept d if d < q (3329); else discard and continue
Variable-time (public matrix A only — P7); expected ~1.74 bytes per coeff.

8.10 Worked Example: ML-KEM-512 Encapsulation (Conceptual)

Input: pk = (rho, t1_bytes); m = 0x00...00 (32 B)

1. H(pk) → 32 B hash of public key bytes
2. (K, r) = G(m || H(pk)) → K=first 32 B, r=next 32 B
3. A = ExpandA(rho) using XOF(rho || (i,j)) — k=2, 4 polys in Ntt domain
4. r_vec = Sample_poly_CBD(r, eta1=3) — 2 polys, Normal domain
5. e1_vec = Sample_poly_CBD(sigma, eta2=2) — 2 polys noise
6. e2_poly = Sample_poly_CBD(sigma, eta2=2) — 1 poly noise
7. r_ntt = ntt(r_vec)
8. u = inv_ntt(A^T * r_ntt) + e1   — Compress(u, du=10) → 320 B
9. m_poly = Decompress(m, 1)        — 1-bit per coeff poly
10. v = inv_ntt(t1_ntt * r_ntt) + e2 + m_poly  — Compress(v, dv=4) → 128 B
11. c = encode(u) || encode(v)       — 448 B ciphertext
12. output (K, c)

Malformed-input example:

Input: c with encode(v) truncated by 1 byte
  → byte-length check in decode fails before any poly operation
  → return Err(MalformedCiphertext) (I10)
  → no information leakage; same timing as a normal-length invalid ciphertext

8.11 Constant-Time Execution Model

Operation CT requirement Mechanism
FO ciphertext comparison Must not branch on result ct_eq returns u8 mask; ct_select picks K or PRF(z,c)
CBD sampling No secret-dependent branch XOR + popcount on uniform bits; no early exit
Rejection sampling (public A) Variable-time allowed P7; A is not secret
Rejection sampling (sign loop iteration count) Variable-time allowed loop count is not secret (leaks only statistical info)
z, r0, hint bounds check during signing Values are secret ct_cmp for bounds; result fed into loop-continue flag without branching on value
zeroize on secret structs Volatile write barrier zeroize crate or equivalent; must not be optimized out
Memory indexing on secret keys Must be constant stride No sk[secret_idx]; all accesses via fixed-size loops

Secret data categories: s1, s2, t0, y (masking), m (message in KEM), K (shared secret before output), z intermediate, r in encaps.
