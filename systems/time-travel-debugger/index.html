3. Architectural Overview

Recorder. Owns the tracee during recording. Spawns child, sets PTRACE_TRACEME+exec, installs seccomp-BPF filter to trap syscalls cheaply, drives the run loop, and at each nondeterminism point writes a TraceEvent tagged with the current Tick. Captures syscall return value plus every byte the kernel wrote into tracee memory (output buffers). Serializes all tracee threads onto one logical core so scheduling is a recordable sequence, not a true race.

Replayer. Re-spawns the same binary, drives an identical run loop, but at each syscall instead of letting the kernel execute it, it reads the recorded TraceEvent, writes the recorded memory effects back into the tracee, sets the recorded return register, and skips the instruction. Signals are re-delivered when the perf counter reaches the recorded Tick (then IP+regs match, then single-step the residual). Continuously compares observed regs/IP at known points against the trace; any mismatch = Diverged, surfaced immediately.

Tracee. The child process under ptrace. State machine {Running, AtSyscallEntry, AtSyscallExit, Stopped, Checkpointed, Diverged}. Inspected via PTRACE_GETREGS (registers) and process_vm_readv/PTRACE_PEEKDATA (memory). Controlled via PTRACE_CONT/PTRACE_SYSCALL/PTRACE_SINGLESTEP/PTRACE_SETREGS.

PerfCtr (ttdb-perf). Per-tracee-thread perf_event_open counting retired conditional branches (the unit that makes a deterministic, reproducible instruction clock; raw instruction count is less reliable across reps). Read to obtain the current Tick; programmed to interrupt (PMI) near a target tick so the supervisor can single-step the final stretch precisely (skid forces this two-stage approach).

Trace / EventLog (ttdb-trace). Append-only, tick-indexed, on-disk. Sequence of TraceEvents plus side-channel MmapData blobs (large memory captures stored out-of-line). Read sequentially during replay; binary-searchable by tick for seek. Versioned header; CRC per block; never mutated after write (crash-only).

Checkpoint Engine (ttdb-checkpoint). Periodically COW-forks the replaying tracee (or captures a memory diff) producing Checkpoint{tick, mem_snapshot, regs}. ReplayTimeline indexes checkpoints by tick; seek(T) = restore nearest checkpoint ≤ T, then replay forward to T. Substrate for fast random seek and all reverse operations.

Session / Debug Engine (ttdb-debug). Orchestrates replay + checkpoints into a debugger. Forward: int3/hardware breakpoints, single-step, stack unwinding, variable inspection via DWARF. Reverse: reverse-continue/step implemented as "restore an earlier checkpoint, replay forward recording breakpoint hits, stop at the last hit before current time." Watchpoints forward via DR0–DR3, reverse via replay scan. Answers "state at tick T" by seeking and reading regs/memory.

Target (DAP, ttdb-dap). Implements the Debug Adapter Protocol so editors drive ttdb. Standard requests (setBreakpoints, stackTrace, variables, continue, next, stepIn) plus reverse extensions (stepBack, reverseContinue, custom seekTick). Bridges DAP's forward-only worldview onto the timeline.

8. Domain Model

8.11 Timeline / event model

Recorded execution is a totally ordered sequence of instructions; the Tick (retired conditional-branch count) is a monotonic logical clock over that sequence. Nondeterminism enters only at discrete points; each becomes a TraceEvent anchored to a (Tick, IP, regs) coordinate. The timeline is the trace; "now" during replay is the current tick; seeking moves "now" along the timeline.

EBNF (logical trace structure):

Trace        = Header , { Block } , Footer ;
Header       = magic , version , arch , binary_id , aslr_flag , perf_event_cfg ;
Block        = block_len , crc32 , Event ;
Event        = tick , kind , RegSnapshot , Payload ;
kind         = "SyscallEntry" | "SyscallExit" | "Signal"
             | "Sched" | "RdtscRdrandCpuid" | "MmapData" ;
RegSnapshot  = gp_regs , rip , rflags , [ fp_state_ref ] ;   (* compact *)
Payload      = SyscallPayload | SignalPayload | SchedPayload
             | NondetInsnPayload | MmapRef ;
SyscallPayload    = nr , args[6] , retval , { MemWrite } ;
MemWrite          = addr , len , data_ref ;                  (* bytes kernel wrote *)
SignalPayload     = signo , siginfo , delivery_anchor ;
SchedPayload      = from_tid , to_tid ;
NondetInsnPayload = insn_kind , result_regs ;                (* RAX/RDX, etc. *)
MmapRef           = blob_id , addr , len ;                   (* large data out-of-line *)

8.12 Trace + tick + checkpoint schema (on-disk, lightweight)

  • Trace: directory trace/ = header.bin, events.log (append-only), blobs/ (MmapData payloads), checkpoints/ (snapshot images), index.bin (tick→file-offset, built lazily).
  • Tick: u64, retired conditional branches since record start for the current tracee thread; per-thread counters sequenced via Sched events.
  • Checkpoint: { tick:u64, regs:RegisterFile, mem:MemSnapshot, fd_table:FdSnapshot }; MemSnapshot = COW-fork pid (live) or page-set diff (persisted).

8.13 Worked example

Program: t = time(NULL); if (t & 1) A(); else B();

  • Record. At the time syscall: SyscallEntry(nr=201,...) then kernel returns 1000 into RAX → SyscallExit(nr=201, retval=1000, MemWrite none here). Tick at exit = e.g. 540. Program computes 1000 & 1 == 0 → branch to B() (this branch increments the tick). Recorder logs nothing more for the branch — it is deterministic given RAX=1000.
  • Replay. Re-run to the time syscall; at SyscallEntry, Replayer reads recorded SyscallExit, sets RAX=1000, advances RIP past the syscall instruction, does NOT enter the kernel. Program recomputes 1000 & 1 == 0 → branch to B(). Same branch, same tick progression. Observed regs at the next sync point match recorded ⇒ no divergence.
  • Counterfactual (bug). If time were not trapped, replay's real time() returns 2000; a value whose low bit flips to 1 routes to A() → branch differs → tick stream diverges → I1/I6 fire at the next compare with divergence{tick, reg=rip}.

8.14 Record loop (sequence)

Recorder            Tracee              Kernel            Trace
   | spawn+TRACEME --->|                                   |
   | install seccomp ->|                                   |
   | PTRACE_CONT ----->| run...                            |
   |                   |-- syscall -->| (SECCOMP_RET_TRACE)|
   |<-- ptrace stop (syscall-entry) --|                    |
   | read Tick, regs   |              |                    |
   | append SyscallEntry --------------------------------->|
   | PTRACE_SYSCALL -->| kernel executes syscall --------->|
   |<-- ptrace stop (syscall-exit) ---|                    |
   | read retval, copy MemWrites (process_vm_readv)        |
   | append SyscallExit ---------------------------------->|
   | PTRACE_CONT ----->| run...                            |
   | (async signal pending) read Tick anchor               |
   | append Signal{tick,anchor} -------------------------->|
   | deliver signal via PTRACE_CONT(sig) ->|               |

8.15 Replay loop (sequence)

Replayer            Tracee                         Trace
   | re-spawn (ASLR off / recorded maps) ---------->|
   | read next Event ------------------------------>|
   |  case SyscallEntry: PTRACE_SYSCALL to entry    |
   |  read SyscallExit from trace ----------------->|
   |  write MemWrites into tracee (process_vm_writev)|
   |  SETREGS: RAX=retval, RIP past `syscall`        |
   |  (DO NOT enter kernel)                          |
   |  case Signal: program perf PMI to anchor.tick   |
   |   count-to-near, single-step residual to IP     |
   |   compare regs==anchor.regs (I10) else DIVERGE  |
   |   inject signal frame                           |
   | at each sync point: compare regs/IP vs trace    |
   |   mismatch -> emit `diverged`, STOP (I6)        |

8.16 Tracee state machine

        spawn                PTRACE_SYSCALL (entry)
[start] ----> (Running) --------------------------> (AtSyscallEntry)
                ^  |                                      |
   PTRACE_CONT  |  | signal/stop                          | PTRACE_SYSCALL
                |  v                                      v
            (Stopped) <----------------------------- (AtSyscallExit)
                |   \                                   /
   checkpoint   |    \  divergence (replay)            / done -> Running
                v     \--------------> (Diverged) <---/
          (Checkpointed)                  (terminal, replay only)

State transition table:

From Event To Action
Running syscall trap AtSyscallEntry read regs, log/inject
AtSyscallEntry PTRACE_SYSCALL AtSyscallExit capture retval+mem (record) / already injected (replay)
AtSyscallExit PTRACE_CONT Running continue
Running signal Stopped read pending signo
Stopped PTRACE_CONT(sig) Running deliver (record) / inject at tick (replay)
Running checkpoint trigger Checkpointed COW fork / mem diff
Checkpointed resume Running continue from fork
any (replay) reg/IP mismatch Diverged emit fatal, halt

8.17 Malformed / divergence examples

  • Untrapped nondeterministic instruction. RDTSC not trapped; record sees TSC=X, replay's CPU returns Y → downstream branch differs → divergence at next compare. Fix: install trap (CR4.TSD trap-and-emulate, or rewrite) (I11).
  • Signal one branch late. Anchor recorded at tick T but replay delivers at T+1 (skid mishandled) → register state at delivery differs → I10 anchor mismatch. Fix: two-stage convergence (§ principle 7).
  • Shared-memory race (documented limitation). Two threads racing on a word without serialization order recorded → not reproducible at single-core granularity if the outcome depended on true parallelism. PhaseDeferred("§12.4"); surfaced as divergence, never silently wrong.
  • vDSO syscall bypass. clock_gettime via vDSO never traps ptrace → unrecorded nondeterminism. Fix (Phase 14): patch vDSO to force real syscall, or trap the underlying read. Until then: divergence on time-dependent branches.
  • Torn trace tail. Process killed mid-append → last block CRC fails → reader truncates to last good block (I9); replay covers the valid prefix.

Design principles (§6)

  • Determinism over convenience. Every nondeterministic input must be recorded or eliminated; if a source is unhandled, replay must diverge loudly, never silently produce wrong state. Tradeoff: slower record (must trap more). Operational: divergence is a first-class alert. Violation: silent wrong replay = worse than no tool (engineers trust a lie).
  • Divergence is detected, never tolerated. At every re-synchronization point (syscall, signal tick, checkpoint) compare observed vs recorded regs/IP. Tradeoff: extra compares cost replay time. Operational: a Diverged event names the exact tick + register that disagreed. Violation: undetected drift corrupts all downstream debugging.
  • The Tick is the only clock. All temporal coordinates are (Tick, IP, regs), never wall-clock. Tradeoff: tied to a reproducible PMU counter (microarch-sensitive, §12.3). Operational: traces are portable only across identical-enough CPUs. Violation: wall-clock ordering is nonreproducible → replay impossible.
  • Single runnable tracee thread during record. Serialize threads onto one core; record context-switch points as events. Tradeoff: no true parallelism in recorded run (slower for parallel workloads). Operational: scheduling becomes a deterministic, replayable sequence. Violation: true concurrent execution = unrecordable memory races (§12.4).
  • Append-only, crash-only trace. The trace is written once, never mutated; a torn tail is truncated on read; no in-place edits. Tradeoff: storage grows monotonically. Operational: kill -9 mid-record still yields a replayable prefix. Violation: in-place mutation risks corrupting already-recorded history.
  • Suppress, then inject (replay). On replay the tracee never performs real syscalls; the recorded result + memory effects are injected. Tradeoff: must perfectly model every syscall's memory side effects. Operational: replay is hermetic (no real I/O, safe to run anywhere). Violation: a real syscall during replay re-introduces nondeterminism.
  • Two-stage convergence (count then step). Use the perf counter to get near a target tick, then single-step the residual to the exact instruction (skid means counters overshoot/undershoot). Tradeoff: single-step is slow → keep the residual short. Operational: bounded, predictable convergence. Violation: trusting the raw counter places async events one branch early/late → mismatch.
  • Checkpoints are the time machine. Random seek and all reverse ops = restore nearest checkpoint ≤ T then replay forward. Tradeoff: checkpoint memory vs seek latency (tunable interval). Operational: reverse-continue cost is bounded by one interval. Violation: linear replay-from-start makes reverse ops unusably slow.
  • Explicit ownership of the tracee. Exactly one supervisor thread owns ptrace control of a given tracee (the thread that attached). Tradeoff: no multi-threaded supervisor parallelism over one tracee. Operational: avoids ESRCH/owner-thread bugs. Violation: cross-thread ptrace calls fail unpredictably (the Go rejection rationale).
  • Hermetic, reproducible replay environment. Replay re-creates the recorded address-space layout (disable ASLR / record mmap addresses); same binary, same env recorded. Tradeoff: must pin/record layout. Operational: addresses in the trace are meaningful across replays. Violation: ASLR variance shifts addresses → breakpoints/divergence break.
  • Observability by default. Every event, tick, divergence, checkpoint, and seek emits structured telemetry. Tradeoff: log volume. Operational: the tool is debuggable. Violation: a determinism bug with no telemetry is undebuggable.
  • Bounded resource usage. Trace growth, checkpoint memory, single-step stretch length all have ceilings + backpressure. Tradeoff: may pause record to flush. Operational: never OOM the host. Violation: unbounded MmapData captures fill the disk mid-record.
  • Stable trace wire format. On-disk trace has a versioned, length-prefixed, CRC'd format with forward/backward compat rules (§ Compatibility & Versioning). Tradeoff: format ceremony. Operational: old traces replay on new ttdb. Violation: format drift orphans recorded traces.
  • Minimal trusted FFI surface. All unsafe (ptrace, perf, /proc/mem) is confined to ttdb-ptrace/ttdb-perf with safe wrappers; the rest is safe Rust. Tradeoff: wrapper boilerplate. Operational: audit surface is small. Violation: scattered unsafe makes silent-corruption bugs hard to find.
  • Record once, replay infinitely, never re-record to answer a question. All queries (state@T, reverse ops) operate on the existing trace. Tradeoff: trace must capture enough up front. Operational: deterministic, repeatable investigations. Violation: re-recording reintroduces nondeterminism and breaks reproducibility.
