11. Core Schema and Core Types

Lightweight signatures only (no implementation). Ownership / mutation / concurrency / persistence / serialization / compatibility annotated per type.

Tick — struct Tick(u64) retired-conditional-branch count.

  • Ownership: Copy value. Mutation: immutable; produced by PerfCounter. Concurrency: per-thread source; Send. Persistence: stored in every event (LE u64). Serialization: raw u64. Compatibility: width fixed at u64 forever (saturating beyond is a hard error, not a wrap).

RegisterFile — struct RegisterFile { gp:[u64;16], rip:u64, rflags:u64, fs_base:u64, gs_base:u64, fp_ref:Option<FpStateId> }.

  • Ownership: owned, Clone. Mutation: rebuilt from GETREGS / set via SETREGS. Concurrency: Send; not shared mutably. Persistence: compact snapshot in events + checkpoints. Serialization: fixed layout, version-tagged. Compatibility: new arch regs ⇒ new version + optional trailer (forward-compatible append).

AddressSpace — struct AddressSpace { regions:Vec<MemRegion>, aslr:bool }; MemRegion { base, len, prot, backing }.

  • Ownership: owned by Session. Mutation: updated on mmap/munmap events. Concurrency: single-owner. Persistence: snapshotted in checkpoints; maps recorded at start (I8). Serialization: region list. Compatibility: region flags extensible.

TraceEvent — struct TraceEvent { tick:Tick, kind:EventKind, regs:RegisterFile, payload:Payload }.

  • enum EventKind { SyscallEntry, SyscallExit, Signal, Sched, RdtscRdrandCpuid, MmapData }.
  • Ownership: owned, immutable once appended. Mutation: none post-append (I9). Concurrency: produced by owner thread only. Persistence: the core log record. Serialization: length-prefixed block, CRC32C. Compatibility: unknown future kinds skipped via length prefix (forward-compat read).

Payload — enum Payload { Syscall{nr:i64, args:[u64;6], ret:i64, mem:Vec<MemWrite>}, Signal{signo:i32, siginfo:[u8;128], anchor:Coord}, Sched{from:Tid,to:Tid}, NondetInsn{kind:InsnKind, out:RegDelta}, Mmap{blob:BlobId, addr:u64, len:u64} }.

  • MemWrite{addr:u64, len:u32, data:DataRef} — inline if small, blob if large. Coord{tick:Tick, rip:u64, regs_hash:u64}.
  • Ownership/mut/conc: as TraceEvent. Persistence: inline + blob store. Serialization: tagged union. Compatibility: per-variant trailer for added fields.

Checkpoint — struct Checkpoint { tick:Tick, regs:RegisterFile, mem:MemSnapshot, fds:FdSnapshot }; enum MemSnapshot { CowFork(Pid), PageDiff(Vec<PageImage>) }.

  • Ownership: owned by ReplayTimeline. Mutation: created, never edited. Concurrency: single-owner. Persistence: live (fork pid, volatile) or on-disk (PageDiff). Serialization: PageDiff persisted; CowFork is process-lifetime only. Compatibility: PageDiff format versioned.

Trace / EventLog — struct Trace { dir, header:Header, reader/writer, index:TickIndex, blobs:BlobStore }.

  • Methods (contracts): append(&mut self, ev) -> Result<()> (monotone tick, I3); read_at(&self, off) -> Result<TraceEvent>; seek_tick(&self, t:Tick) -> Result<Offset> (≤ t); truncate_torn(&mut self) (I9). Concurrency: single writer; many readers after seal. Persistence: directory of files. Compatibility: header carries format_version.

Recorder — struct Recorder { tracee:Tracee, perf:PerfCounter, trace:Trace, sched:Scheduler }.

  • run(&mut self) -> Result<()> drives §8.14. Owns the tracee (principle 9). Single thread. Not persisted.

Replayer — struct Replayer { tracee:Tracee, perf:PerfCounter, trace:Trace, pos:Offset }.

  • step_event(&mut self) -> Result<ReplayStop>; run_to(&mut self, t:Tick). Drives §8.15; emits divergence (I6). Single owner thread.

ReplayTimeline — struct ReplayTimeline { replayer:Replayer, checkpoints:BTreeMap<Tick,Checkpoint> }.

  • seek(&mut self, t:Tick) -> Result<()> (restore nearest ≤ t, replay forward); checkpoint_now(&mut self). Concurrency: single-owner.

Session — struct Session { timeline:ReplayTimeline, breakpoints, watchpoints, dwarf, now:Tick }.

  • Top-level debug orchestrator; continue/step/reverse_* map onto timeline. Owns debug state.

Tracee — struct Tracee { pid:Pid, state:TraceeState, owner:ThreadId }; enum TraceeState { Running, AtSyscallEntry, AtSyscallExit, Stopped, Checkpointed, Diverged }.

  • Ownership: exclusively by its owner thread (principle 9). Mutation: state advances per ptrace stop. Concurrency: !Sync across ptrace ops — enforced by owner-thread check.

Breakpoint — enum Breakpoint { Software{addr:u64, saved_byte:u8}, Hardware{addr:u64, drx:u8} }.

  • Ownership: Session. Mutation: install (write 0xCC / set DRx) / remove (restore). Persistence: not persisted (per-session). Concurrency: owner thread.

Watchpoint — struct Watchpoint { addr:u64, len:u8, kind:WatchKind, impl_:WatchImpl }; enum WatchKind{Write,ReadWrite,Exec}; enum WatchImpl{Hw(u8 /*drx*/), ReplayScan}.

  • Forward = Hw(DRx); reverse = ReplayScan over a replay window.

Target (DAP) — trait Target { fn capabilities(&self)->Capabilities; fn continue_(&mut self); fn step_back(&mut self); fn reverse_continue(&mut self); fn stack_trace(&self)->Vec<Frame>; fn read_vars(&self, frame)->Vec<Var>; fn seek_tick(&mut self, t:Tick); }.

  • Bridges Session to DAP; capabilities.supportsStepBack = true.

TtdbError — enum TtdbError { Ptrace(nix::Error), Perf(io::Error), TraceCorrupt{off:u64}, Diverged(Coord, RegMismatch), AnchorUnreachable(Coord), UntrappedNondet{ip:u64}, AspaceMismatch{region}, SchedSerialization, ... }.

  • Ownership: returned by value. Serialization: rendered in telemetry. Compatibility: non-exhaustive enum.
