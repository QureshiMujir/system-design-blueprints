32. Mental Models & First Principles

  • MM1 — Insight: a cellular network is a giant distributed state machine whose job is to keep a moving UE continuously reachable; every procedure maintains that reachability invariant across mobility. Prediction: any new procedure added to the simulator must define what happens to reachability during its execution, not just its happy path. Bug class without it: a handover or paging procedure with a "successful" terminal state that leaves the UE unreachable in an unmodeled intermediate window. Resolves §7 (I5, I13), §21.
  • MM2 — Insight: message-sequence correctness is a stronger and more useful correctness notion than waveform fidelity for this project's purpose (P1) — the 3GPP specs are themselves state-machine specifications for everything above the PHY. Prediction: a defect in this simulator almost always shows up as a wrong or missing message in a trace, not a numerical drift. Bug class without it: chasing PHY-level "realism" investments that never move a call-flow-conformance number. Resolves §1, §28.
  • MM3 — Insight: every timer is a promise about the future that some other part of the system is relying on (I9) — a lost or double-fired timer breaks a promise another state machine assumed was kept. Prediction: any procedure with a supervision timer needs an explicit test for "timer never fires" and "timer fires twice," not only "timer fires once correctly." Bug class without it: a T300-class timer silently orphaned, leaving a UE stuck in an intermediate state forever. Resolves §7 (I9), §16, §20.
  • MM4 — Insight: identity (IMSI/GUTI/SUPI) is the addressing layer underneath every procedure — every later phase (paging, handover, TAU) assumes the identity layer from Phase 5 is correct, so an identity bug is a foundation crack, not a local defect. Prediction: an identity-allocation race under load (I8) manifests downstream, in paging or handover, before it manifests where it originated. Bug class without it: debugging a Phase 8 paging failure for hours before realizing the root cause is a Phase 5 GUTI collision. Resolves §7 (I8), §17, §20.
  • MM5 — Insight: determinism is not a nice-to-have property layered on top of a discrete-event simulator — it is the simulator's actual claim to being a scientific instrument (P10); without it, every reported metric is a one-off anecdote, not a reproducible measurement. Prediction: any hidden source of nondeterminism (unseeded HashMap iteration, system-clock reads) eventually surfaces as a hard-to-reproduce flaky test, usually far downstream from its actual location. Bug class without it: chasing a "flaky" Phase 10 soak-test failure that is actually a Phase 0 iteration-order bug. Resolves §7 (I11), §12, §22.
  • MM6 — Insight: security-context establishment is a strict prerequisite gate, not a parallel concern (P4, I3) — the entire protected-message universe is downstream of one boolean (has AKA completed), so getting that gate wrong invalidates everything after it. Prediction: any new protected-message type added in a later phase must be checked against the I3 guard from day one of that phase's work, not retrofitted. Bug class without it: a new 5G message type (Phase 11) that bypasses the I3-equivalent check because the guard was per-message-type rather than structural. Resolves §7 (I3), §18, §23.
  • MM7 — Insight: a handover is fundamentally a two-phase-commit-shaped problem (prepare on target, commit by switching path, only then release source) even though 3GPP doesn't name it that way — recognizing the shape means the same failure-mode vocabulary (partial commit, rollback, never leave both sides uncommitted) applies. Prediction: any handover-adjacent bug looks like a classic distributed-transaction bug — a resource released before its replacement is confirmed — once traced. Bug class without it: releasing the source-cell context on a fixed timer instead of gating it on target confirmation. Resolves §7 (I5), §21.
  • MM8 — Insight: the core network's logical decomposition (MME/SGW/PGW/HSS, or AMF/SMF/UPF/UDM) exists because 3GPP separates concerns by function, and that separation is itself a scalability lever, not incidental structure (ADR-09) — the state each element owns is exactly the state that must serialize through it under concurrency (P5). Prediction: the practical parallelism ceiling in Phase 10 traces directly back to which elements a given scenario's UEs share. Bug class without it: trying to parallelize handover-heavy scenarios without noticing every handover serializes through the same MME instance. Resolves §9 (ADR-09), §22, §31.

Reference Implementations

  • srsRAN (srsLTE) — lib/src/ for the protocol layers (RRC, PDCP, RLC, MAC). Lesson: clean per-layer separation with explicit SDU/PDU types. Pitfall: tight coupling between scheduler and PHY driver assumptions that do not transfer to a simulator. Applied in Phase 1, Phase 4.
  • OpenAirInterface (OAI) — openair2/ for RRC/PDCP/RLC/MAC. Lesson: RRC procedure state machines map closely to 3GPP clause structure. Pitfall: heavy macro/config coupling complicates isolated study. Applied in Phase 4, Phase 9.
  • Open5GS — src/ for the core-network elements (AMF, SMF, UPF, UDM). Lesson: clear per-network-function process boundaries mirroring SBA. Pitfall: full SBA microservice depth is unnecessary for message-level fidelity. Applied in Phase 7, Phase 10.
  • free5GC — 5G core reference for AMF/SMF/UPF call flows. Lesson: Go-based SBA reference showing NF interaction patterns. Pitfall: HTTP/2-based SBI encoding detail is out of this project's scope (ADR-18). Applied in Phase 11.
  • ns-3 (LTE module, src/lte/, and 5G-LENA) — discrete-event scheduler and event-queue design; LTE/NR RRC and scheduler models. Lesson: calendar-queue scheduling at scale. Pitfall: tight coupling of protocol logic to ns-3's own object model. Applied in Phase 0, §33.
  • Amarisoft (where documented) — commercial reference for real call-flow traces used in differential comparison. Applied in §28, §33.

Glossary (§38) · 59 terms · site-wide glossary

UE
User Equipment; the mobile device/subscriber terminal.
eNodeB
LTE radio access network base station.
gNB
5G NR radio access network base station.
EPC
Evolved Packet Core; the LTE core network (MME/SGW/PGW/HSS).
5GC
5G Core network (AMF/SMF/UPF/UDM).
MME
Mobility Management Entity; LTE control-plane core element.
AMF
Access and Mobility Management Function; 5G equivalent of MME.
SGW
Serving Gateway; LTE user-plane anchor toward the PGW.
PGW
Packet Data Network Gateway; LTE user-plane anchor toward external networks.
UPF
User Plane Function; 5G equivalent of SGW/PGW.
HSS
Home Subscriber Server; LTE subscriber/security-data store.
UDM
Unified Data Management; 5G equivalent of HSS.
NAS
Non-Access Stratum; mobility/session-management signaling between UE and MME/AMF.
RRC
Radio Resource Control; radio-resource signaling between UE and eNodeB/gNB.
PDCP
Packet Data Convergence Protocol; sequencing/ciphering-placeholder layer.
RLC
Radio Link Control; segmentation, ARQ, reordering layer.
MAC
Medium Access Control; scheduling, HARQ, multiplexing layer.
PHY
Physical layer; here, an analytic SINR/BLER abstraction, not a waveform model.
RRC Idle
RRC state with no active radio connection.
RRC Connected
RRC state with an active radio connection.
RRC Inactive
5G RRC state suspending the radio connection for fast resume.
EMM
EPS Mobility Management; LTE NAS-layer mobility state machine.
MM
Mobility Management; 5G NAS-layer mobility state machine (EMM's equivalent).
RACH
Random Access Channel procedure; how a UE gains initial uplink access.
preamble
the random-access signal a UE transmits in step 1 of RACH.
RAR
Random Access Response; step 2 of RACH.
contention resolution
RACH step 4, resolving which UE "won" a shared preamble.
SIB
System Information Block; broadcast cell-configuration information.
MIB
Master Information Block; the first broadcast block a UE reads.
attach
the LTE procedure by which a UE registers with the core network (the 5G equivalent term is registration).
AKA
Authentication and Key Agreement; the challenge-response authentication procedure.
IMSI
International Mobile Subscriber Identity; LTE permanent subscriber identity.
SUPI
Subscription Permanent Identifier; 5G permanent subscriber identity.
GUTI
Globally Unique Temporary Identity; LTE temporary identity.
SUCI
Subscription Concealed Identifier; 5G's concealed form of the SUPI.
KASME
LTE key derived from CK/IK and the serving-network identity.
KeNB
LTE key derived from KASME, securing the RRC/user-plane context at an eNodeB.
KAMF
5G key derived analogous to KASME, held by the AMF.
KgNB
5G key derived analogous to KeNB, held by the gNB.
bearer
an LTE logical data-transport channel with an associated QoS class (QCI).
PDU session
the 5G equivalent of a bearer, associated with a 5QI.
QCI
QoS Class Identifier; LTE bearer QoS class.
5QI
5G QoS Identifier; 5G PDU-session QoS class.
handover
the procedure moving a UE's active connection from one cell to another.
X2
the LTE eNodeB-to-eNodeB interface used for direct handover signaling.
Xn
the 5G gNB-to-gNB interface, X2's 5G equivalent.
S1
the LTE eNodeB-to-MME/SGW interface.
N2
the 5G gNB-to-AMF interface, S1's 5G equivalent.
paging
the procedure notifying an Idle UE of pending downlink data or signaling.
TAU
Tracking Area Update; a lightweight periodic/mobility-triggered re-registration.
GTP
GPRS Tunneling Protocol; user-plane (GTP-U) and control-plane (GTP-C) tunneling.
SBI
Service-Based Interface; 5G core's HTTP/2-based inter-NF interface.
discrete-event simulation
a simulation paradigm advancing time only at event timestamps, not fixed ticks.
event queue
the ordered data structure (here, a binary min-heap) holding pending events.
SINR
Signal-to-Interference-plus-Noise Ratio; the channel-quality metric driving the PHY abstraction.
BLER
Block Error Rate; the transport-block failure probability derived from SINR.
radio-link failure
an unexpected loss of the RRC-Connected radio link (FM-1).
tracking area
the geographic grouping of cells within which paging is dispatched without a fresh location update.
replay hash
the deterministic checksum of an event trace, used to verify I11.
