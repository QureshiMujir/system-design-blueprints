⬜ Phase 2 — CTL syntax, AST, and well-formedness §14

Objectives
  • Extend tl-syntax + tl-formula to CTL: fused path-quantifier ops Ex/Ax/Eg/Ag/Ef/Af/Eu/Au (no bare E/A).
  • Parse E[p U q] / A[p U q] (bracketed binary CTL until) into Formula::Eu/Au; parse EX/AX/EG/AG/EF/AF prefix unaries.
  • Enforce state-vs-path well-formedness: in CTL every temporal op (X/U/R/F/G) must sit directly under a path quantifier; no nesting two temporals without an intervening quantifier; no bare path quantifier.
  • Classify any parsed Formula -> Kind { Ltl, Ctl, PastLtl, Ltlf } by which operator families appear (mutually exclusive checks).
  • NNF for CTL: dualities not Ex = Ag not, not Ef = Ag not (= not Eu(true,·)), pushing negation to atoms preserving the fixed op set.
  • Reject ill-formed CTL with a precise ParseError/WfError (offset + kind + offending op). No silent acceptance — a wrong Kind mislabels downstream (CtlChecker vs automata path).
Deliverable
  • tl parse "AG(req -> AF ack)" -> typed Formula + Kind::Ctl, pretty-printed back identically (round-trip).
  • tl parse "AG(F p)" (path op under no quantifier between G and F) -> WfError::NestedTemporalNoQuantifier with span on F.
  • classify returns the correct Kind for LTL / CTL / past-LTL / LTLf-flagged inputs; mixed -> typed error.

⬜ Phase 3 — Trace and Kripke models §15

Objectives
  • State { aps: Bitset } — AP valuation; holds(ap) -> bool, len/popcount, Eq/Hash/Ord for state dedup + product hashing.
  • Trace { prefix: Vec<State>, loop_start: Option<usize> } — None = finite word (LTLf); Some(i) = lasso, suffix prefix[i..] repeats forever → omega-word prefix[0..i]·(prefix[i..])^ω; Trace::at(t) unrolls the lasso for any t: usize.

⬜ Phase 4 — Finite-trace LTL (LTLf) by formula progression §16

Objectives
  • tl-eval::ltlf::eval_ltlf(f: &Formula, t: &Trace) -> bool: total, panic-free, definitive verdict on any finite, NNF-or-raw LTL/LTLf Formula.
  • Progression recurrence engine: progress(f, s) -> Formula folding one State -> residual; eval_ltlf = fold over prefix then end-of-trace collapse.
  • Weak/strong next on finite words: X f is strong (false past end), weak-X f / dual R,G are satisfied vacuously at end; collapse residual via end_value.
  • Linear-in-trace, bounded residual size; reject CTL/path-quantifier Formula variants with an Err-free precondition (debug_assert Kind == Ltl|Ltlf); match canonical LTLf truth tables on a fixture suite with zero verdict drift vs hand-computed semantics.

⬜ Phase 6 — LTL to generalized Buchi (GPVW on-the-fly tableau) §18

Objectives
  • ltl_to_ngba(f) -> Ngba: NNF LTL → generalized Buchi, L(Ngba) = models of f exactly.
  • GPVW node = obligation set over subformula closure(f), split current (now) vs next; expand boolean/temporal until only literals + X-deferrals remain.
  • Edge Guard = conjunction of the node's atomic literals (positive AP, negated AP); next field → successor node's incoming obligations.
  • Accept sets: one per U-subformula α U β; a node is in that accept set iff β ∈ now OR (α U β) ∉ now → prevents stalling on the eventuality.
  • Lazy worklist: expand only generates successors of reached nodes; dedup by canonical now-set key → no full-2^closure blowup.
Deliverable

ltl_to_ngba in tl-automata returning a populated Ngba (nstates, init, edges with Guards, accept = one set per Until). tl to-buchi --gba <formula> prints the Ngba as HOA / dot. Lazy construction: a --max-states N guard aborts pathological inputs. Round-trips through Phase 7 degeneralize.

Acceptance
  • L(ltl_to_ngba(f)) = models of f for all Phase-13 pattern formulas (verified via product-emptiness vs hand traces + Spot).
  • State count within constant factor of Spot ltl2tgba on the pattern set; |accept| == count_until_subformulas(f).
  • ltl_to_ngba(F p) ≤ 2 reachable states, 1 accept set; ltl_to_ngba(G p) ≤ 1 state, 0 accept sets (all-accepting); ltl_to_ngba(p U q) ≤ 2 states, 1 accept set.
  • Worst-case ≤ 2^|closure(f)| states (theoretical bound); typical pattern formulas ≪ that. Construction of any pattern formula < 50 ms.
  • Every reachable node is dedup-canonical: no two Ngba states share an identical (now, next) key.

Pitfalls
  • AP-naming skew with Spot: Spot relabels/orders APs; mapping tl Ap id ↔ Spot proposition by string is essential — mismatched bit positions ⇒ phantom non-equiv. Debug: dump both Guard truth tables per edge.
  • ltl2tgba operator-syntax drift (<>,[],W,M): translate Formula→Spot syntax via one printer; a wrong R/W mapping silently yields a different formula that may still pass on weak fixtures. Debug: round-trip φ→spot-str→spot-parse→HOA→equiv(φ).
  • Trivially-empty masking: if BOTH sides build the empty/false automaton from a bug, cross-product emptiness passes vacuously. Guard: include positive-language assertions (L≠∅ for satisfiable φ) and check accepting-run existence.
  • Fuzz finds reductions, not equivalence: a fuzz panic in ltl_to_ngba may be a real GPVW eventuality bug. Triage: cargo fuzz tmin then replay through to-buchi --hoa + equiv.
  • Spot version nondeterminism: automaton size varies across Spot releases ⇒ never assert exact Spot state counts, only language equivalence + tl's own size bounds (pin Spot version in Docker for the size-regression baseline only). Lasso false-positive: a Lasso whose cycle isn't actually accepting (inner-DFS color bug) self-validates wrong if the replayer reuses buggy code; replayer must be an independent lasso evaluator over φ (NNF).
