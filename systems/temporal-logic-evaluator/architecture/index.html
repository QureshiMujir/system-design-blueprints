3. Architectural Overview

The evaluator is a seven-crate Rust workspace. tl-syntax + tl-formula form the shared front end: untrusted formula text becomes a typed Formula AST in NNF. From that single AST, four disjoint evaluation paths fan out — CTL labeling, LTL automata-theoretic model checking, LTLf/past-LTL trace evaluation, and runtime monitoring — every one of them grounded on the tl-trace model (State, Trace, KripkeStructure). tl-cli (the tl binary) is the only std member and the only I/O surface. No path persists state; all structures are in-memory, single-process, deterministic.

3.1 Canonical Architecture Diagram

                       tl-cli   (tl: eval / to-buchi / check / monitor)            [std; only I/O surface]
                           |  formula text  +  (trace | Kripke structure | event stream)

     EX/EU/EG fixpoints    -> degeneralize      finite Trace) ;         Verdict; monitor
     over Kripke states    -> product           past-LTL DP             automaton)
        |                  (Nba x Kripke)        |                       |
        |                  -> emptiness          |                       |

   == NO PERSISTENCE BOUNDARY == nothing below tl-cli touches disk/network; all in-memory, deterministic

Data flows:

  • In: formula text -> Lexer/Parser -> Formula -> nnf() -> NNF Formula; trace text -> Trace; Kripke text -> KripkeStructure; event lines -> State stream.
  • Out: Vec<bool> per-state sat labeling + holds: bool (CTL); holds + Lasso counterexample (LTL); bool verdict (LTLf/past); streaming RvVerdict (monitor); Ngba/Nba as HOA/dot (to-buchi).
  • Trust boundary: drawn directly below tl-cli. Formula text, trace text, Kripke text, and the event stream are all untrusted; tl-syntax (bounded recursion, sized errors) + tl-trace validation (total transition relation, well-formed lasso) are the only sanitizers. Everything below treats inputs as already-typed and total.
  • Persistence boundary: none. No file/network/clock/RNG dependency below tl-cli (RNG appears only in Phase 13 test harnesses, not the engine). Each invocation is a pure function of its inputs.

3.2 Per-Box Responsibilities

tl-cli — the tl binary, the single std crate and sole I/O boundary. Subcommands: eval (formula + trace -> verdict), to-buchi (formula -> Ngba/Nba as HOA or dot), check (formula + Kripke -> holds / Lasso counterexample), monitor (event stream -> streaming RvVerdict). In: argv + stdin/files (formula, trace, Kripke, stream text). Out: stdout verdict/automaton/counterexample, exit codes (0 holds, 1 counterexample, 2 usage/parse error). Depends on all six lower crates. Invariant: it is the only member with side effects; all engine logic stays pure below the trust boundary. Built across Phase 0 (skeleton wiring) and finalized as each subcommand's path lands (Phases 4/5/8/9).

tl-syntax — no_std + alloc lexer + parser for LTL, CTL, past-LTL, and LTLf concrete syntax into the Formula AST, plus a pretty-printer. Exposes Lexer, Token, Parser, ParseError/ParseErrorKind; interns each atomic proposition to an Ap = u32. In: untrusted formula text. Out: Formula or a sized, positioned ParseError. Precedence (locked): unary X/F/G/past unaries/Not bind tightest, then binary U/R/S, then And, then Or. Invariant: bounded recursion depth — no stack overflow on adversarial nesting; every accepted string round-trips through the pretty-printer to an equal Formula. The outermost line of defense at the trust boundary. Built in Phases 1 (LTL/NNF tokens + precedence) and 2 (CTL fused path-quantifier operators).

tl-formula — no_std + alloc home of the Formula AST and its transformations, the semantic core every path shares. Atom = Ap id. Provides nnf() (push Not to atoms via the locked dualities: not X = X not, not(p U q) = (not p) R (not q), not F = G not, not G = F not, not(EX) = AX(not), etc.), simplification/rewrite, closure() (subformula closure feeding GPVW and CTL labeling), and Kind well-formedness classification (Ltl/Ctl/PastLtl/Ltlf, enforcing the CTL state-formula-vs-path-formula distinction). In: raw Formula. Out: NNF Formula, Vec<Formula> closure, Kind. Invariant: after nnf(), negation appears only on atoms and the operator set is fixed — GPVW and the labeling algorithm depend on this precondition. Built in Phases 1 (NNF) and 2 (CTL well-formedness).

tl-trace — no_std + alloc word/structure model shared by all four evaluation paths. State { aps: Bitset } (which APs hold), Trace { prefix: Vec<State>, loop_start: Option<usize> } (finite prefix; Some => lasso-shaped infinite word), KripkeStructure { states, init, edges, /* successors */ } (states, init set, successor edges, labeling). In: parsed model text from tl-cli. Out: validated structures consumed by tl-eval, tl-automata, tl-monitor. Invariant: a KripkeStructure has a total transition relation (every state has ≥1 successor — required for correct CTL/Buchi semantics) and a Trace's loop_start, when present, indexes a valid prefix position (well-formed lasso). The inner sanitizer of the trust boundary. Built in Phase 3.

tl-automata — no_std + alloc omega-automata layer, depends on tl-formula + tl-trace. Types: Ngba (generalized Buchi, accept: Vec<Vec<usize>> = set of accept sets), Nba (Buchi, single accept: Vec<usize>), Guard (boolean over APs as DNF / bitset mask+care), Lasso { stem, cycle }. Pipeline: ltl_to_ngba (GPVW on-the-fly tableau — nodes = obligation sets over the closure split into now-guard / next-obligations; one generalized accept set per Until-eventuality), degeneralize (Ngba k accept sets -> Nba on state x counter 0..k), product (synchronous Nba x Kripke), emptiness (nested DFS -> Option<Lasso>). In: NNF Formula, KripkeStructure. Out: Ngba/Nba, Lasso. Invariant: the constructed automaton's language exactly equals the LTL formula's models, and emptiness returns Some(lasso) iff a reachable accepting cycle exists — this is the gravest correctness surface, since a GPVW/degeneralization/nested-DFS bug silently flips a verdict with no crash (primary guard: Phase 13 differential testing vs Spot's ltl2tgba). Built in Phases 6 (GPVW->Ngba), 7 (degeneralize + simplify), 8 (product + nested-DFS emptiness), with lazy/on-the-fly product in Phase 12.

tl-eval — no_std + alloc evaluators, depends on tl-formula + tl-trace + tl-automata. CtlChecker<'a> over a KripkeStructure: sat(f) -> Vec<bool> per-state labeling (sat(EX p) = preimage; sat(E[p U q]) = least fixpoint; sat(EG p) = greatest fixpoint via SCC quotient; EF/AG/AF/AX/A[U] by duality) and holds(f) -> bool (every init state labeled). eval_ltlf(f, t) -> bool (finite-trace LTL by formula progression, definitive at end-of-trace, weak/strong next distinction on finite words). check_ltl(f, k) -> Result<(), Lasso> (the automata-theoretic check: product(Nba(not phi), k) then emptiness; Ok = holds, Err(lasso) = counterexample). Past-LTL DP. In: NNF Formula + Trace/KripkeStructure. Out: labeling Vec<bool>, bool, Result<(), Lasso>. Invariant: K satisfies A phi iff L(product(Nba(not phi), K)) is empty; CTL holds iff every init state ∈ sat(f). Built in Phases 4 (LTLf), 5 (CTL labeling), 8 (LTL model check), 10 (past-LTL DP), 11 (LTLf->DFA).

tl-monitor — no_std + alloc runtime verification, depends on tl-formula + tl-automata. Verdict { True, False } (2-valued definitive); RvVerdict { True, False, PresumablyTrue, PresumablyFalse, Unknown } (LTL3 / RV-LTL 4-valued); Monitor (current progressed Formula or monitor-automaton state). Monitor::step(&mut self, s) -> RvVerdict folds progress(f, s) -> Formula (the LTL derivative: progress(X f,s)=f; progress(f U g,s)=progress(g,s) OR (progress(f,s) AND f U g); progress(G f,s)=progress(f,s) AND G f; progress(atom p,s)=True/False) over the event stream. Monitorability classification + optional monitor-automaton synthesis. In: NNF Formula + streamed State events. Out: per-event RvVerdict; a True/False residual = definitive (good/bad prefix). Invariant: a definitive verdict is emitted iff the observed prefix is a good prefix (all extensions satisfy phi -> True) or bad prefix (none do -> False); otherwise Unknown and the verdict is latched once definitive (never reverts). Built in Phase 9.

8. Domain Model — LTL/CTL Syntax, Automata, and Trace Semantics

This is the formal core: the grammar tl-syntax parses, the semantics tl-eval/tl-monitor implement, the NNF tl-formula produces, the omega-automata tl-automata builds, and the trace/Kripke structures tl-trace defines. Every later phase is an algorithm over these objects; ambiguity here is a verdict-flipping bug (the gravest failure class). All definitions LOCKED.

8.1 Atomic propositions and alphabet

Concept Definition Representation
AP (atomic proposition) named boolean observable, e.g. p, req, ack_2 Ap = u32, interned by tl-syntax
AP universe Σ_AP = { all interned Ap }, size n symbol table; n fixed per formula/model
Letter / valuation a subset of AP that hold simultaneously State { aps: Bitset }, bit i set ⇔ AP i holds
Alphabet Σ 2^Σ_AP — power set of APs (one letter = one valuation) `
omega-word w ∈ Σ^ω, infinite sequence w = w₀ w₁ w₂ …, each wᵢ ⊆ AP lasso-encoded Trace (§8.7)
finite word u ∈ Σ⁺, u = u₀ … u_{m-1}, length m ≥ 1 Trace with loop_start = None
  • AP id assignment: first-seen order during lex; identical lexeme ⇒ same Ap. Closed alphabet ⇒ Guard masks have fixed width n.
  • Bitset width = n rounded to machine words; Σ is NEVER materialized (2^n blowup) — guards stay symbolic (mask+care, DNF over APs).

8.2 Grammar (EBNF) — LTL + past-LTL + LTLf + CTL

Single concrete syntax; Kind ∈ {Ltl, Ctl, PastLtl, Ltlf} is decided post-parse by tl-formula well-formedness (§8.6), not by separate grammars. CTL fuses each path quantifier with exactly one temporal op (no bare A/E).

formula     = iff_expr ;

(* boolean layer — lowest precedence first, all left-assoc except -> right-assoc *)
iff_expr    = imp_expr , { "<->" , imp_expr } ;          (* <-> : equivalence  *)
imp_expr    = or_expr  , [ "->" , imp_expr ] ;           (* -> : right-assoc, lowest binary *)
or_expr     = and_expr , { "|"  , and_expr } ;           (* | : disjunction *)
and_expr    = bin_temp , { "&"  , bin_temp } ;           (* & : conjunction *)

(* binary temporal — bind tighter than boolean, right-assoc *)
bin_temp    = un_expr , { ("U" | "R" | "W" | "M" | "S") , un_expr } ;
                (* U until, R release, W weak-until, M strong-release (LTL);
                   S since (past-LTL). W,M are sugar -> U,R in NNF *)

(* unary prefix — highest precedence, right-assoc, stackable: e.g. X X G p *)
un_expr     = { un_op } , primary ;
un_op       = "!" | "X" | "F" | "G"                       (* future LTL: ! not, X next, F eventually, G globally *)
            | "Y" | "O" | "H"                             (* past-LTL: Y previous, O once, H historically *)
            | ctl_un ;                                    (* CTL fused quantifier+op *)
ctl_un      = "EX" | "AX" | "EF" | "AF" | "EG" | "AG" ;

primary     = atom
            | "true" | "false"
            | "(" , formula , ")"
            | ctl_bin_until ;                             (* fused CTL until needs explicit bracket form *)

ctl_bin_until = ("E" | "A") , "[" , formula , "U" , formula , "]" ;  (* E[φ U ψ], A[φ U ψ] *)

atom        = lower_id ;                                  (* AP: [a-z][A-Za-z0-9_]*  e.g. p, req, ack_2 *)
lower_id    = ? [a-z][A-Za-z0-9_]* ? ;

Precedence summary (tightest → loosest): unary prefix (!,X,F,G,Y,O,H,EX…AG) > binary temporal (U,R,W,M,S) > & > | > -> > <->. Examples disambiguated:

Input Parse
G p -> F q (G p) -> (F q) — unary binds before ->
a U b U c a U (b U c) — U right-assoc
! a U b (! a) U b — ! binds before U
a & b U c a & (b U c) — U tighter than &
EF p & q (EF p) & q — EF unary, tighter than &
A[p U q] -> r (A[p U q]) -> (r)

Sugar expansion (parse-time, before NNF): p<->q ⇒ (p->q)&(q->p); p->q ⇒ !p|q; p W q ⇒ (p U q)|G p; p M q ⇒ (p R q)&F p. Formula AST has no W/M/->/<-> nodes — only LOCKED variants.

8.3 LTL semantics over omega-words

w ⊨ φ ("word w models φ"); wⁱ = wᵢ wᵢ₊₁ … is the suffix from position i; w ⊨ φ ≜ w⁰ ⊨ φ. Future fragment (positions i,j ∈ ℕ):

Operator wⁱ ⊨ … iff
Atom(p) p ∈ wᵢ
True / False always / never
Not φ not wⁱ ⊨ φ
And φ ψ / Or φ ψ both / either
X φ (next) wⁱ⁺¹ ⊨ φ
F φ (eventually) ∃ j ≥ i. wʲ ⊨ φ
G φ (globally) ∀ j ≥ i. wʲ ⊨ φ
U φ ψ (until) ∃ j ≥ i. (wʲ ⊨ ψ) ∧ ∀ i ≤ k < j. wᵏ ⊨ φ
R φ ψ (release) ∀ j ≥ i. (wʲ ⊨ ψ) ∨ ∃ i ≤ k < j. wᵏ ⊨ φ

Identities (used by simplification + NNF): F φ ≡ true U φ; G φ ≡ false R φ ≡ !F!φ; φ R ψ ≡ !(!φ U !ψ); X(φ∧ψ) ≡ Xφ ∧ Xψ; X is self-dual: !Xφ ≡ X!φ. Strong-until U requires ψ to actually occur; weak-until W (sugar) does not.

8.4 CTL semantics over Kripke states

CTL is interpreted at a state s of a Kripke structure K = (S, S₀, →, L) where L(s) ⊆ AP. A path π = s₀ s₁ … satisfies s_{k} → s_{k+1} for all k; π[i] is its i-th state. K, s ⊨ φ:

Operator K, s ⊨ … iff Quantifier reading
Atom(p) p ∈ L(s) —
Not/And/Or boolean, pointwise —
Ex φ (EX) ∃ s'. s → s' ∧ K,s' ⊨ φ exists-next
Ax φ (AX) ∀ s'. s → s' ⇒ K,s' ⊨ φ all-next = !EX!φ
Ef φ (EF) ∃ path π from s. ∃ i. K,π[i] ⊨ φ exists-eventually = E[true U φ]
Af φ (AF) ∀ path π from s. ∃ i. K,π[i] ⊨ φ all-eventually = !EG!φ
Eg φ (EG) ∃ path π from s. ∀ i. K,π[i] ⊨ φ exists-globally
Ag φ (AG) ∀ path π from s. ∀ i. K,π[i] ⊨ φ all-globally = !EF!φ
Eu φ ψ (E[φUψ]) ∃ path π. ∃ j. K,π[j] ⊨ ψ ∧ ∀ k<j. K,π[k] ⊨ φ exists-until
Au φ ψ (A[φUψ]) ∀ path π. ∃ j. K,π[j] ⊨ ψ ∧ ∀ k<j. K,π[k] ⊨ φ all-until

CTL adequate basis: {EX, EG, EU} + boolean. Derivations (used by CtlChecker): EF φ = E[true U φ]; AX φ = !EX !φ; AG φ = !EF !φ = !E[true U !φ]; AF φ = !EG !φ; A[φ U ψ] = !( E[!ψ U (!φ∧!ψ)] ) ∧ !EG !ψ. State-vs-path: every CTL operator pairs a quantifier {A,E} with a temporal op {X,F,G,U} — a temporal op WITHOUT a quantifier (e.g. EX(p U q)) is a path formula in a state context ⇒ rejected (§8.6). CTL* (full nesting) is a NON-GOAL.

8.5 Finite-trace LTLf and past-LTL semantics

LTLf (De Giacomo–Vardi): same syntax as LTL, interpreted over a finite word u = u₀…u_{m-1}, m = |u| ≥ 1. Suffix uⁱ, last index m-1. The end-of-trace boundary forces a weak/strong-next split:

Operator uⁱ ⊨ … (LTLf), 0 ≤ i < m iff
X φ (strong next) i+1 < m ∧ u^{i+1} ⊨ φ — false at last index (no successor)
weak-next N φ i+1 = m ∨ u^{i+1} ⊨ φ — true at last index; N φ ≜ !X!φ on finite words
F φ ∃ i ≤ j < m. uʲ ⊨ φ
G φ ∀ i ≤ j < m. uʲ ⊨ φ (vacuously true past the end)
U φ ψ ∃ i ≤ j < m. uʲ ⊨ ψ ∧ ∀ i ≤ k < j. uᵏ ⊨ φ
R φ ψ ∀ i ≤ j < m. uʲ ⊨ ψ ∨ ∃ i ≤ k < j. uᵏ ⊨ φ (release weak at end)
  • eval_ltlf(f, t) returns a definitive bool (no Unknown) — the whole trace is observed. Computed by progression (§8.8, Phase 4): X progresses to its arg; at the final state the residual is evaluated with X φ ⇒ false, G φ ⇒ true, etc. — the weak/strong-next distinction lives entirely at this last step.
  • LTLf ≠ LTL on the same prefix: G p is true on any finite all-p trace but false on an infinite word that later drops p.

Past-LTL: future + past operators over a word, position i, looking backward (Phase 10, evaluated by DP):

Operator wⁱ ⊨ … iff
Y φ (previous, strong) i > 0 ∧ w^{i-1} ⊨ φ — false at i = 0
O φ (once) ∃ 0 ≤ j ≤ i. wʲ ⊨ φ — past-F
H φ (historically) ∀ 0 ≤ j ≤ i. wʲ ⊨ φ — past-G = !O!φ
S φ ψ (since) ∃ 0 ≤ j ≤ i. wʲ ⊨ ψ ∧ ∀ j < k ≤ i. wᵏ ⊨ φ — past-U

Duals: O φ = true S φ; H φ = !O !φ; weak-previous Ỹ φ = !Y!φ (true at i=0). Past-LTL is evaluable left-to-right: each state's past-obligation vector derives from the previous state's (DP, §10), O(m·|cl|) time.

8.6 Well-formedness — Kind classification

tl-formula::Kind ∈ {Ltl, Ctl, PastLtl, Ltlf} assigned by structural rules. Mixing fragments is rejected with the listed error (ParseError/well-formedness check):

Rule Holds Violation → error
CTL state-formula closure every temporal op carries a quantifier (Ex/Ax/Ef/Af/Eg/Ag/Eu/Au); the immediate arg of a quantifier is itself a state formula bare X/F/G/U/R under a state context ⇒ PathFormulaWhereStateRequired
LTL purity no Ex…Au nodes; future ops only CTL op in LTL ⇒ MixedFragment
Past purity (PastLtl) Y/O/H/S present; combined with future LTL allowed; NO CTL CTL op ⇒ MixedFragment
LTLf same node set as LTL; flagged by CLI/context (--finite), not by distinct nodes —
Quantifier well-nesting Eu/Au written E[..U..]/A[..U..]; both args state formulas A p U q (no brackets) ⇒ ParseError::ExpectedBracket

Kind selects the evaluator: Ltl+Kripke → automata path (check_ltl); Ctl+Kripke → CtlChecker; Ltl/Ltlf+Trace → eval_ltlf; PastLtl+Trace → past-LTL DP; Ltl+stream → tl-monitor.

8.7 NNF + duality rules

nnf(f: &Formula) -> Formula pushes Not inward until it sits only on Atom. Why: GPVW tableau (§8.10) and CTL labeling (§8.12) assume negation only on atoms (so the subformula closure is positive and obligation sets are monotone). LOCKED dualities:

Negated form Rewrites to
!!φ φ
!True / !False False / True
!(φ ∧ ψ) !φ ∨ !ψ
!(φ ∨ ψ) !φ ∧ !ψ
!X φ X !φ (X self-dual)
!F φ G !φ
!G φ F !φ
!(φ U ψ) !φ R !ψ
!(φ R ψ) !φ U !ψ
!Y φ Ỹ !φ (weak-previous; = !Y!φ, true at i=0)
!O φ H !φ
!H φ O !φ
!(φ S ψ) weak-since of duals (!φ S̃ !ψ)
!EX φ AX !φ
!AX φ EX !φ
!EF φ AG !φ
!AG φ EF !φ

!AF φ EG !φ
!E[φ U ψ] A[!φ R !ψ] (= AG/AF-derived; uses release form)
!A[φ U ψ] E[!φ R !ψ]

NNF preserves semantics + Kind; size grows ≤ ×2 (one Not per negated leaf). After NNF, Not appears only as Not(Atom(_)); an assert in debug builds checks this invariant before GPVW/labeling.

8.8 Formula progression (the LTL derivative)

progress(f, s) -> Formula rewrites f given current letter s, returning the obligation for the next step; folding it over a stream is the monitor + LTLf evaluator core. Recurrences (over NNF):

progress(true, s)        = true
progress(false, s)       = false
progress(p, s)           = if p ∈ s.aps then true else false       // Atom
progress(!p, s)          = !progress(p, s)                          // p atomic post-NNF
progress(φ ∧ ψ, s)       = progress(φ,s) ∧ progress(ψ,s)
progress(φ ∨ ψ, s)       = progress(φ,s) ∨ progress(ψ,s)
progress(X φ, s)         = φ                                        // discharge one step
progress(F φ, s)         = progress(φ,s) ∨ F φ
progress(G φ, s)         = progress(φ,s) ∧ G φ
progress(φ U ψ, s)       = progress(ψ,s) ∨ (progress(φ,s) ∧ (φ U ψ))
progress(φ R ψ, s)       = progress(ψ,s) ∧ (progress(φ,s) ∨ (φ R ψ))
  • Residual simplified after each step (constant folding) → bounded growth; residual true/false = definitive verdict.
  • LTLf end-of-trace: after the last letter, evaluate the residual with X φ ⇒ false (strong next has no successor), G φ ⇒ true, F φ ⇒ false, φ U ψ ⇒ false, φ R ψ ⇒ true.

8.9 omega-automata model — Nba / Ngba

Concept Ngba (generalized Buchi) Nba (Buchi)
States 0..nstates 0..nstates
Init init: Vec<usize> init: Vec<usize>
Transitions edges[q] = Vec<(Guard, q')> — guard = boolean over APs same
Acceptance accept: Vec<Vec<usize>> — set of accept sets F₁..F_k accept: Vec<usize> — one set F
Run on w∈Σ^ω ρ = q₀ q₁ …, q₀∈init, ∃(g,q_{i+1})∈edges[qᵢ] with wᵢ ⊨ g same
Accepting run ∀ j. inf(ρ) ∩ Fⱼ ≠ ∅ (each Fⱼ hit infinitely often) inf(ρ) ∩ F ≠ ∅ (F hit infinitely often)
Language `L(A) = { w A has an accepting run on w }`
inf(ρ) set of states visited infinitely often same
  • Guard(mask+care / small DNF over APs): a letter wᵢ satisfies g iff wᵢ & care == mask & care. One edge ⇒ a set of letters; Σ never enumerated.
  • A lasso Lasso { stem, cycle } encodes an ultimately-periodic run/word stem·cycle^ω. By the pumping/Ramsey argument: L(A) ≠ ∅ ⇔ A accepts some lasso ⇔ there is a reachable cycle through an accept state (Nba) / through all accept sets (Ngba). emptiness returns Some(Lasso) iff non-empty.

8.10 Worked GPVW example — G(p -> F q) → Ngba

Formula in NNF: G(!p ∨ F q). Subformula closure closure(φ) (positive parts driving obligations): { G(!p∨Fq), !p∨Fq, !p, F q, q }. A GPVW node = an obligation set = subformulas required to hold now, split into a now-part (atomic/boolean ⇒ the edge Guard) and a next-part (carried to the successor). Eventualities (F/U right side) tracked by one generalized accept set each.

Obligation expansion: G ψ ⇒ require ψ now AND G ψ next. F q ⇒ either q now, OR F q next (deferred — must eventually discharge ⇒ accept-set membership). Resulting 2 reachable nodes:

Node Obligation (now / next) Edge guard Successor
n₀ (q pending free) now: !p∨Fq, G-recur; eventuality Fq not yet due true (when p false: !p satisfies; when p true: need Fq) self-loop variants → n₀, n₁
n₁ (owes q) committed Fq deferred: must reach q true n₁ (while !q) / n₀ (when q seen) 
            !p | q                  p & !q
   ┌────────────────────┐      ┌──────────────┐
   │                    v      │              v
 ( n0 )  ───────────────────►  ( n1 )  ◄───────┘   self-loop while !q
   ▲   p & !q (owe q)            │
   └──────── q ──────────────────┘   (q seen: eventuality discharged)
 Ngba accept sets: F1 = { n0 }     (states NOT owing an unfulfilled Fq)
   accepting run must hit F1 infinitely often  ⇒  q recurs whenever p holds
  • One accept set F₁ = {n₀} (one F-eventuality). An infinite run is accepting iff it leaves n₁ (discharges q) infinitely often ⇒ exactly G(p→Fq) semantics: every p is eventually followed by q.
  • Built on-the-fly: nodes generated lazily as obligation sets are explored; only reachable nodes materialized (Phase 6 + Phase 12 lazy product).

Degeneralize Ngba → Nba (§8.11, Phase 7): k=1 accept set ⇒ degeneralization is trivial — the counter has range 0..1, Nba.accept = F₁ = {n₀}, structure unchanged. (For k>1: states become (q, c), c∈0..k, c advances when current accept set F_c is visited; single Nba accept set = {(q,0) : q∈F_k}.)

Accepting lasso readoff: word ({p,q})^ω — at each step p holds and q holds, run n₀ →(p&q? handled as q seen) n₀ … stays in/returns to n₀ ⇒ visits F₁ infinitely ⇒ accepted. Word ({p})^ω (p forever, q never): run forced into n₁ and stuck (!q self-loop), never revisits F₁ ⇒ rejected ⇒ correct (p never followed by q). Lasso for the rejected case in a model check = counterexample stem=[], cycle=[{p}].

8.11 Degeneralization correctness (counter construction)

degeneralize(g: &Ngba) -> Nba: states = {0..g.nstates} × {0..k} where k = g.accept.len(); init = {(q,0) : q∈g.init}; from (q,c) on edge (guard,q'): go to (q', c') where c' = (c+1) mod k if q ∈ accept[c] else c; single accept set F = {(q, 0) : q ∈ accept[k-1]} (chosen convention: accept when the counter wraps past the last set). State blowup ≤ × k. Invariant: an Nba run hits F infinitely often ⇔ the projected Ngba run hits every accept[i] infinitely often. k=0 (no accept sets, e.g. a safety formula) ⇒ all states accepting (every infinite run accepted).

8.12 Worked CTL labeling example — EF q and AG p over a Kripke structure

CtlChecker::sat(f) -> Vec<bool> returns per-state truth (index = state id). holds ⇔ all init states labeled true. Example K: 4 states.

   states: s0{p}   s1{p,q}   s2{p}   s3{}
   init = { s0 }
   edges:  s0 -> s1, s2 ;  s1 -> s1 ;  s2 -> s3 ;  s3 -> s3
   L(s0)={p}  L(s1)={p,q}  L(s2)={p}  L(s3)={}

sat(EF q) = E[true U q] — least fixpoint, seed = states with q, then add predecessors:

Iter Rule Set (state ids true)
0 sat(q) (seed) {s1}
1 add s : ∃ s→s' ∈ set {s1, s0} (s0→s1)
2 fixpoint (no new preds of s1 besides s0) {s1, s0} — stable

sat(EF q) = [s0:T, s1:T, s2:F, s3:F]. holds(EF q): init {s0} true ⇒ holds (some path from s0 reaches q via s0→s1).

sat(AG p) = !EF !p: first sat(!p) = {s3} (only s3 lacks p). sat(EF !p) lfp: seed {s3}; preds: s2→s3 ⇒ add s2; preds of s2: s0→s2 ⇒ add s0; preds of s3: s3(self) already in; preds of s0: none ⇒ {s3,s2,s0}. sat(AG p) = ¬{s3,s2,s0} = {s1} ⇒ [s0:F,s1:T,s2:F,s3:F]. holds(AG p): init s0 false ⇒ fails (path s0→s2→s3 reaches s3 where !p). Counterexample path: s0 s2 s3.

sat(EG p) (gfp via SCCs): restrict to p-states {s0,s1,s2}; an EG p state lies on an infinite p-path = a state that can reach a nontrivial SCC (or self-loop) within the p-subgraph. s1 self-loops (in p-subgraph) ⇒ s1∈sat(EG p); s0→s1 reaches it ⇒ s0; s2→s3 exits p ⇒ s2∉. sat(EG p)=[s0:T,s1:T,s2:F,s3:F].

Labeling complexity: O(|f| · (|S| + |→|)) (each subformula one fixpoint/SCC pass over the graph) — Clarke-Emerson-Sistla.

8.13 Worked runtime-monitoring example — Monitor::step over a stream for G(req -> F ack)

NNF G(!req ∨ F ack). Monitor::step(s) folds progress then maps the residual to RvVerdict (LTL3/RV-LTL). Stream s₀={req}, s₁={}, s₂={ack}, …:

Event progress residual (simplified) LTL3 verdict Why
s₀={req} F ack ∧ G(!req∨F ack) (req fires ⇒ owes ack) Unknown both an extension satisfying and one violating exist
s₁={} (no ack) F ack ∧ G(…) (still owes ack) Unknown ack could still come
s₂={ack} G(!req∨F ack) (ack discharged; back to base obligation) Unknown safety part can still be violated forever-after
(hypothetical) req then ack never, run ends-ish residual keeps F ack undischarged on every extension that drops ack tends False only if a bad prefix is reached G(req→F ack) is non-monitorable for True (no good prefix)
  • LTL3 maps residual: residual ≡ true ⇒ True; residual ≡ false ⇒ False; else Unknown. True/False are definitive (every / no infinite extension satisfies φ — good/bad prefix).
  • RV-LTL (4-valued via RvVerdict): when LTL3 says Unknown, refine using the finite (LTLf) semantics of the residual to PresumablyTrue/PresumablyFalse; reserves True/False for definitive. Verdict (2-valued) used only where a definitive answer is guaranteed.
  • Monitorability: φ is monitorable from prefix u iff some extension of u reaches a definitive verdict. G(req→F ack) has no good prefix (cannot ever conclude True) but has bad prefixes only in the LTLf reading ⇒ classified by tl-monitor monitorability check.
