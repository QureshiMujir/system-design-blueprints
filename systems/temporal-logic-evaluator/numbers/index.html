4.4 Behavioral invariants

  • No panic on bad input. Lexer/parser → Result<_, ParseError>; cap breaches → typed Err (AutomatonTooLarge, ProductTooLarge, KripkeTooLarge, TraceTooLong, TooManyAps, MonitorStateBlowup). Panics reserved for internal-invariant violations only (debug builds).
  • Zero global init. no_std + alloc for crates 1–6; no lazy_static/OnceCell global state; binary tl does all setup in main. Startup cost = argv parse only.
  • Determinism end-to-end (C-14..C-16). Canonical state numbering (insertion order under a fixed obligation-set ordering), deterministic edge/accept ordering, deterministic tie-break for the shortest Lasso (min stem, then min cycle, then lexicographic state IDs). No RNG, no hashing-order dependence, no thread nondeterminism in the verdict path.
  • Soundness over speed (C-2/C-5). Hitting a size cap returns a typed cap error, never a wrong verdict — the gravest failure class (a silently flipped holds/counterexample from a bad automaton or DFS) is guarded by Phase 13 differential testing vs Spot, not by these caps.
  • Total transition relation. KripkeStructure validated: every state has >= 1 successor (else Err), so EG/cycle reasoning is well-defined.

Back-of-Envelope Capacity Model

Derived numbers, traceable from first principles. Each is computable from the preceding formula+constant.

  1. NNF/closure size. nnf(f) is O(|f|), subformula closure ≤ 2·|f| nodes (each node + its negation). For |f| = 30 operators: closure ≤ 60 entries. Memory: 60 × 24 B/Formula-node ≈ 1.4 KB.

  2. GPVW Ngba states (worst case). Theoretically 2^O(|f|) = 2^closure_size. For closure 60: worst case 2^60 states — never realized in practice. On LTL pattern formulas (Dwyer suite): empirically ≤ a few hundred states for |f| ≤ 20. Rule of thumb: nstates ≤ 2^(#Until-subformulas) × 2^(#boolean-depth).

  3. Degeneralized Nba states. Exactly (k+1) × Ngba.nstates upper bound, where k = number of Until-subformulas. For k=3 eventualities and 200 Ngba states: ≤ 800 Nba states. Memory: 800 states × 32 B/state + edge lists ≈ 25 KB + edges.

  4. Product states. |Nba| × |S|. For Nba = 800 states × Kripke = 10⁵ states: product = 8×10⁷ states. At 32 B/state + 2-bit coloring for nested DFS: ~2.5 GB — near the 10⁷ Kripke ceiling. On-the-fly product (Phase 12) materializes only reachable pairs, often 10–100× fewer.

  5. Nested DFS memory. 2 color bits per product state in Vec<u8>. For 8×10⁷ product states: 2×10⁷ bytes = 20 MB for coloring alone. DFS stack depth bounded by product state count (worst case 8×10⁷ frames × ~40 B/frame = 3 GB) — in practice bounded by the counterexample depth (typically ≤ 10³ for real specs).

  6. Monitor residual size. The number of distinct residuals (up to simplification) is bounded by the monitor automaton state count, ≤ 2^O(|f|). For |f| = 10: at most ~1,000 distinct residuals; after canonicalization ≈ tens. Memory: tens of Formula nodes × 24 B/node ≈ a few KB per active monitor.

  7. LTLf DFA states. Subset construction over the progression closure: ≤ 2^|closure(f)|. For |f| = 15 (30-node closure): worst case 2^30 ≈ 10⁹ DFA states. After Hopcroft minimization, typical patterns yield ≤ few thousand states.

  8. CTL labeling cost. O(|f| × (|S| + |R|)). For |f| = 20 subformulas, |S| = 10⁶, average degree 4 → 5×10⁶ edges: 20 × 6×10⁶ = 1.2×10⁸ operations ≈ 1 sec at 10⁸ ops/s. SCC pass for EG is one O(|S|+|R|) Tarjan sweep.

  9. Past-LTL DP memory. Two vectors of size = #past-subformulas, swapped per state. For |f| = 20 past-subformulas: 2 × 20 × 1 bit ≈ 5 bytes per step. Trace length 10⁷ states: O(5 B × 10⁷) = 50 MB of computation — but only 5 B of state (single-pass DP, O(|sub|) space).

  10. Monitor automaton (pre-compiled). States = distinct LTL derivative classes ≤ 2^O(|f|). Transition table = nstates × 2^|AP| entries. For nstates = 100, |AP| = 10 (1024 AP combinations): 100 × 1024 × (1 state-id u32 + 1 verdict u8) = ~512 KB. Per-event cost: one table lookup = O(1).

  11. HOA file size. Each Ngba state emits one line per edge. For 800-state Ngba, average 3 edges/state: 2400 edge lines × ~20 B/line = ~50 KB. Spot parses this in milliseconds.

  12. CI differential test budget. 10,000 random formulas × (ltl2tgba run ~5 ms + our to-buchi ~1 ms + cross-product emptiness ~2 ms) = 10,000 × 8 ms = 80 s. Parallelized at 8 cores: ~10 s. Within the 30 min CI budget.
