34. Alternative Architectures (Roads Not Taken)

ALT-1 — Kernel-only (no userspace lab). Implement CC purely as in-kernel tcp_congestion_ops modules, tested only with live traffic.

  app → socket → [kernel CC module] → NIC → wire
                   (no sim, no replay)

Wins: zero FFI overhead, exact production semantics, ships directly. Embodied by: the mainline Linux stack. Rejected because: no determinism/replay (I9) and no cheap fast iteration — every experiment needs a kernel build and a live path; violates P2 and the teaching goal.

ALT-2 — Pure discrete-event simulation (no kernel/QUIC). Everything lives in a simulator; never touch a real stack.

  [event queue] → [link/queue/loss model] → [CC under test] → metrics

Wins: fully deterministic, fastest iteration, trivial fault injection. Embodied by: ns-3. Rejected because: no ground truth — a simulator can be internally consistent yet wrong vs the real kernel; this blueprint keeps the sim but adds the differential oracle (§20, P13) precisely to avoid ALT-2's blind spot.

ALT-3 — In-network / AQM-centric. Push control into routers: RED/CoDel/PIE + ECN do the work; endpoints stay simple.

  sender → [router AQM: mark/drop by queue] → receiver
             (control lives in the network)

Wins: protects all flows regardless of endpoint algorithm; low latency without endpoint changes. Embodied by: fq_codel / L4S DualQ (RFC 9332). Rejected as the sole architecture because: it requires cooperative infrastructure the sender can't assume end-to-end; this blueprint uses AQM (§19) but keeps end-to-end control as the primary lever (Jacobson 1988 end-to-end principle).

ALT-4 — Centralized rate allocation (SDN/host-agent). A controller computes per-flow rates from a global view; hosts enforce.

  hosts → telemetry → [central allocator] → rate grants → hosts enforce

Wins: near-optimal allocation and isolation in a single administrative domain. Embodied by: datacenter systems like Google BwE / Swift-style host congestion control. Rejected because: it needs a trusted central view and low-latency control plane — impossible across the public Internet; retained only as a datacenter-mode idea (PhaseDeferred("§35")).
