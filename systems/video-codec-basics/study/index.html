Mental Models & First Principles

The compressed insights an expert video-codec engineer holds. Each predicts a bug class. Every cited § resolves to a real heading.

MM1. A codec is a feedback loop: the encoder must decode its own output. Prediction is formed from the reconstructed (lossy) frame the decoder will also have, not the original. Predicts: zero encoder/decoder drift across a long GOP (I2). Bug without it: predicting from the pristine source → reconstruction mismatch that compounds frame over frame. Applied: Phase 5–6 (reconstruction loop), §4.1 (0-bit drift / 300-frame GOP), I2.

MM2. Only quantization loses information. Prediction, transform, and entropy coding are all reversible; quantization is the single lossy step and the sole quality dial. Predicts: where to spend bits and why QP controls quality. Bug without it: hunting for quality loss in the entropy coder (there is none) instead of the quantizer. Applied: Phase 4 (transform/quant), §8 (domain model), MM6.

MM3. Motion estimation is a search; motion compensation is a copy. The search cost (SAD/SATD) is a proxy for bits, not for pixel error. Predicts: why SATD (frequency-domain) beats SAD for mode decision. Bug without it: minimizing raw pixel error and producing motion vectors that cost more bits than they save. Applied: Phase 8–9 (motion search/comp), ADR-13, MM10.

MM4. Integer transforms are normative; floating point drifts across platforms. The H.264 integer butterfly is bit-exact on every CPU; a float DCT is not. Predicts: cross-platform decode equality. Bug without it: a float transform decodes differently on x86 vs ARM, breaking conformance. Applied: Phase 4 (integer transform), ADR-07/ADR-11, P1/P3.

MM5. The DPB is a reference-counted cache with spec-defined eviction. Reference-picture management (sliding window / MMCO) decides which frames remain available for prediction. Predicts: correct reference selection and memory bound. Bug without it: evicting a frame still referenced → prediction from garbage → corruption. Applied: Phase 5–6 (DPB), §4.1 (DPB ≤ 16 refs), §11 Core Schema.

MM6. QP is a logarithmic quality dial: every +6 doubles the step size. Rate scales geometrically with QP, not linearly. Predicts: rate-control step behaviour. Bug without it: a linear QP→bits assumption makes rate control oscillate. Applied: Phase 12 (rate control), §4.1 (QP 0–51), ADR-16.

MM7. Entropy coding must roundtrip exactly — encode then decode is the identity. A single wrong VLC table entry desynchronizes the whole bitstream. Predicts: the I6 roundtrip invariant. Bug without it: an off-by-one in a CAVLC/CABAC table silently corrupts every subsequent symbol. Applied: Phase 7 (CAVLC), Phase 13 (CABAC), I6, ADR-12.

MM8. The in-loop deblocking filter is inside the reconstruction loop, so it is normative. Both encoder and decoder must apply identical filtering before the frame enters the DPB. Predicts: why an out-of-loop post-filter causes drift. Bug without it: filtering only on display (post-loop) → encoder and decoder DPBs diverge (MM1). Applied: Phase 10 (deblocking), I2, P3.

MM9. Decode order is a DAG, not a sequence: B-frames separate coding order from display order. Picture Order Count (display) and decode order differ when B-frames reference future frames. Predicts: correct frame reordering and output timing. Bug without it: emitting frames in decode order shows them out of sequence. Applied: Phase 9 (B-frames), §8 (POC), §11 Core Schema.

MM10. Rate-distortion is Lagrangian: minimize D + λ·R. λ, derived from QP, is the exchange rate between distortion and bits. Predicts: coherent mode decisions across block sizes. Bug without it: minimizing distortion alone yields a correct-looking but bloated bitstream. Applied: Phase 11 (RD mode decision), ADR-15, MM3.

Required reading (§5)

Recommended Reading Order

  • B1 Ch. 1–3 — H.264 overview and terminology; establishes vocabulary used throughout this document.
  • P1 (Wiegand et al. 2003) — Standard overview in 30 pages; understand all tools before implementing any.
  • S1 sec. 6–8 — Normative syntax and decoding process; read alongside the spec while implementing each phase.
  • P2 (Malvar et al.) — Read before Phase 3 (DCT) and Phase 4 (quant); contains exact butterfly constants.
  • P3 (Marpe et al.) — Read before Phase 13 (CABAC); state machine tables are required reading.
  • P4 (List et al.) — Read before Phase 12 (deblocking); boundary-strength derivation algorithm.
  • P8 + P12 (Tourapis EPZS) — Read before Phase 8 (motion estimation); candidate list construction.
  • B5 Ch. 4 (Sayood arithmetic coding) — Read before implementing vc-entropy CABAC in Phase 13; arithmetic interval model.
  • R1 (JM), R2 (x264) — Consult continuously throughout implementation for validation and tradeoff reference.

Glossary · 55 terms · site-wide glossary

4:2:0
Chroma subsampling format: one U and one V sample per 2x2 luma block. Frame carries three Planes: full-res Y, half-res U and V.
AVC
Advanced Video Coding — alternate name for H.264, ISO/IEC 14496-10 / ITU-T H.264. The normative standard for this codec.
B-frame
Bi-predictive frame (FrameType::B). Each macroblock may reference one frame from each of two lists (L0, L1), averaged or weighted. Requires DPB reordering (Phase 11).
Binary arithmetic coding
Core of CABAC: encodes each binary decision by partitioning the probability interval; renormalization emits bytes when the interval shrinks below a threshold (Phase 13).
Bit-exact decoding
Invariant I1. Decoder output is uniquely determined by the bitstream using integer-only operations; no float, no platform-specific rounding.
BitReader / BitWriter
MSB-first bit-level I/O types in vc-bitstream. Support exp-Golomb ue/se, byte-aligned reads, and emulation-prevention insertion/removal.
Block matching
Motion estimation strategy: finds the reference block minimizing SAD/SATD cost. Full search or fast pattern (diamond/EPZS) from a predicted MV start (Phase 8).
Boundary strength (BS)
Integer 0–4 per 4x4 edge, computed from MB type, MVs, coded flags. Controls deblocking filter aggressiveness (Phase 12, vc-deblock).
CABAC
Context-Adaptive Binary Arithmetic Coding. Each syntax element is binarized and each bin coded with a context-selected probability; see Phase 13. Invariant I6.
CAVLC
Context-Adaptive Variable-Length Coding. Encodes quantized residual coefficients as coeff_token + trailing_ones + levels + total_zeros + run_before VLC tables; Phase 7.
CBP (Coded Block Pattern)
Bitmask in Macroblock.cbp indicating which 4x4/8x8 transform blocks contain nonzero coefficients; avoids transmitting all-zero blocks.
Chroma
Color-difference components U (Cb) and V (Cr) after YUV conversion. In 4:2:0 they are subsampled 2x in each dimension relative to luma.
Context model
CABAC state: a probability estimate (MPS + state index) associated with a syntax element bin. Updated after each coded symbol via a lookup table.
DCT (integer)
H.264-style separable 4x4 (or 8x8) transform implemented with integer butterfly operations. Exactly invertible at defined precision; no floating point. See Phase 3, vc-transform, P3, I3.
Dead-zone
Extended quantization interval around zero in vc-quant. Coefficients inside the dead-zone are forced to zero, improving coding efficiency at the cost of slightly greater distortion.
Decoded Picture Buffer (DPB)
Dpb type. Stores reference frames for inter prediction. Manages marking (short-term/long-term/unused), list construction, and POC-based reordering. I8, Phase 11.
Deblocking filter
In-loop filter in vc-deblock applied to 4x4 block edges after reconstruction. Reduces blocking artifacts; must be applied identically in encoder and decoder (P6, I9, Phase 12).
Drift
Divergence between encoder reconstructed frames and decoder frames accumulating over a GOP. Prevented by P2 (drift-free encoder reconstruction loop) and validated by I2.
EPZS
Enhanced Predictive Zonal Search — fast motion estimation pattern starting from predicted MV, checking spatial/temporal candidates, then expanding diamond patterns. Phase 8.
Emulation prevention
0x03 byte inserted by NAL framing when output would contain 0x000001 (start code). vc-bitstream inserts on write and removes on parse. I7.
Exp-Golomb
Variable-length code family (ue: unsigned, se: signed) used in slice/MB syntax. Code: prefix (unary) + suffix (binary) for value. Implemented in BitWriter/BitReader.
Frame
Frame type: three Planes (Y, U, V), POC, FrameType. The unit of encoding/decoding.
GOP
Group of Pictures: an IDR I-frame followed by a cadence of P- and B-frames. Defines the reference structure and key-frame interval. Phase 11.
H.264
ITU-T H.264 / ISO-IEC 14496-10 AVC. The normative standard governing all syntax, transform, prediction, and entropy coding rules implemented here.
Hadamard transform
Integer transform applied to the 4x4 grid of luma DC coefficients in 16x16 intra mode, and to the 2x2 chroma DC. Improves coding of low-frequency DC energy. vc-transform.
I-frame
Intra-coded picture (FrameType::I). All macroblocks use intra prediction from decoded neighbors within the same frame. The first frame of a GOP.
IDR
Instantaneous Decoder Refresh. An I-frame that also clears the DPB; no subsequent frame references anything before the IDR.
In-loop filter
See deblocking filter. "In-loop" means it runs inside the prediction loop, modifying reference frames; distinct from a post-processing filter.
Integer DCT
See DCT (integer).
Inter prediction
Prediction of a macroblock from a previously decoded reference frame using motion-compensated block copy. Produces a residual smaller than the original block.
Intra prediction
Prediction of a macroblock from decoded spatial neighbors (left/top pixels) within the current frame. 4x4 (9 modes), 16x16 (4 modes), 8x8 chroma. P4, Phase 5.
Lambda
Rate-distortion trade-off constant. RD cost = distortion + lambda * bits. Calibrated to QP. Used for mode decision (P5, Phase 13).
Luma
The Y component of YUV, representing luminance (brightness). Full resolution in 4:2:0.
Macroblock
Macroblock type. 16x16 luma + 8x8 U + 8x8 V region. The basic coding unit: carries MB type, QP, partitions, residual blocks, CBP.
Motion compensation
Fetch of a prediction block from a reference frame at a sub-pixel position indicated by a MotionVector. Implemented in vc-inter.
Motion estimation
Search for the MV minimizing prediction error (SAD/SATD). Implemented in vc-motion with full/diamond/EPZS strategies.
Motion vector
MotionVector { x: i16, y: i16 } in quarter-pel units. Signed displacement from the current macroblock position to the reference block.
MVD
Motion Vector Difference: MV minus the median prediction of neighboring MVs. Only MVD is coded in the bitstream; the predictor is re-derived at the decoder.
NAL unit
NalUnit type. Framing unit: a 1-byte header (nal_type) + RBSP payload. Units are delimited by 0x000001 start codes in Annex B format.
P-frame
Predictive picture (FrameType::P). Macroblocks use inter prediction from L0 references or intra prediction. Phase 10.
Partition
Partition type: sub-macroblock division shape (16x16 down to 4x4) with its own MV and reference index.
Plane
Plane { data, width, height, stride }. One component buffer. Stride >= width allows padding/alignment.
POC
Picture Order Count. Display order index for a frame, used for DPB reference list construction and B-frame bi-prediction ordering.
PSNR
Peak Signal-to-Noise Ratio in dB. Quality metric: 10*log10(255^2 / MSE). Used to validate the RD curve and invariant I10.
QP
Qp(u8) in 0..51. Quantization parameter controlling step size via H.264's multiply-shift tables. Higher QP = coarser quantization = lower quality + fewer bits.
Quarter-pel
Sub-pixel precision of motion vectors (1/4 luma pixel). Half-pel via 6-tap H.264 filter; quarter-pel via bilinear averaging of half-pel positions. vc-inter, Phase 9.
RBSP
Raw Byte Sequence Payload. The logical payload of a NAL unit after emulation-prevention bytes are removed.
Rate control
Algorithm in vc-encoder adjusting QP per-frame to match a target bitrate. Basic implementation in Phase 13.
Reconstruction loop
Encoder path: dequant -> inverse DCT -> add prediction -> deblock -> store in DPB. Must match decoder exactly (P2, I2).
Residual
source block - prediction block. The signal compressed by transform + quant + entropy coding. Separation principle: P9.
SAD
Sum of Absolute Differences. Block-matching distortion metric; integer, fast. Used for motion estimation in vc-motion.
SATD
Sum of Absolute Transformed Differences. Hadamard-transformed SAD; better rate-distortion proxy than SAD for mode decisions.
Slice
A consecutive sequence of macroblocks parsed with a shared SliceHeader. Carries slice_type (I/P/B), frame_num, POC, reference list, initial QP.
Stride
Row pitch of a Plane in bytes. Stride >= width; may be rounded up for alignment. Address of sample (x,y) = data[y*stride + x].
YUV
Luma-chroma color representation. Y = luminance, U (Cb) and V (Cr) = color difference. Converted from RGB via BT.601/BT.709 matrices. vc-color.
