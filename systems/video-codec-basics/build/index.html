⬜ Phase 1 — core types + YUV color space

Objectives
  • Define the canonical type vocabulary in vc-core used by every downstream crate; no I/O, no algorithms.
  • Implement full RGB↔YUV BT.601 and BT.601/BT.709 conversion and 4:2:0 chroma subsampling in vc-color.
  • Establish raw YUV file read/write utilities for test vector injection and diffing.
  • Property-test that a roundtrip (RGB→YUV→RGB) is within rounding tolerance.
  • No float in core numeric types; conversion uses fixed-point (coefficient tables × 256 or 2^n).

  • All types usable by importing vc_core::*.

⬜ Phase 2 — bitstream I/O

Objectives
  • Build the complete bitstream serialization/deserialization substrate in vc-bitstream.
  • BitWriter: MSB-first bit-level write with byte accumulator; flush partial byte with zero-padding.
  • BitReader: MSB-first bit-level read with peeking; detect read past end.
  • Unsigned exp-Golomb (ue(v)): encode/decode non-negative integers; signed variant (se(v)) by zigzag mapping.
  • NAL unit framing: RBSP payload → emulation-prevention byte stuffing → NAL byte stream; inverse for parsing.
  • RBSP trailing bits: one 1 bit then zero-padding to byte boundary.
  • Property invariant: parse(write(x)) == x for all syntax elements.
Deliverable
  • cargo test -p vc-bitstream passes all unit and property tests.
  • vc-cli inspect subcommand can parse a NAL byte stream, enumerate NAL types and byte offsets.
  • All downstream crates import BitWriter, BitReader, ue_encode, ue_decode, se_encode, se_decode, NalUnit from vc-bitstream.

  • MVP boundary off-by-one: when MB is at left edge, neighbor A is unavailable → use (0,0), not garbage memory. Root cause: forgetting edge-availability flag. Debug: log MVP per MB; compare against JM reference.
  • CBP luma-vs-chroma bit layout: H.264 inter CBP is ue(v) with a specific 2-MSB chroma field; intra CBP is mapped VLC. Mixing tables → wrong CBP → missing residual. Signal: nonzero coeffs decoded as zero.
  • Drift from original-based prediction: if encoder predicts from original rather than reconstructed frame (violates P2), PSNR degrades sharply after 3–4 P-frames. Debug: subtract encoder recon from decoder recon; should be zero.
  • Skip-run count overflow: skip_run is ue(v); must be flushed before each coded MB. Missing flush → wrong MB addresses. Debug: count skips vs coded MBs in bitstream inspector.
