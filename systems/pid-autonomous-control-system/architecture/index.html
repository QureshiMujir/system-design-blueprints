One paragraph per box:

  • Plant model (offline). TF or state-space description of the system under control. Source of truth for synthesis and tuning. May be hand-written, fit from a step test (FOPDT), or exported from #171. Lives in ctrl-sim.
  • Auto-tune. Consumes a plant (or runs a relay experiment on the closed loop) and emits PID gains / controller params. Ziegler–Nichols and relay-feedback. ctrl-tune. Offline by default; relay can run online behind a safety supervisor.
  • Controller synthesis. Turns a plant + objective (Q/R weights, pole locations, horizon) into a concrete controller (PID config, K gain, MPC matrices). ctrl-ss/ctrl-lqr/ctrl-mpc.
  • Analysis. Computes gain/phase margins, Nyquist, root locus, step/frequency response; runs conformance vs analytic answers. Gate before deploy. ctrl-bench, ctrl-cli.
  • Feedforward. Model-based open-loop term u_ff added ahead of the summing junction; cancels known disturbance/reference dynamics so feedback only corrects residual error. ctrl-ff.
  • Summing junction. Forms error e = r − x̂ (or r − y). For 2-DOF PID, applies setpoint weighting (b·r − x̂). Conceptual; realized inside each controller.
  • Controller (PID | LQR | MPC | track). The control law. Single Controller::update(ref, meas, dt) -> u trait so the loop is law-agnostic. Pluggable.
  • Actuator saturation + rate limit. Hard nonlinearity: clamps to [u_min, u_max] and bounds |Δu|/Δt. Mandatory and always-on; its existence is why anti-windup is required. ctrl-core.
  • Plant (sim or real). Integrates ẋ = f(x,u) with RK4 at fixed Δt in sim; HIL is deferred. The boundary marked PLANT is also the trust boundary for "real world."
  • Sensors. Map state to measurements z = h(x) + noise. In sim, inject configurable noise/bias/dropout to test the estimator.
  • Estimator (Kalman / Luenberger). Reconstructs x̂ from z and the model. Structurally separate from the controller (separation principle). ctrl-kf / ctrl-lqr.
  • Real-time loop (ctrl-rt). Wraps the entire online region, ticking at fixed Δt, measuring jitter, enforcing the deadline, and driving safe-state on overrun. The double-line box is the real-time boundary.

8. Domain Model / Theory

8.1 Plant representations

  • Transfer function: G(s) = N(s)/D(s), e.g. FOPDT G(s) = K e^{−Ls} / (τ s + 1). Coeff vectors, descending powers.
  • Continuous state-space: ẋ = A x + B u, y = C x + D u. A∈ℝ^{n×n}, B∈ℝ^{n×m}, C∈ℝ^{p×n}, D∈ℝ^{p×m}.
  • Discrete state-space: x[k+1] = A_d x[k] + B_d u[k], y[k] = C x[k] + D u[k].

8.2 PID forms (all three first-class)

Form Continuous Notes
Parallel / independent u = Kp·e + Ki·∫e + Kd·de/dt Gains independent; easiest to reason about
Standard / ISA / ideal u = Kp(e + (1/Ti)∫e + Td·de/dt) Ki=Kp/Ti, Kd=Kp·Td; tuning rules target this
Series / interacting u = Kp'(1+1/(Ti's))(1+Td's)·e Classic analog; convertible to standard

Discrete PID update (default: standard form, derivative-on-measurement, filtered D, with setpoint weighting b,c):

e_p = b*r - y            // proportional error (setpoint weight b)
P   = Kp * e_p
I  += Ki * e * dt        // e = r - y ; anti-windup may modify (see 8.4)
// filtered derivative on measurement (avoid kick + noise):
d_y = (y - y_prev)/dt
D    = filter(D_prev, d_y, Kd, N, dt)   // 1st-order LP, coeff N (e.g. 8..20)
u_raw = P + I - Kd*D_filtered            // sign: derivative opposes measurement change
u     = rate_limit(saturate(u_raw))

Filtered derivative (discrete, Tustin of Kd·s/(1+s·Kd/(Kp·N))): a first-order filter with time constant Tf = Td/N.

8.3 Discretization

Method Map Pros Cons
Forward Euler s ← (z−1)/Δt cheap, explicit can destabilize (poles leave unit circle)
Backward Euler s ← (z−1)/(zΔt) always stable distorts dynamics
Tustin (bilinear) s ← (2/Δt)·(z−1)/(z+1) preserves stability, maps LHP→unit disk frequency warping
Tustin + prewarp scale 2/Δt → ω₀/tan(ω₀Δt/2) exact at ω₀ one chosen frequency only
ZOH (exact, SS) A_d=e^{AΔt}, B_d=∫₀^Δt e^{Aτ}dτ·B exact for SS under ZOH needs matrix exponential

ZOH via augmented matrix exponential: [[A,B],[0,0]]·Δt → exp → [[A_d,B_d],[0,I]]. Matrix exp by scaling-and-squaring + Padé.

8.4 Anti-windup

  • Conditional integration (clamping): freeze integration when u_raw saturated and the error would push further into saturation; otherwise integrate.
  • Back-calculation: add (u − u_raw)/Tt to the integrator input; Tt tracking time constant (rule of thumb Tt ≈ √(Ti·Td) or Ti/2…Ti). Smoothly unwinds during saturation.
  • Both bound I (invariant I2). Back-calculation gives smoother recovery; clamping is simpler/cheaper.

8.5 Controllability / Observability

  • Controllability matrix 𝒞 = [B, AB, A²B, …, A^{n−1}B]; controllable iff rank(𝒞)=n.
  • Observability matrix 𝒪 = [C; CA; CA²; …; CA^{n−1}]; observable iff rank(𝒪)=n.
  • Gramians (continuous): W_c solves A W_c + W_c Aᵀ + BBᵀ = 0; W_o solves Aᵀ W_o + W_o A + CᵀC = 0 (Lyapunov). Condition number of Gramian → degree of (un)controllability.

8.6 Pole placement (Ackermann)

K = [0 … 0 1]·𝒞⁻¹·φ_d(A), where φ_d is the desired characteristic polynomial evaluated at A. SISO; multi-input uses robust eigenstructure assignment (deferred-lite). Requires controllable pair (A,B).

8.7 LQR (Riccati)

Minimize J = ∫(xᵀQx + uᵀRu) dt, Q⪰0, R≻0. Optimal u=−Kx, K=R⁻¹BᵀP, P solves continuous ARE: AᵀP + PA − PBR⁻¹BᵀP + Q = 0. Discrete (DARE): P = AᵀPA − AᵀPB(R+BᵀPB)⁻¹BᵀPA + Q, K=(R+BᵀPB)⁻¹BᵀPA. Solve via Hamiltonian eigen / Schur, or iterate the DARE.

8.8 Luenberger observer + duality

x̂̇ = A x̂ + B u + L(y − C x̂); error ė = (A−LC)e. Choose L so A−LC stable & faster than plant. Duality: designing L for (A,C) ≡ pole placement for (Aᵀ,Cᵀ), so Lᵀ = K of the dual.

8.9 Kalman filter (link #285)

Discrete predict/update; process noise Q_k, measurement noise R_k:

predict:  x̂⁻ = A x̂ + B u ;        P⁻ = A P Aᵀ + Q_k
update:   S  = C P⁻ Cᵀ + R_k ;     K = P⁻ Cᵀ S⁻¹
          x̂  = x̂⁻ + K(z − C x̂⁻) ;  P = (I − K C) P⁻   // Joseph form for PSD safety

Joseph form P=(I−KC)P⁻(I−KC)ᵀ + K R_k Kᵀ preserves symmetry/PSD. LQG = LQR gain K ⊕ Kalman gain (separation principle).

8.10 Linear MPC

  • Prediction model: stack x[k+1]=A_d x+B_d u over horizon N → X = Φ x₀ + Γ U.
  • Cost: J = Σ_{i=0}^{N−1}(xᵢᵀQxᵢ + uᵢᵀRuᵢ) + x_NᵀP_f x_N.
  • Condensed QP (eliminate states): min_U ½ Uᵀ H U + (x₀ᵀ Fᵀ) U s.t. A_c U ≤ b_c (box/rate/output constraints).
  • Receding horizon: solve, apply u₀, shift, re-solve next tick. Warm-start U from previous solution.
  • Terminal cost P_f = DARE solution → nominal stability + recursive feasibility (with terminal set).

8.11 Path following

  • Pure pursuit: pick lookahead point at distance L_d on the path; steering δ = atan2(2·Wheelbase·sin(α), L_d), α = angle to lookahead. L_d = k_v·v + L_d0.
  • Stanley: δ = θ_e + atan2(k·e_fa, v + k_s), where θ_e heading error, e_fa front-axle cross-track error, k cross-track gain, k_s softening at low speed.

8.12 Worked example — step response of standard PID on FOPDT

Plant G(s)=2 e^{−0.5s}/(3s+1). ZN open-loop (reaction curve) → Kp≈1.2·τ/(K·L)=1.2·3/(2·0.5)=3.6, Ti=2L=1.0, Td=0.5L=0.25. Closed-loop step: rises, ~10–20 % overshoot, settles ~6–8 s, zero steady-state error (integral). Refined (lower Kp, larger Ti) → ≤5 % overshoot, longer settle. Conformance fixture stores expected y[k] ± tol.

        ▲                                    ▲                                      │ y_inner          │
        │                                    └──────────────── y_inner ─────────────┘                  │
        └───────────────────────────────────────────── y_outer ───────────────────────────────────────┘
 Inner loop must be ~5–10× faster than outer. Inner rejects fast disturbances; outer sets inner's setpoint.

8.14 One control tick (sequence)

tick(k):
  1. wait for fixed-step deadline; record wake_jitter
  2. sample sensors -> z[k]            (sim: y + noise)
  3. estimator.update(u[k-1], z[k]) -> x̂[k]      (Kalman/Luenberger)
  4. r[k] = reference(k)               (or trajectory point)
  5. u_ff = feedforward(r[k])          (optional)
  6. u_raw = controller.update(r[k], x̂[k], dt) + u_ff
  7. u[k] = rate_limit(saturate(u_raw)); anti-windup feedback (u[k]-u_raw)
  8. assert is_finite(u[k]); enforce I1
  9. apply u[k] to plant/actuator
 10. record tick_compute_us; check deadline (I3); telemetry

8.15 Degenerate / failure cases

Case Symptom Handling
Uncontrollable (A,B) rank(𝒞)<n; Ackermann singular reject design, diagnostic listing uncontrollable modes
Unobservable (A,C) rank(𝒪)<n; observer modes don't converge reject; suggest sensor placement
Actuator saturation u_raw≠u; tracking degrades clamp + anti-windup (I1,I2)
Integral windup overshoot after long saturation back-calc/clamp (I2)
Sampling too slow sampled poles leave unit circle; oscillation I12 check; increase rate or slow design
Ill-conditioned ARE/R≈0 huge gains, numerical blowup regularize R, condition-number guard
QP infeasible constraints conflict soft-constrain, fallback to last feasible (I10)
Malformed plant (NaN coeff, negative R) parse/validate error reject at load with typed error

Design principles (§6)

  • Determinism over convenience. Fixed-step Δt; no wall-clock-dependent branches in the law; reproducible given inputs+seed. Tradeoff: less adaptive to host scheduling slop. Operational: enables replay-debugging of any incident. Violation: non-reproducible bugs, untestable controllers, drift between sim and field.
  • Anti-windup is mandatory whenever actuators saturate. Any integrating term must be guarded (clamping or back-calculation) the instant u_raw ≠ u. Tradeoff: slightly more state + a tuning constant Tt. Operational: prevents the classic "integrator charges during saturation, then huge overshoot." Violation: lockout, limit cycling, dangerous overshoot on recovery.
  • Bounded output, always. Every controller output passes saturation + rate limit before reaching an actuator. Tradeoff: introduces a nonlinearity the linear analysis ignores. Operational: physical safety, actuator protection. Violation: actuator damage, model invalidity, instability from rate-limit-induced phase lag.
  • Discretize correctly. Default Tustin (bilinear); ZOH for exact state-space; forward Euler only where speed dominates and Δt≪dynamics. Tradeoff: Tustin warps frequencies (mitigate with prewarping); ZOH costs a matrix exponential. Operational: preserves stability margins designed in continuous time. Violation: a stable continuous design goes unstable when sampled (Euler maps LHP poles outside the unit circle for large Δt).
  • Estimator/controller separation (separation principle). Design K (control) and L/Kalman gain (estimation) independently; compose for LQG. Tradeoff: optimal only for LQG/linear-Gaussian; heuristic otherwise. Operational: modular tuning, swappable estimator. Violation: tangled code, no clean place to inject a better state estimate (#285).
  • Bumpless transfer on every mode/gain change. Switching controllers, retuning, or manual↔auto must not step the output. Pre-load integral/state to match current u. Tradeoff: extra state bookkeeping. Operational: safe online retuning, gain scheduling. Violation: output jump → actuator slam, disturbance, possible instability.
  • Stability is proven, not assumed. Every shipped design carries computed poles/margins; MPC carries feasibility + (where used) terminal ingredients. Tradeoff: analysis cost per design. Operational: the deploy gate. Violation: "worked on my plant" fielded controllers that oscillate.
  • The real-time deadline is a hard invariant. Per-tick compute ≤ budget; overrun triggers a defined safe-state, never a silent skip. Tradeoff: must bound worst-case (esp. MPC QP iterations). Operational: predictable failure, not cascading lag. Violation: loop falls behind, derivative/integral terms see wrong Δt, divergence.
  • Units and frames are explicit. Every signal carries documented units + frame (SI internally; conversions at the boundary). Tradeoff: boilerplate. Operational: prevents Mars-Climate-Orbiter-class errors. Violation: silent gain errors of 10×/57.3× (deg/rad).
  • Observability/controllability checked before design. Compute ranks/Gramians before pole placement / LQR / observer. Tradeoff: upfront linear-algebra. Operational: fail fast with a clear diagnostic. Violation: Ackermann/ARE produce garbage gains for uncontrollable modes; observer never converges on unobservable states.
  • Allocation-free hot loop. Zero heap in update()/tick; all buffers preallocated, sized by const generics. Tradeoff: fixed maxima for n,N. Operational: no_std/embedded-ready, no malloc jitter. Violation: unbounded latency, embedded targets can't run it.
  • Derivative on measurement, filtered. Differentiate −x̂ not e; always low-pass the derivative (N filter coefficient). Tradeoff: filter adds phase lag. Operational: avoids "derivative kick" on setpoint steps and noise amplification. Violation: huge transient spikes on setpoint change; noise-driven actuator chatter.
  • Fail to a defined safe state. Every failure path (NaN, overrun, infeasible QP, sensor dropout) maps to an explicit safe output (hold last good / ramp to safe / handoff). Tradeoff: must define "safe" per application. Operational: graceful degradation. Violation: NaN propagates to actuator; undefined behavior in the field.
  • Numeric robustness first. Guard divisions, clamp before exp, use stable decompositions (Cholesky/QR), detect non-finite every tick. Tradeoff: a few extra cycles. Operational: survives ill-conditioned plants. Violation: NaN/Inf silently produced and applied.
  • One controller interface. All laws implement Controller::update(ref, meas, dt) -> u; the loop and tooling are law-agnostic. Tradeoff: lowest-common-denominator signature; richer config via the constructor. Operational: swap PID↔LQR↔MPC without touching the loop. Violation: bespoke wiring per law, untestable in a uniform harness.
