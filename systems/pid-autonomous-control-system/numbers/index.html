Back-of-Envelope Capacity Model

The numbers an expert computes from §4 (System Constraints) before designing. Each is derived step-by-step; the §4 input is named and the formula shown.

  • C1 — Per-tick PID compute headroom at 1 kHz. Input: §4 "loop rate default sim 1 kHz", "per-tick budget ≤ 50 % of Δt", "PID tick ≤ 5 µs". Δt = 1/1000 Hz = 1 ms = 1000 µs; budget = 0.5 × 1000 = 500 µs; headroom ratio = 500 / 5 = 100× above PID alone. The 495 µs of slack is what an estimator + MPC consume in a complex controller — PID alone barely touches the budget.
  • C2 — Per-tick LQR / state-feedback compute at 1 kHz. Input: §4 "LQR ≤ 10 µs", "n ≤ 32 dense". Take n = 16, m = 4. State-feedback tick = K·x̂ = m×n matvec = 4×16 = 64 FP multiplies ≈ 0.3 µs at 200 MFLOPS (Cortex-M7+FPU); the observer update dominates at ≈ n² = 256 ops ≈ 1.3 µs. Total ≈ 1.6 µs ≪ 10 µs budget.
  • C3 — Full Kalman tick cost vs the 20 µs budget. Input: §4 "Kalman ≤ 20 µs", "n ≤ 32". Dominant term P⁻ = A P Aᵀ + Q is two n×n×n products = 2n³. At n = 8: 2×512 = 1024 ops ÷ 200×10⁶ ≈ 5 µs (within 20 µs). At n = 16: 2×4096 = 8192 ops ≈ 41 µs — exceeds budget, so use the steady-state gain (reduces to a matvec ≈ n² = 256 ops ≈ 1.3 µs).
  • C4 — MPC condensed QP dimension vs horizon. Input: §4 "decision vars N·m ≤ 200", "condensed QP ≤ 200×200". Decision vars D = N·m; at N = 20, m = 2 → D = 40. Condensed H is D×D = 40×40 = 1600 f64 = 12.8 KB (fits L1/L2). At the ceiling D = 200: H = 200×200 = 40 000 f64 = 320 KB — borderline for cache, ADMM iteration still viable.
  • C5 — ADMM QP solve budget per tick at 1 kHz. Input: §4 "QP solve ≤ 200 µs warm-started", "budget ≤ 50 % of Δt". QP fraction = 200/1000 = 20 % of a 1 ms tick. Remaining after QP for the rest of the loop = 500 µs (budget) − 200 µs (QP) − 20 µs (Kalman n=8) − 5 µs (bookkeeping) = 275 µs margin — confirms MPC + estimator co-reside at 1 kHz.
  • C6 — Worst-case MPC iteration count from the deadline. Input: §4 "QP ≤ 200 µs" and C4's D = 40. One ADMM iteration ≈ 2D² = 2×1600 = 3200 ops ≈ 16 µs. Deadline-safe cap = floor(200/16) = 12 iterations. Warm-started steady-state ADMM converges in 3–8 iterations for well-conditioned problems, so the cap is a safe margin (MM8, ADR-6).
  • C7 — Kalman steady-state working memory. Input: §4 "n ≤ 32", "per-controller static footprint documented". Steady-state gain K = P∞ Cᵀ S⁻¹ is n×p; at n = 8, p = 4: 32 f64 = 256 B. P is n×n = 64 f64 = 512 B; Q + R = n² + p² = 64+16 = 80 f64 = 640 B; with x̂ (n = 64 B) the total per instance ≈ 1.5 KB — fits SRAM.
  • C8 — Hot-loop static footprint for PID. Input: §4 "memory ceiling: hot loop allocation = 0 bytes; buffers preallocated". PidController carries integral + deriv-filter state + y_prev + last_u = 4×8 = 32 B; PidConfig ≈ 10 Scalar fields ×8 = 80 B; per instance ≈ 112 B. Ten simultaneous PID loops ≈ 1.1 KB SRAM — negligible against any MCU budget.
  • C9 — LQG combined footprint. Input: §4 per-controller footprint + C7. For n=8, m=2, p=4: Kalman ≈ 1.5 KB (C7) + LQR K (m×n = 16 f64 = 128 B) + StateFeedback last_u (16 B) → combined LQG ≈ 1.7 KB per instance.
  • C10 — MPC footprint at N=20, m=2, n=4. Input: §4 "all working buffers preallocated", "0 bytes hot-loop allocation", C4. H = (N·m)² = 40² = 1600 f64 = 12.8 KB; constraint matrix A_c (box + rate + slack rows ≈ 3·N·m × N·m = 3×40×40 = 4800 f64 = 38.4 KB); warm-start U = N·m = 40 f64 = 320 B. Total ≈ 51 KB, all preallocated static.
  • C11 — Jitter budget for derivative-term accuracy. Input: §4 "p99 wake jitter ≤ 5 % of Δt" and I3. At 1 kHz, 5 % of 1 ms = 50 µs. D = Kd·(y − y_prev)/Δt_actual; a ±50 µs error on 1 ms is a 50/1000 = 5 % Δt error. A derivative filter N=10 attenuates it to ≈ 5 %/10 = 0.5 % — which is why the 5 % jitter target is the right floor, not arbitrary.
  • C12 — Path-tracking lookahead geometry. Input: §4 "loop rate 50–100 Hz vehicle" and §8.11 lookahead law L_d = k_v·v + L_d0. At v = 10 m/s, L_d0 = 2 m, k_v = 0.5 s → L_d = 7 m. For a 0.5 m cross-track: α ≈ atan2(0.5, 7) ≈ 4.1°, Wheelbase = 2.7 m, δ ≈ atan2(2×2.7×sin 4.1°, 7) ≈ atan2(0.385, 7) ≈ 3.1° — small-angle, linear regime, validating the ≤0.1 m steady-state conformance target (§11.4).
