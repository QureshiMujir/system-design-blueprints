30. Mental Models & First Principles

  1. MM1 — A DeliveryRule is a pure function of time, not a task. Predicts the evaluator can re-run identically decades later. Bug class without it: hidden mutable state causing non-reproducible delivery decisions. Applies in §8, §12.
  2. MM2 — Encryption is a boundary, not a feature. Predicts exactly one component (Vault Service) ever holds plaintext, and only transiently. Bug class without it: plaintext leaking into logs, audit entries, or backups. Applies in §13, §7.
  3. MM3 — A schedule is a promise with a wake mechanism, not a data record. Predicts the scheduler must survive its own crash and reconstruct itself from the source of truth (the Message table), not trust its own queue. Bug class without it: silent permanent delivery loss on infrastructure failure. Applies in §14, §7.
  4. MM4 — Identity degrades monotonically with time; verification must deepen, not stay fixed. Predicts a ladder that adds rungs as horizon lengthens. Bug class without it: false confidence in a 5-year-old email address 40 years later. Applies in §15, §20.
  5. MM5 — A secret split N ways is only as available as the least-reliable quorum-required subset. Predicts that choosing quorum 3-of-5 trades single-custodian risk for multi-custodian coordination risk. Bug class without it: a cryptographically sound escrow scheme that's operationally undeliverable when custodians go dark. Applies in §21.
  6. MM6 — An AI Echo is a retrieval system wearing a conversational interface, not a person. Predicts that dignity failures come from treating it as more than grounded retrieval. Bug class without it: ungrounded generation fabricating the subject's opinions. Applies in §17, §18.
  7. MM7 — Append-only is a hash chain's whole security model. Predicts that any mutation capability, even for "cleanup," defeats forensic value. Bug class without it: an audit log that "just this once" allows an update, permanently voiding its evidentiary value. Applies in §22, §7.
  8. MM8 — Durability is a property of the redundancy graph, not of any single component. Predicts that the actual durability number is a function of how independent the failure domains of the S3/Glacier/escrow copies are, not the advertised durability of any one. Applies in §29, §32.

Reference Implementations

  • FiloSottile/age (github.com/FiloSottile/age). Study age/plugin recipient-wrapping format. Lesson: minimal, auditable wrapped-key file format. Pitfall: its single-recipient assumption doesn't generalize — do not copy for multi-custodian escrow. Applied in §13.
  • hashicorp/vault (github.com/hashicorp/vault). Study the shamir/ package and vault/seal_* auto-unseal. Lesson: threshold-unsealing operational pattern. Pitfall: do not copy Vault's dynamic-secrets scope creep — Echoes' escrow is a narrow, rarely-exercised path. Applied in §21.
  • signalapp/Signal-Server (github.com/signalapp/Signal-Server). Study the device-linking / safety-number verification flow. Lesson: identity-continuity-across-device-change pattern. Pitfall: do not copy its assumption of a single, live, responsive user. Applied in §15, §20.
  • taskforcesh/bullmq (github.com/taskforcesh/bullmq). Study src/classes/ delayed-job sorted-set scheduling. Lesson: Redis sorted-set delay model matches dispatch-at-time semantics directly. Pitfall: default at-least-once delivery still needs an explicit idempotency key layered on top. Applied in §14.
  • google/trillian (github.com/google/trillian). Study the append-only Merkle log backing Certificate Transparency. Lesson: signed-tree-head pattern for tamper-evident public logs. Pitfall: do not copy CT's multi-CA trust federation wholesale — Echoes has a single operator. Applied in §19.
  • superfly/litefs (github.com/superfly/litefs). Study LTX-based SQLite replication. Lesson: lightweight durable replication relevant to the deferred on-prem institutional variant. Pitfall: assumes a single-writer primary, a different topology from §13's multi-region write path — study only for the on-prem case. Applied in §21.

Glossary (§36) · 51 terms · site-wide glossary

Activation Condition
a DeliveryRule determining when an AI Echo becomes available to recipients (e.g. onDeathOf(self)).
AI Echo
a respectful AI reconstruction of a consenting subject, trained on their own corpus, available to authorised recipients under the subject's policy.
Audit Envelope
the append-only, hash-chained metadata record produced for every state transition; never contains plaintext.
Backpressure
slowing dispatch under load rather than dropping jobs (P12).
Bankruptcy-Remote Storage
storage contracts held by a foundation, not the operating company, so company insolvency does not orphan stored obligations.
Compound Rule
a DeliveryRule combining sub-rules via all-of/any-of, max depth 3.
Conformance Suite
the mandatory test pack every release of the Echoes core must pass.
Content Digest
the SHA-256 hash verifying ciphertext integrity at read time.
Continuity Charter
the public legal document binding the foundation to deliver outstanding messages.
Custodian
an independent institutional partner holding a key shard for a generational vault.
DEK
Data Encryption Key; the per-message symmetric key encrypting the message body.
Dedupe Key
the (messageId, scheduledAt) key enforcing at-most-once dispatch (I3).
Delivery Engine
the scheduler + queue + dispatcher waking messages at the appointed moment.
Delivery Rule
a declarative condition determining when a message becomes deliverable.
DID
Decentralized Identifier; a self-sovereign identity primitive used from Phase 8.
Dispatch Window
the period (T-24h to scheduledAt) during which a message may no longer be edited, only withdrawn.
Edit Window
the period before the dispatch window during which a draft is freely editable.
Embedding
a vector representation of a corpus chunk used for retrieval (§17).
Endowment
the capital pool funded by generational-account prepayments, invested to cover 100-year storage and operations.
Escrow Shard
one Shamir-split fragment of a generational vault's key.
Evidence Packet
the signed record of a recipient-verification attempt.
Fine-Tune (Echo)
an optional, opt-in model adaptation above a corpus-size threshold; never the default Echo mode.
Generational Account
a 100-year prepaid vault with multi-custodian escrow and will integration.
Hash Chain
the tamper-evident linkage of each audit entry to its predecessor (I6).
Holding State
a message that reached its scheduled time but failed recipient verification; awaits the fallback ladder.
Identity Ladder
the layered verification stack (email → passkey → DID → trustee → KYC → will) that deepens with elapsed time.
Identity Service
the service owning the verification ladder and evidence packets.
Idempotency Key
a value ensuring a retried operation has no additional effect.
KEK
Key Encryption Key; the KMS-managed key wrapping DEKs.
KMS Envelope Encryption
the pattern of wrapping a data key with a key-management-service key rather than encrypting data directly with the KMS key.
Merkle Tree
the hash-tree structure underlying tamper-evident logs (§19).
pgvector
the Postgres extension storing AI Echo embeddings (Phase 2–8).
Public Time Vault
a curated, time-locked, civilizationally minded archive of public Echoes.
Provenance Signing
cryptographically anchoring a public entry's hash to an append-only transparency log.
Quiet Period
the 30-day window after a death assertion before any post-mortem release.
Quorum
the minimum number of escrow shards (3 of 5) required to reconstruct a generational key.
RAG
Retrieval-Augmented Generation; grounding AI Echo replies in retrieved corpus passages.
Reconciliation Sweep
the scheduled job reconstructing Delivery Engine state from the Message table (I11).
Refusal Policy
the topics/modes an AI Echo will not engage with, declared by the subject.
RUFADAA
Revised Uniform Fiduciary Access to Digital Assets Act, governing US fiduciary access to digital accounts.
Schema Version
the explicit compatibility tag on every persisted record (I10).
Shamir Secret Sharing
the threshold-cryptography scheme splitting a key into N shards requiring a quorum to reconstruct (ADR-21).
State Transition
a recorded change in a Message's lifecycle state (§8.6).
TAI
International Atomic Time; the canonical clock's monotonic root (ADR-22).
Tombstone
the audit-logged record of a withdrawn message whose plaintext is unrecoverable (I12).
Transparency Log
the append-only, publicly auditable log anchoring public-vault provenance.
Trustee
a person designated with defined post-mortem authority over a vault.
Vault
a user's encrypted container holding messages, attachments, and AI Echo corpus.
VDPW
Verified Deliveries Per Week; the north-star metric.
Watermark (Audio)
the deliberately detectable signal embedded in synthesized Echo voice output (I13, P10).
WebAuthn / Passkey
the W3C-standardized public-key authentication primitive used as the primary identity-ladder rung.
