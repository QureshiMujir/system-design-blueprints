Alternative Architectures (Roads Not Taken)

Four fundamentally different approaches to the same goal — transmitting inner life between minds. Each: a sketch, the regime where it wins, the real system/program that embodies it, and why this blueprint rejects it as Communion (several survive as components or precedents).

ALT-1 — Behavioral approximation only (the Mirror / LLM; no substrate).

   Person A                          construction                         Person B
   ┌──────────┐   biography, voice,   ┌────────────────────┐   rendered    ┌──────────┐
   │ inner    │── somatic, biometric ─▶│ deep first-person  │── persona ───▶│ inhabits │
   │ life     │      inputs           │ MODEL of A          │   of A        │ a MODEL  │
   └──────────┘                       └────────────────────┘               └────┬─────┘
        ▲                              (narrative + affect;                      │
        │            NO qualia path · NO neural coupling · NO mutual entry       │
        └───────────────────  B's actual inner life never reaches A  ◀──────────┘

Regime where it wins: reachable now; safe-by-construction against the physical risks of neural coupling; the only viable path this century for grief, biography, and cross-cultural understanding at the narrative layer. Embodied by: today's LLM-based companion and persona systems, and this portfolio's #408 The Mirror. Why rejected as Communion: it transmits narrative, not qualia (§8), and it is unilateral — B inhabits a model of A while A receives nothing, breaking bidirectionality (§6 P7). It is explicitly the approximation (Candidate C, §3), and selling it as Communion is Threat T12. Cost / buys: costs nothing in physical risk and buys reachable-now narrative transfer; cannot buy the first-person inhabiting of §1. Retained: as Phase 4's honest, fully-protocolled approximation — practice, never the real thing (Appendix AT).

ALT-2 — Direct neural bridging (BCI ↔ BCI, no AI translation layer).

   Brain A                                                            Brain B
   ┌────────┐   [invasive          raw neural signal       invasive]   ┌────────┐
   │ neural │── electrode ──▶═══════════════════════════▶── electrode ─▶│ neural │
   │ state  │   array ]        (no translation layer;        array ]    │ state  │
   └────────┘   ◀──────────════ assumes A's code = B's code ════──────  └────────┘
                    bidirectional, highest bandwidth, least mediated
                    RISK: signal that is a quale in A may be noise in B  (no C4 envelope)

Regime where it wins: if two nervous systems were sufficiently similar that signals transfer without translation, this is the highest-fidelity path and the least mediated. Embodied by: invasive intracortical BCI programs such as BrainGate, which demonstrate real (one-way, device-control) high-bandwidth interfacing. Why rejected as the sole architecture: §8's translation problem — non-identical nervous systems make raw bridging lossy and unbounded, violating C4 (modelled, disclosed envelope); and invasive coupling carries the highest physical-safety risk (§3 Candidate A). Cost / buys: costs the highest physical risk and a hard biology gate; buys maximal bandwidth and least mediation if (and only if) the signal-compatibility assumption holds. Retained: as the coupling layer of Candidate D (Hybrid), paired with an AI translation layer and biotech safety windows.

ALT-3 — Symbolic / linguistic enhancement (a shared constructed language).

   Person A                       the bridge that already exists           Person B
   ┌────────┐   encode    ┌──────────────────────────────────────┐  decode   ┌────────┐
   │ inner  │── into ────▶│ rich constructed language / shared    │── into ──▶│ A MODEL│
   │ state  │   symbols   │ symbolic protocol (third-person code)  │  meaning  │ of A's │
   └────────┘             └──────────────────────────────────────┘           │ words  │
                          deepen language — never bypass it.                  └────────┘
                          The walls between minds stay up; the messages get richer.

Regime where it wins: fully consensual, fully reversible, zero physical risk, and buildable with no neuroscience breakthrough; it strengthens the bridge humans already have. Embodied by: real constructed-language projects (the tradition of engineered languages built to expand expressible thought). Why rejected as Communion: §2's founding premise is that language is the terrible bridge Communion replaces — a better code is still a code, still third-person, and never delivers the first-person inhabiting of §1. Cost / buys: costs no breakthrough and no risk; buys richer description but never the thing described — the gap between knowing-about and being remains. Retained: as part of the consent ceremony's "legible, plain-language" exchange (Appendix AA) and first-person literacy (The Mirror), not as a transmission substrate.

ALT-4 — The null architecture (refuse to build).

        the preconditions (built)                      the centre (kept empty)
   ┌───────────────────────────────────┐        ┌───────────────────────────────┐
   │ sovereignty · consent · provenance │        │                               │
   │ reversibility · council · treaties │──────▶ │   [ no substrate deployed ]   │
   │ counsels · endowment · refusal-log │ guards │   capability held, unused     │
   └───────────────────────────────────┘        └───────────────────────────────┘
                 │                                              │
                 ▼                                              ▼
         civilization made READY                  "not yet — perhaps not ever":
         (so the choice is real)                   an honourable terminal state

Regime where it wins: whenever readiness is unmet — which §6 (P4) and Kill Criteria hold may be permanent in this generation. If the science arrives before the civilization is ready, this is the correct architecture. Embodied by: the Asilomar (1975) self-imposed moratorium precedent — practitioners choosing not to proceed until containment was agreed. Why "rejected" only conditionally: it is not rejected at all — it is the document's default (P12, ADR-20) and its honourable terminal state (Kill Criteria; MM10). It is listed here because it is a genuine, complete architecture for the goal: a civilization that can Commune but chooses, with discipline and record, not to. Cost / buys: costs the capability's benefits indefinitely; buys the certainty of doing no civilizational harm — the only architecture that is safe by construction. The whole blueprint is the scaffolding that makes this null architecture a choice rather than mere inability.

The four roads, side by side. Across the dimensions that decide whether something is Communion (§6, §7):

Transmits qualia (§8) no — narrative only potentially, if signals translate no — third-person n/a

Why this blueprint's path is none of these alone, and all of them in sequence. The chosen trajectory uses ALT-1 (approximation) as honest practice (Phase 4–5), holds ALT-2 (neural bridging) as one layer of the Hybrid (Candidate D, §3) rather than a standalone, keeps ALT-3 (richer language) inside the consent ceremony rather than as a substrate, and treats ALT-4 (refusal) as the default and the honourable terminal state. The single thread joining them is that bidirectionality, ephemerality, reversibility, plurality, and consent (§6, §7) are required of any path that may bear the name Communion — and that an architecture which cannot meet them is not a lesser Communion but a different, named thing. The decision space is therefore not "which substrate" but "which substrate, under which contract, deployed when — or not at all."

Steward's synthesis — the whole design space in one decision. Pulling the five preceding sections together, the council at any review is really deciding a single question along four axes, each anchored in this document:

  • Which road? — ALT-1/2/3/4 above; in practice a Hybrid (Candidate D, §3) with refusal (ALT-4) as the standing default.
  • Under which contract? — the conjunctive C1–C12 (§7); 11/12 is 0/12 (BEC12). The contract is fixed; the substrate is variable.
  • Governed how? — the four-regime synthesis (Comparative Architecture): independent consent authority + self-imposed restraint + trustless verification + per-participant caution, all at once.
  • Deployed when — or not at all? — gated by the capacity floors (BEC-X2: ~25–30 yr minimum) and the readiness indicators (Operational Readiness), with "not yet, perhaps not ever" (MM10) a valid answer.

The models (MM1–MM10) are what let a steward answer all four under a situation the rules did not foresee; the numbers (BEC1–BEC12) are what keep the answer honest about cost and time; the precedents (§5, Comparative Architecture) are what keep it tethered to what humanity has actually learned about governing dangerous capabilities. That triad — models, numbers, precedents — is the mastery this document is built to confer (§2, What Mastery Looks Like).
