⬜ Phase 1 — Core containers + norms + errors

Objectives

Define Scalar, Vector, row-major DenseMatrix, vector/matrix norms (L1/L2/L∞), BLAS-1 helpers (axpy, dot), tolerance conventions, and the typed error hierarchy. The substrate every solver builds on.

Deliverable

nm-core importable; norms + BLAS-1 validated; cargo test -p nm-core green.

Acceptance
  • Norms match hand calculations to within 1e-14 relative error (core/norms.json); dot/axpy correct on test vectors to the same tolerance (core/blas1.json).
  • Dimension mismatch → DimensionMismatch (not panic), 100% of mismatched-shape test cases.
  • Non-finite detection raises NonFinite (I12) on 100% of NaN/Inf test inputs (core/finite_guard.json).
Fixtures
Fixture Purpose Expected
core/norms.json norm correctness exact
core/blas1.json axpy/dot exact
core/finite_guard.json I12 NonFinite on NaN
Pitfalls
  • L2 norm overflow for large vectors; scale by max (hypot-style) where needed.
  • Row-major vs column-major confusion in DenseMatrix indexing propagates everywhere.

⬜ Phase 2 — Dense direct linear algebra

Objectives

Implement dense LU (partial pivoting), Cholesky (SPD), QR (Householder), forward/back substitution, and the tridiagonal Thomas solver (O(n)) — the direct-solve foundation and 1-D fast path.

Deliverable

Solve dense Ax=b (LU), SPD systems (Cholesky), tridiagonal systems (Thomas); QR factorization; condition estimate.

Acceptance
  • LU/Cholesky/Thomas solve test systems to 1e-10 residual.
  • Cholesky on non-SPD → NotSpd (I2).
  • Thomas matches LU on tridiagonal systems but O(n).
  • QR: A=QR, Q orthogonal (QᵀQ=I) to 1e-10.
Fixtures
Fixture Purpose Expected
linalg/lu_solve.json direct solve residual 1e-10
linalg/cholesky_spd.json SPD path factor + NotSpd reject
linalg/thomas.json tridiagonal matches LU, O(n)
linalg/qr_orthogonal.json QR QᵀQ=I
Pitfalls
  • LU without pivoting fails on zero pivots; partial pivoting is mandatory.
  • Cholesky on a matrix that is symmetric but indefinite produces sqrt of negative → catch and report NotSpd.
  • Thomas is unstable without diagonal dominance; document the assumption.

⬜ Phase 3 — Sparse storage + SpMV + assembly

Objectives

Implement CSR/CSC/COO formats, the SpMV kernel (the hot path for iterative solvers, P3), triplet→CSR assembly, and pattern utilities (symmetry, bandwidth). Enables representing large discretized operators.

Deliverable

Assemble sparse matrices from triplets; SpMV correct + parallel; symmetry detection for solver routing (P4).

Acceptance
  • COO→CSR correct (duplicates summed, sorted columns) vs dense reference.
  • SpMV matches dense matvec to 1e-12; parallel == serial (tol).
  • is_symmetric correct on symmetric + nonsymmetric test matrices.
Fixtures
Fixture Purpose Expected
sparse/coo_to_csr.json assembly matches dense
sparse/spmv.json kernel matches dense matvec
sparse/symmetry.json routing correct flag
Pitfalls
  • Forgetting to sum duplicate triplets (overlapping element contributions) under-assembles the matrix.
  • Unsorted CSR columns break some preconditioners (ILU); sort on build.
  • Parallel SpMV must partition rows (disjoint outputs) to avoid races.

⬜ Phase 4 — Krylov iterative solvers + preconditioners

Objectives

Implement CG (SPD), MINRES (symmetric indefinite), restarted GMRES(m) (nonsymmetric), BiCGSTAB, and preconditioners (Jacobi, SSOR, ILU(0)), with residual-based stopping + true-residual safeguard (P7, I7) and convergence monitoring (P10).

Deliverable

Solve large sparse SPD systems (CG) and nonsymmetric systems (GMRES/BiCGSTAB); preconditioners reduce iterations; reports convergence history.

Acceptance
  • CG on SPD Laplacian converges to ‖b−Ax‖/‖b‖ ≤ 1e-8 in ≤ O(√κ) iters.
  • GMRES/BiCGSTAB solve nonsymmetric advection–diffusion systems.
  • ILU(0)/SSOR reduce CG iterations vs unpreconditioned on a benchmark.
  • True residual at stop matches recurrence residual (I7); cap enforced (non-convergence → typed error, P7).
Fixtures
Fixture Purpose Expected
iter/cg_laplacian.json SPD solve converge ≤ tol
iter/gmres_nonsym.json nonsymmetric converge ≤ tol
iter/precond_speedup.json preconditioning fewer iters
iter/noncvg_cap.json P7 NonConvergence typed
Pitfalls
  • CG on a nonsymmetric or indefinite matrix silently diverges/stalls; check symmetry first (P4).
  • GMRES without restart grows memory O(iters·n); restart(m) bounds it but can stagnate.
  • Recurrence residual drifts from the true residual; recompute at stop (I7) to avoid false convergence.
  • ILU(0) breakdown (zero pivot) on some patterns; fallback to Jacobi.

⬜ Phase 5 — ODE integrators (explicit + adaptive)

Objectives

Implement explicit Euler, classical RK4, and adaptive Dormand–Prince RK45 with a PI step-size controller, dense output, and event detection. Verified to theoretical order (P1, I10).

Deliverable

Integrate test IVPs (exponential decay, harmonic oscillator, Lorenz); RK4 shows O(Δt⁴); RK45 adapts to tolerance; events detected.

Acceptance
  • RK4 convergence order ≈ 4.0 on a smooth IVP (refinement study, I1).
  • RK45 keeps estimated local error within tolerance; accepts/rejects steps correctly.
  • Energy of the harmonic oscillator is bounded over long integration (qualitative stability).
  • Event times found to specified tolerance.
Fixtures
Fixture Purpose Expected
ode/rk4_order.json I1 order ≈ 4
ode/rk45_tol.json adaptivity error ≤ tol
ode/exp_decay.json correctness matches e^{−kt}
ode/event.json event detect correct crossing time
Pitfalls
  • PI controller without min/max bounds takes a zero or runaway step on a discontinuity.
  • Embedded error estimate using the wrong order pair mis-controls the step.
  • Dense output must be consistent with the step taken (use the method's interpolant).
  • Accumulated round-off over many steps — a time variable advanced by repeated t += dt accumulates floating-point error proportional to the step count; carry time as t0 + n*dt (or compensated/Kahan summation) and store time in f64, not a truncated fixed-point register. Documented real-world precedent: the Patriot missile failure at Dhahran (25 Feb 1991), where the system clock counted time in 0.1 s increments held in a truncated register; the round-off in converting that count to floating-point time grew with uptime (≈0.34 s after ~100 h continuous operation), shifting the radar range gate enough to miss an incoming Scud (U.S. GAO report GAO/IMTEC-92-26, Feb 1992). A clean illustration of why accumulated round-off in a time accumulator is a correctness hazard, not a rounding nicety.

⬜ Phase 6 — Implicit / stiff ODE integrators

Objectives

Implement Backward Euler, Crank–Nicolson, and BDF1/2 with Newton's method for the nonlinear stage equations, giving unconditional/stiff stability (P2) for stiff systems and parabolic PDE time stepping.

Deliverable

Integrate stiff systems (e.g., Robertson, stiff linear) stably with large steps; CN shows O(Δt²); Newton converges per step.

Acceptance
  • Backward Euler/CN stable on a stiff test where explicit Euler blows up (P2).
  • CN convergence order ≈ 2.0 (I1).
  • Newton converges quadratically near the solution (residual drops fast).
  • BDF2 matches analytic on a stiff linear ODE.
Fixtures
Fixture Purpose Expected
ode/stiff_stable.json P2 BE stable where Euler fails
ode/cn_order.json I1 order ≈ 2
ode/newton_converge.json stage solve quadratic residual drop
ode/bdf2_stiff.json multistep matches analytic
Pitfalls
  • Newton with a stale/wrong Jacobian converges slowly or diverges; finite-difference Jacobian needs a good perturbation scale.
  • BDF startup (no history) must bootstrap with BDF1/RK; using full order at step 1 is wrong.
  • For large PDE systems, the per-step linear solve must use the sparse Krylov path (Phase 4), not dense.

⬜ Phase 7 — Structured grids + finite-difference operators

Objectives

Implement 1-D/2-D structured grids (uniform + stretched), ghost cells, boundary tagging, FD stencils, assembled Laplacian/gradient/divergence operators, and consistent BC application (Dirichlet/Neumann/Robin/periodic) preserving symmetry (P5, I6).

Deliverable

Assemble FD Laplacian on 1-D/2-D grids; apply all BC types; operator SPD with Dirichlet (CG-solvable).

Acceptance
  • 1-D Laplacian is tridiagonal SPD; 2-D is 5-point SPD with Dirichlet (I2), symmetry residual ‖A−Aᵀ‖∞ ≤ 1e-12 (fd/laplacian_spd.json).
  • Neumann ghost-cell gives correct flux to 1e-10 absolute; periodic wraps correctly (fd/neumann_flux.json).
  • Dirichlet elimination preserves symmetry (I6) — CG converges to ‖b−Ax‖/‖b‖ ≤ 1e-8 (fd/dirichlet_sym.json).
  • Stencil coefficients correct to O(h²) on a non-uniform grid (Taylor check, fd/stretched_stencil.json).
Fixtures
Fixture Purpose Expected
fd/laplacian_spd.json I2 symmetric, CG-solvable
fd/neumann_flux.json BC correct flux
fd/dirichlet_sym.json I6 symmetry preserved
fd/stretched_stencil.json non-uniform Taylor-correct
Pitfalls
  • Naive Dirichlet (zero the row, set diagonal 1) breaks symmetry → CG fails; eliminate column too and move to RHS (I6).
  • Neumann at corners (2-D) needs careful ghost handling.
  • Non-uniform stencil coefficients differ from uniform; using uniform coefficients on a stretched grid loses order.
  • Pure-Neumann problem has a constant nullspace (I8) — pin a node or project.

⬜ Phase 8 — Finite-difference PDEs (Poisson + heat)

Objectives

Solve steady Poisson (FD + CG) and transient heat (method of lines + θ-method) end to end, with CFL enforcement for explicit time stepping (P2, I5). First complete PDE solves.

Deliverable

Solve 1-D/2-D Poisson against MMS; solve heat equation matching the analytic decaying solution; explicit blows up above CFL, implicit stays stable.

Acceptance
  • Poisson L2 error decreases at O(h²) (I1): estimated order 2.0 ± 0.15 on MMS (§8.9, pde/poisson1d_mms.json).
  • Heat (CN) matches analytic e^{−απ²t}sin(πx) to within 1e-6 absolute at final time (§8.10, pde/heat1d_cn.json).
  • Explicit heat above the CFL bound Δt > h²/(2αd) → CflViolation or detected blow-up (I5); implicit stable at Δt 10× the explicit limit (pde/heat_cfl.json).
  • 1-D uses Thomas (O(n)); 2-D uses CG to ‖b−Ax‖/‖b‖ ≤ 1e-8.
Fixtures
Fixture Purpose Expected
pde/poisson1d_mms.json order O(h²)
pde/poisson2d_mms.json 2-D order O(h²)
pde/heat1d_cn.json transient matches analytic
pde/heat_cfl.json I5 explicit blows up / refused
Pitfalls
  • Forgetting the CFL check ships an explicit solver that randomly NaNs (P2).
  • Sign error in the Laplacian (−∇² vs ∇²) flips the problem; verify against MMS.
  • Time-dependent BCs must be re-applied each step.

⬜ Phase 9 — Mesh + finite-element assembly

Objectives

Implement unstructured meshes (1-D segments, 2-D triangles), reference elements (P1/P2), shape functions + derivatives, Gauss quadrature (exact to degree, P6/I4), element stiffness/mass, and global assembly via scatter-add (§8.7, I3).

Deliverable

Assemble global K, M, b for a 2-D triangular mesh; element matrices verified against analytic; partition of unity + quadrature exactness hold.

Acceptance
  • Shape functions sum to 1 (I3) to 1e-14; gradients sum to 0 to the same tolerance (fem/partition_unity.json).
  • Gauss quadrature integrates polynomials up to the rule's degree exactly, residual ≤ 1e-13 (I4, fem/quadrature_exact.json).
  • Element stiffness for a reference triangle matches the analytic 3×3 to 1e-12 (P1, fem/element_stiffness.json).
  • Global K is SPD with Dirichlet BCs (I2); assembly matches a dense reference on a small mesh to 1e-10 (fem/assembly_spd.json).
Fixtures
Fixture Purpose Expected
fem/partition_unity.json I3 ΣN=1, Σ∇N=0
fem/quadrature_exact.json I4 exact for degree
fem/element_stiffness.json local matches analytic
fem/assembly_spd.json global SPD, matches dense
Pitfalls
  • Mapping gradients from reference to physical element requires the inverse Jacobian; forgetting it gives wrong (mesh-size-dependent) stiffness.
  • Degenerate (zero-area) elements → detJ≤0 → MeshError.
  • Under-integration (too-low Gauss degree) can rank-deficient stiffness (P6) or lose order.
  • Scatter-add must use global node indices from connectivity; an off-by-one corrupts assembly.

⬜ Phase 10 — Finite-element PDEs (Poisson + heat)

Objectives

Solve Poisson and heat via FEM with Dirichlet/Neumann/Robin BCs (symmetric Dirichlet imposition, I6), verifying P1 → O(h²) L2 / O(h) H1 and P2 → higher order (P1/I1).

Deliverable

FEM Poisson on a 2-D mesh matching MMS at O(h²) (P1); Neumann/Robin BCs correct; FEM heat transient matches analytic.

Acceptance
  • P1 Poisson: L2 order ≈ 2, H1 order ≈ 1 (I1) under mesh refinement.
  • P2 Poisson: L2 order ≈ 3 (I1).
  • Neumann/Robin BCs verified against MMS with the matching flux.
  • FEM heat (θ-method) matches analytic decay within tolerance.
Fixtures
Fixture Purpose Expected
fem/poisson_p1_order.json I1 L2≈2, H1≈1
fem/poisson_p2_order.json I1 L2≈3
fem/neumann_mms.json BC order preserved
fem/heat_fem.json transient matches analytic
Pitfalls
  • Non-symmetric Dirichlet imposition breaks SPD → CG fails (I6); lift symmetrically.
  • Neumann BCs are natural (in the weak form) — adding them as strong constraints double-counts.
  • Consistent vs lumped mass matrix changes transient accuracy/stability (I9); document which is used.
  • Mixing P1 geometry with P2 fields (or vice versa) silently loses order.

⬜ Phase 11 — Advection, wave, nonlinear (Burgers) + stability

Objectives

Solve hyperbolic/mixed PDEs — advection (upwind), wave (2nd-order/leapfrog), advection–diffusion (GMRES), and nonlinear Burgers (Newton/Picard) — with explicit CFL enforcement and upwinding for stability (P2, I5, I11).

Deliverable

Advection transports a profile without spurious oscillation (within CFL); wave propagates correctly; Burgers forms a stable shock; advection–diffusion solved via GMRES.

Acceptance
  • Upwind advection is stable + monotone within CFL (Δt ≤ h/|a|, I5): no overshoot beyond 1e-8 above the local max (pde/advection_upwind.json); central advection oscillates once cell Péclet > 2 (demonstrated).
  • Wave equation conserves energy to within 1% over 100 periods; CFL Δt ≤ h/c enforced (I5, pde/wave_propagation.json).
  • Burgers shock matches the Cole–Hopf analytic (viscous case) to L2 error ≤ 1e-3 at the reference viscosity (pde/burgers_shock.json).
  • Advection–diffusion converges via GMRES to ‖b−Ax‖/‖b‖ ≤ 1e-8 within 200 iterations at Péclet ≤ 50 (pde/adv_diff_gmres.json).
Fixtures
Fixture Purpose Expected
pde/advection_upwind.json stability monotone within CFL
pde/wave_propagation.json hyperbolic correct speed, energy bounded
pde/burgers_shock.json nonlinear matches Cole–Hopf
pde/adv_diff_gmres.json nonsymmetric GMRES converges
Pitfalls
  • Central differencing for advection is unstable/oscillatory; upwind (or stabilized) is required (P2).
  • CFL for advection (h/|a|) differs from diffusion (h²/α); using the wrong one blows up.
  • Burgers Newton can diverge near a forming shock; Picard or line-search stabilizes.
  • High Péclet (advection-dominated) needs upwinding/SUPG or it oscillates.

⬜ Phase 12 — Verification, conformance, hardening, benchmarks

Objectives

Establish correctness via MMS + convergence-order studies for every method (P1/P8, I1), cross-check against analytic + reference (SciPy/SUNDIALS) results, fuzz spec/mesh parsing, benchmark kernels, and harden error paths.

Deliverable

Green conformance report (per-method order Pass/Deferred), clean fuzz, committed benchmarks, runbooks. Every method's order matches theory.

Acceptance
  • Estimated orders within ±0.15 of theory: central FD/P1 L2 ≈2, P2 L2 ≈3, RK4 ≈4, CN ≈2 (I1).
  • Analytic + reference comparisons within tolerance.
  • Fuzz: ≥10⁶ iterations, zero panics; malformed specs/meshes → typed errors.
  • Benchmarks within ±20% of committed baseline.
Fixtures
Fixture Purpose Expected

conf/analytic/*.json closed-form within tol
conf/reference/*.json vs SciPy/SUNDIALS within tol
fuzz/corpus/* robustness no panic

Pitfalls
  • Measuring order on too-coarse meshes (pre-asymptotic regime) gives wrong slopes; use a fine-enough refinement sequence.
  • MMS source derivation errors make a correct solver "fail"; verify f against the chosen u_exact.
  • Reference solvers use different tolerances/step controllers; compare within combined tolerance, not equality.
  • Benchmark noise from threads/turbo; pin frequency + thread count.
