ADR-01

Language

Chosen

Rust 2021, MSRV 1.78

Rejected

C, C++, Go, Zig

When the rejected choice is right

C wins targeting an 8-bit MCU with no Rust LLVM backend, or extending a DO-178C-certified C codebase

Why: Memory safety + exhaustive sum types; no GC pause on hot path

ADR-02

Core dependency posture

Chosen

Rejected

When the rejected choice is right

std everywhere wins for a short-lived research prototype not worth the no_std tax

Why: Embeddability (P4) without losing sockets ergonomics

ADR-03

TCP state representation

Chosen

Exhaustive enum TcpState

Rejected

Integer state constants, trait-object states

When the rejected choice is right

Integer constants win when FFI layout must match a foreign kernel ABI

ADR-04

Timer wheel

Chosen

Hierarchical wheel (Varghese & Lauck 1987)

Rejected

When the rejected choice is right

35. Alternative Architectures (Roads Not Taken)

AA-1 — Kernel-bypass polling (DPDK/AF_XDP).

NIC -> poll-mode driver (userspace) -> lock-free ring -> protocol stack
       (no syscalls, no interrupts, busy-polled)

Regime: > 2 Gbps single-core, sub-10 µs latency budgets. Real system: seastar (ScyllaDB's framework) + DPDK, and Linux AF_XDP. Rejected because it adds a privileged setup step (hugepages, driver unbinding) that conflicts with the unprivileged-developer-loop goal (§1); the escape hatch is the DriverShim trait (§11), which AA-1 would implement without touching any layer above (ADR-05).

AA-2 — Thread-per-connection (blocking I/O).

accept() -> spawn OS thread -> blocking read()/write() -> OS scheduler multiplexes

Regime: low connection count (<10,000), simple mental model, easy porting of blocking application code. Real system: classic BSD/Solaris socket servers, early Apache httpd (prefork/worker MPM). Rejected because it does not scale past a few thousand threads (stack memory, context-switch overhead), violating P5's determinism and M11's 100,000-connection target.

AA-3 — Full kernel-module implementation (in-kernel stack).

NIC driver -> kernel netif -> in-kernel protocol stack -> syscall boundary -> userspace socket

Regime: needs zero-copy to the page cache, needs to be the OS's actual default stack. Real system: the Linux kernel's own net/ subtree, FreeBSD's sys/netinet/. Rejected because it requires kernel-privilege deployment and kernel-ABI-stability discipline that conflicts with P4 (no_std userspace embeddability) and the "runs unprivileged on a laptop" operational invariant (§1).

AA-4 — Hardware TCP offload (TOE / smartNIC).

NIC ASIC/FPGA terminates TCP entirely -> host sees a socket-like descriptor ring only

Regime: ultra-low CPU budget at very high throughput (40 Gbps+), latency-critical trading systems. Real system: historic TOE NICs (Chelsio, early 2000s), modern smartNICs (Nvidia BlueField, AWS Nitro). Rejected because it is an opaque, unauditable state machine — violating P1's spec-faithfulness verifiability and P6's differential testing (silicon cannot be fuzzed the way Rust code can) — and vendor lock-in defeats the "read and audit in an afternoon" goal (§1).
