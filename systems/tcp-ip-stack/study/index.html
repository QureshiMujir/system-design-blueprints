31. Mental Models & First Principles

  • MM1 — A TCP connection is a state machine with an adversarial input alphabet. Predicts every transition must be defined for every possible segment, not just the happy path. Bug class without it: unhandled-state hangs/crashes against malformed peers. Applies in §8.3 and Phase 4 (§16).
  • MM2 — Sequence numbers are a clock, not a counter. Predicts wraparound at 2^32 must be handled via modular comparison, never native ordering. Bug class without it: silent data corruption after ~34 s of sustained 1 Gbps transfer. Applies in §8.4 and I1.
  • MM3 — The window is a promise about buffer space, not a request. Predicts persist- timer/probe logic must exist because a promise can go to zero. Bug class without it: permanent sender deadlock on a lost window update. Applies in §8.5, §17, and FM-5.
  • MM4 — RTT estimation is a control-system problem, not a measurement problem. Predicts naive averaging fails; smoothing constants trade responsiveness for stability. Bug class without it: RTO oscillation or spurious-retransmit storms. Applies in §18 and Design Principle P14.
  • MM5 — Congestion control is a distributed control loop with no coordination channel. Predicts oscillatory equilibrium (the cwnd sawtooth) is normal, not a bug. Bug class without it: "fixing" the sawtooth by removing multiplicative decrease breaks fairness across flows. Applies in §19 and §32.
  • MM6 — A timer wheel trades precision for O(1) amortized cost. Predicts coarse tick granularity is an intentional tradeoff. Bug class without it: assuming a timer fires at the exact requested instant. Applies in I10 and ADR-04.
  • MM7 — The network is hostile until parsed and validated. Predicts every wire field is attacker-controlled until checksum+bounds are verified. Bug class without it: trusting a length field before bounds-checking it (buffer over-read). Applies in §8.7 and T8.
  • MM8 — Zero-copy has a cost horizon. Predicts that below a payload-size threshold, copying is cheaper than zero-copy's bookkeeping (cache effects, reference tracking). Bug class without it: over-engineering zero-copy for small control segments (bare ACKs) that dominate packet count. Applies in P3 and §29.

  • Cardwell, N.; Cheng, Y.; Gunn, C. S.; Yeganeh, S. H.; Jacobson, V. "BBR: Congestion-Based Congestion Control." ACM Queue 2016 — applied in §35 (comparative note) and the Deferred Features Register (§36).

Reference Implementations

  • smoltcp (github.com/smoltcp-rs/smoltcp) — study src/socket/tcp.rs's state machine and its no_std, allocator-free design; lesson: sum-typed states scale to a full RFC 9293 machine without runtime overhead; pitfall: do not copy its single-buffer ring model wholesale — it trades flexibility for zero-allocation that this project only partially adopts (ADR-10). Applied in §11 and Phase 0 (§12).
  • lwIP (savannah.nongnu.org/projects/lwip) — study core/tcp_in.c/tcp_out.c and the pbuf chain; lesson: decades of embedded hardening encode real-world malformed-input cases worth mining for conformance fixtures (§8.7); pitfall: its raw pointer/callback style is not idiomatic Rust — port the test cases, not the architecture. Applied in §5 (Conformance Corpora) and Phase 2 (§14).
  • picotcp (github.com/tass-belgium/picotcp) — study its modular protocol registration; lesson: a clean layer-registration API keeps L3/L4 decoupled; pitfall: its academic pedigree means some paths are under-fuzzed — do not assume its correctness without an independent fixture. Applied in Phase 3 (§15).
  • Linux kernel net/ (elixir.bootlin.com/linux/latest/source/net) — study net/ipv4/tcp_input.c and tcp_output.c; lesson: the production reference for RFC 5681/6298 interaction at scale; pitfall: kernel code optimizes for in-kernel zero-copy assumptions (skb) that don't map directly to a userspace Buf — translate the algorithm, not the memory layout. Applied in Phase 6 (§18) and Phase 7 (§19).
  • FreeBSD sys/netinet/ (github.com/freebsd/freebsd-src) — study tcp_subr.c and tcp_timer.c; lesson: a cleaner, more readable reference than Linux for the timer interactions (RTO/persist/keepalive); pitfall: BSD sequence-space macros assume a specific integer-overflow behavior — verify against Rust's wrapping semantics before porting. Applied in Phase 6 (§18) and ADR-04.
  • gVisor netstack (github.com/google/gvisor/tree/master/pkg/tcpip) — study its sandboxed, Go-based contemporary design; lesson: a userspace stack can be a security boundary itself, not just a performance choice; pitfall: Go's GC changes allocation tradeoffs versus Rust — do not port its buffer-pooling numbers directly. Applied in the Comparative Architecture Table (§32).

Glossary (§37) · 46 terms · site-wide glossary

ACK
acknowledgement flag/number confirming received bytes.
ARP
Address Resolution Protocol (RFC 826), IP-to-MAC resolution.
BDP
bandwidth-delay product, the in-flight-bytes capacity of a path.
cwnd
congestion window, the sender's loss-based transmit budget.
Delayed ACK
deferring an ACK to piggyback or coalesce, capped at 200 ms.
DHCP
Dynamic Host Configuration Protocol (RFC 2131).
ECN
Explicit Congestion Notification (RFC 3168), router-signaled congestion without a drop.
Fast recovery
RFC 5681's cwnd-halving response paired with fast retransmit.
Fast retransmit
retransmitting on the third duplicate ACK, ahead of an RTO.
FIN
the flag signaling a graceful half-close.
IRS
initial receive sequence number, the peer's ISS.
ISS
initial send sequence number, chosen per RFC 6528 (I11).
Karn's algorithm
discard RTT samples from retransmitted segments (I4).
MSL
maximum segment lifetime, 30 s by convention here.
MSS
maximum segment size, 1460 B default.
MTU
maximum transmission unit, 1500 B default (Ethernet).
Nagle's algorithm
coalescing small writes while data is unacknowledged.
ND
Neighbor Discovery (RFC 4861), IPv6's ARP analogue.
PMTUD
Path MTU Discovery, deferred (§36).
RingBuf
the pre-sized, allocation-free per-socket buffer (I9).
RST
the flag aborting a connection.
RTO
retransmission timeout, estimated per RFC 6298.
RTT
round-trip time.
RTTVAR
RTT variance, RFC 6298's smoothed deviation estimate.
RouteTable
the longest-prefix-match trie for outbound routing.
RSA(not used)
(intentionally omitted; not part of this stack's scope).
SACK
Selective Acknowledgement (RFC 2018), naming non-contiguous received ranges.
SlabRef
an index into the pre-allocated buffer slab (ADR-10).
Slow start
cwnd growth by 1 MSS/ACK until ssthresh.
SLAAC
Stateless Address Autoconfiguration (IPv6).
ssthresh
slow-start threshold, the boundary between slow start and congestion avoidance.
SYN
the flag initiating a connection.
SYN cookie
a stateless SYN-flood defense, deferred (§36).
Tcb
Transmission Control Block, the per-connection state struct (§11).
TCP
Transmission Control Protocol (RFC 9293).
TIME_WAIT
the state holding a closed connection's 5-tuple for 2×MSL (I10).
TOE
TCP Offload Engine, a hardware alternative (AA-4, §35).
TUN/TAP
a virtual network device presenting raw IP (TUN) or Ethernet (TAP) frames to userspace.
UDP
User Datagram Protocol.
VLAN
Virtual LAN, 802.1Q tagging.
Window scaling
RFC 7323's multiplicative extension of the 16-bit advertised window.
Zero-window probe
a 1-byte segment testing whether a zero-advertised window has reopened (§8.5, FM-5).
5-tuple
(src IP, src port, dst IP, dst port, protocol), the socket-dispatch key (I14).
Half-open connection
a connection whose handshake is incomplete, occupying the SYN queue (T2).
Backlog
the bound on a listening socket's SYN+accept queues (§16).
Accept queue
completed handshakes awaiting accept() (§11, ListenState). ---
