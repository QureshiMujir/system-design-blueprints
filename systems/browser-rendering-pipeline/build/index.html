  • Style-sharing cache: siblings with equal inputs share one Arc<ComputedStyle> → cut alloc + cascade work. Consume only 258 (matches_selector+Element+Specificity); P1 supplies property DB + computed-value rules; no selector internals here.
Deliverable

Sharing hit rate ≥ 60% on a 1000-node repeated-sibling fixture, shared nodes pointer-equal (Arc::ptr_eq). Resolve throughput ≥ 200k elem/s single-thread; correctness independent of sharing (cache off → identical ComputedStyle).

⬜ Phase 10 — Compositor + Commit + frame assembly §22

Objectives
  • Snapshot main-thread paint output into an immutable Commit; hand off main→compositor with zero shared mutable state post-handoff. Assemble CompositorFrame: apply TransformTree per CompositorLayer, composite ready Tiles in layer/paint order → display.
  • Run compositor-thread scroll + composited animation by mutating ONLY transform/scroll PaintPropertyNodes (no repaint, no main work) → the NEEDS_COMPOSITE-only fast path. Guarantee: a scroll/transform-anim frame costs O(re-apply property trees + recomposite), NOT O(style+layout+paint).
Deliverable

rpipe frame --composite-only + rpipe raster -o out.png: from one Commit, produce a CompositorFrame; then a scroll delta and a transform-animation tick each emit a new frame WITHOUT re-running style/layout/paint (assert lifecycle stays >= Commit, no NEEDS_PAINT).
