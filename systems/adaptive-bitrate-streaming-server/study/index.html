Hard questions (§37)

Self-examination questions from the blueprint; each points at the section where the answer lives.

  1. Why does segment-before-manifest (DP2/I1) matter more for LIVE than VOD, and how does LL-HLS's blocking reload tighten that same invariant to part granularity? (§7, §19)
  2. Why is GOP/IDR alignment (I3) compared as rationals across timescales rather than raw ticks, and what specific client-visible bug does a raw-tick comparison introduce at a ladder-switch boundary? (§8.1, §16)
  3. The SFU never transcodes (DP3) yet still performs per-consumer layer selection (§22) — what would break, and where, if a decoder were added "to smooth quality transitions"? (§9, §22)
  4. Trace why a naive < comparison on SeqNum/RtpTimestamp becomes a correctness bug specifically at 16-bit/32-bit wraparound, and name the invariant and phase that catch it. (§8.8, §21)
  5. Why is TWCC preferred over REMB even though both estimate available bandwidth, and under what topology would REMB's receiver-side model actually be more robust? (§8.11, §35)
  6. Why does simulcast layer switching require a keyframe while SVC layer dropping does not — connect this to the self-sufficiency of a base/lower layer in each scheme. (§8.10, §22)
  7. Derive why the origin's manifest-reload QPS target is dominated by LL clients rather than standard HLS clients, using the LL part-target arithmetic. (§4, §36)
  8. Why is CMAF chosen so one segment set serves both HLS and DASH rather than maintaining two encoders' worth of output — what doubles if this is violated, and where is that cost paid? (§9, §20)
  9. Why must NACK retransmission fall back to a keyframe request past a bounded window instead of always resending — connect the bound to the pacer's honesty invariant. (§7, §23)
  10. Why is the pacer necessary even though the BWE estimate already bounds the send rate — what specific failure mode does bursty egress cause that a correct estimate alone does not prevent? (§8.11, §23)
  11. Why does flux pin a RoomId to one node (sticky SFU) while the HAS origin is stateless and horizontally scaled — trace this asymmetry to the fan-out cost structure. (§1.3, §33)
  12. Why does the ADR table's "When the Rejected Choice Wins" column matter for the tokio-vs-glommio decision specifically as the SFU scales past one NUMA node — what would the migration path look like? (§9, §33)
  13. Trace the keyframe-storm failure mode from its root cause through its blast radius to its mitigation — why is PLI/FIR coalescing insufficient without the accompanying rate limit? (§22, §23)
  14. Why does flux isolate wall-clock to exactly the dynamic-MPD publishTime/availabilityStartTime fields rather than banning wall-clock entirely — what would break in a live MPD with zero wall-clock anchoring? (§8.6, §9)
  15. Using the Back-of-Envelope Capacity Model, explain why origin sizing is dominated by manifest/LL-reload traffic rather than segment bytes despite segments being far larger, and how CDN offload changes that balance. (§36, §33)
  16. Why does the total-parser principle (DP10) apply uniformly across four unrelated wire formats (RTMP/AMF, ISO-BMFF, RTP/RTCP, HLS/DASH text) — what single class of threat does this defend against across all four? (§9, §26)
  17. Compare flux's SFU forwarding model to mediasoup's and LiveKit's — which one architectural difference most affects blast-radius containment under a crash, and how does that map to flux's per-room single-writer design? (§35, §21)
  18. Why is a codec-agnostic AV1 Dependency Descriptor preferable to OBU parsing for selective forwarding — what invariant would be at risk if the SFU had to parse OBUs to make forwarding decisions? (§8.10, §22)
  19. Given the alternative architecture of a codec/transport co-designed pipeline (Salsify-style), explain concretely why flux's layered ingest→package→deliver design is not simply "worse latency" but a different, interoperability-optimal point in the design space. (§38, §2)
  20. Why does the Deferred Features Register anchor SRT/RIST ingest to the RTMP-ingest phase rather than a new phase — what does that anchoring choice imply about how IngestSource was designed as a seam from Phase 1 onward? (§39, §13)

34. Mental Models & First Principles

Each model is the compressed insight an expert holds; what it predicts; the bug class an engineer without it writes; and the § where this blueprint applies it.

  • MM1 — A media segment/manifest pair is a consistency contract, not a file. Predicts: any write path that advertises before it commits is a correctness bug, not a race condition to "usually" get right. Bug class without it: a manifest referencing a segment whose bytes haven't landed → 404/stall on every deploy under load. Applied in §17 (Phase 5), §19 (Phase 7 LL blocking reload), §20 (Phase 8 commit-before-serve).
  • MM2 — Cross-rendition alignment is a distributed invariant, not a per-track detail. Predicts: comparing presentation times as raw ticks across renditions with different timescales silently passes misaligned ladders. Bug class without it: a client stalls on exactly one rung switch, reproducible only under specific GOP timing. Applied in §8.1 (rational comparison), §16 (Phase 4 verify_alignment).
  • MM3 — An SFU is a router with codec literacy, not a media processor. Predicts: any code path in the forwarding tier that decodes pixels is an architectural smell, not an optimization. Bug class without it: CPU cost silently becomes O(participants × pixels), turning the SFU into an accidental MCU under load. Applied in §9 (ADR A01 rationale), §21–§22 (Phases 9–10).
  • MM4 — Continuity under rewrite is the SFU's central promise. Predicts: client-visible symptoms (spurious NACK storms, decoder resets) map one-to-one to specific rewrite-invariant violations, not vague "network issues". Bug class without it: naive seq/ts copy-through across a layer switch corrupts every subscriber's jitter buffer simultaneously. Applied in §21.2 (rewrite.rs), §22 (layer-switch splice sequencing).
  • MM5 — Congestion control is a control loop closed over a delayed, noisy signal, never an instantaneous truth. Predicts: any threshold-crossing switch without hysteresis oscillates under real network jitter, even in a correct implementation. Bug class without it: a layer selector that flaps every few seconds under stable-but-noisy bandwidth. Applied in §8.11 (GCC model), §23 (Phase 11 hysteresis).
  • MM6 — Determinism is a debugging multiplier, not a nicety. Predicts: byte-identical output from byte-identical input turns every packaging bug into a bisectable unit test instead of a "sometimes" production incident. Bug class without it: wall-clock leaking into segment bytes breaks CDN caching and reproducibility in the same commit. Applied in §9 (ADR A13), §15 (Phase 3 snapshot gate).
  • MM7 — Backpressure is the only legitimate response to a queue that cannot drain. Predicts: any queue without an explicit cap (AU bus, jitter buffer, NACK cache, blocking-reload waiters) is a future OOM incident, not a "should be fine" assumption. Bug class without it: a slow subscriber or a network partition grows one buffer until the whole node falls over. Applied in §9 (DP9/DP13), §20 (Phase 8), §23 (Phase 11).
  • MM8 — Two independent latency regimes cannot share one buffering strategy. Predicts: attempting a "unified" pipeline for HAS and SFU collapses one regime's cost structure into the other — segment quantization added to the SFU destroys its latency budget, or packet-granular delivery added to HAS destroys its cache-scalability. Applied in §3 (Architectural Overview), §36 (Back-of-Envelope Capacity Model), §38 (Alternative Architectures).

Glossary (§40) · 45 terms · site-wide glossary

Access Unit (AU)
one coded frame (video picture / audio frame) with timing (dts/pts/duration); flux's media currency; never decoded (DP1).
ABR (Adaptive Bitrate)
client picks among server-published renditions by bandwidth; the server's job is to publish an aligned, switchable ladder.
HAS (HTTP Adaptive Streaming)
pull-based, segment-quantized delivery (HLS/DASH); cache-scalable, multi-second latency.
SFU (Selective Forwarding Unit)
a media-aware router that forwards (never transcodes) RTP among peers, dropping the right packets/layers per subscriber.
HLS
Apple's HTTP Live Streaming; m3u8 master + media playlists; TS or CMAF segments; LL-HLS adds parts + blocking reload.
DASH
MPEG-DASH; an MPD describing Periods/AdaptationSets/Representations; static (VOD) or dynamic (live); LL-DASH adds chunked CMAF + ATO.
CMAF
Common Media Application Format; a constrained fMP4 profile that lets one segment set serve both HLS and DASH (DP7).
fMP4 / ISO-BMFF
fragmented MP4 / ISO Base Media File Format; ftyp/moov init + styp/moof/mdat media fragments.
MPEG-TS
Transport Stream; 188-byte packets, PAT/PMT/PES, PCR clocking; the legacy HLS container.
RTMP
Real-Time Messaging Protocol; Adobe's chunked TCP ingest protocol (handshake + AMF commands + FLV tags); still the dominant first-mile contribution path.
FLV
Flash Video container; the tag format RTMP carries (audio/video/script-data).
AMF0/AMF3
Action Message Format; RTMP's command serialization.
NAL unit
Network Abstraction Layer unit; the packetization unit of H.264/HEVC (IDR/non-IDR slice, SPS/PPS/VPS, SEI).
AVCC vs Annex-B
length-prefixed NAL framing (BMFF, params out-of-band) vs start-code framing (00 00 00 01, params in-band; used for TS).
IDR / GOP
Instantaneous Decoder Refresh frame (a clean keyframe) / Group of Pictures (frames between IDRs); a segment starts on an IDR (I4).
SPS/PPS/VPS
Sequence/Picture/Video Parameter Sets; decoder configuration carried in params.
ADTS / ASC
Audio Data Transport Stream framing / AudioSpecificConfig; AAC's TS framing vs out-of-band config.
PTS / DTS
Presentation / Decode Time Stamp; pts ≥ dts (I19); their difference is the composition (B-frame reorder) offset.
Timescale
ticks per second for a track timeline (90 kHz video, sample-rate audio); cross-track alignment compares rationals (I3).
Segment / Part
a media chunk (2–6 s) / a sub-chunk (200–500 ms) for low latency; advertised only after fully written (DP2, I1/I13).
Init segment
the ftyp+moov header (per rendition) referenced by #EXT-X-MAP / MPD Initialization before any media (I18).
Media sequence
monotonic per-rendition segment counter (#EXT-X-MEDIA-SEQUENCE / MPD $Number$); never regresses (I2).
DVR / time-shift window
the catch-up buffer a player can seek back into; bounded by timeShiftBufferDepth (DP13).
Blocking playlist reload
LL-HLS long-poll: the origin holds the reload until the requested msn/part exists or a timeout fires (I13).
RTP / RTCP
Real-time Transport Protocol / its Control Protocol (SR/RR/SDES/BYE + feedback); the SFU's wire (RFC 3550).
SSRC
Synchronization Source; an RTP stream's 32-bit id; unique per active stream, stable per consumer (I7).
Simulcast
a producer uploads N independent encodings (RID-tagged); the SFU picks one spatial rung per consumer; switching needs a target keyframe.
SVC (Scalable Video Coding)
a single layered bitstream (temporal/spatial); the SFU forwards a prefix; dropping a layer needs no keyframe.
Dependency Descriptor (DD)
an AV1 RTP header extension encoding per-packet layer/decode-target/chain info for selective forwarding without OBU parsing.
Jitter buffer
reorders/playout-clocks out-of-order RTP; adaptive depth 20–200 ms; overflow drops to keyframe (DP9).
NACK / RTX
Negative ACK (request a lost packet) / the retransmission payload format (RFC 4588); falls back to a keyframe past the window (I14).
PLI / FIR
Picture Loss Indication / Full Intra Request; both request a keyframe upstream; coalesced + rate-limited by the KEYFRAME MANAGER.
BWE (Bandwidth Estimation) / GCC
Google Congestion Control: delay-based (trendline/over-use) + loss-based AIMD fused to a per-consumer send rate.
TWCC / REMB
Transport-Wide Congestion Control feedback (sender-side, primary) / Receiver Estimated Max Bitrate (legacy receiver-side).
Pacer
a token/leaky bucket smoothing egress to the BWE target so bursts aren't misread as congestion (I16).
Over-use detector
the GCC component classifying inter-group delay slope as overuse/underuse/normal against an adaptive threshold.
Layer selector
the per-consumer policy mapping a BWE estimate to a discrete forwarded layer; up-switch needs a keyframe, down-switch is prompt (I8).
Keyframe-before-delta
the rule that a decode context's keyframe is forwarded before any of its delta frames (I8/DP5).
CENC
Common Encryption (ISO 23001-7): cenc (AES-CTR) / cbcs (AES-CBC pattern) subsample encryption; pssh/senc/saiz/saio boxes.
KID / PSSH
Key Identifier / Protection System Specific Header box (per DRM system, carrying init data + KIDs).
EncoderBoundary
the trait seam to an external transcode farm; flux commands + verifies but never encodes (DP3, §16).
SRTP seam
the typed boundary where decrypted RTP enters and plaintext RTP leaves; the cipher body lives in transport (#161, §21).
Glass-to-glass latency
capture-to-display end-to-end latency; the SFU target is <500 ms, LL-HAS <3 s (§4).
Origin
the publication boundary + HTTP server holding segments/manifests; stateless, CDN-frontable (#159).
Invariant counter
a metric (Ixx_total) incremented on an invariant violation; any nonzero value is a defect signal (§7, DP12).
