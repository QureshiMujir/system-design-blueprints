4.3 Scaling Assumptions

  • Vertical: linear throughput scale with CPU cores (retrieval parallel; ingest single-writer).
  • Horizontal (Phase 0): not supported; single process, single node.
  • Horizontal (PhaseDeferred "16.x"): read replicas via snapshot export + WAL streaming.
  • Namespace isolation: each NsId has independent index + storage; no cross-namespace index contention.
  • Embedding provider scaling: LlmIface is async + connection-pooled; embedding latency is off the critical path for recall (uses cached embeddings).

4.4 Failure & Degradation Policy

Failure condition Behavior
WAL fsync failure remember() returns MemError::Io; no record persisted
mmap page fault (corruption) Process-level SIGBUS caught → MemError::StorageCorrupt; safe shutdown
LlmIface embedding timeout Record stored with embedding_ref: None; BM25 + recency retrieval only
LlmIface extraction timeout Record stored as raw content; facts/entities empty; consolidation retries
HNSW index corruption Detected at load (CRC fail) → rebuild from record store; recall falls back to BM25 during rebuild
Consolidation job failure Job retried ≤ 5 times with exponential backoff; failed job logged with full error chain
Disk full remember() returns MemError::StoreFull; read path unaffected
Eviction of linked record Tombstone written; links referencing evicted ID return MemError::NotFound on fetch
