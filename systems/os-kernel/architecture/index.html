This diagram is canonical; every later section stays consistent with it. Box-by-box:

  • User-space. /sbin/init (PID 1), /bin/sh, and static ELF64 programs. Trust boundary: everything here is untrusted input to the kernel (T1). Concurrency boundary: one address space per process, N threads per process (§17).
  • syscall table / trap. The only crossing point of the trust boundary. Persistence boundary: none — stateless dispatch (§18).
  • IDT / trap. CPU-exception and IRQ entry; converts hardware events into typed Rust calls (§15).
  • LAPIC / timer. Per-CPU interrupt controller and preemption clock (§15, §22).
  • per-CPU data. gs:base-addressed; concurrency boundary for anything not behind an explicit lock (P3, §22).
  • scheduler. Owns run-queues and wait-queues; the only mutator of ThreadState (§8.1, §16).
  • address space (mm, VMAR). Owns page tables and virtual memory regions per process; persistence boundary: none, volatile (§14, §17).
  • VFS layer. Filesystem-agnostic dispatch; queue/channel boundary: none, synchronous calls only in Phase 0–12 (§19).
  • driver core. Owns IRQ routing and device state; isolation boundary via the Driver trait (P6, §20).
  • physical frame allocator + kernel heap. Owns all RAM not yet handed to a VMAR or a kernel object (§14).
  • ramfs, ext2 (read-only). Persistence boundary: ramfs is volatile (image reload), ext2 is read-only backing store (§19).
  • drivers (uart, kbd, vga, fb, rtc, pci, virtio-blk). External-interface boundary: MMIO/PIO to real or virtual hardware (§20).
  • firmware / bootloader. Outside the kernel's trust domain until hash-verified (T5); hands off exactly once, never re-entered (§13).

8.2 Syscall Wire Format

Register layout (System V AMD64, kernel-specific clobber rules, ADR-15):

Register Role
rax syscall number in; i64 result out (negative = -errno)
rdi, rsi, rdx, r10, r8, r9 args 1–5 (note: r10 replaces rcx, clobbered by syscall)
rcx, r11 clobbered by syscall/sysret (return address, rflags)

Worked example — write(1, "hello, world\n", 13):

Step Actor Action
1 user loads rax=1 (Write), rdi=1, rsi=&buf, rdx=13; executes syscall
2 CPU loads rip/rsp/rflags from STAR/LSTAR/FMASK (ADR-14)
3 kernel entry stub swapgs; saves user rsp; loads kernel rsp from per-CPU (§18.2)
4 dispatch reads rax, indexes syscall::table, calls handlers::fs::write
5 handler copy_from_user(buf, 13) (T1, T10), writes to fd 1's inode
6 handler returns Ok(13)
7 exit stub reverses entry; sysretq
8 user observes rax == 13

8.3 Page-Table Walk (x86_64, 4-level)

VirtAddr bits:  63........48 47....39 38....30 29....21 20....12 11.....0
                sign-ext     PML4 idx PDPT idx PD idx    PT idx   offset
PML4[idx] -> PDPT[idx] -> PD[idx] -> PT[idx] -> Frame + offset

Each level's entry is a PageTableEntry (§11.3); a PRESENT-clear entry ends the walk with a page fault (§8.7).

8.4 ELF64 Loading Sequence (execve, §17.4)

  1. Parse ELF64 header; verify magic, class=64, machine=x86-64.
  2. Iterate PT_LOAD segments; for each, map pages with the segment's R/W/X flags.
  3. Zero the tail where memsz > filesz (BSS).
  4. Allocate a user stack; push argv, envp, auxv per the SysV ABI supplement.
  5. Set entry rip from the ELF header; iretq to ring 3.

8.5 VFS Path Grammar (EBNF)

path       = [ "/" ] , component , { "/" , component } ;
component  = 1*63( unreserved_char ) ;
unreserved_char = ? any byte except 0x00 and "/" ? ;

Resolution is iterative left-to-right lookup() on each component starting from either the root inode or cwd (relative path); ../. are ordinary components resolved by the filesystem, not the VFS layer (matches ext2/ramfs convention).

8.6 Malformed-Input Example

cpio newc header with a truncated namesize field: the parser reads past the declared archive length. Fix: bounds-check namesize/filesize against the remaining archive length before any slice indexing; on violation return FsError::Malformed (never panic) — exercised by vfs/00-cpio-roundtrip's malformed variant and by the cargo-fuzz corpus (§24.2, FM7).

8.7 Failure-Path Example — User Null-Pointer Dereference

Step Component Action
1 user thread dereferences a null/unmapped pointer
2 CPU raises #PF (vector 14), pushes error code, cr2 = faulting address
3 trap stub saves TrapFrame, calls trap::exceptions::page_fault
4 handler consults the faulting thread's VMAR (§14.4) for cr2
5 handler no region covers cr2 ⇒ not a valid demand-page/COW case
6 handler builds and delivers SIGSEGV to the faulting thread (§21.2)
7 signal delivery default disposition: thread terminates, exit status reflects signal
8 parent observes exit via wait() (I11)

Design principles (§6)

  • Boring first. A correct, slow, single-CPU, cooperative kernel outranks a half-finished SMP kernel. Tradeoff: slower early milestones. Operational implication: SMP (§22) is gated behind single-CPU conformance passing in full. Violating it: bugs multiply combinatorially once concurrency is added on an unproven base.
  • The unsafe budget is finite. Every unsafe block carries a one-line SAFETY comment citing the Rust Nomicon section it relies on (I8). Tradeoff: verbosity. Operational implication: cargo geiger inventories the surface every PR (§30). Violating it: unreviewable memory-safety holes re-enter the exact class Rust was chosen to remove (T7).
  • No hidden global state. Cross-CPU data lives in static cells with explicit locking; per-CPU data lives behind gs:base through a typed wrapper. Tradeoff: more boilerplate accessors. Operational implication: every global is greppable and lock-order-checkable (I14). Violating it: silent data races (T9).
  • The kernel is a service, not a library. User-space talks to the kernel only through documented syscall numbers (I7); the internal API is not stable ABI. Tradeoff: internal refactors are free, external ones are not. Violating it: an ABI break silently corrupts every statically linked user binary.
  • One source of truth per fact. The page table is truth for virtual memory; the run-queue is truth for runnable threads; the VFS is truth for paths (I1, I5). Tradeoff: no caches without explicit invalidation. Violating it: two subsystems disagree about the same fact and the disagreement is undebuggable.
  • Drivers are isolated. A driver implements the Driver trait (§11.9) and does not reach past it into kernel internals. Tradeoff: some drivers need extra plumbing to stay inside the trait. Violating it: a single driver bug corrupts unrelated kernel state (MM4).
  • Fast path is short, slow path is correct. The syscall fast path (no scheduling, no I/O) is < 200 instructions (§4); the slow path may take as long as needed but must be re-entrant. Tradeoff: two code paths to maintain per syscall. Violating it: tail latency explodes under load (M3/M4).
  • Panics print, then halt. A kernel panic emits a structured trace (frame walk, registers, cr2, current task) to serial, then cli; hlt (P8). Tradeoff: no automatic recovery from a kernel bug. Violating it: silent corruption propagates past the point where it was detectable.
  • Reproducibility. Every kernel image is reproducible from a pinned toolchain and bootloader; CI verifies byte-identical rebuilds (§30). Violating it: "works on my machine" bugs become undebuggable across CI/hardware.
  • Readable assembly. Assembly lives in *.S files, commented, preferred over inline asm! that buries register constraints. Violating it: an entry-stub bug becomes unreviewable (T2, MM3).
  • Explicit backpressure over silent drops. Bounded queues (pipe ring, run-queue) block the producer rather than dropping data (ADR-31). Tradeoff: a slow consumer stalls a fast producer. Violating it: unbounded memory growth under load — strictly worse than a stall (T8).
  • Every lock has a documented order. docs/lock-order.md defines a total order; a debug-only checker asserts it (I14). Violating it: deadlock (FM5).
  • Telemetry is not optional. Every subsystem emits at least one counter or histogram to the trace ring (§27). Tradeoff: small per-event overhead. Violating it: production failures are undiagnosable (FM-class blast-radius unknown).
  • Version the ABI, never break it silently. New syscalls append; none are ever renumbered (I7, ADR-14). Violating it: a recompiled user binary silently invokes the wrong syscall.
