Hard questions

Self-examination questions from the blueprint; each points at the section where the answer lives.

  1. Why is DP a property of the mechanism, not the output, and what misuse follows from treating a single noised value as "anonymized"? (MM1 + §8 + Phase 1)
  2. A developer computes sensitivity from the actual dataset, not the worst case. Trace how this voids the ε guarantee and which invariant catches it. (MM2 + Phase 2 + I6 + I10)
  3. Explain the floating-point Laplace attack and why snapping defeats it. Which ADR and invariant mandate it? (MM3 + ADR-05 + I5 + Phase 5)
  4. Why does converting RDP to (ε,δ) after every step inflate the reported ε, and when must you convert? (MM5 + ADR-08 + Phase 9 + §4.5)
  5. Show the TOCTOU race in a non-atomic budget spend and how the ledger prevents two queries from overspending. (MM6 + ADR-12 + Phase 11 + §4.3)
  6. The post-processing theorem makes debiasing randomized-response counts free. Why, and what budget bug does forgetting it cause? (MM7 + Phase 7 + Phase 13 + MM4)
  7. In DP-SGD, why must clipping be per-example and before averaging? What breaks if you clip the mean gradient? (MM8 + ADR-13 + Phase 13)
  8. Reconcile the §4.2 audit-log ceiling (<10 MB) with the 1M-entry cap at ~64 B/entry. At what entry count does rotation trigger? (C9 + §4.2 + §4.6)
  9. Compare basic, advanced, and RDP composition for 10⁴ Gaussian queries. Which gives the smallest ε and why? (MM4 + Phase 8 + Phase 9 + ADR-08)
  10. Why f64 throughout and never f32 on privacy-critical paths? Connect to snapping and analytic-Gaussian precision. (§4.5 + MM3 + ADR-07 + Phase 4)
  11. The analytic Gaussian saves 10–30% σ over the classical bound. What is the engineering cost, and when is the classical bound preferable? (ADR-07 + Phase 4 + Comparative table)
  12. Distinguish ε-DP, (ε,δ)-DP, RDP, and zCDP. Which mechanisms suit each, and why keep separate RDP and zCDP accumulators? (Phase 3 + Phase 4 + Phase 9 + Phase 10 + ADR-09)
  13. A 1000-bin histogram is budgeted at <1 ms. Why does parallel composition let all bins share one ε rather than spending 1000ε? (C2 + MM4 + Phase 8 + Phase 12)
  14. Why must the CSPRNG be OS-seeded and one-state-per-thread? What does each property prevent? (ADR-04 + §4.3 + I5)
  15. The engine declares + audits sensitivity (ADR-27/29) rather than proving it via types like OpenDP. Give two regimes where OpenDP's approach is right. (ADR-27 + ADR-29 + Comparative table)
  16. How does dp-validate empirically detect a σ wrong by 0.01%, and why can't unit tests catch it? (ADR-18 + Phase 14 + §4.5)
  17. Trace the privacy cost of a bounded-mean query that spends budget twice. Why two charges, and how does ADR-31's neighboring relation change sensitivity? (Phase 12 + ADR-31 + Phase 2)
  18. Why does subsampling improve DP-SGD privacy, where is the amplification accounted, and what is the per-step budget for batch 256 over 10⁴ steps? (MM8 + Phase 13 + Phase 10 + C7)
  19. The budget is per-dataset (ADR-30). Show how a global budget lets one analyst exhaust another's quota, and which invariant the per-dataset design enforces. (ADR-30 + Phase 11 + I3)
  20. The exponential mechanism uses log-sum-exp. What numerical failure does it prevent, and how does its sensitivity differ from additive-noise mechanisms? (Phase 6 + §4.5 + Phase 2)

Mental Models & First Principles

The compressed insights an expert holds before writing a line. Each names what it predicts, the bug class you write without it, and the section where this blueprint applies it.

MM1 — DP is a property of the mechanism, not of the output. ε-DP bounds how much one record can shift the output distribution: for neighboring D, D′, Pr[M(D)∈S] ≤ e^ε · Pr[M(D′)∈S] + δ. Predicts: you cannot look at one release and decide whether it is "private" — privacy lives in the randomized algorithm and its parameters. Bug class without it: treating a single noised number as "anonymized" and reusing it freely. Applied in: §8 Domain Model, Phase 1, Phase 3.

MM2 — Noise is calibrated to sensitivity, and getting sensitivity wrong silently voids the guarantee. Laplace scale = sensitivity/ε; sensitivity is the worst-case change in the query output when one record changes. Predicts: underestimating sensitivity gives too little noise, so the proven ε is a lie no test will flag. Bug class: computing sensitivity on the realized data instead of the worst case, or skipping clamping (making it unbounded). Applied in: Phase 2, I6, I10, §4.4.

MM3 — Floating-point sampling leaks; the snapping mechanism is the fix. Naive inverse-CDF Laplace on f64 only lands on representable values; the gaps reveal the exact input (Mironov CCS 2012). Predicts: a correct-on-paper sampler is attackable in practice. Bug class: mu + laplace_sample() from a library RNG with no snapping/clamping. Applied in: ADR-05, P3, I5, Phase 5.

MM4 — Composition is the budget: privacy degrades as you query, and the accountant is the ledger. k queries compose to ≈kε (basic) or ≈√k·ε (advanced); RDP/zCDP give tighter bounds. Predicts: an unbounded query stream has unbounded privacy loss — you MUST stop. Bug class: answering queries without charging a budget, or mis-counting composition. Applied in: Phase 8, Phase 9, Phase 10, I9.

MM5 — RDP linearizes composition; convert to (ε,δ) only once, at the end. Rényi DP tracks a curve over orders α; composing is adding per-order RDP, and a single conversion at report time gives the tightest (ε,δ). Predicts: converting after every step loses tightness and inflates the reported ε. Bug class: per-step (ε,δ) conversion. Applied in: ADR-08, Phase 9, §4.5, MM4.

MM6 — The budget ledger must be fail-closed and atomic, or it is not a guarantee. Spend is a single atomic check-and-charge; on exhaustion the engine errors, never returns a default/zero answer. Predicts: a TOCTOU gap between check and charge lets two concurrent queries overspend. Bug class: if budget.remaining() > cost { release(); budget.spend(cost) } (non-atomic). Applied in: ADR-12, ADR-30, Phase 11, I10, §4.3.

MM7 — Post-processing is free; any function of a DP output is still DP. The post-processing theorem means debiasing randomized-response counts, rounding, or clamping a noised answer costs no additional budget. Predicts: transforms of an already-private value are free. Bug class: re-charging budget for a pure transform, wasting budget. Applied in: Phase 7, Phase 13, MM4.

MM8 — DP-SGD privacy = subsampling + clipping + noise, accounted by the moments/RDP accountant. Per-example gradients are L2-clipped (bounding sensitivity), Gaussian noise is added to the batch sum, and subsampling amplification is tracked across thousands of steps. Predicts: clipping after averaging, or ignoring subsampling amplification, breaks the bound. Bug class: clipping the mean gradient instead of per-example gradients. Applied in: ADR-13, Phase 13, MM4, §4.1.

Glossary

Alphabetical. Terms defined with precision for the dp-* crates. Implementation crate noted where applicable.

Above threshold : SVT primitive. Add Lap(2/eps) to threshold T; add Lap(4/eps) to each query answer. : Release YES when noisy query exceeds noisy threshold; NO answers consume zero budget (up to max YES count c). : Each YES charges eps budget. Implemented in dp-svt/src/above_threshold.rs.

Accountant : Component that tracks cumulative privacy loss across sequential releases. : Outputs a certified (eps, delta) upper bound on demand via to_privacy_params(). : Subtypes: basic, advanced, RDP, zCDP, moments. All implement the Accountant trait in dp-accountant.

Add/remove neighboring : Two datasets D, D' are neighbors if one is obtained by adding or removing exactly one record. : Default neighboring relation in dp-sensitivity. Determines all L1/L2 sensitivity formulas. : Contrasts with replace-one neighboring, which doubles sensitivity.

Analytic Gaussian : Balle-Wang (ICML 2018) exact sigma calibration for the Gaussian mechanism. : Solves the (eps, delta) integral equation numerically via bisection; always yields smaller sigma than the classical bound. : Classical bound: sigma >= sqrt(2 ln(1.25/delta)) * l2 / eps. Analytic is strictly tighter. : Default in dp-mechanism/src/gaussian.rs.

Basic composition : k sequential mechanisms (eps_i, delta_i) compose to (sum eps_i, sum delta_i)-DP. : Simplest accountant; dominated by advanced composition for large k and small delta. : Auto-choose min(basic, advanced) in dp-accountant/src/basic.rs.

Bounded query : A query with finite global sensitivity because all inputs are clamped to [lower, upper] before aggregation. : Required for calibrating any finite noise level. Enforced by dp-sensitivity clamping. : Invariant I6: every value entering an aggregate must be within its declared Bounds.

Budget : Per-dataset (eps, delta) ceiling: Budget { total: PrivacyParams, spent: PrivacyLoss }. : Each release charges the accountant, updates spent, and is denied (DpError::BudgetExhausted) if spent would exceed total. : Atomic spend; fail-closed; per-analyst variant tracked via Ledger. Invariant I3, I10.

Budget exhaustion : State when cumulative (eps, delta) charged against a dataset reaches or would exceed the ceiling. : All subsequent queries denied. Budget cannot go negative. : Invariant I3. Enforced by dp-budget/src/policy.rs.

Central DP : Privacy model where a trusted data curator holds raw data, applies a mechanism, and releases only the noisy result. : The dp-* engine operates in central-DP mode. Contrasts with local DP (dp-local).

Clamping / clipping : Clamping: enforce lower <= x <= upper on every data value before aggregation (I6, P7). : Makes global sensitivity finite; required for bounded queries. : In dp-dpsgd: L2 norm clipping rescales per-example gradient g to min(1, C/||g||_2)*g. : Both operations bound sensitivity at the source.

Composition : Combining outputs of multiple DP mechanisms on the same dataset. : Sequential: privacy losses accumulate (basic or advanced composition, Phase 8). : Parallel: mechanisms on disjoint partitions compose at max(eps_i), not sum. : Correctness invariant I4: accountant's reported loss is an upper bound on the true composed loss.

Concentrated DP (zCDP) : Privacy parameterized by rho; the privacy loss random variable is sub-Gaussian with parameter rho. : Composes additively: rho_total = sum(rho_i). Converts to (eps, delta) at query time. : Tighter than basic composition for repeated Gaussian releases. : Implemented in dp-accountant/src/zcdp.rs. See also: rho.

CSPRNG : Cryptographically secure pseudorandom number generator; seeded from OS entropy (getrandom). : All noise in dp-sample drawn from a CSPRNG. Naive std::rand / SmallRng banned in deny.toml. : Required by secure-sampling fidelity invariant I5.

Delta : Failure probability allowing the eps-bound to be violated; newtype Delta(f64) in [0,1). : delta=0 = pure DP. Gaussian mechanism requires delta > 0 (I8). : Deltas add under basic composition; accumulate in the accountant's spent field.

Debiasing : Converts biased local-DP frequency counts (raw RR TRUE counts) to unbiased estimates. : Formula: f_hat = (count - n*(1-p)) / (2p-1); variance = p*(1-p) / (n*(2p-1)^2). : Implemented in dp-local/src/frequency.rs.

Discrete Gaussian : Integer-valued Gaussian (Canonne-Kamath-Steinke, NeurIPS 2020). : Eliminates floating-point representability gaps that the snapping mechanism addresses for Laplace. : Properties: zero-mean, variance sigma^2, closed under addition. : Implemented in dp-sample/src/gaussian.rs.

DP-SGD : Differentially private SGD. Four steps per mini-batch: : (1) Clip per-example L2 gradient norms to C. (2) Sum clipped gradients. : (3) Add Gaussian noise: sigma = C * noise_multiplier. (4) Track epsilon via moments accountant. : Implemented across dp-dpsgd/clip.rs, noise.rs, tracker.rs, trainer.rs.

Epsilon : Privacy-loss parameter; newtype Epsilon(f64) > 0 and finite (I8). : Smaller = stronger privacy. Every DpResult<T> carries an epsilon via PrivacyParams stamp. : Epsilons add under basic composition; minimized by RDP-to-(eps,delta) conversion over alpha.

Exponential mechanism : Selects candidate c with probability proportional to exp(eps * u(c) / (2 * sensitivity)). : Satisfies eps-DP. Computed via log-sum-exp for numerical stability (avoids overflow). : Used for non-numeric selection: mode, best split, quantile bucket. : Implemented in dp-mechanism/src/exponential.rs.

Fail-closed : I10 policy: any invalid parameter, exhausted budget, or unbounded sensitivity causes DpError and refusal. : No silent release with an incorrect guarantee. : Enforced at: Epsilon/Delta construction, Budget::spend, Sensitivity construction.

Float-DP attack : Mironov (CCS 2012): a naive floating-point Laplace sampler leaks the exact input value. : Cause: inversion formula x = -b*sign(u)*ln(1-2|u|) maps each input to a deterministic set of representable floats. : Fix: snapping mechanism in dp-sample/src/laplace.rs. Invariant I5.

Frequency oracle : Aggregation of local-DP randomized responses into an unbiased domain-wide frequency estimate. : Debiasing formula applied per domain value. Variance scales O(1/(n*(2p-1)^2)). : Implemented in dp-local/src/frequency.rs.

Global sensitivity : sup_{D, D' neighboring} |f(D) - f(D')|, in L1 or L2 norm. : Laplace uses L1; Gaussian uses L2. Declared sensitivity must satisfy I2: declared >= true. : Computed by dp-sensitivity/src/global.rs for count, sum, mean.

Gradient clipping : Per-example: g_clipped = g * min(1, C/||g||_2). Bounds L2 sensitivity of the batch sum at C. : Invariant: ||g_clipped||_2 <= C for every example. : Enables noise calibration: sigma = C * noise_multiplier. Implemented in dp-dpsgd/src/clip.rs.

Heavy hitter : A domain value appearing in a large fraction of local-DP reports. : Estimated via domain reduction (hashing) + multi-channel RR in dp-local/src/heavyhitter.rs. : Privacy cost equals a single RR per hash level.

Histogram query : Parallel composition: each bin is a count query over a disjoint data partition. : Budget cost = max(eps_i) over bins, not sum. : Sensitivity per bin = 1. Implemented in dp-query/src/histogram.rs.

L1 sensitivity : sup_{D,D'} |f(D)-f(D')|_1. Used to calibrate Laplace scale b = l1/eps. : Component of Sensitivity { l1, l2 }. count: l1=1; sum over [lo,hi]: l1=hi-lo.

L2 sensitivity : sup_{D,D'} |f(D)-f(D')|_2. Used to calibrate Gaussian sigma. : Component of Sensitivity { l1, l2 }. sum over [lo,hi]: l2=hi-lo.

Laplace mechanism : Adds Lap(b) noise where b = l1/eps; pure eps-DP. : Requires snapping sampler to close Mironov float-DP attack. : Advertises PrivacyParams { epsilon: eps, delta: Delta(0.0) }. : Implemented in dp-mechanism/src/laplace.rs.

Local DP : Each user perturbs their own data before sending; no trusted curator. : Stronger per-record guarantee, weaker population accuracy. : Epsilon is per-user per-record. Implemented in dp-local.

Local sensitivity : sup_{D' neighboring D} |f(D)-f(D')|; data-dependent. : Cannot be used directly without smooth sensitivity amplification. : Not exposed without explicit wrapping; dp-sensitivity defaults to global sensitivity.

Log-sum-exp trick : Numerically stable: ln(sum_i exp(a_i)) = a_max + ln(sum_i exp(a_i - a_max)). : Required in exponential mechanism to avoid overflow for large utility ranges (>700 units). : Implemented in dp-mechanism/src/exponential.rs.

Mechanism trait : fn privatize(&self, exact: T, sens: Sensitivity) -> T : fn privacy_params(&self) -> PrivacyParams : Every mechanism must implement both. Defined in dp-mechanism/src/lib.rs.

Moments accountant : Specialization of RDP for the subsampled Gaussian mechanism. : Tracks log E[e^{(alpha-1)*L}] where L is the privacy loss variable. : Enables tight per-step epsilon for DP-SGD (Abadi et al., CCS 2016). : Subsampling amplification provably included. Implemented in dp-accountant/src/moments.rs.

Neighboring datasets : Two datasets D, D' differing by one record under the chosen neighboring relation. : The definition determines sensitivity of every query. : dp-sensitivity accepts the relation as a parameter (add/remove or replace-one).

Noise calibration : Setting noise scale as a function of sensitivity and (eps, delta) so the mechanism satisfies its DP claim exactly. : Laplace: b = l1/eps (exact). Gaussian: analytic Balle-Wang (exact). Classical Gaussian: upper bound.

Noise multiplier : In DP-SGD: sigma = C * noise_multiplier, where C is the gradient clipping bound. : Moments accountant maps (noise_multiplier, T steps, q sample rate) to final epsilon at target delta. : Increasing noise_multiplier improves privacy, reduces utility.

Parallel composition : Disjoint dataset partitions processed independently compose at max(eps_i), not sum. : Enables histograms and per-stratum queries without multiplicative budget cost. : Formalized alongside sequential composition in dp-accountant/src/basic.rs.

Post-processing : Any function of a DP output is DP with the same (eps, delta) parameters (I7, P5). : DpResult<T> can be transformed freely — no re-noising required. : DP is defined over output distributions, not computation graphs.

Privacy amplification : Running a mechanism on a random subsample of m < N records amplifies privacy. : Effective eps_sub << eps for small subsampling rate q = m/N. : Quantified only through moments/RDP accountant — never assumed (P9).

Privacy budget : Total (eps, delta) allocated to a dataset or analyst, held in Budget. : Each mechanism release charges the accountant and updates spent. : Query that would push spent past total is denied (I3, I10). Audit log persists every charge.

Privacy loss : Random variable L(D,D') = ln(Pr[M(D) in S] / Pr[M(D') in S]). : Must satisfy L <= eps with probability >= 1-delta for (eps,delta)-DP. : Tracked as a distribution (RDP) or scalar (basic composition) by the accountant.

Privacy stamp : DpResult<T> carries both the released value and PrivacyParams { epsilon, delta }. : Post-processing-immune (I7): downstream transforms do not invalidate the stamp. : Enables downstream systems to verify the DP guarantee without re-computation.

Pure DP : (eps, 0)-DP: no delta failure probability. Hardest guarantee. : Achieved by Laplace mechanism and randomized response. : Gaussian mechanism cannot achieve pure DP. Implies (eps, delta)-DP for any delta > 0.

Randomized response : Local-DP primitive: return true answer with probability p, flip with probability 1-p. : Satisfies eps = ln(p/(1-p))-DP. Debiasing formula recovers unbiased frequencies. : Implemented in dp-local/src/rr.rs.

Renyi DP (RDP) : Parameterized by order alpha; tracks alpha-Renyi divergence D_alpha(M(D)||M(D')). : Composes by addition per order. Converts to tightest (eps,delta) via minimization over alpha. : Gaussian mechanism: RDP at order alpha = alpha/(2 sigma^2). (Mironov, CSF 2017). : Implemented in dp-accountant/src/rdp.rs.

Replace-one neighboring : Two datasets differ by replacing exactly one record with an arbitrary record. : Doubles sensitivity relative to add/remove. : dp-sensitivity exposes the relation as a parameter so callers choose the model.

Report noisy max : Add independent Lap(1/eps) noise to each candidate count; return the argmax. : Satisfies eps-DP for the selection. Cheaper than exponential when candidates are numeric counts. : Differs from exponential in additive noise vs softmax weighting. : Implemented in dp-mechanism/src/rnm.rs.

Rho (zCDP parameter) : Sub-Gaussianity parameter of zero-concentrated DP. : Gaussian mechanism: rho = l2^2 / (2 sigma^2). Composes additively. : Converts to (eps,delta): eps = rho + 2*sqrt(rho * ln(1/delta)). : Tracked in ZcdpAccountant.

Secure sampling : Noise generation that resists the Mironov float-DP attack. : Requirements: snapping mechanism for Laplace, discrete Gaussian for integers, CSPRNG-only seeding. : All of dp-sample embodies P3. I5 formalizes the correctness requirement.

Sensitivity soundness : I2: declared sensitivity >= true global sensitivity for the clamped query. : Over-estimation: safe (more noise, less utility, but correct). : Under-estimation: silently violates DP — the worst failure mode. : Enforced by clamping in dp-sensitivity; unbounded input fails with DpError::UnboundedSensitivity.

Snapping mechanism : Mironov (CCS 2012): rounds a Laplace sample to the nearest float on a lattice scaled to machine precision. : Provably closes the representable-value leakage channel. : Key property: the set of possible outputs is independent of the exact input value. : Mandatory in dp-sample/src/laplace.rs.

Sparse vector technique (SVT) : Answers a long sequence of threshold queries cheaply. : Budget paid only for YES answers (above threshold); NO answers free up to count cap c. : Useful for streaming queries where most answers expected to be NO. : Implemented in dp-svt/src/svt.rs and dp-svt/src/above_threshold.rs.

Stability (transform) : A transform T has stability t if neighboring inputs produce at most t-neighboring outputs. : Sensitivity scales by t through the transform: new_sensitivity = old_sensitivity * t. : Propagated in dp-sensitivity/src/stability.rs; ensures I2 across multi-step pipelines.

StatDP : Ding et al. (CCS 2018) methodology for empirical DP verification. : Draw n samples from M(D) and M(D') for neighboring D, D'; run likelihood-ratio test for (eps,delta) compliance. : Basis of dp-validate/src/hypothesis.rs.

Subsampling : Drawing m < N records before applying a mechanism amplifies privacy. : Only valid when accounted through moments/RDP accountant (P9). : Never assumed; always proved. Amplification factor decreases as q = m/N increases.

Utility function : In the exponential mechanism: u: Candidate -> f64 scoring function. : Higher score = exponentially more likely to be selected. : Sensitivity = max_{D,D' neighboring} max_c |u_D(c) - u_D'(c)|.

Zero-concentrated DP (zCDP) : See Concentrated DP and Rho. : Intermediate representation between RDP and (eps,delta)-DP. : Compositionally convenient: rho values add; conversion to (eps,delta) done at release time. : Implemented in dp-accountant/src/zcdp.rs.
