Mental Models & First Principles

The compressed intuitions a principal engineer carries about this system. Each: the insight, what it predicts, the bug you write without it, and where this blueprint applies it.

MM1 — A digest is a name that is also a checksum. The hash is simultaneously the address and the integrity proof; you never look a blob up "by path" and separately "validate" it — the lookup is the validation. Predicts: you can dedup, cache, and replicate with zero coordination because identity is intrinsic, not assigned. Bug without it: you add a mutable "overwrite" API or a name→blob index and silently serve stale content. Applied: P1, P6, §8.1, §18 (Phase 6 dedup), §24 (Phase 12 shard = hash mod ring).

MM2 — The commit is the rename(2), nothing before it exists. A blob is not "being written then validated then published" — it is invisible until one atomic syscall flips it into existence at its addressable path. Predicts: a crash at any instruction leaves either nothing or a complete, verified blob — never a torn one. Bug without it: in-place writes expose half-written blobs to concurrent readers; verify-then-write races. Applied: P3, I3, §14 (Phase 2), Failure Modes (crash mid-upload).

MM3 — An ActionResult is a promise about CAS, not a value. The AC stores a claim "these output digests exist"; it is only true as long as CAS still holds them. Predicts: the AC and the GC are coupled — you cannot reason about one without the other, and the only safe serving rule is "re-check existence at read time." Bug without it: the phantom hit — you serve a cached result whose outputs were GC'd, and the client builds on vapor. Applied: P4, I2, §19 (Phase 7), §22 (Phase 10 mark-sweep).

MM4 — Reachability is the GC's only truth; refcounts are its only safety belt. A CAS blob is alive iff a live AC entry points at it or an in-flight transfer holds it; everything else is garbage. Predicts: GC correctness reduces to "snapshot the roots, mark, sweep the unmarked with refcount 0" — exactly tracing GC. Bug without it: you evict by LRU alone and delete a blob a live AC entry needs, or evict a blob mid-upload. Applied: I4, I5, P12, §22 (Phase 10), MM3.

MM5 — Compression is a wire/disk costume; the body underneath is what has identity. The digest is computed over plaintext; the zstd frame is a transport detail that must be stripped before the bytes mean anything. Predicts: the only correct order is decompress→verify, and a "compressed digest" is a category error. Bug without it: you hash the compressed frame, store it, and the decompressed content is unverifiable — or a decompression bomb OOMs you. Applied: P13, §20 (Phase 8), §8.4 grammar.

MM6 — Backpressure is a property of the slowest stage, applied at the fastest one. Throughput is set by disk write speed; if you don't push that limit back to the network reader, bytes pile up in RAM. Predicts: every unbounded queue between a fast producer and slow consumer is a latent OOM. Bug without it: a fast uploader on a slow disk silently grows tonic's internal buffer until the process dies. Applied: P5, I9, §16 (Phase 4 Semaphore), §24.6 (Phase 12 write-back queue).

MM7 — Content addressing turns replication into copying and sharding into arithmetic. Because a blob's location is a pure function of its hash, "which node?" is hash mod ring and "is this replica correct?" is rehash == digest — no quorum, no version vector. Predicts: a CAS scales horizontally without consensus; a wrong shard is a cache miss, recoverable by re-upload, never a corruption. Bug without it: you bolt a consensus protocol onto a store that never needed one, paying latency for a guarantee content addressing already gives. Applied: §24 (Phase 12), Chord/Dynamo (§5 Papers), Alternative Architectures.

MM8 — The cache's correctness budget is spent on integrity, not availability. A build cache may miss, lag, or restart empty with no harm — but it must never hand back wrong bytes. Predicts: you optimize correctness → observability → maintainability → performance in that order, and you accept eventual consistency on the remote tier while refusing to weaken verify-on-write. Bug without it: you trade a DigestMismatch check for throughput and poison every downstream build. Applied: §4 (integrity SLO 100%), P2, SLO Definitions, Threat Model (cache poisoning).

MM9 — Two layers, two key spaces, one arrow between them. CAS is keyed by blob digest; AC is keyed by action digest; the only edge is AC→CAS (an ActionResult names CAS blobs). Keeping these distinct is what lets you GC, replicate, and reason about each independently. Predicts: collapsing them into one "memoized key→artifact" map loses the completeness invariant and the free input-tree dedup. Bug without it: you can't express "skip rebuild" separately from "store this output," and partial uploads corrupt the action mapping. Applied: §1, §3, §8.3, Comparative Architecture (vs ccache's single map).

MM10 — atime is a recency oracle, and oracles drift. LRU ordering trusts a per-blob last-access time; on a VM with clock skew or under coarse timestamp resolution, that oracle lies and evicts the wrong blob. Predicts: a monotonic counter is safer than wall-clock for eviction ordering. Bug without it: clock skew makes GC evict a hot blob and keep a cold one, tanking hit rate without any error surfacing. Applied: §15 (Phase 3 BlobMeta.atime), §22 (Phase 10 clock-skew pitfall), Spanner timestamp idea (§5 Papers).

Glossary · 37 terms · site-wide glossary

CAS
Content-Addressable Storage; blob store keyed by Digest {hash, size_bytes}; every lookup is by identity, not name.
AC
Action Cache; maps Digest(Action) → ActionResult; allows skipping rebuild when action result is known.
Digest
{hash: String, size_bytes: i64}; lowercase hex SHA-256 (or Blake3/SHA-512); exact byte count; sole identity of a blob.
DigestFunction
Hash algorithm used: Sha256 (default), Sha512, Blake3; declared in Capabilities and resource names.
InstanceName
Multi-tenant namespace prefix in REAPI resource names; isolates CAS + AC per tenant.
REAPI
Remote Execution API v2; protobuf/gRPC protocol defining CAS, ActionCache, ByteStream, Capabilities services.
ByteStream
Google gRPC streaming API for large blob transfers; Write (upload) and Read (download).
resource name
REAPI string identifying a blob or upload session: {instance}/uploads/{uuid}/blobs/{hash}/{size}.
resumable upload
ByteStream Write that can be interrupted and continued using committed_size from QueryWriteStatus.
committed_size
Bytes durably written so far for an in-progress ByteStream Write; used for resumption.
QueryWriteStatus
ByteStream RPC returning committed_size and complete for an upload UUID.
FindMissingBlobs
CAS RPC returning the subset of requested digests not present in CAS.
BatchUpdateBlobs
CAS RPC for uploading multiple small blobs in a single request (≤ max_batch_total_size_bytes).
BatchReadBlobs
CAS RPC for downloading multiple blobs in a single request.
GetTree
CAS RPC returning the transitive Directory closure of a Merkle tree root, paginated.
GetCapabilities
Capabilities RPC returning ServerCapabilities: supported digest functions, compressors, batch size.
completeness invariant
AC guarantee: an ActionResult is served only if all its referenced output blobs exist in CAS.
phantom hit
Serving an ActionResult whose output blobs are absent from CAS; the critical failure mode the completeness invariant prevents.
verify-on-write
Re-hashing uploaded bytes before committing; rejects any blob whose computed digest ≠ claimed digest.
atomic rename
rename(2) syscall making a blob visible at its addressable path atomically; prevents partial reads.
storage tier
One level of the TieredStore: memory (fast), disk (large), remote/object (durable).
LRU eviction
Removing the least-recently-used blob when the tier exceeds its size watermark.
size watermark (high/low)
Thresholds for GC: eviction starts at high, stops at low.
mark-sweep
GC algorithm: mark all CAS blobs reachable from live AC entries; sweep (evict) unreachable ones.
reachability
A CAS blob is reachable if referenced by any live AC entry's outputs; reachable blobs must not be evicted.
refcount
Per-blob counter in BlobMeta; > 0 means blob is in use (upload in progress or active read); GC must not evict.
cache hit / miss
AC: hit = GetActionResult returns an ActionResult; miss = NOT_FOUND. CAS: hit = contains() true.
compressor
Compressor::Identity (no compression) or Compressor::Zstd (zstd frame); declared in resource names.
compressed-blobs
ByteStream resource path variant indicating zstd-compressed transfer; digest still identifies uncompressed content.
do_not_cache
Action.do_not_cache=true → server must not store the ActionResult in AC.
Merkle directory tree
Build output tree of Directory/FileNode/DirectoryNode/SymlinkNode; each node identified by its digest.
abcd
Server binary name; abcd serve starts the daemon.
abc
CLI binary name; admin commands: stats, gc, verify, import, export, bench.
abc-
Crate name prefix for all workspace members (e.g., abc-core, abc-cas).
read-through
On miss at local tier, fetch from remote tier and cache locally.
write-back
Write to local tier immediately; replicate to remote tier asynchronously.
PhaseDeferred
Marker tying a feature to the phase that unblocks it; the anchor names the real section that builds it (e.g. §24 for the S3 remote tier, §25 for the fuzz canary). See the Deferred Features Register.
