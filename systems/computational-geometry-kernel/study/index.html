Hard questions (§37)

Self-examination questions from the blueprint; each points at the section where the answer lives.

  1. Why do adaptive precision (§13) and SoS (§14) together guarantee zero misclassification (I1, §7), when neither alone would suffice?
  2. How does the lifting map (§8.1) let Phase 11's 3D hull (§23) serve as an independent correctness oracle for Phase 7's Delaunay (§19) — and what would break if orient3d's error bound (§4) were wrong instead of incircle's?
  3. Why is DCEL-arena cache locality (§32) fundamentally in tension with history-DAG memory growth (§19, C4 in §36) at the 50M-point ceiling (§4) — which would you sacrifice first, and why?
  4. If ADR-4 (§9) had chosen "always rational" instead of expansions, which System Constraints numbers (§4) would change, and which System Invariants (§7) would become trivially true instead of requiring active enforcement?
  5. Why does Principle 8 ("no float sign without a proven bound," §6) require a lint/CI gate rather than a code-review policy, given the Threat Model's exact-path-DoS entry (§26) and the Failure Modes entry for predicate misclassification (§27)?
  6. Trace how a single non-robust orient2d call propagates from Phase 7's point-location loop (§19, I10) to a downstream #375 spatial-index consumer's wrong query result — which invariant (§7) catches it first, and which telemetry counter (§28) fires?
  7. Why does the Comparative Architecture Table (§35) show CGAL and this blueprint converging on the EPIC kernel split while GEOS does not — and what does GEOS's snap-rounding alternative (§38) cost it that EPIC avoids?
  8. Given C6's finding (§36) that exact-fallback cost is negligible at a 0.1% fallback rate, at what fallback rate would the exact path dominate wall-clock time, and which Threat Model entry (§26) exists to prevent an adversary from reaching it?
  9. Why must the RNG seed (I17, §7), the FP environment (Principle 9, §6), and the Shewchuk constant table (§13) all be pinned together for Compatibility & Versioning (§29) — what bug class appears if only two of the three are pinned?
  10. Why does Phase 9's CDT (§21) need a different legality rule (constrained-empty-circle) than Phase 7's Delaunay (§19), and how does that interact with the Lawson-flip machinery shared between them (§8.10)?
  11. The Alternative Architectures section (§38) rejects a pure fixed-point/snap-rounding design. Using the GEOS row of the Comparative Architecture Table (§35) as evidence, what production symptom would you expect from that alternative that this blueprint's design (§3) structurally avoids?
  12. Why is parallel Delaunay/hull construction deferred (§39, ADR-29 in §9) rather than built now, and which Scalability Analysis (§33) bottleneck moves to the top if it were un-deferred?
  13. How do the predicate/construction split (Principle 2, §6) and I18 (§7) jointly prevent the bug class a naive Voronoi implementation (circumcenter feeding back into incircle) would hit — trace the mechanism through §8.11 and §20.
  14. Why is Guibas–Stolfi's quad-edge paper (P9, §5) applied at both §8.8 (domain model) and as the Phase 7 alternate (§19), while Fortune's paper (P8) is applied only at §20 — what does that difference say about which paradigm is load-bearing versus oracle-only in this design?
  15. Using the M-table (§32) and the Capacity Model (§36), compute the minimum wall-clock to both build a 50M-point Delaunay mesh and run the full exact-vs-filter differential (§24) over 10⁹ inputs on a single core — which dominates, and why does that justify sharding the differential across cores (§32) but not the Delaunay build (§33)?
  16. Why does the Threat Model (§26) classify memory-corruption/UAF as "structurally absent" rather than "mitigated," and how does that claim depend on a specific ADR (§9) a C++ reimplementation could not make the same way?
  17. If you had to add a new predicate (e.g. a 2D same-side-of-a-parabola test), walk through which sections (§13 stage design, §14 SoS term ordering, §7 invariant table) you would touch, and in what order, to keep I1 and I12 intact.
  18. Why does the Deferred Features Register (§39) anchor "3D Delaunay/Voronoi" to Phase 11 (§23) rather than to a wholly new phase, and what does that anchoring choice reveal about how much of Phase 11's conflict-graph machinery would actually be reusable?

34. Mental Models & First Principles

The compressed insights an expert holds — not the algorithms themselves, but the intuitions that make the algorithms inevitable.

# Insight Predicts Bug class without it Resolving §
MM1 A predicate's sign is not a floating-point value — it's a certified fact. Once a Sign is returned, it is a claim exact real arithmetic would also make. Any code path that "peeks" at a raw f64 determinant instead of going through the staged evaluator will eventually classify a real input wrong. Intermittent hull/triangulation corruption near collinear/cocircular data that "can't be reproduced" because it depends on rounding at one call site but not another. §13
MM2 Error bounds scale with the determinant's permanent (sum of absolute products), not with the determinant's own value — so filter validity has a coordinate-magnitude ceiling. Predicates need more escalation, not fewer, as coordinates approach the 2⁵¹–2⁵³ range. A system that assumes filters "just work" at any coordinate scale, then sees misclassifications only at large magnitudes — the hardest kind of bug to reproduce in a small test. §4, §13
MM3 An expansion is a ledger of exact partial sums, not a rounded number — its "value" is only ever read through the sign of its top (largest-magnitude) component. Any operation that violates the non-overlapping/sorted invariant (I15) corrupts sign extraction silently, with no symptom until a degenerate fixture exercises it. A subtly wrong expansion_sum/scale_expansion variant that passes ordinary tests but fails only the cocircular/collinear conformance fixtures. §13, I15
MM4 Degeneracy elimination is a total function, not an exception handler — SoS gives "the determinant is exactly zero" its own deterministic answer, not a special case to catch. Any code that special-cases "if collinear then X" instead of asking SoS is a second, likely-inconsistent, source of truth. Two algorithms disagree on the same degenerate input because one hand-rolled a tie-break and one asked SoS — an intermittent, input-order-dependent bug. §14
MM5 A planar subdivision's truth lives in its adjacency, not its coordinates — DCEL/quad-edge invariants (twin/next/prev, Euler) are the actual correctness test; coordinates may jiggle from construction rounding and the topology is still valid or not. Any mutation that cannot be expressed as Splice/local half-edge surgery is a topology bug waiting to happen. A corrupted face cycle that manifests only as a wrong V−E+F count several algorithms downstream of the mutation that broke it. §8.7, §8.8, §18, §19
MM6 A sweepline is one machine wearing three costumes — Bentley–Ottmann, Fortune, and Martínez share one event-queue + status-structure contract with a different event vocabulary and status-ordering predicate. Debugging one sweep's degenerate-event grouping transfers directly to the other two. Reinventing event-queue tie-breaking per algorithm instead of recognizing the shared contract, tripling the surface area for off-by-one degeneracy bugs. §17, §20, §22
MM7 The lifting map turns "is it inside a circle" into "is it below a plane" — incircle in 2D is orient3d on paraboloid-lifted points; they are the same object viewed from two dimensions. A bug affecting orient3d's error-bound derivation likely has a shadow bug in incircle, and vice versa. An insphere/incircle discrepancy that looks unrelated to a 3D-hull bug until someone notices both determinants share a derivation shape. §8.1, §19, §23
MM8 Determinism is a budgeted resource, not a default — reproducibility requires pinning the RNG seed, the FP environment (no FMA contraction/fast-math), and the constant table together; any one drifting breaks bit-for-bit reproducibility even with unchanged source. A toolchain upgrade that silently enables FMA changes topology on some inputs without a single source line changing. A "flaky" test that is actually a nondeterministic build, misdiagnosed as a race condition. §12, I17, §29

Glossary (§40) · 44 terms · site-wide glossary

EGC
Exact Geometric Computation — compute coordinates approximately but every predicate sign exactly; the project's central discipline.
Predicate
A function returning the sign (∈ {−1,0,+1}) of a geometric determinant; the load-bearing decision, never the magnitude.
Construction
A function producing new (necessarily inexact) coordinates (intersection point, circumcenter); rounding error is confined here (I18).
orient2d
Sign of twice the signed area of triangle abc; left/right/collinear test (§8.1).
incircle
Sign deciding whether d is inside the circumcircle of CCW a,b,c; the Delaunay test (§8.1).
orient3d
Sign deciding whether d is above/below the plane of a,b,c; engine of the lifting map (§8.1).
insphere
Sign deciding whether e is inside the circumsphere of a,b,c,d (§8.1).
Adaptive precision
Shewchuk's staged evaluation: fast filter → interval → adaptive expansion → exact, stopping as soon as the sign is certain (§8.5).
Filter
The fast stage-A f64 computation with an a-priori error bound; resolves >99.9% of calls.
Error bound
The a-priori threshold (coeff·permanent) above which the f64 sign is provably correct (§8.5).
Permanent
A sum of absolute products from a determinant, used to scale the error bound.
EFT
Error-Free Transformation — two_sum/fast_two_sum/split/two_product; compute a result plus its exact rounding error (§8.3).
Expansion
A real represented as a non-overlapping, magnitude-sorted f64 sequence; supports exact + − × (§8.4, I15).
Interval arithmetic
Directed-rounding [lo,hi] bounds used as a cheap stage-B filter.
SoS
Simulation of Simplicity — symbolic perturbation +ε^(2^k) that makes every input general-position, eliminating degeneracy (§8.6, I12).
Degeneracy
A configuration where a determinant is exactly zero (collinear/cocircular/coincident/cospherical); eliminated by SoS, not special-cased.
General position
An input with no degeneracies; SoS makes every input behave as if in general position.
DCEL
Doubly-Connected Edge List — half-edge representation of a planar subdivision (§8.7, I5).
Half-edge
One of two oppositely-directed edges; stores origin/twin/next/prev/face.
Quad-edge
Guibas–Stolfi self-dual structure (four directed edges); MakeEdge/Splice (§8.8, I13).
Euler's formula
V − E + F = 2 for a connected planar subdivision (incl. outer face); a runtime self-check (I4).
Convex hull
The smallest convex polygon containing all input points; built by monotone chain (§8.9, I6).
Monotone chain
Andrew's O(n log n) hull: sort, build lower then upper chain via orient2d.
Delaunay triangulation
The triangulation where no vertex lies inside any triangle's circumcircle (empty-circumcircle, I3).
Bowyer–Watson
Randomized incremental Delaunay: locate → cavity → delete → retriangulate (§8.10).
Cavity
The set of triangles whose circumcircle contains an inserted point; star-shaped from it (I9).
Lawson flip
An edge flip restoring local Delaunay-ness; the flip-based view of insertion.
History DAG
Delaunay-tree of created/destroyed triangles; O(log n) expected point location (§8.10).
Point location
"Which face contains query q?"; via history DAG or straight-line walk; must terminate (I10).
Voronoi diagram
Partition of the plane into nearest-site cells; the geometric dual of Delaunay (§8.11, I14).
Circumcenter
The center of a triangle's circumcircle; a Voronoi vertex (a Constructed).
Lifting map
(x,y) ↦ (x,y,x²+y²); turns incircle into orient3d and Delaunay into a 3D lower hull (§8.1).
Bentley–Ottmann
Sweepline reporting all k segment intersections in O((n+k) log n) (§8.12, I8).
Sweepline
A moving line with an event queue + a status structure ordered along it; the shared paradigm of Phase 5/8/10 (§17/§20/§22).
Status structure
The balanced BST of objects currently crossing the sweep line, ordered along it.
Event queue
The priority queue of sweep events (endpoints, intersections, site/circle events).
Arrangement
The planar subdivision induced by a set of segments and their intersections.
CDT
Constrained Delaunay Triangulation — Delaunay subject to required (non-flippable) edges (Phase 9, §21).
Boolean op
Polygon set algebra ∪/∩/∖/⊕ via the Martínez sweepline (§8.13, I7).
WKT / WKB
OGC Well-Known Text / Binary geometry interchange formats (§8.15).
Fortune's algorithm
Direct sweepline Voronoi construction via a beach line of parabolic arcs (§8.11).
ulp
Unit in the last place — the spacing between adjacent f64s; the granularity of near-degenerate perturbation.
Catastrophic cancellation
Loss of significance when subtracting nearly-equal f64s; why naive determinant signs fail (§8.2).
FMA contraction
Fusing a*b+c into one rounded op; breaks EFT exactness — forbidden in num/predicates (Principle 9).
