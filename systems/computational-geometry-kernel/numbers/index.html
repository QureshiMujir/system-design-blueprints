RNG a single seeded, recorded PRNG for randomized incremental order seed in telemetry; reproducible
Startup library init O(1); no global mutable state Send + Sync value types
Thread-safety predicates pure/reentrant; meshes are single-owner (&mut) parallel hull/Delaunay deferred
no_std core zero heap on the predicate hot path; num+predicates build no_std algorithm layer uses std/alloc

Non-targets: distributed operation; persistence/durability; networking; GPU acceleration; concurrent mutation of a single mesh. Coordinates are planar/3-space Cartesian f64; no projections.
