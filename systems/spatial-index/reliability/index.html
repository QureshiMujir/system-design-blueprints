Invariants — what must never be false (§7) · 7

Invariants — what must never be false
FieldDetail
StatementEvery R-tree node's stored MBR equals the tight union of its direct children's MBRs; every object in the node's subtree is spatially contained within the node's MBR.
Why it mattersPruning soundness: if !intersects(node.mbr, query_rect) is true, zero objects in the subtree can match — this is the fundamental correctness guarantee of tree-based spatial search.
Where enforcedsidx-rtree adjust_tree (post-insert MBR propagation); condense_tree (post-delete MBR shrink); sidx-bulk STR leaf/internal MBR construction; sidx-rstar reinsertion path.
DetectionPost-mutation audit function in tests: recursively recompute union of all children's MBRs, assert == node.mbr; differential oracle comparison catches false negatives caused by I1 violation.
Telemetrymbr_mismatch_count counter incremented in audit function; logged with node id, level, stored MBR, computed MBR.
RecoveryOffline repair: walk tree bottom-up, recompute and overwrite MBRs; mark all affected pages dirty in sidx-persist; this is a maintenance tool, not a runtime recovery path.
DebugBinary search on mutation history to find the earliest violation; print the (node_id, stored_mbr, computed_mbr) triple; check the AdjustTree call that was skipped or computed incorrectly.
