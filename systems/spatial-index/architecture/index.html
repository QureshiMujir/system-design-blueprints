3.2 Subsystem Descriptions

sidx-core / sidx-geom — geometry foundation. sidx-core defines all shared types: Point<D>, Rect/MBR, NodeId(u32), DataId(u64), Entry, RTreeNode, QuadNode, GeoHash, KnnItem, Query, SplitStrategy, BulkLoad. No I/O, no algorithms. sidx-geom provides the MBR algebra every tree depends on: union (tight bounding of two rects), intersection predicate, area/volume, enlargement (area increase to absorb a new rect — drives ChooseLeaf), overlap area (drives R* split axis choice), contains predicate, and the two distance bounds mindist(point, rect) and minmaxdist(point, rect) that make kNN pruning sound. All other crates import these; the geometry boundary is strict — no tree logic leaks into sidx-geom. Data flows in as Rect pairs; results flow out as scalars (f64) or predicates (bool).

sidx-rtree — R-tree node storage and core operations. Owns an arena Vec<RTreeNode> indexed by NodeId; the root handle is a NodeId. Insert executes ChooseLeaf (least-enlargement descent), adds the Entry, and on overflow (entries > M) splits via quadratic or linear algorithm, propagating splits and MBR adjustments (AdjustTree) up to the root. Window search recurses, pruning subtrees whose MBR does not intersect the query rect; returns Vec<DataId>. Delete finds the leaf entry, removes it, executes CondenseTree (collect orphaned entries from under-full nodes, reinsert them), adjusts MBRs upward. Height is maintained by level bookkeeping; root split increases height. Trust boundary: callers must provide valid Rects; degenerate input (min > max) is normalized by sidx-geom before entry.

sidx-rstar — R-tree split and reinsertion overlay.* Replaces ChooseLeaf with choose-subtree (overlap-enlargement minimization at the leaf level; area-enlargement above). Replaces the quadratic split with R* split: sort entries by each axis, evaluate margin sum, select the axis minimizing margin, then choose the split index minimizing overlap (area as tiebreaker). On first overflow at each level during a single insert, invokes forced reinsertion of the p closest-to-center entries rather than splitting immediately. SplitStrategy::RStar selects this path in sidx-rtree. No new arena; delegates node storage entirely to sidx-rtree. The overlay boundary is the SplitStrategy enum dispatch in the insert path.

sidx-bulk — Sort-Tile-Recursive (STR) bulk loader. Accepts a slice of (Rect, DataId) pairs; produces a fully built R-tree via sidx-rtree arena. Algorithm: compute slice count S = ceil(sqrt(n/M)); sort all rects by x-center into S vertical slices; within each slice sort by y-center; pack consecutive M rects into leaf nodes; recurse one level up until root. Builds near-optimal, high-occupancy static trees far faster than repeated insertion. Output is a read-mostly tree rooted at a NodeId in the shared arena. Concurrency boundary: single-threaded; parallelism of sort passes is PhaseDeferred.

sidx-quadtree — point / region (PR) quadtree. Maintains its own arena of QuadNode: each node is either a Leaf(Vec<(Point, DataId)>) or Internal([NodeId; 4]). Insert: find the leaf whose bounds contain the point; if capacity exceeded, subdivide into four equal quadrants and redistribute entries. Point query: exact match by coordinate. Range query: recursive quadrant overlap test, collect all DataId entries from overlapping leaves. Depth is bounded to prevent infinite subdivision on duplicate/collocated points (degenerate case: bucket all collocated points into one leaf). Partition invariant I9 (children exactly partition parent bounds, no overlap, no gap) is enforced on subdivision. The quadtree is independent of the R-tree arena; it uses its own NodeId namespace.

sidx-geohash — geohash codec. Encodes a (lat, lng) pair by interleaving longitude bits (even) and latitude bits (odd) into a 64-bit integer, then base32-encoding to a string of given precision (1–12 chars). Decodes a string back to a bounding Rect (the cell). Precision controls cell size (precision 1 ≈ 5000 km × 5000 km; precision 12 ≈ 3.7 mm × 1.9 mm). Computes the 8 neighbor cell hashes (N, NE, E, SE, S, SW, W, NW) including boundary carry logic. For a query bounding box, returns the set of prefix strings whose union covers the box — enabling prefix-range scans on ordered key stores. The codec has no tree state; it is a pure function layer. Invariant I8: decoded cell always contains the original point.

sidx-knn — best-first kNN search. Implements a min-heap (BinaryHeap<KnnItem>) keyed by mindist(query_point, node_mbr). Pop the nearest unvisited node; if it is a leaf, emit its DataId entries into a k-element result max-heap, pruning any entry farther than the current k-th distance. If it is an internal node, push all children with their MINDIST. Prune a child if mindist(point, child_mbr) >= current_k_dist. Use minmaxdist to tighten the upper bound: if another node's MINMAXDIST < a candidate's MINDIST, the candidate cannot improve the result. Terminates when the heap is empty or all remaining nodes have MINDIST > current k-th dist. Returns exactly the k nearest DataId values with their distances. Correctness gate: result must match sidx-oracle kNN on every test case (I5).

sidx-query — unified query dispatch layer. Exposes a single Query enum: Window(Rect), Intersect(Rect), Contains(Rect), Knn(Point, usize), Nearest(Point). Dispatches to sidx-rtree, sidx-rstar, sidx-quadtree, or a geohash-prefilter + tree-refine pipeline depending on the index handle. Intersection semantics: any overlap between object MBR and query rect. Containment semantics: query rect fully contains object MBR. Window semantics: alias for intersection in this implementation (per Guttman). Normalizes result types across index kinds; callers see Vec<DataId> or Vec<KnnItem> uniformly. Concurrency boundary: read-only query paths are logically re-entrant; the dispatch layer itself holds no mutable state.

sidx-oracle — brute-force correctness reference. Maintains a flat Vec<(Rect, DataId)> or Vec<(Point, DataId)>. Implements every query type via linear scan. Used exclusively in tests and benchmarks, never in production code paths. Correctness gate: for every randomized dataset and query, sidx-rtree/sidx-rstar/sidx-quadtree results must equal the oracle's results (set equality for window/intersect/contains; ordered-by-distance equality for kNN). A discrepancy is a bug in the index, never in the oracle.

sidx-persist — page-aligned disk persistence. Serializes each RTreeNode into a fixed-size Page (configurable: 4 KiB or 8 KiB). PageId mirrors the NodeId arena index; the page file is a flat array of pages. An in-memory LRU page cache (capacity configurable) holds hot nodes; cache miss triggers a page read from the file. Dirty pages are written back on eviction or explicit flush. On cold start, the root NodeId is read from the header page; the tree is traversed on-demand. Node format includes: magic bytes, format version, level, entry count, entries (each: MBR as 4×f64, child NodeId or DataId as u64). Persistence boundary: sidx-rtree and sidx-rstar talk to the arena through a NodeStore trait; sidx-persist provides the disk-backed implementation; in-memory tests use a Vec-backed implementation.

sidx-cli — command-line tool. Subcommands: build (bulk-load or sequential-insert from CSV/binary input into an index file), insert (single or batch insert into an existing file), query (window/intersect/contains over a persisted index), knn (k nearest neighbors), bench (throughput/latency benchmark over configurable object count and query selectivity). Selects index type via --index {rtree|rstar|quadtree} flag. Outputs results as newline-delimited DataId values or JSON. Trust boundary: validates and normalizes all CLI input; propagates errors to stderr without panicking.

8.3 R-tree State Machine

States apply per RTreeNode; transitions driven by insert/delete operations.

State labels:
  EMPTY    — newly allocated node, 0 entries (root only)
  UNDER    — entries < m (non-root: triggers condense)
  NORMAL   — m <= entries <= M
  OVER     — entries == M+1 (transient; split fires immediately)

Transitions:
  EMPTY  --insert(1st entry)-->  NORMAL  (if root stays leaf with >=1 entry)
  NORMAL --insert--> NORMAL      (while count < M)
  NORMAL --insert--> OVER        (count reaches M+1)
  OVER   --split-->  NORMAL + NORMAL   (two M/2..M nodes; parent gains one entry)
  NORMAL --delete--> UNDER       (count drops below m, non-root)
  UNDER  --condense--> [removed; entries reinserted at root level]
  NORMAL --delete--> EMPTY       (root leaf, all entries removed)
  OVER   (never persists; always resolved within the same operation)

Root special case: root can hold 1 entry when it is a leaf (height 0) and must have >= 2 entries when it is an internal node. If root splits, height increases by 1.

8.4 R*-tree Forced Reinsertion State

Reinsertion fires at most once per level per insert call. Track with a per-call bitmask reinserted: [bool; MAX_HEIGHT].

On overflow at level L:
  if reinserted[L] == false:
    reinserted[L] = true
    remove p farthest-from-center entries from the node
    re-insert those p entries via normal insert (reusing same reinserted mask)
  else:
    perform R* split (no further reinsertion at this level)

p = 30% of M (Beckmann et al. recommendation). Reinsertion reduces overlap across sibling nodes, improving future query fan-out.

8.5 ChooseLeaf / Choose-Subtree Semantics

R-tree ChooseLeaf(rect R, node N):
  if N.level == 0: return N          // leaf
  select child C minimizing enlargement(C.mbr, R)
  tie-break: smallest area
  recurse into C

R*-tree choose-subtree(rect R, target_level L, node N):
  if N.level == L+1:                 // children are at target level
    if L == 0 (children are leaves):
      select C minimizing overlap_enlargement(C.mbr, R, siblings)
      tie-break: area_enlargement, then area
    else:
      select C minimizing area_enlargement(C.mbr, R)
      tie-break: area
  else:
    select C minimizing area_enlargement(C.mbr, R)   // higher levels
  recurse

8.6 Split Algorithm Semantics

8.6.1 Quadratic Split (Guttman 1984)

PickSeeds: for each pair (i,j) of entries, compute d = area(mbr(i,j)) - area(i) - area(j);
           seeds = pair maximizing d (worst waste if placed together)
PickNext:  for each unassigned entry, compute diff = |area_increase_if_in_group1 - area_increase_if_in_group2|;
           assign to group with smaller increase; tie: smaller size, then first group
Terminate: stop when all assigned or one group needs all remaining to meet m

8.6.2 R* Split (Beckmann et al. 1990)

For each axis a in [0..D):
  sort entries by low[a], also by high[a] → 2*D sort orders
  for each order and each split index k in [m..M-m]:
    compute margin(k) = perimeter(mbr(group1)) + perimeter(mbr(group2))
  sum_margin[a] = sum of all margin values for axis a

choose_split_axis = axis minimizing sum_margin
along chosen axis: choose k minimizing overlap(group1,group2); tie: minimizing area

8.7 CondenseTree Algorithm

CondenseTree(leaf node N):
  path = ancestor path from N to root
  Q = empty list of orphan entries
  for each node N' on path bottom-up (excluding root):
    if N'.entries.len() < m:
      remove N' from parent
      Q += N'.entries (with their level tags)
    else:
      adjust parent.entry.mbr to tight union of N'.entries
  reinsert all entries in Q at their respective levels (level-tagged reinsert)
  if root has exactly one entry and is not leaf: collapse root, decrease height

8.8 STR Bulk Load Semantics

Input: n Rect objects with DataIds
Parameters: M (node capacity), m (min occupancy)
S = ceil(sqrt(n / M))    // number of vertical slices

1. Sort all n rects by x-center (or x-min) ascending
2. Partition into S slices of ceil(n/S) rects each
3. Within each slice, sort by y-center (or y-min)
4. Pack consecutive M-sized groups into leaf nodes → leaf level
5. Repeat steps 1-4 on the MBRs of leaf nodes → next level
6. Continue until one root node covers all children

Invariants: all leaves at level 0; every non-root node has between m and M entries; root may have fewer. Expected tree height = ceil(log_M(n)).

8.9 kNN Best-First Algorithm

Input: query point Q, integer k, R-tree root
Structures:
  PQ  = min-heap keyed by MINDIST(Q, node.mbr) or 0 for root
  RES = max-heap (size k) keyed by distance to Q

Algorithm:
  push (0.0, root) into PQ
  while PQ non-empty:
    (d_low, item) = PQ.pop()
    if d_low > RES.peek_max() and |RES| == k: break   // prune
    if item is leaf entry (DataId):
      dist = euclidean(Q, entry.point_or_mbr_centroid)
      if |RES| < k or dist < RES.peek_max():
        RES.push(dist, DataId); if |RES| > k: RES.pop_max()
    else (NodeId):
      for each child entry E in node(item):
        d = MINDIST(Q, E.mbr)
        if |RES| < k or d < RES.peek_max():
          PQ.push(d, E.child)
  return RES as sorted list

MINMAXDIST used for upper-bound pruning: if MINMAXDIST(Q, node.mbr) < current k-th distance, then at least one object in the subtree is definitely closer; conversely if MINDIST > k-th distance, entire subtree pruned.

8.10 MINDIST and MINMAXDIST Formulae (2D; generalize to D)

// Point p = (px, py), Rect R = [rx1,rx2] x [ry1,ry2]

MINDIST(p, R):
  ri_x = if px < rx1 then rx1 elif px > rx2 then rx2 else px
  ri_y = if py < ry1 then ry1 elif py > ry2 then ry2 else py
  return sqrt((px-ri_x)^2 + (py-ri_y)^2)
  // = 0 if p is inside R

MINMAXDIST(p, R):
  // for each axis a: rmk[a] = the endpoint of R on axis a farthest from p
  //                  rmi[a] = the closer endpoint on all OTHER axes to p
  // MINMAXDIST = min over axes a of (dist using rmk[a] on a, rmi on others)
  // Ensures: at least one object in R is at distance <= MINMAXDIST

Invariant I6: MINDIST(p,R) <= dist(p, nearest_object_in_R) <= MINMAXDIST(p,R) always holds.

8.11 Geohash Encoding Model

EBNF (logical bit-interleaving):
  geohash_bits(lat, lng, precision):
    total_bits = 5 * precision
    for i in 0..total_bits:
      if i is even: encode next longitude bit (MSB first in [-180,180])
      if i is odd:  encode next latitude bit  (MSB first in [-90, 90])
    base32_encode(collected_bits, precision)  → string of length precision

base32 alphabet: "0123456789bcdefghjkmnpqrstuvwxyz"  (32 chars; omits a,i,l,o)

Decode: reverse the above → cell Rect [lng1,lng2] x [lat1,lat2]
Cell area ≈ (360/2^(bits/2)) x (180/2^(bits/2)) degrees² for even precision

Neighbor cells: for each of the 8 compass directions, adjust the interleaved bit pattern to select the adjacent cell, handling boundary carry-over at ±180° longitude and ±90° latitude.

Prefix range: all geohash strings with prefix P cover a rectangular region (may be a multi-prefix union for irregular shapes; see Phase 10 for exact prefix computation).

8.12 Quadtree Subdivision Model

QuadNode(bounds = [x1,x2] x [y1,y2]):
  mid_x = (x1+x2)/2
  mid_y = (y1+y2)/2
  quadrant 0 (NW): [x1,mid_x] x [mid_y,y2]
  quadrant 1 (NE): [mid_x,x2] x [mid_y,y2]
  quadrant 2 (SW): [x1,mid_x] x [y1,mid_y]
  quadrant 3 (SE): [mid_x,x2] x [y1,mid_y]

Invariant I9: four children exactly tile the parent with no gap, no overlap. union(Q0,Q1,Q2,Q3) == parent.bounds and intersects(Qi, Qj) == false for i!=j.

Region-point ambiguity at boundary: a point on the split line is assigned to the lower-index quadrant consistently (NW before NE, N before S).

8.13 Unified Query Dispatch Semantics

Query Variant Predicate R-tree pruning rule Quadtree pruning Geohash filter
Window(R) obj.mbr intersects R skip node if node.mbr disjoint R skip quadrant if disjoint compute prefix set covering R; discard non-matching
Intersect(R) obj.mbr intersects R identical to Window identical same prefix set
Contains(R) obj.mbr contains R skip node if node.mbr cannot contain R (node.mbr smaller than R) skip if quadrant cannot contain R prefix of R's cell; refine
Knn(p,k) k nearest by dist MINDIST-based best-first heap (Phase 8) recurse by MINDIST to quadrant decode to rect; nearest cell first
Nearest(p) 1 nearest Knn(p,1) same same

Intersect vs Window: semantically identical for MBR-indexed objects (MBR intersects query rect). Contains differs: filter inverted (object must contain query rect, not merely intersect).

8.14 Persistence / Page Layout

Page format (PAGE_SIZE = 4096 bytes):
  Offset  Size  Field
  0       4     magic: 0x53494458 ("SIDX")
  4       2     format_version: u16
  6       2     node_level: u16  (0=leaf)
  8       2     entry_count: u16
  10      2     flags: u16  (bit0=dirty, bit1=pinned)
  12      4     parent_page_id: u32
  16      4*D*2 per-entry MBR (D=2 → 32 bytes per entry MBR)
  ...     var   child/data IDs (4 bytes NodeId or 8 bytes DataId per entry)
  ...     pad   zero-fill to 4096

Max entries per page at D=2: floor((4096 - 16) / (32 + 8)) = 101; set M=100 by default for clean occupancy.

LRU page cache: capacity in pages configurable; dirty pages written on eviction or explicit flush. Cache hit ratio tracked for observability (P10).

8.15 Worked Example — Insert and Split

Config: M=3, m=1, D=2, SplitStrategy::Quadratic

Initial tree: root (leaf, level=0) with 3 entries:
  E1: mbr=[0,0,2,2], DataId(1)
  E2: mbr=[1,1,3,3], DataId(2)
  E3: mbr=[5,5,7,7], DataId(3)

Insert DataId(4) with mbr=[6,6,8,8]:
  ChooseLeaf → root (only leaf)
  root.entries.len() == 4 > M=3 → overflow → split

PickSeeds (quadratic):
  pairs and waste:
    (E1,E2): area([0,0,3,3])=9  - area(E1)=4 - area(E2)=4 = 1
    (E1,E3): area([0,0,7,7])=49 - 4 - 4 = 41
    (E1,E4): area([0,0,8,8])=64 - 4 - 4 = 56   ← seeds: E1 and E4
    (E2,E3): area([1,1,7,7])=36 - 4 - 4 = 28
    (E2,E4): area([1,1,8,8])=49 - 4 - 4 = 41
    (E3,E4): area([5,5,8,8])=9  - 4 - 4 = 1

Seeds: E1 → Group1, E4 → Group2

Distribute E2: enlargement to G1 = area([0,0,3,3])-4 = 5; to G2 = area([1,1,8,8])-4=41; → G1
Distribute E3: enlargement to G1 = area([0,0,3,3] union [5,5,7,7])-9=40; to G2 = area([5,5,8,8])-4=5; → G2

Result:
  Node A (leaf): [E1(mbr=[0,0,2,2]), E2(mbr=[1,1,3,3])]; node.mbr=[0,0,3,3]
  Node B (leaf): [E4(mbr=[6,6,8,8]), E3(mbr=[5,5,7,7])]; node.mbr=[5,5,8,8]

New root (internal, level=1):
  Entry(mbr=[0,0,3,3], child=NodeA)
  Entry(mbr=[5,5,8,8], child=NodeB)

Verify I1: root.mbr = union([0,0,3,3],[5,5,8,8]) = [0,0,8,8] ✓
Verify I2: both leaves at level 0 ✓
Verify I3: both nodes have 2 entries, m=1<=2<=M=3 ✓
Verify I7: DataIds {1,2,3,4} all present, none duplicated ✓

8.16 Failure-Path Example — MBR Violation (Malformed Input)

Attempted insert: rect = [5,3,2,8] (min[0]=5 > max[0]=2 — axis-0 inverted)
Expected behavior: sidx-geom::Rect::new() returns Err(MalformedRect)
  or normalizes to [2,3,5,8] with a debug warning

If normalization is silently wrong and [5,3,2,8] is stored:
  I1 violated: any query with rect [3,4,4,6] should match the object,
  but MINDIST computed against [5,3,2,8] is undefined / garbage
  → false negative in window search
  → oracle mismatch detected by sidx-oracle differential test (Phase 14)

Enforcement: Rect::new(min,max) asserts min[i]<=max[i] for all i; panic or Result::Err in debug; normalize in release with metric counter increment.

8.17 Edge Cases

Edge Case Expected Behavior
Point objects (zero-area MBR) min == max; valid degenerate rect; MBR union with siblings works normally
Duplicate points in quadtree all placed in same leaf; leaf may exceed capacity; depth-bounded split degenerates to list at MAX_DEPTH
Query rect fully inside one node single path descent; no fan-out
Query rect spanning entire space every node visited; result = all objects
k > total object count return all objects, sorted by distance
Empty tree kNN return empty Vec
Geohash at ±90° latitude boundary bit pattern saturates; neighbor computation clamps and wraps
Geohash at ±180° longitude boundary neighbor wraps around; prefix range spans two string ranges
Delete non-existent DataId return NotFound; tree unchanged; no invariant violation
STR bulk load n=0 return empty tree (height=0, root is empty leaf)
STR bulk load n=1 single leaf with one entry; root is leaf
Root with single internal child collapse: that child becomes new root; height--
f64 NaN in coords rejected at Rect::new; sidx-core returns Err(NonFiniteCoord)

8.18 Memory / Ownership Model

Arena ownership (sidx-rtree, sidx-quadtree):
  Vec<RTreeNode<D>> arena owns all nodes; NodeId indexes into it
  No raw pointers; no reference cycles possible
  Insert/delete may reallocate arena Vec → all NodeIds remain stable
    (arena uses push/swap-remove; NodeId remapping table required for delete)

Alternatively: slab crate for stable-index arena (preferred; see ADR-09)

Query result lifetime:
  search returns Vec<DataId>; caller owns; no borrow into arena

Page cache (sidx-persist):
  Arc<Mutex<PageCache>> shared between read and write paths
  Dirty bit per page; flush-on-eviction
  No unsafe; Box<[u8; PAGE_SIZE]> per page

STR bulk load:
  Builds a temporary Vec<Rect> of all inputs in memory;
  final arena handed off to RTree struct; temp Vec dropped
