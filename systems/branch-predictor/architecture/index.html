Trace Sources. External, untrusted. Intel PT captures, synthetic generators, compiler instrumentation, or bp-fuzz-produced pathological streams. This is a hard trust boundary (T1): malformed traces must not reach the simulation core in any form.

bp-trace. Owns parsing, zstd decompression (ADR-24), validation, canonicalization, and monotonic sequence assignment. Enforces schema compatibility (P15) and rejects malformed input deterministically — the schema boundary between untrusted bytes and typed BranchEvents.

bp-replay. Deterministic event scheduler; assigns a globally monotonic replay-sequence ID (I1) to every event; isolates simulated timing from wall-clock behavior (P1). This is the concurrency boundary: NUMA-partitioned worker threads synchronize only through this layer.

bp-sim. Models fetch-stage interaction with the predictor layer: query dispatch, speculative update application, retire-time training, and rollback coordination on misprediction. Separates architectural correctness from predictor experimentation (P10).

bp-history / bp-btb / bp-ras. Three co-equal speculative-state stores queried per fetch: global and local history (folded, snapshot-rollback-capable), branch-target cache (set-associative, tagged), return-address stack (speculative push/pop). Each independently satisfies rollback correctness (I4).

Predictor Layer. Isolated behind the Predictor trait (ADR-23): bimodal, gshare, perceptron, TAGE, and hybrid/chooser composition. Predictors never own simulator state directly (P10) — they receive PredictorContext and return BranchPrediction.

bp-metrics. Collects MPKI, accuracy, confidence distribution, aliasing pressure, rollback frequency, and queue occupancy; exports Prometheus-format series (ADR-13) and OpenTelemetry-shaped trace spans (ADR-12). This is the observability seam — every anomaly upstream must surface here.

bp-checkpoint. Persistence boundary: append-only, mmap-backed, checksum-verified, schema-tagged snapshots (P12). The only subsystem permitted durable side effects.

Operator Interfaces. bp-cli, bp-bench, Grafana dashboards, CI gates. Every operational artifact they produce must be reproducible byte-for-byte given the same trace and config (P1).

8. Domain Model — Branch Event & Predictor Protocol

Branch event record (as ingested by bp-trace, one per dynamic branch):

BranchEvent — sequence_id: u64, instruction_pointer: u64, branch_type: BranchType,
  target_address: u64, taken: bool, privilege_level: u8, thread_id: u32, timestamp: u64

Branch types.

Type Description Predictor Path
Conditional direction-dependent, PC + history indexed bimodal / gshare / perceptron / TAGE
Unconditional always taken, target-only BTB only
Indirect computed target, no static destination BTB indirect slot (ITTAGE deferred, §35)
Return RAS-predicted target bp-ras pop
Call pushes return address bp-ras push

Predictor query lifecycle (per fetch, driving ReplayEvent state):

Show the original text diagram
FETCH -> QUERY -> SPECULATIVE_UPDATE -> EXECUTE -> RETIRE -> TRAIN
                                    \-> MISPREDICT -> ROLLBACK -> RETRAIN

Saturating counter state machine (bimodal/gshare direction state, 2-bit):

Show the original text diagram
00 Strong-NotTaken <-> 01 Weak-NotTaken <-> 10 Weak-Taken <-> 11 Strong-Taken

Transitions increment toward 11 on taken, decrement toward 00 on not-taken; bounded at both ends (I5).

TAGE tagged-table entry layout (bp-tage, one per geometric-history table):

TageEntry — tag: u16, ctr: i8, usefulness: u8, history_length_class: u8

Replay event sequencing (canonical per-event pipeline through the whole system):

  1. trace event ingest (bp-trace)
  2. normalization (canonical field ordering, timestamp rebasing)
  3. fetch dispatch (bp-sim)
  4. predictor lookup (predictor layer)
  5. speculative update (bp-history/bp-btb/bp-ras)
  6. retirement (bp-sim)
  7. training (predictor layer, retire-time)
  8. metrics flush (bp-metrics)

Malformed-trace taxonomy (rejected by bp-trace validator, I11): sequence-ID regression; negative/backwards timestamp; invalid branch-type discriminant; misaligned instruction pointer (non-multiple-of-instruction-width); truncated record; checksum mismatch.

Canonical failure path (BTB miss cascading to rollback):

Show the original text diagram
BTB miss -> fallback target (sequential/predicted-not-taken) -> speculative execution
  -> retire-time target mismatch -> rollback (I4) -> predictor retraining
