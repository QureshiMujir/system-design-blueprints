pqtool CLI — thin command dispatcher; calls parquet_codec + orc_codec public APIs; no format logic here; used for manual inspection, differential testing, and operator runbooks.

parquet_codec facade — public entry point; owns ParquetReader (footer-driven navigation, predicate evaluation, page iteration) and ParquetWriter (schema ingestion, row-group lifecycle, footer serialization); enforces all invariants at the boundary.

parquet_core — file anatomy: magic verification, footer byte-range read, Thrift deserialization into FileMetaData; schema element tree into SchemaNode DAG; row-group + column-chunk descriptors; page header parsing (DataPageHeaderV1/V2, DictionaryPageHeader); PageIndex (ColumnIndex + OffsetIndex) parsing; Bloom filter block reader; Dremel R/D assembly FSM.

parquet_encoding — stateless encode/decode functions per encoding type; no I/O; operates on &[u8] / Vec<u8>; encoding-selection heuristic module inspects value distribution and picks optimal encoding.

shared — Thrift compact protocol (read/write without generated code; field-ID-driven); bit-level reader/writer (LSB-first, arbitrary widths); CRC-32C computation; varint encode/decode.

#397 codec layer — external dependency boundary; Codec trait with compress/decompress + max_compressed_len; implementation provided by the compression project; per-page instantiation.

orc_codec — independent second-format crate; ORC postscript (last byte = PS length, then PS protobuf), file footer protobuf, stripe footers, column streams, integer RLEv2 decoder/encoder; structurally parallel to parquet_core but shares only shared:: primitives.

8. Domain Model / Protocol

8.1 Parquet File Layout (ASCII)

Byte 0                                                        EOF
┌────────┬──────────────────────────────────┬─────────────────────────────────┐
│ b0..3  │  BODY                            │  FOOTER                         │
│ PAR1   │  [row group 0 ... row group N-1] │ FileMetaData (Thrift compact)   │
│        │                                  │ + 4-byte footer_len (LE int32)  │
│        │                                  │ + PAR1 (4 bytes)                │
└────────┴──────────────────────────────────┴─────────────────────────────────┘

Row Group k:
┌────────────────────────────────────────────────────────────────┐
│  [column chunk 0 | column chunk 1 | ... | column chunk C-1]    │
└────────────────────────────────────────────────────────────────┘

Column Chunk c:
┌───────────────────┬────────────────────────────────────────────┐
│ optional dict page│  data page 0  |  data page 1  | ...        │
└───────────────────┴────────────────────────────────────────────┘

Page (v1):
┌──────────────────────────────┬──────────────────────────────────┐
│  PageHeader (Thrift compact) │  COMPRESSED(ENCODED(data))       │
└──────────────────────────────┴──────────────────────────────────┘

Page (v2):
┌──────────────────────────────┬──────────────────────┬──────────┐
│  DataPageHeaderV2 (Thrift)   │  uncompressed levels │ comp data│
└──────────────────────────────┴──────────────────────┴──────────┘
(V2: rep+def levels NOT compressed; values ARE compressed; CRC covers compressed_values)

8.2 Thrift FileMetaData (Compact Protocol, Abbreviated)

struct FileMetaData {
  1: required i32 version;           // 1 or 2
  2: required list<SchemaElement> schema;
  3: required i64 num_rows;
  4: required list<RowGroup> row_groups;
  5: optional list<KeyValue> key_value_metadata;
  6: optional string created_by;
  7: optional list<ColumnOrder> column_orders;
  8: optional EncryptionAlgorithm encryption_algorithm;
  9: optional binary footer_signing_key_metadata;
}

struct RowGroup {
  1: required list<ColumnChunk> columns;
  2: required i64 total_byte_size;
  3: required i64 num_rows;
  5: optional i64 file_offset;
  6: optional i64 total_compressed_size;
  7: optional i16 ordinal;
}

struct ColumnMetaData {
  1: required Type type;
  2: required list<Encoding> encodings;
  3: required list<string> path_in_schema;
  4: required CompressionCodec codec;
  5: required i64 num_values;
  6: required i64 total_uncompressed_size;
  7: required i64 total_compressed_size;
  9: required i64 data_page_offset;
  10: optional i64 index_page_offset;
  11: optional i64 dictionary_page_offset;
  12: optional Statistics statistics;
}

8.5 Dremel R/D Levels — Worked Example

Schema:

message MyRecord {
  optional group a {       // optional → max_def contributes 1
    repeated group b {     // repeated → max_rep contributes 1, max_def contributes 1
      optional int32 c;    // optional → max_def contributes 1
    }
  }
}

Column a.b.c: max_rep = 1, max_def = 3.

Record a b list c R D Notes
{a: {b: [{c:1}, {c:2}]}} present 2 items 1 0 3 first value of new record
(cont.) — — 2 1 3 second item in b (rep=1 = new b item)
{a: {b: [{c:null}]}} present 1 item null 0 2 c is null → def stops at 2
{a: {b: []}} present empty — 0 1 b list is empty → def stops at 1
{a: null} null — — 0 0 a is null → def stops at 0
{} (a absent) absent — — 0 0 same encoding as null a

Assembly FSM: for each (R, D) pair — if R == 0 emit new top-level record; if D < max_def then corresponding level is null/empty; if D == max_def emit concrete value; R > 0 means repeated field repeats at level R.

8.6 Encoding Catalogue

Encoding Tag Applies To Notes
PLAIN 0 all types raw little-endian; BOOLEAN = LSB-packed
PLAIN_DICTIONARY 2 all dict-page + delta indices (legacy tag; use RLE_DICTIONARY)
RLE 3 BOOLEAN RLE-only (no bit-packing)
BIT_PACKED 4 levels only legacy; fixed 8-values-per-block
DELTA_BINARY_PACKED 5 INT32/INT64 block-delta + bit-pack; zigzag optional
DELTA_LENGTH_BYTE_ARRAY 6 BYTE_ARRAY delta-encode lengths; concatenate values
DELTA_BYTE_ARRAY 7 BYTE_ARRAY shared-prefix delta; suffix plain
RLE_DICTIONARY 8 all (dict indices) hybrid RLE/bit-pack over dict indices
BYTE_STREAM_SPLIT 9 FLOAT/DOUBLE/INT32/INT64 byte-plane interleave; improves compression ratio

Hybrid RLE/BIT_PACKED format (used for levels + dict indices):

  • 4-byte LE byte_count header (total bytes following)
  • then blocks alternating between:
    • RLE block: (count << 1 | 0) varint + 1-byte value (if bit_width ≤ 8) or ceil(bit_width/8) bytes
    • BIT_PACKED block: (block_count << 1 | 1) varint + block_count * bit_width * 8 / 8 bytes (8 values per block)

8.7 ORC File Layout

┌────────────────────────────────────────────────────────────┐
│  [stripe 0] [stripe 1] ... [stripe N-1]  [file footer]     │
│                                           [postscript]      │
│                                           [1-byte PS_len]   │
└────────────────────────────────────────────────────────────┘

Stripe:
┌──────────────┬────────────────────────────────────┐
│ index streams│ data streams  │  stripe footer      │
│ (row-group   │ (PRESENT,DATA,│  (Protobuf)         │
│  indexes)    │  LENGTH, DICT)│                     │
└──────────────┴────────────────────────────────────┘
  • Postscript (last bytes before 1-byte PS_len): Protobuf with footerLength, compression, compressionBlockSize, version.
  • File footer: Protobuf Footer with column types, stripes list, row count, statistics, metadata.
  • Stripe footer: Protobuf with stream list (column, kind, length) and column encodings.
  • Column streams: PRESENT (null bitmap, RLE), DATA (values), LENGTH (string/list/map lengths), DICTIONARY_DATA (dict strings).
  • Integer RLEv2: 4 sub-encodings — DIRECT (bit-pack), DELTA (monotone runs), RLE (short runs), PATCHED_BASE (outlier handling).

8.8 Malformed / Failure-Path Examples

Case Byte Pattern Expected Behavior
Wrong magic first 4 bytes ≠ PAR1 Error::NotParquet before any allocation
Footer length overflow last 8 bytes encode footer_len > file_size − 8 Error::FooterTooLarge{len, file_size}
Thrift truncation footer bytes cut mid-field Error::ThriftDecode{field_id, offset}
Negative column offset ColumnMetaData.data_page_offset < 0 Error::OffsetUnderflow
Dict index OOB RLE_DICTIONARY index ≥ dict_size Error::DictIndexOutOfRange{index, dict_size}
CRC mismatch computed CRC ≠ stored CRC in DataPageV2 Error::Corruption{page_offset, column_path}
Decompression bomb uncompressed_size header = 2 GB Error::DecompressionBomb{claimed, limit} before decompress
Level OOB rep_level > max_rep Error::InvalidLevel{level, max, column}
All-null column every value has D < max_def valid; assemble as all-null column; statistics: null_count = num_rows
Empty row group RowGroup.num_rows = 0 valid; skip; no pages allocated
Schema mismatch file has column x: INT64, caller schema has x: STRING Error::SchemaTypeMismatch{column, expected, found}
