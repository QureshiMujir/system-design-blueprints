Mental Models & First Principles

The compressed intuitions an expert holds about columnar codecs. Each: the insight, what it predicts, the bug class you write without it, and where this blueprint applies it.

  • MM1 — A column chunk is a sorted run in disguise. Even without explicit sort keys, values in one column in one row group cluster: low-cardinality strings collapse onto dict pages, timestamps increment monotonically, NULL/non-NULL status clusters by write time. Predicts: statistics-based pruning is highly effective even on "unsorted" files; an encoding selector should check delta variance before committing to PLAIN. Bug without it: choosing PLAIN for INT64 columns that are 80% monotone, leaving DELTA_BINARY_PACKED savings on the table. Applied: Phase 8 §20.2 (encoding_selector delta std-dev heuristic), Phase 6 §18.2 (predicate skip ratios), P3.
  • MM2 — The footer is the index; the pages are the data. FileMetaData (the Thrift footer) carries all structural metadata — schema, row-group boundaries, per-column offsets, statistics, PageIndex offsets. No byte of page data is needed to answer "can this row group be skipped?" Predicts: open-time cost is dominated by footer parse + PageIndex load; per-page cost is dominated by decompression + decode; predicate evaluation is a pure footer operation. Bug without it: eagerly reading page bytes before evaluating statistics, eliminating all I/O savings. Applied: ADR-A21 (eager PageIndex parse), Phase 6 §18.2 (predicate before seek), Phase 7 §19.2 (ColumnIndex loaded at open).
  • MM3 — Dremel levels are a lossless serialization of a tree path, not a value attribute. Repetition level R encodes "which repeated ancestor started a new instance"; definition level D encodes "how deep the path is defined". Both derive from schema structure, not from the value. Predicts: max_rep and max_def are schema constants, computable once at open time; any value with D = max_def is non-null regardless of its numeric value. Bug without it: recomputing max_rep/max_def per page (slow, drift-prone); misreading D=0 as "value is zero" instead of "outermost optional field is absent". Applied: Phase 3 §15.2 (parquet_core::dremel), ADR-A18 (precomputed levels in SchemaNode), §8.5 worked example.
  • MM4 — Compression operates on byte similarity, not semantic meaning. Column layout clusters similar bytes (all INT64 values for one column in one row group are contiguous), maximizing the run-length and entropy reduction ZSTD/Snappy exploit; BYTE_STREAM_SPLIT further raises byte-plane similarity for IEEE-754 floats by grouping exponent bytes. Predicts: a columnar file with ZSTD compresses 5–10× better than the same data row-oriented with ZSTD. Bug without it: applying BYTE_STREAM_SPLIT to BYTE_ARRAY (variable width — no byte planes) causing a decode error, or leaving PLAIN on float columns that BYTE_STREAM_SPLIT would shrink 15–20%. Applied: Phase 4 §16.2 (codec integration), Phase 8 §20.2 (BYTE_STREAM_SPLIT selector), B3.
  • MM5 — Statistics are a one-sided proof of absence. If a predicate is inconsistent with a row group's min/max/null_count, that row group provably has zero matches; if consistent, it may or may not match — statistics cannot prove presence. So false negatives (skipping a matching group) are catastrophic data loss; false positives (reading an unmatching group) are merely wasted I/O — statistics must err toward inclusion (widen, never narrow). Predicts: a writer that fails to update max after a late large value silently drops row groups at query time. Bug without it: tightening statistics below the true range → silent wrong query results. Applied: Phase 6 §18.9 (I6/I7, P2), Phase 11 §23.2 (pqtool verify --statistics).
  • MM6 — Dictionary encoding is a two-pointer structure with a fallback seam. A dict-encoded column chunk is a pair (dict_page: Vec<T>, data_pages: Vec<u32 indices>) with the invariant that every index ∈ [0, dict_size). The seam is the fallback threshold: once the dict fills, the writer flushes the partial dict, switches to PLAIN, and the reader must decode both encodings in sequence transparently. Predicts: a conformance corpus must include a file that crosses the threshold mid-chunk; a reader assuming "all dict or all plain" silently corrupts the tail. Bug without it: applying dict-index lookup to PLAIN bytes in a mixed-encoding chunk → wrong values or panics. Applied: Phase 2 §14.2 (fallback path, ADR-A17), §14.6 pitfalls, I8.
  • MM7 — Thrift compact protocol is field-ID delta-encoded, not schema-driven. Field IDs are encoded as deltas from the previous ID; a stop byte (0x00) terminates a struct; unknown IDs must be skipped, not rejected. Predicts: forward compatibility is free if you skip unknowns; backward compatibility requires treating absent optional fields as defaults. Bug without it: hard-coding field-ID arithmetic that breaks when a new optional field is inserted between two existing ones (the delta shifts for every later field), crashing on files from a newer parquet-mr. Applied: Phase 0 §12.2 (shared::thrift_compact), Phase 5 §17.2 (full FileMetaData), ADR-A03, P7.
  • MM8 — The split-block Bloom filter is a SIMD-friendly set-membership test. Parquet's filter is not a standard k-hash Bloom: the hash selects a 256-bit block, then 8 probes run within that block via a fixed salt array, all fitting one cache line so the 8 probe results AND together under SIMD. Predicts: any miss in the 8 probes is a definitive "not present" (no false negatives); FPP is set by filter size; the implementation must use Parquet's exact salt constants or be incompatible with parquet-mr. Bug without it: using a generic Bloom crate (different hash/probe pattern) → filters written by parquet-mr are meaningless and I14 is violated. Applied: Phase 7 §19.2 (parquet_core::bloom_filter), ADR-A20, P6/P7.
  • MM9 — ORC stripes and Parquet row groups solve the same problem differently. Both are horizontal partitions enabling column-parallel I/O; the difference is compression granularity — ORC compresses at the stream level (per-column byte streams in configurable chunks) while Parquet compresses at the page level (each encoded page independently). Predicts: for narrow projections Parquet's per-page layout enables tighter I/O coalescing; for wide reads ORC's stream-level layout decompresses sequentially in one pass. Bug without it: applying Parquet per-page decompress logic to ORC streams (which have no page headers — a flat compressed byte stream). Applied: Phase 9 §21.6 (ORC stripe reader, ADR-A22), Comparative Architecture.
  • MM10 — Offset arithmetic is the root of all Parquet corruption bugs. Every structural element — footer byte range, row-group extent, column-chunk start, page start — is an absolute file offset; an off-by-one seeks to the wrong location and the wrong bytes silently decode as valid Thrift or page data, producing garbage rather than an error. Predicts: offset bugs rarely crash (Thrift is lenient; random bytes often decode as valid varints) — they manifest as silent wrong values. Bug without it: recording dict_page_offset after writing the dict header rather than before → every dict decode starts on the wrong byte → silent corruption. Applied: Phase 1 §13.2 (footer offset tracking), Phase 5 §17.2 (WriteCounter<W>), I3/I4/I5, P3.

Glossary · 35 terms · site-wide glossary

Column Chunk
Physical storage unit for one column's data within one row group; contiguous bytes in the file
Data Page
Atomic unit of encoded + compressed values within a column chunk; has v1 or v2 header
Definition Level (D)
Integer (0..max_def) encoding how deep the nested structure is defined for a value; encodes nulls/absent fields
Dremel
Google paper + algorithm for losslessly encoding nested/repeated data into flat R/D + value columns
Dictionary Page
Optional first page in a column chunk; contains PLAIN-encoded dict values; referenced by RLE_DICTIONARY indices
Dictionary Fallback
When dict exceeds cardinality threshold, writer switches to PLAIN mid-chunk; transparent to callers
FileMetaData
Thrift-serialized structure at end of Parquet file; contains schema, row-group metadata, statistics
Hybrid RLE/BIT_PACKED
Encoding for R/D levels + dict indices; alternates between run-length blocks and bit-packed literal blocks
ColumnIndex
Per-page min/max + null counts for a column chunk; enables page-level predicate skip
OffsetIndex
Per-page byte offsets + first row indices for a column chunk; enables seek-to-page
Bloom Filter
Probabilistic set membership structure; split-block variant used in Parquet; FPP configurable; no false negatives
Row Group
Horizontal partition of the Parquet file; contains one column chunk per column; unit of parallelism
Repetition Level (R)
Integer (0..max_rep) encoding at which repeated field level a value represents the start of a new repetition
RLE_DICTIONARY
Encoding: dict page (PLAIN values) + data pages (RLE/BIT_PACKED indices into dict)
PLAIN
Raw encoding: values written as-is in their physical format; no transformation
DELTA_BINARY_PACKED
Block-delta + bit-pack encoding for INT32/INT64; excellent for sorted or near-sorted integers
BYTE_STREAM_SPLIT
Byte-plane transpose encoding for fixed-width types; improves compression ratio for FLOAT/DOUBLE
Thrift Compact Protocol
Binary encoding of FileMetaData; field-ID-driven; zigzag varints; stop byte terminates struct
PageIndex
Collective term for ColumnIndex + OffsetIndex; enables sub-column-chunk predicate pushdown
Schema Element
Parquet's flat DFS-ordered list of schema nodes; reconstructed into SchemaNode tree
max_rep / max_def
Maximum possible R/D values for a column leaf; derived from schema; used for level validation
ORC Stripe
ORC's horizontal partition; analogous to Parquet row group; has index + data + footer sub-sections
ORC Stream
One typed byte stream within a stripe for one column; kinds: PRESENT, DATA, LENGTH, DICTIONARY_DATA
RLEv2
ORC's integer encoding; 4 sub-encodings: SHORT_REPEAT, DIRECT, PATCHED_BASE, DELTA
Postscript
ORC's final footer section; Protobuf; contains footer + metadata lengths and compression codec
LZ4_RAW
LZ4 block compression without framing header; used by Parquet (distinct from framed LZ4)
Statistics
Per-column-chunk min/max/null_count; conservative bound (never narrow); used for predicate skip
Predicate Pushdown
Evaluating filter predicates against statistics/bloom/page-index before reading pages; skips I/O
Coalescing
Merging adjacent byte-range reads within a gap threshold into a single I/O call
ConvertedType
Legacy Parquet field (< spec v2.4) encoding logical type annotation; superseded by LogicalType union
RecordBatch
Type-erased columnar output batch; one DecodedColumn<T> per projected column
PATCHED_BASE
ORC RLEv2 sub-encoding for integer columns with outliers; base value + delta + patch list
FIXED_LEN_BYTE_ARRAY
Parquet physical type for fixed-width binary data; used for UUID, DECIMAL, FLOAT16
WriteCounter
Wrapper over Write tracking bytes written; used to compute column chunk + page offsets
AssemblyFSM
Dremel assembly finite-state machine; state persists across pages within a column chunk
