3. Architectural Overview

One Cargo workspace of seven crates split by a single load-bearing line: the TRUST BOUNDARY. Exactly one crate — tp-kernel — is the TCB. Everything above the line is UNTRUSTED.

    proof script (.thm) / REPL  ──  prove CLI (prove · check · repl · bench)
                         |  parse
                         v
    tp-parse : Parser -> Term/Type/script · notation/fixity · PrettyPrinter · ParseError
                         |  parsed Terms + tactic scripts
                         v
    tp-tactic : Goal · GoalState · Tactic + Justification
        tacticals THEN/ORELSE/REPEAT/TRY · intro · apply · assumption · exact
                         |  uses derived rules          | builds Thm via Justification(Vec<Thm>)
                         v                              v
    tp-logic : HOL-lite constants = ==> /\ \/ ~ T F ! ? choice + derived intro/elim
        ^  defined via primitives (conservative)        |
        |                                               v
    tp-auto : Unify (unify_fo + unify_pattern/Miller) · ResolutionProver · CongruenceClosure · LinearArith
        |  every result = a sequence of primitive-rule calls -> a Thm
        v
    ====================== TRUST BOUNDARY — everything below is the TCB ======================
    tp-kernel : Term (de Bruijn) · Type · Thm (ABSTRACT, private field) · Sequent · type_of
        primitive rules:  refl · trans · mk_comb · abs · beta · assume · eq_mp · deduct_antisym
                          · inst · inst_type · new_basic_definition · new_basic_type_definition
    Trust:   ONLY tp-kernel trusted. Untrusted code obtains Thm solely via primitive rules.
    Input:   proof script (.thm) — may crash/loop; cannot derive a false Thm.
    Concurrency: single-threaded REPL/checker.  Persistence: none at runtime; Proofs serializable.

Central claim. Any value of type Thm is, by construction, a sequent derivable in HOL-lite. Bugs in tp-tactic/tp-auto/tp-parse degrade completeness (proof attempt fails) but never soundness (wrong theorem accepted). This is the LCF discipline, enforced by Rust's module privacy.

8. Domain Model — Logic, Terms, Inference Rules

The TCB. All types/rules below live in tp-kernel (TRUSTED) unless tagged otherwise.

8.1 Term + Type grammar (EBNF)

(* tp-kernel::Type — simple types + rank-1 polymorphism *)
Type = Tyvar , Name
     | Tyapp , Name , "[" , [ Type { "," Type } ] , "]" ;

(* tp-kernel::Term — de Bruijn for bound vars; named free Vars (locally nameless) *)
Term = Var   , Name , Type
     | Bound , u32
     | Const , Name , Type
     | Comb  , Term , Term
     | Abs   , Type , Term ;

Abs(ty, body) binds index 0 in body; each enclosing Abs shifts the reference up by one. Bound(k) with k ≥ (number of enclosing Abs) = dangling index = malformed (rejected by type_of/constructors). Alpha-equivalence is syntactic equality of Term.

8.2 Typing judgement type_of

type_of : &Term -> Result<Type, KernelError> — total + deterministic.

8.3 The ten primitive inference rules (TRUSTED)

(refl)  ─────────────        (trans)  Γ⊢s=t   Δ⊢t'=u    (t≡t')
         ⊢ t = t                      ─────────────────
                                        Γ∪Δ ⊢ s = u

(mk_comb) Γ⊢f=g  Δ⊢x=y      (abs) Γ⊢s=t   v=Var(x,α) ∉FV(Γ)
          ───────────────           ────────────────────────
          Γ∪Δ ⊢ (f x)=(g y)         Γ ⊢ (λx. s)=(λx. t)

(beta) ────────────────────  (assume) ──────────  p:bool
       ⊢ (λx. t) x = t[0:=x]           p ⊢ p

(eq_mp) Γ⊢p=q  Δ⊢p'  (p≡p')   (deduct_antisym) Γ⊢p  Δ⊢q
        ──────────────────              ────────────────────────────
             Γ∪Δ ⊢ q                   (Γ∖{q})∪(Δ∖{p}) ⊢ p = q

(inst)  Γ⊢p   θ=[xᵢ↦tᵢ]     (inst_type) Γ⊢p   θ=[αᵢ↦τᵢ]
        ─────────────              ─────────────
         Γθ ⊢ pθ                    Γθ ⊢ pθ

8.4 HOL-lite bootstrap (tp-logic, UNTRUSTED)

# Const Defining equation Derived rules
1 T T = ((\p:bool. p) = (\p:bool. p)) TRUTH : ⊢ T
2 /\ /\ = \p q. (\f. f p q) = (\f. f T T) CONJ, CONJUNCT1, CONJUNCT2
3 ==> ==> = \p q. (p /\ q) = p DISCH, MP
4 ! ! = \P. P = (\x. T) GEN, SPEC
5 ? ? = \P. !q. (!x. P x ==> q) ==> q EXISTS, CHOOSE
6 F F = !p:bool. p CONTR
7 ~ ~ = \p. p ==> F NOT_INTRO, NOT_ELIM
8 \/ \/ = \p q. !r. (p==>r)==>(q==>r)==>r DISJ1, DISJ2, DISJ_CASES
9 ε (choice) constant + axiom SELECT_AX: ⊢ !P x. P x ==> P (ε P) SELECT_RULE, classical EM

Items 1–8 are conservative definitions (no new axiom). Item 9 introduces the one extralogical axiom (SELECT_AX) giving classical HOL.

8.5 Capture-avoiding substitution (de Bruijn worked example)

  • shift ↑ᵈ_c(t): add d to every Bound(k) with k ≥ c; c increments under each Abs.
  • subst t[j ↦ s]: replace Bound(j) by s (shifted to current depth).
  • beta of Comb(Abs(τ,body), arg): body[0 ↦ arg], then ↑⁻¹ free indices.

Reduce (\x. \y. x) a:

Comb( Abs(α, Abs(β, Bound(1))), Var("a",α) )
beta: substitute arg for Bound(0) in Abs(β, Bound(1)):
  - enter inner Abs → cutoff c=1; Bound(1) refers to x (depth 0 outside)
  - replace with arg shifted by 1 → Var("a",α)
  - drop consumed binder, shift remaining free indices down 1
result : Abs(β, Var("a",α))    i.e.  \y. a
thm    : ⊢ (\x. \y. x) a = (\y. a)

8.6 Definition mechanism (TRUSTED)

new_basic_definition(eq: &Term) -> Result<Thm, KernelError>
  eq must be  Const(c,σ) = t  with:
    c FRESH (∉ Σ);  t CLOSED (no free Vars);  tyvars(t) ⊆ tyvars(σ).
  Violations → BadDefinition.  Yields  ⊢ c = t  and extends Σ with c:σ.

new_basic_type_definition(name, P:&Term, witness:&Thm) -> Result<(Thm,Thm),KernelError>
  P : α→bool; witness ⊢ P w proves subset nonempty.
  Introduces type T_new + abs/rep:
    (⊢ abs(rep a)=a , ⊢ P r = (rep(abs r)=r)).  Empty subset → BadDefinition.

8.7 Worked proofs

Proof 1 — ⊢ p ==> p:

Goal       :  ⊢ p ==> p
intro()    :  subgoal  {p} ⊢ p
assumption :  close via assume(p) : p ⊢ p
justify    :  j1 = |th| DISCH(p, th); j2 = |_| assume(p)
prove()    :  j1(j2(∅)) → ⊢ p ==> p

Proof 2 — ⊢ !x. P x ==> ?y. P y:

intro()   → ⊢ P a ==> ?y. P y  (GEN, fresh a:α)
intro()   → {P a} ⊢ ?y. P y    (DISCH)
exists(a) → {P a} ⊢ P a        (EXISTS, witness a)
assumption → close via assume(P a)
justify (bottom-up): assume(P a) · EXISTS · DISCH · GEN
