I1A ConfigSnapshot is immutable once published.Prevents torn reads under concurrent request handling.ConfigSnapshot has no interior mutability; ArcSwap is replace-only.Code review + loom concurrency model checks.lb_config_generation gauge.Structural — cannot be violated without a code change.
I2In-flight requests never observe a partially-constructed snapshot.A reload must not tear a request's view of routes/clusters.ArcSwap::store is an atomic pointer swap (ADR-07).Reload soak fixture reload_atomicity.json.lb_config_reload_total{outcome}.Two-phase reload rolls back to the previous Arc on validation failure (§22.2).
I3Selector::pick never blocks the calling task.Data-path latency budget (§4) has no room for I/O inside pick.pick is synchronous, no .await, no lock acquisition that can contend with I/O.loom model + perf assertion (< 50 µs p99, §31 M6).lb_pick_duration_seconds.Structural.
I4A backend is never selected while ejected or unhealthy.Correctness of the health-check contract (P5).BackendStatus.healthy is the AND of active and passive flags.Conformance fixture flapping_backend.json.lb_outlier_ejections_total.Automatic clear on the next passing active probe.
I5No response or request body byte is buffered in DRAM beyond one flow-control window.Bounds memory under slow-client/slow-upstream conditions (P11).Streaming architecture — Body::poll_frame end to end.Memory-profiling fixture, 1 GiB upload case.Process RSS gauge.Structural — a violation is a code-review-blocking bug.
I6Every accepted connection's peer address is captured before the proxy task spawns.Access-log completeness (§21).Captured in the listener accept path, before tokio::spawn.Unit test on access-log field presence.Access-log completeness metric.Structural.
I7Hop-by-hop headers are stripped before every forward.RFC 7230 section 6.1 compliance; prevents request smuggling.Header-normalization stage of the proxy pipeline (§8).Conformance smuggling fixtures (smuggling_*.json).lb_header_violations_total.Connection reset, request rejected.
I8A discoverer failure never empties a live backend pool.Availability under a flaky discovery backend.BackendPool::replace only called with a validated, non-catastrophic delta.Discovery-source-kill soak test.lb_discovery_stale_seconds.Last-good pool retained until the source recovers.
I9A draining backend is excluded from new picks but its existing streams complete.Graceful decommission (P12).BackendStatus.draining checked in Selector::pick, not in stream teardown.Drain conformance fixture drain_in_flight.json.lb_pool_size{status="draining"}.Structural.
I10Every admin mutation writes exactly one audit record before returning success.Auditability of the sole mutation surface (P10).lb-admin two-phase commit: audit write, then apply.Audit-log completeness test.lb_admin_audit_failures_total.The admin call fails closed if the audit sink is unavailable.
I11A TLS session ticket never outlives the master-key rotation window.Bounds the blast radius of a leaked ticket key.Ticketer keyed-rotation logic (§18).Conformance fixture ticket_rotation.json.tls_full_handshakes_total.Automatic fallback to a full handshake.
I12A circuit breaker's half-open probe quota is never exceeded concurrently.Prevents a thundering-herd retry storm on recovery.Atomic quota counter in breaker.rs (§20).Concurrency stress test.lb_circuit_state.Excess probes are short-circuited to 503.
I13The Maglev/Ketama/Jump lookup structure is rebuilt off the request path.Data-path latency budget (I3, §4).Rebuild triggered only from the discovery/reload task, never from Selector::pick.Perf assertion (§31 M7: pick p99 < 200 µs @ 10K backends).lb_table_rebuild_seconds.Structural.
I14A rate limiter's retry_after is monotonic non-decreasing across consecutive denies for the same key.Prevents thundering-herd retries against a saturated route.Token/leaky-bucket arithmetic (§19).Conformance burst fixture burst_429.json.lb_rate_limit_denies_total.Structural.
