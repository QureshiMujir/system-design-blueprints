4. System Constraints

Hard, quantified limits binding every phase. A constraint violated is a defect, not a tuning knob. "Default config" below is the reference ConfigParams used for all throughput/IPC targets unless a phase overrides it explicitly.

4.3 Memory footprint

Per-cycle live state is O(rob_size + rs_size + lsq_size + phys_regs) — bounded, no growth with program length (state is recycled via free list + circular ROB).

Structure Element size (approx) Count Bytes
ReorderBuffer (RobEntry) ~40 B 192 ~7.7 KiB
Scheduler (RsEntry) ~32 B 60 ~1.9 KiB
LoadStoreQueue (LsqEntry) ~48 B 64 ~3.1 KiB
PhysRegFile (u64 + ready) 9 B 128 ~1.2 KiB
Predictor (Btb/Ras/Gshare) — — ~16–64 KiB
Caches/TLB (default) — — ~300 KiB
Core resident (excl. guest memory) < 1 MiB

Guest memory: sparse, page-granular (4 KiB) backing map; only touched pages allocated. Total host RSS bound: guest-resident-pages + < 1 MiB core. No per-instruction allocation on the steady-state tick() path; all entry pools pre-sized from ConfigParams at construction.

4.4 Determinism

  • Identical (program, ConfigParams, seed) → byte-identical Stats and identical committed-state sequence, every run, every host. Load-bearing: reverse-order tick() (§ spine) prevents same-cycle value teleporting.
  • No wall-clock, no thread scheduling, no HashMap iteration order, no uninitialized reads in any decision. Any randomness (e.g. fuzz program gen, replacement tie-breaks) draws from one explicitly-seeded PRNG.
  • Deterministic replay (Phase 12): (seed, config) reproduces a run exactly; divergence bisection relies on this.
  • Select/wakeup ties broken by age (oldest ROB index first), never by container address or insertion accident.

4.5 Startup & initialization

  • Zero global/static mutable init; no lazy_static/once_cell on the hot path. All state hangs off an OooCore instance built from ConfigParams.
  • Construction allocates all pools once (ROB/RS/LSQ/PhysRegFile/caches sized from config); tick() allocates nothing.
  • Multiple independent OooCore instances in one process are legal and isolated (enables parallel batch sims, fuzzing shards).

4.6 Program size & ISA scope

  • ISA: RV64IM only. RV64GC (F/D float, A atomics, C compressed) is PhaseDeferred — decoding an out-of-scope opcode raises a defined Trap, never panics.
  • Guest image ≤ 256 MiB virtual; ≤ 4 GiB addressable VA (sparse). Loaded from ELF or flat hex via oooc run.
  • Run length bounded by run(max_cycles); default cap 1e9 cycles. No deadlock: an empty pipeline with non-empty fetch and no forward progress for N cycles aborts with a diagnostic.
  • Single-core only — no multi-core, no cache coherence (MESI is project 187), no SMP guest.

4.7 Modeling fidelity

  • Architectural correctness is absolute: committed ArchState must EXACTLY equal the ooo-isa golden model at every commit (Phase 12 co-sim). Timing is a model; correctness is not negotiable.
  • IPC fidelity target: within ±10% of gem5 DerivO3CPU on shared traces with matched config (width, ROB, latencies, predictor), median across the riscv-tests + microbenchmark suite; per-benchmark outliers documented, not silently tuned.
  • Branch prediction accuracy targets (Phase 3): Gshare ≥ 90%, TageLite ≥ 95% on standard branch-heavy microbenchmarks.
  • Cache/latency model is first-order (fixed per-level latency + MSHR occupancy); no analog, no power/thermal, no DRAM bank/row modeling — explicitly out of scope.

4.8 Out of scope (stated, not budgeted)

No NUMA, no network, no file-descriptor/syscall budget, no async I/O, no real-time deadlines, no RTL/Verilog, no JIT/binary translation (interpreting timing model). These carry zero engineering budget and no constraint targets; listed only to bound expectations.

4.9 Robustness & recovery

Hostile input Mandated behavior
Illegal/unsupported opcode Decode → defined Trap; ROB takes precise exception at head; sim continues
Misaligned / out-of-bounds load/store Trap via LSQ→ROB; no host segfault
Division by zero (Div) RV64IM-defined result (no trap per ISA), modeled exactly
Infinite guest loop Bounded by max_cycles; clean Stats return
Truncated/corrupt ELF Loader error, non-zero exit; never panics mid-load
Internal invariant break (debug) debug_assert!; release path degrades to defined trap, not UB

A malformed guest program traps; it never crashes, panics, or corrupts the simulator. All guest-derived addresses are bounds-checked against the guest memory map before host access. unsafe is forbidden outside vetted, documented hot-path leaf functions (none expected in the reference design).
