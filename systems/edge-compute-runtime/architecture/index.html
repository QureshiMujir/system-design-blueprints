3.2 Subsystem Descriptions

edge-router (ingress + worker dispatch + PoP failover) Receives inbound HTTP requests after anycast delivery. Resolves the target WorkerId from the request hostname/path. Checks local PoP health; on overload or failure, re-routes to next-nearest PoP (RoutingDecision with reason). Dispatches accepted requests to edge-sched for queuing. Trust boundary: first contact with untrusted tenant-initiated traffic; no WASM execution. Concurrency boundary: handles many simultaneous inbound connections; delegates scheduling to edge-sched. Persistence boundary: stateless; PoP health state in-memory with periodic heartbeat refresh.

edge-sched (concurrency limits + CPU time-slicing + fairness + admission/backpressure) Enforces per-PoP and per-tenant concurrency quotas. Queues incoming invocation requests with a deadline; drops or returns 429 when queue full (admission control). Selects next invocation using weighted/fair scheduler (prevents noisy-neighbor starvation). Signals edge-coldstart to acquire a warm instance. CPU time-slicing coordinates with fuel/epoch mechanism in edge-runtime to yield between concurrent invocations. Concurrency boundary: owns the active-invocation set; lock-granularity per tenant bucket.

edge-coldstart (warm pool + snapshot/restore) Maintains a per-WorkerId InstancePool of WarmInstance records. Pool hit: pops a WarmInstance, resets to ColdStartSnapshot baseline (CoW memory restore), validates reset token, returns to caller. Pool miss: instantiates a new instance via edge-runtime, runs module init to checkpoint, snapshots ColdStartSnapshot, promotes to warm. Reuses Wasmtime's pooling allocator to avoid per-instantiation mmap overhead. Persistence boundary: snapshot images held in process heap or memory-mapped arena; disk-backed snapshots are PhaseDeferred("Deferred Features Register").

edge-runtime (WASM engine: instance, linear memory, fuel/epoch) Wraps the Wasmtime engine. Compiles a WASM module to native code (Cranelift); caches compiled artifact by content hash. Instantiates with per-instance linear memory region (no shared memory). Links host imports from edge-host at instantiation time. Calls the exported fetch handler, passing the marshaled Request. Reads Response from guest memory after return. Configures fuel metering (subtract fuel per instruction) and epoch-interruption (deadline timer). Engine config: disable float nondeterminism (deterministic NaN), disable WASM threads and shared memory. Trust boundary: WASM sandbox is the primary isolation primitive; engine memory safety is the TCB.

edge-isolate (per-request instance + memory cap + no cross-tenant state) Layer above edge-runtime enforcing the isolation contract. Each request gets its own Isolate wrapping one WASM instance. Tracks memory_pages (enforces max), fuel_remaining, epoch_deadline, and tenant tag. On any resource breach or trap: destroys the instance (never reuses), records breach in edge-metrics. No shared mutable globals between instances. Trust boundary: enforces I1–I4; audited in Phase 13. Concurrency boundary: one instance per active request; no intra-instance parallelism.

edge-host (host API: fetch / kv / cache / headers / log) Implements the HostCall enum as Wasmtime host functions linked at instantiation. Each call checks ExecutionContext for capability (I10): a worker may only invoke KV/fetch/cache calls declared in its bindings. Fetch counts against subrequest_count (I5). KV and cache calls dispatch to edge-kv/edge-cache. Structured log calls buffer into a per-invocation log drain flushed to edge-metrics on completion. Deny-by-default surface; no ambient host access.

edge-kv (namespaced KV + TTL + eventual consistency) Per-PoP read-optimized replica of the edge KV store. Reads served from local in-memory index (B-tree or hash map) keyed by (KvNamespace, key). Write path: record locally then enqueue for async cross-PoP replication via edge-propagate. TTL enforcement: expired entries not served (I6); background reaper sweeps expired keys. Versioning: monotonic version counter per key (last-writer-wins on conflict). Persistence boundary: local replica rebuilt from propagation stream on PoP restart; disk-backed snapshot is PhaseDeferred("Deferred Features Register").

edge-cache (HTTP cache + TTL + stale-while-revalidate + purge) Two-tier store: hot tier in-memory (bounded LRU), warm tier on local NVMe (optional). Cache key derived from request URL + Vary headers. Stores CacheEntry records with expires_at and stale_until. Stale-while-revalidate: serves stale response while async revalidation dispatches. Purge: marks key invalidated; propagated cross-PoP via edge-propagate Invalidation messages. Workers interact via Cache host API (edge-host -> edge-cache).

edge-propagate (cross-PoP eventual-consistency propagation) Async message bus between PoPs carrying Invalidation records (KvKey or CacheKey with version and origin PoP). Applies monotonic version checks before accepting writes (no rollback). Convergence property: every write eventually reaches every PoP within the stated staleness bound. Fan-out topology: configurable (full-mesh, hub-spoke, gossip); prescribed in Phase 11 contract.

edge-metrics (cold-start rate + p99 latency + hit rate + attribution) Per-PoP metrics collection with per-tenant + per-worker labels. Collects: cold-start vs. warm counts; invocation latency histogram (HdrHistogram); CPU-fuel consumed per invocation; memory pages high-watermark; cache hit/miss counts; subrequest counts. Exposes a Prometheus-compatible scrape endpoint. Attribution: every metric carries TenantId + WorkerId labels for cost accounting.

edge-cli (deploy/run/bench/inspect) Developer-facing toolchain. Commands: deploy <wasm> uploads artifact to configured PoP; run <wasm> <request.json> local single-PoP smoke test; bench <wasm> measures cold/warm start latency locally; inspect <wasm> prints module imports/exports/limits. Offline path: spins up an in-process PoP (edge-runtime + edge-host + edge-kv/cache stubs) without network. Trust model: runs with the developer's credentials; never executes inside the production sandbox.

8. Domain Model

8.1 Entity Taxonomy

Entity Crate Cardinality Lifecycle
TenantId(u64) edge-core 1 per customer account created on onboarding; revoked on account close
WorkerId(u64) edge-core N per tenant created on deploy; invalidated on new deploy
WorkerScript edge-core 1 per WorkerId immutable after deploy; new deploy ⇒ new WorkerId
IsolateId(u64) edge-isolate 1 per request invocation born at dispatch; destroyed on completion or trap
PoPId(u32) edge-core fixed at build time per PoP healthy / degraded / offline
PoP edge-router 1 per physical location health state transitions; capacity integer
ExecutionContext edge-isolate 1 per in-flight invocation created pre-dispatch; dropped post-response
WarmInstance edge-coldstart pooled N per WorkerId idle / in-use / poisoned
ColdStartSnapshot edge-coldstart 1 per WorkerId version created once post-init; read-only thereafter
KvEntry edge-kv N per namespace created/updated/TTL-expired
CacheEntry edge-cache N per cache key fresh / stale / revalidating / purged
RoutingDecision edge-router 1 per inbound request ephemeral; logged for metrics
Invalidation edge-propagate event record in-flight until acknowledged by target PoP

8.2 WorkerScript Lifecycle State Machine

State: [PENDING_DEPLOY] -> [COMPILING] -> [READY] -> [DRAINING] -> [TOMBSTONED]
                                |
                         compile-error
                                |
                          [DEPLOY_FAILED]

Transitions:
  PENDING_DEPLOY  --deploy-request-received-->  COMPILING
  COMPILING       --wasm-validated + module-compiled-->  READY
  COMPILING       --validation-error / OOM-->  DEPLOY_FAILED
  READY           --new-deploy-for-same-worker-->  DRAINING  (in-flight finish; new WorkerId becomes READY)
  DRAINING        --all-in-flight-complete-->  TOMBSTONED
  READY           --explicit-delete-->  DRAINING

8.3 Isolate Lifecycle State Machine

[UNBORN] -> [ACQUIRING_INSTANCE] -> [RUNNING] -> [COMPLETED]
                     |                  |
               [COLD_START]        [TRAPPED]
                     |                  |
               [RUNNING]          [DESTROYED]
                              (never reused: I3)

Transitions:
  UNBORN              --dispatch-->  ACQUIRING_INSTANCE
  ACQUIRING_INSTANCE  --pool-hit-->  RUNNING  (warm path)
  ACQUIRING_INSTANCE  --pool-miss-->  COLD_START
  COLD_START          --snapshot-restore or fresh-instantiate-->  RUNNING
  RUNNING             --handler returns-->  COMPLETED -> instance reset -> pool (P10)
  RUNNING             --fuel-exhausted | epoch-deadline | memory-cap | wall-timeout-->  TRAPPED -> DESTROYED
  RUNNING             --guest-panic | wasm-trap-->  TRAPPED -> DESTROYED
  COMPLETED           --reset-fails integrity check-->  DESTROYED (never pooled)

8.4 WarmInstance Lifecycle State Machine

[IDLE_IN_POOL] -> [CHECKED_OUT] -> [RESETTING] -> [IDLE_IN_POOL]
                       |                |
                  [IN_USE]       [DESTROYED] (reset integrity fail)
                       |
                  [RESETTING]

Key invariant (I4): reset must reproduce ColdStartSnapshot state exactly -- memory image + globals, zero tenant data.
Pool size: bounded by InstancePool::per_worker capacity; LRU eviction on overflow.

8.5 KvEntry State Machine

[LIVE] -> [TTL_EXPIRED] -> (evicted; not served: I6)
[LIVE] -> [SUPERSEDED]   (new write with higher version; old entry invisible to reads)
[LIVE] -> [TOMBSTONED]   (explicit delete; tombstone propagated cross-PoP)

Write path:  KvPut(ns, key, val, ttl)
  -> assign monotonic version (origin_pop || timestamp || sequence)
  -> store locally as KvEntry { value, expires_at }
  -> enqueue Invalidation for edge-propagate fan-out (I9)

Read path: KvGet(ns, key)
  -> local replica lookup
  -> if expires_at <= now -> treat as miss (I6)
  -> return value or miss; never block on remote PoP

8.6 CacheEntry State Machine

[FRESH] -> [STALE] -> [REVALIDATING] -> [FRESH]   (stale-while-revalidate)
                   \               \-> [STALE]    (revalidation 304: extend TTL)
                    [PURGED]          [PURGED]    (explicit invalidation)
[FRESH] -> [PURGED]  (explicit CachePurge or Invalidation arrival)

Admission: cache key derivation -> hash(method, url, vary-header-values, worker-override)
TTL sources (precedence): worker CachePut TTL > Cache-Control max-age > default-per-tenant
Stale-while-revalidate window: configurable per entry; default 0s

8.7 HostCall Dispatch Sequence

guest wasm                edge-isolate          edge-host           downstream
   |                           |                    |                   |
   |--host_call(Fetch(req))-->  |                    |                   |
   |                    check subrequest_count <= cap (I5)              |
   |                           |--dispatch_host_call(Fetch)-->          |
   |                           |                    |--HTTP out-------> |
   |                           |                    |<--response--------|
   |                    fuel: charge outbound bytes  |                   |
   |<--return response bytes-- |<--HostCallResult---|                   |
   |                           |                    |                   |

Failure path (subrequest cap breach):
  subrequest_count == cap -> return HostCallResult::Err(SubrequestCapExceeded)  (no panic, guest sees error)
  (I5: cap+1th fetch fails; guest may handle or trap)

Failure path (fetch timeout):
  wall_ms budget exhausted during outbound fetch -> HostCallResult::Err(Timeout)
  ExecutionContext.wall_deadline checked before and after await points

8.8 Cross-PoP Propagation Sequence

origin-PoP                  edge-propagate              remote-PoP-N
    |                              |                          |
    |--KvPut(ns,k,v,ttl)-->        |                          |
    | locally committed            |                          |
    |--enqueue Invalidation------> |                          |
    |                              |--push Invalidation-----> |
    |                              |                  apply if version > local
    |                              |<--Ack------------|       |
    |                              |                          |
    | (if Ack timeout: retry with exponential backoff)        |
    |                              |                          |

Invalidation record:
  { kind: KvKey(ns, key) | CacheKey(key), version: MonotonicVersion, origin_pop: PoPId }
Convergence guarantee (I9): all PoPs apply or discard based on version ordering; last-writer-wins on version tie-break by PoPId.
Bounded staleness: configurable per namespace; default 5 seconds wall time.

8.9 ResourceLimits Accounting Model

Resource Mechanism Enforcement Point Trap Kind
cpu_fuel: u64 Wasmtime fuel injection; one unit per Wasm instruction engine per-store fuel counter FuelExhausted
memory_bytes: u32 max linear-memory pages (page = 64 KiB) set on instance engine memory limits UnreachableOrOOM
wall_ms: u32 monotonic clock checked at host-call entry and async yield ExecutionContext.wall_deadline WallClockExceeded
subrequests: u16 counter in ExecutionContext, incremented per Fetch dispatch edge-host before dispatch SubrequestCapExceeded

FuelMeter invariant (I1, I8): fuel charged = f(executed instructions); reproducible across runs of the same module + input; no randomness in accounting. EpochDeadline: epoch counter incremented by runtime background thread at configurable tick (e.g., 1ms); instance trapped if epoch counter > deadline epoch. Fuel and epoch may run in parallel; first to trigger wins.

8.10 Wire / Serialization Layouts

Request/Response over guest memory boundary

Layout (little-endian, 4-byte aligned):
  [u32: method_len][method bytes]
  [u32: url_len][url bytes]
  [u32: header_count]
    repeated: [u16: name_len][name bytes][u16: val_len][val bytes]
  [u32: body_len][body bytes]

Zero-copy path: body passed as wasm linear-memory pointer + length; no copy if body <= 64 KiB.

KvEntry storage layout (per-PoP local store)

Key:    namespace_id(8 bytes) || key_bytes (variable)
Value:  [u8: version_type][u64: version][u64: expires_at_unix_ms][u32: value_len][value bytes]

Invalidation wire format (cross-PoP, MessagePack)

{
  kind:       0x01 (KvKey) | 0x02 (CacheKey),
  ns_or_nil:  bytes,
  key:        bytes,
  version:    [u64: wall_ms][u32: pop_id][u32: seq],   -- monotonic vector
  origin_pop: u32
}

8.11 RoutingDecision Semantics

Inputs: client source IP -> anycast catchment -> PoPId list (ordered by proximity)
Algorithm:
  1. Select nearest PoP where PoP.healthy == true (I7)
  2. If that PoP admission-check fails (sched backpressure): advance to next in list
  3. Record RoutingDecision { pop, reason: Nearest | Failover(rank) }
  4. Dispatch to selected PoP; set request affinity header for retry de-loop

Failover:
  - PoP marked unhealthy on N consecutive health-check failures (configurable threshold)
  - In-flight requests on a newly-unhealthy PoP: drain or re-route depending on response stage
  - Sticky vs stateless: workers are stateless (P8); re-routing to a different PoP is safe

8.12 Scheduler Semantics (per-PoP)

Queuing model:
  - Global concurrency slot pool: capacity = PoP.capacity (integer)
  - Per-tenant sub-pool: max_concurrent_per_tenant <= global_capacity / active_tenants
  - Admission queue: bounded FIFO per tenant; max depth = 2x per-tenant sub-pool
  - Deadline-aware eviction: requests past wall_ms budget dropped from queue with 429

CPU time-slicing:
  - Epoch-tick interrupts cooperative multitasking (1ms default epoch)
  - On epoch interrupt: store fuel_remaining in ExecutionContext; yield tokio task
  - Fairness: tenant with lowest cumulative CPU-ms this window scheduled next (deficit scheduling)

Backpressure:
  - Queue full -> 429 Too Many Requests returned immediately (no blocking)
  - Capacity restored when in-flight count drops below 80% of limit (hysteresis)

8.13 Snapshot/Restore Semantics

ColdStartSnapshot creation (once per WorkerScript, post-init):
  1. Instantiate fresh module; run _start / initialization exports
  2. Capture: linear memory image (all pages), global values, table slots
  3. Seal as ColdStartSnapshot { module_id, initialized_memory_image, globals }
  4. Store in InstancePool; mark immutable (never mutated after sealing)

Restore path (warm start):
  1. Obtain pre-allocated memory slab from PoolingAllocator
  2. Copy-on-write (or memcpy) initialized_memory_image into slab
  3. Reset globals to snapshot values
  4. Attach to Wasmtime Instance without re-running init
  5. Assign new IsolateId; set FuelMeter + EpochDeadline per ResourceLimits
  6. Verify reset: hash(memory_image + globals) == snapshot hash (I4)

Reset-and-reuse path (after clean completion):
  1. Call WarmInstance.reset_token handler (guest export, optional)
  2. Verify memory/globals returned to snapshot state (same hash check)
  3. If check passes -> return to pool as IDLE; else DESTROYED (I3, P10)

8.14 Worked Example -- Happy Path Invocation

1. Client HTTP GET /api/data -> anycast -> PoP-7
2. edge-router: parse request -> WorkerId lookup for hostname -> RoutingDecision { pop: 7, reason: Nearest }
3. edge-sched: concurrency slot available -> admit
4. edge-coldstart: InstancePool hit for WorkerId-42 -> WarmInstance { instance, reset_token } checked out
5. edge-isolate: attach ExecutionContext { fuel=500_000, wall_ms=50, subrequests=5 }
6. edge-runtime: invoke fetch handler; guest runs
7. guest calls kv_get("cache:data") -> edge-host -> edge-kv lookup -> LIVE entry -> return value bytes
8. guest returns Response { 200, headers, body }
9. edge-isolate: read response from guest memory; destroy ExecutionContext
10. instance reset -> hash check passes -> return to pool (IDLE)
11. edge-router: send Response to client; record metrics in edge-metrics

8.15 Failure-Path Example -- Fuel Exhaustion

1-6: same as 8.14
7. guest enters tight loop; fuel counter decrements to 0
8. Wasmtime engine raises FuelExhausted trap
9. edge-isolate: catches trap -> IsolateId-XYZ state -> TRAPPED
10. Instance DESTROYED immediately; never returned to pool (I3)
11. edge-router: returns 503 to client with header X-Edge-Error: ResourceLimit/CPUFuel
12. edge-metrics: records invocation_trapped{reason=fuel_exhausted, tenant=T, worker=W}
13. edge-sched: concurrency slot released; next queued request admitted

8.16 Edge Cases

Scenario Handling
Worker deploys while requests in-flight on old WorkerId Old WorkerId drains (DRAINING state); new WorkerId accepts new dispatch; pool for old purged after drain
Snapshot hash mismatch on reset Instance DESTROYED; cold-start path used; alert metric emitted
KV read on non-origin PoP during propagation window Returns local value (may be stale by bounded staleness); correct per P5/I9
Subrequest itself times out HostCallResult::Err(Timeout); fuel charged for attempted request; guest decides to continue or abort
Pool exhausted + cold-start under memory pressure PoolingAllocator returns OOM; 503 returned; metric pool_exhaustion_total incremented
CacheEntry stale-while-revalidate window active Serve stale immediately; background revalidation fetch issued; new entry replaces on 200; TTL extended on 304
Two PoPs write same KV key concurrently Both propagate Invalidation with their version; receiver applies higher version; lower discarded (LWW)
Guest wasm calls host import not declared in bindings Capability check fails; HostCallResult::Err(NotAuthorized); I10 enforced; no ambient authority
PoP health-check flip-flop Hysteresis: N consecutive failures to mark unhealthy; M consecutive successes to mark healthy; prevents routing oscillation
Epoch tick while waiting on outbound fetch Epoch deadline accounts for async wait; deadline = dispatch_time + wall_ms; checked on resume
