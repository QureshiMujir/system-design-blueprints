⬜ Phase 1 — Reflect + Any foundation

Objectives
  • Define PartialReflect (incomplete/dynamic view) and Reflect (full concrete identity) as separate traits in refl-core; establish ReflectRef<'a>/ReflectMut<'a>/ReflectOwned as the dispatch enums every value enters reflection through.
  • Wire std::any::Any: as_any(), as_any_mut(), into_any() on Reflect; provide reflect_partial_eq for structural equality without PartialEq bounds.
  • Ship blanket impls for primitives (i8..i128, u8..u128, f32/f64, bool, char, String, &str) as Opaque/value types. No proc-macro this phase; all impls hand-written.
Deliverable
  • refl-core compiles (cargo check/cargo test); all primitives pass through reflect_ref() → ReflectRef::Opaque.
  • reflect_partial_eq returns Some(true)/Some(false)/None for equal/unequal/cross-type primitives; as_any().downcast_ref::<T>() succeeds for correct T.
  • set() rejects wrong-type values at runtime, returning the value in Err; unit tests in refl-core/tests/reflect_any.rs pass.

Pitfalls
  • Hashing dynamic keys: dyn PartialReflect has no Hash; map proxy walks pairs linearly — this is intentional but must be documented; using DynamicMap as a real HashMap substitute fails silently on large inputs without O(n) documentation.
  • Array const-generic Typed impl: OnceLock keyed by TypeId::of::<[T;N]>() — two different N values for the same T must produce distinct TypeInfo; missing const parameter in the OnceLock path causes aliased static info.

⬜ Phase 9 — TypeRegistry + registration

Objectives

  • TypeId instability across crate versions: TypeId::of::<T>() is not stable across compiler versions/separate compilations; registry keyed on TypeId is valid only within a single binary invocation — persist TypePath only, never TypeId.
  • RwLock write starvation: many concurrent readers can starve a writer; parking_lot::RwLock prefers writers where the platform supports it but this isn't guaranteed — avoid long-held read guards during register calls.
  • Short-path collision silent fallback: get_by_short_path must return Err, not the first candidate, or serde deserializes the wrong type without error.
  • TypeData TypeId key aliasing: TypeId::of::<D>() is the data-map key; confirm TypeData: 'static to prevent lifetime-erased subtypes.
  • Global mutable static temptation: a lazy_static! global registry violates P6 and breaks test isolation — reject; pass TypeRegistry by reference everywhere.
  • Missed clone_type_data impl: omitting Clone on a TypeData struct causes clone_type_data to panic at runtime if the default impl uses unimplemented!; enforce at compile time via derive or blanket-impl requirement.
