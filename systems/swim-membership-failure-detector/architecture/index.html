Subsystem Roles

Operator Tooling — swimctl and the authenticated admin API give operators cluster inspection, node quarantine, replay analysis, and controlled shutdown. Never mutates runtime state except through the admin API's authenticated, audited command path (P4, I2).

Observability Layer — structured events, trace correlation, convergence and suspicion-lifecycle metrics, packet-drop accounting. Every runtime subsystem writes to it; none blocks on it (P5, P6) — sink failure degrades diagnosability, never liveness.

Runtime Kernel — the probe scheduler, gossip/anti-entropy engine, membership FSM, and shared timer wheel. This is the only subsystem that owns mutable cluster state (P4, I2); it commits membership transitions across a single-writer boundary shared by scheduler and gossip engine.

Protocol Processing — wire decode/encode, version negotiation, incarnation conflict resolution, malformed-packet rejection. Sits at the untrusted-input trust boundary: every byte from the network crosses here before reaching runtime state, and must be rejected deterministically on corruption (P9, I1).

Transport Layer — UDP send/receive, packet framing, optional TCP fallback for oversized anti-entropy payloads, rate limiting. Deliberately ignorant of membership semantics (P4) so it can be fuzzed, swapped, or benchmarked in isolation.

Persistence Layer — WAL, snapshot, crash recovery, replay. Sits behind a crash boundary: process kill or power loss must never corrupt on-disk state or block the gossip critical path (P3, P8).

8. Domain Model — SWIM Protocol State & Wire Format

Membership States

State Meaning
Alive node reachable, incarnation current
Suspect reachability unconfirmed, suspicion timer running
Confirmed suspicion timer expired unrefuted — declared failed
Left graceful departure, announced by the node itself
Tombstoned historical suppression state post-GC-eligible window

Suspicion State Machine

Current Event Next
Alive probe timeout (direct + indirect exhausted) Suspect
Suspect Alive refutation with incarnation ≥ current Alive
Suspect suspicion timeout expiry, unrefuted Confirmed
Confirmed node rejoin with higher incarnation Alive
Confirmed tombstone retention window elapses Tombstoned
Alive Left announcement Left

Probe Lifecycle (direct then indirect)

Node A --Ping----------------> Node B
Node B --Ack-------------------> Node A          (fast path: done)
[ timeout, no Ack ]
Node A --PingReq(target=B)----> Node C, D, E      (indirect probe fan-out k=3)
Node C, D, E --Ping-----------> Node B
Node B --Ack-------------------> Node C, D, E
Node C, D, E --AckRelay--------> Node A           (any one relay confirms B alive)

Packet Types

Type Purpose
Ping direct liveness check
Ack probe acknowledgment
PingReq indirect probe request, carries target NodeId
Alive refutation update, carries incarnation
Suspect suspicion propagation, piggybacked on gossip
Confirm failure confirmation, terminal for this incarnation
SyncDigest anti-entropy summary (per-node incarnation digest)
SyncState anti-entropy full-state repair reply

Malformed Packet Handling (P9 — fail closed)

Condition Behavior
Invalid CRC32 drop packet, increment codec_crc_fail_total, emit trace event
Incarnation regression (I1) reject update, preserve current MemberRecord, increment membership_incarnation_regression_total
Oversized packet (> MTU-derived cap) hard reject before decode, rate-limited log line
Unknown protocol version below negotiated floor (I10) reject connection at transport handshake
Duplicate correlation ID on Ack drop as replay, increment probe_ack_unmatched_total
