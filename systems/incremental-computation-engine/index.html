Trust boundary: the only untrusted code is the host-supplied QueryFn body (assumed pure but not provably so). Concurrency boundary: the Memo Cache, Input Cell Store, and Revision Clock are shared across threads (Phase 9); the DependencyStack is thread-local. Persistence boundary: none in core — the entire state is in-process and volatile (on-disk memos deferred, §11).

Per-box detail

Host application. Owns the event loop, threads, and lifetime. Drives the engine by two operations only: set_input(key, value) (mutation) and db.query::<Q>(key) (demand). It must treat returned values as snapshots valid only until the next mutation it issues; it must never call set_input from inside a query body (that would violate purity). The host decides when to demand — the engine never computes speculatively in Phase 0.

Database handle (ice-runtime). The single owning object. Holds the Revision Clock, Input Cell Store, Memo Cache, Key Interner, DDG, and (Phase 9) the executor. &Database is the capability passed to every query. It is Sync; mutation methods take &mut self or use interior synchronization (durability-tagged). It mediates every read so dependencies can be captured. Cloning a handle shares the same underlying state (Arc-backed storage).

Revision Clock. A monotonic Revision(u64) — the global logical clock. Every set_input that actually changes a value increments it. The clock also stores, per durability class, the last revision at which an input of that durability changed (the durability map), enabling the "if nothing of durability >= D changed since verified_at, skip re-validation" shortcut (§7). Never decreases; wraps are unreachable in practice (u64) but treated as a fatal invariant breach.

Input Cell Store. Maps each input key to (value, changed_at: Revision, durability: Durability). The leaves of the DDG. set_input compares new vs old by Eq; if equal, it is a no-op (no clock bump) — input-level early cutoff. If different, it writes the value, sets changed_at = new current revision, and updates the durability map. Reads of input cells from inside a query are intercepted to record a dependency edge on the DependencyStack.

DependencyStack (thread-local). A per-thread stack of frames, one per query currently executing on that thread. The top frame accumulates the set of (NodeId, verified-at-read-time) edges as the running query reads inputs and sub-queries. On query completion the frame's edge set becomes the memo's deps. This is dependency capture by execution tracing — the engine learns the dependency set by running the query, not by static analysis. Thread-local so parallel queries do not cross-contaminate edge recording.

Memo Cache (sharded). QueryKey -> Memo. The heart. Memo carries the cached value, verified_at (last revision we confirmed it current), changed_at (last revision its value actually changed — drives downstream cutoff), durability (min over its inputs' durabilities), and deps (the captured edge list). Sharded by key hash into N independent lock domains (DashMap-style) so parallel queries on different keys do not contend. Lookups return either a usable memo (fast path) or trigger validate-or-recompute.

Query Evaluator. Implements the red-green state machine. On demand for key k: if a memo exists and verified_at == current_rev -> reuse (green). Else run maybe-dirty validation: for each dependency, recursively demand it; if every dep's changed_at <= memo.verified_at (none changed since we last verified) -> backdate (verified_at = current_rev, value reused) — deep early cutoff. Otherwise recompute: push a DependencyStack frame, call the QueryFn, capture deps, compare new value to old by Eq; if equal, keep changed_at (cutoff), else changed_at = current_rev; set verified_at = current_rev.

#[query] user function (QueryFn). The host-supplied pure function. Receives &Database and the key; returns the value. All its reads of inputs/queries route through the Database so they are captured. It must be deterministic and side-effect-free (§6, §7). The engine cannot prove this; it provides best-effort detection (a debug-mode read-set replay check) and documents the contract loudly.

Key Interner. Maps each QueryKey to a compact NodeId(u32) so the DDG, reverse-edge index, and GC structures can use dense integer arrays instead of hashing full keys repeatedly. Interning is append-only within a process (keys are never un-interned while reachable); GC may recycle NodeIds only after a key's memo is evicted and all reverse edges are gone.

DDG (forward + reverse edges). The dynamic dependency graph. Forward edges: query -> things it read. Reverse edges: input/query -> queries that read it (the dependents index, needed to mark maybe-dirty on a change and to compute reachability for GC). Edges are versioned (each edge remembers the verified_at of the dependency when it was read) so validation can detect staleness precisely.

Maybe-dirty frontier. The set of nodes transitively reachable (via reverse edges) from a just-changed input, marked maybe-dirty (not dirty). "Maybe" because early cutoff might prove a node's value is unchanged despite an upstream change — so we cannot eagerly mark dirty. The frontier is what the validate pass walks lazily on demand.

Cycle Detector. A per-evaluation on-stack set of NodeIds currently being computed. If a demand re-enters a key already on the stack, that is a cycle -> return a typed CycleError carrying the participating keys, unwind cleanly, and never cache a partial result. Query graphs must be acyclic at runtime (§6, §7).

Garbage Collector. Bounds memo memory. Combines LRU (evict least-recently-demanded memos first) with a reachability sweep (a memo reachable only from already-evicted memos and not currently demanded is collectible). Honors a configured memory ceiling (§4). Eviction is always safe: a missing memo is simply recomputed on next demand (the oracle property — the engine is a cache, never the source of truth for derived values).

Parallel Executor (Phase 9). A thread pool that evaluates independent demanded queries concurrently. A per-key compute lock ensures two threads never recompute the same key simultaneously (the second waits on the first). A CancellationToken lets the host abandon an in-flight demand (e.g. a superseded IDE request); cancellation is cooperative — checked at demand boundaries. Cross-thread sharing of the Memo Cache and Input Cell Store is the central concurrency hazard the design controls.

ice-trace. The observability sink. Receives structured events (reuse, recompute, backdate, cutoff-fired, cycle, eviction, revision-bump), maintains counters (reuse ratio, recomputes per revision, memo count, bytes), and can dump the DDG as DOT/JSON for offline inspection. Emits tracing spans so a host can correlate engine work with its own.

8. Domain Model

The domain is a dynamic dependency graph (DDG) of two node kinds (inputs, derived queries) connected by versioned dependency edges, evaluated against a monotonic revision clock.

Node and edge schema

Node        := Input | Derived
Input       := { key: QueryKey, value: V, changed_at: Revision, durability: Durability }
Derived     := { key: QueryKey, memo: Option<Memo> }          // None => never computed / evicted
Memo        := { value: V, verified_at: Revision, changed_at: Revision,
                 durability: Durability, deps: Vec<Dependency>, state: NodeState }
Dependency  := { node: NodeId, changed_at_when_read: Revision } // versioned reverse-checkable edge
NodeId      := u32                                              // interned, dense
QueryKey    := (QueryTypeId, KeyBytes)                          // identifies one node
Durability  := Low | Medium | High                             // High = changes rarely
NodeState   := Unverified | Verifying | Verified(Revision) | MaybeDirty | Computing
Revision    := u64                                             // monotonic, global

Forward edges live in each memo's deps; reverse edges live in a separate dependents: NodeId -> SmallVec<NodeId> index maintained alongside.

Node state transition table

From Event To Side effects
(absent) first demand Computing push DependencyStack frame
Computing QueryFn returns, value Eq old (or first run) Verified(R) verified_at=R; changed_at set (R if first run, else kept)
Computing QueryFn returns, value !Eq old Verified(R) verified_at=R; changed_at=R
Computing re-entrant demand of self (error) emit CycleError; do not cache
Verified(R) current_rev advances, this node a maybe-dirty dependent MaybeDirty clear fast-path eligibility
Verified(R) demand, R == current_rev Verified(R) green hit; return memo value
MaybeDirty demand; all deps' changed_at <= verified_at Verified(cur) backdate: verified_at=cur, value reused (deep cutoff)
MaybeDirty demand; some dep changed Computing recompute path
MaybeDirty demand; a dep is itself MaybeDirty Verifying recurse: validate dep first, then re-decide
any GC eviction (not on stack) (absent) drop memo; reverse edges removed
Verifying dep validation completes MaybeDirty/Computing resume the decision with fresh dep timestamps

Worked example — A=1, B=A+1, C=B*2

Inputs/queries: input A; derived B = A + 1; derived C = B * 2. Reverse edges: A -> {B}, B -> {C}.

Cold build at R0 (set_input(A, 1) made R1; demand C):

demand C@R1 -> no memo -> Computing
  demand B@R1 -> no memo -> Computing
    read A -> value 1, A.changed_at=R1; record edge C? no: edge on B's frame: (A, changed_at=R1)
  B computes 2; verified_at=R1, changed_at=R1, deps=[A@R1]
  read B (edge on C's frame): (B, changed_at=R1)
C computes 4; verified_at=R1, changed_at=R1, deps=[B@R1]
Result: C=4. Recomputes: B,C (2). Reuses: 0.

Real edit — set_input(A, 5) (-> R2), demand C:

set_input(A,5): 5 != 1 -> bump to R2; A.value=5, A.changed_at=R2
  dirtying: reverse-closure(A) = {B, C} marked MaybeDirty
demand C@R2 -> MaybeDirty -> validate deps:
  dep B (changed_at_when_read=R1): demand B@R2 -> MaybeDirty -> validate deps:
    dep A: A.changed_at=R2 > B.verified_at(R1) -> A changed -> recompute B
    B recompute: reads A=5 -> 6; 6 != 2 -> changed_at=R2, verified_at=R2, deps=[A@R2]
  back in C: B.changed_at=R2 > C.verified_at(R1) -> recompute C
  C recompute: reads B=6 -> 12; verified_at=R2, changed_at=R2
Result: C=12. Recomputes: B,C (2 — all affected). Reuses: 0. Correct = from-scratch.

Early cutoff — set_input(A, 5) again (already 5):

set_input(A,5): 5 == 5 (Eq) -> NO-OP; clock stays R2. Input-level cutoff.
demand C@R2 -> Verified(R2) == current -> green hit. Recomputes: 0.

Deep cutoff example — make B output insensitive. Redefine B = min(A, 10). At R2, A goes 5 -> 8 (R3):

set_input(A,8) -> R3; dirty {B,C}
demand C@R3 -> MaybeDirty -> validate B:
  B MaybeDirty -> A.changed_at=R3 > B.verified_at(R2) -> recompute B
  B recompute: min(8,10)=8 ... wait prior B was min(5,10)=5; 8 != 5 -> changed_at=R3
  (cutoff would fire only if new B Eq old B)

Now A goes 8 -> 12 (R4) with B = min(A, 10):

set_input(A,12) -> R4; dirty {B,C}
demand C@R4 -> validate B:
  recompute B: min(12,10)=10; prior B (at R3) = 8; 10 != 8 -> changed (no cutoff here)

And A goes 12 -> 20 (R5):

recompute B: min(20,10)=10; prior B = 10; 10 Eq 10 -> CUTOFF: verified_at(B)=R5, changed_at(B) stays R4
back in C: B.changed_at=R4 <= C.verified_at(R4)? C last verified at R4 -> R4 <= R4 -> B did NOT change since -> backdate C: verified_at(C)=R5, no recompute.
Result: C reused. Recomputes: B only (1). C cut off by B's firewall.

Malformed / failure-path examples

Case Setup Expected behavior
Direct cycle A_q = f(A_q) (query reads itself) CycleError{cycle:[A_q]} on first demand; nothing cached.
Indirect cycle X = g(Y), Y = h(X) CycleError{cycle:[X,Y]}; both frames dropped; optional fixpoint recovery (§19).
Dangling dep after GC C's dep B evicted, then C demanded B is absent -> recompute B on demand (INV-10); C validates against fresh B.
Wall-clock read T = now() inside a query INV-9: debug re-run diff flags it; if #[query(nondeterministic)], never memoized; else contract breach.
Equality lie V whose Eq returns true for unequal values INV-4/INV-1 differential test diverges; shrink to the lying type.
Phantom edge query records a read it never used INV-5 read-set replay mismatch (debug).
Missed edge query reads input via a back-door INV-5 mismatch + eventual stale read (INV-3) when that input changes.
Durability lie volatile input marked High INV-12 force-Low differential test diverges.
Revision wrap current_rev == u64::MAX INV-2: panic! (unreachable in practice; ~5.8e11 yr at 10^9 bumps/s).
