A — Downstream Clients. Untrusted, trust boundary #1. Five protocol surfaces multiplex at the TLS/ALPN layer; the proxy never assumes a well-behaved client.

B — Listener. One shard per core via SO_REUSEPORT (ADR-17) to avoid a single accept-queue bottleneck at the 100K-rps/core target (§4). Performs the TLS handshake and demultiplexes by ALPN into the h1/h2/h3 codec chosen for the connection.

C — Request Pipeline. The concurrency boundary is one Tokio task per connection; stages exchange no mutable state except the read-only Arc<Config> snapshot captured at accept time (invariant I1, §7). This is what makes hot reload (H) safe without per-request locking.

D — Cache. Persistence boundary #2: an in-memory LRU backed optionally by a disk tier. The only stage besides logging that writes state surviving a single request.

E — Upstream Selection. Applies the configured load-balancing policy over the health-filtered endpoint set (§8), then checks out a connection from that endpoint's pool.

F — Origin Services. Trust boundary #2; mTLS to the upstream is optional per pool (ADR-05, ADR-13).

G — Response Path. Mirrors C in reverse; the cache store decision happens here, distinct from D's lookup — a response is evaluated for cacheability only after the full response head is available.

H — Control Plane. The only external interface besides the client-facing listener; mTLS-only (P9, §6) or a Unix domain socket. Owns the generation-tagged atomic Config swap that Phase 11 (§23) makes zero-downtime.

I — Observability. An async channel decouples request-path latency from exporter I/O; OTLP export is best-effort and drops silently under exporter unavailability (P10, §6) rather than blocking the request path.

J — Edge Runtime. Invoked synchronously from stage C under a hard wall-clock, memory, and instruction budget (P6, §6). The only place tenant-supplied logic executes; sandboxed per the Sandbox-Execution reference design (§5).

Draining SIGTERM or config-generation retirement → Closed once in-flight requests complete or timeout elapses bounded by drain timeout (I2, ADR-20)

Request Lifecycle State Machine

Received → Parsed → Routed → Authenticated → WafEvaluated → EdgeEvaluated → CacheChecked → UpstreamSelected → UpstreamForwarded → ResponseReceived → Transformed → CacheStored → Sent → Logged

Each arrow is a pipeline stage from §3 box C/D/E/G. A stage may short-circuit directly to Transformed/Sent (WAF block at WafEvaluated, cache hit at CacheChecked, edge-program generated response at EdgeEvaluated) — the state machine is a DAG with Sent reachable from five different upstream states, never a strict linear pipeline once short-circuits are drawn. Logged is unconditional (I14) regardless of which path reached Sent.

Load-Balancing Algorithms

Policy Selection Rule Complexity Regime Where It Wins
RoundRobin next endpoint in fixed cyclic order O(1) homogeneous backend latency, uniform request cost
LeastConn endpoint with fewest in-flight requests O(log n) with a heap heterogeneous request duration, connection-oriented backends
PowerOfTwoChoices (default) sample 2 endpoints at random, pick the less-loaded O(1) large N, avoids the herding failure mode of pure least-conn under synchronized probes (Mitzenmacher, §5)
ConsistentHash hash(key) → ring position → nearest endpoint clockwise O(log n) session affinity / cache-locality-sensitive backends; bounded remapping on membership change (Karger et al., §5)
Random uniform random endpoint O(1) stateless baseline for differential testing against the others

Worked Example — Full Request Trace

GET /api/users/42 HTTP/1.1, Host: api.example.com, Authorization: Bearer <jwt>. Trace: (1) Parsed — h1 codec yields a Request with method=GET, uri.path=/api/users/42; (2) Routed — router matches Matcher{host: Exact("api.example.com"), path: Prefix("/api/")} at priority 100, binds RouteId(7), emits x-route-id: 7; (3) Authenticated — JWT verified against cached JWKS, Principal::Jwt{sub: "u_42", ...}; (4) WafEvaluated — 0 rule matches, Pass; (5) EdgeEvaluated — no edge program configured on this route, no-op; (6) CacheChecked — cache key (GET, /api/users/42, vary=[]) misses; (7) UpstreamSelected — P2C samples endpoints 3 and 7, picks endpoint 3 (fewer in-flight); (8) UpstreamForwarded — request sent over a pooled h1 keep-alive connection; (9) ResponseReceived — 200, Cache-Control: max-age=60; (10) Transformed — response-scope transforms (none configured) no-op; (11) CacheStored — entry stored, fresh_until = now + 60s; (12) Sent; (13) Logged — one JSON access-log line with route_id=7, upstream=3, cache_status=Miss, status=200, duration_us=<n>.

Malformed-Input Example

POST /upload HTTP/1.1 with both Content-Length: 100 and Transfer-Encoding: chunked present (the CL.TE smuggling shape, section 6.3 of RFC 9112). Per I4/P14 and the h1 codec contract (§12 (0.2)): the codec rejects the request at Parsed with 400 Bad Request, closes the connection (never attempts to guess which header wins), and increments smuggling_attempt_rejected_total. The request never reaches Routed. Conformance bucket h1/smuggling fixes this as a regression case (§12 (0.5)).

Failure-Path Example

Upstream connection reset mid-response, after headers were flushed to the client but before the body completed. The proxy cannot recall sent bytes; it cannot retry (retrying would duplicate a partially delivered response — P7's method-aware retry policy, §14 (2.2), only retries before any byte reaches the client). Recovery: the h1/h2 codec terminates the downstream stream with an incomplete-body signal (chunked: no terminating 0\r\n\r\n; content-length: fewer bytes than declared, which well-behaved clients detect as a truncated response), increments upstream_reset_midresponse_total, ejects the upstream connection from the pool (I3), and emits a Logged entry with outcome=upstream_reset_midresponse for postmortem correlation (§25 FM-3).

Design principles (§6)

  • P1 — Connections survive config reloads. A configuration change drops zero in-flight requests; the old generation stays alive for every request that started under it. Tradeoff: bounded memory held per stale generation (I1). Violate it and every config push becomes a mini-outage.
  • P2 — Routing is deterministic and explainable. Given a request and a configuration, the route match is a pure function; an admin-only x-route-id header names the matched route. Violate it and on-call cannot explain "why did this request go there."
  • P3 — The cache is RFC 9111 with extensions, never RFC-9111-inspired. Extensions (surrogate keys, Cache-Tag) never override an RFC "do not cache." Violate it and the cache becomes an unbounded liability (stale/incorrect responses).
  • P4 — TLS is terminated, not snooped. Passthrough routes never decrypt; terminating routes zeroize keys on drop and never log or forward key material. Violate it and a single log line becomes a key-compromise incident.
  • P5 — The WAF blocks before it opens an upstream connection. A blocked request never reaches an upstream, partially or fully. Violate it and the WAF becomes advisory rather than a boundary.
  • P6 — Edge programs are sandboxed, time-bounded, memory-bounded. Default budget: 1 ms wall-clock, 2 MiB memory, a fixed host-function allow-list. The runtime enforces the budget; the program's cooperation is never assumed. Violate it and one tenant's bug is every tenant's outage.
  • P7 — Upstream connections are pooled and never trusted blindly. A connection is health-checked before reuse; one that returns 5xx or a frame-parse error is ejected, never recycled. Violate it and errors compound across requests sharing the poisoned connection.
  • P8 — One configuration source, multiple formats. YAML/TOML/JSON/Caddyfile-style all parse to one internal Config; no per-format code path exists past parsing. Violate it and every feature must be implemented N times.
  • P9 — The control plane is mTLS-only. No plaintext admin endpoint exists, ever, even on localhost. Violate it and local-privilege escalation becomes remote-privilege escalation.
  • P10 — Observability is the default, not the opt-in. Every request emits an access-log line and bumps RED counters; OTLP export drops silently if the collector is absent rather than blocking. Violate it and incidents become undebuggable, and violate the "never block" half and an observability outage becomes a request-path outage.
  • P11 — Backpressure is explicit, never infinite queuing. Every queue (accept backlog, pool checkout, edge-program dispatch) has a bounded depth and a documented rejection policy. Violate it and a slow downstream turns into unbounded memory growth.
  • P12 — Time is a single injectable source. All timeouts, cache freshness math, and health-check scheduling read from one Clock abstraction, mockable in tests. Violate it and tests become flaky and untestable against clock skew.
  • P13 — Every error variant maps to exactly one client-visible status code. RevpError variants are exhaustive and each names its HTTP status (§11 RevpError). Violate it and clients see inconsistent status codes for the same underlying failure.
  • P14 — Hop-by-hop headers never cross the proxy boundary unmodified. Connection, Keep-Alive, TE, Trailers, Transfer-Encoding, Upgrade, Proxy-Authenticate, Proxy-Authorization are stripped per section 7.6.1 of RFC 9110, with an explicit allow-list exception for Upgrade on WebSocket routes. Violate it and protocol-layer state leaks across a boundary that must not see it.
