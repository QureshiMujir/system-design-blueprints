4. System Constraints

All targets: x86-64, single core, release build, MSRV 1.78, std-only. LTL model checking is PSPACE-complete → worst-case unbounded. Every engine honors explicit budgets or reports Unknown (never crash, never silent wrong answer).

4.2 Soundness & Completeness

Engine CEX guarantee "Holds" guarantee
Explicit (reach/invariant/nested-DFS) always a real run (concrete Trace) sound+complete within explored set; Unknown if budget exceeded
Symbolic (CTL fixpoint) sat-set witness decodes to real path sound+complete when fixpoint converges in budget
BMC (depth k) real length-≤k run decoded from SAT model sound only up to k; Unknown unless k ≥ completeness threshold

No panic on untrusted input — parse_model returns Result<_, ParseError> for any byte stream. Single-threaded engines; no global mutable state; same model+seed ⇒ byte-identical verdict + CEX.
