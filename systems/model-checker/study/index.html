Mental Models & First Principles

MM1 — Verification is language-emptiness. A temporal property φ holds on system M iff no run of M satisfies ¬φ — equivalently, L(M) ∩ L(Buchi(¬φ)) = ∅. Every engine answers this question; the engines differ only in how they represent and search the infinite set of runs.

MM2 — State = packed valuation, not object. A model-checking state is a bit-vector of variable values, not a pointer or object. This determines memory: 8–48 B/state decides whether 10^8 states fits in 4 GB or not. Every design choice about State, StateEncoder, and StateTable flows from this.

MM3 — On-the-fly ≡ no graph stored. The next() closure generates successors from a state without consulting a pre-built adjacency list. This means a reachable accepting cycle can be found before the entire reachable state space is explored — critical for liveness checking when the graph is too large to store.

MM4 — Fixpoints are set iterations, not loop enumerations. EX Z = {s | ∃s'. T(s,s') ∧ s'∈Z} is a set transformer. BDDs let you compute the next iterate without enumerating each element of Z — so 10^20 states may occupy a BDD of 10^5 nodes when the function is structurally simple.

MM5 — CTL uses least fixpoint (EU) for "eventually" and greatest fixpoint (EG) for "always". This is Knaster-Tarski: the least fixpoint of a monotone operator over a complete lattice is the limit of iterating from ⊥ (empty set) upward; greatest from ⊤ (all states) downward. Swapping them gives a wrong answer, not a runtime error.

MM6 — BDD canonicity is the invariant, not a property. Every Boolean function has exactly one ROBDD node-graph under a fixed variable order and the two reduction rules. If two nodes differ structurally under the same manager and order, they represent different functions — you can compare BddRef by equality instead of truth-table comparison.

MM7 — Counterexamples are lassos, not trees. A Kripke structure M has a finite reachable state space. Any infinite run either visits a repeated state (lasso) or contradicts finiteness. So every liveness CEX is representable as prefix·cycle^ω — a finite datum that simulate can replay step by step.

MM8 — Partial-order reduction preserves the property, not the state space. POR (ample sets C0–C3) selects a subset of enabled transitions at each state such that the checked LTL_-X property has the same verdict over the reduced graph. The reduced graph is not isomorphic to the full graph — it may have different reachable states.

MM9 — Three engines, one semantic model. All three engines consume the same TransitionSystem produced by mc-lang::compile. They cannot disagree due to different interpretations of the model — only due to bugs. Agreement is therefore a correctness oracle, not a coincidence.

MM10 — "Unknown" is the only safe failure mode. Any resource ceiling, encoding limit, or verification timeout that cannot produce a proved or refuted verdict MUST return Unknown(reason). Collapsing a resource limit into Holds is a soundness violation; into a crash is a reliability violation.

Glossary · 38 terms · site-wide glossary

Kripke structure
KripkeStructure (mc-types): finite state graph (S, S0, R, L) — states, initial states, total transition relation, labeling. The fully-enumerated model the explicit CTL labeler consumes; cf. TransitionSystem (lazy form).
transition system
TransitionSystem (mc-types): the shared semantic model all three engines consume. Carries initial: Vec<State>, a next closure (successors), a label closure, and props. Lazy — successors generated on demand, not stored.
state
State { bits: BitVec } (mc-types): one bit-packed valuation of all model variables. Produced/decoded by StateEncoder. Hashed + interned into StateTable; dominant explicit-memory unit.
StateId
StateId(u64) (mc-types): hash/index handle to a visited State in the StateTable. Endpoints of a Transition.
atomic proposition
AtomicProp(u32) (mc-types): interned id for a boolean fact over a State (e.g. pc==crit). Leaves of LtlFormula/CtlFormula; basis of Label.
labeling
label: Fn(&State)->Label and Label(BitSet) (mc-types): the AtomicProps true in a state; the L of the Kripke structure; consulted by Buchi edge guards and CTL Ap evaluation.
safety / liveness / invariant
Safety: "nothing bad ever happens" — finite-prefix witness; check_invariant. Liveness: "something good eventually happens" — infinite-run witness, needs nested_dfs+Buchi. Invariant: G p over all reachable states.
reachability
Set of states reachable from initial via next. Explicit: reachable() via StateTable; Symbolic: BDD μZ.Init∨image(TR,Z).
on-the-fly / explicit-state / symbolic
On-the-fly: states generated during search, no graph stored. Explicit-state (mc-explicit): enumerates individual States into StateTable. Symbolic (mc-symbolic): represents sets as BDDs; tractable even for 10^20 states.
LTL
Linear Temporal Logic. LtlFormula (mc-ltl); operators over a single run. Checked via negate→Buchi→product→emptiness.
CTL
Computation Tree Logic. CtlFormula (mc-symbolic); branching-time, path quantifiers A/E paired with temporal ops. Checked by fixpoint labeling.
negation normal form (NNF)
to_nnf (mc-ltl): pushes Not to atoms via dualities (!F=G!, !Xp=X!p, !U↔R). Temporal ops: X/Next, F/Finally, G/Globally, U/Until, R/Release; CTL prefixes each with A/E. Prereq for GPVW.
Buchi automaton
BuchiAutomaton (mc-ltl): ω-automaton with accepting set; accepts runs visiting an accepting state infinitely often. Built from !phi by ltl_to_buchi.
accepting cycle / lasso
Reachable cycle in the product containing an accepting state of BuchiAutomaton. = nonempty product language = CEX. Represented as Trace{prefix, cycle:Some(..)}. Generalized Buchi (multiple accepting sets) degeneralized via counter before nested_dfs.
product automaton
Product (mc-explicit): synchronous product TransitionSystem × BuchiAutomaton(!phi). Its accepting cycles are exactly runs of the system violating phi.
language emptiness
Decision "does the product accept any run?". Empty ⇒ phi holds; nonempty ⇒ lasso CEX. Decided on-the-fly by nested_dfs.
nested DFS
nested_dfs (mc-explicit): outer DFS finds accepting states in post-order; inner DFS from each seeks a path back to the outer stack (accepting cycle). O(states+transitions), constant extra colors.
counterexample
Trace (mc-types): concrete witness a property fails — finite path (safety) or lasso (liveness). Replayable via simulate.
fairness
Constraint restricting attention to "fair" runs. Weak: continuously-enabled ⇒ eventually taken. Strong: infinitely-enabled ⇒ infinitely taken. Encoded into the LTL/Buchi pipeline.
ROBDD
Reduced Ordered Binary Decision Diagram (mc-bdd): canonical DAG for a Boolean fn under a fixed variable order + reduction rules. Canonical ⇒ equality = pointer compare.
BDD node
BddNode{var, lo, hi} (mc-bdd): decision on variable var, branching to lo (=0) / hi (=1) child BddRefs.
unique table
BddManager hash HashMap<BddNode,BddRef>: ensures structural sharing — no two equal nodes — enforcing canonicity.
computed cache
BddManager memo of ite(f,g,h) triples → results. Turns exponential recursion into polynomial; eviction policy bounds memory.
complemented edge
BddRef(u32) with a sign/complement bit: edge denoting the negation of its target. Halves table size; not is O(1) edge flip.
variable order
Permutation of BDD variables in BddManager. Dominates BDD size (polynomial vs exponential for same fn); interleaving current/next vars usually best for TransitionRelation.
sifting / reordering
Dynamic variable-reordering heuristic (mc-bdd, Phase 11): slide each variable to its size-minimizing position. Reduces peak nodes mid-run.
ite / apply
BddManager::ite(f,g,h) = "if f then g else h" — the universal apply; and=ite(a,b,0), or=ite(a,1,b), not=edge flip. Recurses on top variable, memoized by computed cache.
image
Forward successor set: `{s'
pre-image
pre_image (mc-symbolic): backward = `{s
least / greatest fixpoint
Fixpoint iteration over BDD sets. E[p U q] = LFP of q ∨ (p ∧ EX Z); EG p = GFP of p ∧ EX Z. Converge when the set BDD stops changing.
transition relation
TransitionRelation{bdd} (mc-symbolic): T(s,s') over current × next-state variables as a single BDD. Subject of image/pre_image.
bounded model checking
bmc (mc-symbolic/mc-bmc): seek a CEX of length ≤ k by unrolling T into CNF and solving. CEX found ⇒ violated; UNSAT to completeness threshold ⇒ holds.
completeness threshold
Depth k at which BMC UNSAT proves phi (e.g. recurrence diameter). Below it, UNSAT means only "no CEX ≤ k". Unrolling: I(s0)∧⋀T(si,si+1)∧bounded(!phi) → CNF → SAT.
state explosion
#reachable states (and product/BDD size) grows exponentially in variables/processes. The central obstacle; motivates symbolic encoding + reductions.
partial-order / symmetry / abstraction
POR (Phase 11): expand only an ample set (C0–C3) of enabled transitions — others independent+invisible to phi. Symmetry: quotient by orbit, explore one canonical representative. Abstraction (Phase 12): map concrete→abstract states (lite predicate abstraction); may introduce spurious CEXs.
CEGAR
Counterexample-Guided Abstraction Refinement (Phase 12): abstract → check → if spurious CEX replay fails → refine predicates → repeat.
StateTable
(mc-types) open-addressing hash set State → StateId of visited states. The dominant explicit-state memory cost; sizing/load-factor decide whether a model fits in RAM.
StateEncoder
(mc-lang) maps each VarDecl to a bit range; encode/decode State ↔ valuation. Defines the bit layout shared by explicit packing and symbolic BDD variables.
