Decisions (§9) · 26 ADRs

1

Implementation language

Chosen

Rust 2021, MSRV 1.78

Rejected

C/C++; Go; Python

When the rejected choice is right

C/C++ when piggybacking an existing C codebase (MiniSat/CaDiCaL forks); Python for a teaching prototype / spec exploration where speed is irrelevant

Why: Hot loop indexes huge arrays from untrusted bytes ⇒ memory safety mandatory; zero-cost abstractions + manual layout + ownership models arena/watcher aliasing

2

Project structure

Chosen

Cargo workspace, 6 crates (sat-types/cnf/solver/preproc/proof/cli)

Rejected

Monolith crate; one crate per algorithm

When the rejected choice is right

Monolith for a <2k-LOC throwaway where the build-graph overhead outweighs layering; per-algorithm crates if each ships independently versioned

Why: Clean layering (types ⟵ all; solver isolated), parallel build, independent fuzz/bench, enforced DAG

3

Clause storage

Chosen

ClauseArena of bump u32 words; ClauseRef(u32) offset (DST Clause=header+inline [Lit])

Rejected

Vec<Clause>; Box<[Lit]>/clause; Rc<Clause>

When the rejected choice is right

Box<[Lit]> if clauses never relocate and per-clause lifetime/sharing matters (e.g. a clause-DB shared by Rc across portfolio threads)

Why: Inline lits = one cache line; u32 handle = half a pointer + survives compaction

4

Literal encoding

Chosen

Lit = 2*var+sign; !lit=^1; var()=>>1

Rejected

Signed i32 (±v); struct{var,sign}

When the rejected choice is right

Signed i32 at the DIMACS I/O boundary (it is the wire format) — kept there, converted once at parse

Why: Flat LitMap of 2*nvars indexed by lit.0; negation 1 instr

5

Truth value

Chosen

enum LBool{True,False,Undef} u8

Rejected

Option<bool>; two bool bitsets

When the rejected choice is right

Dual bitsets when SIMD-scanning many clauses' satisfiedness in bulk (vectorized preprocessing), not the scalar BCP loop

Why: Tri-valued intrinsic; branch-free value(lit) via assigns[var]^sign

6

BCP scheme

Chosen

Two watched literals (Watcher{cref,blocker}, watches:LitMap<Vec<Watcher>>)

Rejected

Counter-based; head/tail pointers

When the rejected choice is right

Counter-based for cardinality/PB constraints where a count is the natural state, or fixed-assignment model-counting with no backtrack

Why: NO watch update on backtrack ⇒ O(1) backjump; blocker skips arena load

7

Conflict analysis

Chosen

1-UIP

Rejected

All-UIP; last-UIP; no learning (DPLL)

When the rejected choice is right

No-learning DPLL for tiny/random-3SAT where learning overhead exceeds payoff; all-UIP in research probing maximum propagation per conflict

Why: Best quality/size tradeoff (MiniSat/Glucose/CaDiCaL consensus): single asserting lit, smallest clause, enables backjump

8

Branching

Chosen

VSIDS (Vsids{activity,inc,decay,heap}) + phase saving

Rejected

DLIS; static MOM/Jeroslow-Wang; random; LRB

When the rejected choice is right

LRB (PhaseDeferred("Deferred Features Register")) wins on many UNSAT crafted families (Liang 2016); static JW for very short solves where burn-in dominates

Why: Conflict-driven locality, O(1) bump, Chaff/MiniSat standard

9

Polarity

Chosen

Phase saving (PhaseSaving{saved})

Rejected

Always-false (MiniSat); always-true; random

When the rejected choice is right

Always-false at the very first decisions before any phase memory exists; random polarity inside a diversified portfolio worker

Why: Reuses last polarity after backjump ⇒ exploits solution-locality, near-free

10

Restart policy

Chosen

Glucose-LBD dynamic + blocking; Luby fallback

Rejected

Fixed-interval; geometric; none

When the rejected choice is right

Luby for crafted/random instances with sharp heavy tails (Luby 1993 optimality); no-restart for trivially-SAT inputs solved before the first restart

Why: Adapts to hardness (restart when recent glue worsens); blocking keeps near-model progress

11

Clause-DB reduction

Chosen

LBD-primary: keep LBD≤2 forever, drop high-LBD/low-activity half

Rejected

Activity-only (MiniSat); size-only; never delete

When the rejected choice is right

Activity-only on application instances where reuse-frequency tracks better than glue; never-delete when the whole DB fits in cache and BCP stays fast

Why: LBD predicts usefulness better than activity (Glucose)

12

Preprocessing

Chosen

BVE + Subsumption + SSR + Vivification (sat-preproc), EliminatedClauseStack recon

Rejected

None; preproc-only

When the rejected choice is right

No-preproc when proof-step fidelity must be minimal and BVE proof-logging cost is unacceptable; preproc-only for one-shot batch with no learnt feedback

Why: Shrinks formula 2–10× on structured CNF; recon restores eliminated vars on SAT

Inprocessing

Chosen

Interleave simplification with search (Phase 9), conflict-budgeted

Rejected

One-shot preprocessing only

When the rejected choice is right

One-shot preproc on short solves where the inprocessing scheduler never reaches its first trigger; pure preproc when reproducibility forbids mid-search formula change

Why: Learnts expose new BVE/subsumption; bounded interleaving (CaDiCaL) amortizes

38. Alternative Architectures (Roads Not Taken)

Fundamentally different designs for the same "decide one CNF" problem.

Alt-1 — Pure DPLL (chronological backtracking, no learning).

decide → propagate → conflict? backtrack one level + flip : decide   (no analyze, no learnt DB)

Wins when: tiny or near-uniform-random instances where the learnt DB + analyze overhead exceeds the pruning payoff (and as the Phase-3 correctness oracle). Real system: original DPLL (Davis-Logemann-Loveland 1962); early GRASP variants. Rejected: chronological backtrack re-derives the same conflicts → exponential blowup on structured industrial CNF; loses the asserting-clause leverage that is the whole point of CDCL (ADR-7).

Alt-2 — Stochastic local search (WalkSAT-style).

random total assignment → loop { pick an unsat clause → flip a var in it (greedy/noise) } → stop at a model

Wins when: satisfiable, under-constrained random instances near/below the phase transition, where it finds models orders of magnitude faster than CDCL. Real system: WalkSAT / probSAT (Selman, Kautz, Cohen). Rejected: cannot prove UNSAT (no certificate, no completeness) — violates the non-negotiable proof-carrying-UNSAT contract (P6.1/P6.9); useless for the SMT/BMC consumers that need a checkable no.

Alt-3 — Look-ahead / cube-and-conquer.

look-ahead picks a strong split var by trial-propagating both polarities (failed-literal detection)
└─ cube phase splits the formula into N subcubes → conquer each with a CDCL solver (parallel)

Wins when: hard combinatorial/crafted instances (parity, pigeonhole, van der Waerden numbers) and massively parallel hardware — cube-and-conquer solved open math problems (e.g. Boolean Pythagorean triples, Heule 2016). Real system: march (look-ahead); cube-and-conquer (march + CDCL). Rejected here: look-ahead's per-decision trial propagation is far too slow on large application CNF (ADR-8 rejected look-ahead branching); cube-and-conquer needs a parallel substrate this single-process core defers to the portfolio stretch.
