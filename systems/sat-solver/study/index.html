34. Mental Models & First Principles

The compressed insights an expert holds. Each: the model · what it predicts · the bug class you write without it · where this blueprint applies it.

  • MM1 — Conflict analysis IS resolution; a learnt clause is a resolvent chain. Predicts: every learnt clause is entailed (RUP-derivable), so UNSAT is just deriving the empty clause; learnt-clause quality is resolution-proof quality. Without it you treat analyze() as ad-hoc bookkeeping and add "optimizations" that learn non-implied clauses → false UNSAT. Applies: §16 (Phase 4), §22 (Phase 10), P6.3/P6.15, I3.
  • MM2 — A watched literal is a lazy "wake me when you might matter" subscription; the invariant survives undo without repair. Predicts: O(1) backjump (no watch fixup), and that a clause is touched only when a watch falsifies. Without it you "fix up" watches on backtrack (slow) or skip a falsified clause (missed unit → unsound). Applies: §14 (Phase 2), §24 (Phase 12), ADR-6, I1.
  • MM3 — VSIDS is recency-weighted activity with lazy decay; bump the increment, never the scores. Predicts: O(1) decay, and that branching tracks the current conflict frontier. Without it you rescale all activities every conflict (O(n) hot-loop death) or break heap order on overflow. Applies: §18 (Phase 6), §24, ADR-8, I6.
  • MM4 — A no answer is worthless without a certificate; trust the proof, not the prover. Predicts: a watch/analyze bug degrades to caught (checker rejects) not wrong, because an independent RUP/RAT engine re-derives ⊥. Without it a single kernel bug silently poisons every downstream. Applies: §22 (Phase 10), Threat Model TB-2, P6.1/P6.9, I9.
  • MM5 — Runtime is heavy-tailed, so restart and diversify rather than push one search. Predicts: restarts help (escape a bad subtree), Luby/Glucose-LBD beat fixed intervals, portfolio gives superlinear speedup. Without it you tune for the mean and stall on the tail. Applies: §19 (Phase 7), Scalability Analysis, ADR-10, MM-link to portfolio.
  • MM6 — The solver is a pure function of (CNF, seed, config); determinism is the debugger. Predicts: any failure replays bit-for-bit, so bisection/ddmin work. Without it (HashMap iteration, wall-clock, threads in the core) failures are unbisectable flakes. Applies: §17 (Phase 5), Compatibility & Versioning, P6.8.
  • MM7 — Clauses live in one arena addressed by handles; compaction rewrites the handle table, not the holders' minds. Predicts: a ClauseRef survives relocation but a &Clause/pointer dangles; compaction must rewrite every live ref in one pass. Without it you cache a slice across add_clause → use-after-realloc. Applies: §24 (Phase 12), Core Schema & Types, ADR-3, P6.5.
  • MM8 — Heuristics only order; the kernel decides what is correct. Predicts: swapping VSIDS/restart/reduceDB changes speed, never the verdict — so you can tune fearlessly behind a frozen core. Without it a "smart" rule hard-assigns outside enqueue, corrupting the implication graph → unsound learnt. Applies: §18–§19, Compatibility & Versioning, P6.6.

Glossary (§40) · 53 terms · site-wide glossary

CNF / clause / literal
input = AND of clauses (OR of literals); Cnf{nvars,clauses,arena}, Clause DST in ClauseArena, Lit(u32)=2*var+sign. (full semantics §8.1)
unit clause
exactly one unassigned literal (rest false) → forced true; detected in propagate().
empty clause
zero/all-false literals = unconditional conflict; deriving it proves UNSAT + ends a DRAT proof.
DPLL
Davis–Putnam–Logemann–Loveland: decide→propagate→chronological backtrack. Phase-3 baseline.
CDCL
DPLL + conflict analysis + learnt clauses + non-chronological backjump. Core search(), Phase 5.
BCP / unit propagation
enqueue forced literals from unit clauses to fixpoint/conflict. propagate().
two watched literals
inspect a clause only when one of its 2 watches falsifies; NO restore on backtrack.
watch list
watches: LitMap<Vec<Watcher>> keyed by the falsified literal.
blocker literal
cached 2nd-watch lit in Watcher; if true, skip dereferencing the clause (cache opt).
trail
Trail{lits,lim} chronological assignment stack; lim[d] = start index of level d.
decision level
count of decisions on the trail; level: VarMap<u32>; level 0 = unconditional.
decision literal
branched (pick_branch), not forced; Reason::Decision; opens a level.
implication graph
DAG of forced assignments (antecedent edges → implied lit); walked by analyze().
antecedent / reason
the clause that forced an assignment. Reason{Decision,Clause(ClauseRef),Unit}.
conflict clause
a clause falsified under the trail; propagate()→Some(cref) seeds analyze().
conflict analysis
analyze(): resolve the conflict clause backward through antecedents → learnt + backjump.
1-UIP
First Unique Implication Point: resolve until exactly ONE current-level lit remains (the asserting lit).
asserting clause / literal
The learnt clause; after backjump it has exactly one unassigned literal (the asserting literal) which it immediately propagates.
backjump (non-chronological)
Jump directly to the 2nd-highest decision level among learnt-clause literals (0 if unit), skipping intervening levels. backjump(level).
backtrack (chronological)
DPLL-style: undo exactly one decision level. Used in Phase 3 baseline only; CDCL uses backjump.
VSIDS
Variable State Independent Decaying Sum: branch on max-activity unassigned variable. Vsids { activity, inc, decay, heap }.
activity
Per-variable score (VarMap<f64>); bumped when a variable appears in conflict-side clauses; inc *= 1/decay per conflict; rescale all on overflow.
phase saving
Reuse a variable's last-assigned polarity on re-decision. PhaseSaving { saved: VarMap<bool> }.
restart
Abandon current assignment back to level 0, keeping learnt clauses; diversifies search. RestartPolicy.
Luby restart
Restart intervals following the Luby sequence (1,1,2,1,1,2,4,…) × unit; the fallback policy.
Glucose-LBD restart
Dynamic: fire when recent-LBD fast EMA > K × slow EMA (search is producing high-glue clauses).
blocking restart
Suppress a restart when the trail is unusually long (search looks productive), to avoid throwing away progress.
LBD / glue
Literal Block Distance = number of distinct decision levels among a learnt clause's literals. LBD-2 = "glue". Stored in ClauseHeader.lbd.
learnt clause
Clause derived by analyze() and added to ClauseDb; ClauseHeader.learnt = true. Subject to reduceDB.
reduceDB
Periodic learnt-DB reduction: delete high-LBD, low-activity, non-reason learnts (keep ~half); glue clauses kept permanently. ClauseDb { learnts, reduce_limit }.
BVE
Bounded Variable Elimination: resolve away a variable if the resulting clause-set growth is bounded. BoundedVarElim; pushes onto EliminatedClauseStack.
subsumption
Remove clause C if another clause D ⊆ C (D's presence makes C redundant). Subsumption, uses OccurrenceList.
self-subsuming resolution
Strengthen C by removing literal l when resolving C with D yields a clause ⊆ C. SelfSubsumingResolution.
vivification
Strengthen a clause by trial-propagating negated prefixes; drop literals whose negation is already implied. Vivification (Phase 9).
occurrence list
OccurrenceList: per-literal index of clauses containing it; powers BVE/subsumption (vs. watch lists used for BCP).
inprocessing
Interleaving simplification (BVE, subsumption, vivification) with search between restarts, on the current DB. Phase 9.
preprocessing
One-shot simplification of the input CNF before search begins. Phase 8.
DRAT
Deletion Resolution Asymmetric Tautology: proof = sequence of ProofStep { Add, Delete }, each RUP- or RAT-redundant; UNSAT proven at empty clause. Emitted via ProofTracer.
LRAT
Linearized RAT: DRAT plus explicit clause-id hints per step, enabling fast forward checking. LratChecker, check_lrat().
RUP
Reverse Unit Propagation: a clause is RUP-redundant if asserting the negation of its literals and running BCP yields a conflict.
RAT
Resolution Asymmetric Tautology: redundancy w.r.t. a pivot literal — every resolvent on the pivot is RUP. Generalizes RUP.
resolution proof
Sequence of resolution steps deriving the empty clause from the input clauses; the certificate underlying DRAT/LRAT.
model reconstruction
On SAT after elimination: replay EliminatedClauseStack in reverse to extend the model to BVE-eliminated variables.
assumption
A literal fixed true for one incremental call. solve_under(assumptions: &[Lit]); assumptions are decision-level-0-like temporary decisions.
failed assumption
Subset of assumptions appearing in the final conflict that caused UNSAT-under-assumptions; extracted for the host (UNSAT core).
incremental SAT
Solving a sequence of related queries reusing learnt clauses across solve_under/add_clause calls.
IPASIR
Reentrant Incremental SAT solver API standard (add/assume/solve/val/failed) that the incremental interface mirrors.
clause arena
ClauseArena: bump-allocated u32-word region holding all clauses; supports compaction/GC. Clauses addressed by offset.
ClauseRef
ClauseRef(u32): offset/handle into ClauseArena (NOT a raw pointer) → survives arena compaction, cache-friendly indexing.
tautology
Clause containing both l and !l; always true → dropped during DIMACS normalization (sat-cnf).
pure literal
Variable occurring with only one polarity across all clauses → may be set to satisfy them; handled in preprocessing.
LBool
Tri-valued assignment { True, False, Undef }, packed to u8; assigns: VarMap<LBool> holds the partial model.
SolveResult
{ Sat(Model), Unsat, Unknown }; Unknown = budget exhausted or interrupt. Model(VarMap<bool>) = total assignment.
