3. Architectural Overview

3.1 System Diagram

        DIMACS .cnf file (untrusted bytes)        IPASIR host (incremental: add_clause, solve_under)
                  |                                          |
                  |  ===== TRUST BOUNDARY: untrusted DIMACS bytes + clause sizes (DoS) =====
                  v                                          v
        +-------------------------------------------------------------------------+
        |  sat-cli  "minisolve"   :  solve · check · dimacs · bench · incremental  |
        +-------------------------------------------------------------------------+
            |  parse                                              |  proof out
            v                                                     v
        +---------------------------+                   +-----------------------------------+
        | sat-cnf                   |                   | sat-proof                         |
        |  DimacsParser -> Cnf      |                   |  ProofTracer (DRAT emit)          |
        |  normalize/validate       |                   |  DratChecker · LratChecker        |
        +---------------------------+                   |  ProofStep Add/Delete             |
            |  Cnf (arena + ClauseRef[])                +-----------------------------------+
            v                                              ^  add/delete steps (RUP/RAT)
        +---------------------------------------------------|---------------------------+
        | sat-solver : Solver                               |                           |
        |   propagate() two-watched BCP ── analyze() 1-UIP ── backjump (non-chrono)    |
        |   Trail · Vsids · PhaseSaving · RestartPolicy · ClauseDb(LBD)                 |
        +---------------------------------------------------------------------------+--+
            |  occurrence lists / clause set                       | learnt clauses |
            v                                                                       |
        +---------------------------------------------------------------------------+
        | sat-preproc : BoundedVarElim · Subsumption · SelfSubsumingResolution ·     |
        |               Vivification · OccurrenceList                                |

        +---------------------------------------------------------------------------+

        ===== CONCURRENCY BOUNDARY: single-threaded core; shared-clause portfolio DEFERRED =====
        ===== PERSISTENCE BOUNDARY: none at runtime except append-only DRAT/LRAT proof stream =====

Data flow: bytes → sat-cnf → Cnf (arena + refs) → sat-solver search loop → SolveResult::Sat(Model) reconstructed through sat-preproc's EliminatedClauseStack, or Unsat + a sat-proof DRAT/LRAT stream re-checkable by DratChecker/LratChecker. All inter-crate handoffs use ClauseRef indices into a shared ClauseArena, never pointers — relocation-safe across compaction.

3.2 Component Responsibilities (one per box)

sat-types — value/layout foundation. Cache-critical memory model, zero policy. Lit = var<<1|sign (!lit=^1, var()=>>1); LBool packed u8. Clause DST = ClauseHeader{size,lbd,learnt,deleted,used} + inline [Lit], co-located in one cache line for short clauses. ClauseArena = bump u32-word vec; ClauseRef(u32) is an offset not a pointer ⇒ compaction rewrites only the ref table. VarMap<T>(len nvars), LitMap<T>(len 2·nvars) dense. In: nothing (leaf). Out: types for all. Inv: every ClauseRef < arena watermark at a valid header; Lit < 2·nvars. Phases: Phase 0 builds; Phase 12 compaction+layout tuning.

sat-cnf — DIMACS ingestion at the trust boundary. Only crate facing adversarial input. parse_dimacs<R:Read>(r,out) streams; normalizes tautologies (drop) + dup literals (dedup); validates p cnf V C. Errors DimacsError::{BadHeader,VarOutOfRange,MissingZeroTerminator,IoError,NonNumeric}. In: reader + target Cnf. Out: populated arena+refs, or typed error. Inv: on Ok every clause non-taut, dedup'd, lits in [1,nvars], none over size cap (DoS guard). Phases: Phase 1 implements; Phase 13 fuzzes; dimacs subcommand re-exports.

sat-solver / propagate() — BCP hot loop. Two-watched BCP: each clause has two Watcher{cref,blocker} in watches:LitMap<Vec<Watcher>>; clause inspected only when a watched lit goes false. Visit: blocker true⇒skip; else find new non-false lit (swap), else unit⇒enqueue, else conflict⇒return cref. Driven off qhead. In: trail tail. Out: Option<ClauseRef>. Inv: watches need no update on backtrack; every non-sat clause has ≥2 non-false watches while no conflict pending. Target: ≥10⁷ propagations/sec. Phases: Phase 2 builds; Phase 12 cache/blocker tuning.

sat-solver / analyze() — 1-UIP learning. Resolve the conflict clause against the Reason::Clause of the most-recent current-level literal (trail backward) until exactly one current-level literal remains (First UIP). Returns (learnt, backjump); asserting lit first; backjump = 2nd-highest learnt level (0 if unit). Bumps VSIDS of seen literals. In: conflicting cref, Trail, reason/level. Out: asserting clause + backjump. Inv: exactly one current-level literal; empty iff UNSAT. Phases: Phase 4 builds; Phase 10 hooks DRAT add; Phase 9 vivifies learnts.

sat-solver / Trail — assignment stack + levels. Trail{lits:Vec<Lit>, lim:Vec<usize>}; lim[d] = trail index where level d began. enqueue assigns+pushes; backjump(level) truncates to lim[level], clears popped assigns/level/reason, saves phase. In: decision/propagation assignments. Out: implication-graph spine. Inv: lits[0..lim[d]] = level-d prefix; qhead ≤ lits.len(). Phases: Phase 2 introduces; Phase 5 wires non-chrono backjump.

sat-solver / Vsids — branching. Vsids{activity:VarMap<f64>, inc, decay, heap:BinaryHeap}. Bump conflict-side by inc; per conflict inc *= 1/decay (lazy; rescale all+inc on f64 overflow). pick_branch pops max-activity unassigned var. In: analyze-seen vars. Out: next decision var. Inv: heap may hold stale assigned vars (lazy deletion); popped result is always unassigned or None. Phases: Phase 6 builds; Phase 12 tunes decay/rescale.

sat-solver / PhaseSaving — polarity memory. PhaseSaving{saved:VarMap<bool>}; backjump records each unassigned var's last value; pick_branch takes sign from saved. In: popped-var phases. Out: decision polarity. Inv: every assigned-then-unassigned var has a saved phase. Phases: Phase 6 builds; restarts (Phase 7) reuse it to re-find partial models.

sat-solver / RestartPolicy — restart control. Luby unit (fallback) + Glucose dynamic (fire when fast-LBD EMA > K·slow EMA) + blocking (suppress when trail unusually long). In: per-conflict LBD + trail length. Out: restart-now to search(). Inv: restart always backjumps to 0; never discards learnts. Phases: Phase 5 hook; Phase 7 implements Luby+Glucose+blocking; Phase 12 tunes K/EMA.

sat-solver / ClauseDb(LBD) — learnt lifecycle. ClauseDb{learnts:Vec<ClauseRef>, reduce_limit:u64}. LBD(glue)=distinct decision levels; LBD-2 kept forever. reduceDB deletes high-LBD/low-activity/non-reason learnts (~half), marks deleted for next compaction. In: analyze learnts. Out: bounded high-quality set. Inv: a current Reason clause is never deleted; glue survives. Phases: Phase 7 builds; Phase 12 ties to GC.

sat-preproc — simplification + reconstruction. OccurrenceList (var→clauses) backs BoundedVarElim (resolve pos×neg when result bounded), Subsumption (drop subsumed), SelfSubsumingResolution (strengthen), Vivification (probe-strengthen). Each elimination pushes EliminatedClauseStack. In: Cnf/live set. Out: simplified set + reconstruction stack. Inv: preserves satisfiability; on SAT, reverse-replay extends Model to eliminated vars. Phases: Phase 8 preproc; Phase 9 inprocessing schedule.

sat-proof — proof emit + check. ProofTracer emits ProofStep::{Add,Delete} (learnt=Add, deletion=Delete). check_drat runs the backward checker (RUP=reverse-unit-prop conflict; RAT=resolution asymmetric tautology on pivot); check_lrat verifies clause-id-hinted LRAT. UNSAT proven at empty clause. In: add/delete stream or file. Out: Result<(),ProofError>. Inv: every Add RUP/RAT-redundant w.r.t. current DB; stream append-only. Phases: Phase 10 emit+check+trim; Phase 13 differential vs drat-trim.

sat-cli "minisolve" — orchestration + I/O. solve/check/dimacs/bench/incremental. Wires sat-cnf→sat-solver→sat-proof, enforces size/DoS caps, owns exit codes (10 SAT / 20 UNSAT, SAT-Competition convention). In: args+files/stdin. Out: model/proof/diagnostics. Inv: UNSAT with proof logging always yields a checkable stream. Phases: Phase 0 skeleton; Phase 13 drives buckets+differential through bench.

8. Domain Model — CNF, DIMACS, and the CDCL State Machine

8.1 Propositional CNF semantics

Concept Definition Encoding in sat-types
Variable propositional atom, 0-based index 0..nvars Var(u32)
Literal a variable or its negation Lit(u32), sign-encoded
Clause disjunction (l1 ∨ l2 ∨ … ∨ lk) Clause { header, lits: [Lit] } (DST)
Formula conjunction of clauses C1 ∧ C2 ∧ … ∧ Cm Cnf { nvars, clauses, arena }
Assignment partial/total map Var → {True,False,Undef} assigns: VarMap<LBool>
Model total assignment satisfying every clause Model(VarMap<bool>)

Satisfaction (under A): literal satisfied iff A(l.var())==l.polarity (else falsified / unassigned if Undef); clause satisfied iff ≥1 lit satisfied, conflicting iff all falsified, unit iff exactly 1 unassigned + rest falsified, else unresolved; formula SAT iff ∃ total A satisfying all clauses.

Distinguished objects: empty clause () ≡ false ⇒ immediate UNSAT (the derivation target of any proof); unit (l) ⇒ l forced at level 0 (Reason::Unit); tautology (x ∧ ¬x) ⇒ dropped at parse; pure literal (one polarity) ⇒ set freely by BVE; empty formula ⇒ trivially SAT.

8.2 DIMACS CNF grammar (EBNF)

dimacs      = { comment } , header , { clause } , { comment } ;
comment     = "c" , { any-char-except-newline } , newline ;
header      = "p" , ws , "cnf" , ws , nvars , ws , nclauses , newline ;
clause      = { ws } , literal , { ws , literal } , ws , "0" , [ ws ] , newline ;
literal     = [ "-" ] , pos-int ;            (* 1..nvars ; "-" = negative literal *)
nvars       = nat ;                          (* u32 *)
nclauses    = nat ;
pos-int     = nonzero-digit , { digit } ;
nat         = digit , { digit } ;
ws          = ( " " | "\t" ) , { " " | "\t" } ;

Rules (enforced by DimacsParser): DIMACS vars 1-based signed (v→Var(v-1), -v→negation, 0=terminator only); header precedes clauses (interleaved comments accepted leniently); nclauses advisory (pre-reserve only, mismatch = warning unless strict); whitespace = spaces/tabs, clauses may span newlines, 0 delimits not the newline.

8.3 Lit / Var bit encoding (worked)

Lit = (var << 1) | sign        sign: 0 = positive, 1 = negative
lit.var()  = Lit >> 1          lit.sign() = Lit & 1
!lit       = Lit ^ 1           (flip low bit)
LitMap size = 2 * nvars        index by raw Lit value
DIMACS Var sign Lit (raw)
1 Var(0) 0 0
-1 Var(0) 1 1
2 Var(1) 0 2
-2 Var(1) 1 3
5 Var(4) 0 8
-5 Var(4) 1 9

!Lit(8)=9 (≡ -5). Watch lists indexed by the falsified literal: when Lit l goes false, watches[l] clauses are inspected.

8.4 CDCL state machine

States: Propagate, Decide, AnalyzeConflict, Backjump, Restart, Sat, Unsat. Start in Propagate (level 0, after enqueuing input units).

From Trigger Action To
Propagate propagate() → None, all vars assigned — Sat
Propagate propagate() → None, vars remain, restart not due pick_branch(); new level Decide
Propagate propagate() → None, restart due — Restart
Propagate propagate() → Some(cref), level == 0 conflict at root Unsat
Propagate propagate() → Some(cref), level > 0 — AnalyzeConflict
Decide pick_branch() → Some(l) enqueue(l, Decision) Propagate
Decide pick_branch() → None (none unassigned) build Model Sat
AnalyzeConflict always analyze(cref) → (learnt, bjlvl); bump VSIDS; add learnt to ClauseDb; emit DRAT add Backjump
Backjump bjlvl computed backjump(bjlvl); enqueue(asserting_lit, Clause(learnt)) Propagate
Restart always backjump(0); keep learnts; reset Luby/Glucose counters Propagate
Sat / Unsat terminal return SolveResult —

Budget/interrupt at any state → Unknown. Under assumptions (solve_under): assumption literals are enqueued as pseudo-decisions before free Decide; a conflict whose analysis reaches an assumption ⇒ failed-assumption UNSAT (final conflict over assumption literals), not global UNSAT.

8.5 Implication graph

DAG on assigned literals: node = assigned l tagged level+Reason; decision = no incoming edges (Reason::Decision), opens a level; implied l with Reason::Clause(c) = incoming edges from ¬p for each other p∈c (antecedents that made c unit); conflict ⊥ = a falsified clause's negated lits point in. A cut separating decisions from ⊥ yields a learnt clause (negation of the reason side); 1-UIP = the unique current-level node dominating ⊥.

8.6 Worked SAT/conflict example (6 vars, 8 clauses)

Variables x1..x6 → Var(0..5). Clauses (DIMACS):

p cnf 6 8
 1  2  0          c1: (x1 ∨ x2)
-2  3  0          c2: (¬x2 ∨ x3)
-3  4  0          c3: (¬x3 ∨ x4)
-1 -4  5  0       c4: (¬x1 ∨ ¬x4 ∨ x5)
-5  6  0          c5: (¬x5 ∨ x6)
-5 -6  0          c6: (¬x5 ∨ ¬x6)
 1 -3  0          c7
 2  4  0          c8

Search (decision polarity = false via phase saving default):

Step Action Trail (lit@level, reason)
d1 Decide x1=true (c1 sat, no unit) x1@1 (Decision)
d2 Decide x2=true x2@2 (Decision)
p c2⇒x3 (c2), c3⇒x4 (c3), c4⇒x5 (c4), c5⇒x6 (c5) x3,x4,x5,x6 @2
p c6 (¬x5 ∨ ¬x6): both false ⇒ CONFLICT conflict = c6

Implication graph (current level 2; x1@1 is the only level-1 node feeding in via c4):

            x2@2 ──c2──► x3@2 ──c3──► x4@2 ─┐
                                            ├─c4─► x5@2 ──c5──► x6@2 ─┐
   x1@1 ───────────────────────────────────┘                        ├─► ⊥ (c6)
                                            x5@2 ──────────c6─────────┘

1-UIP analysis (analyze(c6)): walk trail backward at level 2, resolve conflict clause against the reason of the most-recent level-2 literal until one level-2 literal remains.

Step Resolution Level-2 lits remaining
seed c6 = (¬x5 ∨ ¬x6) {x5, x6}
resolve on x6 (reason c5=(¬x5 ∨ x6)) (¬x5 ∨ ¬x6) ⊗_x6 (¬x5 ∨ x6) = (¬x5) {x5} ← exactly one ⇒ STOP
result learnt = (¬x5) unit learnt clause
  • Asserting lit ¬x5; backjump = 2nd-highest learnt level = none ⇒ 0 (unit). backjump(0); enqueue(¬x5, Clause(learnt)); VSIDS bump {x5,x6}; DRAT add (¬x5). Propagating at level 0 makes x5 permanently false — the learnt unit prunes the whole conflict subtree non-chronologically (skipped re-deciding x1,x2).

8.7 Worked UNSAT example + DRAT proof

Classic unsatisfiable core (every assignment falsifies one clause):

p cnf 2 4
 1  2  0     c1
 1 -2  0     c2
-1  2  0     c3
-1 -2  0     c4

CDCL trace: decide x1=true → c2,c4 conflict on x2 ⇒ learnt (¬x1); assert x1=false → c1,c3 conflict ⇒ learnt (). DRAT stream (each Add RUP-redundant, 0-terminated):

-1 0          c DRAT: add (¬x1)   — RUP redundant
0             c DRAT: add ()      — empty clause ⇒ UNSAT established

RUP check (check_drat, backward): to validate Add(L), assume ¬L for every lit of L, unit-propagate over the current DB; a derived conflict ⇒ L is RUP-redundant ⇒ accept.

Step being verified Unit-propagation trace Verdict
add (¬1) assume x1=true → c2 unit x2=false → c3=(-1,2) both false CONFLICT ✓ (RUP-redundant)
add () (¬1) now in DB ⇒ x1=false → c1 ⇒ x2=true → c2 both false CONFLICT ✓ ⇒ ⊥ derived ⇒ valid

If a step is not RUP-redundant the checker retries as RAT on the pivot (first literal): Add(L) is RAT iff for every clause D containing ¬pivot, the resolvent (L \ {pivot}) ∪ (D \ {¬pivot}) is RUP-redundant. Empty clause derivation ⇒ Ok(()); otherwise ProofError.

8.8 Malformed / edge DIMACS → DimacsError

Input fragment Condition Result
p cnf 3 / p sat 3 2 / q cnf 3 2 missing count / wrong token / non-p DimacsError::BadHeader
1 4 0 with nvars=3 ` literal
1 2 3 (EOF, no 0) clause not terminated DimacsError::MissingZeroTerminator
1 x 0 non-integer token DimacsError::NonNumeric
read failure mid-stream underlying I/O DimacsError::IoError
0 alone empty clause in input parse OK → empty clause ⇒ trivially UNSAT (no error)
1 -1 2 0 / 1 1 2 0 tautology / duplicate parse OK → dropped / deduped to (1 2)
nclauses mismatch declared ≠ actual accepted (warn); strict → BadHeader

Post-parse invariants (I7): every lit var() < nvars; no tautology; no dup lit; arena words match each size; an empty input clause is preserved verbatim (so UNSAT stays detectable), never normalized away.
