277 — SAT Solver from Scratch

Goal: Implement, from scratch in Rust, a modern CDCL Boolean satisfiability solver — a DIMACS CNF reader, two-watched-literal unit propagation, 1-UIP conflict analysis with non-chronological backjumping, the VSIDS branching heuristic + phase saving, Glucose-LBD and Luby restarts with an LBD-managed learnt-clause database, CNF pre/inprocessing (bounded variable elimination, subsumption, self-subsuming resolution, vivification), DRAT/LRAT proof logging + checking, and IPASIR-style incremental solving under assumptions. SAT yields a total model; UNSAT yields a machine-checked resolution proof. It is a SAT engine, not an SMT solver (#278) or a model checker (#279).

1. Goal

Goal: A from-scratch, single-process CDCL SAT decision procedure that reads DIMACS CNF and answers SAT + total model or UNSAT + machine-checkable DRAT/LRAT proof, shipped as an embeddable Rust library, the minisolve CLI, and an IPASIR-style incremental API.

1.1 Precise engineering definition

Decision procedure for propositional satisfiability over CNF formulas.

Aspect Definition
Input DIMACS CNF (p cnf <nvars> <nclauses> + zero-terminated integer clauses), or programmatic add_clause(&[Lit])
Output SolveResult::Sat(Model) (total assignment over all nvars), Unsat (+ DRAT/LRAT proof stream), or Unknown (budget/interrupt exhausted)
Core algorithm CDCL: two-watched-literal BCP → 1-UIP conflict analysis → non-chronological backjumping → VSIDS + phase-saving search → Luby/Glucose-LBD restarts → LBD-based reduceDB
Simplification Pre/inprocessing: BVE, subsumption, self-subsuming resolution, vivification; model reconstruction via EliminatedClauseStack
Verification Every UNSAT result is independently checkable; SAT model is checkable by clause evaluation
Determinism Same CNF + same config + same seed → identical decisions, conflicts, proof bytes

Correctness contract (LOCKED, §7): Sat(m) ⟺ every clause has ≥1 true literal under m; Unsat ⟺ the DRAT/LRAT proof derives ⊥ and passes check_drat/check_lrat; no silent Unknown (only on explicit budget/interrupt).

1.10 Recommended language — Rust (edition 2021, MSRV 1.78)

2. Why Build This

A CDCL SAT solver is the densest tour of practical CS systems engineering available in one ~15k-LOC codebase: it is the canonical NP-complete decision problem, the engine under SMT/BMC/planning/EDA, and a cache-bound pointer-chasing inner loop whose performance is decided by data layout, not algorithmic cleverness. Building it from scratch (not wrapping MiniSat) forces mastery of search, online heuristics, certificate-carrying results, and arena-based memory — skills that generalize far past SAT.

2.1 Unique systems knowledge this teaches

Concept What it really trains Where it recurs

Implication graph Build a DAG of forced assignments with antecedent edges (Reason::Clause); reason about why each value was forced dataflow analysis, incremental computation
1-UIP learning (analyze()) Resolution on the implication graph until one current-level literal remains -> minimal asserting clause; the single highest-leverage idea in SAT proof systems, theory of resolution

VSIDS (Vsids) An online ranking heuristic with exponential decay + lazy rescale; "recency-weighted activity" without re-scanning LRU/CLOCK eviction, ML feature decay, hot-path profiling
Restart theory (RestartPolicy) Heavy-tailed runtime distributions -> Luby universal sequence; Glucose-LBD fast/slow EMA dynamic restarts + blocking restarts randomized algorithms, adaptive scheduling
Proof-carrying UNSAT (sat-proof) A no answer must be machine-checkable: emit DRAT, check via RUP/RAT, distill to LRAT verified compilers, zk/attestation, untrusted-solver oracles

Clause arena (ClauseArena/ClauseRef) Bump-allocated DST clauses indexed by handles, not pointers; compaction/GC under aliasing GC heaps, ECS, region allocators

2.2 Why SAT matters — historically and architecturally

  • First NP-complete problem (Cook 1971, Levin 1973): the reduction target every NP problem maps to; understanding SAT is understanding NP empirically.
  • The "SAT revolution": 1990s ~100-var instances were hard; today solvers dispatch 10⁶–10⁷-variable industrial CNFs. The gap is engineering (CDCL + watched literals + VSIDS + LBD), not a complexity-class breakthrough.
  • The engine under everything: SMT (bit-blast/lazy-DPLL(T)), BMC, AI planning (SATPLAN), EDA equivalence/ATPG, cryptanalysis, dependency resolution, type inference all reduce to or call a SAT core.
  • Lineage, consistently cited: GRASP (CDCL origin, conflict analysis) → Chaff (VSIDS, watched literals) → MiniSat (canonical minimal reference, Eén & Sörensson) → Glucose (LBD/glue, dynamic restarts, Audemard & Simon) → CaDiCaL/Kissat (inprocessing, Biere). DRAT-trim/LRAT define proof-checking; IPASIR the incremental ABI.

2.3 Engineering muscles built

Hot-path layout (VarMap/LitMap dense arrays, SoA trail, cache-line Watcher, arena compaction) · perf under adversarial input (untrusted DIMACS, bounds-safe huge-array indexing without UB) · correctness via certificates not trust (differential vs MiniSat/CaDiCaL; every UNSAT DRAT/LRAT-checked — a solver that proves itself) · online/anytime algorithms (VSIDS decay, EMA restarts, periodic reduceDB) · numeric hygiene (f64 activity overflow + lazy rescale; no float in correctness paths) · Rust ownership for aliasing (one small audited unsafe arena/DST module, rest safe).

2.7 What Mastery Looks Like

After building this you can, by competency:

  • Reason about a learning search as resolution: read any analyze() trace and state which resolvents it derived and why the 1-UIP cut is the asserting one (Phase 4, §16; MM1).
  • Design a lazy data structure whose invariant survives undo without repair — the two-watched scheme generalizes to readiness lists and dirty-bit trackers (Phase 2, §14; MM2).
  • Make a no answer machine-checkable: emit and independently verify a certificate, separating trust from computation (Phase 10, §22; MM4).
  • Tune an online heuristic (recency-weighted activity + decay, EMA-driven restarts) under a reproducible-trace constraint, without touching correctness (Phases 6–7, §18–19; MM3, MM5).
  • Operate an exponential-worst-case engine safely: budget-bound it so adversarial input times out, never crashes the host (Phase 5/13, §17/§25 + Threat Model; MM6, P6.7).
  • Build a self-validating system: differential oracle + proof-check gate every verdict, so a kernel bug degrades to caught, not wrong (Phase 13, §25; P6.1).
  • Manage a region allocator under aliasing: handle-indexed clauses + compaction that rewrites all live refs in one pass (Phase 12, §24; MM7).

3.2 Component Responsibilities (one per box)

sat-types — value/layout foundation. Cache-critical memory model, zero policy. Lit = var<<1|sign (!lit=^1, var()=>>1); LBool packed u8. Clause DST = ClauseHeader{size,lbd,learnt,deleted,used} + inline [Lit], co-located in one cache line for short clauses. ClauseArena = bump u32-word vec; ClauseRef(u32) is an offset not a pointer ⇒ compaction rewrites only the ref table. VarMap<T>(len nvars), LitMap<T>(len 2·nvars) dense. In: nothing (leaf). Out: types for all. Inv: every ClauseRef < arena watermark at a valid header; Lit < 2·nvars. Phases: Phase 0 builds; Phase 12 compaction+layout tuning.

sat-cnf — DIMACS ingestion at the trust boundary. Only crate facing adversarial input. parse_dimacs<R:Read>(r,out) streams; normalizes tautologies (drop) + dup literals (dedup); validates p cnf V C. Errors DimacsError::{BadHeader,VarOutOfRange,MissingZeroTerminator,IoError,NonNumeric}. In: reader + target Cnf. Out: populated arena+refs, or typed error. Inv: on Ok every clause non-taut, dedup'd, lits in [1,nvars], none over size cap (DoS guard). Phases: Phase 1 implements; Phase 13 fuzzes; dimacs subcommand re-exports.

sat-solver / propagate() — BCP hot loop. Two-watched BCP: each clause has two Watcher{cref,blocker} in watches:LitMap<Vec<Watcher>>; clause inspected only when a watched lit goes false. Visit: blocker true⇒skip; else find new non-false lit (swap), else unit⇒enqueue, else conflict⇒return cref. Driven off qhead. In: trail tail. Out: Option<ClauseRef>. Inv: watches need no update on backtrack; every non-sat clause has ≥2 non-false watches while no conflict pending. Target: ≥10⁷ propagations/sec. Phases: Phase 2 builds; Phase 12 cache/blocker tuning.

sat-solver / analyze() — 1-UIP learning. Resolve the conflict clause against the Reason::Clause of the most-recent current-level literal (trail backward) until exactly one current-level literal remains (First UIP). Returns (learnt, backjump); asserting lit first; backjump = 2nd-highest learnt level (0 if unit). Bumps VSIDS of seen literals. In: conflicting cref, Trail, reason/level. Out: asserting clause + backjump. Inv: exactly one current-level literal; empty iff UNSAT. Phases: Phase 4 builds; Phase 10 hooks DRAT add; Phase 9 vivifies learnts.

sat-solver / Trail — assignment stack + levels. Trail{lits:Vec<Lit>, lim:Vec<usize>}; lim[d] = trail index where level d began. enqueue assigns+pushes; backjump(level) truncates to lim[level], clears popped assigns/level/reason, saves phase. In: decision/propagation assignments. Out: implication-graph spine. Inv: lits[0..lim[d]] = level-d prefix; qhead ≤ lits.len(). Phases: Phase 2 introduces; Phase 5 wires non-chrono backjump.

sat-solver / Vsids — branching. Vsids{activity:VarMap<f64>, inc, decay, heap:BinaryHeap}. Bump conflict-side by inc; per conflict inc *= 1/decay (lazy; rescale all+inc on f64 overflow). pick_branch pops max-activity unassigned var. In: analyze-seen vars. Out: next decision var. Inv: heap may hold stale assigned vars (lazy deletion); popped result is always unassigned or None. Phases: Phase 6 builds; Phase 12 tunes decay/rescale.

sat-solver / PhaseSaving — polarity memory. PhaseSaving{saved:VarMap<bool>}; backjump records each unassigned var's last value; pick_branch takes sign from saved. In: popped-var phases. Out: decision polarity. Inv: every assigned-then-unassigned var has a saved phase. Phases: Phase 6 builds; restarts (Phase 7) reuse it to re-find partial models.

sat-solver / RestartPolicy — restart control. Luby unit (fallback) + Glucose dynamic (fire when fast-LBD EMA > K·slow EMA) + blocking (suppress when trail unusually long). In: per-conflict LBD + trail length. Out: restart-now to search(). Inv: restart always backjumps to 0; never discards learnts. Phases: Phase 5 hook; Phase 7 implements Luby+Glucose+blocking; Phase 12 tunes K/EMA.

sat-solver / ClauseDb(LBD) — learnt lifecycle. ClauseDb{learnts:Vec<ClauseRef>, reduce_limit:u64}. LBD(glue)=distinct decision levels; LBD-2 kept forever. reduceDB deletes high-LBD/low-activity/non-reason learnts (~half), marks deleted for next compaction. In: analyze learnts. Out: bounded high-quality set. Inv: a current Reason clause is never deleted; glue survives. Phases: Phase 7 builds; Phase 12 ties to GC.

sat-preproc — simplification + reconstruction. OccurrenceList (var→clauses) backs BoundedVarElim (resolve pos×neg when result bounded), Subsumption (drop subsumed), SelfSubsumingResolution (strengthen), Vivification (probe-strengthen). Each elimination pushes EliminatedClauseStack. In: Cnf/live set. Out: simplified set + reconstruction stack. Inv: preserves satisfiability; on SAT, reverse-replay extends Model to eliminated vars. Phases: Phase 8 preproc; Phase 9 inprocessing schedule.

sat-proof — proof emit + check. ProofTracer emits ProofStep::{Add,Delete} (learnt=Add, deletion=Delete). check_drat runs the backward checker (RUP=reverse-unit-prop conflict; RAT=resolution asymmetric tautology on pivot); check_lrat verifies clause-id-hinted LRAT. UNSAT proven at empty clause. In: add/delete stream or file. Out: Result<(),ProofError>. Inv: every Add RUP/RAT-redundant w.r.t. current DB; stream append-only. Phases: Phase 10 emit+check+trim; Phase 13 differential vs drat-trim.

sat-cli "minisolve" — orchestration + I/O. solve/check/dimacs/bench/incremental. Wires sat-cnf→sat-solver→sat-proof, enforces size/DoS caps, owns exit codes (10 SAT / 20 UNSAT, SAT-Competition convention). In: args+files/stdin. Out: model/proof/diagnostics. Inv: UNSAT with proof logging always yields a checkable stream. Phases: Phase 0 skeleton; Phase 13 drives buckets+differential through bench.

4. System Constraints

4.1 Resource budgets (quantified targets)

Resource Target / cap Mechanism Rationale
Clause storage ClauseArena packed u32 words; header 2 words + 1 word/literal -> ~4 bytes/literal ClauseRef(u32) handle, not pointer; bump alloc + compaction cache density; 32-bit handles halve footprint vs ptrs
Lit/Var width u32 each; nvars <= 2^31-1 sign-bit encoding 2*var+sign one word indexes LitMap sized 2*nvars
Watch lists ~2 Watcher entries/clause (binary watched-lit invariant) watches: LitMap<Vec<Watcher>>; Watcher{cref,blocker} = 8 bytes minimize touched clauses on BCP
Assignment arrays assigns/level/reason/phase = VarMap dense, O(nvars) indexed by Var, no hashing L1/L2-resident per-var state
Learnt DB capped to multiple of original clauses (default ~2-4x, dynamic) reduceDB: keep LBD-2 glue + high-activity + reasons; drop ~half bound memory + GC pressure
Trail <= nvars Lit; lim <= max decision level Trail{lits,lim} total assignment bound is nvars
Proof stream on-disk append-only, unbounded; not RAM-resident ProofTracer streams ProofStep competition proofs reach 10s of GB

4.2 Throughput / latency targets

Metric Target (single core, competition CNF) Notes
Propagations/sec > 1e7 BCP hot loop; L1/L2-bound; dominates runtime
Conflicts/sec ~1e4-1e6 (instance-dependent) each conflict = analyze() + backjump + DB bump
Decisions/sec tracks conflicts pick_branch() = heap pop + phase lookup
Restart cadence Luby unit ~50-100 conflicts base; Glucose-LBD dynamic; blocking on long trail EMA fast vs slow LBD
reduceDB cadence every reduce_limit conflicts (geometric/arith growth)
Parse throughput O(formula bytes); streaming, no full-buffer slurp large .cnf files (GB)
  • Worst-case solve time is UNBOUNDED — SAT is NP-hard. Every solve()/solve_under() runs under a conflict and/or wall-clock budget; on exhaustion returns SolveResult::Unknown (never spins forever). No steady-state latency SLO: "fast" vs "impossible" differ by >10⁹×; latency is budget-bounded, not per-call bounded.

4.3 Startup / load

Zero global init (no static tables, lazy_static, warm-up). Solver::new(cnf) allocates VarMap/LitMap to nvars, builds initial watches — O(formula size). Cold-start to first decision = parse (O(bytes)) + arena fill + watch init; no I/O beyond input .cnf and optional proof file.

4.4 Capacity caps (DoS bounding)

Dimension Soft fit Hard cap Enforcement
Variables millions < 2^31 (Lit encoding) DimacsError::VarOutOfRange at parse
Clauses tens of millions configurable max (RAM-derived) reject in parse_dimacs
Single clause size normal <= nvars bounded; reject absurd sizes DimacsError
Header counts must match body mismatch tolerated or rejected per mode BadHeader / count check
  • Untrusted DIMACS bytes + declared clause sizes are the DoS surface at sat-cnf (trust boundary). All caps enforced before allocation to prevent OOM/length-overflow from a hostile header.

4.5 CPU / cache assumptions

Propagation is L1/L2-bound, pointer-chasing over watches+ClauseArena; layout is the perf lever. blocker lets BCP skip the arena load when blocker is true (avoids a miss/clause). Watched-literal invariant: clause touched only when a watched lit goes false, no update on backtrack ⇒ cheap backjump. VarMap/LitMap dense ⇒ sequential, prefetch-friendly, no hot-path hashing. Arena compaction (Phase 12) restores locality after reduceDB churn.

4.6 Platform / environment constraints

Single-threaded core; shared-clause portfolio PhaseDeferred("Deferred Features Register"); no threading/locks/atomics. No NUMA, network, IPC. No async — synchronous std. unsafe confined to the audited arena/watch-list module (ADR-20). MSRV 1.78, edition 2021, std only.

6. Design Principles

Fifteen non-negotiable principles (P6.1…). Each: rule · rationale · tradeoff/op · violation-failure. Referenced by ID throughout Phases 0–13.

6.1 Soundness is absolute

  • Rule: never Sat(Model) for UNSAT nor Unsat for SAT. SAT carries a total Model; UNSAT a sat-proof-checked DRAT/LRAT proof.
  • Rationale: a decision oracle others trust blindly; one wrong bit poisons every downstream (278, 279).
  • Op: CI re-verifies every UNSAT via check_drat; SAT models re-evaluated against original Cnf (O(lits)). Never ship a build where a verdict disagrees with the checker.
  • Violation: off-by-one in analyze() learns a non-implied clause → prunes a satisfying assignment → false Unsat; caught only by proof check.

6.2 Watches never lie

  • Rule: two-watched invariant (I1) — every non-deleted non-unit clause has both watches non-false, OR is queued conflicting/unit — holds at every quiescent point of propagate().
  • Rationale: BCP inspects a clause only on a false watch; a stale watch silently misses a unit/conflict → unsound or non-terminating.
  • Op: debug check_watch_invariant() after each propagate()→None; release strips it. Watches NOT updated on backjump (invariant chosen so backtrack is watch-free).
  • Violation: failing to install the new watcher when relocating off a false literal → clause never re-examined → Sat with a clause unsatisfied.

6.3 Learn only implied clauses

  • Rule: every analyze() clause is a consequence of Cnf (RUP-derivable from the DB) ⇒ the DRAT stream is valid by construction (I3).
  • Rationale: learnts steer search; an unsound one is corruption — but proof-checkable if learning is pure 1-UIP resolution.
  • Op: ProofTracer::add is called at the learning moment, so proof and DB never diverge. No optimization may add a clause unjustified by resolution.
  • Violation: a vivification/BVE step adds a strengthened clause without an EliminatedClauseStack/proof entry → proof check fails (good) or silent unsoundness (proof off).

6.4 Backjump, don't backtrack

  • Rule: after learning, jump to the 2nd-highest learnt-literal level (0 if unit) — non-chronological. Never undo one level at a time (I5).
  • Rationale: the asserting clause becomes unit at exactly that level; chronological backtrack repeats propagations + loses asserting power → exponential blowup.
  • Op: backjump(level) truncates Trail to lim[level], restores assigns/level/reason/qhead; Vsids+PhaseSaving survive (search, not assignment, state).
  • Violation: jumping to level-1 leaves the asserting literal unassigned higher up → loops re-deriving the same conflict, conflicts/sec collapses.

6.5 The arena owns clauses, refs index it

  • Rule: all storage in ClauseArena; code holds ClauseRef (u32 offset), never a &Clause across any alloc/reduce/compact.
  • Rationale: borrow rules + one arena make aliasing explicit; pointers dangle after compaction/reduceDB.
  • Op: deref = one bounds-checked index; compaction rewrites all live refs (watches, reason, learnts, Cnf.clauses) in one pass. The arena module is the only audited unsafe (ADR-20).
  • Violation: caching arena.get(cref) as a slice then add_clause (may relocate) → use-after-realloc → garbage literals → unsoundness/panic.

6.6 Heuristics replaceable, correctness not

  • Rule: Vsids/PhaseSaving/RestartPolicy/ClauseDb reduction live behind a stable kernel (propagate/analyze/enqueue/backjump); swapping a heuristic changes only speed, never which answers are correct.
  • Rationale: isolates the trusted kernel from the tunable shell.
  • Op: heuristic modules cannot assign a value or skip a clause; they only order decisions + select deletions. Differential tests toggle heuristics, assert identical verdicts.
  • Violation: a "smart" rule that hard-assigns a literal outside enqueue/Reason corrupts the implication graph → analyze() resolves a missing antecedent → unsound learnt.

6.7 Bounded resources, never OOM-crash

  • Rule: conflict/decision/time/memory budgets are first-class; on exhaustion solve() returns Unknown, never crash/kill.
  • Rationale: adversarial CNF must degrade gracefully, not abort the host.
  • Op: arena+learnts checked vs a memory cap; reduceDB+GC bound footprint; budgets checked at the restart boundary (cheap).
  • Violation: unbounded learnt retention on a hard instance → arena alloc aborts the process → host loses all incremental state instead of Unknown.

6.8 Determinism on demand

  • Rule: fixed seed + config ⇒ byte-identical trace (decisions, conflicts, learnts, answer) across runs/platforms.
  • Rationale: debugging, bisection, differential testing need reproducible traces; f64 activity must order deterministically (stable tie-break by Var).
  • Op: no wall-clock, no thread scheduling, no HashMap iteration in the hot path; total-order tie-breaks. Deferred portfolio is the only intentional nondeterminism.
  • Violation: tie-breaking the VSIDS heap by hash order → runs diverge after the first equal-activity pair → unbisectable flaky regression.

6.9 Proof-carrying UNSAT

  • Rule: every Unsat carries a DRAT (optionally LRAT) stream an independent checker validates to the empty clause (I9). Operational form of P6.1 for UNSAT.
  • Op: emission costs ~5–15% runtime + an append-only stream; on in CI/competition proof track, optional in raw-speed mode. Deletions emitted so the checker DB stays bounded.
  • Violation: dropping a Delete for a reduceDB-removed clause → checker RUP succeeds against a stale clause → proof "passes" but doesn't match the derivation.

6.10 Incremental safety

  • Rule: across solve_under/add_clause, permanent clauses + var space persist; only assumption-dependent state resets. Globally-valid learnts retained; assumption-tainted ones discarded (I11).
  • Rationale: IPASIR hosts call thousands of times; re-parsing is fatal, leaking assumptions is unsound.
  • Op: assumptions pushed as pseudo-decisions at the trail bottom; a conflict at assumption level yields the failed-assumption set, then backjump to 0.
  • Violation: keeping a learnt derived under assumption a after a is dropped → next call inherits a clause not implied by the persistent formula → cross-call unsoundness.

6.11 Parse never panics

  • Rule: parse_dimacs returns Err(DimacsError) for every malformed input — never panics, OOMs, reads OOB (I7).
  • Rationale: the DIMACS stream is the trust boundary; a panic is DoS, OOB is a CVE.
  • Op: streaming reader bounds counts vs the header before allocating; integer parses checked; fuzzed (Phase 13) asserting "Ok or typed Err, never panic".
  • Violation: trusting the header count + pre-allocating count*sizeof → attacker sets u32::MAX → alloc aborts before the first clause.

6.12 Measure conflicts, not wall-clock

  • Rule: perf regressions gate on algorithmic counters (conflicts, propagations, decisions, learnts, LBD), not noisy wall-clock.
  • Rationale: wall-clock varies with machine/load; halving conflicts is a real win even if a noisy box reports slower.
  • Op: bench records both; CI fails on >X% conflict regression at fixed seed; wall-clock is a smoothed secondary. Targets quantified per phase (≥10M props/sec).
  • Violation: tuning to a flaky wall-clock on one box → accepting a change that inflates conflicts broadly → real slowdown masked by lucky timing.

6.13 One representation, no shadow state

  • Rule: each fact has one authority: assignment⇒assigns:VarMap<LBool>, antecedent⇒reason, level⇒level, order⇒Trail. No cached copy may disagree (I2).
  • Rationale: duplicated state (e.g. a parallel is-assigned bitset) drifts → phantom units/conflicts.
  • Op: Watcher.blocker is the sole sanctioned cache — a hint, re-validated vs assigns, never trusted as truth. Debug asserts cross-check derived views.
  • Violation: trusting a blocker as "satisfied" without checking assigns after backjump → clause skipped though now unit → missed propagation (special case of P6.2).

6.14 Fail loud in debug, degrade safe in release

  • Rule: internal invariants (P6.2/6.4/6.5/6.13) are debug_assert!-checked and abort tests; release trips only on genuine impossibility, never on attacker input.
  • Rationale: invariant violations are bugs (surface in CI); malformed input is Err/Unknown (P6.7/6.11).
  • Op: asserts zero-cost in release; "bug vs bad input" enforced at the API boundary — sat-cnf makes typed errors, the kernel asserts only on self-bug states.
  • Violation: demoting the watch-invariant check to a release if that "repairs" state → masks the bug, ships an occasionally-unsound solver with no signal.

6.15 Resolution is the only inference

  • Rule: the kernel derives clauses by one rule — resolution (1-UIP, BVE, SSR, vivification all reduce to it). No clause enters the DB without a resolution/RUP/RAT justification recordable as a ProofStep.
  • Rationale: one primitive keeps soundness (P6.1/6.3/6.9) auditable end-to-end; one checker validates the whole pipeline.
  • Op: non-proof-expressible steps forbidden in proof mode; model-affecting eliminations push EliminatedClauseStack.
  • Violation: a simplification that "knows" a clause redundant by an unproven argument → no ProofStep → proof gap the checker rejects, or silent unsoundness with proofs off.

7.2 I1 — Two-watched-literal well-formedness

  • Statement: for every non-deleted c (size≥2): (a) both watches c.lits[0..2] non-false, OR (b) c satisfied, OR (c) c unit with its sole non-false lit a watch + enqueued, OR (d) c is the returned conflict. Both watches in watches[!w]; blocker = the other watch's lit.
  • Why: correctness+completeness of propagate(); a clause not watched on a falsified lit goes unit/conflict unseen → unsound/non-terminating. Holds at every assigned prefix ⇒ no backtrack repair (P6.2).
  • Enforced/detect: install at Solver::new/add_clause, re-watch in propagate(), re-point in reduceDB/compaction. debug_check_watches(): each clause in exactly two !w lists, watch[0..2] non-false unless sat. O(clauses), --verify.
  • Tele/recover/debug: propagations, blocker_hits, re_watch_misses. CORRUPT→abort; compaction rebuilds lists wholesale. On fail dump cref/lits/lists/assigns; bisect by disabling reduceDB → bug is in ClauseRef re-pointing.

7.3 I2 — Trail / level / reason coherence

  • Statement: per assigned v: assigns[v]≠Undef ⟺ once on lits; level[v]=d ⟺ enqueued in [lim[d],lim[d+1]); reason==Decision ⟺ first lit at its level (index lim[level[v]], level>0); reason==Clause(cr) ⟹ all other cr lits False at level ≤ level[v]; reason==Unit ⟹ level=0. lim monotone; lim.len()==decision_level.
  • Why: analyze() walks reason backward; stale level/reason corrupts 1-UIP+backjump → unsound learnt. lim underpins backjump().
  • Enforced/detect: enqueue sets all four atomically; decisions push lim; backjump truncates+clears+pops. debug_check_trail(): level matches lim, antecedents all False at ≤level, no Var twice, lim sorted. O(trail).
  • Tele/recover/debug: decisions, decision_level, max depth. CORRUPT→abort; backjump is the only legal shortener. Ring-buffer (idx,lit,level,reason) on assign; common bug: backjump clearing reason not level, or stale qhead.

7.4 I3 — Every learnt clause is implied (RUP-checkable)

  • Statement: each analyze() clause added via ProofTracer::add is RUP-redundant w.r.t. the DB (negate its lits + unit-prop ⇒ conflict); equivalently a resolvent chain over reasons, entailed by the formula (P6.3).
  • Why/enforced: soundness of UNSAT + pruning; a non-implied learnt cuts satisfying assignments → false UNSAT. Structural in analyze() (resolution over genuine antecedents); externally audited by DratChecker/LratChecker.
  • Detect/tele/recover: --verify runs a self-contained RUP check post-analyze; always re-validated by check_drat. rup_check_fail must be 0. CORRUPT→abort + emit clause+resolution trace; feed to drat-trim for independent confirmation.

7.5 I4 — 1-UIP cardinality

  • Statement: the learnt clause has exactly one literal at the conflict level (the asserting lit = ¬First-UIP); all others strictly lower (I4).
  • Why/enforced: defines the asserting clause ⇒ unit after backjump (progress); two current-level lits = not at a UIP, zero = over-resolved. analyze() loop stops when the current-level seen-counter hits 1.
  • Detect/recover/debug: assert count of level==conflict_level over learnt ==1. analyze_resolutions histogram. CORRUPT→abort. On count≠1, log seen evolution; cause: reason level mis-set (I2) or double-count (missing dedup).

7.6 I5 — Backjump target

  • Statement: analyze()'s backjump level = 2nd-highest decision level among learnt lits (0 if unit); search() calls backjump(that) directly, non-chronological (I5, P6.4).
  • Why/enforced: too high re-explores, too low leaves the clause non-unit; equals 2nd-highest because after backjump only the UIP lit stays unassigned at the top. analyze() computes max-of-lower while building; backjump() asserts target < conflict_level.
  • Detect/recover/debug: assert bj == sort(levels)[-2] (0 if unit), bj < conflict_level. backjump_distance histogram. CORRUPT→abort. Bug class: off-by-one (highest vs 2nd-highest).

7.7 I6 — VSIDS heap = unassigned set

  • Statement: Vsids.heap holds exactly the unassigned vars by activity; pick_branch() pops max and it is guaranteed Undef.
  • Why/enforced: a missing unassigned var → unbranchable → wrong UNSAT; a stale assigned var wastes pops (PERF) unless branched without an Undef check → CORRUPT double-assign. Lazy: enqueue doesn't remove; pick_branch pops-until-Undef; backjump re-inserts.
  • Detect/recover/debug: debug_check_heap() set-equality (lazy variant: every Undef in heap). stale_pops, rescale_count. If exhausted with Undef vars (CORRUPT) → rebuild from assigns scan, log; repeat aborts. Common bug: backjump not re-inserting.

7.8 I7 — No tautology / no duplicate literals

  • Statement: post-normalization no clause has both x and !x (tautologies dropped) or a duplicate literal; empty clause ⟹ trivially UNSAT (recorded); units enqueued at level 0 (I7).
  • Why/enforced: two-watched (I1) + resolution assume distinct lits; {x,!x} is noise (breaks LBD/activity); dups corrupt watch counting. parse_dimacs sort+dedup + complementary-pair scan.
  • Detect/recover/debug: assert per clause lits sorted-unique, no !lits[i] ∈ lits. tautologies_dropped, dup_literals_removed. Tautology→drop, dup→collapse (normalization, not abort). Log dropped clauses with DIMACS line numbers.

7.9 I8 — Propagation fixpoint before decision

  • Statement: pick_branch() runs only at BCP fixpoint: qhead==trail.len() and last propagate()→None; never decide with a pending unit (I8).
  • Why/enforced: branching over a forced var produces inconsistent assignments + mis-leveled reasons, wastes the tree. search() order: propagate → conflict? analyze+backjump : (qhead==len) pick_branch.
  • Detect/recover/debug: assert qhead==trail.len() at pick_branch top. bcp_fixpoint_violations must be 0. CORRUPT→abort. Bug class: early continue skipping the test, or qhead not advanced after enqueue.

7.10 I9 — DRAT ends in empty clause iff UNSAT

  • Statement: the DRAT proof derives the empty clause ⟺ solver reported Unsat; on Sat no empty clause + a total Model. DratChecker accepts ⟺ genuinely UNSAT (I9, P6.9).
  • Why/enforced: the machine-checkable UNSAT contract (competition + downstream trust). A unit learnt backjumping to 0 then conflicting at 0 ⟹ empty clause ProofTracer::add(&[]); solve() returns Unsat exactly then.
  • Detect/recover/debug: post-solve Unsat ⇒ check_drat to acceptance, assert last clause empty; Sat ⇒ no empty Add + verify_model. CORRUPT (mismatch)→abort, return Unknown over an unsound UNSAT. Trim → first rejected step localizes the unjustified clause (cross-check I3).

7.11 I10 — Model reconstruction satisfies the ORIGINAL formula

  • Statement: after BVE/elimination, the final Model (reverse-replay of EliminatedClauseStack) satisfies every original clause, incl. eliminated vars (I10).
  • Why/enforced: BVE changes the formula; the solver only solves the simplified one; without reconstruction a Sat model is invalid against the user's formula. BoundedVarElim stacks removed + defining clauses; on Sat, reverse-replay sets each eliminated var's polarity to satisfy its stacked clauses.
  • Detect/recover/debug: mandatory verify_model_original evaluates the pre-preprocessing CNF on every Sat (not just --verify). vars_eliminated, recon_flips. CORRUPT→abort; never emit an unverified model. On fail, locate the first unsatisfied original clause + its eliminated var, confirm strict-LIFO replay set a witness.

7.12 I11 — Assumption / failed-assumption discipline

  • Statement: in solve_under(assumptions) the assumptions are the only decisions at levels 1..=k (one per level, in order) before any heuristic decision; the failed-assumption set (core) is a subset of assumptions; add_clause clauses persist across calls, assumptions don't (I11, P6.10).
  • Why/enforced: IPASIR contract; the core must be a genuine subset to be usable; heuristic decisions in the prefix corrupt extraction. solve_under enqueues each assumption as a Decision (or detects immediate conflict) before pick_branch; failed set from the level-1..k lits in analyze_final.
  • Detect/recover/debug: assert assumptions[i] is the level-i+1 decision until first conflict, failed ⊆ assumptions, state cleared between calls. failed_core_size, clauses_persisted. CORRUPT→abort. Bug class: a pick_branch firing before the prefix is placed.

7.13 I12 — ClauseRef validity across compaction

  • Statement: after any ClauseArena compaction/GC, every live ClauseRef (in watches, reason==Clause, db.learnts, Cnf.clauses) points at an in-range, non-deleted header; no holder retains a pre-compaction offset (I12, P6.5, MM7).
  • Why/enforced: a stale ref reads garbage literals → arbitrary unsoundness/UB; compaction must rewrite all holders from the old→new remap in one pass before search resumes. Enforced in collect_garbage/compact; only fires at decision level 0.
  • Detect/recover/debug: post-compaction debug_assert cref < arena.len() on every holder + a non-deleted scan; churn-heavy GC fuzz (Phase 13). CORRUPT→abort. Dump the old→new remap + the stale holder identity; bisect by disabling GC (if the verdict stabilizes, the remap pass missed a holder set).

8. Domain Model — CNF, DIMACS, and the CDCL State Machine

8.1 Propositional CNF semantics

Concept Definition Encoding in sat-types
Variable propositional atom, 0-based index 0..nvars Var(u32)
Literal a variable or its negation Lit(u32), sign-encoded
Clause disjunction (l1 ∨ l2 ∨ … ∨ lk) Clause { header, lits: [Lit] } (DST)
Formula conjunction of clauses C1 ∧ C2 ∧ … ∧ Cm Cnf { nvars, clauses, arena }
Assignment partial/total map Var → {True,False,Undef} assigns: VarMap<LBool>
Model total assignment satisfying every clause Model(VarMap<bool>)

Satisfaction (under A): literal satisfied iff A(l.var())==l.polarity (else falsified / unassigned if Undef); clause satisfied iff ≥1 lit satisfied, conflicting iff all falsified, unit iff exactly 1 unassigned + rest falsified, else unresolved; formula SAT iff ∃ total A satisfying all clauses.

Distinguished objects: empty clause () ≡ false ⇒ immediate UNSAT (the derivation target of any proof); unit (l) ⇒ l forced at level 0 (Reason::Unit); tautology (x ∧ ¬x) ⇒ dropped at parse; pure literal (one polarity) ⇒ set freely by BVE; empty formula ⇒ trivially SAT.

8.2 DIMACS CNF grammar (EBNF)

dimacs      = { comment } , header , { clause } , { comment } ;
comment     = "c" , { any-char-except-newline } , newline ;
header      = "p" , ws , "cnf" , ws , nvars , ws , nclauses , newline ;
clause      = { ws } , literal , { ws , literal } , ws , "0" , [ ws ] , newline ;
literal     = [ "-" ] , pos-int ;            (* 1..nvars ; "-" = negative literal *)
nvars       = nat ;                          (* u32 *)
nclauses    = nat ;
pos-int     = nonzero-digit , { digit } ;
nat         = digit , { digit } ;
ws          = ( " " | "\t" ) , { " " | "\t" } ;

Rules (enforced by DimacsParser): DIMACS vars 1-based signed (v→Var(v-1), -v→negation, 0=terminator only); header precedes clauses (interleaved comments accepted leniently); nclauses advisory (pre-reserve only, mismatch = warning unless strict); whitespace = spaces/tabs, clauses may span newlines, 0 delimits not the newline.

8.3 Lit / Var bit encoding (worked)

Lit = (var << 1) | sign        sign: 0 = positive, 1 = negative
lit.var()  = Lit >> 1          lit.sign() = Lit & 1
!lit       = Lit ^ 1           (flip low bit)
LitMap size = 2 * nvars        index by raw Lit value
DIMACS Var sign Lit (raw)
1 Var(0) 0 0
-1 Var(0) 1 1
2 Var(1) 0 2
-2 Var(1) 1 3
5 Var(4) 0 8
-5 Var(4) 1 9

!Lit(8)=9 (≡ -5). Watch lists indexed by the falsified literal: when Lit l goes false, watches[l] clauses are inspected.

8.4 CDCL state machine

States: Propagate, Decide, AnalyzeConflict, Backjump, Restart, Sat, Unsat. Start in Propagate (level 0, after enqueuing input units).

From Trigger Action To
Propagate propagate() → None, all vars assigned — Sat
Propagate propagate() → None, vars remain, restart not due pick_branch(); new level Decide
Propagate propagate() → None, restart due — Restart
Propagate propagate() → Some(cref), level == 0 conflict at root Unsat
Propagate propagate() → Some(cref), level > 0 — AnalyzeConflict
Decide pick_branch() → Some(l) enqueue(l, Decision) Propagate
Decide pick_branch() → None (none unassigned) build Model Sat
AnalyzeConflict always analyze(cref) → (learnt, bjlvl); bump VSIDS; add learnt to ClauseDb; emit DRAT add Backjump
Backjump bjlvl computed backjump(bjlvl); enqueue(asserting_lit, Clause(learnt)) Propagate
Restart always backjump(0); keep learnts; reset Luby/Glucose counters Propagate
Sat / Unsat terminal return SolveResult —

Budget/interrupt at any state → Unknown. Under assumptions (solve_under): assumption literals are enqueued as pseudo-decisions before free Decide; a conflict whose analysis reaches an assumption ⇒ failed-assumption UNSAT (final conflict over assumption literals), not global UNSAT.

8.5 Implication graph

DAG on assigned literals: node = assigned l tagged level+Reason; decision = no incoming edges (Reason::Decision), opens a level; implied l with Reason::Clause(c) = incoming edges from ¬p for each other p∈c (antecedents that made c unit); conflict ⊥ = a falsified clause's negated lits point in. A cut separating decisions from ⊥ yields a learnt clause (negation of the reason side); 1-UIP = the unique current-level node dominating ⊥.

8.6 Worked SAT/conflict example (6 vars, 8 clauses)

Variables x1..x6 → Var(0..5). Clauses (DIMACS):

p cnf 6 8
 1  2  0          c1: (x1 ∨ x2)
-2  3  0          c2: (¬x2 ∨ x3)
-3  4  0          c3: (¬x3 ∨ x4)
-1 -4  5  0       c4: (¬x1 ∨ ¬x4 ∨ x5)
-5  6  0          c5: (¬x5 ∨ x6)
-5 -6  0          c6: (¬x5 ∨ ¬x6)
 1 -3  0          c7
 2  4  0          c8

Search (decision polarity = false via phase saving default):

Step Action Trail (lit@level, reason)
d1 Decide x1=true (c1 sat, no unit) x1@1 (Decision)
d2 Decide x2=true x2@2 (Decision)
p c2⇒x3 (c2), c3⇒x4 (c3), c4⇒x5 (c4), c5⇒x6 (c5) x3,x4,x5,x6 @2
p c6 (¬x5 ∨ ¬x6): both false ⇒ CONFLICT conflict = c6

Implication graph (current level 2; x1@1 is the only level-1 node feeding in via c4):

            x2@2 ──c2──► x3@2 ──c3──► x4@2 ─┐
                                            ├─c4─► x5@2 ──c5──► x6@2 ─┐
   x1@1 ───────────────────────────────────┘                        ├─► ⊥ (c6)
                                            x5@2 ──────────c6─────────┘

1-UIP analysis (analyze(c6)): walk trail backward at level 2, resolve conflict clause against the reason of the most-recent level-2 literal until one level-2 literal remains.

Step Resolution Level-2 lits remaining
seed c6 = (¬x5 ∨ ¬x6) {x5, x6}
resolve on x6 (reason c5=(¬x5 ∨ x6)) (¬x5 ∨ ¬x6) ⊗_x6 (¬x5 ∨ x6) = (¬x5) {x5} ← exactly one ⇒ STOP
result learnt = (¬x5) unit learnt clause
  • Asserting lit ¬x5; backjump = 2nd-highest learnt level = none ⇒ 0 (unit). backjump(0); enqueue(¬x5, Clause(learnt)); VSIDS bump {x5,x6}; DRAT add (¬x5). Propagating at level 0 makes x5 permanently false — the learnt unit prunes the whole conflict subtree non-chronologically (skipped re-deciding x1,x2).

8.7 Worked UNSAT example + DRAT proof

Classic unsatisfiable core (every assignment falsifies one clause):

p cnf 2 4
 1  2  0     c1
 1 -2  0     c2
-1  2  0     c3
-1 -2  0     c4

CDCL trace: decide x1=true → c2,c4 conflict on x2 ⇒ learnt (¬x1); assert x1=false → c1,c3 conflict ⇒ learnt (). DRAT stream (each Add RUP-redundant, 0-terminated):

-1 0          c DRAT: add (¬x1)   — RUP redundant
0             c DRAT: add ()      — empty clause ⇒ UNSAT established

RUP check (check_drat, backward): to validate Add(L), assume ¬L for every lit of L, unit-propagate over the current DB; a derived conflict ⇒ L is RUP-redundant ⇒ accept.

Step being verified Unit-propagation trace Verdict
add (¬1) assume x1=true → c2 unit x2=false → c3=(-1,2) both false CONFLICT ✓ (RUP-redundant)
add () (¬1) now in DB ⇒ x1=false → c1 ⇒ x2=true → c2 both false CONFLICT ✓ ⇒ ⊥ derived ⇒ valid

If a step is not RUP-redundant the checker retries as RAT on the pivot (first literal): Add(L) is RAT iff for every clause D containing ¬pivot, the resolvent (L \ {pivot}) ∪ (D \ {¬pivot}) is RUP-redundant. Empty clause derivation ⇒ Ok(()); otherwise ProofError.

8.8 Malformed / edge DIMACS → DimacsError

Input fragment Condition Result
p cnf 3 / p sat 3 2 / q cnf 3 2 missing count / wrong token / non-p DimacsError::BadHeader
1 4 0 with nvars=3 ` literal
1 2 3 (EOF, no 0) clause not terminated DimacsError::MissingZeroTerminator
1 x 0 non-integer token DimacsError::NonNumeric
read failure mid-stream underlying I/O DimacsError::IoError
0 alone empty clause in input parse OK → empty clause ⇒ trivially UNSAT (no error)
1 -1 2 0 / 1 1 2 0 tautology / duplicate parse OK → dropped / deduped to (1 2)
nclauses mismatch declared ≠ actual accepted (warn); strict → BadHeader

Post-parse invariants (I7): every lit var() < nvars; no tautology; no dup lit; arena words match each size; an empty input clause is preserved verbatim (so UNSAT stays detectable), never normalized away.

11.1 sat-types — core value types

#[derive(Clone, Copy, PartialEq, Eq, Hash)]

#[derive(Clone, Copy, PartialEq, Eq, Hash)]
pub struct Lit(pub u32);                            // bits = var<<1 | sign (0=pos,1=neg); POD
impl Lit {                                          // signatures only (No-Code Rule §4)
    pub fn new(v: Var, neg: bool) -> Lit;           // (v.0<<1)|neg
    pub fn var(self) -> Var;                        // self.0>>1
    pub fn sign(self) -> bool;                      // self.0&1
}
impl std::ops::Not for Lit { type Output = Lit; }   // not = self.0 ^ 1

#[derive(Clone, Copy, PartialEq, Eq)] #[repr(u8)]
pub enum LBool { False = 0, True = 1, Undef = 2 }   // tri-value u8; ^sign flips T/F, leaves Undef
impl LBool { pub fn from_bool(b: bool) -> LBool; pub fn xor_sign(self, s: bool) -> LBool; }
  • Rationale (ADR-4): 2*var+sign ⇒ LitMap sized 2*nvars, l/l^1 adjacent, negation a branch-free XOR; Lit::MAX = "no blocker" sentinel. assigns: VarMap<LBool> is the assignment authority; lit truth = assigns[lit.var()].xor_sign(lit.sign()).

11.1.1 Clause storage — DST + arena (the load-bearing decision)

pub struct ClauseHeader {     // 8 bytes, precedes the inline [Lit] in the arena
    size:   u32,              // literal count; bounds the trailing [Lit]
    lbd:    u32,              // glue; 0 for original clauses
    learnt: bool,             // reduceDB only touches learnt
    deleted:bool,             // tombstone; reclaimed at compaction
    used:   u8,               // reduceDB recency (decremented each reduce)
}
pub struct Clause { header: ClauseHeader, lits: [Lit] }   // DST; lits[0..2] = watched (I1)

#[derive(Clone, Copy, PartialEq, Eq, Hash)]
pub struct ClauseRef(pub u32);                            // u32 word-offset, NOT a pointer; survives compaction via remap

pub struct ClauseArena { words: Vec<u32>, wasted: usize } // bump alloc; alloc→ref, clause(cref), free=tombstone, compact()→remap
  • Why DST+arena, not Vec<Vec<Lit>> (ADR-3, P6.5): one contiguous alloc ⇒ header+lits co-located, zero per-clause heap headers, linear-scan iteration, 4-byte ClauseRef vs 8/16-byte fat pointer, whole arena freed at drop. Access = 1 indexed load + bounds-free slice. ClauseRef not &Clause/*const because the arena reallocs/relocates and the borrow checker forbids &Clause while mutating watches — the offset sidesteps both.
  • Mutation: header (lbd/used/deleted) in place via clause_mut; lit slice only by watch-relocation (swap) + vivification (shrink size); size never grows (strengthen shrinks, learning allocates new). Compaction at wasted/words.len() > 0.20 (Phase 12) copies live clauses, emits remap, Solver patches all ref-holders. ClauseArena is Send, !Sync (single-threaded core).

11.3 sat-solver — the CDCL engine

pub struct Solver {                  // owns the arena (moved from Cnf) + per-var state; !Sync, &mut self only
    arena:   ClauseArena,            // all clause bytes
    trail:   Trail,                  // assignment stack + level limits
    watches: LitMap<Vec<Watcher>>,   // 2*nvars buckets; watched-by lists
    assigns: VarMap<LBool>,          // current truth value per var
    level:   VarMap<u32>,            // decision level a var was assigned at
    reason:  VarMap<Reason>,         // antecedent clause / Decision / Unit
    vsids:   Vsids,                  // branching heuristic
    phase:   PhaseSaving,            // saved polarity per var
    restart: RestartPolicy,          // Luby + Glucose-LBD EMA + blocking
    db:      ClauseDb,               // learnt-clause database (reduceDB)
    qhead:   usize,                  // propagation cursor into trail.lits
    conflicts: u64, decisions: u64, propagations: u64,  // statistics
}
impl Solver {
    pub fn new(cnf: Cnf) -> Solver;
    pub fn solve(&mut self) -> SolveResult;
    pub fn solve_under(&mut self, assumptions: &[Lit]) -> SolveResult;
    pub fn add_clause(&mut self, lits: &[Lit]);
    fn propagate(&mut self) -> Option<ClauseRef>;        // BCP; Some=conflict
    fn analyze(&mut self, conflict: ClauseRef) -> (Vec<Lit>, u32);  // (learnt, bj level)
    fn enqueue(&mut self, lit: Lit, reason: Reason);
    fn backjump(&mut self, level: u32);
    fn pick_branch(&mut self) -> Option<Lit>;
}
  • Lifecycle: new→(optional preproc)→solve/solve_under→SolveResult. Incremental (Phase 11): learnts/activities/phases persist across calls, trail resets to 0. qhead invariant (I8): lits[0..qhead] propagated; propagate advances to lits.len() or returns the first conflict.
pub struct Watcher { pub cref: ClauseRef, pub blocker: Lit }   // 8 B; blocker-True ⇒ skip arena load (re-validate vs assigns)
pub struct Trail { lits: Vec<Lit>, lim: Vec<usize> }           // lim[d] = level-d start; backjump truncates to lim[L]
pub enum Reason { Decision, Clause(ClauseRef), Unit }          // #[non_exhaustive]; antecedent in the implication graph
  • Blocker: most BCP visits are no-ops; the hot bucket blocker avoids a cold arena deref (P6.13). Two-watched (I1): each non-sat clause has lits[0..2] watched, NO backtrack repair. lim: level d spans lits[lim[d-1]..lim[d]]; decision_level()==lim.len()-1.
pub struct Vsids { activity: VarMap<f64>, inc: f64, decay: f64, heap: BinaryHeap<Var> }  // bump by inc, lazy inc*=1/decay, rescale at 1e100 (order-preserving), lazy heap of unassigned
impl Vsids { fn bump(&mut self, v: Var); fn decay_inc(&mut self); fn rescale(&mut self); }
pub struct PhaseSaving { saved: VarMap<bool> }                 // pick_branch reuses last polarity
pub struct RestartPolicy {            // Glucose: fire fast>K·slow (K~1.25); block when trail>R·avg (R~1.4); Luby fallback
    fast_lbd: f64, slow_lbd: f64,     // EMAs of recent learnt LBD
    trail_ema: f64,                   // blocking restarts
    luby_idx: u64, luby_unit: u64,    // fallback sequence
}
pub struct ClauseDb { learnts: Vec<ClauseRef>, reduce_limit: u64 }  // keep LBD-2 forever; sort (lbd,activity), drop worst half, skip reasons; geometric reduce_limit
  • LBD = distinct decision levels in a learnt clause; computed at learn time, recomputed on re-participation (only decreases).

State Action
init counter=0, p=UNDEF, idx=trail.len()-1, seed clause=conflict, learnt=[placeholder]

27. Failure Modes & Recovery

Severity scale: S0 unsoundness (wrong SAT/UNSAT) > S1 corruption/crash (panic, OOM, dangling ref) > S2 liveness (non-termination, livelock) > S3 degraded (slow, Unknown on tractable input) > S4 input (parse error, user fault). Recovery priority follows severity; S0 is never "recovered" silently — it aborts.

F1 — DIMACS parse error (S4)

  • Symptoms/root: Err(DimacsError), no Cnf — bad header (BadHeader), var > nvars (VarOutOfRange), missing 0 (MissingZeroTerminator), non-integer (NonNumeric), truncation (IoError).
  • Detect/recover: total during parse, byte-offset+line recorded; reject formula, exit 2, no partial solve. Operator: fix CNF / minisolve dimacs --validate.
  • Mitigation: fuzz parser (Phase 13) with malformed headers, oversized indices, missing zeros, huge clauses — cap clause length + reject before allocation (P6.11, T1).

F2 — Budget exhaustion (S3)

  • Symptoms/root: solve() returns Unknown — conflict/prop/time limit, interrupt, or genuinely hard formula.
  • Detect/recover: counter vs cap at restart boundary (cheap); clean Unknown, engine consistent for a larger-budget follow-up solve_under (incremental learnt reuse). Operator: raise --conflicts/--time, enable inprocessing, alt seed.
  • Mitigation: never conflate Unknown with Unsat (distinct variants); exit codes 10 SAT / 20 UNSAT / 0 UNKNOWN (P6.7).

F3 / F4 — UNSOUNDNESS (S0, gravest class)

A wrong answer is the only failure that silently corrupts a downstream proof. Treat every S0 as a release blocker.

Root-cause families: watch-invariant violation (falsified-watch clause skipped in propagate() → missed unit/conflict → wrong SAT, I1); 1-UIP error (analyze() stops at ≠1 current-level lits or wrong antecedent → wrong UNSAT, I4); backjump-level bug (wrong level → asserting lit not forced → both, I5); clause-DB use-after-delete (ClauseRef to a deleted clause read post-reduceDB → both, P6.5).

Detection (defense in depth, on by default in test/CI): (a) model validation — Sat re-evaluates every original clause (unsatisfied ⇒ F4, O(lits), I10); (b) DRAT self-check — Unsat feeds ProofTracer to DratChecker (no ⊥ ⇒ F3, I9); (c) watch invariant (debug, I1); (d) trail invariant (debug, I2). Recovery: none — S0 aborts (test panic / release UNSOUND exit), never emits a rejected verdict, no retry (P6.1/P6.14).

Debugging (canonical S0): (1) seeded replay reproduces trail/decisions/conflicts/learnts bit-for-bit (P6.8, MM6); (2) --trace dumps every enqueue/decision/conflict/resolution/backjump/reduceDB; (3) the first DratChecker-rejected Add localizes the unsound learnt → the exact analyze() (I3); (4) delta-debug to a minimal CNF, cross-check MiniSat/CaDiCaL (Phase 13). Forensic: seed, config, trace, rejected step, minimal CNF, offending ClauseRef. Long-term: self-check+model-validation CI gate; fuzz + mandatory UNSAT proof-check.

F5 — Clause-DB corruption / dangling ClauseRef (S1)

  • Garbage literals / arena-index panic / silent S0 from a ClauseRef retained across compaction without remap or a read of a deleted clause. Detect: debug bounds-check every arena[cref] + post-compaction assert all live refs (watches/reason/learnts/trail) in-range non-deleted. None in release (UB-adjacent)→debug panic; compaction rewrites all holders atomically (single audited routine, only handles never pointers, P6.5). Forensic: old→new remap, stale ref, holder.

F6 — Non-termination / livelock (S2)

  • Runs forever / restart-thrash — fast-EMA never below K·slow, reduceDB mis-tuned, reason cycle, re-derived duplicate. Detect: no-progress watchdog (best level + DB size); N restarts with no new glue over reduce_limit ⇒ livelock. Auto: force Luby + reduceDB; still stuck within budget ⇒ Unknown. Mitigation: Luby ceiling + keep-half bound; assert acyclic graph (debug).

F7 — Proof checker false-reject (S0 trust / S1 functional)

  • check_drat/check_lrat rejects a believed-correct proof — RUP order bug, wrong RAT pivot, deletion before last use, stale LRAT hints. Detect: cross-check the other checker + external drat-trim; disagreement isolates the bug → escalate to manual, trust neither until reconciled. Mitigation: full DRAT/LRAT conformance suite; trim before RAT checks. Forensic: failing step, RUP trail, expected pivot.

F8 — Proof checker false-accept (S0)

  • Ok for a proof not entailing ⊥ — RAT skips a resolvent, premature RUP conflict, missing empty-clause check. Detect: differential vs drat-trim/LRAT-check on known-bad injected proofs + mutation testing (flip a lit → must reject). None — abort (a false-accept invalidates the UNSAT trust chain). Mitigation: mandatory negative-test corpus; prefer LRAT for the trusted path.

F9 — Incremental state leakage across solve_under (S0)

  • An answer depends on a prior call's assumptions — trail not unwound to 0, stale reason/level (stale phase/activity is fine), failed-conflict clause leaking as a permanent learnt. Detect: assert trail empty above 0 + qhead==0 between calls + equivalence test solve_under(A);solve_under(B) == fresh+solve_under(B). Abort + reset to clean level-0. Mitigation: backjump to 0 on entry; only add_clause persists; failed assumptions returned, never auto-added (P6.10/I11).

F10 — Arena OOM (S1)

  • Alloc fail / RSS over cap during add_clause/learnt growth (explosion on hard instances, fragmentation). Detect: RSS soft cap + arena-grow hook at reduceDB boundary. Auto: aggressive reduceDB then compaction; still over cap ⇒ clean Unknown (never crash, P6.7). Mitigation: hard --max-memory, doubling-with-cap growth, sat-cnf rejects pathological clauses pre-solve.

F11 — VSIDS heap inconsistency (S1)

  • pick_branch returns an assigned Var or order violated → wrong/duplicate decisions (possible S0) — var not removed, rescale not re-heapifying, bump without sift-up. Detect: debug assert top Undef + heap-property post-rescale + lazy-deletion sanity. Auto: rebuild from unassigned by activity. Mitigation: single insert/remove path; pop-until-Undef degrades to slow not unsound (I6).

Cross-cutting recovery principles

  • Fail loud, never wrong: any S0 aborts with an UNSOUND banner, never a hidden Unknown (P6.1/P6.14). Determinism is the debugger: single-threaded ⇒ (CNF, seed, config) reproduces every failure bit-for-bit (P6.8). Two independent oracles gate correctness — model validation (SAT) + DRAT/LRAT self-check (UNSAT), neither alone trusted. Builds: release strips hot-path asserts; the conformance build (Phase 13, CI) compiles all invariants + mandatory proof-checking. Clean state machine: every recoverable failure returns to a defined state (level-0 trail, consistent arena, valid heap) or Unknown — no half-solved limbo.

32.4 Cache locality & branch prediction

  • Contiguous ClauseArena ⇒ sequential learnts spatially local (fewer L1d misses on analyze() walk). 32.7 VSIDS heap cost

  • BinaryHeap over VarMap<f64>: bump = sift-up O(log n), pick = pop-max O(log n), decay = lazy inc *= 1/decay O(1), rescale O(n) but rare (~every 1e4–1e5 conflicts). Target <100 ns/decision at 1M vars, bump <30 ns. Phase saving = O(1) saved[var] read. Pitfall: stale entries → pop-and-skip-if-assigned, not eager deletion.

32.8 Tail latency & hard-instance analysis

  • Runtime is heavy-tailed: crafted UNSAT (PHP pigeonhole, parity/XOR) explode super-polynomially — CDCL resolution lower bounds (PHP exponential without symmetry breaking). Symptom: conflicts/s high but no progress (level oscillates, LBD flat, DB churns). Drivers: high tree-width / no good 1-UIP cuts; VSIDS thrashing on symmetric vars; restart stuck (fast EMA never exceeds slow).
  • Budget (--conflicts/--propagations/--time-ms/--mem-mb, checked at restart boundaries) ⇒ Unknown (P6.7). bench watchdog: hard TO = PAR-2 timeout (e.g. 5000s), 2× PAR-2 contribution. On timeout dump conflicts/s, restarts, LBD, DB size, peak trail to classify exploded (high churn) vs stuck (flat). Track p95/p99 per-instance time across commits — p99 up >10% flags a regression even if mean is flat.

33. Scalability Analysis

Cost vs. problem size (vars n, clauses m)

Resource Scaling Constant / detail
Initial memory O(n + m·k) arena u32 words Σ(2+size); VarMap=n·sizeof; LitMap=2n·sizeof; per-clause 2 u32 header + 4·size B (inline lits)
Watch lists O(m) (2/clause) LitMap<Vec<Watcher>>, Watcher=8 B
Occurrence lists (preproc) O(total-lits), transient live only during BVE/subsumption
Vsids heap + trail/level/reason O(n) one entry per var, bounded by n
Solve time worst-case Θ(2^n) NP-complete; not bounded by size

Memory is ~linear in formula size; time is exponential worst-case but in practice governed by structure (community/treewidth, backdoor size, clause/var ratio) not raw n,m. Industrial CNFs with millions of clauses solve while crafted ~150-var pigeonhole/parity instances do not.

Learnt-clause DB growth (bounded)

  • One learnt/conflict ⇒ unbounded without control; reduceDB caps it, steady-state db.learnts.len() oscillates around reduce_limit. Retention: LBD-2 glue forever, reason clauses never deleted, else drop high-LBD/low-activity half. Effective DB memory bounded ~O(reduce_limit · avg-learnt-size), decoupled from total conflicts. Arena fragments → Phase-12 compaction reclaims when dead-fraction >25%.

Preprocessing effect on effective size

  • BVE (occ_pos·occ_neg ≤ orig+grow) shrinks n and often m, trading search memory for EliminatedClauseStack reconstruction memory. Subsumption+SSR are monotone non-increasing on m and shrink clauses (cheaper BCP). Net effective n,m drops 10–50% on structured CNF ⇒ superlinear time payoff; pathological BVE blowup capped by the resolvent-growth bound.

Single-thread ceiling

  • propagate()→analyze()→backjump() is inherently sequential: each implication depends on the current trail; VSIDS + learnts feed the next decision. No BCP data parallelism (shared watch lists + single Trail/qhead; speculative parallel propagation re-converges, wasting work). So the scaling lever is clause sharing across instances, not splitting one solver. Ceiling = memory bandwidth + BCP branch misprediction, not CPU count.

Horizontal scaling — deferred shared-clause portfolio

  • PhaseDeferred("Deferred Features Register"): launch P Solver on the same CNF diversified by seed/decay/RestartPolicy/phase/preproc; first to terminate wins, others cancel — superlinear speedup on heavy-tailed distributions (diversification, not work-splitting). Import low-LBD (≤~4) learnts via a bounded lock-free queue, rate-capped against DB bloat.

Watch-list + occurrence-list memory scaling

34. Mental Models & First Principles

The compressed insights an expert holds. Each: the model · what it predicts · the bug class you write without it · where this blueprint applies it.

  • MM1 — Conflict analysis IS resolution; a learnt clause is a resolvent chain. Predicts: every learnt clause is entailed (RUP-derivable), so UNSAT is just deriving the empty clause; learnt-clause quality is resolution-proof quality. Without it you treat analyze() as ad-hoc bookkeeping and add "optimizations" that learn non-implied clauses → false UNSAT. Applies: §16 (Phase 4), §22 (Phase 10), P6.3/P6.15, I3.
  • MM2 — A watched literal is a lazy "wake me when you might matter" subscription; the invariant survives undo without repair. Predicts: O(1) backjump (no watch fixup), and that a clause is touched only when a watch falsifies. Without it you "fix up" watches on backtrack (slow) or skip a falsified clause (missed unit → unsound). Applies: §14 (Phase 2), §24 (Phase 12), ADR-6, I1.
  • MM3 — VSIDS is recency-weighted activity with lazy decay; bump the increment, never the scores. Predicts: O(1) decay, and that branching tracks the current conflict frontier. Without it you rescale all activities every conflict (O(n) hot-loop death) or break heap order on overflow. Applies: §18 (Phase 6), §24, ADR-8, I6.
  • MM4 — A no answer is worthless without a certificate; trust the proof, not the prover. Predicts: a watch/analyze bug degrades to caught (checker rejects) not wrong, because an independent RUP/RAT engine re-derives ⊥. Without it a single kernel bug silently poisons every downstream. Applies: §22 (Phase 10), Threat Model TB-2, P6.1/P6.9, I9.
  • MM5 — Runtime is heavy-tailed, so restart and diversify rather than push one search. Predicts: restarts help (escape a bad subtree), Luby/Glucose-LBD beat fixed intervals, portfolio gives superlinear speedup. Without it you tune for the mean and stall on the tail. Applies: §19 (Phase 7), Scalability Analysis, ADR-10, MM-link to portfolio.
  • MM6 — The solver is a pure function of (CNF, seed, config); determinism is the debugger. Predicts: any failure replays bit-for-bit, so bisection/ddmin work. Without it (HashMap iteration, wall-clock, threads in the core) failures are unbisectable flakes. Applies: §17 (Phase 5), Compatibility & Versioning, P6.8.
  • MM7 — Clauses live in one arena addressed by handles; compaction rewrites the handle table, not the holders' minds. Predicts: a ClauseRef survives relocation but a &Clause/pointer dangles; compaction must rewrite every live ref in one pass. Without it you cache a slice across add_clause → use-after-realloc. Applies: §24 (Phase 12), Core Schema & Types, ADR-3, P6.5.
  • MM8 — Heuristics only order; the kernel decides what is correct. Predicts: swapping VSIDS/restart/reduceDB changes speed, never the verdict — so you can tune fearlessly behind a frozen core. Without it a "smart" rule hard-assigns outside enqueue, corrupting the implication graph → unsound learnt. Applies: §18–§19, Compatibility & Versioning, P6.6.

36. Back-of-Envelope Capacity Model

Numbers an expert computes before designing, derived from System Constraints (§4). Formula shown; assume a single ~3 GHz core, 64 B cache line.

  1. Clause-arena bytes = clauses × (header 2 words + avg-size lits) × 4 B. For 1e6 clauses, avg size 8: 1e6 × (2+8) × 4 ≈ 40 MB. (§4.1 clause storage.)
  2. Watch-list memory = clauses × 2 watchers × 8 B (Watcher{cref,blocker}): 1e6 × 2 × 8 ≈ 16 MB. (§4.1; MM2.)
  3. Per-var dense arrays = nvars × (assigns 1 + level 4 + reason 8 + activity 8 + phase 1) ≈ 22 B. For 1e6 vars: ≈ 22 MB. LitMap watch heads add 2·nvars pointers. (§4.1.)
  4. Total RAM @ 1e6 vars / 5e6 clauses, avg size 6: arena 5e6×(2+6)×4 ≈ 160 MB + watches 5e6×2×8 = 80 MB + per-var 22 MB ≈ ~260 MB before learnts. (§4.1, §4.4.)
  5. Learnt-DB ceiling = reduce_limit × avg-learnt-size × 4 B. At reduce_limit ≈ 2e5, avg learnt 12: 2e5 × 12 × 4 ≈ 9.6 MB steady-state (bounded, not monotone). (Scalability "Learnt-DB growth".)
  6. LitMap size cap = 2 × nvars must fit u32 ⇒ nvars < 2^31; the configured cap 2^28 ≈ 268M keeps 2·nvars ≈ 2^29 words safely under 2^31. (§4.4, ADR-4, T6.)
  7. BCP throughput vs cache: at ≥1e7 props/s and ≤1 cache miss/propagated lit (~100-cycle miss), miss-bound rate ≈ 3e9 / 100 = 3e7 misses/s — so the target needs <1 miss/prop, exactly what the blocker shortcut buys (§4.5, §32.7).
  8. VSIDS heap ops/s = decisions/s × log₂(nvars). At 1e5 decisions/s, 1e6 vars: 2e6 sift ops/s — negligible vs BCP (§32.7, I6).
  9. reduceDB cadence = one sort per reduce_limit conflicts. At 1e5 conflicts/s, reduce_limit=2e5: a sort every ~2 s over ~2e5 learnts (≈ sub-ms) — <1% runtime (Phase 7 §19.7).
  10. Proof-stream rate = ~1 Add/conflict; at 1e5 conflicts/s, avg 12 lits binary-DRAT: ≈ 1.5 MB/s ⇒ a 1-hour hard UNSAT emits ~5 GB — hence streaming + .zst + trim (§4.1, §28).
  11. Compaction pause = O(live words) at ~1 word/ns: a 40 MB arena ≈ 10 ms, fired at >20% waste (~once per ~10 reduceDB cycles) ⇒ <2% wall (§32.7).
  12. Cold start = parse at ≥150 MB/s + arena fill + watch init: a 200 MB CNF loads in ~1.3 s before the first decision (§4.3, Phase 13 §25).

38. Alternative Architectures (Roads Not Taken)

Fundamentally different designs for the same "decide one CNF" problem.

Alt-1 — Pure DPLL (chronological backtracking, no learning).

decide → propagate → conflict? backtrack one level + flip : decide   (no analyze, no learnt DB)

Wins when: tiny or near-uniform-random instances where the learnt DB + analyze overhead exceeds the pruning payoff (and as the Phase-3 correctness oracle). Real system: original DPLL (Davis-Logemann-Loveland 1962); early GRASP variants. Rejected: chronological backtrack re-derives the same conflicts → exponential blowup on structured industrial CNF; loses the asserting-clause leverage that is the whole point of CDCL (ADR-7).

Alt-2 — Stochastic local search (WalkSAT-style).

random total assignment → loop { pick an unsat clause → flip a var in it (greedy/noise) } → stop at a model

Wins when: satisfiable, under-constrained random instances near/below the phase transition, where it finds models orders of magnitude faster than CDCL. Real system: WalkSAT / probSAT (Selman, Kautz, Cohen). Rejected: cannot prove UNSAT (no certificate, no completeness) — violates the non-negotiable proof-carrying-UNSAT contract (P6.1/P6.9); useless for the SMT/BMC consumers that need a checkable no.

Alt-3 — Look-ahead / cube-and-conquer.

look-ahead picks a strong split var by trial-propagating both polarities (failed-literal detection)
└─ cube phase splits the formula into N subcubes → conquer each with a CDCL solver (parallel)

Wins when: hard combinatorial/crafted instances (parity, pigeonhole, van der Waerden numbers) and massively parallel hardware — cube-and-conquer solved open math problems (e.g. Boolean Pythagorean triples, Heule 2016). Real system: march (look-ahead); cube-and-conquer (march + CDCL). Rejected here: look-ahead's per-decision trial propagation is far too slow on large application CNF (ADR-8 rejected look-ahead branching); cube-and-conquer needs a parallel substrate this single-process core defers to the portfolio stretch.

40. Glossary

Term Definition (implementation-relevant)
CNF / clause / literal input = AND of clauses (OR of literals); Cnf{nvars,clauses,arena}, Clause DST in ClauseArena, Lit(u32)=2*var+sign. (full semantics §8.1)
unit clause exactly one unassigned literal (rest false) → forced true; detected in propagate().
empty clause zero/all-false literals = unconditional conflict; deriving it proves UNSAT + ends a DRAT proof.
DPLL Davis–Putnam–Logemann–Loveland: decide→propagate→chronological backtrack. Phase-3 baseline.
CDCL DPLL + conflict analysis + learnt clauses + non-chronological backjump. Core search(), Phase 5.
BCP / unit propagation enqueue forced literals from unit clauses to fixpoint/conflict. propagate().
two watched literals inspect a clause only when one of its 2 watches falsifies; NO restore on backtrack.
watch list watches: LitMap<Vec<Watcher>> keyed by the falsified literal.
blocker literal cached 2nd-watch lit in Watcher; if true, skip dereferencing the clause (cache opt).
trail Trail{lits,lim} chronological assignment stack; lim[d] = start index of level d.
decision level count of decisions on the trail; level: VarMap<u32>; level 0 = unconditional.
decision literal branched (pick_branch), not forced; Reason::Decision; opens a level.
implication graph DAG of forced assignments (antecedent edges → implied lit); walked by analyze().
antecedent / reason the clause that forced an assignment. Reason{Decision,Clause(ClauseRef),Unit}.
conflict clause a clause falsified under the trail; propagate()→Some(cref) seeds analyze().
conflict analysis analyze(): resolve the conflict clause backward through antecedents → learnt + backjump.
1-UIP First Unique Implication Point: resolve until exactly ONE current-level lit remains (the asserting lit).
asserting clause / literal The learnt clause; after backjump it has exactly one unassigned literal (the asserting literal) which it immediately propagates.
backjump (non-chronological) Jump directly to the 2nd-highest decision level among learnt-clause literals (0 if unit), skipping intervening levels. backjump(level).
backtrack (chronological) DPLL-style: undo exactly one decision level. Used in Phase 3 baseline only; CDCL uses backjump.
VSIDS Variable State Independent Decaying Sum: branch on max-activity unassigned variable. Vsids { activity, inc, decay, heap }.
activity Per-variable score (VarMap<f64>); bumped when a variable appears in conflict-side clauses; inc *= 1/decay per conflict; rescale all on overflow.
phase saving Reuse a variable's last-assigned polarity on re-decision. PhaseSaving { saved: VarMap<bool> }.
restart Abandon current assignment back to level 0, keeping learnt clauses; diversifies search. RestartPolicy.
Luby restart Restart intervals following the Luby sequence (1,1,2,1,1,2,4,…) × unit; the fallback policy.
Glucose-LBD restart Dynamic: fire when recent-LBD fast EMA > K × slow EMA (search is producing high-glue clauses).
blocking restart Suppress a restart when the trail is unusually long (search looks productive), to avoid throwing away progress.
LBD / glue Literal Block Distance = number of distinct decision levels among a learnt clause's literals. LBD-2 = "glue". Stored in ClauseHeader.lbd.
learnt clause Clause derived by analyze() and added to ClauseDb; ClauseHeader.learnt = true. Subject to reduceDB.
reduceDB Periodic learnt-DB reduction: delete high-LBD, low-activity, non-reason learnts (keep ~half); glue clauses kept permanently. ClauseDb { learnts, reduce_limit }.
BVE Bounded Variable Elimination: resolve away a variable if the resulting clause-set growth is bounded. BoundedVarElim; pushes onto EliminatedClauseStack.
subsumption Remove clause C if another clause D ⊆ C (D's presence makes C redundant). Subsumption, uses OccurrenceList.
self-subsuming resolution Strengthen C by removing literal l when resolving C with D yields a clause ⊆ C. SelfSubsumingResolution.
vivification Strengthen a clause by trial-propagating negated prefixes; drop literals whose negation is already implied. Vivification (Phase 9).
occurrence list OccurrenceList: per-literal index of clauses containing it; powers BVE/subsumption (vs. watch lists used for BCP).
inprocessing Interleaving simplification (BVE, subsumption, vivification) with search between restarts, on the current DB. Phase 9.
preprocessing One-shot simplification of the input CNF before search begins. Phase 8.
DRAT Deletion Resolution Asymmetric Tautology: proof = sequence of ProofStep { Add, Delete }, each RUP- or RAT-redundant; UNSAT proven at empty clause. Emitted via ProofTracer.
LRAT Linearized RAT: DRAT plus explicit clause-id hints per step, enabling fast forward checking. LratChecker, check_lrat().
RUP Reverse Unit Propagation: a clause is RUP-redundant if asserting the negation of its literals and running BCP yields a conflict.
RAT Resolution Asymmetric Tautology: redundancy w.r.t. a pivot literal — every resolvent on the pivot is RUP. Generalizes RUP.
resolution proof Sequence of resolution steps deriving the empty clause from the input clauses; the certificate underlying DRAT/LRAT.
model reconstruction On SAT after elimination: replay EliminatedClauseStack in reverse to extend the model to BVE-eliminated variables.
assumption A literal fixed true for one incremental call. solve_under(assumptions: &[Lit]); assumptions are decision-level-0-like temporary decisions.
failed assumption Subset of assumptions appearing in the final conflict that caused UNSAT-under-assumptions; extracted for the host (UNSAT core).
incremental SAT Solving a sequence of related queries reusing learnt clauses across solve_under/add_clause calls.
IPASIR Reentrant Incremental SAT solver API standard (add/assume/solve/val/failed) that the incremental interface mirrors.
clause arena ClauseArena: bump-allocated u32-word region holding all clauses; supports compaction/GC. Clauses addressed by offset.
ClauseRef ClauseRef(u32): offset/handle into ClauseArena (NOT a raw pointer) → survives arena compaction, cache-friendly indexing.
tautology Clause containing both l and !l; always true → dropped during DIMACS normalization (sat-cnf).
pure literal Variable occurring with only one polarity across all clauses → may be set to satisfy them; handled in preprocessing.
LBool Tri-valued assignment { True, False, Undef }, packed to u8; assigns: VarMap<LBool> holds the partial model.
SolveResult { Sat(Model), Unsat, Unknown }; Unknown = budget exhausted or interrupt. Model(VarMap<bool>) = total assignment.
