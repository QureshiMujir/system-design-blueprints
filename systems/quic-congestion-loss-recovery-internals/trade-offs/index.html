Roads not taken (§34)

Whole architectures the blueprint considered and rejected, each with the regime where it would win.

Alt A — Kernel-Resident Congestion Control

+------------------+      +---------------------+
| Application      | ---> | tcp_congestion_ops   |
+------------------+      | (in-kernel module)   |
                           +---------------------+
                                    |
                                    v
                           +---------------------+
                           | Kernel TCP/IP stack |
                           +---------------------+

Wins in: environments where kernel-level scheduling and NIC integration already exist and userspace round-trips are the bottleneck (classic kernel TCP deployments). Real system: Linux kernel's tcp_congestion_ops framework (pluggable in-kernel CUBIC/BBR modules). Rejected because: userspace determinism and replay (P1, P6) cannot be retrofitted onto kernel scheduling, and portability across the BSD/macOS secondary targets (§1.5) breaks entirely.

Alt B — Hashmap-Indexed Send History

HashMap<PacketNumber, SentPacket>
  lookup: O(1) average, cache-hostile
  iteration: unordered, defeats descending ACK-range scan

Wins in: low connection counts (<1,000/node) where implementation simplicity and flexible eviction outweigh cache locality. Real system: early quic-go send-history implementations before locality-driven rewrites. Rejected because: at the §4 250k-connection ceiling, hashmap cache-miss amplification dominates ACK-processing latency (ADR-27's rationale), breaking the §4 p99 budget.

Alt C — BBR-First Congestion Control

CongestionController = BbrV1 { delivery_rate_filter, min_rtt_filter, pacing_gain_cycle }

Wins in: long-fat-network-dominated fleets (satellite CDN edge, transcontinental links) where CUBIC's loss-based signal is too slow to react. Real system: msquic (ships BBR by default). Rejected for v1 because: BBR's delivery-rate-sampling determinism needed for replay (P1) is unsolved absent the groundwork planned for §21; CUBIC's RFC 8312 formula is simpler to make bit-reproducible today, with BBR deferred (§35, PhaseDeferred("§17")).

Alt D — Single Global Connection Table with Lock Striping

Mutex<HashMap<ConnId, ConnectionState>>  (striped N-ways)
  every ACK/loss/pacing decision acquires a stripe lock

Wins in: moderate connection counts where a simpler mental model (one table, no actor mailboxes) is worth some contention. Real system: earlier lsquic engine-wide locking designs before per-connection isolation. Rejected because: cross-connection lock contention on the hot ACK path violates the single-writer, no-cross-connection-contention goal (ADR-08) at the §4 250k-connection scale.
