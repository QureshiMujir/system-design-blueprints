Hard questions

Self-examination questions from the blueprint; each points at the section where the answer lives.

  1. If you double the C-space dimension from 3 to 6 DOF, which §4 targets become infeasible and why? Trace the impact through the near-radius formula, near-neighbor cost, and the collision-check budget. (§4, §7 §7.9, Phase 7, MM4)
  2. CHOMP reduces path length but ESDF clearance decreases after smoothing. Diagnose the three most likely root causes and cite the invariant that detects each. (§7 §7.1, Phase 3, Phase 9, MM5, ADR-10)
  3. Your D* Lite repair after 50 obstacle insertions produces a path longer than a fresh A* on the same changed map. Under what conditions is this expected, and when does it indicate a bug in the k_m update or the rhs/g inconsistency propagation? (Phase 4, I6, MM10, ADR-5)
  4. A DWA tick runs at 22 ms on one test scenario. List the five most likely causes in order of probability, the telemetry signals that distinguish them, and the fix for each. (§4, §7 §7.7, Phase 11, I7, ADR-12, MM7)
  5. You must serve a 7-DOF manipulator and a non-holonomic car with a single Planner implementation. What trait boundaries must be respected, and what breaks if you pass a Dubins SteeringFn to a joint-space StateSpace? (§11.5, §11.1, Phase 8, P5, P9, I3)
  6. RRT* is used in a 6 m × 6 m room with a single narrow doorway (0.3 m wide). After 1e4 samples the cost gap to optimal is 30%, not 5%. Cite the two most likely causes and the exact §4 acceptance criterion that is failing. (§4, Phase 7, Phase 5, I4, MM3, ADR-8)
  7. The ESDF's gradient at a cell adjacent to an obstacle wall is zero rather than pointing outward. Explain which step of the Felzenszwalb-Huttenlocher EDT or the subsequent central-difference computation is wrong and how the Phase 3 property tests would catch it. (§8.5, Phase 3, I1, MM5, ADR-10)
  8. An adversarial map file causes the planner to allocate 800 MB and OOM-kill the process. Enumerate every resource-cap path that should have triggered a ResourceExhausted before the OOM, citing the relevant threat-model row and the ADR that enforces the cap. (§4, Threat Model, Phase 3, ADR-10, ADR-21, P10)
  9. You need to prove that the returned path satisfies I1, I2, and I3 simultaneously for a Hybrid A* result. Which three checks in mp-planner::pipeline.rs produce this proof, and what happens if one of them is skipped under a deadline? (§7 §7.1 §7.2 §7.3, §11.6, Phase 8, Phase 12, P6, P11)
  10. How does the InformedEllipsoid sampler's transverse diameter change as c_best approaches c_min, and what degenerate geometry must be handled when they are equal? (§8.3, §7 §7.5, Phase 7, ADR-6, MM4, I5)
  11. A PRM built in a static environment is reused after a wall has been added. The query returns a path that passes through the new wall. Enumerate the three defense layers that should have caught this and identify which invariant each enforces. (§7 §7.1 §7.8, Phase 5, I1, I8, MM3, ADR-14)
  12. You observe that astar_expansions on a 500×500 grid with octile heuristic is 240 000 — close to the grid size — instead of the expected ~10%. Diagnose the heuristic, connectivity, and cost-function interactions that could cause this. (Phase 4, I6, §7 §7.6, MM6, ADR-5)
  13. The trapezoidal time-parameterizer produces a trajectory where joint 3 reaches a_max for only 1 ms before needing to decelerate. The multi-DOF synchronization then elongates all other joints' profiles by 4×. Is this correct behavior? What does it imply for the DynamicLimits design and the TOPP-lite alternative? (Phase 10, I3, §11.7, §7 §7.3, MM9)
  14. How does the lock-free single-slot channel between the global planner and mp-local guarantee that the local loop never sees a half-written Trajectory? What memory-ordering guarantees are required and what goes wrong if only a relaxed load is used? (§3.3, Phase 11, I7, ADR-11, ADR-12, P12)
  15. Compare the failure modes of NoPath under three different root causes: (a) sealed region, (b) narrow-passage starvation, and (c) resource cap hit. For each, identify the telemetry signal, the recovery action, and the planner change that would prevent recurrence. (Failure Modes & Recovery, Phase 5, Phase 6, §4, P10, MM3, ADR-8)
  16. If you replace ChaCha8 with a deterministic but platform-dependent hash as the RNG, enumerate every place in the codebase where I5 (determinism given seed) would break and why byte-identity is lost. (§7 §7.5, Phase 0, Phase 12, I5, ADR-6, MM8, ADR-23)
  17. CHOMP uses a covariant gradient A⁻¹·∇U. What is the purpose of the A⁻¹ factor (the metric in trajectory space), and why does omitting it and using a plain gradient ∇U cause unequal step sizes across waypoints? (Phase 9, §8.5, MM5, ADR-3)
  18. Explain why the Hybrid A* analytic-expansion shortcut must use the same κ_max as the lattice primitives, and what path-cost anomaly arises if the analytic shot uses a slightly larger turning radius. (Phase 8, I3, §7 §7.3, MM9, ADR-8)
  19. A new deployment requires planning for a 12-DOF bimanual manipulator. Identify the three §4 targets most at risk, the Deferred Features Register entry that is closest to enabling it, and the concrete measurement that would justify un-deferring it. (§4, §1.8, Deferred Features Register, MM4, P2, ADR-8)
  20. The benchmark harness shows that Informed RRT* reaches 5% cost-gap in 3 000 samples on narrow_passage_2d but only 12 000 samples on random_2d. Explain this reversal and identify the sampling-volume calculation that accounts for it. (§4, Phase 7, §8.3, MM4, I4, ADR-6)

Mental Models & First Principles

  1. MM1 — C-space is the only space where planning is tractable. Predicts: whether a planner can serve both a car and an arm without rewriting. Without it: you hard-code SE(2) into search logic, write a separate planner for every robot morphology, and collision logic leaks into the planner (violates P5). Applied: §8.1 / §11.1 / Phase 1 where StateSpace is the universal abstraction every planner is generic over.

  2. MM2 — Collision checking is a first-order bottleneck; everything else is second-order. Predicts: where 90%+ of planning CPU goes, and which optimizations yield linear speedup. Without it: you optimize the wrong layer (heuristic computation, kd-tree queries) while narrow-phase GJK still dominates; your planner is 10× slower than it needs to be (P1). Applied: §8.6 / Phase 2 (BVH early-out, batch broad phase) / Phase 7 (lazy near-set validation).

  3. MM3 — Probabilistic completeness is an asymptotic statement, not a convergence-rate guarantee. Predicts: why PRM fails on a narrow passage at n = 200 but succeeds at n = 5000; why raising n costs quadratically in edge checks. Without it: you declare the planner broken when it is merely under-sampled, or you over-provision n and blow memory/time budgets (P2, I1). Applied: §4 (success-rate targets with explicit n) / Phase 5 / Phase 6.

  4. MM4 — Asymptotic optimality requires a shrinking near-radius; fixed-k RRT is not optimal. Predicts: whether r_n = γ·(log n / n)^(1/d) is necessary and what γ must be for the given C-space dimension d. Without it: you ship RRT*-labeled code with a fixed k-nearest neighbor that converges to a suboptimal path and does not satisfy the Karaman & Frazzoli 2011 conditions (I4, P7). Applied: Phase 7 (near-radius decay, dimension-aware γ) / §7.4.

  5. MM5 — A signed distance field turns clearance into a differentiable cost; without the sign, gradient ascent pushes into, not away from, obstacles. Predicts: whether CHOMP's gradient step reduces or increases collision. Without it: an unsigned distance field has zero gradient inside obstacles, making the optimizer unable to escape; the smoothed path can be worse than the input (P6, I1). Applied: §8.5 / Phase 3 (ESDF sign convention + gradient direction) / Phase 9 (CHOMP obstacle cost).

  6. MM6 — Admissible heuristics are necessary, not sufficient, for A-optimal paths.* Predicts: when octile distance overestimates on 4-connected grids (inadmissible) vs 8-connected grids (tight admissible bound). Without it: you use octile on a 4-connected grid and produce suboptimal paths while believing them optimal; invariant §7.6 silently breaks (P8, I6). Applied: Phase 4 (heuristic-to-connectivity matching, Dijkstra ground-truth property test).

  7. MM7 — The dynamic window restricts to velocities that allow a safe stop; without the admissibility filter the local planner is a crash generator. Predicts: which (v, ω) pairs are reachable and stoppable given current accel limits and nearest obstacle distance. Without it: the DWA scores and selects velocities the robot cannot brake from before hitting an obstacle — the scoring objective wins over physical safety (P9, I7, I3). Applied: Phase 11 (admissibility filter before scoring) / §7.7.

  8. MM8 — Determinism is a protocol property, not an implementation detail; any thread-local entropy or unordered iteration breaks it globally. Predicts: which data structures and API patterns violate replay (HashMap iteration, thread_rng, wall-clock timestamps in search). Without it: bugs are irreproducible; differential tests flap; the CI gate has false negatives; the audit trail is broken (P4, I5). Applied: §3.3 (determinism boundary) / Phase 0 (ordered-float, BTreeMap) / Phase 12 (byte-compare harness).

  9. MM9 — Kinodynamic constraints must be satisfied by the steering function, not checked after the fact. Predicts: whether a Reeds-Shepp path can guarantee κ ≤ κ_max by construction rather than by post-hoc pruning. Without it: you generate candidate paths and reject most, wasting collision budget; or you miss constraint violations that invalidate the trajectory for the downstream controller (I3, P5). Applied: §8.4 / Phase 8 (Dubins/RS closed-form, SteeringFn trait contract).

  10. MM10 — Incremental replanning repairs only the changed subgraph; full replanning from scratch does not scale with environment dynamism. Predicts: when D* Lite's incremental-expansion count is sublinear in map size vs a fresh A* sweep. Without it: a dynamic environment with frequent small changes forces full A* replans that blow the local-loop budget, and the reactive planner starves (P3, I7). Applied: §8.7 / Phase 4 (D* Lite k_m + rhs logic) / Phase 11 (replan trigger selects D* Lite incremental vs full).

5.4 RFCs / specifications

No formal RFC governs motion planning. Treat as normative references: OMPL planner taxonomy (geometric vs control vs optimizing planners) for naming; URDF (Unified Robot Description Format) and SRDF (Semantic Robot Description Format) for the robot-model schema mp-geom ingests (links, joints, joint limits, collision geometry, planning groups, allowed-collision matrix). Map formats: ROS nav_msgs/OccupancyGrid semantics (row-major, [0,100] occupancy, -1 unknown) as the mp-env import baseline.

Glossary · 54 terms · site-wide glossary

Configuration (q)
a complete specification of robot pose: SE(2)/SE(3)/joint values
Configuration space (C-space)
the space of all configurations; planning is a search in C-space
C-obstacle
the region of C-space corresponding to robot-obstacle collision
Holonomic
a robot whose controllable DOF equal its total DOF (can move any direction)
Non-holonomic
motion constraints reduce instantaneous controllable DOF (e.g. a car cannot move sideways)
Kinodynamic
planning subject to velocity/acceleration (dynamic) constraints
Completeness
a planner finds a solution if one exists (resolution / probabilistic variants)
Resolution completeness
complete up to the chosen discretization (A*, Hybrid A*)
Probabilistic completeness
probability of finding a solution -> 1 as samples -> ∞ (RRT, PRM)
Asymptotic optimality
solution cost -> optimal as samples -> ∞ (RRT*, Informed RRT*)
Anytime planner
returns a valid (improving) solution at any interruption point
Metric
a true distance function (symmetric, triangle inequality) on C-space
Sampler
draws configurations from C-space (uniform/Gaussian/bridge/Halton/informed)
Dispersion
a measure of the largest unsampled gap; lower is better coverage
Occupancy grid
a grid of free/occupied/unknown cells representing the environment
Costmap
a grid of traversal costs, typically with obstacle inflation
ESDF
Euclidean Signed Distance Field: per-cell signed distance to the nearest obstacle (+ gradient)
EDT
Euclidean Distance Transform: algorithm computing distance to nearest obstacle
Broad phase
fast culling of non-colliding pairs (BVH / spatial hash)
Narrow phase
exact collision/distance between candidate pairs (GJK/EPA/SAT)
BVH
Bounding Volume Hierarchy: tree of bounding volumes (AABBs) for broad phase
GJK
Gilbert-Johnson-Keerthi: convex distance/intersection algorithm
EPA
Expanding Polytope Algorithm: penetration depth/normal after GJK overlap
SAT
Separating Axis Theorem: convex (esp. box) intersection test
FK
Forward Kinematics: map joint values to link poses
Jacobian
maps joint velocities to end-effector/workspace velocities
PRM
Probabilistic Blueprint: multi-query sampling-based blueprint planner
Lazy PRM
PRM that defers edge collision checks until query time
RRT
Rapidly-exploring Random Tree: single-query incremental planner
RRT-Connect
bidirectional greedy-connect RRT
RRT
asymptotically optimal RRT via rewiring
Informed RRT
RRT* sampling restricted to an ellipsoidal informed set
Rewiring
reconnecting near nodes through a new node to reduce cost (RRT*)
Near-radius (r_n)
the connection radius γ·(log n/n)^(1/d) ensuring RRT* optimality
Dijkstra
uniform-cost shortest-path graph search
A
best-first search with an admissible heuristic
Admissible heuristic
never overestimates cost-to-go (necessary for A* optimality)
Weighted A
A* with inflated heuristic for bounded-suboptimal speed
D* Lite
incremental heuristic search repairing plans on edge-cost changes
Hybrid A
continuous-state A* with discretized closed set + analytic expansions
State lattice
a graph of precomputed feasible motion primitives
Motion primitive
a short feasible control/trajectory segment
Dubins path
shortest forward-only curvature-bounded path between two poses
Reeds-Shepp path
shortest curvature-bounded path allowing reversal
Shortcutting
path smoothing by replacing sub-paths with shorter valid connections
CHOMP
covariant Hamiltonian gradient trajectory optimization on a cost field
Time parameterization
assigning timestamps/velocities to a geometric path under dynamic limits
Trapezoidal profile
accel / cruise / decel velocity profile
S-curve profile
jerk-limited 7-phase velocity profile
TOPP
Time-Optimal Path Parameterization (phase-plane velocity optimization)
DWA
Dynamic Window Approach: reactive velocity-space local planner
Dynamic window
the set of reachable + admissible velocities over the next interval
Admissible velocity
one allowing a stop before the nearest obstacle
Replanning
recomputing/repairing a plan when the environment or state changes
