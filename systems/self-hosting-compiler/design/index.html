11. Core Schema & Types

  • SourceFile — struct SourceFile { file_id: FileId, canonical_path: PathBuf, content_hash: Blake3Hash, utf8_buffer: Arc<str>, line_index: LineIndex } — Ownership: Arc-shared, immutable post-construction · Mutation: none (P2) · Concurrency: safe multi-thread share, no interior mutability · Persistence: not persisted directly, feeds IncrementalKey · Serialization: not serialized whole · Compatibility: hash algorithm version-tagged (ADR-13).
  • Token — struct Token { kind: TokenKind, byte_span: Span, trivia_range: TriviaRange } — Ownership: owned by the token stream, copied by value (small, Copy) · Mutation: immutable once lexed · Concurrency: Send/Sync, freely shared · Persistence: not persisted · Serialization: deterministic binary encoding for parser benchmark corpora · Compatibility: TokenKind enum is additive-only across minor versions.
  • AstNodeId — struct AstNodeId(u64) — Ownership: value type, Copy · Mutation: immutable · Concurrency: trivially shareable · Persistence: keys incremental dependency edges (I8) · Serialization: deterministic binary encoding · Compatibility: allocation scheme fixed by I1, never renumbered across a reparse.
  • TypedNode — struct TypedNode { node_id: AstNodeId, inferred_type: TypeId, borrow_state: BorrowState, scope_id: ScopeId } — Ownership: owned by the type arena · Mutation: write-once during Phase 2 (§14), immutable after · Concurrency: read-shared post-sema · Persistence: cached under IncrementalKey · Serialization: postcard-encoded (ADR-03) · Compatibility: BorrowState variants are additive-only.
  • MirBody — struct MirBody { basic_blocks: Vec<BasicBlock>, locals: Vec<LocalDecl>, drops: Vec<DropPoint>, terminators: Vec<Terminator> } — Ownership: owned by the MIR arena, immutable post-verification (P2) · Mutation: mutable only during construction (§15), frozen after MirVerifier passes (I3) · Concurrency: read-shared across the optimizer's worker pool · Persistence: cached under IncrementalKey · Serialization: postcard-encoded · Compatibility: block/local indices are stable within one compilation, not across recompilation.
  • SsaFunction — struct SsaFunction { blocks: BlockGraph, phi_nodes: Vec<PhiNode>, dominance_tree: DomTree, value_table: ValueTable } — Ownership: owned by the SSA arena · Mutation: immutable post-verification (I4) · Concurrency: read-shared across optimization passes · Persistence: replay logs retain a serialized snapshot per pass (P11) · Serialization: postcard-encoded · Compatibility: ValueTable numbering is per-compilation only.
  • MachineFunction — struct MachineFunction { vregs: Vec<VirtualRegister>, instructions: Vec<MachineInst>, frame_layout: FrameLayout } — Ownership: owned by the backend, one per compilation unit · Mutation: mutable during instruction selection/allocation, frozen after BackendVerifier (I5) · Concurrency: one MachineFunction per worker, no cross-thread sharing needed · Persistence: not cached (regenerated per build) · Serialization: consumed directly by the object emitter · Compatibility: FrameLayout respects the ABI window in I6.
  • PackageManifest — struct PackageManifest { name: PackageName, version: SemVer, dependencies: DepGraph, features: FeatureFlags } — Ownership: owned by the package resolver · Mutation: immutable once parsed from Cargo.toml-equivalent · Concurrency: read-shared during resolution · Persistence: persisted in the lockfile (package-manager/integrity/lockfile.rs) · Serialization: TOML on disk, postcard in the resolver's internal graph · Compatibility: follows SemVer 2.0.0 (§5 RFCs).
  • IncrementalKey — struct IncrementalKey { compiler_version: VersionId, target_triple: TargetTriple, semantic_hash: Blake3Hash } — Ownership: value type, Copy-able composite key · Mutation: immutable · Concurrency: used as a hash-map key under the Incremental DB's lock ordering (I9) · Persistence: the primary key of every cache entry · Serialization: postcard-encoded, version-tagged (P9) · Compatibility: a compiler_version bump invalidates all keys deterministically (never silently reinterpreted).
  • Diagnostic — struct Diagnostic { category: DiagCategory, severity: Severity, primary_span: Span, secondary_spans: Vec<Span>, notes: Vec<Note>, suggestions: Vec<Suggestion> } — Ownership: owned by the diagnostics sink until flushed · Mutation: builder-mutable until emitted, immutable after (P8) · Concurrency: per-worker diagnostic buffers merged under I10's ordering rule at flush · Persistence: not persisted beyond the current build's log · Serialization: machine-readable JSON for tooling, human-readable render for the terminal · Compatibility: DiagCategory is additive-only across releases.
  • CacheEntry — struct CacheEntry { key: IncrementalKey, payload: Bytes, checksum: Crc32, schema_version: u16 } — Ownership: owned by the Incremental DB · Mutation: immutable once written; a mismatch triggers purge, never in-place patch (P14) · Concurrency: read-shared, write-once-per-key under I9's lock ordering · Persistence: on-disk content-addressed store · Serialization: postcard-encoded · Compatibility: schema_version mismatch is a hard fail-closed (I11).
  • WorkerTask — trait WorkerTask { fn phase(&self) -> PhaseId; fn run(self, ctx: &PassContext) -> Result<PhaseOutput, Diagnostic>; } — Ownership: moved into the worker pool queue, consumed on execution · Mutation: not applicable (behavior, not state) · Concurrency: Send, dispatched across the bounded pool (§4, ADR-06) · Persistence: not persisted · Serialization: not serialized · Compatibility: PhaseId enum is additive-only.
