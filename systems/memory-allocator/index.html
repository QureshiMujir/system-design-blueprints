One paragraph per box:

Application. Any C/C++/dynamically-linked process calling the standard malloc family; unaware of smalloc beneath it (P9). Its only contract is the C17 section 7.22.3 alignment and lifetime rules.

smalloc façade (src/smalloc.c). Validates arguments, classifies the request size (class_for, §11.5), and routes to the per-thread cache; the only layer every call passes through, so it stays branch-minimal (P5).

Per-thread cache (src/tcache.c). __thread-resident freelists per small class (I8); the fast path (pop/push, no lock, no syscall); owns the remote-free MPSC queue that receives cross-thread frees (I13, Phase 6).

Central arena (src/arena.c). One per CPU (bounded by SM_MAX_ARENAS, §4); holds the segregated freelists (Phase 3), the buddy page allocator (Phase 4), and the slab caches (Phase 5) behind one ticket lock (ADR-11); refills/drains the tcache in batches.

Segregated freelists (src/seglist.c). One explicit freelist per size class (ADR-08); O(1) placement, no best-fit search, bounded internal fragmentation (I2).

Buddy allocator (src/buddy.c). Page-grain backend, orders 12..21 (4 KiB–2 MiB); splits/coalesces power-of-two regions (ADR-09); the layer that talks to the page provider for growth/decommit.

Slab caches (src/slab.c). Bonwick-style two-level magazines (ADR-10) for the hottest kernel-shaped fixed-size objects; out-of-band descriptors (I3, P4).

Page provider (src/pages.c). The sole layer that issues syscalls (mmap/mprotect/madvise); platform shims abstract MADV_DONTNEED (Linux) vs MADV_FREE (macOS/FreeBSD) behind one call (ADR-21).

Side channels. hardening.c, trace.c, stats.c, radixmap.c cross-cut every layer without sitting on the hot path; radixmap.c is the exception — its lookup is on path for large allocations and cache misses (I1).

Allocation state machine (smalloc_alloc):

State Trigger Next state
REQUESTED smalloc_alloc(size, align) called CLASSIFIED
CLASSIFIED class_for(size) resolves a size class (ADR-08) CACHE_LOOKUP
CACHE_LOOKUP tcache bin non-empty SERVED (fast path, P5)
CACHE_LOOKUP tcache bin empty ARENA_REFILL
ARENA_REFILL arena bin non-empty CACHE_FILL → SERVED
ARENA_REFILL arena bin empty BUDDY_SPLIT or SLAB_GROW
BUDDY_SPLIT / SLAB_GROW region available CACHE_FILL → SERVED
BUDDY_SPLIT / SLAB_GROW no region available PAGE_PROVIDER_MMAP
PAGE_PROVIDER_MMAP mmap succeeds CACHE_FILL → SERVED
PAGE_PROVIDER_MMAP mmap fails (ENOMEM) FAILED (returns NULL, errno=ENOMEM)

Free state machine (smalloc_free):

State Trigger Next state
FREED smalloc_free(ptr) called HARDENING_CHECK
HARDENING_CHECK redzone/canary intact, not in DFD table OWNER_CHECK
HARDENING_CHECK violation detected ABORT (I5, I6)
OWNER_CHECK freeing thread owns the arena CACHE_PUSH
OWNER_CHECK cross-thread free REMOTE_ENQUEUE (I13)
CACHE_PUSH tcache bin below limit DONE
CACHE_PUSH tcache bin at limit CACHE_DRAIN → BIN_PUSH
BIN_PUSH (arena bin) buddy-backed and buddy neighbor free COALESCE → DECOMMIT_CHECK
DECOMMIT_CHECK region fully free madvise/MADV_DONTNEED

Worked example — malloc(40) trace (Phase 15+ steady state): class_for(40) rounds up to the 48 B class (ADR-08) → tcache bin [48] checked → empty (cold cache) → ARENA_REFILL acquires the arena ticket lock (ADR-11) → arena bin [48] empty → BUDDY_SPLIT carves one 4 KiB page from an order-12 buddy block into 85 chunks of 48 B → 15 chunks fill the tcache (I8), the rest populate the arena bin → lock released → first chunk served to the caller. Total path length: 1 TLS lookup + 1 lock acquire/ release + 1 buddy split — amortized to O(1/85) per steady-state call.

Malformed-input examples: smalloc_free(garbage_ptr) — radix-map lookup misses → in a hardened build, abort() with SM_E_FAULT (I1); in glibc-compat mode, silently ignored per historical free(invalid) UB tolerance (documented divergence, Phase 22). smalloc_realloc(ptr_not_from_us, n) — undefined per C17 section 7.22.3.5; detected only when the sm_block_hdr_t magic (§11.4) fails to match, otherwise UB is inherited as-is.

Failure-path example — OOM on arena refill: BUDDY_SPLIT requests a new 2 MiB region from pages.c → mmap returns MAP_FAILED/ENOMEM → the failure propagates as NULL through ARENA_REFILL → CACHE_LOOKUP → the façade sets errno=ENOMEM and returns NULL to the caller; the tcache bin for that class remains empty; the next call to that class retries the same path (no cached failure state, per I4's accounting identity staying valid even on a failed refill).

Design principles (§6)

  • Correctness above throughput (P1). Every commit passes the conformance suite under ASan/MSan/TSan/UBSan before merge. Tradeoff: slower CI. Operational: sanitizer builds gated in ci.yml (ADR-19). Violate it and silent heap corruption reaches production.
  • Layered fallback (P2). The hot path is the tcache; a miss falls to segregated lists, then buddy, then mmap. Tradeoff: more paths to test. Operational: each layer is independently benchmarkable and shippable. Violate it and a monolithic allocator cannot ship a partial phase.
  • Bounded, documented metadata (P3). Every allocation's overhead is a known, tabled number (§4). Tradeoff: less per-object flexibility. Operational: capacity planning is exact. Violate it and RSS surprises reach production.
  • Out-of-band metadata where possible (P4). Small-class metadata lives in the radix map (I3), never adjacent to user data. Tradeoff: an extra indirection (cache miss) on the map lookup. Operational: a user-buffer overrun cannot corrupt allocator state. Violate it and the classic overflow-corrupts-header bug class returns.
  • Constant-time fast path (P5). malloc(≤4096) never takes a lock or a syscall on a cache hit. Tradeoff: a cache miss falls to a slower, lock-guarded path. Operational: p99 tail latency is bounded (§4). Violate it and a hot loop that occasionally blocks on a syscall destroys tail-latency SLOs.
  • Address space is cheap; memory is not (P6). Reserve large VA ranges (16 GiB) via MAP_NORESERVE, commit lazily. Tradeoff: relies on sane overcommit. Operational: madvise/DONTNEED returns RSS aggressively. Violate it and misconfigured hosts reserve swap for the full VA range (Phase 14 pitfall).
  • Hardening is opt-in, always available (P7). A runtime flag reaches every hardening feature even in a release build. Tradeoff: a flag check on the fast path (compiled dead when off). Operational: an incident can enable redzones without a rebuild (Phase 20). Violate it and an incident forces a slow debug rebuild.
  • Reproducible builds (P8). Pinned toolchain, deterministic flags, CI verifies bit-identical artifacts (ADR-02, ADR-20). Tradeoff: slower contributor onboarding. Operational: security audits trust the artifact. Violate it and a supply-chain trust gap opens.
  • Drop-in ABI compatibility (P9). Export the right symbol versions (GLIBC_2.2.5, GLIBC_2.34) so LD_PRELOAD "just works" (Phase 22, ADR-04). Tradeoff: must track glibc's evolving surface. Operational: the version script is maintained per release. Violate it and a silent symbol mismatch crashes at load time.
  • Telemetry that does not lie (P10). Every cross-thread counter is atomic; reading stats never blocks an allocation (I9). Tradeoff: an atomic RMW cost on increment. Operational: dashboards are trustworthy under load. Violate it and racy counters produce false confidence.
  • Differential correctness over unit correctness (P11). The same operation sequence is replayed against glibc/jemalloc/smalloc and outputs compared (ADR-19, Phase 24). Tradeoff: needs multiple allocators linked into one harness. Operational: catches divergence unit tests miss. Violate it and allocator-specific bugs escape testing.
  • Fail loud, never silently corrupt (P12). A detected invariant violation (double-free, redzone mismatch) calls abort() with a structured diagnostic, never limps on (I5, I6). Tradeoff: a false-positive detector crashes a healthy process. Operational: postmortem tooling parses the abort diagnostic. Violate it and undetected corruption propagates to unrelated allocations.
  • Size-class geometry bounds waste, not fit search (P13). Segregated lists eliminate best-fit search, trading a small fixed step-waste for O(1) placement (ADR-08, Phase 15). Tradeoff: cannot reach zero internal fragmentation. Operational: the class table is the single source of truth for the waste bound (§4). Violate it and an ad-hoc "round to next power of two" scheme wastes far more (§"Back-of-Envelope Capacity Model").
