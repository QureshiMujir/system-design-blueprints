3.2 Subsystem Descriptions

lp-parse: Accepts MPS (fixed-width + free-format) and LP (CPLEX-style) files from disk or Read trait. Produces LpProblem with sparse objective, CSC constraint matrix, RHS vector, relation vector, and per-variable Bound. No solving logic. Trust boundary: untrusted file input; validates dimensions and bound sanity before emitting. Outputs LpProblem into the presolve pipeline or directly into lp-model for CLI passthrough.

lp-presolve: Receives LpProblem; applies passes: remove empty rows/cols, substitute singleton rows, tighten bounds from implied bounds, drop redundant constraints, fix variables pinned by bounds. Applies geometric or Curtis-Reid scaling to the matrix to improve condition number. Records an ordered postsolve stack of inverse transformations. Outputs a reduced LpProblem + PresolveSolution (for postsolve mapping). Invariant I9 is enforced here: the presolved optimum must equal the original optimum.

lp-model: Converts LpProblem to StandardForm: negates c if Maximize, adds slack columns for Le constraints, surplus+artificial for Ge, artificial-only for Eq, handles free variables by split or bounded treatment, shifts lower bounds to zero. Records var_map: Vec<VarId> from each standard-form column back to the original problem. Outputs StandardForm consumed by lp-simplex. Invariant I10 is enforced here.

lp-simplex: Top-level primal driver. Phase I builds an auxiliary problem minimizing the sum of artificials; delegates to the pivot engine until residual = 0 (feasible) or > 0 (infeasible, emit Certificate::DualRay). Phase II iterates: select entering variable via lp-pricing, compute RatioTestResult via lp-tableau or lp-revised, pivot, check optimality. Detects unboundedness (no leaving variable) and emits Certificate::PrimalRay. Returns Solution.

lp-pricing: Stateless pivot-rule module. Dantzig selects most-negative reduced cost; Bland selects smallest index with negative reduced cost (anti-cycling guarantee); Devex maintains approximate steepest-edge weights for faster convergence. Selects the entering variable column given a reduced-cost slice. Auto-switches to Bland after a stall threshold is detected (P3, I7).

lp-bounds: Bounded-variable ratio-test logic. Given entering column direction, computes RatioTestResult accounting for nonbasic variables at lower or upper bounds and the possibility of a bound flip (entering hits its opposite bound before any basic variable hits a bound). Reduces effective problem size by keeping general bounds native rather than adding rows.

lp-tableau: Dense (m × n) f64 tableau. Reference engine only (P4). Stores current basis columns explicitly. pivot(entering, leaving) normalizes the pivot row then does full Gaussian elimination on all other rows + the objective row. Used for differential testing against lp-revised. Never used for large problems. No persistence.

lp-revised: Production simplex pivot path. Does not store the full tableau. On each iteration: BTRAN (y = c_B B^{-1}) to get dual variables; price reduced costs r_j = c_j - y a_j; FTRAN (d = B^{-1} a_j) for the entering column direction; hand d to lp-bounds for ratio test; update basis. Delegates factorization and solves to lp-lu. Memory O(nnz) not O(m × n).

lp-lu: Sparse LU factorization of the basis matrix B with partial pivoting for numerical stability. Supports FTRAN (forward solve Bx = v) and BTRAN (backward solve B^T y = w) as the core linear-algebra primitives. On each pivot, applies a Forrest-Tomlin (or Bartels-Golub) rank-1 eta-vector update instead of refactoring from scratch. Monitors fill factor and estimated condition; triggers full refactorization when either exceeds threshold. This is the numerical heart of the solver; I1, I2, I3, P2 are all enforced here.

lp-dual: Dual simplex driver. Assumes dual-feasible starting basis (all reduced costs optimal-sign). Selects leaving variable (most-infeasible basic row); computes dual direction; selects entering via bounded dual ratio test to maintain dual feasibility. Ideal for warm-start after RHS or bound perturbation (P8). Accepts a saved Basis object, bypasses Phase I entirely.

lp-sensitivity: Post-optimal module. Given the optimal Basis and Solution, computes: cost-coefficient ranging (allowable increase/decrease in each c_j before the basis changes), RHS ranging (allowable change in each b_i), shadow prices (the dual values y), and reduced-cost ranges. Returns Sensitivity. No re-solving required — all computed from B^{-1} already available in lp-lu.

lp-cli: Binary crate. Subcommands: solve (parse → presolve → model → simplex → postsolve → print solution + certificate), sensitivity (solve + sensitivity analysis), convert (MPS ↔ LP format), check (read a claimed solution, verify KKT conditions, print pass/fail). Reads solver options from CLI flags (tolerance, pivot rule, iteration limit, warm-start basis file). Orchestrates the full pipeline per P7.

8.2 Variable Status State Machine

Each structural variable (and later each slack/artificial) carries a VarStatus that evolves through the simplex iterations.

              add to basis                  pivot out (ratio test)
  ┌─────────────────────────────────────────────────────────────────┐
  │   ┌──────────────┐   enter basis   ┌─────────┐                 │
  │   │NonbasicLower │ ─────────────▶  │  Basic  │                 │
  │   └──────────────┘ ◀─────────────  └─────────┘ ──▶ NonbasicUpper
  │         ▲           leave, at ub       │               │
  │         │                              │  leave, at lb │
  │         └──────────────────────────────┘               │
  │                                                         │
  │   ┌──────────────┐                                     │
  │   │  Free (super │ ◀── bound flip during bounded ratio test
  │   │  nonbasic)   │
  └───┴──────────────┘

State-transition table:

From Trigger To Guard
NonbasicLower entering variable selected by pricing Basic reduced cost < -eps_opt (minimise)
NonbasicUpper entering variable selected by pricing Basic reduced cost > +eps_opt
Basic ratio test selects this as leaving at lower bound NonbasicLower x_B[i] - theta * a_ij = lb_i
Basic ratio test selects this as leaving at upper bound NonbasicUpper x_B[i] - theta * a_ij = ub_i
NonbasicLower entering column hits its upper bound before any basic var NonbasicUpper bound flip: theta = ub_j - lb_j
NonbasicUpper entering column hits its lower bound before any basic var NonbasicLower bound flip (decreasing direction)
NonbasicLower/Upper variable fixed by presolve Fixed (removed) lb == ub within eps_feas

8.3 Solver Phase State Machine

  [Parse / Build]
        │
        ▼
  [Presolve + Scale]
        │ problem trivially infeasible? ──▶ Status::Infeasible + DualRay
        ▼
  [Standard Form Conversion]
        │
        ▼
  [Phase I — minimise sum(artificials)]
        │ optimal value > eps_feas ──────▶ Status::Infeasible + DualRay
        │ optimal value <= eps_feas
        ▼
  [Drop artificials; construct primal-feasible basis]
        │
        ▼
  [Phase II — primal or revised simplex loop]
        │ all reduced costs >= -eps_opt ─▶ Status::Optimal ──▶ KKT check
        │ no leaving var on unbounded col ▶ Status::Unbounded + PrimalRay
        │ iter >= iter_limit ─────────────▶ Status::IterationLimit
        │ severe numerical failure ───────▶ Status::Numerical → refactorize / retry
        ▼
  [Postsolve + Unscale]
        │
        ▼
  [Sensitivity Analysis (optional)]
        │
        ▼
  [Return Solution + Certificate]

8.4 LpProblem Memory Layout

LpProblem stores the constraint matrix in column-major CSC (Compressed Sparse Column):

  SparseMatrix {
    nrows : usize,        // m — number of constraints
    ncols : usize,        // n_struct — number of structural vars
    values  : Vec<f64>,   // non-zeros, column order
    row_ind : Vec<usize>, // row index per non-zero
    col_ptr : Vec<usize>, // col_ptr[j]..col_ptr[j+1] is column j's range; len = ncols+1
  }

Column j occupies values[col_ptr[j]..col_ptr[j+1]]. Access row i of column j requires a linear scan of row_ind[col_ptr[j]..col_ptr[j+1]]; this is acceptable because column operations dominate in simplex.

8.5 StandardForm Layout

After lp-model::to_standard_form:

  StandardForm {
    A_std      : SparseMatrix,   // m x (n_struct + n_slack + n_artificial)
    b          : Vec<f64>,       // m — RHS (always >= 0 after row sign flip)
    c          : Vec<f64>,       // n_total — cost (minimise convention)
    n_struct   : usize,
    n_slack    : usize,
    n_artificial : usize,
    var_map    : Vec<OrigVar>,   // standard index -> original VarId + sense (slack/artificial tag)
    row_signs  : Vec<i8>,        // ±1: track which rows were negated for b >= 0
  }

Standard-form conversion rules (per constraint type):

Relation Action Added columns
Le (<=) add slack s >= 0 1 slack
Ge (>=) subtract surplus s >= 0, add artificial a >= 0 1 surplus + 1 artificial
Eq (=) add artificial a >= 0 1 artificial

For Sense::Maximize: negate every entry of c before solving; negate the reported objective at postsolve.

Free variable x (lb = -inf, ub = +inf): split into x = x+ - x-, both >= 0; var_map records the split.

Bounded variable with finite lb: substitute x' = x - lb, so x' >= 0 and ub' = ub - lb.

8.6 Basis Representation and LU Layout

  Basis {
    basic     : Vec<VarId>,         // basic[i] = variable occupying row i; len = m
    status    : Vec<VarStatus>,     // status[j] for every variable j in n_total
    factor    : LuFactorization,
    n_updates : usize,              // eta vectors accumulated since last refactorization
  }

  LuFactorization {
    l_eta     : Vec<EtaVector>,     // spike columns from pivots (Forrest-Tomlin)
    u         : SparseMatrix,       // upper triangular factor (row-sparse)
    l_dense   : Option<SparseMatrix>, // lower triangular factor (col-sparse), rebuilt on refact
    row_perm  : Vec<usize>,         // P: row permutation applied before factorization
    col_perm  : Vec<usize>,         // Q: column permutation
    n_updates : usize,
    condition_est : f64,            // cheap 1-norm condition estimate; triggers refact when large
  }

FTRAN (forward solve B x = r): apply L^-1 (eta columns left-to-right), then U^-1 (back-substitution). BTRAN (backward solve B^T y = c_B): apply U^-T (forward substitution), then L^-T (eta columns right-to-left).

Refactorization trigger: n_updates >= refact_interval (default 50) OR condition_est > cond_threshold (default 1e12).

8.7 Pivot Sequence — Worked Example (3-variable LP)

Problem:

  maximise   5x1 + 4x2 + 3x3
  subject to
    6x1 + 4x2 + 2x3 <= 240   [row 0]
    3x1 + 2x2 + 5x3 <= 270   [row 1]
    5x1 + 6x2 + 5x3 <= 420   [row 2]
    x1, x2, x3 >= 0

Converted (minimise -5x1 - 4x2 - 3x3; add slacks s4, s5, s6):

Initial tableau (rows = constraints; basis = {s4,s5,s6}; obj row last):

     x1   x2   x3  | s4  s5  s6 | RHS
  [  6    4    2   |  1   0   0 | 240 ]  row0
  [  3    2    5   |  0   1   0 | 270 ]  row1
  [  5    6    5   |  0   0   1 | 420 ]  row2
  [ -5   -4   -3   |  0   0   0 |   0 ]  obj

Iteration 1 — Dantzig entering: x1 (most negative rc = -5, col 0). Ratio test: 240/6=40, 270/3=90, 420/5=84 → min=40, row0 leaves (s4 leaves). Pivot on (row0, col0); x1 enters basis.

Post-pivot tableau (abbreviated):

     x1   x2    x3  | s4     s5  s6  | RHS
  [  1   2/3  1/3  | 1/6     0   0  |  40 ]  row0 (x1 basic)
  [  0   0    4   | -1/2    1   0  | 150 ]  row1
  [  0  10/3  10/3 | -5/6    0   1  | 220 ]  row2
  [  0  -2/3  -4/3 |  5/6    0   0  | 200 ]  obj

Iteration 2 — entering: x3 (rc = -4/3). Ratio test: 40/(1/3)=120, 150/4=37.5, 220/(10/3)=66 → row1 leaves (s5). Objective after pivot: 200 + (4/3)*(37.5) = 250.

Iteration 3 — entering: x2 (rc remains negative). After pivot → all reduced costs >= 0; optimal.

Final: x1=30, x2=0, x3=37.5, objective=300. KKT check: primal feasible + dual feasible + complementary slackness verified within eps_opt=1e-8.

8.8 Malformed / Failure-Path Example

Input: constraints specify A x >= b with b > 0, but after Phase I the sum-of-artificials optimum is 3.2e-5 > eps_feas (1e-8).

Outcome path:

  1. Phase I terminates with objective 3.2e-5.
  2. Solver checks: min-artificial-objective > eps_feas → primal infeasible.
  3. Extract dual ray d from Phase I dual values: d satisfies A^T d <= 0, b^T d > 0 (Farkas certificate).
  4. Status::Infeasible, Certificate::DualRay(d) emitted.
  5. Postsolve maps d back through presolve undo-stack (re-scaling, restored fixed vars).
  6. CLI prints: INFEASIBLE — dual ray [d0, d1, ...], verifiable by lp-cli check --certificate.

Edge case — Phase I optimum exactly zero but artificials still basic: occurs when degenerate rows keep an artificial at value 0. Resolution: pivot artificials out of the basis using a non-artificial column (pivot-on-zero procedure); if no such column exists the row is redundant and dropped.

8.9 Sensitivity Analysis Data Model

Post-optimal sensitivity requires the optimal basis B and dual prices y = c_B B^-1.

Range type Definition Formula
obj range for x_j basic interval [lb_j, ub_j] for c_j keeping B optimal delta s.t. all rc_k + delta*(B^-1 a_j)_k remain dual-feasible
obj range for x_j nonbasic keep rc_j >= 0 (or <= 0); simple scalar interval c_j - rc_j ± epsilon
RHS range for row i interval [lb_i, ub_i] for b_i keeping B primal-feasible theta s.t. x_B + theta * B^-1 e_i >= 0 per bound
Shadow price (row i) y_i = (c_B B^-1)_i available from BTRAN after solve
Reduced cost x_j nonbasic rc_j = c_j - y^T a_j available directly

Sensitivity struct stores all ranges and dual prices; computed in one pass using BTRAN results already available from Phase II.

8.10 Serialisation / Wire Formats

MPS format (fixed-field, 10-column):

  EBNF:
  mps-file   ::= NAME-section ROWS-section COLS-section RHS-section
                 [BOUNDS-section] [RANGES-section] ENDATA
  NAME-section ::= "NAME" ws name NL
  ROWS-section ::= "ROWS" NL (row-line)+
  row-line     ::= ws sense ws row-name NL
  sense        ::= "N" | "L" | "G" | "E"
  COLS-section ::= "COLUMNS" NL (col-entry)+
  col-entry    ::= ws col-name ws row-name ws value [ws row-name ws value] NL
  RHS-section  ::= "RHS" NL (rhs-entry)+
  BOUNDS-section ::= "BOUNDS" NL (bound-entry)+
  bound-entry  ::= ws btype ws bnd-name ws col-name [ws value] NL
  btype        ::= "UP"|"LO"|"FX"|"FR"|"MI"|"BV"|"LI"|"UI"|"PL"

LP format (free-form, CPLEX-style):

  lp-file ::= [obj-section] constraints-section [bounds-section] [generals-section] END
  obj-section ::= ("Minimize"|"Maximize") NL obj-name ":" linear-expr NL
  linear-expr ::= [sign] term (sign term)*
  term        ::= [coef] var-name
  sign        ::= "+" | "-"

Solution output (JSON, optional):

  {
    "status": "Optimal",
    "objective": 300.0,
    "variables": { "x1": 30.0, "x3": 37.5 },
    "duals": { "row0": 0.833, "row1": 0.667 },
    "certificate": { "type": "KktOptimal" }
  }

Basis warm-start format (binary, little-endian):

  [4B magic: 0x4C505342] [4B version] [4B m] [4B n_total]
  [m x 4B: basic[] VarId values]
  [n_total x 1B: VarStatus enum byte]

8.11 Tolerance Schema

All float comparisons use named constants; comparing to exact zero is forbidden (P6).

Constant Default Used in
EPS_FEAS 1e-8 primal feasibility check, Phase I termination
EPS_OPT 1e-8 optimality / dual feasibility (reduced cost sign)
EPS_PIVOT 1e-7 pivot element too small → skip column or refactorize
EPS_RATIO 1e-9 ratio test tie-breaking
COND_THRESHOLD 1e12 condition estimate → force refactorization
REFACT_INTERVAL 50 max eta updates before scheduled refactorization
ITER_LIMIT 1_000_000 hard iteration cap → Status::IterationLimit

8.12 Presolve Undo Stack

Each presolve transformation pushes a typed record:

Record Fields Postsolve action
RemoveEmptyRow(i) row index no-op (dual = 0)
FixVariable(j, val) VarId, fixed value set x[j] = val; compute dual contribution
SubstituteSingleton(j, i, coef) VarId, row, coefficient x[j] = (b[i] - sum_{k!=j} a_ik x_k) / coef
TightenBound(j, old_lb, old_ub) VarId, bounds restore bounds; verify optimum unchanged
RemoveRedundantRow(i, multiplier) row, Farkas multiplier compute dual[i] = multiplier * base_dual
Scale(row_scales, col_scales) Vec<f64>, Vec<f64> x[j] /= col_scales[j]; y[i] /= row_scales[i]

Postsolve processes the stack in reverse order (LIFO). Invariant I9 requires postsolve to produce a solution feasible to the original problem within EPS_FEAS.

8.13 Edge Cases

Case Detection Handling
All-zero row during presolve remove if b[i]==0; else infeasible
Duplicate rows hash comparison in presolve keep one; set dual of removed = 0
Unbounded variable (no finite bounds) var_map free-split split x+/x- in standard form
Artificial remains basic at 0 Phase I termination pivot out using degenerate pivot; if impossible, row is dependent
Basis becomes singular mid-solve pivot element < EPS_PIVOT refactorize; if still singular, mark Status::Numerical
Cycling detected (stall counter) same objective N consecutive iters switch pricing to Bland (P3 / I7)
Very dense column nnz > density_threshold deprioritize in Devex pricing to limit fill
b[i] < 0 after row selection detected in to_standard_form multiply row by -1; record in row_signs
Free variable with artificial Ge/Eq row for free var split var, add artificial as usual
Infeasible bounds (lb > ub) validation in builder return error before solving

Design principles (§6)

  • Primal feasibility: ‖Ax - b‖∞ ≤ FEAS_TOL and lⱼ - FEAS_TOL ≤ xⱼ ≤ uⱼ + FEAS_TOL for all j
  • Dual feasibility: rcⱼ ≥ -OPT_TOL for NonbasicLower, rcⱼ ≤ OPT_TOL for NonbasicUpper, |rcⱼ| ≤ OPT_TOL for basic
  • Complementary slackness: |(xⱼ - lⱼ) · rcⱼ| ≤ OPT_TOL · max(1, |xⱼ|) for all j → lp-presolve::reduce() → (LpProblem reduced, PostsolveStack) → lp-model::to_standard_form() → StandardForm → lp-simplex / lp-revised → Solution (reduced space) → lp-presolve::postsolve() → Solution (original space)
