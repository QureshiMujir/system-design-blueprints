4.2 Tolerance Hierarchy

pivot_tol (1e-4)  <  feasibility_tol (1e-7)  <  optimality_tol (1e-7)
  • pivot_tol: minimum absolute pivot element; reject smaller pivots as numerically unsafe (I1).
  • feasibility_tol: maximum violation of Ax = b or bound constraint at a basic solution (I2, I3).
  • optimality_tol: maximum negative reduced cost accepted as optimal (I4).
  • Comparing any f64 to exact 0.0 against these tolerances is forbidden (P6).

Back-of-Envelope Capacity Model

All inputs are taken from §4 (System Constraints); arithmetic is shown.

  1. Dense-tableau memory. 8 × m × n × 1.2. For m=n=1000 → 8e6 × 1.2 = 9.6 MB (matches §4).
  2. Revised-basis memory. 32 × nnz(B), nnz(B) ≈ 5–10× m. m=10K → nnz ≈ 50K–100K → 32 × 1e5 = 3.2 MB.
  3. LU fill ceiling. fill ≤ 5 × nnz(B) before refactor (§4); at nnz=1e5 → ≤ 5e5 nonzeros in the factors.
  4. Refactorization cadence. every 100–200 pivots (§4); a solve of P pivots → ≈ P/150 refactorizations.
  5. Dense pivot throughput. ≥ 50K pivots/s on 500×500 (§4); one pivot updates ≈ 500×500 = 250K f64 ops → 50K × 250K = 1.25e10 flops/s ≈ 12.5 GFLOP/s (plausible single-core f64).
  6. Revised pivot throughput. ≥ 200K/s on a 1000-constraint basis (§4); FTRAN+BTRAN each O(nnz(B)+nnz(eta)) ≈ few×1000 → 200K × ~5000 = 1e9 ops/s.
  7. Small LP wall time. ≤ 200 vars, pivots ≈ 2–3× m ≈ 400–600; at 50K/s dense ≈ ~10 ms → within p99 ≤ 20 ms (§4).
  8. Medium LP. 1000 vars, revised path ≈ 2000–3000 pivots at 200K/s ≈ 10–15 ms compute + LU refactor → fits p50 ≤ 500 ms (§4) with conditioning slack.
  9. Iteration ceiling. default 100K (§4) or 10 × m × n; for m=n=1000 → 1e7 hard ceiling — far above the ~2–3m expected, a safety net.
  10. Warm-start. ≤ 10% of cold for ±5% RHS perturbation (§4); dual simplex resumes from the old optimal basis → a few dual pivots vs a full Phase I.
  11. Netlib conformance. 95 instances, objective within 1e-6 relative (§4); up to ≈ 3000 constraints, all ≤ 60 s.
  12. Verification overhead. KKT ≤ 5%, sensitivity ≤ 10% of solve (§4); both reuse B⁻¹ already in lp-lu → no extra factorization.
