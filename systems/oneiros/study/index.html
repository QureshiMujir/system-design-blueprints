30. Mental Models & First Principles

  1. MM1 — A scene is a state machine; the scheduler is its clock. Predicts that buffer-ahead invariants generalize from any clock-driven system. Bug class without it: treating scene dispatch as fire-and-forget rather than deadline-driven, producing visible stutter. Applied in §17.
  2. MM2 — The Composer is a single-writer log, not a database. Predicts that append-only world deltas compose safely, and that concurrent writers are a category error, not a race to optimize away. Bug class without it: attempting multi-writer world edits, causing identity collapse. Applied in §13, §14, I1/I2.
  3. MM3 — Safety classification is a trust boundary, not a feature. Predicts it must sit on the output path of every adapter, never bypassable by a fast-path optimization. Bug class without it: an optimization that skips classification "just this once," producing FM-4. Applied in §18.
  4. MM4 — Cost is a scheduling input, not a billing afterthought. Predicts routing decisions must weigh ¢/unit at dispatch time, not just measure it after the fact. Bug class without it: unbounded cost growth invisible until the invoice arrives. Applied in §19, I13.
  5. MM5 — Cancellation is a contract, not a courtesy. Predicts every adapter must treat cancel() as a first-class API symmetric with render(). Bug class without it: skip-ahead behavior silently bankrupting the cost model. Applied in §17, §19, I11.
  6. MM6 — A persistent world is an event-sourced log with periodic snapshots, not a mutable row. Predicts replay-from-log always recovers correctness; snapshots are an optimization, not a source of truth. Bug class without it: trusting a stale or corrupted snapshot as ground truth after a crash. Applied in §13.
  7. MM7 — Provider heterogeneity is data, not an exception. Predicts the capability registry (latency/cost/health) must be queried at every dispatch, not hardcoded per adapter. Bug class without it: brittle single-provider assumptions that break the moment one provider changes pricing. Applied in §15, §19.
  8. MM8 — Degradation must be modality-local, not session-global. Predicts a failing video adapter should never take down text/image/music in the same scene. Bug class without it: cascading failure from what should be an isolated fault. Applied in §21, P13.
  9. MM9 — An estimate without a reconciliation path is a liability, not a metric. Predicts that any real-time telemetry derived from external billing (cost) or external classification (safety) needs a scheduled ground-truth check. Bug class without it: silent drift between believed and actual state, discovered only when it becomes a financial or compliance surprise. Applied in §19, §22 (T12), I14, P15.
  10. MM10 — A branded identifier is cheaper than the bug it prevents. Predicts that compile-time type distinctions between superficially identical strings (WorldId vs. SceneId) pay for themselves the first time a refactor would otherwise silently swap them. Bug class without it: cross-entity confusion bugs that only surface as data corruption in production, never a compiler error. Applied in §11.8, P14.

Reference Implementations

  • LiveKit (github.com/livekit/livekit, pkg/sfu). Lesson: server-side track/quality selection under bandwidth constraint. Pitfall: do not copy WebRTC/SDP negotiation — Oneiros streams over WebSocket + HLS, not WebRTC. Applied in §17.
  • Temporal (github.com/temporalio/temporal, service/history). Lesson: event-sourced state machines for long-running sessions. Pitfall: full workflow-determinism does not fit — Composer calls are inherently stochastic; replay is delta-based, not re-execution-based. Applied in §13, §14.
  • LangGraph (github.com/langchain-ai/langgraph, libs/langgraph/langgraph/graph). Lesson: explicit state-graph planning beats implicit prompt-chaining. Pitfall: its cheap-re-execution checkpoint model doesn't fit — Composer calls are GPU-billed. Applied in §14.
  • Envoy (github.com/envoyproxy/envoy, source/common/upstream). Lesson: outlier detection driving health/circuit-breaking. Pitfall: Envoy's L7 config surface is far larger than the capability registry needs. Applied in §15, §19.
  • Kafka (github.com/apache/kafka, core/src/main/scala/kafka/log). Lesson: segment/retention model applied to the scene-completion event log. Pitfall: do not adopt full log-compaction semantics — PWS deltas are already normalized relationally. Applied in §11, §13.
  • Netflix Conductor (github.com/Netflix/conductor). Lesson: task-queue worker model applied to Scene Scheduler dispatch. Pitfall: Conductor assumes idempotent, cheap-to-retry workers; GPU-billed adapter calls are not. Applied in §17.

Glossary (§36) · 53 terms · site-wide glossary

Adapter
modality-specific renderer implementing ModalityAdapter (§11.4–11.5).
Arousal
Mood axis, −1 (calming) to +1 (intense); capped at 0 in sleep mode (I4).
Buffer-ahead
the invariant (I7) that ≥1 scene is fully rendered ahead of playback.
Bulkhead
resource-isolation pattern preventing one failure from exhausting shared capacity (§19).
¢/SH
cost per stream-hour, the defining cost metric (§4, I13).
Cache promotion
moving a classified asset into the CDN edge cache (§20).
Cancellation
explicit reclaim of an in-flight adapter call's cost (I11).
Capability registry
in-memory index of adapter capabilities by modality (§11.4, §15).
Circuit breaker
a provider-health pattern isolating a failing dependency (§19).
Classifier Ensemble
the dual (general + sleep-mode) safety-classification pipeline (§18).
Composer
the LLM-driven scene planner and sole PWS writer (§11.5, P1).
Conformance suite
the per-adapter release gate covering latency, cost, mood-fidelity, safety, cancellation (§15, §26).
Content profile
per-user policy bounding Composer planning and classifier admission.
Cosmology
Composer-authored world-physics/history prose (§11.1).
Edge Asset Cache
CDN-level cache of classified assets (§20).
Envelope encryption
a per-user data key wrapped by a KMS master key (I10, RFC 7516).
GPU Orchestration Pool
multi-provider inference-routing subsystem (§19).
Hedged request
a redundant request issued to cut tail latency, cancelled on first response (§19).
Modality
a sensory channel: text, image, music, video, voice (voice deferred).
Modality Adapter Bus
the collection of pluggable adapters behind one interface (§3, §11.4–11.5).
Modality fallback
degrading a scene to a cheaper modality rather than failing it (P13).
Mood
the (arousal, valence, descriptors, biometrics?) tuple conditioning adapter output (§11.4).
PWS
Persistent World Store, per-user encrypted durable state (§13).
Provenance
per-asset record of prompt hash, seed, model version (I8).
Scene
the atomic streaming unit, 30–90 s (§8.3, §11.2).
Scene Scheduler
dispatches adapter calls under budget, enforces I7 (§17).
Schema version
the semver tag on every persisted record, non-decreasing (I6).
Seed
256-char re-hydration payload for a world (type defined §11.3, feature deferred).
Session orchestrator
enforces the per-world write lock (I1) and cross-user scoping (I12).
Sim-harness
the deterministic invariant simulator gating Composer/Scheduler/PWS changes (§12, §26).
Sleep mode
a Stream mode with the strictest tone envelope (I4, P5).
Snapshot
a periodic (every 50 scenes) durable checkpoint of world state (§13).
Stitching layer
the Phase 9 technique hiding video clip boundaries via last-frame + seed conditioning (§21).
Stream
a viewer session, a sequence of scenes (§11.3).
Streaming Runtime
the latency-budgeted scene-scheduling subsystem (§3, §17).
Tone envelope
the per-world arousal/valence hard rails (§11.1).
TTFF
time-to-first-frame, prompt submit to first scene byte (§4, M1).
Valence
Mood axis, −1 (dark) to +1 (joyful); floored at −0.2 in sleep mode (I4).
Vibe
viewer-supplied text/voice input biasing scene planning (§11.2).
Watermark
the streaming-systems accounting concept underlying buffer-ahead tracking (§17).
World
a persistent per-user context: cosmology, characters, threads, locations (§11.1).
World delta
an incremental change to world state emitted after a scene (§11.5).
WorldId
the stable ULID identifying a World forever (§11.1).
Branded type
a compile-time-only type wrapper (e.g. WorldId vs. plain string) preventing cross-identifier confusion with zero runtime cost (§11.8).
Canary analysis
automated comparison of key SLIs between a 1%-traffic canary and the stable cohort before a full rollout (§24).
Error budget
the allowed cumulative SLO-violation time within a measurement window (e.g. 3.6 h/month at 99.5% availability, §24).
RTO
Recovery Time Objective, the maximum acceptable time to restore service after a failure (§4, §13.9).
RPO
Recovery Point Objective, the maximum acceptable data loss window measured in time (§4, §13).
SBOM
Software Bill of Materials, the enumerated dependency manifest generated per release (§27).
Reconciliation
the batch process comparing real-time cost/audit estimates against an authoritative source (provider invoice, storage listing) after the fact (§19, T12).
Sticky routing
a provider-routing policy that holds a choice stable across a rolling window rather than re-deciding per call, with a hard override on repeated failure (§21.6).
Deferred feature
a capability intentionally out of scope for Phases 0–9, tracked with an anchor, building phase, and un-defer trigger (§35).
Hierarchical memory
a deferred Composer design (short/medium/long-term layers) for bounding context growth in multi-year worlds (§35).
