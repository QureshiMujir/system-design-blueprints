Instrumentation Hooks install into the target's own realm at attach time and are the only component with a hard zero-overhead-when-detached requirement (I1); they call into the framework adapter (Phase 1) and forward raw mount/update/unmount/edge/event notifications.

Snapshot Serializer walks the live object graph reachable from tracked roots, applies cycle detection and truncation, and produces a StateSnapshot — the single artifact everything downstream operates on.

Dependency Graph Tracker observes signal reads, effect registrations, and subscription edges as they are established or torn down, and emits DependencyEdge records independent of the snapshot tree.

Redaction Filter applies RedactionRules to a snapshot or event before it leaves trust boundary A; this is the only point downstream code may assume secrets have already been stripped.

Event Ring Buffer stores EventRecords in a fixed-capacity, LogicalClock-ordered buffer inside the target process, so a hot-reload or crash doesn't require replaying history from zero.

Transport is a WebSocket connection carrying CBOR-encoded TransportMessages, with a bounded send-queue and an explicit reconnect/resume handshake that survives a hot-reload disconnect.

Session Manager owns the per-attach state machine (§8.6), routes messages to the query engine and replay projector, and is the only component permitted to change session state.

Query Engine compiles and evaluates QuerySpec predicates/projections over the current snapshot and the event log, without ever falling back to string-matching serialized JSON (P10).

Time-Scrub / Replay Projector reconstructs any historical ScrubCursor position from the nearest keyframe plus delta application, without re-invoking any target-side code (I9).

UI Client renders the tree, the dependency graph, the event log, and the scrubber; it holds no direct reference to the target and communicates exclusively over the wire protocol.

Telemetry emits OpenTelemetry spans/metrics from the backend and transport only — never from the hooks, preserving the zero-overhead boundary (ADR-19).

8. Domain Model

8.1 StateSnapshot Node Fields

Field Type Meaning
nodeId NodeId stable identity within the session
typeTag enum object | array | primitive | function | ref | component | store | signal
shapeSummary string compact descriptor, e.g. Object{12 keys}
value SerializedValue? present iff typeTag === "primitive"
children NodeId[]? present iff container-shaped
truncated TruncationMarker? present iff this subtree was cut off
cycleRef CycleRef? present iff this node is a back-reference
origin AdapterId which adapter produced this node
clock LogicalClock snapshot logical time of capture

8.2 Instrumentation Contract

Hook Call When Ordering Guarantee
onMount(node) first materialization of a tracked node happens-before any onUpdate for that node
onUpdate(node, prevRef) a value/shape change commits ordered by LogicalClock; never reordered relative to onMount/onUnmount for the same node
onUnmount(node) node is removed happens-after all onUpdate calls for that node
onDependencyEdge(from, to, kind) a signal/effect/subscription edge is (dis)established may interleave with onUpdate; always tagged with the triggering commit's clock
onAsyncTaskStart / onAsyncTaskEnd an async boundary is crossed matched pair, single writer per task id
onEvent(record) a discrete event occurs (dispatch, render, effect run) append-only, monotonic clock

8.3 Dependency Graph Model

Nodes are signals, effects, and subscriptions. Edges are DependencyEdge { from, to, kind } where kind ∈ { reads, writes, subscribes, triggers }. The graph is captured independently of the snapshot tree so that "what depends on this" is a graph traversal, not a tree search (P10).

8.7 Time-Scrub Projection Model

A keyframe is captured every K commits (K derived in §34). ScrubCursor = { keyframeId, deltasApplied }. Seeking forward from the cursor applies subsequent deltas in order; seeking to an earlier point replays from the nearest prior keyframe forward (deltas are not assumed invertible unless the adapter declares them so).

8.8 Worked Example — Serializing a Cyclic Reactive Store

Store S has a computed signal derived whose value structurally embeds a back-reference to S itself (a common pattern: a store exposing self for chaining). The serializer visits S, assigns it nodeId = N1, walks into derived, and on encountering the embedded reference to S again, recognizes N1 in the visited-WeakMap and emits { typeTag: "ref", cycleRef: { target: "N1" } } instead of recursing. The resulting payload is finite regardless of how many times S references itself, satisfying I3.

8.9 Malformed-Input Examples

  • An EventBatch containing an out-of-order LogicalClock value — quarantined per I4, session flagged Degraded until the source stream is confirmed sane.
  • A Snapshot referencing a NodeId absent from the id table (orphaned after a hot reload) — treated as a newly-mounted node; the orphan is flagged, never silently merged into stale state.
  • A TransportMessage carrying a truncated CBOR frame — the decoder rejects the frame and requests retransmission rather than attempting partial decode.

8.10 Failure-Path Example

A hot reload occurs mid-snapshot-serialization. The partial payload is discarded (never partially applied); the adapter is reinstalled; a fresh keyframe is requested; the UI shows a Degraded badge until the new keyframe arrives and the session returns to Attached.
