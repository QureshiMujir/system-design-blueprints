3.1 Command Side

CommandBus routes a command to its aggregate handler; repo loads state (snapshot ≤ head + replay tail), calls pure handle(cmd,&state) -> Result<Vec<Event>,DomainError>. Events append at expected_version = loaded_version; conflicts ⇒ VersionConflict. Owns invariants; never writes read models.

3.2 Event Store / Log

Wraps es-log w/ stream API + optimistic concurrency: validates expected_version under a per-partition writer lock, assigns next version + global offset, serializes envelopes, durably appends, returns AppendResult. Single mutation point; all else reads.

3.3 Append-Only Log (es-log)

Monotonically numbered segments; active appended, sealed immutable; each record length-prefixed w/ CRC, offset, stream id, version, ts, payload. fsync configurable. Recovery scans active segment, validates CRC, truncates at first torn record. No in-place mutation.

3.4 Stream Partitioning

partition = hash(stream_id) mod P (P fixed at init; reshardable in P12). Each partition = independent ordered log (own segments/offsets/writer). Cross-partition global order NOT provided — PhaseDeferred("Deferred Features Register"); per-partition order is total — the subscription-ordering unit.

3.5 Aggregate Repository

Folds events: state = fold(seed, apply), apply pure+total; w/ snapshots seeds from newest + folds tail. Exposes load/save; no cross-command cache by default — write-through cache is PhaseDeferred("Deferred Features Register").

3.6 Snapshot Store

State keyed (stream_id, version); taken when version - last_snapshot_version ≥ interval; load = newest ≤ target + replay (snapshot.version, target]; optimization only, never authoritative (INV-5).

3.7 Projection / Read-Model Builders

Consume ordered stream; apply each event idempotently to a read-model store; advance checkpoint atomically w/ effect. Rebuildable (drop model+checkpoint, replay from 0). Failures pause the projection, not the writer.

3.8 Subscription / Catch-up Dispatcher

Delivers per-partition-ordered events; a subscriber runs catch-up (offset → head) then live (tail); backpressure bounds a laggard. At-least-once ordered; exactly-once effect is the consumer's via checkpointing.

3.9 Saga / Process-Manager Runtime

Stateful consumer: reacts to events, persists saga state, emits commands to CommandBus, schedules timers/timeouts, compensates on failure. Event-sourced where possible (same replay/idempotency).

3.10 Upcaster Pipeline

On read each payload tagged (event_type, schema_version); registry chains v1→…→vCurrent so consumers see the latest shape. Lazy, pure, total; never rewrites bytes. Unknown future versions rejected; missing upcaster = startup error.

3.11 Read-Model Store (KV/SQL)

Pluggable backend (embedded KV default, SQL optional) holding projection outputs + checkpoints; atomic (mutation + checkpoint advance) per commit, or idempotent upsert keyed by offset.

3.12 External Interfaces

Embedded API (EventStore, repository, projection host); optional server (binary append/read/subscribe + routing); admin/replay tools (explain, replay, rebuild, verify).

8. Domain Model / Protocol / Data Model

8.1 Event envelope schema

EventEnvelope {
  event_id:        Uuid (v7, time-ordered),
  stream_id:       StreamId,            // category-instance, e.g. "order-7f3a"
  stream_version:  u64,                 // 0-based, per stream
  global_offset:   u64,                 // per partition
  partition:       u16,
  event_type:      String,             // e.g. "OrderPlaced"
  schema_version:  u32,                 // upcast target tracking
  payload:         Bytes,              // serialized, codec-tagged
  metadata:        EventMetadata,
  recorded_at:     Timestamp,          // server append time (not domain time)
}

8.2 Event metadata (CloudEvents-aligned)

EventMetadata {
  correlation_id:  Uuid,    // ties a workflow together
  causation_id:    Uuid,    // the command/event that caused this
  actor:           String,  // who/what issued the command
  source:          String,  // bounded context / service
  content_type:    String,  // "application/json" | "application/avro" | ...
  trace_context:   Option<W3CTraceParent>,
  custom:          Map<String, String>, // bounded size
}

8.3 Event metadata EBNF (wire framing)

record        = magic length crc body ;
magic         = "ESLG" ;                          (* 4 bytes *)
length        = u32_le ;                          (* body length *)
crc           = u32_le ;                           (* CRC-32C of body *)
body          = header payload metadata ;
header        = version partition global_off stream_id_len stream_id
                stream_ver event_type_len event_type schema_ver ts ;
version       = u8 ;
partition     = u16_le ;
global_off    = u64_le ;
stream_id_len = u16_le ;
stream_id     = byte{stream_id_len} ;
stream_ver    = u64_le ;
event_type_len= u16_le ;
event_type    = byte{event_type_len} ;
schema_ver    = u32_le ;
ts            = i64_le ;                            (* unix micros *)
payload       = length_prefixed_bytes ;
metadata      = length_prefixed_bytes ;            (* codec-encoded EventMetadata *)

8.4 Stream / aggregate identity

  • StreamId = "<category>-<instance>", e.g. order-7f3a9c; category groups same-type aggregates (for category projections/subscriptions).
  • One aggregate ↔ one stream; partition = hash(stream_id) mod P; all events of a stream share one partition (preserves per-aggregate order).

8.5 Command & event types (illustrative)

enum OrderCommand { Place{items,total}, Cancel{reason}, Ship{carrier} }
enum OrderEvent   { OrderPlaced{items,total}, OrderCancelled{reason}, OrderShipped{carrier} }

8.6 Upcasting / versioning model

  • Upcaster trait + chained registry: see §11.13; registry: Map<(EventType,SchemaVer), Upcaster> applies v1→…→vN on read (pure, total).

  • Compatible: add optional field (vN→vN+1 upcaster fills default). Breaking: new event_type + migrator projection; never reuse a type meaning.

8.7 Projection checkpoint model

Checkpoint { projection_name, partition: u16, offset: u64 }   // see §11.11
// advanced atomically w/ read-model mutation OR encoded into an idempotent upsert key

8.8 Saga state machine

SagaState = enum { Pending, AwaitingShipment, AwaitingPayment, Completed, Compensating, Failed }
SagaEvent = enum { Started, ReactedTo(EventRef), TimerFired(TimerId), CommandEmitted(CmdRef),
                   CompensationStarted, CompensationDone, Finished }

Saga itself is event-sourced: saga_state = fold(SagaEvent).

8.9 Aggregate lifecycle state machine

   ┌─────────┐  first event   ┌──────────┐  events    ┌──────────┐
   │ NonExist │ ─────────────▶ │  Active   │ ─────────▶ │  Active   │ (version++)
   └─────────┘  (NoStream OK)  └────┬─────┘            └────┬─────┘

8.10 Command → event sequence diagram

Client → CommandBus: PlaceOrder(cmd, expected=NoStream)
CommandBus → Repo: load("order-7f3a")            -> state=NonExist, ver=-1
Repo → Aggregate: handle(PlaceOrder, state)       -> [OrderPlaced]
Repo → EventStore: append("order-7f3a", NoStream, [OrderPlaced])
EventStore → Log: durable append (ver=0, off=N)   -> AppendResult{ver=0}
EventStore → Dispatcher: notify(off=N)
Dispatcher → Projection: deliver(OrderPlaced@N)    -> upsert read model, checkpoint=N
Dispatcher → Saga: deliver(OrderPlaced@N)          -> emit ReserveInventory cmd

8.12 Edge cases / malformed / failure paths

  • Empty batch append → EmptyBatch (rejected to keep versions meaningful).
  • expected=NoStream to an existing stream → VersionConflict.
  • Payload fails read-time schema validation → DecodeError → poison quarantine.
  • Missing upcaster for a stored version → MissingUpcaster → startup fail / projection pause.
  • Snapshot deserialization fails → discard, replay (no loss). Saga command conflicts → retry w/ reload; persistent → compensation. Duplicate command (same idempotency key) → dedup; return prior AppendResult.
