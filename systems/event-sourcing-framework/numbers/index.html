Failure budget torn-write loss ≤ last unsynced batch bounded by fsync policy
RTO / RPO RTO ≤ 30 s; RPO = 0 (durable fsync) or ≤ batch (group-commit) operator-selectable
Deployment single static binary; ≤ 30 MB embedded crate has zero runtime deps beyond std
Horizontal scaling partition count P; near-linear append to P writers cross-partition order not global
Vertical scaling scales w/ NVMe IOPS + cores for codec/replay fsync is the throughput governor

Failure-budget: GroupCommit(10ms) ⇒ worst-case power-failure loss is one commit window; PerBatch ⇒ RPO=0 at throughput cost — operator policy, not code.
