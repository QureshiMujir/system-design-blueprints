Mental Models & First Principles

The compressed insights an expert holds before touching the code. Each predicts behavior, names the bug class you write without it, and the § where this blueprint applies it.

  • MM1 — A NIC is a producer-consumer ring; "driving" it is just advancing two indices. RX = the device produces filled descriptors, you consume them; TX = you produce descriptors, the device consumes them. Predicts: every I/O bug reduces to "who owns this slot now, and is the index visible to the other side?". Bug class without it: treating RX/TX as function calls and missing that a descriptor not yet consumed by the device must not be reused. Applied: §8.3 (ring semantics), §Phase 0 (vNIC RX/TX), §Phase 2 (AF_XDP FILL/COMP/RX/TX).
  • MM2 — Throughput is a cycle budget, not a rate. At 14.88 Mpps on one ~2.2 GHz core you have ≈150 cycles/packet; every design choice spends from that fixed bank. Predicts: you can sum the cost of parse+lookup+rewrite+checksum and know before benchmarking whether a design fits. Bug class without it: adding a "cheap" per-packet malloc or clock_gettime that silently overruns the bank and shows up only as a throughput cliff. Applied: §4 (constraints), §8.7 (worked budget), §Phase 9, Back-of-Envelope Capacity Model.
  • MM3 — The kernel's per-packet cost is a fixed tax you pay once at the seam or never. Interrupt + softirq + skb alloc + socket copy + syscall is ~thousands of cycles/packet; AF_XDP pays it once at setup and then the kernel is off the path. Predicts: the win from kernel-bypass is bounded by how much of that tax you actually remove (copy-mode AF_PACKET keeps the copy). Bug class without it: expecting line rate from a copy-mode fallback. Applied: principle 1/15, §Phase 2, Comparative Architecture Table.
  • MM4 — Shared mutable state is the enemy; the ring is the only sanctioned sharing. A value that never leaves its core needs no lock and no atomic. Predicts: throughput scales linearly with cores exactly until two cores write the same cache line — then it collapses to one core's worth. Bug class without it: a Mutex<HashMap> flow table that serializes every core, or an unpadded shared counter that false-shares. Applied: principle 4, I3/I14, §Phase 1, §Phase 10 (per-core conntrack).
  • MM5 — A lockless ring is correct only if the payload write happens-before the index publish. The producer must Release the tail after writing the slot; the consumer must Acquire the tail before reading. Predicts: a relaxed store on the tail lets the consumer read a slot whose payload is not yet visible — intermittent corruption that no single-threaded test finds. Bug class without it: the classic "works on x86, corrupts on ARM" memory-ordering bug (x86's TSO hides the missing fence). Applied: I1, §8.3, §Phase 1, ADR-005, tested by loom in §Phase 12.
  • MM6 — Batching amortizes fixed cost and unlocks prefetch. Process 32 packets per call: the per-call overhead is paid once per 32, and while you work packet i you prefetch i+1's data and lookup entry, hiding cache-miss latency. Predicts: per-packet processing is not 1/32 the throughput of batched — it is far worse, because prefetch can no longer overlap. Bug class without it: a "simple" per-packet loop that benchmarks at a fraction of expected pps. Applied: principle 3, §Phase 9 (prefetch), §8.7.
  • MM7 — Tables must be read without locking; reclamation is deferred, not synchronous. RCU/seqlock let the dataplane read while the control plane swaps a new version; the old version is freed only after every reader has left it (grace period). Predicts: a lock on the lookup path stalls all cores during a route update; a torn in-place write yields a wrong next-hop. Bug class without it: use-after-free of the old table (freed before a reader finished) or a read of a half-updated table. Applied: I7, principle 8, §Phase 5, ADR-013.
  • MM8 — Symmetric hashing is what makes per-core flow state lock-free. If a flow and its reverse hash to the same core, all of a connection's packets — both directions — land on one core, so its conntrack/NAT state needs no lock. Predicts: asymmetric RSS splits a connection across two cores, forcing either a lock or two half-states. Bug class without it: a conntrack table that needs a per-entry lock, re-introducing the contention sharding removed. Applied: §8.5, principle 12, I3, §Phase 4 → consumed in §Phase 10.
  • MM9 — Every packet that disappears must increment a counter; "loss" with no reason is a bug, not a drop. Conservation: rx == forwarded + Σ drops{reason}. Predicts: if the conservation check fails, there is a drop path with no counter — you have lost observability, not just packets. Bug class without it: the 3 a.m. "where did 2% of traffic go?" with no telemetry to answer it. Applied: I2, §Phase 11 (drop accounting), Operational Readiness (Drop SLO).
  • MM10 — Determinism is engineered, and it is the precondition for debugging. Fix the RSS key, the hash seeds, and use the vNIC source, and the same input pcap reproduces the same packet→queue→core→action→egress, byte for byte. Predicts: with a random key you cannot reproduce an incident; with a fixed one you can replay it offline. Bug class without it: heisenbugs that vanish on the next run. Applied: I10, principle 12, §Phase 4, §Phase 11 (replay), §Phase 12 (differential).

Required reading (§5)

Books

  • DPDK Programmer's Guide (current LTS) — chapters: Mempool Library, Mbuf Library, Ring Library, Poll Mode Driver, RSS / Flow Classification, LPM Library, QoS Framework. The single most direct blueprint; extract mbuf layout (§Phase 0), ring head/tail protocol (§Phase 1), PMD lifecycle (§Phase 0/2), RSS indirection (§Phase 4), DIR-24-8 (§Phase 5), hierarchical scheduler (§Phase 7).
  • Drepper, "What Every Programmer Should Know About Memory" (2007) — cache lines, false sharing, NUMA, prefetch, write-combining. Every hot-path layout decision (§Phase 9, and I14 false-sharing) traces here.
  • McKenney, Is Parallel Programming Hard… (perfbook) — RCU, lockless data structures, memory ordering. The ring (§Phase 1, I1) and RCU-safe tables (§Phase 5, I7) come from here.
  • Herlihy & Shavit, The Art of Multiprocessor Programming, 2e — lock-free queues, the ABA problem, memory consistency. Ring correctness (§Phase 1, §8.3, I1) and the MPMC CAS protocol.
  • Stevens, TCP/IP Illustrated, Vol. 1, 2e — Ethernet/ARP/IP/ICMP/UDP packet anatomy + checksum. §8 domain model + parsing (§Phase 3).
  • Comer, Internetworking with TCP/IP, Vol. 1 — forwarding, longest-prefix-match, ARP/ND semantics. L3 router + neighbor resolution (§Phase 6).
  • Klabnik & Nichols, The Rust Programming Language + Rustonomicon — ownership, Send/Sync, unsafe, UnsafeCell, atomics. Per-core sharding (§Phase 1, I3) + scoped unsafe (ADR-001, ring/mbuf/UMEM in §Phase 0/1/2).
  • Varghese, Network Algorithmics — packet lookup, switching, scheduling algorithms. LPM/classification engineering (§Phase 5) + QoS scheduling (§Phase 7).
  • Bovet & Cesati, Understanding the Linux Kernel, 3e — chapters on the network stack, softirq/NAPI, and the per-packet path the kernel takes. Read to understand exactly what cost this design removes at the AF_XDP/AF_PACKET seam (§Phase 2) and why the differential oracle (kernel netns) is a valid reference (§Phase 12).

Glossary · 55 terms · site-wide glossary

Kernel bypass
Moving packet I/O out of the kernel network stack into userspace for line-rate processing.
Poll-mode driver (PMD)
A driver that busy-polls the device for packets instead of taking interrupts.
Run-to-completion (RTC)
One core processes a packet through the entire pipeline before fetching the next.
Pipeline model
Processing split into stages, each on its own core, connected by rings.
EAL
Environment Abstraction Layer — hugepages, lcores, per-core data, NUMA topology.
lcore
Logical core — an OS thread pinned to a CPU running a busy-poll loop.
Hugepage
A large (2 MiB/1 GiB) memory page reducing TLB pressure; backs mempool + rings.
mbuf
Message buffer — the packet metadata + data-room structure (headroom/tailroom/refcount/ol_flags).
Headroom / tailroom
Reserved space before/after packet data for prepending headers / appending payload.
Mempool
Lockless pool of pre-allocated mbufs with a per-core magazine cache.
Magazine cache
Per-core array of free mbufs enabling atomic-free alloc/free on the common path.
rte_ring / Ring
Lockless bounded queue (SPSC or MPMC) with head/tail counters and explicit ordering.
SPSC / MPMC
Single-producer/single-consumer / multi-producer/multi-consumer ring variants.
Burst
A batch of packets (default 32) processed per RX/TX/loop iteration.
Acquire / Release
Memory-ordering on atomics: Release publishes prior writes; Acquire observes them.
ABA problem
A CAS sees an unchanged value though it changed and changed back; avoided by monotonic counters.
AF_XDP
Linux address family for high-speed userspace packet I/O via UMEM + XSK rings.
UMEM
The shared memory region AF_XDP uses for packet buffers (chunks).
FILL / COMPLETION / RX / TX ring
AF_XDP's four rings: empty-to-fill, sent-reclaim, received, to-send.
XSK
AF_XDP socket bound to a (netdev, queue).
AF_PACKET v3
Portable mmap'd block-ring packet capture/send fallback (TPACKET_V3).
Virtual NIC (vNIC)
An in-memory, deterministic packet source/sink for testing (no kernel).
Zero-copy
Processing packets in place (mbuf data is the device/UMEM frame) without memcpy.
RSS
Receive Side Scaling — spreading flows across queues/cores by a hash.
Toeplitz hash
The RSS hash function over the 5-tuple using a fixed key.
Indirection table
Maps RSS hash to an RX queue (reprogrammable).
Symmetric RSS
Serialization making a flow and its reverse hash to the same queue (state locality).
Flow steering
Overriding RSS for specific n-tuples to a chosen queue.
5-tuple
(src IP, dst IP, src port, dst port, protocol) — the flow key.
LPM
Longest-Prefix-Match routing lookup.
DIR-24-8
A two-level LPM table (2²⁴ first level + 256-entry second levels) for O(1)/O(2) lookup.
Cuckoo hash
An exact-match table with two hash functions and bounded worst-case lookup.
ACL
Access Control List — ordered classification rules over tuples/ranges → action.
RCU
Read-Copy-Update — lock-free reads with deferred reclamation of old versions.
Seqlock
A lock where readers retry if a sequence counter changed mid-read.
Offload flags (ol_flags)
mbuf bits indicating RX/TX checksum/VLAN/ptype offload status.
ptype
Packed packet-type (L2/L3/L4) computed once at parse for fast downstream dispatch.
Incremental checksum
Updating a checksum by the delta of a changed field (RFC 1624) instead of full recompute.
Token bucket
A rate limiter: tokens accrue at rate r up to burst b; a packet consumes its length.
srTCM / trTCM
Single-/two-rate three-color metering (RFC 2697/2698) → green/yellow/red.
Hierarchical scheduler
Multi-level (port/subport/pipe/tc/queue) QoS scheduler with priority + fairness.
DRR / WRR
Deficit / Weighted Round Robin — fair byte-share scheduling among queues.
RED / WRED
(Weighted) Random Early Detection — probabilistic active-queue-management drop.
Conntrack
Connection tracking — per-flow state machine over a 5-tuple.
Timer wheel
O(1) timer data structure for flow aging / timeouts (Varghese & Lauck).
Stateful NAT
Network Address Translation with per-flow forward + reverse mappings.
Reorder buffer
Restores per-flow packet order after parallel (out-of-order) processing.
Distributor
An RX core that fans packets to worker cores, sticky per flow.
FILL starvation
RX returns nothing because the AF_XDP FILL ring was not refilled.
Cycle budget
The fixed per-packet CPU-cycle allowance to sustain a target packet rate.
False sharing
Two cores writing the same cache line, causing cache-line bouncing.
NUMA-local
Memory on the same node as the accessing core (avoids remote-access latency).
Graceful drain
Shutdown that flushes in-flight packets, frees mbufs, unmaps hugepages, closes FDs.
Crash-only
A design where the only stop path is failure-and-restart (no complex shutdown state).
xstats
Extended per-queue/per-core statistics counters.
