3.2 Per-box responsibilities

sfnt::reader — bounds-checked big-endian cursor over &'a [u8]. Reads u8/u16/u32/i16/i16/Tag/F2Dot14/Fixed. Every read returns Result; out-of-range offset → FontError::OutOfBounds. Invariant: never reads past slice; never panics. Input: &[u8] + offset. Output: scalars / sub-slices. Zero allocation; the single trust gate — all parsers funnel through it.

sfnt::loader — detects container: 0x00010000/'true'/'typ1' (TrueType), 'OTTO' (CFF), 'ttcf' (collection). For ttcf exposes N font offset tables. Output: OffsetTable { sfnt_version, num_tables, search params } + directory slice. Invariant: rejects unknown magic with BadMagic.

sfnt::table_directory — parses num_tables × TableRecord{tag,checkSum,offset,length}; builds tag→record map (sorted/binary search or small linear). Verifies each offset+length ≤ file_len. Output: TableDirectory. Invariant: every table region within file bounds before any table parser runs.

sfnt::checksum — per-table 32-bit sum-of-u32 (big-endian, zero-padded); head.checkSumAdjustment whole-file check. Soft-fail (warn telemetry) — many real fonts have wrong checksums; never reject solely on checksum. Output: validity flags.

tables::head/maxp/hhea/hmtx/post/os2 — scalar metadata. head→unitsPerEm,indexToLocFormat,bbox,flags. maxp→numGlyphs,maxPoints,maxComponentDepth. hhea+hmtx→numberOfHMetrics,per-glyph advanceWidth/lsb. post→glyph names (format 1/2/3). OS/2→typo metrics, weight/width class. Invariants in §7.

tables::cmap — character map subtables; selects best (prefer (3,10) format 12 → (3,1) format 4 → (0,*) → (1,0)). Maps char→GlyphId; unmapped → glyph 0 (.notdef). Output: Cmap with chosen subtable. Invariant: returned gid < numGlyphs.

tables::loca — glyph offset array; short (×2, u16) or long (u32) per head.indexToLocFormat. loca[i],loca[i+1] bound glyph i in glyf. Invariant: monotonic non-decreasing; all within glyf length; len == numGlyphs+1.

tables::glyf — raw glyph data; numberOfContours ≥ 0 simple, < 0 composite. Parsed lazily by outline::builder. Empty glyph (loca[i]==loca[i+1]) = whitespace, valid.

tables::cvt/fpgm/prep — hinting inputs. cvt= Control Value Table (i16 funit array, scaled at use). fpgm= font program (defines functions, run once at face load). prep= control-value program (run once per size change). Consumed by hint::vm.

tables::kern / gpos — kern format 0 (h-pair adjustments); GPOS PairPos (format 1/2) subset for kerning only. Output: kern(left,right)->i16 delta. Everything else in GPOS deferred.

outline::builder — extracts Outline from glyf. Simple: decode flag run-length, then x/y delta-coded coords, split by endPtsOfContours; on/off-curve points. Composite: read components, apply 2×2 + offset transform, recurse (depth ≤ maxComponentDepth, hard cap 8), union bboxes; optionally inherit instructions. Output: Outline in funits. Invariants §7.

scale::transform / fixed — device = funit · ppem / unitsPerEm where ppem = pointSize · DPI / 72. Applies user affine (16.16). Produces 26.6 device coords. F2Dot14 used for composite component scales. Invariant: no i32 overflow (use i64 intermediates).

hint::vm — optional grid-fitting interpreter. Runs fpgm (once), prep (per ppem), then the glyph's instruction stream. State: operand stack, GraphicsState (freedom/projection vectors, round state, zone pointers), CVT, storage area, twilight zone. Mutates point coordinates. Bounded: instruction budget + loop cap → HintBudgetExceeded. Output: hinted Outline. Disabled by default (HintMode::None).

raster::flatten — adaptive subdivision (de Casteljau) of quadratic/cubic Béziers to line segments within flatness tolerance (≤ 0.25 px device). Output: monotone line segments → EdgeList. Bounded recursion depth.

raster::edges / scanline / coverage — the rasterizer. Build edges (y-sorted), active edge table per scanline, accumulate signed-area + cover per Cell, integrate across each row → coverage. Non-zero winding fill. Output: CoverageBuffer (per-pixel area ∈ [0,1] in fixed). Invariant: coverage clamped [0,1].

raster::lcd / gamma — optional. LCD = 3× horizontal supersample + FIR filter (FreeType-style) → RGB coverage triplet. Gamma = linear-space blending LUT. Deferred to Phase 12.

cache::glyph_cache / atlas — GlyphCacheKey{gid,size,transform,hint_mode}→GlyphBitmap. LRU + memory budget (MB). Atlas = shelf/skyline bin-pack of bitmaps into a texture sheet for GPU consumers. Shared read (interior mutability / sharding). Invariant: key uniquely determines bitmap.

api::* — public surface: FontRef::new(&[u8]), font.glyph_index(char), font.outline(gid), font.render(gid, size, transform, hint_mode), font.metrics(gid). All return Result; never panic on malformed input.

8. Domain Model — the sfnt / TrueType format

8.1 Container: offset table + table directory

OffsetTable {
  sfntVersion : u32   // 0x00010000 (TrueType) | 'OTTO' (CFF) | 'true' | 'typ1' | 'ttcf' (collection)
  numTables   : u16
  searchRange : u16   // (max pow2 ≤ numTables) * 16   — advisory, recompute, do not trust
  entrySelector : u16 // log2(max pow2 ≤ numTables)
  rangeShift  : u16   // numTables*16 - searchRange
}
TableRecord (repeated numTables times, sorted by tag ascending) {
  tag      : Tag(u32)  // 4 ASCII bytes, e.g. "glyf","loca","cmap","head"
  checkSum : u32
  offset   : u32       // from start of file
  length   : u32       // unpadded; physical region padded to 4 bytes
}

TTC: 'ttcf' → TTCHeader{ ttcTag, version, numFonts:u32, offsetTable:[u32;numFonts] }; each offset points to an OffsetTable. Required tables for TrueType render: head, maxp, hhea, hmtx, cmap, loca, glyf. Required for CFF: head, maxp, hhea, hmtx, cmap, CFF . Optional: post, OS/2, kern, GPOS, cvt, fpgm, prep, gasp.

8.2 head (font header, 54 bytes)

Field Type Use
majorVersion/minorVersion u16,u16 1.0
fontRevision Fixed(16.16) author version
checkSumAdjustment u32 whole-file checksum magic (0xB1B0AFBA − sum)
magicNumber u32 must == 0x5F0F3CF5
flags u16 bit0 baseline@y=0, etc.
unitsPerEm u16 em square size in funits (16…16384)
created/modified LONGDATETIME(i64×2) timestamps
xMin/yMin/xMax/yMax i16×4 font bbox (funits)
macStyle u16 bold/italic bits
lowestRecPPEM u16 smallest readable ppem
fontDirectionHint i16 legacy
indexToLocFormat i16 0 = short loca, 1 = long loca
glyphDataFormat i16 0

8.3 maxp (maximum profile)

Field Type Use
version Fixed 0x00010000 (TrueType) or 0x00005000 (CFF, fewer fields)
numGlyphs u16 glyph count; bounds for gid
maxPoints u16 max points in a non-composite glyph
maxContours u16 max contours non-composite
maxCompositePoints/maxCompositeContours u16,u16 composite caps
maxZones u16 1 (no twilight) or 2
maxTwilightPoints u16 twilight zone size (hint)
maxStorage u16 storage-area cells (hint)
maxFunctionDefs/maxInstructionDefs u16,u16 fpgm function/instr defs
maxStackElements u16 hint operand-stack depth
maxSizeOfInstructions u16 longest instruction stream
maxComponentDepth u16 composite recursion limit (we also hard-cap 8)

8.4 hhea + hmtx

hhea: ascender:i16, descender:i16, lineGap:i16, advanceWidthMax:u16, …, numberOfHMetrics:u16. hmtx: longHorMetric[numberOfHMetrics] { advanceWidth:u16, lsb:i16 } then leftSideBearing[numGlyphs − numberOfHMetrics] : i16 (monospaced tail reuses last advance). Lookup glyph i: if i < numberOfHMetrics → record i; else advance = record[last].advanceWidth, lsb = trailing lsb[i − numberOfHMetrics].

8.5 cmap (character → glyph)

cmap {
  version : u16  // 0
  numTables : u16
  encodingRecords[numTables] { platformID:u16, encodingID:u16, subtableOffset:u32 }
}

Selection preference (best Unicode coverage first): (3,10) fmt12 → (3,1) fmt4 → (0,4)/(0,6) → (0,3) → (1,0) fmt0. Subtable formats handled:

Format Shape Notes
0 byte→gid array[256] legacy Mac
2 high-byte mapping CJK legacy (parse, low priority)
4 segment mapping to deltas the BMP Unicode format
6 trimmed array (firstCode,count) dense small range
12 segmented coverage (groups) full Unicode, supplementary planes
14 Unicode Variation Sequences selector → gid (parse, used by shaper)

Format 4 fields: format:u16, length, language, segCountX2:u16, searchRange, entrySelector, rangeShift, endCode[segCount]:u16, reservedPad:u16, startCode[segCount]:u16, idDelta[segCount]:i16, idRangeOffset[segCount]:u16, glyphIdArray[…]. Lookup char c: find seg with endCode[s] ≥ c and startCode[s] ≤ c; if idRangeOffset[s]==0 → gid=(c+idDelta[s]) mod 65536; else gid = glyphIdArray[ idRangeOffset[s]/2 + (c−startCode[s]) − (segCount−s) ] (then apply idDelta if nonzero). Last segment must have endCode==0xFFFF.

Format 12 groups: format:u32(=12.0), reserved:u16, length:u32, language:u32, numGroups:u32, groups[numGroups]{ startCharCode:u32, endCharCode:u32, startGlyphID:u32 }. Lookup c: binary search group with startCharCode ≤ c ≤ endCharCode → gid = startGlyphID + (c − startCharCode).

8.6 loca (glyph location)

Short: offsets[numGlyphs+1] : u16, actual byte offset = 2 × value. Long: offsets[numGlyphs+1] : u32. Glyph i bytes in glyf = [off(i), off(i+1)). off(i)==off(i+1) ⇒ empty glyph (whitespace, no outline). Selected by head.indexToLocFormat.

8.7 glyf simple glyph

GlyphHeader {
  numberOfContours : i16   // ≥0 simple ; <0 composite (-1 typical)
  xMin,yMin,xMax,yMax : i16 // glyph bbox (funits)
}
SimpleGlyph (numberOfContours ≥ 0) {
  endPtsOfContours[numberOfContours] : u16   // last index of each contour; numPts = last+1
  instructionLength : u16
  instructions[instructionLength] : u8       // hint bytecode
  flags[numPts]   : u8 (run-length compressed via REPEAT_FLAG)
  xCoordinates[]  : delta-encoded (u8 or i16 per flags)
  yCoordinates[]  : delta-encoded (u8 or i16 per flags)
}

Flag bits:

Bit Name Meaning
0 ON_CURVE_POINT 1 = on-curve, 0 = off-curve (control point)
1 X_SHORT_VECTOR x delta is 1 byte (else 2)
2 Y_SHORT_VECTOR y delta is 1 byte (else 2)
3 REPEAT_FLAG next byte = repeat count for this flag
4 X_IS_SAME_OR_POSITIVE_X_SHORT if X_SHORT: 1⇒+,0⇒−; if not X_SHORT: 1⇒same x (Δ=0),0⇒i16 delta
5 Y_IS_SAME_OR_POSITIVE_Y_SHORT analogous for y
6 OVERLAP_SIMPLE hint to fill overlapping contours non-zero
7 reserved 0

Coordinates are delta-encoded running totals (absolute = prev + delta), first delta relative to 0.

8.8 glyf composite glyph

CompositeComponent (repeat while MORE_COMPONENTS) {
  flags : u16
  glyphIndex : u16
  arg1,arg2 : (i8|i16) | (u8|u16)  // dx,dy (xy values) OR point-match indices
  [scale | xScale,yScale | 2x2 matrix]  // each F2Dot14
}

Composite flags:

Bit Name Effect
0 ARG_1_AND_2_ARE_WORDS args are i16/u16 (else i8/u8)
1 ARGS_ARE_XY_VALUES args = dx,dy offset (else point-match indices)
2 ROUND_XY_TO_GRID round offsets to grid
3 WE_HAVE_A_SCALE single F2Dot14 uniform scale follows
5 MORE_COMPONENTS another component follows
6 WE_HAVE_AN_X_AND_Y_SCALE xScale,yScale (F2Dot14) follow
7 WE_HAVE_A_TWO_BY_TWO full 2×2 (xx,xy,yx,yy F2Dot14)
8 WE_HAVE_INSTRUCTIONS instruction stream follows last component
9 USE_MY_METRICS use this component's advance/lsb
10 OVERLAP_COMPOUND overlapping fill
11 SCALED_COMPONENT_OFFSET apply scale to offset (Apple)
12 UNSCALED_COMPONENT_OFFSET do not scale offset (MS default)

Component placement: p' = M·p + (dx,dy) where M = identity / uniform / x,y / 2×2; F2Dot14 → 16.16 for math.

8.9 Quadratic Bézier reconstruction

TrueType outlines are quadratic B-splines defined by alternating on/off-curve points. Rule: between two consecutive off-curve points there is an implied on-curve midpoint. Segment types after inserting implied points:

  • on→on : straight line.
  • on→off→on : quadratic with the off point as control.
  • off→off : implied on-curve at midpoint splits into two quadratics.

If a contour starts off-curve, the start point = midpoint of last and first off-curve points (or use the last on-curve point). Contour is cyclic (wraps end→start).

Worked example (one contour, 4 stored points): points [A(on), B(off), C(off), D(on)], cyclic.

  • A→B→? : B,C both off ⇒ insert implied M = midpoint(B,C). Quadratic A–B–M.
  • M→C→D : quadratic M–C–D.
  • D→A : both on? A on, wrap to A on ⇒ check next stored after D is A(on) ⇒ line D–A. Result: 2 quadratics + 1 line, closed.

8.10 Coordinate spaces + scaling

ppem        = pointSize * DPI / 72            // pixels per em
deviceScale = ppem / unitsPerEm               // funit → pixel
x_device    = funit_x * pointSize * DPI / (72 * unitsPerEm)

Stored in 26.6: x_26_6 = round( funit_x * ppem * 64 / unitsPerEm ) using i64 intermediate. User affine (rotation/skew/scale) applied in 16.16 after em-scale, before rounding to 26.6. Fill rule = non-zero winding (default; even-odd available for SVG-style if ever needed, but TrueType uses non-zero). Y convention: font space y-up; device buffer top-left origin → flip y during scale (y_dev = (ascent_or_bbox_top − funit_y)·scale); fixed once in scale::transform.

8.11 Worked glyph examples

  • 'O' — two contours: outer ellipse + inner ellipse (counter). Non-zero winding requires opposite orientations: outer CW, inner CCW (or vice versa) so the hole's winding cancels. If both same orientation, the counter fills solid → visual bug → I8/winding test catches.
  • 'é' (composite) — component 0 = 'e' (glyphIndex of e), identity transform, offset (0,0); component 1 = acute accent, offset (dx,dy) placing it above. MORE_COMPONENTS set on component 0. bbox = union. May carry WE_HAVE_INSTRUCTIONS.
  • space — loca[sp]==loca[sp+1] ⇒ empty glyph, advance from hmtx, no outline, bitmap is 0×0 with nonzero advance.

8.13 Flag run-length decoder state table

Decoding flags[numPts] (variable-length input → numPts flags):

State Input Action Next
READ_FLAG read byte f store f; if f & REPEAT_FLAG → goto READ_COUNT else goto READ_FLAG (until numPts) —
READ_COUNT read byte n append f n more times (bounds: total ≤ numPts) READ_FLAG
DONE count == numPts proceed to coords —

Then x-pass: for each flag, if X_SHORT read u8 (sign from bit4), elif X_IS_SAME Δ=0, else read i16. y-pass analogous with bits 2/5. Guard: total bytes consumed ≤ glyph length (else OutOfBounds).

Design principles (§6)

  • Determinism over convenience. Identical (bytes, size, transform, hint-mode) → byte-identical bitmap on every platform/arch. Tradeoff: forgoes fast float fill paths. Operational: enables snapshot/golden testing and reproducible bug reports. Violation: golden tests flap; cross-platform renders diverge; cache becomes unsafe to share.
  • Bounded resource usage — fonts are adversarial input. Every loop, recursion, and allocation has a static cap (points, contours, recursion depth, hint instructions, atlas size). Tradeoff: rejects a few pathological-but-valid fonts. Operational: a malformed font can never hang or OOM a service. Violation: loca/composite/hint bombs → DoS.
  • Correctness before speed. Phase 7 (monochrome, simple, slow) lands before Phase 8 (AA) before any SIMD. Each optimization must preserve byte-identical output (or a versioned, documented change). Violation: subtle coverage drift that only differential tests catch ships silently.
  • Fixed-point where determinism matters. 26.6 device, 16.16 transform, F2Dot14 scale; the fill path is integer-only. Tradeoff: manual overflow reasoning. Operational: reproducible across CPUs. Violation: float reassociation → per-platform pixel diffs.
  • Separate outline extraction from rasterization. outline::* knows nothing about pixels; raster::* knows nothing about glyf. Tradeoff: an intermediate Outline/EdgeList copy. Operational: hinting, flattening, and rasterizing are independently testable/swappable (e.g., SDF backend later). Violation: parsing bugs masquerade as raster bugs; cannot unit-test in isolation.
  • Coverage is first-class (analytic AA). Use signed-area cell coverage, not post-hoc supersampling, as the default AA. Tradeoff: more intricate accumulation code. Operational: 1× memory, exact edge coverage, sharp results. Violation: supersampling costs N× memory/time and still aliases at low N.
  • Defensive parsing — every offset/length is hostile. All access via sfnt::reader bounds checks; cross-validate loca/maxp/numGlyphs. Tradeoff: a bounds check per read. Operational: OOB reads become typed errors, not CVEs. Violation: the entire FreeType/stb CVE class.
  • No panics on malformed input. Malformed fonts yield Err(FontError::…), never panic!/unwrap/array-index-panic in the core. Tradeoff: pervasive Result plumbing. Operational: a library embedded in a server cannot crash the host on bad input. Violation: one bad font kills the process.
  • Cache by full identity. Key = (glyph_id, size, transform, hint_mode); any input that changes pixels is in the key. Tradeoff: more keys, lower hit rate if transforms vary. Operational: cache correctness is trivially provable. Violation: stale/wrong bitmap served for a different size/transform.
  • Observability of rejection. Every refusal emits a typed error + metric + trace event naming the table/offset. Tradeoff: instrumentation overhead. Operational: "why is this glyph blank?" is answerable from telemetry. Violation: silent .notdef everywhere, undiagnosable.
  • Pixel-grid conventions fixed once. Y-axis direction, pixel center sampling (sample at pixel center, integer pixel = lower-left), rounding of bbox to device pixels, and 26.6 origin are defined in raster:: once and never re-litigated. Tradeoff: must be chosen carefully up front. Operational: metrics (left,top) are consistent across glyphs. Violation: 1-px drift / off-by-one seams in atlases.
  • Lazy table loading. Parse the directory eagerly; parse each table on first use, cache the view in FontRef. Tradeoff: first-use latency spike. Operational: fast face open; pay only for tables you touch. Violation: opening a font parses CFF/hinting you never render.
  • Soft-fail on non-fatal anomalies. Bad checksums, missing post names, unusual but in-bounds values → warn telemetry + continue. Hard-fail only on safety/correctness violations (OOB, bad magic, loca out of range). Tradeoff: renders some technically-broken fonts. Operational: matches real-world font sloppiness (matches FreeType leniency). Violation: rejecting fonts the rest of the world renders fine.
  • Single trust gate. All byte access flows through sfnt::reader; no parser indexes raw slices directly. Tradeoff: minor ceremony. Operational: one place to audit/fuzz for bounds safety. Violation: an un-audited raw index becomes the one OOB bug.
  • Versioned, stable output. GlyphBitmap byte layout + cache file format are versioned; an intentional rasterizer change bumps the version and is documented in CHANGELOG. Tradeoff: can't silently "improve" pixels. Operational: downstream golden images stay valid until a known version bump. Violation: invisible regressions break consumers' visual tests.
