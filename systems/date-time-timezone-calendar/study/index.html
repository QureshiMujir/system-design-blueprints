Mental Models & First Principles

The compressed intuitions an expert in this domain holds. Each: the insight, what it predicts, the bug class you write without it, and where this blueprint applies it.

  • MM1 — An Instant is a count; a Civil time is a label; they are never the same type. Predicts: you cannot order, subtract, or compare two civil times without first naming a zone; a wall-clock string carries no instant until resolved. Bug without it: "store local time, compare as UTC" — off-by-offset ordering, double-counted DST hours, the single most common time bug. Applied: §11 (Core Types), Phase 0, Phase 6; principle P1.
  • MM2 — The tzdb is a database of the past and a guess about the future. Predicts: historical transitions are tabulated facts; everything past the last transition is a POSIX-rule extrapolation that a government can invalidate at any time, so "future offset" is a prediction, not a constant. Bug without it: caching a far-future offset and treating it as immutable; failing to re-baseline when a country changes DST law. Applied: §8.6, Phase 5 (POSIX footer), Phase 12 (tzdb updates); principle P5, ADR-6.
  • MM3 — Local time is not monotonic — gaps and overlaps are normal, not errors. Predicts: a local civil time maps to 0, 1, or 2 instants; a "missing" 02:30 in spring and a doubled 01:30 in fall are correct behavior the API must expose. Bug without it: assuming civil → instant is a total function; silently picking one offset on overlap (the twice-a-year meeting-hour bug). Applied: §8.8, Phase 6; invariant I4, ADR-8.
  • MM4 — Unix time is a label for a calendar position, not a count of elapsed SI seconds. Predicts: a Unix day is always 86,400 — the leap second is not counted — so two Unix timestamps spanning a leap second under-count true elapsed time by one second; only TAI counts SI seconds continuously. Bug without it: using Unix-second differences for precise interval physics; expecting 23:59:60 to have a distinct Unix value. Applied: §8.1, Phase 7; principle P6.
  • MM5 — Wall-clock time can go backwards; only a monotonic clock cannot. Predicts: instant_b − instant_a can be negative across an NTP slew, a DST step, or a leap second, so elapsed time must be measured from a monotonic source and a negative Duration must be a representable, checkable result. Bug without it: feeding a negative interval into code that assumes non-negativity — exactly the Cloudflare 2017 leap-second panic (Failure Modes & Recovery, Phase 7.6). Applied: principle P8, Phase 7; the negative-duration failure class.
  • MM6 — Calendar arithmetic is integer arithmetic on a day-number; the calendar is a labeling of that integer. Predicts: every conversion can pivot through a single serial day count (days_from_civil), so Gregorian/Julian/ISO-week are views of one integer, not independent systems; no floating point is ever needed. Bug without it: competing internal epochs, float drift, irreconcilable round-trips. Applied: §8.4, §8.5, Phase 1, Phase 8; principle P2, ADR-4.
  • MM7 — A Period is not a Duration; calendrical spans have no fixed length. Predicts: "+1 month" and "+1 day" depend on where you stand (Feb has 28/29; a DST day is 23/24/25 h), so Period addition is non-associative and order-dependent, while Duration addition is exact and associative. Bug without it: normalizing months to a fixed day count; expecting +1mo +1mo == +2mo at month-ends. Applied: §8.9, Phase 2; invariants I6/I10, ADR-9.
  • MM8 — Every parser of external bytes is an attack surface; totality is the contract. Predicts: a TZif file or RRULE string is adversarial input — valid bytes → value, every other byte sequence → a positioned error, allocation bounded by validated counts, never the declared ones. Bug without it: a truncated TZif over-reads or panics; a FREQ=SECONDLY rule with no bound exhausts CPU. Applied: §8.13, Phase 4, Phase 9, Phase 10; principles P7/P12, the Threat Model.
  • MM9 — Recurrence is generate-then-filter-then-select, and it must be bounded by construction. Predicts: RFC 5545 expansion is a pipeline (candidates → BY* expand/limit → BYSETPOS select → dedupe → EXDATE/RDATE → bound), and "expand vs limit" flips on whether a BY* part is finer or coarser than FREQ. Bug without it: eager materialization that hangs; getting expand/limit backwards so occurrences silently appear or vanish. Applied: §8.11, §8.14, Phase 9, Phase 10; invariant I8, ADR-10.
  • MM10 — Correctness in time is defined against an authority, relative to a pinned version. Predicts: there is no abstract "right answer" for an offset — only agreement with a specific tzdb version as dumped by zdump; so conformance is differential and every result is stamped with its data version. Bug without it: trusting self-consistency; an unbisectable "works on my machine" offset bug after an unpinned data bump. Applied: §5 (Required Reading oracles), Phase 12, the Testing & Verification Strategy; principle P4, ADR-19/ADR-24.

Glossary · 36 terms · site-wide glossary

Instant
an absolute point on a time scale (seconds + nanoseconds since an epoch).
Civil time
wall-clock fields (Y-M-D h:m:s) with no inherent offset.
Wall clock
the time a local clock shows, subject to DST.
UTC
Coordinated Universal Time; includes leap seconds.
TAI
International Atomic Time; monotonic, no leap seconds.
Unix time
seconds since 1970-01-01 UTC, ignoring leap seconds.
Leap second
a one-second adjustment to UTC (the :60 second).
Proleptic Gregorian
the Gregorian calendar extended before 1582.
Julian calendar
the older calendar with a ÷4 leap rule.
ISO week date
year/week/weekday where week 1 contains the first Thursday.
Rata Die / serial day
an integer day count used for conversions.
days-from-civil
the algorithm mapping (Y,M,D) to a serial day.
TZif
the binary IANA time-zone file format (RFC 8536).
zoneinfo / tzdb
the IANA time-zone database.
POSIX TZ string
a compact rule for offsets and future DST transitions.
DST
Daylight Saving Time, a seasonal offset change.
Transition
an instant at which a zone's offset changes.
Offset
seconds east of UTC for a given instant in a zone.
Abbreviation
a zone's short name for a period (e.g., EST, EDT).
Gap / nonexistent time
a local time skipped by a spring-forward.
Overlap / ambiguous time
a local time occurring twice at a fall-back.
AmbiguityPolicy
how the library resolves gaps/overlaps.
Duration
an exact, scale-free length of time (seconds + nanos).
Period
a calendrical length (years/months/days), variable in absolute size.
Month-end clamping
adjusting an overflowed day to the month's last day.
RRULE
an RFC-5545 recurrence rule.
FREQ
recurrence frequency (SECONDLY…YEARLY).
INTERVAL
the step between recurrences.
BYDAY/BYMONTHDAY/…
BY-rules that expand or limit candidate occurrences.
BYSETPOS
selects the Nth occurrence within each interval set.
WKST
the week-start day affecting weekly expansion.
EXDATE / RDATE
explicit excluded / added recurrence dates.
Smearing
spreading a leap second over a window on the Unix scale.
ISO-8601 / RFC-3339
text formats for dates, times, durations, intervals.
Era / rollover
timestamp range boundaries (e.g., NTP era, 2038).
Quantum
n/a here (decimal term); included to avoid cross-blueprint confusion.
