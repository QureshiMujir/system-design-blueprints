30. Mental Models & First Principles

MM1 — Distance Is Cheap, Comparisons Are Not. The dominant cost in ANN search is the number of distance computations, not any one computation's cost; every index design question reduces to "how do we visit fewer candidates for the same recall." Predicts: graph/tree/hash indexes all trade candidate-count for structure-maintenance cost. Bug class without it: over-optimizing SIMD distance kernels while ignoring an O(N) candidate set (§15).

MM2 — Recall Is A Curve, Not A Number. Every ANN parameter traces a recall-vs-latency curve; quoting one recall number without its ef_search/nprobe value is meaningless. Predicts: production incidents where "recall dropped" actually means "traffic shifted along the same curve." Bug class: tuning defaults from a single benchmark point (§21).

MM3 — Quantization Trades Accuracy For Density, Deliberately. PQ/SQ are not approximations that vecdb-flat exclusively "owns" the truth of — density is a resource traded against precision, like a cache line. Predicts: memory-bound workloads benefit from quantization even at some recall cost. Bug class: comparing a quantized distance directly to a raw distance without recalibration (§16).

MM4 — A Graph's Reachability Is Its Recall Ceiling. No amount of ef_search tuning recovers recall lost to a disconnected or poorly-connected graph; the ceiling is set at construction time. Predicts: HNSW recall plateaus below 1.0 no matter how large ef_search grows if M is too small. Bug class: "fixing" a recall regression by only raising ef_search at query time (§14, §15).

MM5 — Filtering And Ranking Are Different Operations. A metadata predicate is a boolean gate; a distance metric is a total order; conflating them (encoding a filter as a distance penalty) breaks both. Predicts: hybrid systems that hack filters into the distance function silently drop valid results. Bug class: additive filter-penalty hacks instead of a real pre/post-filter design (§18).

MM6 — Durability Is A Property Of The Write Path, Not The File Format. bincode vs Protobuf is a red herring for crash safety; what matters is whether every write is atomic end-to-end. Predicts: a well-designed schema with a non-atomic write path still corrupts under crash. Bug class: assuming schema quality implies crash safety (§19).

MM7 — Sharding Multiplies Coordination Cost, Not Just Capacity. Adding shards grows capacity linearly but grows the coordination surface (routing, merge, rebalancing, partial-failure handling) super-linearly. Predicts: naive N-shard scale-out latency grows with shard count even when each shard is individually fast. Bug class: sharding purely for capacity without budgeting for merge-step tail latency (§20, §29).

MM8 — Approximate Systems Need An Exact Twin. An ANN system without a brute-force oracle has no way to distinguish "index bug" from "expected approximation." Predicts: teams without a flat-index equivalent chase phantom recall bugs indefinitely. Bug class: shipping an ANN index with no differential test against exact search (§12, §21).

Required reading (§5)

Books

  • Hanan Samet — Foundations of Multidimensional and Metric Data Structures (Morgan Kaufmann, 2006), Ch. 4 "Point Access Methods" (kd-trees, quadtrees, space partitioning). Extract: the spatial-partitioning-vs-graph tradeoff. Applied in §31, §34.
  • Jure Leskovec, Anand Rajaraman & Jeffrey D. Ullman — Mining of Massive Datasets, 3rd ed. (Cambridge University Press, 2020), Ch. 3 "Finding Similar Items" (shingling, minhash, LSH banding). Extract: the band/row LSH tradeoff. Applied in §17.
  • Christopher D. Manning, Prabhakar Raghavan & Hinrich Schütze — Introduction to Information Retrieval (Cambridge University Press, 2008), Ch. 6–7 (vector-space scoring, cosine ranking) and Ch. 16 "Flat Clustering" (k-means). Extract: cosine ranking discipline and k-means for coarse-quantizer training. Applied in §8, §16.
  • Martin Kleppmann — Designing Data-Intensive Applications (O'Reilly, 2017), Ch. 3 "Storage and Retrieval" and Ch. 6 "Partitioning". Extract: WAL/snapshot durability and hash-partitioning tradeoffs. Applied in §19, §20.
  • Alex Petrov — Database Internals (O'Reilly, 2019), Part I, Ch. 2–4 ("B-Tree Basics", "File Formats"). Extract: the write-tmp + fsync + rename crash-consistent write path. Applied in §19.
  • Donald E. Knuth — The Art of Computer Programming, Vol. 3: Sorting and Searching, 2nd ed. (Addison-Wesley, 1998), §6.5 "Retrieval on Secondary Keys". Extract: exact nearest-neighbor baseline complexity, grounding the flat-index oracle. Applied in §12.

Glossary (§36) · 57 terms · site-wide glossary

ANN
approximate nearest-neighbor search; trades exactness for speed/memory.
HNSW
Hierarchical Navigable Small World, a layered proximity-graph ANN index.
IVF
Inverted File index; coarse-quantizes vectors into clusters (lists).
IVF-PQ
IVF combined with Product Quantization-compressed list entries.
LSH
Locality-Sensitive Hashing; hashes similar vectors into the same bucket with high probability.
PQ
Product Quantization; splits a vector into sub-vectors, each quantized independently against a trained codebook.
recall@k
fraction of a query's true top-k neighbors that an approximate index actually returns.
ef_search
HNSW's query-time beam width; the primary recall/latency dial.
ef_construction
HNSW's construction-time beam width, affecting graph quality.
M
HNSW's max neighbors per node per layer (except layer 0).
M_max0
HNSW's max neighbors per node at layer 0 (typically 2*M).
codebook
a PQ sub-quantizer's set of trained centroids for one sub-vector space.
centroid
the mean point of a cluster, produced by k-means.
coarse quantizer
IVF's top-level k-means clustering that defines the inverted lists.
residual
the difference between a vector and its assigned centroid (used in some PQ variants, not this project's plain PQ).
ADC
Asymmetric Distance Computation; PQ query-to-compressed-candidate distance without decompressing the query.
SDC
Symmetric Distance Computation; both query and candidate are quantized (not used in this design's locked ADR-04 path).
Voronoi cell
the region of space closer to one centroid than any other; IVF's inverted lists approximate Voronoi cells.
k-means
an iterative clustering algorithm partitioning points into k clusters by nearest centroid.
Lloyd's algorithm
the classic k-means iteration: assign points, recompute centroids, repeat.
ground truth
the exact top-k result set, used as the recall-measurement reference.
brute-force search
exact O(N) linear-scan nearest-neighbor search.
cosine similarity
the cosine of the angle between two vectors; 1 - cosine is a common distance.
L2 distance
Euclidean distance between two vectors.
inner product
dot product; used directly as a similarity score in some metrics.
curse of dimensionality
the phenomenon where distance concentration and index effectiveness degrade as dimensionality grows.
beam search
search that retains a bounded-width frontier of candidates rather than expanding all reachable nodes.
greedy search
search that always expands the currently-nearest unvisited candidate.
small-world graph
a graph with short average path length between any two nodes, the structural basis of HNSW.
navigable graph
a small-world graph augmented with long-range edges enabling efficient greedy routing.
entry point
the node where HNSW search begins its top-layer descent.
tombstone
a soft-delete marker retained until compaction physically removes the record.
compaction
the process of rebuilding a structure to exclude tombstoned records.
WAL
Write-Ahead Log; a durability mechanism recording mutations before they are considered committed.
snapshot
a full point-in-time serialization of a collection's state.
fsync
the system call guaranteeing data is flushed to durable storage.
atomic rename
a filesystem operation swapping a temp file into place as a single indivisible step.
sharding
partitioning a dataset across multiple independent collections/nodes.
partition key
the field/value used to deterministically route a record to a shard.
scatter-gather
a query pattern that fans out to multiple shards and merges their results.
quantization error / distortion
the reconstruction error introduced by compressing a vector through a codebook.
bitset
a compact boolean array, often used for candidate-set intersection in filtering.
predicate pushdown
evaluating a filter as early as possible in a query pipeline to reduce downstream work.
hybrid search
search combining vector similarity with metadata filtering.
metadata filter
a boolean predicate over a vector record's associated attributes.
over-fetch factor
the multiplier applied to k when fetching candidates before filtering, to compensate for filtered-out results.
multi-probe LSH
an LSH variant that additionally probes buckets adjacent to the query's exact bucket, improving recall per unit memory.
p-stable distribution
a probability distribution family (e.g., Gaussian for p=2) used to construct LSH projections preserving Lp distances in expectation.
random projection
a dimensionality-reducing linear map used as an LSH hash function.
vector database
a system specialized for storing and searching high-dimensional vectors by similarity.
embedding
a vector representation of an object (text, image, etc.) produced by a model, consumed but not produced by this system.
top-k
the k nearest results returned by a search query.
QPS
queries per second; a throughput metric.
p99 latency
the 99th-percentile response time across a measured window.
incremental indexing
updating a live index structure per-insert without a full rebuild.
differential testing
validating a system by comparing its output against an independent reference implementation (here, vecdb-flat) on the same input.
conformance fixture
a versioned test input/expected-output pair used to gate correctness in CI. ---
