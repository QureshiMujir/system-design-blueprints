3.2 Box Narratives

  • Public API / cv facade. Re-exports the stateless operations; e.g. canny(&Image,lo,hi,aperture) -> Image, hough_lines(&Image,ρ_res,θ_res,thresh) -> Vec<Line>. Thin — validates dtype/dims/params, dispatches, never holds state. The contract: an operation reads its input immutably and returns a new Image/result (no hidden mutation, principle 3).
  • cabi ABI. #[repr(C)] functions over a row-major uint8*/float*+dims+stride; results into caller buffers or opaque result handles (cv_lines_count/cv_lines_get); never unwinds across the boundary (catch → code). This is the surface #387 and external C/Python callers use.
  • cv-core. The vocabulary. Image<T> (typed pixels, explicit stride, zero-copy ROI ImageViews that borrow); BorderMode (Constant/Replicate/Reflect/Reflect101/Wrap); Kernel (separable or dense); StructElem (morphology); Point/Size/Rect; color conversion (RGB↔Gray↔HSV↔Lab); CvError; seeded Rng (RANSAC/FAST-training, no global RNG, I7). No algorithms.
  • imageio. Native PGM/PPM/PBM (the trivial test formats) + #173 for PNG/JPEG. To/from Image<T>; preserves bit depth.
  • convolve. The substrate. Correlation (slide kernel) vs convolution (flip kernel first) — the duality every text confuses (I2). Separable apply (row pass then column pass, O(k) per pixel) when the kernel is rank-1 (I3). Border handling (the pixel-exactness crux). FFT-conv (#369) for large kernels (convolution theorem, the O(k²)→O(log N) crossover). Anchor + normalization conventions pinned to OpenCV.
  • filter. Built on convolve. Box (mean) via the integral image (O(1)/pixel, window-size-independent). Gaussian (separable, σ→radius). Derivative-of-Gaussian (smooth + differentiate in one kernel). Non-linear: median (sliding histogram, O(1) amortized for 8-bit), bilateral (edge-preserving, range+space weights), min/max (the morphology connection).
  • gradient. Sobel / Scharr (more rotationally symmetric) / Prewitt operators (separable derivative kernels); magnitude √(gx²+gy²) (or |gx|+|gy|), orientation atan2(gy,gx) (radians, the pinned convention, I9). Feeds edges, Hough, corners.
  • edge. Canny: Gaussian smooth → Sobel gradient → non-maximum suppression (thin to 1-px ridges along the rounded gradient direction) → double threshold (high/low) → hysteresis (BFS/flood from strong edges through weak, I11-style connectivity). Output is 1-px-thin, connected (I8). Marr-Hildreth: LoG zero-crossings (the alternative).
  • hough. Line: build a ρ-θ accumulator; each edge pixel votes ρ = x·cosθ + y·sinθ for all θ; peaks → lines. Probabilistic Hough (PPHT): randomized + segment-tracing for line segments. Circle: gradient-direction-guided (a,b) accumulator at candidate radii (Hough-gradient). Peak detection + NMS in accumulator space (I6).
  • morphology. Erosion (min over the structuring element) / dilation (max); opening (erode∘dilate), closing (dilate∘erode), gradient/tophat/blackhat, hit-or-miss; arbitrary StructElem (rect/ellipse/cross/custom); distance transform (two-pass chamfer / exact); skeleton. Duality: erosion of the complement = complement of dilation (I12).
  • features. Harris (corner response det(M)−k·tr(M)² from the structure tensor M=Σw·∇I∇Iᵀ), Shi-Tomasi (min eigenvalue), FAST (segment test on a Bresenham circle). ORB = FAST keypoints + oriented BRIEF binary descriptor (rotation-aware); brute-force Hamming/SSD matching + ratio test. SIFT full pipeline PhaseDeferred("Deferred Features Register") (built on the §22 scale space).
  • pyramid. Gaussian pyramid (blur + downsample by 2 — anti-aliased), Laplacian pyramid (band-pass residual = level − upsample(next)); scale space for multi-scale feature detection. pyrUp/pyrDown reuse filter + geometry.
  • geometry. Interpolation (nearest/bilinear/bicubic); affine (2×3) + perspective (3×3) warp (inverse mapping + interpolation); homography estimation (DLT: build the constraint matrix, SVD via #349; RANSAC for outlier-robust fit, seeded I7); resize/rotate (warp special cases). Identity transform = identity image (I15).
  • contour. Connected components (two-pass union-find, the primitive #387's layout analysis calls); Suzuki border following (contour extraction with hierarchy); Douglas-Peucker polyline simplification; moments (area/centroid/perimeter/Hu).
  • match. Template matching: slide a template, score SSD/SAD/NCC/CCORR per position → response map → peaks; multi-scale option.
  • bench. Mpix/s per operation; separable-vs-dense convolution crossover; FFT-conv crossover (kernel size where #369 wins); border-mode cost; tiling/parallel scaling. Pinned, median-of-k.
  • conformance. Synthetic ground-truth (procedurally drawn lines/circles/edges/corners with known geometry), the OpenCV differential harness (offline golden outputs, pinned version), primitive-invariant asserts, fuzzing (degenerate/huge/adversarial images).

3.3 Boundaries

  • Trust boundary: C ABI (untrusted dims/stride/pointers/params → validated) + untrusted image data (huge/degenerate/adversarial pixels → bounded, never UB).
  • Concurrency boundary: image operations are tile/row-parallel over a shared read-only input → an output tile per task (I11); no cross-tile state except halo reads.
  • Numerical boundary: integer ops saturate/round to a pinned convention; float ops match OpenCV within tol; FFT-conv vs spatial-conv differ by rounding (documented, ADR-18). Pixel-exact where integer-deterministic; ≤tol where float.
  • Mutation boundary: operations do not mutate their input (return a new Image) unless an explicit in-place variant is called; ROI views are read-only-aliased safely (principle 3).
  • Border boundary: every neighborhood op declares its BorderMode; off-image reads are defined, never out-of-bounds (I13).

3.4 Data-flow walk — one hough_lines over a photo (the #387 deskew path)

  1. imageio decodes page.png (#173) → Image<Rgb8> → cvt_color → Image<Gray8>.
  2. filter::gaussian (separable, σ) smooths → noise suppressed.
  3. edge::canny(lo,hi): Sobel gradient → NMS → hysteresis → 1-px edge map (I8).
  4. hough::lines(ρ_res=1, θ_res=π/180, thresh): each edge pixel votes into the ρ-θ accumulator; accumulator peaks (NMS) → Vec<Line{ρ,θ,votes}> (I6).
  5. Dominant line angle → page skew (the consumer, #387, rotates by −θ).
  6. Optional OpTrace (per-stage ms, edge-pixel count, accumulator peak heights, n_lines).

8.3 Convolution & separability

correlation: O(x,y) = Σ_{i,j} K(i,j)·I(x+i−a_x, y+j−a_y)        (a = anchor)
convolution: flip kernel first: O = corr(I, flip(K))            (I2)
separable (rank-1 K = c·rᵀ): row pass P(x,y)=Σ_i r(i)I(x+i,y) ; col pass O(x,y)=Σ_j c(j)P(x,y+j)   (I3)
FFT-conv (large K): O = IFFT( FFT(I_pad) · FFT(K_pad) )         (#369; crossover k≳15)
border: out-of-range index → Replicate/Reflect/Reflect101/Constant/Wrap  (I5)

8.4 Edge detection (Canny, the named spine)

1. smooth: G = I * Gaussian(σ)
2. gradient: gx = G*Sobel_x , gy = G*Sobel_y ; mag=√(gx²+gy²) ; θ=atan2(gy,gx) (I9)
3. NMS: for each pixel, compare mag to the two neighbors along round(θ) to {0,45,90,135}°;
        keep only local maxima → 1-px ridges (I8)
4. double threshold: strong = mag≥hi ; weak = lo≤mag<hi
5. hysteresis: BFS from strong pixels through 8-connected weak pixels → keep; drop isolated weak (I8)

8.5 Hough transform (voting)

line: ∀ edge pixel (x,y), ∀ θ∈[0,π): ρ = x·cosθ + y·sinθ ; accumulator[ρ][θ] += 1
      peaks (local maxima ≥ thresh, NMS in accum) → lines (ρ,θ)  (I6)
probabilistic (PPHT): random edge pixels vote; on a peak, walk the line to extract a segment
circle (Hough-gradient): ∀ edge pixel, vote along the gradient direction for centers (a,b)
      at radius r; 2-stage: find centers, then best radius (I6)

8.6 Features & geometry

Harris: M = Σ_w [gx²  gxgy; gxgy  gy²]  (structure tensor) ; R = det(M) − k·tr(M)²  (k≈0.04)
        corner if R > thresh and local-max ; Shi-Tomasi: min(λ1,λ2) > thresh
FAST: center c; corner if ≥N contiguous of 16 Bresenham-circle pixels all > c+t or < c−t
ORB: FAST keypoint + intensity-centroid orientation + rotated BRIEF (binary) ; match by Hamming + ratio test
homography (DLT): for ≥4 (x,y)↔(x',y'): build A (2N×9) from x'×Hx=0 ; h = null-space(A) via SVD (#349)
        normalize points (Hartley) ; RANSAC: sample 4, fit, count inliers, keep best, re-fit (I15)
warp (inverse map): ∀ dst (x',y'): (x,y)=H⁻¹(x',y') ; O(x',y')=interp(I, x, y)   (I14)

8.7 Worked example (Hough line on a 3-point edge)

edges at (0,0),(1,1),(2,2) (a 45° line). Each votes ρ=x cosθ+y sinθ for all θ.
At θ=135° (−45° normal): ρ = x cos135 + y sin135 = (−x+y)/√2 = 0 for all three → accumulator[0][135°] = 3 (peak).
Peak (ρ=0, θ=135°) ↔ the line y=x. Single dominant bin (I6).

Design principles (§6)

  • Correctness before speed; OpenCV + synthetic ground truth are the oracles. Gate every primitive on pixel-exact/≤tol agreement with OpenCV and on procedurally-known geometry before optimizing. Violation: a fast filter that disagrees with OpenCV at the borders → silent downstream breakage in #387.
  • Convolution semantics are explicit: correlation vs convolution, anchor, border, normalization. State each once, pin to OpenCV. Violation: an unflipped "convolution" or a wrong border → off-by-pixel everywhere downstream.
  • Operations are pure: read input immutably, return a new image; ROI views never alias-mutate. In-place variants are explicit. Violation: a hidden in-place write corrupts a caller's image or an overlapping ROI.
  • Separable kernels take the separable path; it must equal the dense path. Detect rank-1 kernels; row-then-column pass. Violation: a separable/dense mismatch → subtle blur differences, failed differential tests.
  • Every neighborhood operation declares a border mode; off-image reads are defined. No out-of-bounds, no undefined edges. Violation: reading past the image → UB or garbage borders that diverge from OpenCV.
  • Integer arithmetic saturates and rounds to a pinned convention. 8-bit results clamp to [0,255] with OpenCV's rounding. Violation: wraparound or banker's-vs-half-up rounding → off-by-one vs the oracle.
  • Edges are thinned (NMS) and tracked (hysteresis); the output is 1-px and connected. Canny's stages are non-negotiable and ordered. Violation: skipping NMS → thick edges; skipping hysteresis → fragmented edges.
  • Hough is voting in a quantized parameter space; resolution and peak-detection are explicit. ρ/θ/radius resolution + accumulator NMS are parameters. Violation: implicit resolution → merged/split peaks, irreproducible lines.
  • Geometric warps use inverse mapping + interpolation; the transform is invertible. Sample the source for each destination pixel. Violation: forward mapping → holes/overlaps; non-invertible transform → can't round-trip boxes (the #387 coordinate contract).
  • Numerical behavior is a tolerance contract, not bit-equality (for float ops). Pixel-exact for integer-deterministic ops; ≤tol for float; FFT-conv vs spatial documented. Violation: promising bit-equality on Gaussian → broken by any SIMD/FFT order change.
  • Reuse #369/#349/#181/#173; never reimplement a dependency. FFT-conv, SVD/homography, SIMD, codecs go through their owners. Violation: a private FFT/SVD → numeric drift + duplicated maintenance.
  • Bounded memory; tile and stream, don't materialize intermediates. O(W·H) in + out (+ accumulator); no O(k²·W·H). Violation: im2col-style blowup on big kernels → OOM.
  • Validate dtype, dims, and params at the boundary. Wrong dtype, zero dims, even-sized kernel where odd required, negative σ, degenerate point sets → typed error pre-compute. Violation: trusting inputs → panics, OOB, garbage.
  • Determinism: seed RANSAC/FAST-training; reductions order-deterministic per config. Same seed + threads ⇒ same homography/keypoints. Violation: unseeded RANSAC → irreproducible geometry, untestable.
