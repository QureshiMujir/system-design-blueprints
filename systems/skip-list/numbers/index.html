4.2 p Parameter Trade-offs

p E[height] Levels traversed per search Memory factor Use case
1/2 2.0 ~2 log₂ n 2× Classic; best average latency
1/4 1.33 ~2 log₄ n (fewer levels) 1.33× Memory-constrained; slightly more work per level
1/e 1.58 theoretical optimum 1.58× Theoretical; not standard

Default: p = 1/2 (p_inv = 2), max_level = 32.
