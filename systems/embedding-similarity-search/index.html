Bindings Layer. Thin translation only — no business logic. PyO3 exposes zero-copy numpy views; wasm-bindgen exposes WASM linear memory; the C ABI is the escape hatch (ADR-15–ADR-17). Trust boundary: input crossing this layer is untrusted and validated against §8.6 (malformed-input handling) before touching engine internals.

Embedding Pipeline. Tokenizer wrapper (§13) feeds a model runtime (ONNX Runtime via ort, or candle — ADR-03/ADR-04) that produces raw vectors; a pooling layer reduces token-level output to one embedding per input.

Index Builder / families. Six index families share one Index/IndexBuilder trait pair (§11.10, §11.11): brute-force flat, kd-tree/ball-tree, IVF/IVF-PQ, HNSW, NSG, ScaNN-style partitioned. Concurrency boundary: builders are single-writer; built indexes are Send + Sync and safe for concurrent search (I3, I4).

Distance Kernel Layer. Scalar kernels are the correctness oracle (I5); AVX2/AVX-512/ NEON kernels are dispatched at runtime via CPUID detection (P7, ADR-06), never silently downgraded.

Quantizer. PQ/OPQ/SQ compress vectors post-training; persistence boundary — codebook state is serialized alongside the index it quantizes (§11.6).

Hybrid Search Composer. Merges dense ANN results with a sparse retriever (BM25 or SPLADE) via reciprocal-rank fusion or weighted-sum, then optionally reranks the top candidates with a cross-encoder (§19).

Shard Router. Present only when the corpus exceeds a single shard's RAM ceiling (§4); fans a query out to N shards and re-ranks the union of per-shard top-k lists (MM7) rather than trusting per-shard scores as globally comparable.

Cross-cutting. Tracing/metrics/telemetry apply uniformly (§27 Operational Readiness); the conformance/recall harness (§28 Testing & Verification Strategy) is wired to every index family identically.

8. Domain Model

8.1 Vector & Index Model

A vector is a fixed-length, typed numeric array (Dtype ∈ {F32, F16, Bf16, I8, U8, PqCode}) with no semantic meaning outside the embedding model that produced it (MM1). An index is a structure over a corpus of vectors that answers search(query, k) → top-k (id, score) under a declared Distance. Every index family in this engine implements the same Index/IndexBuilder contract (§11.10–§11.11); families differ only in the space/time/recall point they occupy:

Family Build cost Query cost Recall Memory Exactness
Flat (brute force) O(1) O(N·d) 1.0 (exact) O(N·d) Exact — the oracle (P10)
kd-tree / ball-tree O(N log N) O(log N)–O(N) degraded Exact ≤ ~32 dims, else poor O(N·d) Exact but curse-prone (§15)
IVF / IVF-PQ O(N) (k-means) O(nprobe·N/nlist) 0.80–0.90 O(N·d) / O(N·m) Approximate
HNSW O(N log N) O(log N) 0.93–0.98 O(N·d + N·M) Approximate
NSG O(N log N) O(log N) 0.94–0.98 O(N·d + N·R), smaller than HNSW Approximate
ScaNN-style O(N) (tree + AVQ) O(√N) leaf scan 0.93–0.97 O(N·d) or quantized Approximate

8.2 Distance Metrics

Three kernels (Distance enum, §11.5): L2 (Euclidean, ascending order), IP (inner product, descending), Cosine (implemented as IP after L2-normalization — I2). Triangle inequality holds for L2 (enables kd-tree/ball-tree pruning, §15) but not for IP; cosine similarity is IP restricted to the unit hypersphere. State transition for a vector's dtype across the pipeline:

raw f32 embedding --normalize (Cosine only, I2)--> unit f32
       │
       ├--quantize (PQ/OPQ, §16)--> PqCode { m, ks }
       ├--quantize (SQ, §16.6)-----> I8/U8 per-dim
       └--(Flat/HNSW/NSG default)--> stays f32

8.3 Graph Index State Model (HNSW)

Each node has a layer assignment l ~ Geometric(mL = 1/ln(M)) and, per layer ≤ l, a neighbor list of size ≤ M (≤ 2M at layer 0). States: Active (searchable, mutable neighbor list), Tombstoned (excluded from search per I9, retained for graph connectivity until compaction), Compacted (physically removed, neighbor lists repaired). Insert: assign layer → greedy descent from entry point through layers > l → neighbor selection heuristic (Malkov & Yashunin, Algorithm 4) at each layer ≤ l → update reverse edges. Search: greedy descent through layers > 0 → ef_search-bounded best-first search at layer 0.

8.4 Quantization Structures (IVF-PQ)

IVF partitions the corpus into nlist Voronoi cells via k-means; each vector's residual (vector − assigned centroid) is product-quantized: split into m sub-vectors, each independently vector-quantized to one of 2^ks sub-centroids (codebook trained via k-means++, P4/P11). A vector's on-disk form is (cell_id: u32, code: [u8; m]). Query: compute the residual of the query against each of nprobe nearest cells, then compute an asymmetric distance (query residual vs. codebook centroids, not vs. decoded vectors) via a precomputed lookup table — this is what makes IVF-PQ query cost independent of d after the LUT build.

8.5 Worked Example

Corpus: 4 vectors, dim = 4, L2 distance. v0=[0,0,0,0], v1=[1,0,0,0], v2=[0,1,0,0], v3=[5,5,5,5]. Query q=[0.1,0.1,0,0], k=2. Brute force computes d(q,v0)=0.0141, d(q,v1)=0.9055, d(q,v2)=0.9055, d(q,v3)=~8.63; sorted ascending → top-2 = [v0, v1] (v1 wins the tie over v2 by insertion-order tie-break, a documented, deterministic rule per I6). recall_at(2, ground_truth=[v0,v1]) against this brute-force answer = 1.0 for any index family that returns the same set.

8.6 Malformed-Input Handling

  • Dim mismatch (query.dim != index.dim) → Error::DimMismatch (I1), never a buffer over-read.
  • NaN/Inf components → rejected at insert with Error::Other("non-finite vector component"); a query containing NaN returns Error::Other rather than a distance of NaN silently sorting first or last.
  • Zero-length vector on a Cosine index → normalization divides by ‖v‖=0; rejected explicitly (Error::Other("zero-norm vector on cosine index")) rather than producing NaN (I2).
  • k = 0 → returns an empty result, not an error (documented as valid).
  • k > corpus size → returns all available hits (≤ corpus size), never pads with sentinel entries.

8.7 Failure-Path Example

An HNSW build is interrupted mid-insert (process killed at 60% of corpus indexed). On restart, the partially-written index file fails its CRC32 footer check (§25 FM-2) → Error::Io surfaces to the host → the host's conformance runner reports the shard Deferred{blueprint_ref="§25 FM-2"} rather than serving a corrupted graph → operator runbook (§27) directs a rebuild from the last checkpointed vector log, not a partial graph repair (graph repair is explicitly out of scope — a partially built HNSW graph has no defined recovery point per I8).

Design principles (§6)

  • P1 — The engine is a library, not a service. No background threads at load time, no sockets opened, no environment variables read silently. Violating it turns every host into an implicit multi-process system with no supervision contract.
  • P2 — Determinism by construction. Every index build accepts a seed; every embedding call is deterministic for fixed (model, input, tokenizer, device). Violating it makes recall regressions unreproducible (breaks §28 differential testing).
  • P3 — Zero-copy where the language allows. VectorView borrows across the binding boundary. Violating it doubles memory pressure at the exact point (host boundary) where the corpus is largest.
  • P4 — Numerical stability is not an aesthetic. Accumulate in f64 (or compensated f32) when summing many terms. Violating it silently corrupts recall on high-dimensional vectors (768+ dims) — the error is invisible until an audit.
  • P5 — Recall is a first-class output, not a comment. Every index exposes recall_at(k, ground_truth). Violating it means shipping an index family with no falsifiable claim about quality.
  • P6 — No model is bundled. The crate ships runners, not weights; weights are host-supplied and SHA-256-verified. Violating it either bloats the crate to hundreds of MB or introduces unverified supply-chain risk (T1).
  • P7 — SIMD is feature-gated, never silent. Kernel choice is CPUID-detected and logged once. Violating it makes a performance regression from a kernel downgrade invisible until a benchmark catches it days later.
  • P8 — Errors are typed. One enum Error per crate boundary, no Box<dyn Error> in the public API. Violating it forces callers to string-match error messages to recover from a specific failure (breaks I13).
  • P9 — The engine never owns long-lived state beyond an index handle. Handles are Send + Sync, reference-counted; the host decides lifetime. Violating it creates global mutable state that defeats testing isolation.
  • P10 — Exactness is a first-class mode, not a fallback. Brute force is not "the slow path" — it is the recall oracle every ANN family is graded against (I5, I11). Violating it (e.g. deleting the flat index once ANN "works") destroys the ability to detect silent recall regressions.
  • P11 — Quantization error is measured, not assumed. Every Quantizer reports reconstruction error on a held-out sample at training time. Violating it hides codebook drift (MM5) until production recall collapses.
  • P12 — A shard boundary never changes result semantics. A query against N shards must return the same top-k (modulo tie-breaking) as the same query against one shard holding the same data. Violating it breaks MM7 and silently corrupts recall at scale.
  • P13 — Insert/delete never blocks concurrent search. Streaming ingestion uses copy-on-write or lock-striped structures (§20). Violating it turns every write into a latency-tail incident for readers.
  • P14 — Every acceptance criterion is a number. No phase ships on "works" — every N.4 cites recall@k, QPS, latency, or a named fixture. Violating it is the single most common way a from-scratch ANN engine degrades into an unmeasured pile of code.
