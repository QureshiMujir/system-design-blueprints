Invariants — what must never be false (§7) · 12

Invariants — what must never be false
Item
x0 always reads as 0; writes to x0 are discarded. Why: ISA contract, canonical zero/NOP. Where: regfile read mux + write guard. Detect: SVA rd==0 |-> regfile[0]==0; differential vs Spike. Telemetry: regfile write trace. Recover: N/A (compile-time guard). Debug: dump regfile after each commit.
The pipeline commits in program order; results match the single-cycle core and Spike. Why: correctness. Where: WB commit + differential harness. Detect: lockstep PC+regfile mismatch. Telemetry: RVFI retire record (pc, insn, rd, wdata). Recover: bisect to first divergent instruction. Debug: dump both traces, diff.
Every register read sees the most recent write (via forwarding or stall). Why: data-hazard correctness. Where: hazard forwarding + load-use stall. Detect: differential value mismatch; SVA on forward-select one-hotness. Telemetry: forward-select signals in waveform. Recover: add/fix forwarding path. Debug: trace producer/consumer cycles in GTKWave.
A taken branch/jump flushes exactly the wrong-path instructions (IF/ID and ID/EX), no more, no less. Why: control-hazard correctness. Where: branch_unit + hazard flush. Detect: wrong instruction retires after a branch (differential). Telemetry: flush signal + redirected PC. Recover: fix flush mask/timing. Debug: branch-redirect waveform.
Loads complete before a dependent instruction reads the loaded register (load-use stall inserted). Why: 1-cycle load latency. Where: hazard load-use detection. Detect: stale value read after a load (differential). Telemetry: stall signal, load-use detect. Recover: insert stall. Debug: load→use cycle trace.
Traps are precise: mepc = faulting PC, younger instructions flushed, older committed. Why: precise-exception requirement. Where: csr_file + hazard trap redirect. Detect: wrong mepc/mcause (differential vs Spike CSR). Telemetry: trap event (cause, epc, tval). Recover: fix commit-point/flush. Debug: trap-entry waveform + Spike CSR diff.
mret restores mstatus.MIE from MPIE and resumes at mepc. Why: trap-return semantics. Where: csr_file. Detect: wrong resume PC or interrupt-enable state. Telemetry: mret event, mstatus before/after. Recover: fix mstatus-stack logic. Debug: nested-trap test trace.
Wishbone handshake is well-formed: every cyc&stb is eventually ack'd (or err); no stuck cycles. Why: bus liveness. Where: wb_fabric + slaves. Detect: SVA bus-handshake property; watchdog timeout. Telemetry: bus cycle counters, stall cycles. Recover: bus reset / fix slave. Debug: bus waveform, decode-region check.
Memory accesses respect alignment; misaligned access raises the correct trap (or is handled per config). Why: ISA load/store semantics. Where: MEM-stage align/check. Detect: misaligned address without trap (differential). Telemetry: misaligned-access counter, trap cause. Recover: raise trap. Debug: address LSBs vs access size in trace.
Only one source drives the regfile write port per cycle (single writer). Why: structural correctness. Where: WB stage. Detect: SVA single-writer; X on regfile if multi-driven. Telemetry: write-enable + rd. Recover: fix writeback mux. Debug: writeback-control waveform.
No X (unknown) in architectural state after reset deassertion. Why: determinism, sim/FPGA parity. Where: global SVA. Detect: assert (!$isunknown(state)). Telemetry: X-origin (first offending signal). Recover: add reset value. Debug: trace X back to its source signal.
Illegal instructions raise the illegal instruction trap with mtval=the bad insn. Why: ISA robustness. Where: decoder illegal flag + csr_file. Detect: undecoded opcode doesn't trap (differential/fuzz). Telemetry: illegal-insn counter, mtval. Recover: trap. Debug: opcode vs decode table.
