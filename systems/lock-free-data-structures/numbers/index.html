35. Back-of-Envelope Capacity Model

All numbers chain from §4's constraint table.

  1. Peak aggregate throughput: 20M ops/s/core (uncontended Vyukov, §4) × 16 cores = 320M ops/s aggregate ceiling before contention-scaling loss.
  2. Contention-adjusted throughput at 16 threads: 320M × 60% linear-scaling floor (§4 contention-scaling row) = 192M ops/s realistic ceiling for the Vyukov ring.
  3. Michael–Scott contention-adjusted throughput: 320M × 40% (MS's lower scaling floor, §4) = 128M ops/s ceiling.
  4. Per-instance fixed memory: 256 B metadata (I11 padding) × 1 instance = 256 B floor regardless of workload — the number every sharded-instance count multiplies.
  5. Hazard-pointer memory ceiling per thread: 4 slots (I8 default) × 8 B/pointer = 32 B/thread fixed hazard-slot memory, independent of live-node count.
  6. Hazard-pointer memory ceiling, fleet-wide: 32 B/thread × 64 threads (§4 max tested concurrency) = 2,048 B (2 KB) fleet-wide fixed hazard overhead at max tested concurrency.
  7. Retire-list worst-case retained memory (hazard): 64-op threshold (§15.2) × average node size (assume 32 B payload + 16 B header = 48 B) = 3,072 B (3 KB) worst- case per-thread retained-but-unreclaimed memory before a scan triggers.
  8. Epoch retained memory (2-epoch lag): assume 10K retires/sec sustained × epoch duration ~1 ms (a fast-advancing epoch under low starvation) × 2 epochs lag = 20 retained objects × 48 B = 960 B typical retained-bag size — far below the hazard worst case (7), which is exactly ADR-02's bounded-vs-unbounded tradeoff made numeric.
  9. ABA tag-wrap time-to-exhaustion: 2¹⁶ (default 16-bit tag, §4 ABA-window row) ÷ 10M CAS/s sustained on one word = 6.55 ms to wrap at extreme sustained contention — the exact number behind T8's mitigation trigger (32-bit tag gives 2³² ÷ 10M = 429 s, i.e. ~7 minutes, a three-orders-of-magnitude safety margin).
  10. Cache-line padding overhead at scale: 256 B/instance (4) × 1M concurrent instances (a hypothetical cache-serving fleet) = 256 MB aggregate fixed overhead — the number that justifies NOT padding every field indiscriminately, only the hot head/tail pair (I11's scope is deliberately narrow).
