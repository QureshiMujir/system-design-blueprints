⬜ Phase 4 — Core dispatch algorithm (capture / at-target / bubble) §16

Objectives
  • Implement evt-dispatch::dispatch<T: EventTarget>(target, event, legacy_target_override) -> bool returning !CANCELED.
  • Drive 3 phases over the Phase-3 path: CapturingPhase (root→target, exclusive), AtTarget, BubblingPhase (target→root, only if event.bubbles).
  • Spec invoke+inner_invoke with listener snapshot: mid-dispatch adds excluded; removed skipped; once removed from real list before callback.
  • Entry: set DISPATCH + event.target. Per step: mutate current_target/event_phase. Exit: reset both to None.
  • Scope = ordering + phase walk + snapshot only. Out of scope: stop*/preventDefault/passive (P5), signal removal (P7), retargeting/closed-tree gates (P8), activation (P9). At-target retarget = identity; honor shadow_adjusted_target if present.
  • Constraint: callbacks RE-ENTER (add/remove/nested dispatch) → never hold live borrow of listeners() across a callback.
Deliverable
  • evt-dispatch compiles no_std + alloc; dispatch callable from evt-dom nodes.
  • Fixture suite (5.5) green: capture/at-target/bubble ordering, cap+non-cap at target in registration order, bubbles=false truncation, once, mid-dispatch add ignored.
  • domevt dispatch --trace prints full per-step invocation order for a loaded tree.
Acceptance
  • 100% Phase-4 fixtures pass; observed listener call sequence == golden ordered list.
  • Post-dispatch: current_target == None, event_phase == None, DISPATCH cleared.
  • Capturing visits exactly target_index items; bubbling visits len - target_index - 1 (0 if !bubbles).
  • dispatch return == !event.flags.contains(CANCELED) (P4: always true).
  • Perf: depth-16 path, ≤4 listeners/node → ≤6 µs median, ≤25 µs p99; allocs ≤ 1 snapshot Vec/visited target.
  • miri clean; zero RefCell borrow panics under re-entrant fixtures.

⬜ Phase 5 — Propagation control and cancelation §17

Objectives
  • Three propagation/cancel controls on Event vs EventFlags: stop_propagation (STOP_PROPAGATION), stop_immediate_propagation (STOP_IMMEDIATE_PROPAGATION), prevent_default (CANCELED).
  • Wire flag reads into inner_invoke (per-listener gate) + invoke/dispatch (per-path-item gate) → short-circuit Phase 4 walk; defaultPrevented returns CANCELED.
  • Passive guard: prevent_default sets CANCELED iff cancelable && !IN_PASSIVE_LISTENER; else no-op + diagnostic.
  • DISPATCH re-entrancy gate in dispatch: mid-dispatch event → EventError::AlreadyDispatching; no INITIALIZED → EventError::Uninitialized.
  • Constraints: no new path computation (Phase 3/4 path final); flags append-only within one dispatch; controls idempotent; nested dispatch of a different event legal.
  • Excludes: activation/legacy_canceled_activation_behavior (Phase 9), signal-driven removal (Phase 7), trusted gate (Phase 10).
Deliverable
  • evt-dispatch compiles with dispatch → Result<bool, EventError>; stop_propagation/stop_immediate_propagation/prevent_default/default_prevented callable from any listener mid-dispatch.
  • domevt dispatch --trace emits post-stop truncation + CANCELED outcome; passive prevent_default shows diagnostic line.
  • Measurable: per-listener flag-check overhead, flag-clear cost at dispatch end, re-entrancy error returns in O(1).
