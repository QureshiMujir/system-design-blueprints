3. Architectural Overview

Show the original text diagram

        |  trusted events: queue a task               |  synthetic events: .dispatchEvent (synchronous)
        v                                             |
 evt-loop : EventLoop · TaskQueue[source] · microtask checkpoint · trusted-event gate · fire_event
        |  run a task -> dispatch                      |
        v                                             v
 evt-dispatch : dispatch() · capturing/at-target/bubbling · invoke · inner_invoke · stop/cancel/passive · activation
    |  build path                                     |  read/snapshot listeners
    v                                                 v
 evt-path : EventPathItem · get_the_parent · retarget · composed_path     evt-core : Event · EventFlags · EventListener · EventTarget
    |  walk tree (+ shadow/slot)                       ^  signal aborts -> remove listener
    v                                                 |
 evt-dom : Node arena · element/text/shadow-root/slot · impl EventTarget   evt-signal : AbortController/AbortSignal

 ====================================================================================================
 TRUST BOUNDARY (everything below Host is untrusted-input territory):
   · untrusted tree         — get_the_parent may form deep/degenerate/cyclic-shaped ancestor chains
   · untrusted listeners     — CallbackRef RE-ENTERS the API mid-dispatch (add/remove, nested dispatch)
   · adversarial events      — uninitialized / already-dispatching / mismatched bubbles·cancelable·composed
 CONCURRENCY BOUNDARY:
   · Event + listener lists are !Send by design (Rc + RefCell) — ONE event loop per thread
   · dispatch is SYNCHRONOUS + single-threaded; no internal locks; cross-thread strictly via channels
 PERSISTENCE BOUNDARY:
   · NONE at runtime — all state (path, flags, queues, signals) is in-memory + per-dispatch/per-tick;
     only evt-cli serializes scenario fixtures (load) + trace output off the hot path
 ====================================================================================================

Layering: Host -> evt-loop -> evt-dispatch -> {evt-path, evt-core}; evt-dom realizes evt-core's EventTarget under evt-path; evt-signal feeds listener teardown sideways into evt-core's listener list. Edges acyclic; only evt-dom/evt-loop/evt-cli link std, rest is no_std + alloc.

3.1 evt-loop

Minimal HTML-style scheduler. Responsibilities: per-TaskSource TaskQueues (Dom, UserInteraction, Networking, Timer), one microtasks queue, perform_microtask_checkpoint, host-driven tick, trusted-event gate, fire_event (UA-originated). In: host queue_task/queue_microtask + a chosen Task. Out: synchronous dispatch on a target. Invariant: task runs to completion, THEN one microtask checkpoint fully drains microtasks (incl. re-entrant enqueues) before next task/render; fire_event is the ONLY producer of is_trusted = true. Referenced by: Phase 10 (## 22) primarily; gate consumed by Phase 11/12 trusted-event tests.

3.2 evt-dispatch

Dispatch state machine. Responsibilities: dispatch() driving CapturingPhase -> AtTarget -> BubblingPhase, invoke/inner_invoke, listener snapshotting, once pre-removal, stop_propagation/stop_immediate_propagation/canceled handling, passive preventDefault guard, activation-behavior + legacy_pre_activation_behavior/legacy_canceled_activation_behavior hooks. In: (&T: EventTarget, &mut Event, legacy_target_override). Out: bool = !canceled (defaultPrevented); Event flags + current_target/event_phase mutated then reset (currentTarget=null, eventPhase=None). Invariant: path computed ONCE at start; inner_invoke iterates a SNAPSHOT (mid-invoke adds never run, removed skipped, once removed before callback); DISPATCH flag rejects re-entrant dispatch of SAME event (AlreadyDispatching) but permits nested dispatch of OTHER events. Referenced by: Phases 4–5 (## 16–17) core; extended by 9 (activation), 10 (loop-driven), 12 (conformance/fuzz).

3.3 evt-path

Propagation-path computation. Responsibilities: build Vec<EventPathItem> via get_the_parent walk, retarget(a,b), composed_path, shadow-including ancestor traversal, slot/slottable handling, related-target + touch-target retargeting. In: build_event_path(&target, &event) over a tree + event's composed flag. Out: ordered path (root..target) of EventPathItem carrying shadow_adjusted_target, related_target, touch_target_list, root_of_closed_tree, slot_in_closed_tree. Invariant: encapsulation — exposed target for item w/ invocation target A + cross-tree B is retarget(B, A); non-composed events truncate path at nearest shadow-including root containing target; composed_path() filters by closed-tree visibility relative to currentTarget. Referenced by: Phase 3 (## 15) flat tree; Phase 8 (## 20) shadow retargeting; reused by 4/12.

3.4 evt-core

Normative type layer. Responsibilities: Event, EventPhase, EventFlags, EventListener + AddEventListenerOptions/EventListenerOptions, EventTarget trait (listener registry + get_the_parent + activation hooks), CallbackRef, EventInit dictionaries, Atom (interned type), EventError, add_event_listener/remove_event_listener. In: target + (ty, CallbackRef, opts). Out: mutations to a ListenerListRef; constructed/initialized Events. Invariant: listener dedup key is (type, callback identity, capture) — duplicate add is a no-op; passive/once/signal NOT part of key; preventDefault sets CANCELED only when cancelable && !IN_PASSIVE_LISTENER. Referenced by: every crate + phase; established in Phases 0–1 (## 12–13), extended for options in Phase 6 (## 18).

3.5 evt-signal

Abort integration. Responsibilities: AbortController + AbortSignal (aborted, reason, abort_algorithms, source_signals/dependent_signals), abort, timeout, any, throw_if_aborted, follow relationship, addEventListener's signal option. In: a signal handed to a listener add, or host abort/timeout trigger. Out: abort algorithms that REMOVE the associated listener from its list. Invariant: firing once sets aborted + reason permanently and runs each abort algorithm at most once; dependent signals (any) abort exactly when any source_signals member aborts; weak refs prevent controller<->signal cycle leaks. Referenced by: Phase 7 (## 19); aborts exercised under re-entrancy in Phases 5/12.

3.6 evt-dom

Concrete reference tree. Responsibilities: Node arena (document, element, text, shadow root, slot) impl EventTarget + tree hooks; open/closed shadow trees (ShadowMode); slot assignment. In: programmatic tree construction + listener registration via NodeRef. Out: a host tree whose get_the_parent drives evt-path. Invariant: flat tree honors slot assignment + shadow encapsulation so retargeting/composedPath are deterministic + spec-faithful; only std-linked tree backing tests, CLI, conformance, fuzzing. Referenced by: Phase 2 (## 14) flat tree; Phase 8 (## 20) shadow/slots; test/conformance substrate for Phases 4–12.

3.7 evt-cli

The domevt binary. Responsibilities: subcommands load, listen, dispatch, trace, bench over an evt-dom tree. In: scenario fixtures + CLI args. Out: dispatch results, per-step propagation traces, benchmark numbers. Invariant: thin host driving public API only (no privileged internals); all serialization off the dispatch hot path. Referenced by: Phase 12 (## 24) for differential traces + benchmarks; usable as debugging harness from Phase 4 onward.

8. Domain Model — DOM Events, Dispatch, and Retargeting

Normative core: target + event ⇒ which listeners run, in what order, what propagates, is default action prevented. Types from evt-core/evt-path/evt-dispatch; algorithms dispatch, invoke, inner invoke, retarget, event path.

8.1 Event object model

Event (module event, evt-core) — fields + provenance:

Field Type Semantics Mutability after dispatch start
ty Atom interned type; dedup key component init; immutable
target Option<OpaqueTarget> dispatch origin (post-retarget per item, shadow_adjusted_target) set by dispatch
related_target Option<OpaqueTarget> e.g. mouseout peer; retargeted per path item set at init
current_target Option<OpaqueTarget> node whose listeners run now; None outside dispatch per step
event_phase EventPhase state machine §8.3; None outside dispatch per step
flags EventFlags bitflags §8.2 per algorithm
bubbles cancelable composed bool gate bubbling / preventDefault / shadow crossing init; immutable
is_trusted bool UA-created ⇒ true; script dispatchEvent ⇒ false (§8.7) set by creator
time_stamp f64 monotonic ms at creation init; immutable
path Vec<EventPathItem> computed ONCE at dispatch start (§8.4) built by dispatch

defaultPrevented ≡ CANCELED ∈ flags. composedPath() ≡ composed_path(event, current_target) (§8.4/§8.6).

8.2 EventFlags state table

bitflags EventFlags — set-by / cleared-by are the ONLY transitions:

Bit Meaning Set by Cleared by
INITIALIZED initialize/ctor ran; required to dispatch ctor, init_event never (re-init keeps it)
DISPATCH mid-flight; re-entry guard dispatch entry dispatch exit (incl. early return)
STOP_PROPAGATION skip subsequent path items stopPropagation dispatch start (per dispatch)
STOP_IMMEDIATE_PROPAGATION skip remaining listeners on current target (+ implies stop) stopImmediatePropagation dispatch start
CANCELED default action prevented preventDefault iff cancelable & ¬IN_PASSIVE_LISTENER dispatch start
IN_PASSIVE_LISTENER current listener passive ⇒ preventDefault no-op inner_invoke before passive cb inner_invoke after that cb
COMPOSED mirror of composed; path may cross shadow roots ctor from EventInit.composed never

Invariant: STOP_IMMEDIATE_PROPAGATION ⇒ STOP_PROPAGATION enforced at read sites (check both). IN_PASSIVE_LISTENER strictly scoped to one callback frame.

8.3 Dispatch algorithm + EventPhase state machine

dispatch<T: EventTarget>(target, event, legacy_target_override) -> bool (returns !canceled). Ordered steps:

D1  if ¬INITIALIZED        -> Err(Uninitialized)            // throws
D2  if DISPATCH            -> Err(AlreadyDispatching)       // InvalidStateError
D3  set DISPATCH; clear STOP_PROPAGATION|STOP_IMMEDIATE_PROPAGATION|CANCELED
D4  event.target = target.opaque() (or override); is_trusted unchanged
D5  event.path = build_event_path(target, event)           // §8.4, ONCE
D6  legacy_pre_activation_behavior() on activation target if any
D7  CAPTURING: for item in path[root .. target)  (top-down, EXCLUDE target)
        if STOP_PROPAGATION break;  invoke(item, event, CapturingPhase)
D8  AT_TARGET: invoke(target_item, event, AtTarget)        // unless STOP_PROPAGATION
D9  BUBBLING: if event.bubbles: for item in path(target .. root]  (bottom-up, EXCLUDE target)
        if STOP_PROPAGATION break;  invoke(item, event, BubblingPhase)
D10 event_phase = None; current_target = None
D11 if CANCELED: legacy_canceled_activation_behavior() else activation_behavior()(event)
D12 clear DISPATCH; return ¬CANCELED

invoke(item, event, phase): set current_target = item.invocation_target; compute exposed target/related_target via item's shadow_adjusted_target/related_target; select listeners matching phase (capture-flag ⇔ Capturing; AtTarget runs both in registration order); inner_invoke.

inner_invoke(event, listeners, phase) -> bool: iterate a SNAPSHOT of listeners; per listener: skip if removed; skip if capture-flag mismatches phase (except AtTarget); if once remove from REAL list before calling; set IN_PASSIVE_LISTENER iff passive; run callback; clear IN_PASSIVE_LISTENER; if STOP_IMMEDIATE_PROPAGATION return early.

EventPhase transition table (None=0,Capturing=1,AtTarget=2,Bubbling=3):

From Trigger To
None dispatch D7, path has pre-target items CapturingPhase
None D7 empty (target is root) → D8 AtTarget
CapturingPhase path exhausted above target → D8 AtTarget
CapturingPhase STOP_PROPAGATION set (jump) AtTarget? no — D8 guarded; effectively None at D10
AtTarget D9, bubbles true BubblingPhase
AtTarget bubbles false OR STOP_PROPAGATION None (D10)
BubblingPhase path exhausted OR STOP_PROPAGATION None (D10)

Note: AtTarget always runs unless STOP_PROPAGATION set during capturing; event_phase is AtTarget while target listeners run regardless of capture flag.

8.4 Listener list, get_the_parent, EventPathItem

EventTarget trait (evt-core): listeners() -> ListenerListRef (shared-mutable Rc<RefCell<Vec<EventListener>>>), get_the_parent(&self,&Event) -> Option<Self>, activation_behavior(), opaque().

EventListener fields: ty:Atom, callback:CallbackRef, capture:bool, passive:Option<bool>, once:bool, signal:Option<AbortSignalRef>, removed:bool. Dedup key = (ty, callback identity, capture); duplicate add = no-op; passive/once/signal excluded from key.

get_the_parent: flat-tree parent during dispatch — element→parent node; slotted node's parent is its assigned slot; shadow root's parent is its host iff event composed or current target is the shadow root (else None, truncating path); Document→None.

build_event_path(target, event): walk get_the_parent target→root, one EventPathItem per node (target first, root last); per item compute shadow_adjusted_target, related_target (via retarget), closed-tree gate bits.

EventPathItem fields:

Field Type Meaning
invocation_target OpaqueTarget node whose listeners run here (current_target)
invocation_target_in_shadow_tree bool target lies inside a shadow tree
shadow_adjusted_target Option<OpaqueTarget> exposed event.target here (None ⇒ unchanged); Some only at shadow-tree boundaries
related_target Option<OpaqueTarget> exposed relatedTarget after retarget(orig, invocation_target)
touch_target_list Vec<Option<OpaqueTarget>> each touch target retargeted against invocation_target
root_of_closed_tree bool item is root of a CLOSED shadow tree
slot_in_closed_tree bool item is a slot inside a closed shadow tree

retarget(a, b) -> OpaqueTarget: while a's root is a shadow root AND b not a shadow-including inclusive descendant of a's root → a = a.root.host; return a. Encapsulation: closed internals never leak as target/relatedTarget.

8.6 Sequence diagram — capture → at-target → bubble with stopPropagation

Flat path document → div#app → button#btn; listeners: div capture C, div bubble B, btn AtTarget T1,T2 (T1 calls stopPropagation). bubbles=true.

phase        currentTarget   listeners run          flags after
Capturing -> document        (none)
Capturing -> div#app         C                      -
AtTarget  -> button#btn      T1 (stopPropagation)   STOP_PROPAGATION
AtTarget  -> button#btn      T2  (still runs)       STOP_PROPAGATION
Bubbling     div#app         SKIPPED (STOP_PROP)    -> break
Bubbling     document        SKIPPED
END          null/None       activation_behavior()  (CANCELED? no)

stopPropagation does NOT halt remaining listeners on current target (T2 runs); only stopImmediatePropagation skips T2. Subsequent path items (bubbling div,document) skipped.

8.7 Worked example — click on slotted closed-tree element; composed true vs false

Target #btn in SR_c (closed); currentTarget queried at two points. Path = §8.5 list.

composed = true: path spans btn .. document (host hop at SR_c allowed because composed). composedPath() filters by closed-tree visibility relative to currentTarget:

currentTarget visible items (composedPath() output) hidden because
document (outside all shadows) [x-outer, div#app, document] root_of_closed_tree(SR_c) hides items 0–1; closed slot/host of x-inner collapse to x-outer exposure
btn (inside closed SR_c) [btn, SR_c, x-inner, slot#so, section, SR_o, x-outer, div#app, document] caller inside closed tree ⇒ full path visible

composed = false: get_the_parent returns None at SR_c (host hop denied) ⇒ path truncated at the shadow-including root containing target: path = [btn, SR_c]. Dispatch never reaches x-inner/document; composedPath() from document = [] (document not on path); from btn = [btn, SR_c].

8.8 Malformed / edge cases — exact results

Scenario Exact result
dispatch event without INITIALIZED Err(EventError::Uninitialized) at D1; no path built, no listeners run
re-dispatch in-flight event (DISPATCH set) Err(EventError::AlreadyDispatching) (InvalidStateError) at D2; original dispatch unaffected
preventDefault inside passive listener (IN_PASSIVE_LISTENER) no-op; CANCELED NOT set; emit one diagnostic (passive preventDefault ignored); defaultPrevented stays false
preventDefault when ¬cancelable no-op silently; CANCELED not set
remove currently-running listener (self-remove) sets removed=true on REAL list; current inner_invoke SNAPSHOT still holds it but it already ran; future items skip it
add listener during dispatch (same current_target, same phase) NOT called this invoke (snapshot at invoke entry); eligible on later path items / later dispatches
add a once listener that fires removed from real list BEFORE its callback runs (fires exactly once even if it self-dispatches)
AbortSignal aborts mid-dispatch abort algorithm runs remove_event_listener → sets removed=true; if its invoke snapshot already started, skipped only if not yet reached; subsequent items never call it
nested dispatch of a DIFFERENT event from a callback allowed; inner dispatch gets own DISPATCH flag + own path; outer resumes after
nested dispatch of the SAME event from a callback Err(AlreadyDispatching) (its DISPATCH still set)
stopImmediatePropagation in first AtTarget listener remaining AtTarget listeners skipped; bubbling skipped; event_phase=None at D10
empty path (target == root, no parent) only AtTarget runs; no capturing/bubbling items
