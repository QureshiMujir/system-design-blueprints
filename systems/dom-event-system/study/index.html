33. Mental Models & First Principles

The compressed insights a principal engineer holds about DOM event dispatch. Each: the model, what it lets you predict, the bug class you write without it, and the resolving section reference.

MM1 — The path is a frozen filmstrip, read three ways. build_event_path shoots one strip of EventPathItems root→target ONCE; capturing plays it forward (root→target), at-target is one frame, bubbling plays it backward (target→root). Predicts: tree mutation mid-dispatch never adds/removes a frame; composedPath() is the same strip re-filtered, never re-walked. Without it: you re-walk get_the_parent per phase → O(depth²), and listeners on moved/detached nodes get the wrong (in)visibility. Resolves: §6.3, §8.4, INV-01 (Phase 3, §15).

MM2 — inner_invoke iterates a photograph, not the live list. At invoke entry you clone the listener list into a snapshot, drop the borrow, then call. Adds during the call land in the live Vec (not the photo); removals flip a removed tombstone the photo re-checks; a once listener is torn out of the live list before its callback so a nested same-type dispatch can't re-find it. Predicts: exactly which mutations are visible this pass vs deferred. Without it: iterator-invalidation UB, infinite self-feeding loops, once double-fire under re-entrancy. Resolves: §6.9, §6.10, §8.3, INV-02/03 (Phase 4, §16).

MM3 — retarget(B, A) is a one-way mirror at every shadow boundary. Standing at invocation target A, any cross-tree node B you'd expose is first climbed to the nearest ancestor A is allowed to see. Closed internals are behind the mirror; you only ever see the boundary host. Predicts: arg order is load-bearing — retarget(B, A), never retarget(A, B); relatedTarget and every touch target get the same treatment per item. Without it: a light-DOM listener reads closed-shadow node identities — a privacy/security leak (the gravest failure, F6). Resolves: §6.4, §8.4, §8.5, INV-08 (Phase 8, §20).

MM4 — composed is the boundary's one-bit passport; absence truncates the trip. A composed event's path crosses shadow roots via the host hop; a non-composed event's get_the_parent returns None at the shadow-including root, so the path simply ends there. Predicts: a non-composed event physically cannot reach a listener above its own shadow root; composedPath() from outside that tree is empty. Without it: you append the host anyway and fire listeners that spec says never run. Resolves: §6.3, §8.7, INV-09 (Phase 8, §20).

MM5 — Flags are the only state; currentTarget/eventPhase are scratch. Seven EventFlags bits + the phase enum are the dispatch state machine; currentTarget/eventPhase are set per step and MUST reset to null/None at every exit. defaultPrevented is literally CANCELED ∈ flags; DISPATCH is the re-entrancy interlock. Predicts: a single RAII drop-guard clearing these covers every return path (normal, stop, Err, panic-unwind). Without it: leaked currentTarget after dispatch, missing re-entrancy guard, ad-hoc booleans that disagree across call sites. Resolves: §6.16, §8.2, INV-06/07 (Phase 5, §17).

MM6 — passive trades cancelability for a parallel compositor. A passive listener's preventDefault is a deliberate no-op so the compositor scrolls without awaiting the main thread. The contract is one-directional: IN_PASSIVE_LISTENER set ⇒ cancel suppressed, never the reverse. Predicts: default-passive types (touchstart/touchmove/wheel/mousewheel on roots) start passive precisely to keep scroll off the JS critical path. Without it: a passive handler that "cancels" silently blocks scroll, or you honor a cancel you must ignore — the jank passive exists to prevent. Resolves: §6.5, §8.8, INV-05 (Phase 6, §18).

MM7 — A task is a turn; the microtask checkpoint is the turn's settling. One task runs to completion, then the checkpoint drains all microtasks (including those they enqueue) before the next task or render. The checkpoint is non-re-entrant: a microtask requesting another checkpoint enqueues, it does not nest. Predicts: the exact ordering of await, queueMicrotask, MutationObserver, promise jobs relative to events. Without it: promise/microtask ordering diverges from every browser — async-timing bugs that only bite between events. Resolves: §6.14, INV-10 (Phase 10, §22).

MM8 — Trust is conferred by the door you entered, not the claim you make. isTrusted=true is set by exactly one authority (fire_event); script's dispatchEvent is structurally incapable of forging it (private field, crate-sealed). Predicts: synthetic input can never trip a UA-only default action gated on isTrusted. Without it: click-jacking / synthetic-input defenses collapse — a privilege-escalation class. Resolves: §6.8, INV-11 (Phase 10, §22).

MM9 — The engine bounds itself, never the callback. A CallbackRef is opaque host code that may loop forever or recurse; the engine cannot preempt it, so it instead caps its own resources — path depth, listeners/target, nested-dispatch depth, microtask budget — and turns every breach into a defined EventError/no-op, never a panic or UB. Predicts: a pathological tree or listener-bomb degrades to a diagnostic, the host keeps running. Without it: stack overflow / OOM from untrusted input — a remote-DoS surface. Resolves: §6.11, §4.3, Threat Model T1/T3/T7 (Phase 12, §24).

MM10 — Identity, not structure, crosses every boundary. OpaqueTarget and CallbackRef compare by identity only; they are the sole tokens that cross the host↔engine and shadow boundaries, and they never deref to host internals. Predicts: the dedup key works (CallbackRef identity), path equality is cheap, and no Rc/raw pointer leaks heap layout to script. Without it: dedup misfires on cloned closures, or you leak ASLR-defeating pointers as targets. Resolves: §6.6, §6.12, ADR-09, ADR-06 (Phase 1, §13).

Glossary (§39) · 48 terms · site-wide glossary

event target
Object that can have an event listener registered + be a dispatch target. Modeled by trait EventTarget; each impl owns a listener list + supplies get_the_parent. evt-dom NodeRef is the reference impl.
event listener
Registration record EventListener { ty: Atom, callback: CallbackRef, capture, passive: Option<bool>, once, signal, removed }. Lives in the listener list. Invoked by inner_invoke when type+phase match.
listener list
Per-event target ordered list (ListenerListRef, Rc<RefCell<…>>) of EventListeners, in registration order. Shared-mutable: callbacks may add/remove mid-dispatch.
capture / capturing phase
EventPhase::CapturingPhase = 1. Path walked ROOT→target (excluding target); only capture=true listeners run.
at-target
EventPhase::AtTarget = 2. Target's own listeners run in registration order, capture + non-capture together.
bubbling phase
EventPhase::BubblingPhase = 3. Path walked above-target→ROOT; only capture=false listeners run; entered only if event.bubbles.
propagation path / event path
Ordered Vec<EventPathItem> from target up to ROOT, computed ONCE at dispatch start by build_event_path. Drives all three phases.
composed path
composed_path(event, current) -> Vec<OpaqueTarget>: the saved path filtered by closed-tree visibility relative to currentTarget. Backs composedPath().
get the parent
EventTarget::get_the_parent(&self, &Event) -> Option<Self>: returns the next ancestor for path building (flat tree; slot for slottables).
dispatch
dispatch(target, &mut Event, legacy_target_override) -> bool (!canceled). The capture→at-target→bubble state machine; sets/clears the DISPATCH flag, currentTarget, eventPhase.
invoke
invoke(item, &mut Event, phase): per-EventPathItem step. Sets currentTarget = item target + shadow_adjusted_target/related_target, then calls inner_invoke. Spec "invoke".
inner invoke
inner_invoke(&mut Event, &[EventListener], phase) -> bool: iterates a SNAPSHOT of the list; skips removed; removes a once listener BEFORE its callback; honors stop-immediate.
retargeting
retarget(a, b) -> OpaqueTarget: spec "retarget"; computes the target of a relative to b so closed-shadow internals don't leak across boundaries.
shadow-adjusted target
EventPathItem.shadow_adjusted_target: the target value exposed while currentTarget is at this item, after retargeting. None ⇒ skip the item's at-target exposure.
related target
Event.related_target / EventPathItem.related_target: secondary target (e.g. mouseover). Retargeted per path item via retarget(B, A).
slottable / slot
Slottable = a node assignable into a <slot>. Slot = the shadow-tree insertion point; a slottable's get_the_parent yields its assigned slot.
assigned slot
The slot a slottable is assigned to; inserted into the flat-tree path so distributed nodes propagate through their host's shadow tree.
open vs closed shadow tree
ShadowMode::{Open, Closed}. Open ⇒ retargeting still applies but internals are inspectable; Closed ⇒ path items flagged root_of_closed_tree/slot_in_closed_tree and hidden from composed_path.
shadow-including root
The topmost root reachable by crossing shadow boundaries. Non-composed events truncate their path at the nearest shadow-including root containing the target.
composed flag
EventFlags::COMPOSED (init from Event.composed). True ⇒ event crosses shadow boundaries; false ⇒ path truncated at the host's shadow root.
stop propagation flag
EventFlags::STOP_PROPAGATION. Set by stopPropagation(); halts subsequent EventPathItems (current item's remaining listeners still run).
stop immediate propagation flag
EventFlags::STOP_IMMEDIATE_PROPAGATION. Set by stopImmediatePropagation(); halts the current target's remaining listeners AND later path items.
canceled flag
EventFlags::CANCELED. Set by preventDefault() iff cancelable && !IN_PASSIVE_LISTENER. Equals defaultPrevented; suppresses the default action.
default action
Host-defined behavior after dispatch when not canceled (e.g. link navigation). Realized via activation behavior.
activation behavior
ActivationBehavior host hook (fn(&Event)) returned by EventTarget::activation_behavior; runs post-dispatch on the activation target unless canceled. Drives click().
legacy-pre-activation behavior
EventTarget::legacy_pre_activation_behavior: runs BEFORE dispatch for legacy controls (e.g. checkbox toggle); paired with legacy_canceled_activation_behavior to undo if canceled.
passive listener
Listener with passive == Some(true). During its invoke IN_PASSIVE_LISTENER is set; preventDefault() becomes a no-op (emit diagnostic).
default-passive
Event types defaulted to passive (e.g. touch/wheel scroll types) when passive is unspecified (None); resolves passive to true for those types.
once listener
Listener with once == true; removed from the real listener list before its callback runs, so it fires at most once.
AbortSignal
AbortSignal { aborted, reason, abort_algorithms, source_signals, dependent_signals } (AbortSignalRef). The signal option ties a listener's lifetime to it; abort ⇒ remove listener.
abort algorithm
A callback in AbortSignal.abort_algorithms; run once when the signal aborts. Used to deregister listeners registered with that signal.
dependent signal
A signal in dependent_signals derived via AbortSignal::any / ::timeout; aborts when any source_signals member aborts (weak refs avoid cycles).
trusted event / isTrusted
Event.is_trusted. True ONLY for events evt-loop creates+dispatches (fire_event); script dispatchEvent yields false. The trusted-event gate enforces this.
synthetic event
A script-created event dispatched synchronously via dispatchEvent; is_trusted == false. Contrast trusted event.
task source
TaskSource::{Dom, UserInteraction, Networking, Timer}: labels a Task; selects which task queue it enters.
task queue
EventLoop.task_queues: Map<TaskSource, VecDeque<Task>>. Per-source FIFO; one Task runs to completion per tick.
microtask
A Task on EventLoop.microtasks; queued via queue_microtask; drained at the microtask checkpoint, may enqueue more.
microtask checkpoint
perform_microtask_checkpoint: drains microtasks to empty after each task / before next render; guarded by performing_checkpoint against re-entry.
event loop
EventLoop: owns task queues + microtask queue; tick runs one task then a checkpoint; fire_event dispatches a trusted event synchronously within a task.
currentTarget
Event.current_target: the event target whose listeners are running this invoke. None outside dispatch.
eventPhase
Event.event_phase: EventPhase. None outside dispatch; set per phase during dispatch.
defaultPrevented
Boolean view of the canceled flag; dispatch returns !defaultPrevented.
OpaqueTarget
Identity-only handle to an event target stored in Event/EventPathItem (avoids generic infection of the path); resolved by the host.
CallbackRef
CallbackRef: opaque host handle to a callable listener; equality by identity (used in the dedup key); engine never introspects it.
Atom
Interned event-type string in evt-core; O(1) equality for type matching in inner_invoke and the dedup key.
EventError
