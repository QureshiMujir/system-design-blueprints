⬜ Phase 1 — Core statevector + indexing + invariants

Objectives

Define StateVector (contiguous Vec<Complex64>, length 2ⁿ), the little-endian indexing convention (P2), |0…0⟩ initialization with a RAM-budget check (I10, P4), normalization invariant (I1), inner products, and the error hierarchy. Everything else builds on this layout.

Deliverable

StateVector::zero(n) for n up to budget; norm checks; pair-index iterator validated; cargo test -p qsim-core green.

Acceptance
  • zero(n) yields amp[0]=1, rest 0, norm 1.
  • pair_indices enumerates exactly 2ⁿ⁻¹ disjoint pairs covering all indices once.
  • zero(35) with 16 GiB budget → InsufficientMemory (no alloc, I10).
  • inner(ψ,ψ)=1 for normalized states.
Fixtures
Fixture Purpose Expected
core/init_zero.json initialization amp[0]=1
core/pair_cover.json index coverage all 2ⁿ once, disjoint
core/oom_refuse.json budget guard InsufficientMemory
Pitfalls
  • 1<<n overflows usize for large n on 32-bit; require 64-bit, check n<64 and budget.
  • Off-by-one in pair iteration double-applies a gate to some amplitudes.
  • Forgetting endianness here propagates a wrong convention everywhere (P2).

⬜ Phase 2 — Single-qubit gate kernels + gate library

Objectives

Implement the strided apply_1q kernel (§8.4, P3) and the single-qubit gate catalog (X,Y,Z,H,S,T,Rx,Ry,Rz,Phase,U3) with is_unitary validation (I2, P1). First superposition (H|0⟩).

Deliverable

H(0) on |0⟩ → (|0⟩+|1⟩)/√2; all 1q gates apply; norm preserved (I1); each gate is_unitary.

Acceptance
  • H|0⟩, X|0⟩=|1⟩, Z|+⟩=|−⟩, Rz(θ) phases verified to 1e-12.
  • Norm stays 1±1e-10 after every gate (I1).
  • All built-in 1q gates pass is_unitary(1e-12) (I2).
  • Applying a gate then its adjoint returns to start (I9, P11).
Fixtures
Fixture Purpose Expected
apply/h_superposition.json H amplitudes 1/√2
apply/1q_unitary.json I2 all pass
apply/1q_reversible.json I9 round-trip 1e-9
Pitfalls
  • Reading both amps before writing either — overwriting amps[i0] then using stale amps[i1] corrupts the update.
  • Rx/Ry sign conventions (θ/2) easy to get wrong; pin to Nielsen & Chuang.
  • Float drift in repeated gates slowly erodes norm; periodic check, not per-gate renormalize.

⬜ Phase 3 — Multi-qubit + controlled gates

Objectives

Implement controlled-gate masking (§8.5, I8), two-qubit gates (CX, CZ, SWAP, iSWAP), three-qubit (CCX, CSWAP), and the general apply_kq. First entanglement (Bell, GHZ).

Deliverable

H(0);CX(0,1) → Bell Φ⁺; GHZ on 3 qubits; CX truth table verified; entangled states non-product.

Acceptance
  • Bell state amplitudes (1/√2 at |00⟩,|11⟩) to 1e-12; GHZ likewise.
  • CX truth table: |10⟩→|11⟩ etc. exact.
  • Controlled gate leaves amplitudes with control=0 unchanged (I8).
  • Random circuit ∘ adjoint = I (I9) for multi-qubit gates.

  • SWAP via apply_kq needs correct index gather order; transposed mapping silently permutes wrong qubits.

⬜ Phase 4 — Circuit IR + builder + validation

Objectives

Define the Circuit IR (Op list, registers), a fluent builder, validation (I4, P9), depth/moments, and adjoint() (for reversibility tests, I9). Decouple program construction from execution.

Deliverable

Build circuits programmatically; validate() rejects malformed circuits; depth() correct; adjoint() produces the inverse circuit.

Acceptance
  • Validation rejects OOB qubit, duplicate target/control, arity mismatch (I4).
  • depth() matches hand-computed depth on ≥5 test circuits, exact integer match.
  • circuit.adjoint() applied after circuit returns to the initial state to ≤1e-9 (I9), verified by fixture circuit/adjoint_identity.json.
  • Builder produces the same IR as the equivalent QASM, op-for-op (Phase 5 cross-check).
Fixtures
Fixture Purpose Expected
circuit/validate_oob.json I4 QubitIndex error
circuit/depth.json layering known depth
circuit/adjoint_identity.json I9 round-trip 1e-9
Pitfalls
  • Depth computation must respect that gates on disjoint qubits share a layer; naive op-count overstates depth.
  • adjoint must reverse op order AND adjoint each gate; doing one without the other is wrong.
  • Mutating a Circuit after validation can re-introduce invalid ops; validate at execution entry too.

⬜ Phase 5 — OpenQASM 2.0 subset parser

Objectives

Lex + parse an OpenQASM 2.0 subset (§8.10) into a Circuit, with precise error reporting (line/col), mapping standard qelib1.inc gates. Standard, portable circuit input.

Deliverable

Parse bell.qasm, ghz.qasm, grover.qasm, teleport.qasm into circuits equal to the builder versions.

Acceptance
  • Parsed circuits match builder-constructed equivalents op-for-op, verified by fixture qasm/bell_roundtrip.json.
  • Malformed QASM (unknown gate, missing semicolon, bad index) → QasmParse with correct line/col, verified by fixture qasm/parse_errors.json.
  • All 19 qelib1.inc subset gate names (§8.10) map to the correct Gate + params with zero unmapped names, verified by fixture qasm/qelib_gates.json.
Fixtures
Fixture Purpose Expected
qasm/bell_roundtrip.json parse correctness matches builder
qasm/parse_errors.json error reporting right line:col
qasm/qelib_gates.json gate mapping exact gates
Pitfalls
  • Floating-point param parsing (pi, expressions like pi/2) needs a small expression evaluator; many QASM files use pi.
  • Register indexing q[2] vs whole-register q (broadcast) semantics; support the indexed form, document broadcast.
  • Comment handling (//) and whitespace in the lexer.

⬜ Phase 6 — Measurement + collapse + classical registers

Objectives

Implement Born-rule measurement (§8.6, P5): marginal probabilities, shot sampling (seeded, I11), collapse + renormalization for mid-circuit measurement (I7), and classical-register binding.

Deliverable

Sample Bell state → ~50/50 |00⟩/|11⟩; mid-circuit measurement collapses + renormalizes; teleportation circuit works end to end.

Acceptance
  • Bell-state shot counts ≈ 50/50 within binomial CI; never |01⟩/|10⟩.
  • Probabilities sum to 1±1e-10 (I6); post-collapse norm 1 (I7).
  • Same seed → identical shot results (I11, P6).
  • Teleportation: measured+corrected state has fidelity 1 with the input (P7).
Fixtures
Fixture Purpose Expected
measure/bell_counts.json Born rule ~50/50, no
measure/collapse_norm.json I7 post-norm 1
measure/seed_repro.json I11 identical shots
measure/teleport.json mid-circuit + correction fidelity 1
Pitfalls
  • Sampling without rebuilding/normalizing the CDF after a collapse double-counts probability.
  • Forgetting renormalization after collapse leaves an unnormalized state → wrong subsequent gates (I7).
  • Using a global RNG breaks reproducibility (P6); thread an explicit seeded Rng.

⬜ Phase 7 — Observables + Pauli expectations

Objectives

Implement Pauli strings, weighted-sum observables (Hamiltonians), and ⟨ψ|O|ψ⟩ + variance (§8.7). The metric used to verify algorithms and to express energy.

Deliverable

⟨ZZ⟩=1 on Bell Φ⁺; ⟨X⟩=0 on |0⟩, =1 on |+⟩; Hamiltonian expectation on a test state matches hand calculation.

Acceptance
  • Pauli expectations match analytic values to 1e-12 on Bell/GHZ/product states.
  • Hamiltonian (weighted sum) expectation correct on a 3-qubit test.
  • Variance ≥ 0; zero for eigenstates of O.

Fixture Purpose Expected

⬜ Phase 8 — Statevector analysis (entanglement, fidelity)

Objectives

Implement state fidelity (global-phase-invariant, P7, I12), partial trace → reduced density matrix, von Neumann entanglement entropy, Bloch vectors, and probability tables (§8.8).

Deliverable

Bell state → S(A)=1 bit; product state → S=0; fidelity(|+⟩, global-phase·|+⟩)=1; Bloch vector of |0⟩=(0,0,1).

Acceptance
  • Entanglement entropy: Bell=1 bit, GHZ-bipartition=1 bit, product=0 (±1e-10).
  • Fidelity invariant under global phase (I12, P7).
  • RDM is Hermitian, trace 1, PSD.
  • Bloch vectors match analytic single-qubit states.
Fixtures
Fixture Purpose Expected
analysis/bell_entropy.json entanglement S=1 bit

Pitfalls
  • Partial-trace index bookkeeping for non-contiguous kept qubits is error-prone; test against analytic RDMs.
  • log(0) in entropy for zero eigenvalues; treat 0 log 0 = 0.
  • Tiny negative eigenvalues from float error; clamp to 0 before log.

⬜ Phase 9 — Performance: fusion, threading, SIMD

Objectives

Make the bandwidth-bound kernel fast: gate fusion (P8), rayon multithreading over disjoint amplitude pairs (ADR-8), optional SIMD; raise the practical qubit ceiling. GPU remains deferred.

Deliverable

Fused dense circuits run ≥2× faster than unfused; threaded apply scales near-linearly to cores; documented bandwidth model.

Acceptance
  • Fusion preserves the statevector bit-for-bit vs unfused (within float tol) — correctness first (P1).
  • Threaded result equals single-threaded within tolerance (reassociation only, ADR-26).
  • ≥2× fusion speedup on a layered circuit; near-linear thread scaling to physical cores.
  • No data races (verified under cargo test + sanitizer where available).
Fixtures
Fixture Purpose Expected
perf/fusion_equiv.json correctness matches unfused
perf/thread_equiv.json parallel correctness matches serial (tol)
bench/apply1q_scaling.json throughput near-linear
Pitfalls
  • High-bit target → large stride → poor cache locality; blocking helps.
  • Fusing across a measurement is illegal (collapse intervenes); fusion stops at measurement boundaries.
  • Threaded float reduction changes low bits → only single-build determinism, not cross-config (ADR-26).
  • False sharing at partition boundaries; align chunks.

⬜ Phase 10 — Trajectory noise (Kraus / quantum-jump)

Objectives

Add stochastic noise on the pure statevector via the trajectory (quantum-jump) method: depolarizing, amplitude damping, phase damping channels as Kraus operators applied probabilistically (§3.2 noise). Density-matrix noise stays deferred.

Deliverable

Single-qubit amplitude damping drives |1⟩→|0⟩ over trajectories; averaged expectations match analytic density-matrix results within sampling error.

Acceptance
  • Trajectory-averaged ⟨Z⟩ under amplitude damping matches the analytic decay e-curve to within ±0.01 at 95% CI over ≥3.8×10⁴ trajectories (§ Back-of-Envelope Capacity Model #12), verified by fixture noise/amp_damp_decay.json.
  • Each trajectory stays normalized to ≤1e-10 (I1/I7).
  • Seeded trajectories reproducible bit-for-bit (I11), verified by fixture noise/trajectory_repro.json.
  • Σ Kₖ†Kₖ = I to ≤1e-12 checked per channel (trace preservation), verified by fixture noise/kraus_complete.json.
Fixtures
Fixture Purpose Expected
noise/amp_damp_decay.json channel correctness analytic decay ± MC error
noise/kraus_complete.json ΣK†K=I identity
noise/trajectory_repro.json I11 identical per seed
Pitfalls
  • Forgetting to renormalize after a jump biases subsequent dynamics.
  • Branch-probability rounding can sum to ≠1; normalize the selection.
  • Confusing trajectory averaging (expectations) with a single sampled state (one realization) — document which the API returns.

⬜ Phase 11 — Conformance, hardening, fuzzing, benchmarks

Objectives

Validate against analytic results and an external reference simulator, fuzz the parser + circuit kernels, benchmark gate throughput, and harden error paths. Close or re-gate deferred features.

Deliverable

Green conformance report (Pass/Deferred per algorithm), clean fuzz over the corpus, committed benchmarks, runbooks.

Acceptance
  • Bell/GHZ/QFT/Grover/teleportation match analytic + reference within 1e-10 (global-phase-invariant).
  • Fuzz: ≥10⁶ iterations, zero panics; malformed inputs → typed errors.
  • Reversibility (I9) holds on random circuits up to n=20.
  • Benchmarks within ±20% of committed baseline.
Fixtures
Fixture Purpose Expected
conf/algorithms/*.json analytic within 1e-10
conf/reference/*.npy vs QuEST/Qiskit match (global phase)
fuzz/corpus/* robustness no panic
bench/results/*.json perf within ±20%
Pitfalls
  • Comparing raw amplitudes without removing global phase falsely fails QFT/Grover (P7); compare via fidelity or fixed-gauge.
  • Reference simulators may use big-endian qubit order; map conventions before comparison (P2).
  • Benchmark noise from turbo/threads; pin frequency + thread count.
  • Documented dispute — the classical-simulation frontier moves. Google's Sycamore result (Arute et al., Nature 572, 2019) claimed a sampling task taking the processor ~200 s would need ~10,000 years on a classical supercomputer. IBM (Pednault et al., 2019, "Leveraging Secondary Storage to Simulate Deep 54-qubit Sycamore Circuits", arXiv:1910.09534) published that an improved classical simulation using secondary storage could reproduce the task in ~2.5 days — and later tensor-network methods cut estimates further. Engineering lesson for this simulator: never hard-code a "max simulable n" as physics; the dense statevector wall is real (§ Scalability Analysis), but the classical-simulation frontier depends on method (secondary storage, tensor networks — § Alternative Architectures) and is an active research target, not a constant. A conformance claim of "no classical simulator can reproduce X" is out of scope and would be a fabrication if asserted.
