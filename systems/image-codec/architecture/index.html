Format Sniffer — reads the first 8 bytes; dispatches to PNG or JPEG parser on an exact signature/marker match; anything else is CodecError.InvalidSignature before any further read. PNG Container Parser — walks <len><type><data><crc> chunks; validates CRC-32 (I4) before returning chunk data to any consumer; enforces IHDR-first / IEND-last ordering. JPEG Container Parser — walks marker segments (SOI, APPn, DQT, DHT, SOF0/SOF2, SOS, EOI); handles byte-stuffing (0xFF 0x00) inside entropy data; validates marker length fields against remaining bytes. DecodeLimits gate — the buffer boundary: computes width × height × channels × bytes_per_sample with checked (overflow-safe) arithmetic and rejects before any pixel buffer is allocated (P1, I2, T2). Shared BitReader/BitWriter — two instances, MSB-first (JPEG) and LSB-first (DEFLATE/PNG); never interchanged (P10); both refuse to read past the declared buffer end (I3). DEFLATE Inflate — RFC 1951 LZ77 + Huffman decoder with a 32 KiB sliding window; enforces the decompression-bomb bound (I11, T3) during streaming, not after. Huffman Entropy Decoder (JPEG) — decodes DC/AC symbols via canonical codes; rejects over-subscribed tables (I5); resets DC predictors on restart markers (I8). Scanline Unfilter — applies the inverse of one of five PNG filter types per row; requires the previous row to already be materialized (I10) before Up/Average/Paeth math runs. Dequantize + Zigzag + IDCT — reverses zigzag order, multiplies by the quantization table, runs the separable inverse DCT (P4, P11). Adam7 Deinterlace — reassembles the seven interlace passes into the final scanline grid; validates per-pass geometry sums to the declared image size (I9). Chroma Upsample + YCbCr→RGB — reconstructs full-resolution chroma planes, applies the fixed-point color-space transform, clamps to the pixel format's range. ImageBuffer — the one pixel representation both pipelines converge on; the trust boundary is crossed outward here — everything downstream trusts this buffer. PNG Encoder — selects a per-scanline filter heuristically, re-filters, and re-DEFLATEs into IDAT chunks with recomputed CRC-32. JPEG Encoder — forward color transform, chroma subsample, forward DCT, quality-scaled quantization, zigzag, RLE, Huffman encode, marker assembly. Quality Metrics Harness — computes PSNR, SSIM, and bits-per-pixel between a reference and a codec-round-tripped ImageBuffer (§11, §28). CLI — imgcodec entry points wiring the above into scriptable commands; the operator-facing surface (§26).

8. Domain Model

8.1 Color transform (JPEG, JFIF convention)

Forward (RGB → YCbCr):

Y  =  0.299   R + 0.587   G + 0.114   B
Cb = -0.168736 R - 0.331264 G + 0.5     B + 128
Cr =  0.5     R - 0.418688 G - 0.081312 B + 128

Inverse (YCbCr → RGB):

R = Y                       + 1.402   (Cr - 128)
G = Y - 0.344136 (Cb - 128) - 0.714136 (Cr - 128)
B = Y + 1.772   (Cb - 128)

Fixed-point form (ADR-04): each coefficient scaled by 2^10 and rounded to an integer; multiply, sum, then arithmetic-shift right 10, matching the precision policy in P11.

8.2 Forward/inverse DCT-II, 8×8

Forward:

F(u,v) = (1/4) C(u) C(v) Σx Σy f(x,y) cos((2x+1)uπ/16) cos((2y+1)vπ/16)
C(0) = 1/√2 ;  C(k>0) = 1

Inverse:

f(x,y) = (1/4) Σu Σv C(u) C(v) F(u,v) cos((2x+1)uπ/16) cos((2y+1)vπ/16)

Separability (P4): the 2-D sum factors into an 8-point 1-D DCT applied to each row, then an 8-point 1-D DCT applied to each resulting column — 16 one-dimensional transforms per block instead of one 2-D convolution.

8.3 Quantization / dequantization and quality mapping

Fq(u,v)  = round( F(u,v) / Q(u,v) )                     [encode]
F'(u,v)  = Fq(u,v) × Q(u,v)                              [decode]
scale    = quality < 50 ? floor(5000/quality) : 200 - 2×quality
Q(u,v)   = clamp( floor((Qbase(u,v)×scale + 50)/100), 1, 255 )

quality=50 → scale=100 → Q=Qbase; quality=100 → scale=0 → Q≈1 (near-lossless); quality=1 → scale=4900 → Q saturates at 255. Monotonicity (I14) follows directly from scale being monotonic non-increasing in quality.

8.5 DC differential coding

DIFF = DC_i − DC_{i−1} (per component, reset to 0 at SOI and at every restart marker per I8). Encoded as (category, sign-magnitude bits) where category = number of bits needed to represent |DIFF| (0 for DIFF=0).

8.6 Run-length / end-of-block AC symbol structure

Each AC Huffman symbol byte = (RUNLENGTH << 4) | SIZE. RUNLENGTH = zero-run length before the next nonzero (0–15); SIZE = category of the following nonzero's magnitude. Reserved symbols: 0x00 = EOB (all remaining AC coefficients zero); 0xF0 = ZRL (16 zeros, no value, run continues).

8.7 Huffman canonical code construction

Given code-length counts L[1..16] and a value order list: assign codes in increasing length, increasing value order, each length's first code = (previous length's first code + previous length's count) << 1. No two symbols of the same length ever share a numeric code; the code-length array alone reconstructs the table (P5).

8.8 LZ77 match/literal model and DEFLATE block types

Literal: one byte, 0–255. Match: (length, distance), length ∈ [3,258], distance ∈ [1,32768]. BTYPE: 00 stored (raw, byte-aligned), 01 fixed Huffman (RFC 1951 section 3.2.6 fixed tables), 10 dynamic Huffman (tables transmitted per-block), 11 reserved/error.

8.9 PNG per-scanline filter equations (byte-wise, mod 256)

Type Encode (Filt) Decode (Recon)
0 None Filt(x) = Orig(x) Recon(x) = Filt(x)
1 Sub Filt(x) = Orig(x) − Orig(x−bpp) Recon(x) = Filt(x) + Recon(x−bpp)
2 Up Filt(x) = Orig(x) − Prior(x) Recon(x) = Filt(x) + Prior(x)
3 Average Filt(x) = Orig(x) − floor((Orig(x−bpp)+Prior(x))/2) Recon(x) = Filt(x) + floor((Recon(x−bpp)+Prior(x))/2)
4 Paeth Filt(x) = Orig(x) − Paeth(Orig(x−bpp),Prior(x),Prior(x−bpp)) Recon(x) = Filt(x) + Paeth(Recon(x−bpp),Prior(x),Prior(x−bpp))

Paeth(a,b,c): p = a+b−c; pick whichever of a, b, c minimizes |p−a|,|p−b|,|p−c| (ties broken a, then b, then c). bpp = bytes per complete pixel (≥1); out-of-range neighbors (row/column < 0) are treated as 0 (I10).

8.10 Adam7 interlace pass geometry

Pass Start (col,row) Col step Row step
1 0,0 8 8
2 4,0 8 8
3 0,4 4 8
4 2,0 4 4
5 0,2 2 4
6 1,0 2 2
7 0,1 1 2

Per-pass pixel count = ceil((width−start_col)/col_step) × ceil((height−start_row)/row_step), clamped to 0 if the image is smaller than a pass's start offset; the seven counts sum to width×height (I9).

8.11 CRC-32 (PNG, Ethernet/RFC-1952 polynomial)

Polynomial 0xEDB88320 (reversed representation of 0x04C11DB7), initial value 0xFFFFFFFF, final XOR 0xFFFFFFFF, computed over chunk type + data.

8.12 PSNR and SSIM

MSE  = (1/N) Σ (ref_i − test_i)^2
PSNR = 10 log10( MAXval^2 / MSE )                (MAXval = 255 for 8-bit)
SSIM(x,y) = [(2μxμy+C1)(2σxy+C2)] / [(μx²+μy²+C1)(σx²+σy²+C2)]

evaluated per local window and averaged (Wang et al. 2004); C1=(0.01×255)^2, C2=(0.03×255)^2 for 8-bit images.

8.17 Worked numeric example — one 8×8 luma block, quality 50

Input pixels (row 0, illustrative 8 values, level-shifted by −128): [52,55,61,66,70,61,64,73]−128 = [-76,-73,-67,-62,-58,-67,-64,-55]. Row 1-D DCT (per §8.2) on this row yields a DC-heavy coefficient vector with F(0)≈−509 (scaled) and rapidly decaying AC terms; after all 8 rows then 8 columns (§8.2 separability), the block's F(0,0) (DC) dominates and high-frequency F(u,v) for u+v≥10 are near zero for a smooth patch. Quantizing at quality 50 (Q=Qbase, §8.3) rounds most F(u,v) with u+v≥6 to 0. Zigzag reorders (§8.4) so the surviving nonzeros cluster early; RLE/Huffman (§8.6–8.7) encodes them in roughly 40–60 bits versus 512 bits raw (8×8×8). Reconstruction error after IDCT + level-shift-back is bounded by the discarded high-frequency energy — for a smooth 8×8 patch this is typically < 2 gray levels RMS, consistent with the §4 bit-exactness tolerance.

8.18 Malformed-input examples

Case Symptom if unguarded This design's guard
IHDR width=0 or height=0 divide-by-zero downstream in filter/Adam7 math I2 rejects before allocation
Over-subscribed Huffman table (lengths summing past 2^n) infinite/garbage decode loop I5 rejects at table-build time
Chunk length exceeding remaining file bytes OOB read I3 bounds check on the underlying reader
CRC mismatch on an IDAT chunk corrupted pixel data silently used I4 rejects in strict mode
Adam7 pass with inconsistent dimensions (image smaller than pass 1's macro-cell) negative/garbage pass buffer size I9 clamps degenerate passes to 0 pixels
JPEG SOS referencing an undefined DQT/DHT id null-table dereference class bug I12 rejects before scan decode
Decompression bomb (kilobytes → gigabytes) OOM I11 aborts streaming inflate at the declared-size multiple

8.19 Failure-path example

A JPEG truncated mid-MCU 3 of 40 in the only scan: ScanEntropy hits ReadMagnitude with fewer bits than the category demands → UnexpectedEof is raised → the top-level decode call catches it, returns an ImageBuffer populated through MCU 2 with truncated=True and a CodecError.UnexpectedEof attached as partial_error, per I7; no exception escapes to the caller unless strict_eof=True (ADR-19), in which case the call raises instead of returning a partial buffer.
