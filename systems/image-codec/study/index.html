32. Mental Models & First Principles

MM1 — The quantization table is the perceptual model. Lossy compression is not about discarding data but about choosing which errors the eye forgives. Predicts: encoder quality tuning is table design, not per-pixel special-casing. Bug class without it: ad hoc rounding rules that can't be justified against any perceptual model, breaking P14's clamp contract. Resolving: §8.3, P7.

MM2 — Every decoder is a parser for adversarial input; bounds checking is the feature, decoding is the side effect. Predicts: validation code should be as prominent in review as decode logic, not bolted on afterward. Bug class without it: hardening treated as a Phase-10 afterthought rather than woven through every earlier phase's acceptance criteria. Resolving: §7, §24.

MM3 — A canonical Huffman code is an agreement on tie-breaking; the tree itself is disposable, only the length shape matters. Predicts: any two independent implementations building from the same lengths + value order produce bit-identical codes. Bug class without it: serializing/comparing trees instead of length arrays, or a non-deterministic tie-break producing cross-implementation-incompatible codes. Resolving: §8.7, P5.

MM4 — Separable transforms turn intractable per-axis work into tractable per-axis work. The 2-D DCT's row/column split is the general pattern: any transform claimed to be "2-D" should be checked for separability before writing the naive form. Bug class without it: an O(N⁴)-equivalent DCT that is "correct" but blows the throughput target. Resolving: §8.2, P4.

MM5 — A filter is a bet that neighbors predict you well; DEFLATE is the payoff collector. PNG's two-stage design (predict, then general-purpose compress) means filter quality only matters insofar as it helps the downstream compressor — not as a standalone metric. Predicts: a filter heuristic should ultimately be judged by post-DEFLATE size, not its own proxy metric alone. Bug class without it: over-trusting the MSAD heuristic (ADR-10) in a regime where it diverges from actual compressed size. Resolving: §8.9, ADR-10.

MM6 — Precision is a stated contract, not a property of the hardware. Fixed-point vs. float is a decision, documented once, not an accident of which code path happened to be written first. Predicts: every numeric path names its scale explicitly. Bug class without it: silent precision drift between an encoder's fixed-point path and a decoder's (accidentally) float path. Resolving: P11, §8.3, ADR-04.

MM7 — A header field is trustworthy only as an upper bound on validation, never directly as an allocation size. Predicts: allocation always follows a two-step validate-then-allocate sequence, with the validated bound (not the raw field) driving the allocation call. Bug class without it: T1/T2's overflow-driven heap-overflow class. Resolving: I2, §24.

MM8 — Quality metrics disagree with each other on purpose. PSNR measures energy, SSIM measures structure; an encoder tuned to only one will eventually look wrong on the other's blind spot. Predicts: any change that improves PSNR should be sanity-checked against SSIM before being called an improvement. Bug class without it: "improving" PSNR while making banding or structural artifacts measurably worse. Resolving: §8.12, §23.6.

Required reading (§5)

Books

  • Pennebaker & Mitchell, JPEG: Still Image Data Compression Standard — chapters on Huffman/arithmetic entropy coding, the baseline decoder data flow, the AAN fast DCT derivation — applied in Phase 6, Phase 7.
  • Sayood, Introduction to Data Compression, 5th ed. — Huffman-coding chapter, LZ77/LZ78 chapter, the JPEG chapter — applied in Phase 2, Phase 7.
  • Salomon & Motta, Handbook of Data Compression — the DEFLATE chapter, the image-compression survey chapter — applied in Phase 2, Phase 3.
  • Gonzalez & Woods, Digital Image Processing — the transform-coding chapter (DCT), the color-space-conversion chapter — applied in Phase 5, Phase 6.
  • Taubman & Marcellin, JPEG2000: Image Compression Fundamentals, Standards and Practice — the wavelet-transform chapters, used only for the comparative treatment — applied in §33, §36.
  • Rabbani & Jones, Digital Image Compression Techniques (SPIE Press) — the DCT/quantization chapters, the JPEG baseline walkthrough — applied in Phase 6, Phase 8.

Papers

  • Wallace, 1992, "The JPEG Still Picture Compression Standard," IEEE Trans. Consumer Electronics — the canonical baseline-JPEG overview — applied in Phase 8.
  • Ahmed, Natarajan & Rao, 1974, "Discrete Cosine Transform," IEEE Trans. Computers — the DCT's original derivation — applied in Phase 6.
  • Loeffler, Ligtenberg & Moschytz, 1989, "Practical fast 1-D DCT algorithms with 11 multiplications," ICASSP — the fast-DCT factorization alternative to AAN — applied in Phase 6, §36.
  • Arai, Agui & Nakajima, 1988 — the AAN fast IDCT algorithm (11 multiplications per 8 samples) — applied in Phase 6.
  • Huffman, 1952, "A Method for the Construction of Minimum-Redundancy Codes," Proc. IRE — canonical-code optimality — applied in Phase 7.
  • Ziv & Lempel, 1977, IEEE Trans. Information Theory — the LZ77 dictionary-coding model — applied in Phase 2.
  • Ziv & Lempel, 1978 — the LZ78 dictionary variant, used for the historical contrast in ADR-11 — applied in §9, §33.
  • Rissanen & Langdon, 1979, "Arithmetic coding," IBM J. Research and Development — the arithmetic-coding alternative to Huffman — applied in Phase 7, §36.
  • Witten, Neal & Cleary, 1987, "Arithmetic coding for data compression," CACM — the practical arithmetic-coder construction — applied in §36.
  • Wang et al., 2004, "Image Quality Assessment: From Error Visibility to Structural Similarity," IEEE Trans. Image Processing — the SSIM definition — applied in Phase 11.
  • Watson, 1993 — DCTune / perceptual quantization-table design — applied in Phase 6, §32.
  • Alakuijala et al. — Guetzli and Brotli as published engineering work on perceptually-tuned quantization and modern entropy coding — applied in §33.

Reference Implementations

  • libjpeg-turbo — jdhuff.c (Huffman decode), jdcoefct.c (coefficient buffering), jidctint.c (integer IDCT) — lesson: fast-table Huffman lookup; pitfall not to copy: its C-array bounds are hand-audited, not compiler-enforced — applied in Phase 7, Phase 8.
  • libpng — pngrutil.c (chunk/CRC handling) — lesson: strict chunk-ordering validation; pitfall not to copy: historical integer-overflow bugs in chunk-length arithmetic (CVE-2018-13785) — applied in Phase 1, Phase 10.
  • zlib — deflate.c, inflate.c — lesson: the sliding-window ring-buffer implementation; pitfall not to copy: silent lenient-mode acceptance of malformed streams — applied in Phase 2.
  • stb_image — stb_image.h — lesson: a single-file decoder can still be spec-complete; pitfall not to copy: minimal input validation (it assumes a cooperative caller) — applied in Phase 10.
  • mozjpeg — lesson: trellis quantization and jpgcrush-style re-encoding for smaller files at equal quality — applied in Phase 6, §33.
  • Pillow — src/libImaging/ — lesson: a Python-facing codec boundary design (C core, Python API) — applied in Phase 0, §33.

Glossary (§38) · 48 terms · site-wide glossary

Lossy
a compression scheme (JPEG) that discards information irrecoverably in exchange for a smaller file, guided by a perceptual model (§8.3).
Lossless
a compression scheme (PNG) whose decode reproduces the original pixel data exactly (I1, P2).
YCbCr
a color space separating luma (Y) from two chroma components (Cb, Cr); JPEG's working color space (§8.1).
Chroma subsampling
reducing chroma-plane resolution relative to luma, exploiting the eye's lower spatial acuity for color (§17).
4:2:0
a chroma-subsampling factor halving both horizontal and vertical chroma resolution (ADR-06).
DCT-II
the specific discrete cosine transform variant used by JPEG, mapping spatial pixel blocks to frequency-domain coefficients (§8.2).
Basis function
one of the fixed cosine waveforms the DCT projects a block onto; each coefficient is the block's weight on one basis function.
Quantization table
the per-frequency divisor array that discards perceptually-unimportant coefficient precision (§8.3, MM1).
Quality factor
the 1–100 scalar an encoder exposes, mapped through the quantization-table scaling formula (§8.3).
Zigzag order
the diagonal traversal ordering of an 8×8 coefficient block that clusters low frequencies first (§8.4).
DC coefficient
a block's [0,0] coefficient, representing its average value (§8.5).
AC coefficient
any non-DC coefficient, representing higher-frequency content (§8.6).
Run-length
the count of consecutive zero coefficients preceding the next nonzero AC value (§8.6).
End-of-block (EOB)
the reserved AC symbol signaling all remaining coefficients in a block are zero (§8.6).
Huffman code
a variable-length, prefix-free entropy code assigning shorter codes to more frequent symbols (Huffman 1952).
Canonical code
a Huffman code reconstructible from code lengths alone via a fixed assignment rule (§8.7, P5).
Over-subscribed table
an invalid Huffman code-length set violating the Kraft inequality; must be rejected, not decoded (I5).
Restart marker
a JPEG marker resetting DC prediction state, enabling error resync and parallel decode (§8.13, I8).
Progressive scan
a JPEG scan covering a coefficient subset (spectral selection) or bit-plane subset (successive approximation) rather than a full block in one pass (§21).
Spectral selection
the progressive-JPEG technique of encoding a coefficient-index range per scan (§21.2).
Successive approximation
the progressive-JPEG technique of encoding a coefficient's bits from most- to least-significant across scans (§21.2).
JFIF
the JPEG File Interchange Format, defining APP0 and the default color-space/density convention (§5, §20).
EXIF
the metadata format embedded in APP1, including camera orientation and (optionally) GPS data (§5, ADR-15).
DEFLATE
the LZ77 + Huffman compression algorithm defined by RFC 1951, underlying PNG's IDAT stream (§8.8).
LZ77
the dictionary-coding scheme replacing repeated byte sequences with (length, distance) back-references (Ziv & Lempel 1977).
Sliding window
DEFLATE's 32 KiB bounded history buffer that back-references may point into (§8.8).
Match/literal
DEFLATE's two token kinds: a literal byte, or a length/distance back-reference match (§8.8).
PNG filter type
one of five per-scanline byte-transform strategies (None/Sub/Up/Average/Paeth) applied before DEFLATE (§8.9).
Paeth predictor
PNG's three-neighbor linear predictor with a nonlinear closest-neighbor selection rule (§8.9, MM5).
Adam7 interlace
PNG's seven-pass progressive-scan geometry for incremental image display (§8.10).
CRC-32
the 32-bit cyclic redundancy check validating every PNG chunk's integrity (§8.11, I4).
Critical vs. ancillary chunk
PNG's case-bit convention distinguishing chunks a decoder must understand (critical, uppercase first letter) from ones it may skip (ancillary, lowercase) (§8.14).
Decompression bomb
a small compressed input engineered to expand to an enormous decompressed size, an allocation-DOS attack (T3, I11).
PSNR
Peak Signal-to-Noise Ratio, a logarithmic energy-error quality metric (§8.12).
SSIM
Structural Similarity Index, a perceptual quality metric sensitive to structural (not just energy) error (Wang et al. 2004, §8.12).
Bits per pixel (bpp)
compressed size in bits divided by pixel count, the standard density metric for comparing compression ratios (§8.12).
Blocking artefact
visible 8×8 block-boundary discontinuities from independent per-block DCT quantization at low quality.
Banding
visible discrete steps in what should be a smooth gradient, from quantization-table rounding (FM-8).
MCU (Minimum Coded Unit)
the smallest independently-decodable group of blocks in a JPEG scan, sized by the components' sampling factors (§20.2).
IDCT
the Inverse Discrete Cosine Transform, mapping frequency-domain coefficients back to spatial pixels (§8.2).
zlib
the RFC 1950 wrapper format around a raw DEFLATE stream, adding a header and Adler-32 trailer (§14.2).
Adler-32
the checksum zlib uses for stream integrity, distinct from PNG's CRC-32 (§14.6).
Fixed-point
a numeric representation using an implicit scale factor over integers instead of floating-point, chosen here for deterministic rounding (ADR-04, P11).
Level shift
JPEG's −128/+128 pixel-value rebiasing around zero before/after the DCT/IDCT (§18.6).
Trust boundary
the point in the pipeline where previously-untrusted bytes become a validated, trusted ImageBuffer (§3).
Canonical assignment
the deterministic rule mapping a sorted code-length list to explicit Huffman codes (§8.7).
Baseline JPEG
the universally-supported JPEG variant (SOF0), sequential single-pass entropy coding (§20).
Sample precision
the bit depth of a single color-channel sample (8-bit for baseline JPEG; 1–16-bit for PNG) (§4).
