34. Back-of-Envelope Capacity Model

  1. Peak memory, 10K-LOC module: 10,000 LOC × 8 nodes/LOC (empirical AST density) = 80,000 nodes. Per-node footprint ≈ 96 B (Expr variant + Span + Type pointer) + ≈64 B annotation-side-table overhead (3 HashMaps, amortized) = 160 B/node. 80,000 × 160 B ≈ 12.8 MB baseline; saturation's e-class duplication (~4× during Phase 8, §20) before extraction ⇒ ≈ 51 MB peak — within the ≤200 MB/10K-LOC ceiling (§4).
  2. Saturator e-graph structural ceiling: fuel = 50,000 e-nodes (§4) × ≈120 B/e-node (ENode<AstLanguage> + e-class metadata) ≈ 6 MB e-graph ceiling.
  3. Per-pass throughput derivation: O1 @ 10K LOC in ≤100 ms (§4/M1, Phase-1) ⇒ 80,000 nodes / 0.1 s = 800,000 nodes/sec sustained across 5 passes (fold, propagate, dce, cse, peephole) ⇒ per-pass budget ≈ 4,000,000 nodes/sec/pass single-threaded (matches §4's throughput floor exactly).
  4. Manager worst-case wall time: max_iter=32 (§4/ADR-03) × 5 passes/iteration × (80,000/4,000,000) s per pass ≈ 32 × 5 × 0.02 s = 3.2 s worst-case ceiling. Compared against the ≤400 ms O2 target (M2): confirms typical convergence is ~8× faster than worst case, consistent with the empirical "fewer than 8 iterations" acceptance criterion (§21.4).
  5. Inliner growth bound: fuel = 1,024 inlines/run (§4/ADR-08) × Cost.size ≤ 30 nodes/inline (worst case) = ≤ 30,720 injected nodes/run; against the 80,000-node baseline that bounds inliner-driven growth to ≤ 38% (M12).
  6. Differential-harness throughput: 1,000 cases in ≤2 s (Phase-1, M8) = 500 cases/sec ⇒ ≤2 ms/case budget (generate + interpret×2 + compare); at arb_expr's default depth bound of 6 (≤127 nodes/expr, §22.7), the interpreter must sustain ≥500 evals/sec on generated expressions of that size.
  7. FD/concurrency budget: N worker threads (rayon) × 2 FDs/worker (1 read + 1 write for dumps) = 2N; at the §4 cap of 64 workers/batch, FD ceiling = 128 — well under a typical 1024 soft ulimit.
  8. Storage amplification (pass dumps): each pass writes before+after text dumps (~1.2× source size each) × up to 11 passes (O2 profile) ⇒ ≈ 11 × 2 × 1.2 = 26.4× the original source size in transient dumps per run — a 1 MB source file produces ≈26 MB of transient dump data, cleaned per the §29 retention policy.
