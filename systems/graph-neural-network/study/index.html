Mental Models & First Principles

MM1 — Gather and Scatter are Exact Adjoints Expert insight: gather(X, idx) selects rows; its reverse-mode adjoint is scatter_add, and scatter_add's adjoint is gather. This is not an approximation — it is exact. What it predicts: any gradient through a GNN layer can be computed with one gather and one scatter. Bug class written without it: implementing the scatter gradient as anything other than a gather produces subtly wrong gradients that pass forward tests but train a wrong model (I2, I3). Applied in: Phase 2 (autodiff/graph_ops.py), Phase 4 (MessagePassing base).

MM2 — Message Passing Is a Factored SpMM Expert insight: every GNN propagation step is a sparse matrix-vector multiply in disguise: H_new = Â·(H·W). The sparse adjacency operator Â is applied via gather (source rows) + segment_sum (accumulate to destination), never by materializing the dense N×N matrix. What it predicts: propagation cost is O(E·F), not O(N²·F), for E≪N². Bug class written without it: materializing a dense Â for a 10⁵-node graph exhausts RAM in seconds (P13, ADR-7). Applied in: Phase 3 (sym_norm), Phase 6 (GCNConv §8.6), Performance Engineering.

MM3 — Symmetric Normalization as Spectral Radius Control Expert insight: Â = D̃^-1/2(A+I)D̃^-1/2 has spectral radius ≤ 1, so repeated multiplication Â^L·X does not blow up (bounded by the initial norm). The 1/√(d_i·d_j) per-edge weight is the key: it balances the contribution from high-degree hubs. What it predicts: without normalization, propagation magnitudes grow (or collapse to zero for isolated nodes). Bug class written without it: raw A·H propagation causes feature-magnitude explosion in any graph with a hub node (I7, ADR-9). Applied in: Phase 3 (§8.4), Phase 6 (GCNConv), Phase 12 (numerical hardening).

MM4 — Oversmoothing Is Low-Pass Filtering to Convergence Expert insight: each GCN propagation step applies a low-pass filter (Â is a smoothing operator). With enough layers, all node representations converge to a vector proportional to the eigenvector associated with the largest eigenvalue — a degree-weighted constant that carries no local discriminative information. What it predicts: test accuracy first rises then falls as layer count increases, independently of model capacity. Bug class written without it: adding depth to fight underfitting actually hurts a well-specified shallow model (Li et al. 2018, Oono & Suzuki 2020). Applied in: Phase 12 (oversmoothing telemetry, §23.2), Failure Modes.

MM5 — Sum Aggregation Preserves Multiplicity; Mean and Max Do Not Expert insight: sum(neighbor features) counts repeated neighbors; mean and max collapse multiplicity (two identical neighbors look the same as one). The Weisfeiler-Lehman test distinguishes graphs by multiset of neighborhood features. Sum aggregation replicates this; mean/max strictly weaker. What it predicts: GIN with sum is WL-expressive; a mean-GIN cannot distinguish certain non-isomorphic graphs. Bug class written without it: using mean instead of sum in GIN produces a correctly-running but expressivity-weakened model that fails the multiplicity fixture (§8.8, Xu et al. 2019, ADR-11). Applied in: Phase 8 (GINConv), Phase 9 (readout).

MM6 — A Future/Module Is a State Machine; the Tape Is Its Accumulator Expert insight: a Node on the autodiff tape is not a value — it is a value plus a deferred adjoint accumulator. The reverse sweep visits nodes in reverse topological order and accumulates (sums) incoming adjoint contributions from all children (important for DAG reuse). What it predicts: re-used subexpressions double their contribution to the gradient unless the tape accumulates correctly. Bug class written without it: overwriting the adjoint instead of summing it (tree semantics) produces wrong gradients for any shared subexpression (I4, P6, Goodfellow Ch 6). Applied in: Phase 2 (autodiff/tape.py, autodiff/grad.py).

MM7 — Dropout as Bernoulli Masking with Inverted Scaling Expert insight: dropout at train time multiplies each feature by Bernoulli(1−p) and divides by (1−p), so expected output equals the eval output exactly. This means no rescaling is needed at eval — the model is deterministic at inference without any code change. What it predicts: omitting the 1/(1−p) scaling at train time makes the model see smaller activations at train than at eval, biasing every layer's weight. Bug class written without it: scaling at eval time instead of train time (original Srivastava formulation) requires a code path switch that is easy to misapply (P9, P10, I10, Srivastava 2014). Applied in: Phase 5 (nn/dropout.py), Phase 11 (Trainer eval mode).

MM8 — Neighbor Sampling as Variance-Bounded Gradient Estimation Expert insight: sampling k neighbors uniformly estimates the full neighborhood mean with variance 1/(k·d) where d is the true degree. The estimate is unbiased under mean aggregation. Each additional hop multiplies the sample size by k, so 2-hop sampling with fanout [25,10] touches at most 250 nodes per target. What it predicts: training with sampling converges to the same optima as full-batch but with O(fanout) cost per target rather than O(d^L). Bug class written without it: assuming the sampled subgraph is the same graph as the full training graph and recomputing global normalization instead of subgraph normalization (Hamilton et al. 2017, ADR-17). Applied in: Phase 7 (train/sampler.py, §18.2), Scalability Analysis.

Required reading (§5)

Books

  • Hamilton — Graph Representation Learning (2020). Ch 5–7 (neighborhood aggregation, GNN theory, expressivity). Extract: the MPNN framing, GraphSAGE, GAT, oversmoothing, WL connection — the spine of this project. → applied in Phase 4 (message-passing primitive), Phase 7 (GraphSAGE), Phase 8 (GAT/GIN expressivity), Phase 12 (oversmoothing).
  • Goodfellow, Bengio, Courville — Deep Learning. Ch 6 (feedforward + backprop), Ch 8 (optimization). Extract: reverse-mode backprop, SGD/Adam, weight init, normalization rationale. → applied in Phase 2 (reverse-mode tape), Phase 5 (weight init), Phase 10 (SGD/Adam).
  • Bishop — Pattern Recognition and Machine Learning. Ch 5 (neural networks). Extract: error backprop derivation, gradient checking. → applied in Phase 2 (grad_check harness, I4).
  • Bronstein, Bruna, Cohen, Veličković — Geometric Deep Learning (2021 proto-book). Extract: equivariance/invariance as a design principle; GNNs as permutation-equivariant networks. → applied in Phase 4 (I5 permutation equivariance), Phase 9 (I6 readout invariance).
  • Wu, Sun, et al. — Graph Neural Networks: Foundations, Frontiers, and Applications (2022). Extract: survey of GCN/SAGE/GAT/GIN variants, training tricks, sampling. → applied in Phase 6 (GCN), Phase 7 (SAGE sampling), Phase 8 (GAT/GIN), Phase 12 (training tricks).
  • Strang — Linear Algebra and Its Applications. Extract: matrix multiply, sparse structure, eigenvalues/normalization intuition for the graph Laplacian. → applied in Phase 3 (sym_norm, I7 spectral-radius bound), Phase 6 (GCN propagation).
  • Trefethen & Bau — Numerical Linear Algebra. Extract: conditioning, stability, why normalization matters for repeated multiplication. → applied in Phase 3 (sym_norm stability, I7), Phase 12 (numerical hardening).
  • Murphy — Probabilistic Machine Learning: An Introduction. Extract: softmax/cross-entropy, regularization, the bias-variance view of dropout. → applied in Phase 10 (cross_entropy in log-space, P5), Phase 5 (Dropout, P9).

Glossary · 32 terms · site-wide glossary

Adjacency matrix A
N×N (sparse) edge incidence; A_{ij}=1 if edge i→j
Aggregation
segment reduce (sum/mean/max) of messages by destination node
Attention (GAT)
learned per-edge weight α_ij, normalized per destination via softmax
Autodiff (reverse-mode)
adjoint accumulation over a recorded tape; gradient at ~1 extra pass
BatchedGraph
block-diagonal disjoint union of graphs + per-node graph-id batch
COO
coordinate sparse format: edge_index [src; dst]
CSR
compressed sparse row; sorted-by-destination for fast segment ops
Degree
number of edges incident to a node (in/out)
Dirichlet energy
sum of squared feature differences across edges; oversmoothing metric
DropEdge
edge-level dropout; randomly removes edges in training (Rong 2020)
Edge softmax
softmax of edge scores normalized over each node's incoming edges
Equivariance (permutation)
relabel nodes → outputs relabel identically (node-level layers)
GAT
Graph Attention Network; multi-head edge attention
Gather
select rows of X by index (source features per edge); vjp is scatter_add
GCN
Graph Convolutional Network; symmetric-normalized propagation (Kipf 2017)
GIN
Graph Isomorphism Network; sum aggregation + MLP; WL-expressive (Xu 2019)
GraphSAGE
sampling + mean/pool aggregation; inductive (Hamilton 2017)
Invariance (permutation)
relabel nodes → identical graph-level output (readout)
Message passing
gather → message → aggregate → update; the universal GNN primitive
MPNN
Message Passing Neural Network; the unifying framework (Gilmer 2017)
Neighbor sampling
sample a bounded set of neighbors per node per layer (scalability)
Normalization (symmetric)
Â = D̃^-1/2(A+I)D̃^-1/2; bounds spectral radius, stabilizes propagation
Oversmoothing
repeated propagation drives node features to a constant; depth pathology
Pooling / readout
aggregate node embeddings into a graph embedding (add/mean/max)
Scatter-add
accumulate values into output rows by index (duplicates summed); vjp is gather
Segment reduction
reduce values grouped by a segment index (sum/mean/max)
Self-loop
edge from a node to itself; A+I keeps a node's own features in propagation
Transductive
train + infer on the same fixed graph (e.g. Cora node classification)
Inductive
generalize to unseen nodes/graphs (GraphSAGE, graph classification)
vjp
vector-Jacobian product; the per-op reverse-mode rule
Weisfeiler-Lehman (WL) test
graph-isomorphism heuristic; upper-bounds GNN expressivity
Xavier/He init
weight initialization scaled by fan-in/out for stable gradients
