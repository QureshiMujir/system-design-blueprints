30. Mental Models & First Principles

  • MM1 — A scale is a unit conversion, not a compression trick. Predicts: accuracy loss traces to a badly chosen scale far more often than to too few bits. Bug class without it: adding bits to fix an accuracy problem that a better calibration method (§13) would have fixed at the same bit width. Applied in §8.1, §13.
  • MM2 — Outliers are conserved, not destroyed. Predicts: every outlier-handling method (LLM.int8(), SmoothQuant, AWQ) relocates the cost of an outlier — to a side-path, to the weights, or to a pre-scaled weight — never eliminates it. Bug class without it: expecting a single universal "fix outliers" method rather than picking the relocation that fits the architecture. Applied in §17, §18, §19.
  • MM3 — The accumulator is the actual precision of your matmul. Predicts: input operand precision matters far less than accumulator precision at scale. Bug class without it: picking an INT32 accumulator to save 5–10% throughput and silently overflowing at long sequence lengths. Applied in §8.1, I3, ADR-07.
  • MM4 — Quantization error compounds like floating-point error, not like a discount. Predicts: independent per-column rounding accumulates a whole-layer error far worse than a naive per-weight bound suggests. Bug class without it: assuming a per-weight error bound bounds the whole layer, missing why GPTQ's error-compensation update exists at all. Applied in §16.
  • MM5 — A packed format is a contract, not an implementation detail. Predicts: matching a reference byte layout exactly (gguf's Q4_0/Q4_K) is what makes ecosystem interop possible at all. Bug class without it: "optimizing" a packed layout in a way that silently breaks every downstream reader. Applied in §11.6, P11.
  • MM6 — Calibration is measurement, and measurement needs provenance. Predicts: an accuracy number without a recorded corpus+seed is an anecdote, not a number. Bug class without it: comparing two quantized models whose calibration provenance silently differs and drawing a false conclusion about which method is better. Applied in §13, I5, I9.
  • MM7 — Fusion is what makes a bandwidth reduction real. Predicts: quantizing without fusing dequant into the matmul just relocates the bandwidth cost, it does not remove it. Bug class without it: shipping a "quantized" model that materializes a dequantized fp16 tensor and measures zero speedup, then blaming the quantization scheme. Applied in §21, P6.
  • MM8 — Every scheme is a point on a Pareto frontier, not a strictly-better replacement. Predicts: INT4 is not "better" than INT8 — it is a different, deliberate trade. Bug class without it: assuming a lower bit width is a free lunch and shipping it without checking its accuracy budget (§4). Applied in §4, §32.

5. Required Reading

Books

  • Hennessy & Patterson — Computer Architecture: A Quantitative Approach, 6th ed. Ch. 3 (Instruction-Level Parallelism) and the arithmetic appendix. Extract: fixed-point/integer arithmetic cost, memory-bandwidth-vs-compute-bound reasoning. Applied in §4 and §28 (bandwidth-bound INT4 decode).
  • Goodfellow, Bengio, Courville — Deep Learning (MIT Press, 2016). Ch. 4, Numerical Computation. Extract: overflow/underflow, conditioning of ill-posed problems. Applied in §16 (GPTQ Hessian conditioning, damping).
  • Bryant & O'Hallaron — Computer Systems: A Programmer's Perspective, 3rd ed. Ch. 2, Representing and Manipulating Information. Extract: two's-complement, bit-field packing. Applied in §14 (INT4 nibble packing) and §11.6 (block layouts).
  • Kirk & Hwu — Programming Massively Parallel Processors, 4th ed. Ch. 5 (memory architecture) and Ch. 10 (reduction/tiling patterns). Extract: shared-memory tiling, register pressure, coalesced access. Applied in §21 (fused CUDA dequant-matmul kernel).
  • Overton — Numerical Computing with IEEE Floating Point Arithmetic (SIAM, 2001). Ch. 2–3, rounding-error analysis. Extract: forward/backward error bounds for rounding. Applied in I3 and §8 (round-to-nearest-even semantics).
  • Kleppmann — Designing Data-Intensive Applications (O'Reilly, 2017). Ch. 4, Encoding and Evolution. Extract: schema-evolution discipline for a binary wire format. Applied in §25 (Compatibility & Versioning) for the Q-file TLV metadata block.

Papers

  • Jacob, Kligys, Chen, Zhu, Tang, Howard, Adam, Kalenichenko, 2018. Quantization and Training of Neural Networks for Efficient Integer-Arithmetic-Only Inference. CVPR. Defines the affine-quantization vocabulary (scale, zero-point, per-channel weight / per-tensor activation) every later paper assumes. Applied in §8 (Domain Model) and §12 (Phase 0).
  • Krishnamoorthi, 2018. Quantizing Deep Convolutional Networks for Efficient Inference: A Whitepaper. arXiv:1806.08342. The PTQ taxonomy survey. Applied in §8 and §13 (calibration method selection: min-max/percentile/MSE/entropy).
  • Dettmers, Lewis, Belkada, Zettlemoyer, 2022. LLM.int8(): 8-bit Matrix Multiplication for Transformers at Scale. NeurIPS. The outlier-feature discovery and mixed-precision decomposition. Applied in §19 (Phase 7).
  • Frantar, Ashkboos, Hoefler, Alistarh, 2023. GPTQ: Accurate Post-Training Quantization for Generative Pre-trained Transformers. ICLR. The Hessian-aware, Cholesky-cached OBQ algorithm. Applied in §16 (Phase 4).
  • Lin, Tang, Tang, Yang, Dang, Gan, Han, 2024. AWQ: Activation-aware Weight Quantization for LLM Compression and Acceleration. MLSys. The activation-salience scaling method. Applied in §17 (Phase 5).
  • Xiao, Lin, Seznec, Wu, Demouth, Han, 2023. SmoothQuant: Accurate and Efficient Post-Training Quantization for Large Language Models. ICML. Outlier migration from activations to weights. Applied in §18 (Phase 6).
  • Dettmers, Pagnoni, Holtzman, Zettlemoyer, 2023. QLoRA: Efficient Finetuning of Quantized LLMs. NeurIPS. Introduces the NF4 grid and double quantization. Applied in §15 (Phase 3).
  • Micikevicius et al. (17 authors incl. Stosic, Burgess, Dubey), 2022. FP8 Formats for Deep Learning. arXiv:2209.05433. The E4M3/E5M2 format definitions. Applied in §21 (Phase 9).
  • Dettmers & Zettlemoyer, 2023. The Case for 4-bit Precision: k-bit Inference Scaling Laws. ICML. The Pareto argument for 4-bit as the inference sweet spot. Applied in §4 (System Constraints rationale) and §32 (Capacity Model).
  • Dettmers, Svirschevski, Egiazarian, Kuznedelev, Frantar, Ashkboos, Borzunov, Hoefler, Alistarh, 2023. SpQR: A Sparse-Quantized Representation for Near-Lossless LLM Weight Compression. arXiv:2306.03078. Sparse-outlier + low-bit hybrid. Applied in §34 (Alternative Architectures) and the Deferred Features Register.
  • Kim, Hooper, Gholami, Yao, Mahoney, Keutzer, 2023. SqueezeLLM: Dense-and-Sparse Quantization. arXiv:2306.07629. Non-uniform sensitivity-based grid + sparse outliers. Applied in §34.
  • Banner, Nahshan, Soudry, 2019. Post-training 4-bit Quantization of Convolutional Networks for Rapid Deployment. NeurIPS. The analytical clipping-threshold derivation for symmetric quantization. Applied in §13 (MSE-based calibration).
  • Nagel, Fournarakis, Amjad, Bondarenko, van Baalen, Blankevoort, 2021. A White Paper on Neural Network Quantization. arXiv:2106.08295. The cleanest contemporary PTQ-vs-QAT treatment. Applied in §8 and §20 (Phase 8).
  • Esser, McKinstry, Bablani, Appuswamy, Modha, 2020. Learned Step Size Quantization. ICLR. The LSQ gradient-scaled learnable-scale method. Applied in §20 (Phase 8).

Reference Implementations

  • bitsandbytes (bitsandbytes-foundation/bitsandbytes, dirs csrc/, bitsandbytes/). The reference for INT8 outlier decomposition and NF4/double-quantization. Lesson: Linear8bitLt and Linear4bit are the API surface we mirror. Pitfall not to copy: its CUDA kernels materialize an intermediate fp16 tensor in some code paths — we fuse dequant into the matmul prologue instead (P6). Applied in §19, §15.
  • llama.cpp (ggml-quants.c, ggml-common.h, docs/gguf.md). The canonical Q4_0/Q4_K/Q8_0 block-layout reference and the gguf container spec. Applied in §11.6, §14, §21.
  • GPTQ official implementation (IST-DASLab/gptq). The Cholesky-cached OBQ reference and the act-order trick. Pitfall not to copy: the reference recomputes the full Hessian in fp32 in places — we mandate fp64 accumulation (§16.3). Applied in §16.
  • AWQ official implementation (mit-han-lab/llm-awq). The alpha-grid search and the scale-fold-into-previous-layer transform. Applied in §17.
  • PyTorch quantization (torch.ao.quantization, PyTorch core). The Observer/FakeQuantize module pattern for QAT. Lesson: separate the observer (statistics collection) from the fake-quantize (forward simulation) — we adopt this split in §20. Applied in §20.
  • NVIDIA TensorRT / TensorRT-LLM (tensorrt_llm/quantization/). The production SmoothQuant and FP8 implementation in an inference-serving stack. Applied in §18, §21.
  • ONNX Runtime quantization tool (onnxruntime/python/tools/quantization). The QuantizeLinear/DequantizeLinear operator-pair reference and its entropy/percentile calibrators. Applied in §13 (entropy calibration method).

RFCs / Specifications

  • gguf format specification (llama.cpp docs/gguf.md). The on-disk container this project extends. Applied in §11.6, §11.7, §21.
  • ONNX QuantizeLinear/DequantizeLinear operator specification (onnx/onnx, docs/Operators.md). The industry-standard affine-quantization operator contract. Applied in §8.
  • IEEE 754-2019 (floating-point arithmetic standard). Governs the fp16/bf16/fp32 rounding semantics every dequant path depends on. Applied in §8, I3.

Glossary (§36) · 50 terms · site-wide glossary

Affine quantization
mapping q = round(r/s)+z between real and integer domains.
Scale (s)
the real-valued step size per quantization level.
Zero-point (z)
the integer offset making an asymmetric range's zero representable exactly.
Symmetric quantization
z=0; range mirrored around zero.
Asymmetric quantization
z≠0; recovers dynamic range for non-zero-mean distributions.
Per-tensor quantization
one (s,z) for an entire tensor.
Per-channel quantization
one (s,z) per output channel.
Per-group quantization
one (s,z) per contiguous run of group_size elements.
Group size
the element count sharing one scale in per-group quantization (32/64/128/256 here).
PTQ (post-training quantization)
quantizing a trained model with no gradient step.
QAT (quantization-aware training)
fine-tuning with a fake-quantize op in the forward pass.
Straight-through estimator (STE)
approximates round()'s gradient as identity inside the clip range.
LSQ (Learned Step-Size Quantization)
makes the scale a trainable parameter with a normalized gradient.
Calibration
the process of observing a corpus to derive scales/zero-points.
Calibration corpus
the fixed dataset (here: 128×2048-token C4 sequences) used for calibration.
Min-max calibration
scale derived directly from observed abs_max.
Percentile calibration
scale derived from a clipped percentile of observed values.
MSE calibration
scale chosen to minimize L2 reconstruction error.
Entropy calibration
scale chosen to minimize KL-divergence between original/quantized histograms.
GPTQ
Hessian-aware, Cholesky-cached PTQ method (Frantar et al. 2023).
Hessian
here, 2X^TX/N, the second-order term of the layer-wise reconstruction objective.
Optimal Brain Quantization (OBQ)
the column-wise quantize-then-compensate algorithm GPTQ generalizes.
Cholesky decomposition
the matrix factorization used to cache the Hessian inverse efficiently.
Damping
regularizing the Hessian diagonal to keep Cholesky numerically stable.
Act-order
GPTQ's column-processing-order permutation by descending Hessian diagonal.
AWQ
activation-aware weight quantization (Lin et al. 2024).
Activation salience
the degree to which a weight channel's error matters, driven by its corresponding activation magnitude.
Scale folding
absorbing a per-channel scale into a preceding layer's parameters at zero runtime cost.
SmoothQuant
outlier migration from activations to weights via a per-channel rescale (Xiao et al. 2023).
Outlier migration
SmoothQuant's exact rebalancing transform.
LLM.int8()
outlier-column decomposition into an INT8 bulk path + fp16 side path (Dettmers et al. 2022).
Outlier decomposition
LLM.int8()'s runtime split.
NF4
the QLoRA 16-level quantile-based non-uniform 4-bit grid.
Double quantization
quantizing the per-group scales themselves (to FP8) for additional storage savings.
FP8
8-bit floating point; E4M3 (4-bit exponent, 3-bit mantissa, weights/activations) and E5M2 (5-bit exponent, 2-bit mantissa, gradients).
Mixed precision
a per-layer assignment of different schemes across one model.
Q-file
this system's gguf-compatible on-disk quantized-model artifact.
GGUF
the llama.cpp container format this system's Q-file extends.
Block layout
a fixed-size struct packing N weights + their scale/zero-point (BlockQ4_0/Q4_K/Q8_0).
TLV (Type-Length-Value)
the forward-compatible metadata-extension encoding used for calibration provenance.
Perplexity
exp(mean cross-entropy), this system's primary accuracy metric.
Dequantization
the inverse affine map, r_hat = s(q-z).
Fused kernel
a kernel that dequantizes in-register during the matmul, never materializing an intermediate dequantized tensor.
Accumulator
the dtype a matmul's partial sums are held in (mandated fp32 here, I3).
Round-to-nearest-even
the IEEE-754 default rounding mode used throughout.
RTN (round-to-nearest quantization)
plain per-column/group rounding with no error compensation (GPTQ/AWQ's baseline comparator).
Calibration provenance
the recorded (corpus hash, seed, scheme) tuple proving a Q-file's reproducibility lineage.
Outlier threshold
the per-channel activation-magnitude cutoff selecting LLM.int8()'s outlier columns.
Bits per weight
the effective average storage cost per weight including scale/zero-point overhead.
Storage amplification
the ratio of actual Q-file size to the theoretical bit-packed minimum. ---
