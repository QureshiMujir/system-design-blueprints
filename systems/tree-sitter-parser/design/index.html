11. Core Schema & Types

All types below are signatures only (no bodies), living in crates/parsekit/src/ per §10. Ownership/mutation/concurrency/persistence/serialization annotations follow each.

  • Parser — opaque value type. fn new() -> Self; fn set_language(&mut self, lang: &Language); fn parse(&mut self, text: &[u8], old_tree: Option<&Tree>) -> Tree; fn set_timeout(&mut self, d: Duration). Owns no shared state; !Sync, Send; not persisted; no serialization surface.
  • Language — opaque, Clone (cheap, Arc-backed), Send + Sync. fn load(bytes: &[u8]) -> Result<Self, LanguageError>. Immutable after load (I1, §7); the table bytes are the serialization format (versioned, I12).
  • Tree — immutable value, Clone (cheap, structural sharing via green-tree interning). fn root_node(&self) -> Node<'_>; fn edit(&self, edit: &InputEdit) -> Tree; fn language(&self) -> Language. Carries a generation counter (I10).
  • Node<'tree> — borrowed, positioned view, lifetime-bound to its Tree (I6). fn kind(&self) -> &'static str; fn kind_id(&self) -> u16; fn child_count(&self) -> usize; fn child(&self, i: usize) -> Option<Node<'tree>>; fn child_by_field_name(&self, name: &str) -> Option<Node<'tree>>; fn start_byte(&self) -> u32; fn end_byte(&self) -> u32; fn start_point(&self) -> Point; fn parent(&self) -> Option<Node<'tree>>; fn next_sibling(&self) -> Option<Node<'tree>>; fn is_error(&self) -> bool; fn is_missing(&self) -> bool; fn text<'s>(&self, source: &'s [u8]) -> &'s [u8].
  • TreeCursor<'tree> — stateful walker, owns a stack of (Node<'tree>, usize). fn goto_first_child(&mut self) -> bool; fn goto_next_sibling(&mut self) -> bool; fn goto_parent(&mut self) -> bool; fn current_node(&self) -> Node<'tree>; fn current_field_name(&self) -> Option<&'static str>.
  • InputEdit — plain data, Copy. Fields: start_byte: u32, old_end_byte: u32, new_end_byte: u32, start_point: Point, old_end_point: Point, new_end_point: Point. Constructor validates I8 (monotonic, non-overlapping).
  • Point — Copy, Eq, Ord. Fields: row: u32, column: u32.
  • Query — opaque, immutable after construction. fn new(lang: &Language, pattern: &str) -> Result<Self, QueryError>. Carries the compiled pattern NFA (§20.2).
  • QueryCursor<'q, 'tree> — stateful, generation-checked against its Tree (I10). fn matches(&mut self, query: &'q Query, node: Node<'tree>, source: &[u8]) -> impl Iterator<Item = QueryMatch<'tree>>; fn set_byte_range(&mut self, range: Range<u32>).
  • QueryMatch<'tree> — data. Fields: pattern_index: u16, captures: Vec<QueryCapture <'tree>>.
  • QueryCapture<'tree> — data. Fields: node: Node<'tree>, capture_index: u16.
  • LanguageError — typed enum: InvalidTableVersion { found: u16, expected: u16 }, InvalidLanguage, IncompatibleAbi. #[non_exhaustive]; no Box<dyn Error> (P14).
  • EditError — typed enum: Overlapping, NonMonotonic. Returned by InputEdit's fallible constructor.
  • ExternalScanner (trait, parsekit-runtime::lex::external) — fn scan(&mut self, lexer: &mut Lexer<'_>, valid: &ValidTokens) -> bool; fn serialize(&self, buf: &mut [u8]) -> usize; fn deserialize(&mut self, buf: &[u8]). Implementors own their scanner state; serialization feeds I11.
  • ParseTable (generator/runtime shared schema, §8.1) — immutable, embedded in the Language's loaded bytes; never constructed by the runtime, only deserialized.
