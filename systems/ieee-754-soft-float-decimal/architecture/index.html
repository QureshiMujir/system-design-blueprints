Figure 3b: Decimal and Money/Fixed-point pipelines.

DECODE. Splits a stored bit pattern into raw (sign, biased_exp, trailing_significand). Pure shifts/masks per softfp-formats constants. No interpretation yet.

CLASSIFY. Maps raw fields to FpClass. Conditions: exp all-zero + frac zero → ±0; exp all-zero + frac≠0 → subnormal; exp all-ones + frac zero → ±inf; exp all-ones + frac≠0 → NaN (MSB of frac = quiet bit → qNaN else sNaN). Else normal. Feeds special-value fast paths so cores only see finite operands.

UNPACK. Produces the internal Unpacked{sign, exp (unbiased i32), sig (extended), grs}. Normal values get the implicit bit restored; subnormals keep leading zeros and an exponent pinned at emin. The significand is widened so cores can accumulate guard/round/sticky.

OPERATION CORES. Each algebraic op works on Unpacked and emits an unrounded (sign, exp, sig, G, R, S). Cores never round and never set flags except the intrinsic ones (e.g., div-by-zero detection lives at the special-path layer). They produce enough low-order information (G, R, S) for the rounding unit to be exact.

ROUNDING UNIT. The single chokepoint. Given mode + (L, G, R, S) + sign, decides truncate vs increment, handles carry-out renormalization (e.g., 1.111…→10.000… bumps exponent), and detects overflow/underflow at the boundary. Built and tested standalone in P2 before any arithmetic uses it.

EXCEPTION AGGREGATOR. Sticky-ORs raised flags into FpContext.flags. Inexact set whenever any of G,R,S nonzero (or rounding changed value); Overflow/Underflow at exponent range limits; Invalid/DivByZero from special paths.

PACK / NORMALIZE. Re-biases exponent, drops the implicit bit, clamps to inf on overflow (mode-dependent), produces subnormal encodings on underflow, writes the final bit pattern.

DECIMAL DECODE/ENCODE. BID stores the coefficient as a plain binary integer; DPD packs 3 decimal digits per 10 bits (declets). Both share the combination-field exponent/MSD scheme. Decode → {sign, coeff:BigInt-or-u128, exp}.

DECIMAL ROUNDING. Operates in base-10 on the integer coefficient; default half-even; cohort selection picks the preferred exponent per the standard.

MONEY/FIXED-POINT. A scaled BigInt (unscaled value + decimal scale) plus an explicit RoundPolicy and Currency. Arithmetic stays exact until an explicit quantize/round, which applies the policy.

8. Domain Model — IEEE-754 in Depth

8.1 Binary interchange formats

Format Total bits sign exp bits trailing significand (frac) precision p bias emax emin min subnormal max finite
binary16 16 1 5 10 11 15 +15 −14 2⁻²⁴ 65504
bfloat16 (opt) 16 1 8 7 8 127 +127 −126 2⁻¹³³ ~3.39e38
binary32 32 1 8 23 24 127 +127 −126 2⁻¹⁴⁹ ~3.40e38
binary64 64 1 11 52 53 1023 +1023 −1022 2⁻¹⁰⁷⁴ ~1.80e308
binary128 128 1 15 112 113 16383 +16383 −16382 2⁻¹⁶⁴⁹⁴ ~1.19e4932

Implicit leading bit: value of a normal number = (-1)^s × 1.frac × 2^(E-bias). Value of a subnormal = (-1)^s × 0.frac × 2^(emin) (exponent field = 0 but effective exponent pinned at emin). Stored exponent E ∈ [1, 2^w−2] for normals; E=0 subnormal/zero; E=2^w−1 inf/NaN.

8.2 Value classes

Class Condition (E = biased exp field, T = trailing significand)
+0 / −0 E = 0, T = 0 (sign bit distinguishes)
subnormal E = 0, T ≠ 0
normal 1 ≤ E ≤ 2^w−2
+inf / −inf E = all-ones, T = 0
qNaN E = all-ones, T ≠ 0, MSB(T)=1
sNaN E = all-ones, T ≠ 0, MSB(T)=0, rest ≠ 0

NaN payload = T with the quiet bit (MSB of T) masked. sNaN with payload-low bits all zero except quiet bit reserved per format; an all-zero payload with quiet bit clear would be inf, so sNaN requires at least one payload bit set.

8.3 Internal unpacked representation

Unpacked {
  sign : bool,          // true = negative
  exp  : i32,           // unbiased; subnormals normalized lazily
  sig  : Wide,          // integer significand, MSB-aligned, implicit bit explicit
  // low-order rounding info produced by cores:
  g    : bool,          // guard  (first bit below LSB kept)
  r    : bool,          // round  (second bit below)
  s    : bool,          // sticky (OR of all remaining lower bits)
}

Wide = u64/u128 for ≤binary64, u256/BigInt(#370) for binary128 and FMA products. Cores keep sig so its top set bit indicates normalization; rounding position derived from format p.

8.4 Rounding modes + GRS decision

| Mode (IEEE name) | Alias | Increment rule (given retained LSB L, guard G, round R, sticky S; rest = R|S) | |------------------|-------|---------------------------------------------------------------------------------| | roundTiesToEven | RNE (default) | inc = G & (rest \| L) — tie (G&!rest) rounds to even | | roundTiesToAway | RNA | inc = G — tie rounds away from zero | | roundTowardPositive | RTP / ceil | inc = (!sign) & (G \| rest) | | roundTowardNegative | RTN / floor | inc = sign & (G \| rest) | | roundTowardZero | RTZ / trunc | inc = 0 (drop GRS) |

Two-bit simplification (sticky folds R): with guard G and sticky S' = R|S: RNE inc = G & (S' | L); RNA inc = G; RTP inc = !sign & (G|S'); RTN inc = sign & (G|S'); RTZ inc = 0. Carry-out: if inc makes sig overflow p bits (1.11…1 → 10.0…0), shift right 1 and exp += 1 (may trigger overflow).

8.5 Add / subtract algorithm

Steps (effective op determined by signs):

  1. Classify; special paths (NaN, inf, zero, ±0 rules).
  2. Order by exponent; d = exp_large − exp_small.
  3. Shift smaller significand right by d, capturing shifted-out bits into G,R,S (sticky = OR of all bits past round position).
  4. Effective add (like signs) → may carry out → normalize right 1. Effective subtract (unlike signs) → may cancel leading bits → normalize left (renormalize), pulling in zeros (G,R,S feed back).
  5. Round (P2). Set NX if any GRS set; OF/UF at range limits. Cancellation note: massive cancellation (e.g., x − y, x≈y) yields few significant bits; sticky from the alignment is what makes the rounded result correct.

8.6 Multiply

  1. Special paths (0×inf→NaN+NV; inf×finite→inf; etc.).
  2. Full product P = sig_a × sig_b = up to 2p bits.
  3. exp = exp_a + exp_b (+ normalization adjust).
  4. Normalize: top bit of P sets whether to shift 1.
  5. Round using bits below position p: G = bit p+? , S = OR of the rest of the 2p-bit product. Exact because the full product is retained.

8.7 Divide

  1. Special paths (x/0→inf+DZ for finite x≠0; 0/0,inf/inf→NaN+NV).
  2. Compute quotient significand to p bits plus guard + round, with a remainder to derive sticky exactly.
    • Restoring/non-restoring long division: produce p+2 quotient bits; sticky = (final remainder ≠ 0).
    • OR Newton-Raphson reciprocal: q ≈ a × recip(b); refine to p+2 good bits; compute residual a − q·b sign/zero → guard/round/sticky.
  3. exp = exp_a − exp_b (+ adjust).
  4. Round; NX if remainder ≠ 0.

8.8 Square root

  1. Special paths: sqrt(−x) (x>0)→NaN+NV; sqrt(−0)=−0; sqrt(+inf)=+inf; sqrt(NaN) propagate.
  2. Even-exponent reduction: factor 2^(2k) so radicand mantissa ∈ [1,4).
  3. Digit-recurrence (SRT-style) or Newton-Raphson for 1/√ then multiply; produce p+2 bits.
  4. Correct rounding via remainder sign: compare result² (or (result±½ulp)²) to radicand to decide round direction exactly. NX if not a perfect square.

8.9 Fused multiply-add

  1. Special paths including the FMA-specific (0×inf)+c and inf+(-inf) orderings (NV where mandated).
  2. Exact product P = sig_a × sig_b (2p bits), exp_p = exp_a + exp_b.
  3. Align addend c against P (shift to common exponent; the wider of product/addend ranges sets the field; capture sticky on the short side).
  4. Add/subtract in the wide accumulator; normalize.
  5. Single rounding to p bits. NX/OF/UF from the one rounding. No intermediate rounding of P.

8.10 Exception flags

Flag Code Raised when
Invalid NV sNaN operand; 0/0,inf−inf,0×inf,inf/inf; sqrt(neg); invalid conversion (NaN/inf→int, out of range with no defined result); remainder by 0 / of inf
DivByZero DZ finite nonzero / ±0 (exact-infinite result from finite operands)
Overflow OF rounded result's exponent > emax (magnitude too large); accompanied by NX
Underflow UF nonzero result tiny (below min normal) and inexact (per default "after rounding, inexact" definition); accompanied by NX
Inexact NX rounded result ≠ exact result (any G/R/S caused rounding, or overflow/underflow rounded)

8.11 NaN details

  • Quiet bit = MSB of trailing significand. qNaN sets it; sNaN clears it (with ≥1 other payload bit set).
  • sNaN as operand → raise NV, return a qNaN (quieted: set MSB, preserve remaining payload where possible).
  • Which-NaN selection (two NaN operands): return one input NaN quieted; this library's rule = prefer the first operand's NaN, else second; payload preserved. Documented + tested (the standard leaves it implementation-defined; we fix it for determinism, I15).
  • NaN never compares ordered; any compare with NaN → Unordered; equality with NaN is false (even NaN==NaN).

8.12 Conversions

Conversion Rule
int → float round per mode (large ints inexact → NX); sign preserved
float → int round-to-integral toward chosen direction then truncate to int; out-of-range / NaN → NV + defined result (e.g., saturate or INT_MIN per ABI)
float → wider float exact (no rounding); subnormal source becomes normal in wider format
float → narrower float round per mode; may overflow→inf (OF) or underflow→subnormal/0 (UF)
round-to-integral per mode; result is an integral float; NX only if mode-dependent variants require (the "exact" variant raises NX, the others do not)

8.13 Decimal formats

IEEE decimal interchange = sign(1) + combination(5) + exponent-continuation(w) + coefficient-continuation(t).

Format bits w t precision p (digits) emax emin exponent bias
decimal32 32 6 20 7 96 −95 101
decimal64 64 8 50 16 384 −383 398
decimal128 128 12 110 34 6144 −6143 6176

Combination field encodes the two most-significant exponent bits and the most-significant digit (MSD) jointly (because MSD ∈ 0..9 needs <4 bits, leaving room). Two encodings of the coefficient continuation:

  • BID (Binary Integer Decimal): coefficient is one plain binary integer; arithmetic is binary-integer on the coefficient. Fast on binary hardware.
  • DPD (Densely Packed Decimal): 3 decimal digits packed per 10-bit declet (1000 values < 1024); coefficient is a digit string. Compact, decimal-native.

Cohort: a finite decimal value has many representations (coeff × 10^exp) (e.g., 1.0 = 10×10⁻¹ = 1×10⁰ = 100×10⁻²). The set is the cohort. Operations pick a preferred exponent per the standard (e.g., add/sub prefer the smaller exponent of operands). Equality is by value, not encoding.

Decimal rounding modes: the five binary modes plus roundHalfUp, roundHalfDown, roundDown, roundUp, roundCeiling, roundFloor (the RoundPolicy enum, §11). Default for IEEE decimal ops = roundTiesToEven; default for Money = HalfEven.

8.14 Fixed-point / money

Money { amount: BigDecimal{ unscaled: BigInt(#370), scale: i32 }, currency: Currency, policy: RoundPolicy }

Value = unscaled × 10^(−scale). Arithmetic stays exact (scales reconcile by widening) until an explicit quantize(scale, policy) applies rounding. Currency carries the canonical minor-unit scale (USD=2, JPY=0, BHD=3). Q-format fixed-point (Qm.n, binary scaled int) supported as a separate FixedQ type for embedded DSP use.

8.16 Malformed / edge cases

  • sNaN propagation across every op (must quiet + NV).
  • +0.0 vs −0.0: 1/−0 = −inf; (+0)+(−0)=+0 (RNE), (−0)+(−0)=−0; min(+0,−0),max sign rules.
  • Overflow at emax: result magnitude just above max finite → inf (RNE/RNA) or max finite (RTZ, and directed toward zero) → OF+NX.
  • Gradual underflow at emin: rounding a tiny exact value into the subnormal range → UF+NX; result may round up to min normal (boundary case must be exact).
  • Max subnormal → min normal boundary: max_subnormal + 1ulp = min_normal; the carry from subnormal into the implicit-bit position must set the exponent correctly.
  • Double-rounding pitfall: rounding to extended precision then to target; forbidden — must round once to target (relevant to FMA and to narrowing conversions).
  • Ties in each mode: construct exact-half cases and assert RNE→even, RNA→away, RTP/RTN/RTZ→directed.

8.17 State table — rounding decision

sign × mode × G × S' → {truncate, increment} (S' = R|S; L used only for RNE ties):

mode G S' L decision
RNE 0 x x truncate
RNE 1 1 x increment
RNE 1 0 0 truncate (tie→even, LSB already 0)
RNE 1 0 1 increment (tie→even)
RNA 1 x x increment
RNA 0 x x truncate
RTZ x x x truncate
RTP (sign=+) (G|S')=1 increment
RTP (sign=−) any truncate
RTN (sign=−) (G|S')=1 increment
RTN (sign=+) any truncate

Design principles (§6)

  • Correct rounding is non-negotiable. Every algebraic op returns the correctly-rounded image of the exact real result (≤0.5 ulp). Mechanism: guard+round+sticky are mandatory; cores must preserve enough low-order information. Tradeoff: more intermediate width + a remainder step for div/sqrt. Operational: TestFloat diff is the gate. Violation: off-by-1-ulp results that pass casual tests but fail conformance and silently corrupt downstream numerics.
  • No hardware float in the core. Determinism + FPU-less targets demand integer-only arithmetic. Mechanism: f32/f64 banned in bits/binary/decimal via lint + a core feature that does not link any float intrinsic (ADR-02). Tradeoff: slower, more code. Violation: non-reproducible bits across targets; impossible on no-FPU MCUs; secret double-rounding through an x87 80-bit register.
  • Exception flags are first-class sticky state. NV/DZ/OF/UF/NX accumulate in an explicit FpContext, never thrown, never reset implicitly. Tradeoff: every op takes &mut FpContext. Operational: flags are asserted in conformance vectors. Violation: a "fast" path that skips flag updates passes value checks but fails flag checks; consumers relying on Inexact (e.g., exact-arithmetic detection) break.
  • NaN propagation follows the standard exactly. sNaN input → qNaN output + raise NV; qNaN propagates quietly; the which-NaN selection and payload rules are obeyed. Tradeoff: extra branches on every op entry. Violation: sNaN silently treated as qNaN hides signaling errors; nondeterministic NaN payloads break differential tests.
  • Signed zero and signed infinity semantics preserved. +0 ≠ −0 in sign bit though they compare equal; 1/+0=+inf, 1/−0=−inf; x+(-x)=+0 (RNE). Violation: losing −0 breaks branch-cut conventions (complex libs) and reciprocal sign.
  • Gradual underflow, never flush-to-zero (core). Subnormals are computed exactly and rounded; UF flag set per standard. Tradeoff: a separate subnormal alignment path. Violation: FTZ changes results near emin, breaks the max-subnormal→min-normal continuity, fails conformance.
  • FMA rounds once. a*b+c keeps the full 2p-bit product, aligns c against it, and rounds the single combined result. Tradeoff: widest intermediate in the library. Violation: rounding the product first (double rounding) gives a different, wrong bit pattern; defeats the entire reason FMA exists.
  • Decimal for exact base-10; money never in binary float. Currency lives in decimal*/BigDecimal/Money, never binary64. Violation: 0.1+0.2≠0.3 errors accumulate into accounting discrepancies.
  • Banker's rounding (half-even) is the money default. Eliminates the upward bias of half-up over many transactions. Tradeoff: surprises users expecting half-up; policy is explicit + overridable. Violation: systematic rounding bias in aggregates.
  • Determinism + bit-exact cross-platform. Identical inputs + mode produce identical bits on any architecture, compiler, opt-level. Mechanism: integer-only, no fast-math, no reassociation, fixed evaluation order. Violation: "works on my machine" numeric bugs; broken reproducible builds.
  • Test against the standard's own vectors. Self-authored tests are necessary but insufficient; Berkeley TestFloat + IBM decTest + a slow-exact oracle are the authority. Violation: shared blind spots between implementation and home-grown tests pass while real conformance fails.
  • One rounding unit, one source of truth. All ops funnel GRS through a single round() component (P2). Tradeoff: a slightly more general interface. Violation: per-op ad-hoc rounding drifts; bugs must be fixed N times.
  • Special values handled before the cores. inf/NaN/zero resolved at a fast-path layer; cores only see finite, classified operands. Violation: cores littered with if inf checks, easy to get an ordering wrong (e.g., inf*0 vs inf+(-inf)).
  • Lightweight schemas, never source. Blueprint carries signatures, bit-layouts, ≤2-line rounding fragments; no function bodies (CRITICAL RULE 10).
  • Reproducible, audited dependencies. Only #370 Bignum + std test-only crates; cargo deny/vet; SBOM. Violation: a transitive crate pulling libm/hardware float into the core silently breaks Principle 2.
