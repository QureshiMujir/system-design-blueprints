8.1 Token model (js-lexer)

8.2 Grammar (EBNF, ES2023 — abridged, load-bearing productions)

Script        ::= StatementList?
Module        ::= ModuleItemList?
ModuleItem    ::= ImportDeclaration | ExportDeclaration | StatementListItem

Statement     ::= Block | VariableStatement | EmptyStatement | ExpressionStatement
                | IfStatement | BreakableStatement | ReturnStatement | ThrowStatement
                | TryStatement | LabelledStatement | WithStatement | DebuggerStatement
IterationStatement ::= "do" Statement "while" "(" Expression ")" ";"
                | "while" "(" Expression ")" Statement
                | "for" "(" ForHeader ")" Statement
ForHeader     ::= Expression? ";" Expression? ";" Expression?
                | (("var"|LexicalKw) ForBinding | LeftHandSide) ("in"|"of") Expression
LexicalDeclaration ::= ("let"|"const") BindingList ";"
Expression    ::= AssignmentExpression ("," AssignmentExpression)*
AssignmentExpression ::= ConditionalExpression | ArrowFunction | YieldExpression
                | LeftHandSide AssignmentOperator AssignmentExpression
ShortCircuitExpression ::= LogicalORExpression | CoalesceExpression
CoalesceExpression ::= CoalesceExpr "??" BitwiseORExpression  (* ?? NOT mixable w/ &&,|| *)
UnaryExpression ::= ("delete"|"void"|"typeof"|"+"|"-"|"~"|"!"|"await") UnaryExpression
                | UpdateExpression
LeftHandSide  ::= NewExpression | CallExpression | OptionalExpression
OptionalExpression ::= (MemberExpr|CallExpr) OptionalChain  (* ?. *)
ArrowFunction ::= ArrowParameters [no LT] "=>" ConciseBody
CoverParenthesizedExpressionAndArrowParameterList ::=
      "(" Expression? ")" | "(" Expression "," ")" | "(" ")" | "(" "..." BindingElement ")"
    | "(" Expression "," "..." BindingElement ")"

ImportDeclaration ::= "import" ImportClause FromClause ";" | "import" ModuleSpecifier ";"
ImportClause  ::= ImportedDefaultBinding ("," (NameSpaceImport | NamedImports))?
ExportDeclaration ::= "export" ExportFromClause FromClause ";"
                | "export" NamedExports ";" | "export" VariableStatement
                | "export" Declaration | "export" "default" (HoistableDecl|ClassDecl|AssignExpr ";")

8.4 ASI decision table (P6)

# Trigger Inserts? Example
1 offending token preceded by ≥1 LineTerminator yes a=1\nb=2 → a=1; b=2;
2 offending token = } yes {1\n2} → {1;2;}
3 end of input, incomplete production yes x=1 (EOF) → x=1;
4 restricted production w/ LT present yes return\nx → return; x;
5 postfix ++/-- with LT before operator yes a\n++b → a; ++b;
6 inside for( ; ; ) header no syntax error
7 token is grammatically valid on next line no a\n.b → a.b

Restricted productions (LOCKED): return, throw, break, continue, postfix ++/--, arrow => params, yield.

8.5 Worked example A — const f = (a, b) => a ?? b;

Lex (Script): Keyword(const) Ident(f) Punct(=) Punct(() Ident(a) Punct(,) Ident(b) Punct()) Punct(=>) Ident(a) Punct(??) Ident(b) Punct(;) Eof

Cover→refine: (a, b) parsed as CoverParenthesizedExpressionAndArrowParameterList; on => [no LT] reinterpreted as ArrowParameters (single-pass refine, not re-parse).

Scopes: Scope#0 Global [f: Const, tdz→false@init] · Scope#1 Function(arrow) [a: Param, b: Param]

f TDZ until const initializer; ?? is LogicalExpression, not mixable with &&/||.

8.6 Worked example B — cyclic module pair (live binding)

Parse: a.js, b.js → SourceTextModuleRecord{status:Unlinked} each.

Link (DFS, Unlinked→Linking→Linked): ResolveExport(a,"a"), ResolveExport(b,"b") → resolved; b in a.js → indirect (LIVE) slot → b.js's ModuleEnv.

Evaluate: post-order, cyclic-safe via status guard; a=1 first, b=a+1=2; getB() reads live binding.
