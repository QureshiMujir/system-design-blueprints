⬜ Phase 1 — Lexer / scanner (ECMA-262 §11-12) §13

Objectives

js-lexer crate no_std + alloc. Produce Token<'s> stream from &'s str — pull model (next_token(goal: LexGoal)), zero-copy slices. GOAL-DIRECTED: parser supplies LexGoal per / site. Signal ASI via had_line_terminator. Never panic on any byte sequence.

Deliverable

Lexer<'s> callable via next_token(goal); jsfront lex <file> → NDJSON token stream. Round-trips: concat of all raw == source byte-for-byte.

Acceptance
metric target
panic-freedom 0 panics over fuzz corpus (≥10M iters)
raw round-trip 100% byte-identical reconstruction
throughput ≥30 MB/s single-thread (ASCII-heavy)
Token<'s> size ≤32 bytes (size_of asserted)
Test262 lex subset 100% pass on §11/§12 fixtures
Fixtures
file expects
ident_escape.js (abc) Ident("abc") cooked, CowStr::Owned
numeric_sep.js (1_000, 0x_F ✗) ok; 0x_F → InvalidNumber
template_nested.js brace-stack depth 2; head/mid/tail correct
regex_vs_div.js (a/b/g vs /re/g) depends on supplied LexGoal
malformed: unterminated_string.js, legacy_octal_strict.js error token, no panic
Pitfalls
  • Regex/div misresolve — root: lexer guessing without goal. Debug: dump (pos, goal) at each /.
  • Template } ambiguity — root: } is both Punct and template resume. Fix: template_brace_stack.
  • ?. before digit — x?.3 is x ? .3, NOT optional chain. Guard: peek next char.
  • Lone surrogates in \u — Rust char rejects surrogates; store cooked as WTF-8 marker.
  • CRLF as one terminator — \r\n = ONE LineTerminator; cursor coalesces.

⬜ Phase 2 — Expression parser (Pratt) §14

Objectives

Parse arbitrary ES2023 expressions → ESTree Expr with correct precedence + associativity + byte Spans. Pratt precedence-climbing core; LHS atoms via recursive descent. Drive LexGoal correctly. Cover-grammar arrow refine = P5; stub as InvalidCover until then.

Deliverable

parse_expr reachable via parse_script; jsfront parse --expr <src> emits ESTree JSON.

Acceptance
  • 2**3**2 → right-assoc; a,b,c → flat Sequence len 3; a?.b.c?.() → one OptionalChain.
  • a ?? b || c rejected; diff vs Acorn ESTree byte-identical on corpus/expr/*.js (≥200 cases).

Pitfalls
Pitfall Root cause Debug
/ mis-lexed after ) LexGoal not set Div post-primary dump (tok, goal) trace
** left-assoc equal lbp/rbp rbp = lbp-1 for right-assoc
??+` ` silently accepted
optional chain over-wrapped ?. re-wraps each link wrap once at chain root

Complete Stmt + Decl grammar → ESTree. Cover ECMA-262 §14: var/let/const, Block, If, iteration, While/DoWhile, Switch, Try, Return/Throw/Break/Continue, Labeled, With, Empty, Debugger. Emit hoisting markers into AST for P8. Thread ParseCtx flags for context-sensitive early errors.

Deliverable

parse_script/parse_module parse full statement grammar; jsfront parse <file> round-trips fixtures.

Acceptance
  • All §3.5 well-formed fixtures parse; ESTree JSON byte-diff-equal vs Acorn.
  • with in strict/module → EarlyError; for await outside async → IllegalAwait.
  • Statement throughput ≥12 MB/s on bench statements.js.

⬜ Phase 8 — Static semantics: scope, binding, hoisting, TDZ §20

Deliverable
