⬜ Phase 0 — Workspace Skeleton + Governance §12

Objectives
  • Establish Cargo workspace with the 12 crates (§1.6), CI matrix (host + thumbv7em-none-eabihf), governance docs, and the no_std/no-alloc gate. No estimation logic yet.
Deliverable
  • cargo build + cargo test green on host; core crates build for thumbv7em; CI passes on empty stubs.
Acceptance
  • All 12 crates compile (host + thumbv7em for the six no_std crates). Clippy clean. nostd.yml proves no alloc symbol in core. Docs present and linked.
Fixtures
  • conformance/synthetic/circle.spec (placeholder), zupt.spec, figure8.spec declared (no golden yet). datasets/README.md lists EuRoC/KITTI checksums.
Pitfalls
  • no_std drift: a transitive std-only dep silently re-enables std → MCU build breaks late. Root cause: default features. Detect: thumbv7em CI from day 1. Recovery: default-features=false.
  • Float-contraction nondeterminism: default codegen may emit FMA → replay hash differs across CPUs. Detect: determinism CI. Recovery: pin target-feature flags.
  • Workspace feature unification: one crate's std feature leaks via feature unification. Detect: separate no_std build job. Recovery: avoid shared optional std features.

⬜ Phase 1 — Fixed-Size Linear Algebra Core (no_std) + Decompositions §13

Objectives
  • sf-linalg: stack-allocated Vector<S,N>, Matrix<S,R,C>; arithmetic; Cholesky, LU, QR; SPD utilities. Zero alloc, compile-time dimension checking, deterministic.
Deliverable
  • Linear algebra crate passing decomposition + SPD + dimension tests on host and thumbv7em.
Acceptance
  • Aᵀ=A, A≻0 ⇒ Cholesky reconstructs A within 1e-10 (f64) / 1e-4 (f32). solve residual ‖Ax−b‖ < 1e-9 (f64). Non-PD matrix returns Err. Dimension mismatch is a compile error (trybuild test). No heap allocation (alloc-counter test = 0).
Fixtures
  • tests/decomp.rs: Hilbert matrix (ill-conditioned) detects high condition number; spd.rs: random SPD via A=BBᵀ; dims.rs (trybuild): Matrix<_,3,4>·Matrix<_,3,3> fails to compile.
Pitfalls
  • Silent loss of symmetry in A−B of nearly-equal matrices → false non-PD. Root: catastrophic cancellation. Detect: symmetry assert. Recovery: symmetrize before Cholesky.
  • Householder sign choice wrong → QR instability. Detect: reconstruction test. Recovery: choose sign to avoid cancellation.
  • f32 Cholesky on near-singular → spurious Err. Detect: condition-number gauge. Recovery: regularize +εI (callers, not in primitive).
  • Row-major vs column-major confusion in block ops → transposed sub-blocks. Detect: block round-trip test.

⬜ Phase 2 — Quaternion + SO(3)/SE(3) + Coordinate Frames/Transforms §14

Objectives
  • sf-math: Hamilton quaternion algebra, exp/log, SO(3)/SE(3), skew, DCM, frame conversions (LLH↔ECEF↔NED/ENU), gravity model, lever-arm transforms. Conventions LOCKED (§8.6–8.7).
Deliverable
  • Math crate: quaternion + frame conversions validated to reference values; no_std.
Acceptance
  • q⊗q⁻¹=identity (1e-12 f64). Log(Exp(φ))=φ for ‖φ‖<π (1e-10). R(q) orthonormal (RᵀR=I, det=+1). llh→ecef→llh round-trip < 1e-3 m. gravity_ned within 1e-3 m/s² of WGS-84 table at test latitudes. No alloc.
Fixtures
  • tests/quat_props.rs: random unit quats, associativity of mul, double-cover sign handling; exp_log.rs: near-zero and near-π angles; frames.rs: known LLH (e.g. equator, pole-adjacent) ↔ ECEF golden values; ENU/NED sign relationship R_enu = P·R_ned.
Pitfalls
  • JPL vs Hamilton inversion: wrong product order flips composition. Manifestation: attitude rotates opposite. Detect: from_two_vectors aligns gravity to [0,0,1] body when level. Recovery: single-sourced product, property test.
  • exp/log near singularities: ‖φ‖→0 (div by zero) and ‖φ‖→π (sign). Detect: small-angle branch test. Recovery: Taylor expansion / sign canonicalization.
  • ECEF→LLH iteration non-convergence near poles. Detect: pole-adjacent fixture. Recovery: closed-form Bowring + iteration cap.
  • NED/ENU mixup: down vs up sign on baro/gravity. Detect: stationary vertical test. Recovery: frame flag single-sourced (Principle 5).
  • Euler gimbal lock at pitch ±90°. Manifestation: yaw jumps. Recovery: never filter Euler; quaternion only.

⬜ Phase 3 — State + Covariance Types; Sensor/Measurement/Timestamp Types; Buffer §15

Objectives
  • sf-state: StateVector, ErrorState, Covariance with SPD enforcement, inject/reset. sf-sensor: Measurement enum, Timestamp, SensorModel/SensorSource traits, per-sensor model stubs. sf-sync: MeasurementBuffer.
Deliverable
  • State/covariance/measurement/buffer types compile no_std; invariants enforced and tested.
Acceptance
  • After 10⁶ random injections, |‖q‖−1|<1e-6 (I1). symmetrize yields max|P−Pᵀ|<1e-12. assert_spd rejects an injected non-PD matrix. Buffer maintains ts order under random insert; overflow increments dropped and never panics. No alloc on RT path.
Fixtures
  • tests/inject_reset.rs: inject then boxminus recovers δx (small-angle); spd_enforce.rs: PD matrix + tiny asymmetric perturbation → repaired; tests/ooo.rs: shuffled timestamps drain in order; degenerate: duplicate timestamps (stable order), full buffer.
Pitfalls
  • Covariance ordering mismatch between state layout and P blocks (e.g. swapping δv/δθ). Manifestation: cross-terms wrong, slow divergence. Detect: block-labeled unit tests; finite-diff cross-check in Phase 6. Recovery: single canonical index map constant.
  • Reset Jacobian omitted after injection → covariance inconsistent with new linearization point. Detect: NEES drift in Monte-Carlo (Phase 9). Recovery: apply J P Jᵀ on reset.
  • Buffer drop policy dropping newest → permanently stale estimate. Detect: latency telemetry. Recovery: drop-oldest-unapplied.
  • Timestamp wrap/units (ms vs ns, u32 overflow). Detect: unit test; type is u64 ns. Recovery: normalize at ingest.

⬜ Phase 4 — Linear Kalman Filter + Complementary Filter Baseline §16

Objectives
  • sf-filter: Filter trait; linear Kf (predict/update with Joseph form); Complementary AHRS baseline (Mahony/Madgwick-style). Establish update plumbing, gating hook, snapshot publish.
Deliverable
  • Running linear KF on a synthetic constant-velocity target; complementary AHRS on synthetic IMU; both emit snapshots.
Acceptance
  • Linear KF on CV tracker: position RMSE within 5% of analytic steady-state KF; P matches Riccati steady-state within 1e-6. NIS of linear-Gaussian sim within 95% χ² bounds. Complementary AHRS: attitude RMSE < 2° on a synthetic level+rotate sequence (no bias). Joseph keeps P SPD over 10⁵ steps.
Fixtures
  • tests/kf_linear.rs: CV model with known Q,R; compare to closed-form Riccati. synthetic/figure8.spec: complementary AHRS attitude vs ground truth. Degenerate: R→0 (overconfident, gain→1) and R→∞ (gain→0) limits.
Pitfalls
  • Non-Joseph update drifts P non-PD over time. Manifestation: eventual NaN. Detect: SPD probe each step. Recovery: Joseph + symmetrize.
  • Gain blow-up when S near-singular (duplicate measurement). Detect: S Cholesky fail (I9). Recovery: inflate R, skip.
  • Complementary gain mis-tuning: kp too high → noisy attitude; too low → slow convergence + gyro drift. Detect: attitude RMSE + drift slope. Recovery: tune against fixture.
  • Mag disturbance corrupts heading in complementary. Detect: mag-norm deviation from reference. Recovery: gate mag by field magnitude (Phase 9/11).

⬜ Phase 5 — IMU Strapdown Mechanization (Process Model, Bias Handling) §17

Objectives
  • sf-imu: full strapdown predict — attitude exp-map integration, specific-force rotation, gravity removal, velocity/position integration; continuous→discrete F, Q; gyro/accel bias states; optional coning/sculling.
Deliverable
  • IMU-only dead-reckoning predictor producing pose/velocity/attitude with growing covariance; integrates ESKF/EKF predict.
Acceptance
  • Stationary 60 s, zero bias: position drift < 1 m, attitude drift < 0.5° (f64). With known bias injected, mechanization reproduces analytic drift within 2%. F finite-diff error < 1e-5. Coning test: pure coning motion attitude error reduced ≥10× with correction enabled.
Fixtures
  • tests/stationary.rs: zero-motion drift bound; fjac.rs: F vs numerical. synthetic/circle.spec: constant-rate yaw + centripetal accel → known circular trajectory; IMU-only drift characterized (baseline for later aided improvement).
Pitfalls
  • Gravity sign/frame error: down vs up → velocity ramps. Manifestation: vertical divergence. Detect: stationary test residual. Recovery: locked gravity_ned (Principle 5, I12).
  • First-order attitude integration at high rate accumulates coning error. Detect: coning fixture. Recovery: exp-map + coning correction.
  • Δt jitter / dropped samples over-integrate. Detect: Δt histogram; cap Δt. Recovery: inflate Q for large Δt; flag (state-machine DeadReckon).
  • Bias sign convention (a−b vs a+b) flips correction. Detect: bias-injection test. Recovery: documented ω=ω_m−b_g.
  • Q underscaling → overconfident predict → divergence under real noise. Detect: NIS. Recovery: tune PSDs from Allan variance (Phase 11).

⬜ Phase 6 — EKF with Jacobians (IMU + GPS Fusion) §18

Objectives
  • sf-filter::Ekf: nonlinear predict (IMU mechanization) + linearized covariance; analytic measurement Jacobians for GPS position/velocity (+ heading, baro). First end-to-end loosely-coupled INS/GNSS.
Deliverable
  • EKF fusing IMU + GPS (+baro, +mag heading) producing bounded-error global pose; sfctl can run a synthetic INS/GNSS scenario.
Acceptance
  • On synthetic INS/GNSS (circle/figure-8, GPS@5Hz σ=1.5 m): horizontal position RMSE < 1.0 m, velocity RMSE < 0.2 m/s, attitude RMSE < 1°, after convergence. All H finite-diff errors < 1e-5. Covariance SPD throughout. NIS within 95% χ² (consistent EKF on synthetic-Gaussian case).
Fixtures
  • tests/ekf_jac.rs: per-sensor H vs finite diff. synthetic/circle.spec,figure8.spec with GPS dropouts; degenerate: GPS-only-Z (vertical) update; heading update at high pitch. Regression: golden RMSE in conformance/synthetic/expected/.
Pitfalls
  • Wrong H attitude column sign (lever arm) → attitude-correlated position bias. Manifestation: bias grows with turn rate. Detect: finite-diff; turn-heavy fixture. Recovery: re-derive, test.
  • Linearization error under large innovation (e.g. GPS jump after outage) → inconsistent update. Detect: NIS spike. Recovery: gate (Phase 9), iterate (IEKF) if needed.
  • Yaw observability with position-only GPS at low dynamics → yaw drifts. Detect: yaw variance not shrinking. Recovery: add heading/mag or rely on acceleration excitation (§9).
  • Mag heading vs true/magnetic north (declination) → constant yaw offset. Detect: yaw bias vs GPS course. Recovery: apply declination model.
  • Baro datum drift (weather) → slow altitude bias. Detect: baro-GPS-alt residual trend. Recovery: estimate baro bias state or fuse loosely.

⬜ Phase 7 — Error-State KF (Nominal/Error Split, Injection, Reset) — Recommended Core §19

Objectives
  • sf-filter::Eskf: the recommended production core. Nominal state integrated full-precision; 15-DOF error filtered; inject + reset with reset-Jacobian. Same models as EKF but error-state-correct.
Deliverable
  • ESKF fusing IMU+GPS(+baro,mag,odo,ZUPT) — the default Filter for sfctl.
Acceptance
  • Matches EKF within 1e-3 on benign data; on aggressive attitude maneuvers, ESKF attitude RMSE ≤ EKF and NEES closer to dof. Reset keeps P SPD and consistent (NEES within bounds over Monte-Carlo, Phase 9). Inject keeps |q|=1. Same RMSE thresholds as Phase 6, met or better.
Fixtures
  • tests/eskf_consistency.rs: NEES vs ground truth over 100 Monte-Carlo runs within 95% χ²(15). synthetic/figure8.spec with high yaw rate; compare ESKF vs EKF attitude error. Degenerate: large initial attitude error (30°) — ESKF converges, EKF may not.
Pitfalls
  • Missing reset Jacobian → covariance inconsistent with relinearization → optimistic P → divergence. Manifestation: NEES below dof then blow-up. Detect: Monte-Carlo NEES. Recovery: apply J P Jᵀ.
  • Injecting into wrong sign/side (left vs right perturbation) → attitude correction inverted. Detect: differential vs EKF. Recovery: lock right-perturbation convention (§8.2).
  • Error mean not reset to 0 → double counting. Detect: error norm grows unbounded. Recovery: reset after inject.
  • Bias states uncorrected because H bias columns zero → biases never observed. Detect: bias estimate flat under excitation. Recovery: verify H includes R(q) bias coupling.

⬜ Phase 8 — Unscented KF (Sigma Points, Unscented Transform) — Alternative Back-End §20

Objectives
  • sf-filter::Ukf: derivative-free back-end via unscented transform; manifold-aware sigma handling for attitude; square-root form for conditioning. Validate against EKF/ESKF.
Deliverable
  • Working UKF back-end selectable via Filter trait; matches ESKF/EKF on benign data, more robust on strong nonlinearity.
Acceptance
  • UKF vs ESKF estimate difference < 1e-2 on benign data; on highly nonlinear measurement (e.g. heading near singularity) UKF NIS more consistent than EKF. 2n+1 sigma propagation within budget (≤600 µs M4F, m=3). Covariance SPD (square-root form never produces non-PD). Manifold mean converges (iterative averaging < 5 iters).
Fixtures
  • tests/ukf_vs_ekf.rs: identical input, compare estimates + NIS. Degenerate: α tuning extremes (very small spread → numerical; large → overshoot). Strong-nonlinearity fixture (large attitude uncertainty). Deferred: MSCKF visual-inertial sigma handling → PhaseDeferred("FINAL_BLUEPRINT §8.5").
Pitfalls
  • Naive Euclidean sigma mean on quaternion → invalid/denormalized mean attitude. Manifestation: attitude bias. Detect: |q| of recombined mean. Recovery: tangent-space (Exp/Log) averaging.
  • Matrix sqrt non-PD when P ill-conditioned → sigma generation fails. Detect: Cholesky fail. Recovery: square-root UKF / regularize.
  • Weight W_c^0 negative (with λ<0) can yield non-PD recombined covariance. Detect: SPD probe. Recovery: square-root form or scaled UKF.
  • Sigma count cost 2n+1 predicts per step — 31 mechanizations at n=15. Detect: cycle budget. Recovery: reuse DCM/structure, or restrict UKF to update-only with EKF predict.

⬜ Phase 9 — Outlier Rejection + Consistency Monitoring + Adaptive Noise §21

Objectives
  • sf-gate: Mahalanobis χ² innovation gating before every update; NIS (online) + NEES (test) consistency monitoring; divergence detection; adaptive R/Q; optional FEJ for observability consistency.
Deliverable
  • Gating + consistency layer wired into all filters; outliers rejected; health flags + adaptive noise active.
Acceptance
  • Injected outliers (10× σ GPS spikes) rejected with false-accept rate < 1% at 0.99 gate; false-reject of valid measurements < 1%. NIS within 95% χ² bounds on consistent sims. NEES within χ²(15) 95% bounds over 100 MC runs (ESKF). Divergence detector fires within N=20 windows of induced divergence. Adaptive noise restores consistency on mild model mismatch without oscillation.
Fixtures
  • tests/chi2.rs: known innovation distributions → expected accept rate. nees_mc.rs: 100-run Monte-Carlo NEES. Fixtures: outlier_burst.spec, slow_bias_drift.spec, cov_collapse.spec. Degenerate: all measurements outliers (filter holds), zero outliers (no false reject).
Pitfalls
  • Gate too tight rejects valid measurements after legitimate state jump → filter starves, diverges. Manifestation: rising covariance + high reject rate. Detect: reject-rate telemetry. Recovery: looser gate or innovation-adaptive threshold.
  • Gate too loose admits outliers → covariance collapse. Detect: NIS low then attitude error high. Recovery: tighten; cross-check with NEES.
  • Adaptive Q runaway (positive feedback) → covariance inflation → everything passes gate. Detect: trace ceiling. Recovery: bound adaptation, hysteresis.
  • Observability collapse undetected: yaw unobservable (stationary, no heading) → P_yaw may artificially shrink from linearization. Detect: observability Gramian rank / yaw variance floor. Recovery: FEJ + hold yaw variance.
  • Single-measurement gating vs joint (correlated GPS pos+vel) — gating components separately misses joint outliers. Detect: joint NIS. Recovery: gate stacked measurement jointly.

⬜ Phase 10 — Time Sync, Out-of-Order + Delayed Measurements, Latency Compensation, Interpolation §22

Objectives
  • sf-sync: robust handling of multi-rate, out-of-order, and delayed measurements; latency compensation via state cloning / OOSM; IMU interpolation; per-sensor time-offset application.
Deliverable
  • Sync layer that makes the filter order-invariant and delay-tolerant up to a bounded horizon.
Acceptance
  • Shuffled + delayed measurement stream produces estimate identical (within 1e-9) to in-order processing, up to max delay. GPS with 100 ms latency, compensated, reduces position RMSE vs naive (no compensation) by ≥30% on dynamic trajectory. History/buffer never exceeds memory ceiling. Deterministic replay hash stable under reordering.
Fixtures
  • tests/ooo.rs: random permutation of timestamps. tests/delay.rs: fixed + variable latency. Fixtures: delayed_gps.spec, multirate.spec. Degenerate: delay exceeding history (fallback to approximation + flag), simultaneous identical timestamps, time going backward at ingest (rejected by I4 at core, reordered in sync).
Pitfalls
  • Applying delayed measurement at now instead of ts → correlated error, especially under acceleration. Manifestation: position lag/overshoot. Detect: compare vs ground truth on dynamic segment. Recovery: timestamp-correct OOSM.
  • History too shallow for actual delay → silent approximation error. Detect: delay vs history-depth telemetry. Recovery: size history to max delay; flag overflow.
  • Interpolation across a state reset (attitude) using linear instead of SLERP → wrong attitude at meas time. Detect: attitude residual. Recovery: SLERP on quaternion.
  • Time offset sign (t_true=t_device±offset) wrong → systematic lead/lag. Detect: cross-correlation of innovation with motion. Recovery: estimate + lock sign (Phase 11).
  • Non-determinism from re-propagation order → replay hash drift. Detect: determinism CI. Recovery: canonical replay order.

⬜ Phase 11 — Calibration (IMU Intrinsics, Mag Iron, Extrinsics, Time Offset) §23

Objectives
  • sf-calib: offline + limited online calibration — gyro/accel bias+scale+misalignment, magnetometer hard/soft-iron, sensor-to-body extrinsics (lever arm + rotation), and per-sensor time offset. Allan variance for noise PSDs.
Deliverable
  • Calibration toolset producing a versioned parameter set consumed by ingest + models + process noise.
Acceptance
  • Accel calibration residual (gravity magnitude across orientations) < 0.01 m/s². Gyro bias estimate within 0.01 °/s of injected truth (synthetic). Mag ellipsoid fit RMS < 2% of field magnitude; corrected samples lie on a sphere. Lever-arm estimate within 2 cm on synthetic. Time-offset estimate within 1 ms. Allan variance recovers injected PSDs within 10%.
Fixtures
  • tests/mag_ellipsoid.rs: synthetic distorted field → recover hard/soft-iron. allan.rs: synthetic noise with known PSD. Fixtures: tumble6.spec, mag_sphere.spec, lever_arm.spec, time_offset.spec. Degenerate: insufficient excitation (rank-deficient extrinsics → flag), magnetic anomaly during mag cal (reject), pure-rotation-only data for lever arm.
Pitfalls
  • Insufficient motion excitation → unobservable extrinsics/scale → garbage estimates. Manifestation: huge parameter covariance. Detect: observability/rank check. Recovery: require excitation; flag low-rank.
  • Mag calibration under disturbance (nearby metal) → wrong soft-iron. Detect: residual + field-magnitude variance. Recovery: collect in clean environment; reject anomalies.
  • Declination vs calibration conflation → yaw offset absorbed into soft-iron. Detect: yaw vs GPS course post-cal. Recovery: separate declination model.
  • Online bias vs offline bias double-correction → over-subtraction. Detect: stationary residual after applying both. Recovery: single source of truth; offline sets prior only.
  • Time-offset/lever-arm aliasing (both produce motion-correlated error). Detect: joint estimation observability. Recovery: estimate jointly or fix one.

⬜ Phase 12 — Replay Harness + Dataset Conformance + Benchmarks + Real-Time Budget §24

Objectives
  • sf-replay + sf-bench + sf-cli: deterministic binary log format; EuRoC/KITTI-style loaders; RMSE/ATE/RPE evaluation; criterion benchmarks; MCU cycle-budget verification; conformance gate in CI.
Deliverable
  • End-to-end: ingest a standard dataset, produce + evaluate a trajectory, replay it bit-deterministically, and prove the real-time budget.
Acceptance
  • EuRoC (loosely coupled equivalent) ATE within target band (document per sequence; e.g. < a few % of trajectory length for the aided cases). Replay hash identical across two runs (I7) and across CI runs (same target/flags). Predict ≤ 50 µs M4F / ≤ 5 µs x86; GPS EKF update ≤ 120 µs M4F (verified by sf-bench). Memory within §4 ceiling. All prior-phase fixtures pass as regression.
Fixtures
  • conformance/euroc/*.spec + expected/*.json (golden RMSE/ATE with tolerance). kitti/seq00.spec. synthetic/* regression. Degenerate: GPS-denied stretch (dead-reckon ATE bound), sensor dropout, corrupted log (decode error handled). Replay-equality fixture across reordered input (links Phase 10).
Pitfalls
  • Dataset frame/units mismatch (EuRoC body frame, gravity-aligned) → large ATE from convention error, not algorithm. Manifestation: constant rotation offset. Detect: ATE after alignment vs before. Recovery: documented per-dataset adapter.
  • ATE alignment masking drift (Umeyama alignment hides bias). Detect: also report RPE (drift rate). Recovery: report both ATE + RPE.
  • Nondeterministic eval (float reduction order) → flaky conformance. Detect: determinism CI. Recovery: fixed reduction order, pinned flags.
  • Benchmark variance on shared CI → false regressions. Detect: criterion confidence intervals. Recovery: statistical thresholds, dedicated runner or relative gates.
  • Log-format drift breaks old logs. Detect: round-trip + version test. Recovery: versioned format + migration (Compatibility Guarantees).
