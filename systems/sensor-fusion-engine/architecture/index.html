3.2 Per-box detail (one paragraph each)

  • Sensor drivers (external). Out of scope as hardware; represented by traits + mock/dataset producers. Emit raw, device-unit, device-frame samples tagged with a device timestamp. No filtering here. Interface: SensorSource::poll() -> Option<RawSample>. Trust boundary: all input is untrusted (malformed/spoofed handled downstream).

  • sf-sensor ingest. Converts raw → canonical Measurement (SI units, documented frame, covariance R). Normalizes units, applies static calibration corrections, attaches a core Timestamp. Runs on the non-RT ingest path; may allocate at setup but not per-sample in steady state (fixed-capacity pools). External interface: submit(Measurement).

  • sf-sync MeasurementBuffer. Fixed-capacity ring buffer ordered by timestamp. Absorbs out-of-order arrival and bounded delay; supports interpolation (between IMU samples) and latency compensation (re-apply a delayed measurement at its true time via state cloning / OOSM logic). Concurrency boundary: SPSC/MPSC queue from ingest threads → drained by RT core. Backpressure: full buffer drops oldest non-applied with a counted telemetry event.

  • sf-imu strapdown predict. The RT predict step. Integrates gyro to propagate attitude (quaternion exp map), rotates specific force to nav frame, subtracts gravity, integrates to velocity then position. Computes discrete F, Q. Bounded compute, no heap. Runs at IMU rate (100–1000 Hz) on the RT thread. This is the only step allowed to run without an aiding measurement.

  • sf-filter core. Houses Filter trait + KF/EKF/ESKF/UKF. Owns the predict/update math (covariance propagation, Kalman gain, Joseph update, ESKF inject/reset, UKF sigma transform). Stateless w.r.t. sensors — receives (F,Q) from sf-imu and (h,H,R,z) from sensor models. Concurrency: single-writer to state/covariance on the RT thread.

  • sf-state store. Authoritative StateVector + Covariance + ErrorState. Enforces invariants: quaternion normalized, P symmetric PD. Only the RT thread mutates; readers get an atomically-published snapshot (double-buffer) for the Estimate API. Serializable for logging/replay.

  • sf-gate (outlier + consistency). Before applying any update, computes innovation y and S, evaluates Mahalanobis d² = yᵀ S⁻¹ y against a χ² threshold; accepts/rejects/defers. Tracks NIS (per update) and NEES (vs ground truth in test), runs divergence detection, drives adaptive R/Q. Emits health telemetry. Can veto a measurement entirely.

  • Estimate API / output. Publishes the current best estimate: position/velocity in nav frame, attitude quaternion (+ Euler convenience), bias estimates, full or marginal covariance, and health flags (gated count, NIS status, divergence flag). Lock-free read snapshot for control consumers (#289).

  • sf-replay logging/replay. Captures the full input stream + estimator outputs to a versioned binary log; replays bit-deterministically; computes RMSE / ATE / RPE against ground truth. The backbone of regression and conformance testing.

  • sf-calib. Offline (batch) and limited online calibration of IMU intrinsics, magnetometer iron, sensor-to-body extrinsics, and per-sensor time offset. Feeds parameters into ingest + models; not in the RT hot loop except online bias states (which live in the filter state itself).

3.3 Data flows / boundaries summary

  • RT boundary: predict + (gated) update + state publish. Hard real-time, bounded compute, no heap.
  • Non-RT boundary: ingest, normalization, buffering, calibration, logging.
  • Trust boundary: every measurement crosses from untrusted → validated at sf-gate before touching covariance.
  • Persistence boundary: only sf-replay persists (logs); core holds no disk state.

8. Domain Model / Math

8.1 State vector (nominal)

x = [ p (3), v (3), q (4, body→nav, Hamilton), b_g (3), b_a (3) ], dim 16. Frame: p,v in nav (NED); q maps body→nav; biases in body.

8.2 Error-state (15-DOF)

δx = [ δp (3), δv (3), δθ (3), δb_g (3), δb_a (3) ]. Attitude error is a 3-vector rotation in the tangent space; nominal/error relation (right perturbation): q = q_nom ⊗ δq, δq ≈ [1, ½ δθ]ᵀ. (Convention locked: right/local error, Hamilton.)

8.3 Process model (IMU strapdown mechanization)

Inputs: gyro ω_m, accel a_m (specific force). Corrected: ω = ω_m − b_g − n_g, a = a_m − b_a − n_a. Continuous nominal kinematics (nav = NED, g = local gravity vector):

ṗ = v
v̇ = R(q) a + g
q̇ = ½ q ⊗ [0, ω]
ḃ_g = n_bg   (random walk)
ḃ_a = n_ba   (random walk)

R(q) = body→nav DCM. Discretization over Δt (median IMU dt): attitude via exp map q_{k+1}=q_k ⊗ Exp(ω Δt); velocity/position via first/second-order integration (trapezoidal; optional coning/sculling correction).

Continuous error-state dynamics δẋ = F_c δx + G w, with (standard ESKF blocks, right perturbation):

δṗ = δv
δv̇ = −R(q)[a]_× δθ − R(q) δb_a − R(q) n_a
δθ̇ = −[ω]_× δθ − δb_g − n_g
δḃ_g = n_bg
δḃ_a = n_ba

[·]_× = skew. Discrete F = exp(F_c Δt) ≈ I + F_c Δt + ½(F_c Δt)²; discrete Q via Van Loan or trapezoidal of G Q_c Gᵀ.

Process-noise PSDs (continuous): gyro σ_g², accel σ_a², gyro-bias RW σ_bg², accel-bias RW σ_ba² (from datasheet noise density + bias instability).

Sensor z h(x) H (error-state) R

8.5 KF / EKF / ESKF / UKF equations

Linear KF (predict/update):

predict:  x⁻ = F x⁺ ;            P⁻ = F P⁺ Fᵀ + Q
update :  y = z − H x⁻ ;          S = H P⁻ Hᵀ + R
          K = P⁻ Hᵀ S⁻¹
          x⁺ = x⁻ + K y
          P⁺ = (I − K H) P⁻ (I − K H)ᵀ + K R Kᵀ      (Joseph form)

S⁻¹ via Cholesky solve (never explicit inverse).

EKF: h(x) nonlinear; H = ∂h/∂x|_{x⁻}, F = ∂f/∂x; predict via nonlinear f, covariance via Jacobian F. Jacobians verified by central finite differences (tol 1e-5 f64).

ESKF (recommended core): split nominal x (integrated full-precision) and error δx (filtered, mean 0 between resets).

predict: nominal integrated (no covariance growth from nominal);
         δx⁻ = F δx⁺ (mean stays 0) ; P⁻ = F P⁺ Fᵀ + Q
update : y = z − h(x_nom) ; S = H P⁻ Hᵀ + R ; K = P⁻ Hᵀ S⁻¹
         δx⁺ = K y ; P⁺ Joseph
inject : x_nom ← x_nom ⊞ δx⁺   (⊞: p,v additive; q ← q ⊗ Exp(δθ); biases additive)
reset  : δx ← 0 ; P ← J P Jᵀ  (J = reset Jacobian ≈ I − ½[δθ]_× on attitude block)

ESKF advantages: error stays small (linearization valid), attitude minimal (3-DOF), no quaternion-norm constraint in P.

UKF (alternative back-end): unscented transform; 2n+1 sigma points (n=error-dim or augmented), weights:

λ = α²(n+κ) − n
χ₀ = x̄ ; χ_i = x̄ ± (√((n+λ)P))_i      (columns of matrix sqrt, Cholesky)
W_m^0 = λ/(n+λ) ; W_c^0 = λ/(n+λ)+(1−α²+β) ; W_{m/c}^i = 1/(2(n+λ))

Propagate sigmas through f/h; recombine mean/covariance; cross-covariance P_xz; K = P_xz S⁻¹. On manifolds: sigma points generated in tangent space, mapped through Exp, recombined via iterative mean (or simple for small spread). Square-root UKF preferred for conditioning.

Complementary filter (baseline): fuse high-pass gyro integration with low-pass accel/mag attitude: q_{k+1} = q_k ⊗ Exp((ω + k_p e) Δt), e = error between measured and predicted gravity/mag direction (Mahony) — no covariance, O(1), used as a sanity baseline and fallback.

8.6 Quaternion algebra (Hamilton — LOCKED)

  • Storage q = [w, x, y, z], scalar-first, Hamilton product (i j = k). JPL convention is not used anywhere (single-sourced in sf-math).
  • q maps body→nav (active rotation of a body vector into nav frame).
  • Exp: R³→S³, Exp(φ) = [cos(‖φ‖/2), sin(‖φ‖/2) φ/‖φ‖]; small-angle ≈ [1, ½φ].
  • Log: S³→R³ inverse; Rotvec = Log × 2 mapping to SO(3) tangent.
  • R(q) ∈ SO(3); derivative w.r.t right error: R(q⊗Exp(δθ)) ≈ R(q)(I+[δθ]_×).
  • Renormalize after each injection; sign-fix w≥0 to avoid double cover ambiguity in logs.

8.7 Frames & transforms (LOCKED defaults)

  • Navigation frame: local NED (North-East-Down) tangent at a fixed reference origin. (ENU adapter provided; one flag at construction; never mixed at runtime.)
  • Frames: body (b), nav (NED, n), ECEF (e), geodetic LLH. Conversions: LLH↔ECEF (WGS-84), ECEF↔NED (rotation by ref lat/lon), body↔nav via R(q).
  • Lever arm l: sensor offset from IMU/body origin, body frame. GPS measures p_body + R(q) l_gps.
  • Gravity: g_ned = [0,0,+9.81…] (down positive) using a latitude-dependent gravity model.

8.8 Worked numeric example (1-D vertical, baro+IMU)

State [p_D, v_D, b_a]. IMU a_m=0, true g=9.81. Init P=diag(1,1,0.01). Baro z=0 m, R=0.04. Predict Δt=0.01: v_D⁻=v_D+(a_m−b_a−g+g)Δt (gravity cancels in down channel when at rest) → demonstrates that a stationary vehicle should show ~0 velocity; nonzero residual reveals b_a (Invariant I12 test). Update: y=z−p_D, S=P_pp+R, K=P_pp/S, Joseph P⁺. After ~50 updates b_a observable through baro+gravity coupling only weakly → illustrates partial observability (§9).

Design principles (§6)

  • Covariance stays SPD, always. Every update uses Joseph form + explicit symmetrization; failure ⇒ negative variance ⇒ NaN gain ⇒ divergence. Enforced at write boundary of sf-state; violation is a hard fault with telemetry. - Tradeoff: Joseph costs ~2× a naive (I−KH)P. Operational: cheaper than recovering a diverged filter in the field.
  • Quaternion stays normalized. |q|=1 within tol after every injection. Drift ⇒ implicit scaling of attitude ⇒ biased rotation. Enforced in sf-math/sf-state. Violation breaks the rotation group assumption.
  • Error-state over full-state for attitude. Attitude lives on SO(3); a 3-DOF error in the tangent space (MEKF/ESKF) avoids quaternion-norm constraint singularities and keeps P minimal-dimension. Violating it (filtering the 4-vector directly) creates a rank-deficient covariance.
  • Innovation gating before every update. No measurement touches P before passing the χ² gate. Skipping ⇒ one spoofed/outlier sample can collapse covariance. Enforced in sf-gate.
  • Frame conventions explicit and single-sourced. Every quantity carries (or is documented with) a Frame. One module defines NED/ENU/ECEF/body; no ad-hoc conversions. Mixing NED/ENU or Hamilton/JPL silently flips signs → catastrophic, hard-to-find errors.
  • Bounded compute in the hot loop. Predict + update are O(n²)/O(n³) with fixed n; no allocation, no unbounded iteration. Violation ⇒ deadline miss ⇒ dropped IMU samples ⇒ attitude drift.
  • Determinism over convenience. Given (init, stream, params, target, flags) → identical output. No wall-clock, no RNG in core, no FMA contraction unless globally fixed. Enables replay-based debugging and conformance.
  • Numerical stability over micro-optimization. Prefer Cholesky/square-root forms and conditioning checks over the fastest algebraic shortcut. A faster but ill-conditioned update is worthless after an hour.
  • Observability monitored, not assumed. Track which states are observable given current sensor set; apply FEJ where needed; flag observability collapse (e.g. yaw unobservable when stationary without mag/GNSS heading).
  • Consistency is measured. NIS per update and NEES in Monte-Carlo tests must lie within χ² bounds; a "confident but wrong" filter is the worst failure. Drives adaptive noise and alerts.
  • Time is monotonic at the core. The filter advances only forward in time; all reordering/delay handled in sf-sync before the core. Non-monotonic time ⇒ negative dt ⇒ unstable propagation.
  • Models are explicit and testable in isolation. Each sensor model (h,H,R) is a unit, validated by finite-difference Jacobian checks and against analytic truth.
  • Type-level dimension safety. Matrix dimensions are const-generic; mismatched multiplies fail at compile time, not runtime.
  • Fail loud, contain locally. A bad sensor degrades that channel (reject + flag), never silently corrupts the shared state.
  • Replayability first. Every input and decision is loggable; nothing in the core is observable only via a debugger.
