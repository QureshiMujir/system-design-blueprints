Box-by-box (one paragraph each).

Front ends (cli/server/ffi/wasm). Thin adapters that translate external requests (set_cell, get_value, recalc, insert_rows) into core API calls. The server holds one Workbook per session; reads serve from an immutable Arc<Snapshot> (snapshot isolation) so a long read never blocks a write and never sees a half-finished recalc. No business logic here; all semantics live in core. WASM/FFI expose the same Workbook API across an ABI.

Workbook (owner). The single owner of all sheets, the named-range table, the dependency graph, the function registry, and the op-log. All mutation funnels through it (&mut self); it is the concurrency root. It enforces invariants (no dangling refs, acyclic-or-flagged graph, dirty-set ⊇ all affected). It produces snapshots for readers and applies/undoes ops atomically.

Lexer (sheetcalc-lex). Converts formula text into a token stream: numbers, strings, booleans, errors, operators, references, function names, separators, parens, braces, ranges. Locale-aware on argument separator (, vs ;) and decimal point. Pure, allocation-light, streaming; produces precise spans for diagnostics. No semantics — just lexical structure.

Parser (sheetcalc-parse). Pratt / precedence-climbing parser producing a FormulaAst. Encodes the full operator precedence/associativity table, unary +/-/%, range :, intersection (space), union ,, comparison, concat &, exponent (right-assoc). Emits structured parse errors (→ #NAME?/#ERROR! paths). ASTs are interned/shared so identical formulas reuse one tree.

Reference model (sheetcalc-ref). Resolves textual references against the current sheet/cell context: relative A1, absolute $A$1, mixed, cross-sheet Sheet1!A1, quoted 'My Sheet'!A1, named ranges, R1C1 (R[1]C[-2]). Produces canonical CellId/RangeRef. Owns the named-range table. Critical for reference fixup on structural edits (the offset math lives here).

Cell store (sparse columnar). The data plane: stores per-cell value/formula/format sparsely (most of a 1M×16K grid is empty). Columnar layout (column → sorted run/interval map) for cache-friendly column scans (SUM(A:A)) and cheap row/col insert. Holds CellValue, optional FormulaAst handle, cached evaluated result, format id, spill metadata. Mutated only via Workbook; readable from snapshots.

Dependency graph (sheetcalc-graph). Bidirectional graph: precedents (cells/ranges a formula reads) and dependents (cells whose formula reads this cell). Supports topo order via Kahn, SCC via Tarjan for cycle detection. Edge cardinality can be huge (a range precedent = one edge to a range node, not N edges) — range nodes avoid O(N²) blowup. Rebuilt incrementally as formulas change.

Function registry (sheetcalc-fn). Maps function name → metadata (arity, arg coercion rules, volatility, array-awareness) + evaluator. ~120 functions across math/stat/logical/lookup/text/date/info/financial. Tracks the volatile set (NOW/TODAY/RAND/RANDBETWEEN/OFFSET/INDIRECT/CELL/INFO) so recalc always re-evaluates them. Pluggable: hosts can register custom functions.

Recalc engine (sheetcalc-recalc). The orchestrator. On dirty cells: compute affected set (forward closure over dependents), topo-order them, evaluate in order, handle spills (re-anchor, detect #SPILL!), run cycle/iterative loop for SCCs, and (P10) farm independent subgraphs to a work-stealing pool under snapshot isolation. Emits recalc traces + metrics.

Evaluation engine (sheetcalc-eval). Tree-walks one cell's AST against an EvalContext (snapshot of precedent values + sheet context + registry). Implements type coercion (text↔number↔bool), the error model + first-error propagation, comparison semantics, array broadcasting, implicit intersection. Pure w.r.t. a snapshot — same inputs → same output (determinism invariant).

Dynamic arrays (sheetcalc-array). Handles array results that spill into neighboring cells (Excel 365 dynamic arrays). Owns spill anchors, spill ranges, collision detection (#SPILL!), implicit intersection (@), and array broadcasting rules. Interacts tightly with the store (reserve spill region) and graph (spill region becomes precedent-affecting).

Number formatting (sheetcalc-fmt). Display layer: number format codes (#,##0.00, 0.00%, date/time patterns), locale (decimal/thousands/date order), date serials (1900 vs 1904 epoch, the Lotus 1900 leap-year bug). Separates stored value (canonical f64/serial) from displayed string. Never affects computation (formatting is presentation-only).

Undo log / op-log. Records every mutation as a reversible op (set-cell, edit, define-name). Powers undo/redo (in-memory ring) and durability (append-only WAL .scwal). On crash, replay log over last snapshot to recover. Ops are the unit of compatibility + the audit trail.

Persistence (sheetcalc-persist). Snapshot files (.scbk, full workbook image) + op-log (.scwal, incremental). CSV import/export (lossy, values only). xlsx subset (sheets, cells, formulas, basic formats; no charts/styles). Recovery = load snapshot + replay tail of op-log. Format versioning + migration handled here.

8. Domain Model / Source Language

The formula language: a small expression language evaluated per cell. A cell holds either a literal value or a formula (text beginning with =).

8.2 EBNF grammar

formula        = "=" , expr ;
expr           = compare ;
compare        = concat , { ( "=" | "<>" | "<" | "<=" | ">" | ">=" ) , concat } ;
concat         = additive , { "&" , additive } ;
additive       = multiplicative , { ( "+" | "-" ) , multiplicative } ;
multiplicative = exponent , { ( "*" | "/" ) , exponent } ;
exponent       = unary , { "^" , exponent } ;                 (* right-assoc *)
unary          = { "+" | "-" } , postfix ;
postfix        = primary , { "%" } ;                          (* percent postfix *)
primary        = number
               | string
               | bool
               | errorlit
               | array
               | "@" , primary                                 (* implicit intersection *)
               | funccall
               | reference
               | "(" , expr ")" ;
funccall       = funcname , "(" , [ arglist ] , ")" ;
arglist        = arg , { argsep , arg } ;
arg            = [ expr ] ;                                     (* empty arg allowed: ",,," *)
array          = "{" , arrayrow , { ";" , arrayrow } , "}" ;
arrayrow       = expr , { "," , expr } ;
reference      = refrange , { ( " " | "," ) , refrange } ;     (* intersection/union *)
refrange       = refprimary , [ ":" , refprimary ] ;
refprimary     = [ sheetprefix ] , ( cellref | r1c1ref | name ) ;
sheetprefix    = ( sheetname | quotedsheet ) , [ ":" , ( sheetname | quotedsheet ) ] , "!" ;
cellref        = [ "$" ] , col , [ "$" ] , row ;
col            = letter , { letter } ;                          (* A..XFD *)
row            = digit , { digit } ;                            (* 1..1048576 *)

8.3 Operator precedence / associativity (lowest → highest)

Lvl Operators Assoc Notes
1 , (union, inside refs) left also arg separator at call level
2 (space, intersection) left reference intersection
3 : (range) left binds two refs into a range
4 = <> < <= > >= left comparison → boolean
5 & left text concatenation
6 + - (binary) left
7 * / left
8 ^ right exponentiation
9 + - (unary) right sign
10 % postfix percent (×0.01)
11 @ prefix implicit intersection

Reference operators (: , space) bind tighter than arithmetic so SUM(A1:B2 B1:C3) parses references before arithmetic context. Implementation: Pratt parser with binding-power table; ^ right-assoc via rbp = lbp - 1.

Coordinate model. Internal canonical: (sheet: SheetId, row: u32 (0-based), col: u32 (0-based)) plus per-axis Abs|Rel flag for fixup. A1 column letters ↔ index via bijective base-26 (A=0, Z=25, AA=26, … XFD=16383).

8.6 Array literals & broadcasting

  • {1,2;3,4} → 2×2 inline array (rows by ;, cols by ,).
  • Broadcasting: scalar ⊕ array → elementwise; array ⊕ array of differing shape → broadcast if a dimension is 1, else #VALUE! (Excel) / #N/A per rules.
  • Array result spills (P8): writing to anchor, occupying a rectangle; collision ⇒ #SPILL!.

8.7 Error model (precedence + propagation)

Error values, precedence high→low (first encountered in evaluation order wins; for operands, the leftmost highest-precedence policy follows Excel — typically first-error-in-eval-order):

Error Trigger Precedence rank
#NULL! empty intersection of ranges 1
#DIV/0! divide by zero / MOD 0 2
#VALUE! wrong type / uncoercible operand 3
#REF! reference to deleted/invalid cell 4
#NAME? unknown name/function 5
#NUM! numeric overflow / invalid arg (SQRT(-1)) 6
#N/A value not available (lookup miss, NA()) 7
#SPILL! spill blocked 8
#CALC! array calc error (empty array, nested) 9
#CIRCULAR! circular ref (non-iterative mode) 10
#GETTING_DATA async (not used here) — (deferred)

Propagation rule. Any operand that is an error makes the result that error (short-circuit), except functions explicitly error-tolerant: IFERROR, IFNA, ISERROR, ISERR, ISNA, ISBLANK, N, TYPE, ERROR.TYPE, AGGREGATE, COUNT* (skip errors per spec). First-error-wins: in =A1+B1 where both error, the result is A1's error (eval order left→right).

8.8 Type coercion (text↔number↔bool)

Context Rule
Arithmetic (+ - * / ^ %) TRUE→1, FALSE→0; numeric text "3.5"→3.5; empty cell→0; non-numeric text→#VALUE!; blank string ""→#VALUE! in arithmetic
Concat (&) numbers→default text repr; bool→TRUE/FALSE; error propagates
Comparison (=,<…) type ordering: number < text < bool (Excel); text compare case-insensitive, locale-collated; "" vs blank distinct
Logical (IF,AND) 0→FALSE, nonzero→TRUE; text→#VALUE! unless "TRUE"/"FALSE" in some funcs
Function args per-arg declared coercion (number/text/range/any/logical)

8.9 Worked examples

=1+2*3            → 7            (precedence: * before +)
=2^3^2            → 512          (right-assoc: 2^(3^2)=2^9)
=-3^2             → 9            (unary minus binds looser than ^? Excel: =-3^2 = 9 → (-3)^2)
=10%              → 0.1          (postfix percent)
="a"&"b"&1        → "ab1"        (concat coerces number)
=SUM(A1:A3)       → 60           (A1=10,A2=20,A3=30)
={1,2;3,4}+10     → {11,12;13,14}(array broadcast)
=IF(A1>0,"pos","neg") → "pos"   (A1=10)
=Sheet2!B2*2      → cross-sheet
=VLOOKUP(3,A1:B5,2,FALSE) → exact-match lookup
=A1:A3 B1:C3      → intersection → A1:A3 ∩ B1:C3 = (empty col A) → #NULL!

=1++                  → parse error → #ERROR! (or #NAME? in some hosts)
=SUM(                 → unterminated call → #ERROR!
=NONEXISTENT()        → #NAME?       (unknown function)
=Frob                 → #NAME?       (unknown name)
=1/0                  → #DIV/0!
=SQRT(-1)             → #NUM!
=A1+"x"               → #VALUE!      (uncoercible text)
=#REF!+1              → #REF!         (error literal propagates)

={1,2}+{1,2,3}        → #VALUE!       (shape mismatch, no broadcast dim=1)

Design principles (§6)

  • Determinism over convenience. Same workbook + same inputs ⇒ bit-identical results across runs, machines, thread counts. Tradeoff: forbids unordered float reductions and HashMap iteration in compute paths. Operational: enables differential testing + replay debugging. Violation: parallel SUM with non-deterministic add order → results differ run-to-run → conformance + replay both break, bug becomes irreproducible.
  • Demand-bounded recompute (minimal recalc). Never recompute more than the forward closure of dirty cells. Tradeoff: must maintain an accurate dependents graph (memory + bookkeeping). Operational: edit latency scales with affected cells, not workbook size. Violation: full rebuild on every keystroke → 1M-cell workbook becomes unusable (seconds per edit).
  • Correctness before performance. Match reference-engine semantics (errors, coercion, edge cases) first; optimize later behind a stable oracle. Tradeoff: slower initial delivery. Operational: conformance suite is the gate. Violation: a "fast" coercion that mis-handles "" → 0 diverges from Excel → silently wrong financial models, worse than slow.
  • Errors are values, propagated first-error-wins. Excel errors (#DIV/0!, #VALUE!, …) are first-class CellValue variants with a fixed precedence; they short-circuit. Tradeoff: every operator/function must thread error checks. Operational: errors are observable, never panics. Violation: treating an error as 0 → cascading wrong results with no signal.
  • Explicit ownership; single mutation root. The Workbook owns everything; all mutation is &mut Workbook. Tradeoff: no ad-hoc shared mutability. Operational: snapshots are trivially safe (immutable Arc). Violation: two paths mutating the store concurrently → data race / torn graph → UB or corrupt dependents.
  • Snapshot isolation for reads. Readers (server, undo preview, formatting) see an immutable snapshot, never a mid-recalc state. Tradeoff: snapshot cost + memory (mitigated by structural sharing). Operational: long reads never block writes. Violation: a reader observing half-applied recalc → returns inconsistent cross-cell values (A updated, B not).
  • Volatility is explicit and minimized. Volatile functions (NOW/RAND/OFFSET/INDIRECT/…) are tagged; they always re-evaluate. Tradeoff: volatile cells defeat incrementality. Operational: warn when volatile count high; expose volatile-cell metric. Violation: forgetting to tag OFFSET as volatile → stale results after edits that should have re-fired it.
  • Range nodes, not edge explosion. A formula reading A1:A1000 creates one edge to a range node, not 1000 edges. Tradeoff: range/precedent intersection logic is more complex. Operational: keeps graph O(formulas), not O(cells touched). Violation: per-cell edges → 1M-cell SUM over a column = 1M edges → memory + topo blowup.
  • Reference fixup is arithmetic, not text. On insert/delete/move, references are rewritten by coordinate math on the structured Reference, never by string surgery. Tradeoff: every reference kind needs precise offset rules (absolute pins, relative shifts, cross-sheet). Operational: edits stay correct + fast. Violation: regex rewriting A1→A2 corrupts $A$1, NAMED, 'Sheet'!A1, strings containing "A1".
  • Stored value ≠ displayed value. Computation uses canonical f64/serial; formatting is a pure presentation transform. Tradeoff: two representations to keep in sync. Operational: changing a number format never triggers recalc. Violation: computing on the formatted string ("1,234.50") → parse errors, locale-dependent math.
  • Crash-only + replayable persistence. State = last snapshot + op-log tail; recovery = load + replay. No clean-shutdown assumptions. Tradeoff: must make ops idempotent + ordered. Operational: RTO < 5 s; no fsck-style repair. Violation: relying on in-memory-only state → crash loses everything since last save.
  • Bounded everything. Formula depth, cells, edges, iterations, spill size all capped; over-limit ⇒ a defined error, never OOM/hang. Tradeoff: some legitimate giant inputs rejected. Operational: predictable resource ceilings. Violation: unbounded recursion in a self-referential INDIRECT → stack overflow / hang.
  • Observability by default. Recalc emits traces (cells evaluated, dirty-set size, cycle count, duration) + metrics. Tradeoff: trace overhead (gated/sampled). Operational: "why is recalc slow?" answerable from telemetry. Violation: opaque recalc → cannot diagnose a runaway volatile chain in production.
  • Stable formula + file compatibility. Formula syntax + persisted format are versioned; old files load, parse forward-compatibly. Tradeoff: migration code accumulates. Operational: upgrades don't corrupt workbooks. Violation: silently changing operator precedence → existing formulas compute differently after upgrade.
  • Pure evaluation against a snapshot. Cell evaluation is a pure function of (AST, snapshot, registry); no hidden global state, no in-eval mutation. Tradeoff: must pre-gather precedent values into the context. Operational: enables parallelism + memoization + replay. Violation: eval mutating the store mid-pass → order-dependent results, races, non-determinism.
