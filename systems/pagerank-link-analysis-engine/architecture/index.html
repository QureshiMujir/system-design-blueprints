cli — parses args (ADR-12), detects input format, orchestrates load→build→rank→emit, and streams a structured per-iteration convergence log to stderr (I9). It owns exit codes (§19) and never holds graph invariants — it delegates to the library crates.

graph-io — the only code that touches untrusted bytes; everything downstream trusts its output. Parses SNAP/BV/adjacency, interns labels to dense NodeId, and computes the dangling set. All failure is a typed GraphIoError (no panics; fuzzed in Phase 9).

graph-repr — owns the in-memory graph. CsrGraph holds out-links (row = source); CscGraph holds in-links (column = destination) and carries the co-located src_out_deg_recip array so the SpMV inner loop reads reciprocals sequentially. DanglingBitVec (Roaring, ADR-07) answers is_dangling in O(1) and reduces dangling mass.

pagerank-core — the mathematical heart. One iteration = dangling-mass pre-pass → pull SpMV over CSC → scale by d → add teleportation → L1/L2 convergence check → renormalize. Hosts the RankAlgorithm trait that every variant implements (P8).

pagerank-parallel — swaps the sequential SpMV for a Rayon par_chunks_mut over disjoint destination ranges; dangling mass becomes a parallel tree-reduction (documented non-determinism, P5/I5). No locks; correctness checked against the sequential oracle.

hits / salsa / personalized-pr / trust-rank — algorithm crates behind the common trait. HITS needs both CSR and CSC (two SpMVs/iter); SALSA walks the bipartite hub/authority graph; personalized-pr offers exact and sublinear-push PPR; trust-rank is PPR over a trusted seed teleportation vector.

bench — Criterion harness; the only crate allowed to read data/. Emits GFLOP/s, MB/s, and wall-time JSON that the CI regression gate (§27) compares against a baseline.

8. Domain Model

8.1 The web graph as a Markov chain

G = (V,E), |V| = n, |E| = m, directed. PageRank r ∈ ℝⁿ is the stationary distribution of a random surfer: r[i] = long-run probability of being at page i. The link-transition matrix H is column-stochastic:

H[i][j] = 1 / outdeg(j)   if (j → i) ∈ E     (mass leaves j, split over its out-links)
        = 0               otherwise

So H·x pushes mass backward along links — rank arrives at i from its in-neighbors. This is why the kernel stores and iterates the in-link structure (CSC), not CSR (P3, MM2).

8.2 Dangling correction and the Google matrix

A node j with outdeg(j)=0 makes column j all-zero — mass vanishes. Patch with the dangling indicator a (a[j]=1 iff dangling):

S = H + (1/n) · 1 · aᵀ          (dangling columns become uniform)

S is column-stochastic. Make it irreducible+aperiodic (a unique, reachable stationary vector — Perron–Frobenius) by mixing in teleportation with damping d:

G = d·S + (1−d)·(1/n)·1·1ᵀ      Google matrix; r = G·r, ‖r‖₁ = 1

8.3 Power iteration (recurrence, not a loop)

Start r⁽⁰⁾ = (1/n)·1. The iterate is defined by the recurrence (computed as: dangling pre-pass → SpMV → scalar fold):

r⁽ᵏ⁺¹⟩ = d·H·r⁽ᵏ⁾ + [ d·(aᵀ·r⁽ᵏ⁾)/n + (1−d)/n ]·1
         └── SpMV ──┘   └──── one uniform scalar added to every node ────┘

The bracket is a single scalar (P10): c = (d·dmass + (1−d))/n, dmass = aᵀr⁽ᵏ⁾. Stop when ‖r⁽ᵏ⁺¹⟩ − r⁽ᵏ⁾‖₁ < ε.

8.4 Worked example (the tiny-4node fixture)

Edges A→B, A→D, B→C, C→A; D is dangling. outdeg = {A:2, B:1, C:1, D:0}, d=0.85, n=4, r⁽⁰⁾ = 0.25 each.

Step dmass =r[D] scalar c r[A] r[B] r[C] r[D]
k=0 0.250 (0.85·0.25+0.15)/4 = 0.0906 0.250 0.250 0.250 0.250
k=1 0.250 0.0906 0.303 0.197 0.197 0.197
k=2 0.197 0.0794 0.270 0.208 0.247 0.196
… … … converges ≈ A:0.275 B:0.198 C:0.230, D:0.166

The hand-check: A gains from C (A's only in-link) plus dangling+teleport; D, with no in-links beyond teleport, settles lowest. Σr = 1 at every step (I1). The .expected file is the NumPy/NetworkX value at ε=1e-12.

8.5 Convergence rate

The asymptotic rate equals the subdominant eigenvalue modulus |λ₂|, and for the Google matrix |λ₂| ≤ d (Haveliwala–Kamvar bound). Hence to reach ε:

dᵏ < ε  ⇒  k > ln(ε)/ln(d).   d=0.85, ε=1e-6 ⇒ k > 85.   (graph-independent upper bound)

Strong block/community structure can converge faster (Kamvar et al. 2003, §5). Larger d (→1) ranks "more faithfully" but converges slower and conditions worse — the core tradeoff a reader must feel (§32 #4, HQ3 §33).

8.7 Personalized PageRank — local push (Andersen–Chung–Lang)

Maintain estimate p and residual res; init p=0, res[s]=1. While some u has res[u] ≥ ε·outdeg(u), push u (these are mathematical updates, applied per popped u):

p[u]      += (1−d)·res[u]
res[w]    += d·res[u]/outdeg(u)      ∀ w : u→w  (out-neighbors)
res[u]     = 0

Terminates in O(1/ε) pushes, independent of n (MM5); L1 error ≤ ε·m (Phase 5, §17). A max-priority frontier keyed on res[u]/outdeg(u) orders the work.

8.8 WebGraph BV wire format (decode schema)

Successors of node v are encoded as fields (no logic — a layout the decoder consumes):

outdeg            : ζ₃ or γ integer
copy_ref_gap      : γ        (reference node v−ref, window W=7); present iff copy block used
copy_block_runs   : γ*       (alternating include/exclude run-lengths over ref's successors)
interval_count t  : γ
intervals         : t × (start_gap : γ, length : γ)   starts gap-coded from prev interval end
residuals         : γ*       remaining successors, gap-coded from last interval end or from v

All integers are γ (gamma) or ζ₃ (zeta, k=3); ζ₃ matches the ~1/x^{1+1/k} degree law of web graphs (§5 Boldi–Vigna, glossary). The decoder keeps a window buffer of the last W lists.

8.9 Malformed-input and failure-path examples

  • Malformed edge ("12\tfoo"): non-numeric dst → GraphIoError::MalformedEdge{line,detail}, exit 1 — never a partial graph.
  • Crafted CSR binary (header.m ≫ file length): rejected by I12 length+checksum check before any bytemuck cast — defeats the OOB read (Threat T4, §22).
  • All-dangling graph: dmass=1 every step ⇒ r = teleport vector, converges in one iteration (I1 holds; valid degenerate, §14 edge cases).
  • d=1.0: rejected at parse (I7) — without teleport the chain may be reducible/periodic and power iteration need not converge.
