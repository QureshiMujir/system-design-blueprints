4. System Constraints

4.1 Quantified Engineering Targets

Constraint Target
Paillier modulus n of 2048/3072/4096 bits; ciphertexts in Z_{n²} (2× bits)
Paillier security 2048-bit n ≈ 112-bit; 3072 ≈ 128-bit (NIST)
BFV ring degree n ∈ {4096, 8192, 16384, 32768} (power of two)
BFV coeff modulus q = product of 1–8 NTT primes, total 109–881 bits per SEAL tables
BFV plaintext modulus t prime, ~16–60 bits; t ≡ 1 mod 2n for batching
BFV security ≥128-bit per LWE estimator for (n,q,σ=3.2)
Multiplicative depth L configurable 0–~8 (leveled; no bootstrapping)
Error std-dev σ ≈ 3.2 (discrete Gaussian); ternary secret {−1,0,1}
NTT prime size ≤ 62 bits (fits Montgomery in u64/u128 products)
Decryption correctness Dec(ct)=plaintext iff noise budget > 0 (I1)
Noise budget monotone non-increasing across ops; abort if next op → <0 (I2/I3)
NTT cost O(n log n) per residue; INTT∘NTT round-trip exact (I7)
RNS base conversion exact reconstruction error 0; fast variant bounded, corrected (I8)
Paillier enc < 50 ms at n=2048 (single modexp pair)
BFV mul+relin dominated by ~(k+1)· NTTs over k residues; target < 100 ms at n=8192,k=3
Determinism seeded test mode bit-reproducible; real keygen uses CSPRNG (I11)
Memory one BFV ciphertext ≈ 2·k·n·8 bytes; keep ≤ a few full ciphertexts live
Constant-time decryption + key-dependent ops branch-free / index-independent (I9)
Failure budget non-prime key, depth overflow, malformed ct, sec-too-low fail loud
