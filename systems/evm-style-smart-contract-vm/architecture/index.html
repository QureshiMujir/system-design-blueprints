The transaction entry / state-transition function is the outer boundary: it accepts (pre-state, transaction) and returns (post-state, receipt), exactly the tuple the Yellow Paper defines as Υ.

The execution coordinator owns call-frame lifecycle, journaling, snapshotting, and revert orchestration; every opcode's side effect ultimately routes through it before touching world state.

The interpreter loop performs fetch/decode/dispatch on one opcode per cycle and dominates raw CPU cost.

The gas meter charges static and dynamic costs per opcode, enforces the EIP-150 63/64 forwarding rule, and halts execution the instant gas reaches zero.

The call-frame stack tracks nested CALL/DELEGATECALL/STATICCALL/CREATE/CREATE2 frames, each with its own stack, memory, and return-data buffer, bounded at depth 1024.

The 256-bit ALU, stack, and memory form the per-frame execution substrate: fixed 4×u64-limb arithmetic, a 1024-slot value stack, and byte-addressed, quadratically-priced linear memory.

Everything above the determinism boundary is pure, replicated computation; everything at or below it is the durable, cryptographically committed world state that must match bit-for-bit across nodes.

The world state holds accounts (nonce, balance, codeHash, storageRoot) as leaves of the account trie, with each contract's storage as its own Merkle-Patricia trie.

Precompiles are host-provided, gas-priced native functions (ECRECOVER, hash functions) invoked like ordinary calls but bypassing the interpreter.

State-root computation re-hashes the modified trie nodes bottom-up to a single 32-byte Keccak commitment after every transaction.

The logs/receipts collector accumulates LOG0-LOG4 events and per-transaction receipts (status, gas used, bloom, logs) for the host to persist.

8.3 256-Bit Word and Memory Model

Words are unsigned 256-bit integers stored as 4×u64 limbs, little-endian internally, serialized big-endian at the ABI/RLP boundary. Memory is byte-addressed, initialized to zero on first touch, and expands only in 32-byte-word increments. Memory-expansion gas for growing to w words: C(w) = 3w + floor(w²/512); the marginal cost of a single expansion from w_old to w_new is C(w_new) - C(w_old), charged once per expanding access.

8.5 Call-Frame Model

Field Meaning
gas forwarded min(requested, gas_remaining − gas_remaining/64) — the 63/64 rule, EIP-150
value transfer CALL only; DELEGATECALL/STATICCALL forbid nonzero value
storage context CALL/STATICCALL/CREATE use callee's own storage; DELEGATECALL uses caller's storage and identity
write permission STATICCALL (and any frame beneath it) forbids SSTORE/LOG/CREATE/SELFDESTRUCT/value-CALL
gas stipend 2300 gas stipend added automatically on nonzero-value CALL, to allow the callee a minimal fallback

Worked nested call: A calls B with gas_remaining=1,000,000; forwarded gas = 1,000,000 − 1,000,000/64 = 984,375. B calls C forwarding 984,375 − 984,375/64 ≈ 968,995. Each hop loses ~1/64, bounding effective depth before gas exhaustion even at max call-stack depth 1024.

8.6 World-State Account Model and the Merkle-Patricia Trie

Account field Meaning
nonce tx count sent (EOA) or contracts created (contract account)
balance wei, U256
storageRoot root hash of this account's storage MPT
codeHash Keccak256 of the account's bytecode (empty for EOAs)

MPT node kinds: Leaf (remaining nibble path + value), Extension (shared nibble path + pointer to next node), Branch (16 child slots + optional value). Keys are nibble-encoded (hex-prefix encoding distinguishes leaf/extension and odd/even nibble count in the first byte). Node values are RLP-encoded; the trie root is the Keccak256 hash of the top node's RLP encoding.

Worked trie insertion: inserting key 0xa711 with value V1 into an empty trie creates a single Leaf node (hex-prefix(0xa711, leaf=true), V1); the root becomes Keccak256(RLP([hex-prefix-bytes, V1])). Inserting a second key 0xa722 sharing nibble prefix a7 converts the structure: an Extension node covering nibble a7 points to a Branch node with children at nibble 1 (leading to Leaf for the remainder 1, value V1) and nibble 2 (Leaf for remainder 2, value V2); the new root re-hashes the Extension node's RLP.

8.7 Journal / Revert Mechanism

Every state-mutating opcode first records a JournalEntry (previous value) before mutating; a Snapshot captures the current journal length; revert_to(snapshot) replays journal entries in reverse from the current length back to the snapshot length, restoring prior values; commit simply discards entries below the snapshot (no-op on the underlying state).

8.8 Contract Creation

Init code executes in a throwaway frame; its RETURN output becomes the runtime code stored under the new account's codeHash, subject to the EIP-170/3541/3860 size and prefix checks. Address derivation: CREATE → Keccak256(RLP([sender, nonce]))[12:]; CREATE2 → Keccak256(0xff ++ sender ++ salt ++ Keccak256(init_code))[12:] (EIP-1014) — deterministic and precomputable off-chain.

8.10 Malformed / Attack Examples

  • Out-of-gas mid-execution: gas hits zero inside a loop; interpreter halts immediately with OutOfGas, journal reverts to the enclosing frame's snapshot, no partial writes persist.
  • Stack overflow: a PUSH-heavy sequence exceeding 1024 entries halts as StackOverflow before the 1025th push commits.
  • Invalid jump: JUMP to a PC that is a PUSH-immediate byte, not JUMPDEST-scanned, halts as InvalidJump.
  • Reentrancy (the DAO pattern): a victim contract's external CALL to an attacker re-enters the victim before its balance is zeroed; the VM faithfully executes this — it is the withdraw-then-zero ordering (checks-effects-interactions) in the contract, not the VM, that must guard against it; the VM's only job is exact re-entry semantics per the call-frame model.
  • Integer overflow in 256-bit arithmetic: ADD of two large U256 values wraps modulo 2^256 per protocol — a contract relying on this wrapping without an explicit check is a contract-level bug, correctly and deterministically executed.
  • State root mismatch: a differential run against geth disagrees on the post-state root — treated as I1 violation, halts CI, triggers forensic opcode-by-opcode trace diff.
  • Exceeding code-size limit: init code returns 30,000 bytes of runtime code; CREATE rejects, no code stored, gas for the excess is still consumed per EIP-170 semantics, deployer address's nonce still increments.

Failure-path example: a call chain A→B→C where C reverts; C's frame journal unwinds to C's snapshot; B observes the revert via its CALL return value (0), decides whether to propagate or swallow; if B propagates via its own REVERT, its frame unwinds to B's snapshot; A observes accordingly — only fully-successful frames' mutations survive to the committed state.
