34. Back-of-Envelope Capacity Model

  1. RT deadline, block 64 @48kHz: 64 / 48000 = 0.001333 s = 1.333 ms = 1333 µs (§4).
  2. RT deadline, block 128 @48kHz: 128 / 48000 = 0.002667 s = 2.667 ms = 2667 µs (§4, default).
  3. RT deadline, block 512 @48kHz: 512 / 48000 = 0.010667 s = 10.667 ms = 10667 µs (§4).
  4. Max polyphony from per-voice budget: with a 70% headroom target at block 128 (0.7 * 2667 µs = 1867 µs available for voices), and a measured per-voice cost of ~29 µs/block (M2), 1867 / 29 ≈ 64 voices — matching the §4 default polyphony exactly by construction.
  5. Delay-line memory, 1 s max delay, stereo, 100 instances: 1 s * 48000 Hz * 4 bytes (float32) * 2 channels * 100 instances = 38,400,000 bytes ≈ 36.6 MiB.
  6. Oversampling cost, 4x factor, base per-sample cost c: total cost ≈ 4c for the upsampled nonlinearity evaluation, plus the polyphase anti-imaging filter's own cost (a fixed multi-tap FIR/IIR stage per direction, independent of the nonlinearity itself) — so total node cost is 4c + 2*f where f is one polyphase filter stage's cost (up + down).
  7. FFT cost per block, if a spectral node existed (deferred, §37): N log2(N) butterflies for an N-point FFT; at N=1024, 1024 * 10 = 10240 butterfly operations per transform, times a per-butterfly cost, times two (forward+inverse) for an analysis/resynthesis round trip — this blueprint defers spectral nodes precisely because this cost does not fit the per-block RT budget at small block sizes (§37 anchor).
  8. Alias energy, naive sawtooth at 220 Hz (repeated from §8's worked example, chained here for completeness): Nyquist 24000 Hz; harmonics alias once k > 24000/220 = 109.09, i.e. k>=110; at k=110, amplitude 20*log10(1/110) = -40.8 dB — 39.2 dB above the -80 dBFS floor (§4), demonstrating naive generation's structural violation before summing the remaining infinite tail of aliased harmonics (which only adds more energy).
  9. Total memory per voice: oscillator state (~16 bytes) + filter state (~16 bytes) + envelope state (~16 bytes) + bookkeeping (note, age, flags, ~16 bytes) ≈ 64 bytes of active state, comfortably inside the ≤4096-byte budget (I14, §4), leaving headroom for per-voice modulation- route storage and future per-voice effect sends.
  10. Total voice-array memory at max polyphony ceiling (256 voices): 256 * 4096 bytes = 1,048,576 bytes = 1 MiB — the worst-case static allocation the arena must reserve at stream-open regardless of the configured default (§4, ADR-15).
