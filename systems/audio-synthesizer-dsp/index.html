3. Architectural Overview

CONTROL / NON-REAL-TIME (persistence + parsing + orchestration)
+------------------------------------------------------------+
| MIDI Parser  <- raw bytes (MIDI 1.0 / UMP)                  |
| Preset/Patch Loader <- WAV/RIFF, patch files (persistence)  |
| Automation Editor -> ParamEvent stream                      |
| Offline Renderer (non-RT, throughput-bound) -> WAV out       |
+---------------------+------------------+-------------------+
                      | SPSC ring buffer  | SPSC ring buffer
                      | (NoteEvent,       | (RenderStats,
                      |  ParamEvent)      |  telemetry records)
                      v                   ^

                      v                   |
+---------------------+------------------+-------------------+
| AUDIO CALLBACK (PortAudio/JACK/ALSA/CoreAudio contract)      |

|  event-due sample offsets                                    |
|    |                                                          |
|    v                                                          |
|  Voice Allocator/Stealer -- assigns NoteEvent -> Voice slot   |
|    |                                                          |
|    v                                                          |

|         +--- Modulation Matrix <---+-------------+            |
|    |                                                           |

|  Output Buffer -> Device                                       |
+---------------------------------------------------------------+
                      |
                      v (metrics/log records, lock-free handoff)
              TELEMETRY (non-RT consumer thread) -> dashboards

MIDI Parser: strict MIDI 1.0/UMP byte-stream parser (ADR-11) running on a control thread; turns raw bytes into NoteEvent/ParamEvent records pushed through the SPSC queue. Preset/Patch Loader: persistence boundary — reads/writes patch files and WAV assets, never touches the audio thread directly (ADR-17). Automation Editor: produces a ParamEvent stream ahead of render time; feeds the same queue as live MIDI. Offline Renderer: a separate, non-RT execution path sharing the compiled kernel with the RT path (P14/I13); bypasses the device entirely, writing WAV directly. SPSC ring buffers: the sole concurrency boundary between control and audio threads (P9); fixed capacity, backpressure policy per ADR-27. Audio Callback: the real-time boundary; everything below the "REAL-TIME BOUNDARY" line executes with zero allocation, no locks, no blocking syscalls (P1, I1). Block Scheduler: splits each callback's block at the sample offsets where queued events become due (§8 block-processing contract). Voice Allocator/Stealer: assigns incoming NoteEvents to Voice slots per the decision table in §8; enforces the click-free stealing guarantee (P8, I5). Signal Graph: the topologically-sorted DAG of Nodes (§8 interface table); per-voice subgraphs plus a global bus. Modulation Matrix: routes named sources to named destinations at a bounded route count (ADR-10). Global Effects Chain: post-mixdown delay/FDN-reverb/chorus/distortion, each RT-safe. Telemetry: a non-RT consumer thread draining the lock-free metrics/log queue (ADR-18/19/20), feeding dashboards (§26) without ever touching the RT thread's timing.

8. Domain Model

Sampling and the Nyquist criterion.

fs >= 2 * f_max                         (Nyquist–Shannon)
f_alias = min_k | f_true - k * fs |     (aliasing condition, k integer, result folded into [0, fs/2])

The z-transform and transfer functions (Oppenheim & Schafer ch. 2, 5).

X(z) = sum_{n=-inf}^{inf} x[n] * z^-n
H(z) = Y(z) / X(z) = (b0 + b1 z^-1 + b2 z^-2) / (1 + a1 z^-1 + a2 z^-2)
stable  <=>  all poles (roots of denominator) satisfy |z| < 1

Biquad coefficients (Bristow-Johnson Audio EQ Cookbook; low-pass shown, other types by the same reference table — high-pass, band-pass, notch, peaking, shelving each substitute the b/a numerator form for the same alpha/omega machinery).

omega0 = 2*pi*f0/fs ;  alpha = sin(omega0) / (2*Q)
LPF:  b0=(1-cos(omega0))/2, b1=1-cos(omega0), b2=b0
      a0=1+alpha,           a1=-2*cos(omega0), a2=1-alpha
normalize: b_i /= a0 ,  a_i /= a0   (applied in §16, ADR-06)

TPT / trapezoidal-integrator state-variable filter (Zavalishin 2012; Smith CCRMA TPT notes).

g  = tan(pi * fc / fs) ;  k = 1 / Q
v3 = x - ic2
v1 = (ic1 + g*v3) / (1 + g*(g+k))
v2 = ic2 + g*v1
ic1' = 2*v1 - ic1 ;  ic2' = 2*v2 - ic2
outputs: LP = v2 ,  BP = v1 ,  HP = x - k*v1 - v2

ADSR envelope segment equations.

Attack  (linear):    level[n] = level[n-1] + 1/N_A                      until level >= 1
Decay   (exp, tau_D): level[n] = sustain + (level[n-1]-sustain)*exp(-1/(tau_D*fs))
Sustain:             level[n] = sustain                                 while gate held
Release (exp, tau_R): level[n] = level[n-1] * exp(-1/(tau_R*fs))        until level < eps

Band-limited oscillator construction.

BLIT[n]   = (M/N) * sin(pi*M*n/N) / (M*sin(pi*n/N)) ,  M = 2*floor(fs/(2*f0)) + 1   (Stilson & Smith 1996)
Saw       = leaky_integrate(BLIT)
PolyBLEP correction, applied at the discontinuity, t in phase units, dt = phase increment:
  t < dt:        +=  t/dt + t/dt - (t/dt)^2 - 1
  t > 1-dt:      +=  ((t-1)/dt)^2 + (t-1)/dt + (t-1)/dt + 1
minBLEP: naive discontinuity convolved with a precomputed band-limited step residual (Brandt 2001)

FM/PM index and sidebands (Chowning 1973).

y[n] = A * sin(2*pi*fc*n/fs + I * sin(2*pi*fm*n/fs))
sideband amplitude at fc +/- k*fm  =  J_k(I)     (Bessel function of the first kind, order k)

FDN reverb stability condition (Jot & Chaigne 1991).

y[n] = A * x[n - m]          (per-line feedback through delay vector m)
stable  <=>  spectral_radius(A) <= 1     (enforced by an orthogonal/unitary A, gain-scaled < 1)

Parameter smoothing time constant.

y[n] = y[n-1] + (target - y[n-1]) / N_smooth ,   N_smooth ~= tau_ms * fs / 1000   (tau ~ 5-30 ms)

Node/graph interface (signatures in §11). Every node exposes process(ctx, inputs) -> outputs, static_size() -> bytes, reset(). process is called exactly once per block per node, in topological order; static_size is queried once at graph-commit time (P1); reset never allocates.

Block-processing contract. (1) a node's output for a given absolute sample range is independent of how that range was sliced into blocks (P7/I8); (2) internal phase/state persists across block boundaries; (3) a node never reads beyond the current block's declared inputs; (4) latency introduced by a node is declared and additive into the global budget (P13).

Voice-allocation and stealing policy (decision table).

Pool State Event Action Resulting Voice Count
≥1 voice Idle NoteOn assign Idle voice, start Attack active += 1
all voices busy, none matches note NoteOn steal oldest voice (ADR-08), force fast-release ramp (P8), reassign after ramp active unchanged (steal, not add)
a voice already plays this MIDI note NoteOn (same note) reuse that voice (legato fast path) active unchanged
voice in Release, level < epsilon (background) transition to Idle, return to free list active -= 1
NoteOff for a playing note NoteOff trigger Release on the matching voice active unchanged until Release completes
NoteOff for a note with no matching voice NoteOff no-op, log active unchanged

Modulation-matrix routing model. Sources: LFO1, LFO2, EnvelopeN, Velocity, ModWheel, Aftertouch. Destinations: oscillator pitch, filter cutoff, amplitude, pan. Each ModRoute is (source, destination, depth); the matrix is bounded to a fixed route ceiling per voice (§4 graph node ceiling divided across per-voice budget) so CPU cost is statically known (ADR-10).

Parameter-automation event record. ParamEvent { param_id, target_value, sample_index, curve_type }; curve_type in { step, linear, exponential-smoothed } (§11).

Voice lifecycle state-transition table.

From Event To Failure Edge
Idle NoteOn Attack none
Attack level reaches 1.0 Decay NoteOff before completion -> Release
Decay level reaches sustain Sustain NoteOff before completion -> Release
Sustain NoteOff Release none
Release level < epsilon Idle steal request mid-release -> forced Idle (fast ramp, P8)
any active state steal request Release (forced fast ramp) double-steal (already stealing) -> no-op, log

Worked example — biquad coefficients, cutoff 1000 Hz, Q=0.707, fs=48000 Hz (ADR-06, applied §16): omega0 = 2*pi*1000/48000 = 0.130900 rad; cos(omega0)=0.991445, sin(omega0)=0.130537; alpha = 0.130537/(2*0.707) = 0.092322; unnormalized b0=0.0042775, b1=0.008555, b2=0.0042775, a0=1.092322, a1=-1.98289, a2=0.907678; normalized by a0: b0=0.0039166, b1=0.0078332, b2=0.0039166, a1=-1.815483, a2=0.830958.

Worked example — aliasing from a naive sawtooth at f0=220 Hz, fs=48000 Hz (applied §13/§14): Nyquist = 24000 Hz; naive saw contains harmonics at k*220 Hz for all k with amplitude ~1/k; harmonics alias once k*220 > 24000, i.e. k > 109.09, so k>=110 folds. For k=110: true frequency 24200 Hz aliases to |24200-48000| = 23800 Hz at amplitude 20*log10(1/110) = -40.8 dB relative to the fundamental — already far above the -80 dBFS floor (§4), and the infinite sum over k>=110 accumulates further energy, demonstrating naive generation structurally violates the aliasing floor and motivating band-limited construction (P2).

Malformed-input examples (applied §22, §24, §28): MIDI running status — a Note On status byte followed by status-omitted data bytes for subsequent messages must retain the last status per the MIDI 1.0 Detailed Specification; a stream lacking an initial status byte is rejected (I11). Out-of-range pitch bend — a 14-bit value outside [0, 16383] is clamped and logged, never passed through raw. NaN in a feedback loop — a zero-Q biquad division or an ill-conditioned FDN matrix edit is caught by the isfinite guard (I10) before it poisons state.

Failure-path example. A patch commit introduces a cycle without an explicit delay node: the graph validator raises GraphCycleError at commit time, before the audio thread ever observes it; the previous valid graph snapshot remains active (the atomic snapshot swap never occurs, P9); the operator sees a rejected-commit log entry, not a runtime crash (I3).
