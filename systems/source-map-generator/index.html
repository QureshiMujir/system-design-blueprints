3. Architectural Overview

3.1 System Diagram

   transpilers · minifiers · bundler (#264) · TS compiler          browsers · error reporters · devtools · V8

                  |                                                                  ^
                  v                                                                  |
        smap-builder  /  smap-edit  ---build--->  SourceMap (smap-model)  <--query-- smap-consumer

Dataflow: producers push (gen, orig, name) positions into smap-builder (or edit a buffer via smap-edit); into_sourcemap sorts + hands DecodedMap to smap-codec -> mappings string -> smap-vlq per integer; smap-json wraps the SourceMap envelope as v3 JSON (disk / inline data: / sourceMappingURL). Consume reverses: smap-json parse -> SourceMap -> smap-consumer (SourceMapConsumer::new decodes via smap-codec, builds sorted indexes) -> binary-searched original_position_for / generated_position_for. smap-compose + smap-index operate above the model.

3.2 Boundaries

Boundary Where Rule
Trust smap-json::from_json / decode_mappings / extract_source_mapping_url Inbound maps are UNTRUSTED (web fetch, build artifact, attacker-authored). The trust boundary is the load-bearing safety contract: every decode path (Phase 1 VLQ, Phase 3 mappings, Phase 4 JSON) is fuzzed in Phase 11 against malformed/adversarial input with a "never panics, always typed error" invariant.

3.3 Crate Responsibilities (one per box)

smap-vlq (no_std+alloc). Lowest layer: Base64 VLQ integer codec. Owns B64: [u8;64] (A-Za-z0-9+/) + the reverse lookup table, encode_vlq(value, &mut String), decode_vlq(&[u8], &mut usize) -> Result<i64, VlqError>. Encodes via 5-bit groups low-to-high, bit 5 (=32) continuation, value-LSB sign bit (sign+magnitude, NOT two's complement). In: i64 (encode) / byte slice + cursor (decode); out: appended Base64 chars / decoded i64 + advanced cursor. Invariant: decode_vlq(encode_vlq(v))==v for all i64 in range; never panics — overflow -> VlqError::Overflow, bad char -> InvalidBase64Char, truncation -> UnexpectedEof. Foundation for Phase 1; every mappings field in Phase 3 routes through it; Phase 12 table-driven Base64 + byte-at-a-time decode optimize it.

smap-model (no_std+alloc). Pure data, zero logic. Defines Position{line,column:u32} (0-based), Segment{gen_column, source:Option<u32>, orig_line, orig_column, name:Option<u32>}, DecodedMap(Vec<Vec<Segment>>) (outer = generated line), the v3 SourceMap envelope struct (version:u8==3, file, source_root, sources:Vec<Option<String>>, sources_content, names, mappings:String, ignore_list), OriginalLocation, and source/name index newtypes. In/out: none (definitions). Invariant: 0-based lines+columns internally — the 0↔1 conversion lives ONLY at the API/CLI boundary, never inside the model. Referenced by all 9 other crates; the shared vocabulary fixed in Phase 0/2.

smap-codec (no_std+alloc, dep: smap-vlq+smap-model). The relative-delta state machine. encode_mappings(&DecodedMap)->String and decode_mappings(&str)->Result<DecodedMap,CodecError>. Owns EncoderState/DecoderState carrying running deltas: prev_gen_col RESET per ;, prev_source/prev_orig_line/prev_orig_column/prev_name CARRIED ACROSS lines. In: DecodedMap / mappings str; out: mappings str / DecodedMap. Invariants: field count ∈ {1,4,5} (else BadFieldCount); ;=new generated line, ,=next segment; gen_column reset is the #1 bug surface so it is asserted. Tolerant decode of real-world maps (trailing separators, empty groups). Built in Phase 3; consumed by builder (Phase 5), consumer (Phase 6), compose/index/edit, cli.

smap-json (std, dep: smap-model). The serialization/envelope layer + only place touching I/O-ish formats. to_json(&SourceMap)->String (emits version:3), from_json(&str)->Result<SourceMap,JsonError> (strips optional XSSI )]}'), extract_source_mapping_url(code)->Option<SourceMapRef> (parses //# sourceMappingURL=, decodes inline data:application/json;base64, -> SourceMapRef::Inline, else Url). Handles sourcesContent/sourceRoot/ignoreList (x_google_ignoreList). In: JSON text / source code text; out: SourceMap / JSON text / SourceMapRef. Invariant: untrusted input -> typed JsonError (Parse/BadVersion/MissingField), never panic; version!=3 rejected. Phase 4; Phase 12 zero-copy parsing.

smap-builder (no_std+alloc, dep: smap-model+smap-codec). The SourceMapGenerator contract — what producers call while emitting. Holds sources+names interners + per-line segment buffers. add_source(&str)->u32, add_name(&str)->u32 (dedup-interned), set_source_content(source,&str), add_mapping(gen:Position, orig:Option<(u32,Position)>, name:Option<u32>), into_sourcemap(self)->SourceMap (sorts by (gen_line,gen_column), dedups, encodes via smap-codec). In: incremental positions; out: a complete SourceMap. Invariant: output segments sorted + dedup'd, every source/name index in range of sources/names. Phase 5; consumed by compose (Phase 7), index (Phase 8), edit (Phase 9), the #264 integration (Phase 10).

smap-consumer (no_std+alloc, dep: smap-model+smap-codec). The query/decoder side. SourceMapConsumer::new(SourceMap)->Result<Self,CodecError> decodes mappings and builds two sorted indexes: by-generated (line,column) and by-original (source,line,column). original_position_for(gen, Bias)->Option<OriginalLocation> binary-searches greatest gen ≤ query (Bias::GreatestLowerBound, default) or least ≥ (LeastUpperBound); generated_position_for(source,orig,Bias)->Option<Position> over the by-original index; source_content_for(source)->Option<&str>; all_generated_positions_for. In: a SourceMap; out: positions. Invariant: indexes total-ordered, query O(log n). Phase 6; basis of compose lookups (Phase 7), cli query, devtools-equivalent behavior.

smap-compose (no_std+alloc, dep: smap-consumer+smap-builder). Composition/chaining: compose(orig_to_mid:&SourceMapConsumer, mid_to_gen:&DecodedMap, mid_names:&[String])->SourceMap and remap(chain:&[SourceMap])->Result<SourceMap,CodecError> (fold compose). For each mid_to_gen segment, look up its mid (original) position in orig_to_mid; if mapped, emit gen -> deepest source/line/col(+name); if unmapped, emit a 1-field generated-only segment (null-segment propagation). Names follow the deepest mapping; sourcesContent preserved. In: a consumer + a DecodedMap (or a chain); out: a flattened SourceMap. Invariant: compose associative -> remap order-independent in result; round-trip-through-chain property. Phase 7.

smap-index (no_std+alloc, dep: smap-model+smap-builder). Sectioned (index) maps: Section{offset:Position, map:SourceMap}, IndexedSourceMap{version, file, sections:Vec<Section>}, flatten()->Result<SourceMap,CodecError>. Builds from concatenated chunk maps (each chunk's map + its byte offset in the combined output); flatten shifts each section's generated positions by offset (offset.line added to every gen line; offset.column added ONLY to the first line of the section). In: per-chunk SourceMaps + offsets; out: one flat SourceMap. Invariant: sections sorted-by-offset + non-overlapping. Phase 8; used by #264 for concatenated bundles (Phase 10).

smap-edit (std, dep: smap-builder). MagicString-style source editor: emit transformed code + a correct map WITHOUT re-parsing. MagicString over an original buffer with ordered edits — overwrite(start,end,&str), append, prepend, remove(start,end), plus move/indent — to_string() materializes output, generate_map(&MapOptions)->SourceMap derives mappings from interval bookkeeping + column tracking against the original byte ranges. In: original buffer + edit ops; out: edited string + SourceMap. Invariant: untouched intervals map 1:1 to original positions; removed ranges produce no segments; map stays consistent with to_string() output. Phase 9.

smap-cli (std, dep: all). The smap binary surfacing every capability: encode, decode, validate, compose, flatten, query (original-for / generated-for), inspect, extract-url. Translates the 0-based internal model to 1-based user-facing lines at the CLI boundary (per §3.2). In: files/stdin + flags; out: JSON/text + exit codes. Invariant: the ONLY place that does 0↔1 conversion and human formatting; pure-library crates stay 0-based. Phase 0 scaffold, fully wired by Phase 12.

8. Domain Model — Source Map v3, VLQ, and the Mappings Grammar

The single normative reference for the whole toolkit. Every crate (smap-vlq → smap-codec → smap-json/smap-builder/smap-consumer) derives its invariants from here. Lines/columns are 0-based everywhere inside the model and codec; the 1-based presentation conversion lives only at the smap-cli/public-API boundary (§8.3, §8.8).

8.1 Base64 VLQ bit layout

VLQ = Variable Length Quantity, Base64-encoded. One integer → one or more Base64 chars; one char carries one 6-bit digit = 1 continuation bit + 5 payload bits.

  • Digit layout (6 bits): C dddd d — bit 5 (value 32) = continuation (1 = more digits follow), bits 0..4 = 5 payload bits.
  • Sign: NOT two's complement. The integer is transformed to sign-magnitude before grouping: vlq = (|n| << 1) | (n < 0). So bit 0 of the first digit's payload is the sign bit (1 = negative). The remaining bits are the magnitude, low-to-high.
  • Grouping: take vlq, emit low 5 bits as first digit; while bits remain, set continuation on the emitted digit and shift right 5; final digit has continuation 0.
  • Alphabet (smap-vlq::B64, index→char): ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/. A=0 … /=63. Reverse table maps char→0..63, all other bytes → InvalidBase64Char.
encode_vlq(123):  n=123  -> vlq = (123<<1)|0 = 246 = 0b11110110
   group0 = vlq & 31      = 0b10110 = 22 ; vlq>>=5 -> 7 (more) -> set cont(32) -> 54 -> '2'
   group1 = 7  & 31       = 0b00111 = 7  ; vlq>>=5 -> 0 (done)  -> cont=0       -> 7  -> 'H'
   chars: '2H'
   digit0 byte:  [C=1][payload=10110]  (sign bit = LSB of payload = 0 -> positive)
   digit1 byte:  [C=0][payload=00111]

encode_vlq(-1):   n=-1   -> vlq = (1<<1)|1 = 3 = 0b00011
   group0 = 3 & 31 = 3 ; vlq>>=5 -> 0 (done) -> cont=0 -> 3 -> 'D'
   chars: 'D'
   digit byte: [C=0][payload=00011]  (sign bit = 1 -> negative ; magnitude bits = 0b001 = 1)

encode_vlq(0):    n=0 -> vlq=0 -> single digit 0 -> 'A'

decode_vlq(input, pos): read digit, shift payload into result at shift (0,5,10,…), stop when continuation clears; then negative = result & 1, magnitude = result >> 1, final = if negative { -magnitude } else { magnitude }; advance *pos. Errors: UnexpectedEof (continuation set but no next byte), InvalidBase64Char(b), Overflow (>32 bits accumulated, i.e. >6 digits / magnitude exceeds i64 safe range).

8.2 The "mappings" grammar (EBNF)

mappings   = line , { ";" , line } ;          (* ";" begins a new GENERATED line *)
line       = [ segment , { "," , segment } ]; (* a line may be empty *)
segment    = field4or5 | field1 ;             (* see field-count rule below *)
field1     = vlq ;                            (* gen_column only          *)
field4or5  = vlq , vlq , vlq , vlq , [ vlq ] ;(* gen_col, src, oline, ocol[, name] *)
vlq        = vlqdigit , { vlqdigit } ;        (* >=1 Base64 char          *)
vlqdigit   = "A" | … | "Z" | "a" | … | "z" | "0" | … | "9" | "+" | "/" ;

Field-count rule (LOCKED): a segment has exactly 1, 4, or 5 fields. 2 or 3 → CodecError::BadFieldCount(n). Counts decode as:

Fields Meaning Has source? Has name?
1 generated column only (unmapped — "generated-only") no no
4 gen col + source + orig line + orig col yes no
5 the above + name index yes yes

8.3 Relative-delta semantics (the #1 source of bugs)

Each field is a relative delta against running state held in EncoderState/DecoderState. The reset discipline is the load-bearing invariant:

# Field Decoded into Segment Relative to Reset per ; (new gen line)? State name
1 generated column gen_column previous segment's gen_column on the same line YES → reset to 0 prev_gen_col
2 source index source previous segment's source index NO → carries ACROSS lines prev_source
3 original line orig_line previous segment's orig line NO → carries prev_orig_line
4 original column orig_column previous segment's orig column NO → carries prev_orig_column
5 name index name previous segment's name index NO → carries prev_name

Unmissable rule: only prev_gen_col resets at ;; the other four persist for the entire map. A 1-field segment advances only prev_gen_col. Encoder mirrors decoder: emit cur - prev, then prev = cur.

8.4 v3 JSON envelope schema

{
  "version":        3,            // u8, MUST == 3 ; else JsonError::BadVersion(n)
  "file":           "out.js",     // string | absent  -> Option<String>
  "sourceRoot":     "src/",       // string | absent  -> Option<String> ; prepended to each source
  "sources":        ["a.ts", null],     // Vec<Option<String>> (null allowed)
  "sourcesContent": ["…", null],        // Vec<Option<String>> ; index-aligned to sources
  "names":          ["foo","bar"],      // Vec<String>
  "mappings":       "AAAA,…",           // string (REQUIRED) -> MissingField if absent
  "ignoreList":     [1]                 // Vec<u32> ; indexes into sources ; a.k.a. x_google_ignoreList
}
  • version and mappings are required; all else optional (MissingField("mappings")).
  • sourcesContent: content[i] is the full text of sources[i]; null/shorter array ⇒ that source has no embedded content. smap-json pads to sources.len() with None.
  • ignoreList: source indexes the debugger should skip (vendored/framework code). Emitted as "ignoreList"; parsed from "ignoreList" and legacy "x_google_ignoreList". Out-of-range index → validation warning (§8.7).
  • sourceRoot: resolution = sourceRoot + sources[i] (string concat with single / normalization); never alters indexes.
  • Index integrity: every segment source < sources.len(), every name < names.len() (enforced in smap-consumer::new).

Generated file out.js (2 lines) maps to two sources, a.ts (idx 0) and b.ts (idx 1).

8.6 sourceMappingURL comment + inline data: URL

extract_source_mapping_url(code) scans from EOF for the last match (line or block form):

//# sourceMappingURL=out.js.map          -> SourceMapRef::Url("out.js.map")
//@ sourceMappingURL=out.js.map          (legacy '@' accepted on read, '#' on emit)
/*# sourceMappingURL=out.js.map */       (block form)
//# sourceMappingURL=data:application/json;base64,eyJ2ZXJ…  -> SourceMapRef::Inline(SourceMap)
//# sourceMappingURL=data:application/json;charset=utf-8;base64,…

Inline data: URL: split on first ,; require MIME application/json; if ;base64 present, Base64-decode the tail then from_json; else URL-decode then from_json. Result wrapped SourceMapRef::Inline. Emit always uses //# (hash form).

8.7 Malformed / edge examples → error

Input fragment Detected by Error / behavior
segment with 2 or 3 fields (e.g. "AA", "AAA") smap-codec field count CodecError::BadFieldCount(2) / (3)
VLQ overflowing i64 (>6 continuation digits) decode_vlq CodecError::Vlq(VlqError::Overflow)
source index ≥ sources.len() after deltas smap-consumer::new CodecError::SourceIndexOob
original column delta drives orig_column negative smap-codec CodecError::NegativeColumn
mappings line with leading "," (e.g. ",AAAA") smap-codec empty-segment → BadFieldCount(0)
truncated VLQ (continuation set, no next char, e.g. "g") decode_vlq VlqError::UnexpectedEof → CodecError::Vlq
non-Base64 byte in mappings (e.g. "=A") decode_vlq VlqError::InvalidBase64Char(b'=')
"version": 2 (or 4) from_json JsonError::BadVersion(2)
mappings field absent from_json JsonError::MissingField("mappings")
XSSI prefix )]}' before JSON from_json stripped silently, then parse
UTF-8 BOM (EF BB BF) before JSON / XSSI from_json stripped silently, then parse
empty mappings:"" decode_mappings valid → DecodedMap(vec![]) (0 lines)
trailing ; (e.g. "AAAA;") decode_mappings valid → final empty line appended

Invariant: decode_vlq, decode_mappings, and from_json NEVER panic on arbitrary bytes — all faults surface as the typed errors above (fuzz-enforced, Phase 11).

8.8 original_position_for binary-search flow

Consumer holds segments sorted by (gen_line, gen_column). Query gen: Position (0-based), bias:

original_position_for(gen, bias):
  1. row = index of generated line gen.line          (outer Vec index; absent -> None)
  2. segs = row's segments, sorted ascending by gen_column
  3. binary-search segs for gen.column:
        GreatestLowerBound (default): largest seg with gen_column <= gen.column
        LeastUpperBound:              smallest seg with gen_column >= gen.column
  4. chosen seg: if seg.source.is_none() -> None (generated-only / unmapped)
                 else -> Some(OriginalLocation{
                            source: seg.source,
                            line:   seg.orig_line,
                            column: seg.orig_column,
                            name:   seg.name })
  5. (CLI boundary only) convert line/column 0-based -> 1-based for display

generated_position_for(source, orig, bias) mirrors this over the by-original index, sorted (source, orig_line, orig_column), returning the generated Position. Both are O(log n) per query; index build is O(n log n) once in SourceMapConsumer::new (Phase 6).

Non-goals restated: this section models, encodes, decodes, and queries source maps only. JS parsing/transform (#264), minification, AST work, devtools UI, and the wasm/DWARF source-map extension are out of scope (the latter gated behind PhaseDeferred).
