Invariants — what must never be false (§7) · 14

Invariants — what must never be false
Item
No system allocation occurs on any RT thread after streaming starts. Why: allocation latency is unbounded → glitch. Where: media-rt pools + a debug global allocator hook that flags RT-thread allocs. Detect: alloc-on-RT-thread assertion (debug builds), latency spikes (release). Telemetry: rt_alloc_violations. Recover: none — it is a bug; degrade by reusing last buffer. Debug: allocator backtrace + RT-thread id check.
No blocking lock is acquired on any RT thread. Why: priority inversion → deadline miss. Where: only SPSC rings/atomics on RT paths; loom model tests. Detect: a try-lock that would block (debug trap); contention telemetry. Telemetry: rt_lock_violations. Recover: ring-based fallback. Debug: thread-priority + lock-owner trace.
Audio playout produces no xrun under in-scope load. Why: top invariant. Where: media-audio sink; buffer-level monitor. Detect: ALSA EPIPE / buffer-level < threshold. Telemetry: xrun_total, buffer_level_frames. Recover: snd_pcm_recover + account the gap + (if recurring) raise latency. Debug: buffer-level timeline vs deadline-miss log.
PTS is monotonically non-decreasing per stream. Why: ordered presentation. Where: capture timestamping + a monotonicity check at sink. Detect: PTS regression. Telemetry: pts_regressions. Recover: clamp/drop the offending frame. Debug: per-stream PTS trace.
A/V sync error stays within ±20 ms of the master clock. Why: lip-sync. Where: media-sync lip-sync controller. Detect: |video_pts_mapped − master_now| > bound. Telemetry: av_sync_error_ms (gauge + histogram). Recover: drop (video ahead) / repeat (video behind) frames. Debug: sync-error timeline correlated with drift estimate.
Every inter-node queue is bounded; depth never exceeds capacity. Why: bounded memory + latency. Where: media-sched queues. Detect: enqueue into a full queue triggers the declared policy. Telemetry: queue_depth{edge}, queue_drops{edge,policy}. Recover: policy applied (drop/block — block only off-RT). Debug: per-edge depth + drop counters.
The buffer pool is conserved: buffers_out + buffers_free == pool_size. Why: no leaks, no allocation. Where: media-core::BufferPool refcount + a conservation check. Detect: count mismatch. Telemetry: pool_free{type}, pool_leak_suspected. Recover: reclaim on drop; if exhausted, backpressure. Debug: per-buffer refcount/owner tag.
The SPSC ring neither drops nor duplicates an item under correct single-producer/single-consumer use. Why: data integrity across the RT boundary. Where: media-rt ring + loom tests. Detect: sequence-number gap/dup in a checked mode. Telemetry: ring_full_events, ring_empty_events. Recover: full → backpressure; empty → underrun handling. Debug: head/tail indices + memory-ordering model test.
Caps are fully fixed on every active link before the first buffer flows. Why: no per-buffer format ambiguity. Where: media-graph negotiation. Detect: an unfixed/under-specified cap at stream start. Telemetry: negotiation_failures. Recover: refuse to start the segment; report the failing link. Debug: per-pad caps intersection log.
Deadline misses are counted, timestamped, and never silently absorbed. Why: visibility into RT health. Where: media-sched/media-rt deadline accounting. Detect: iteration end > deadline. Telemetry: deadline_miss_total, deadline_overrun_us histogram. Recover: continue; if sustained, raise latency / shed load. Debug: overrun distribution + the node that overran.
Clock-drift compensation keeps the audio buffer level within ±1 period of its target. Why: prevents slow drift to xrun. Where: media-clock estimator → media-dsp resampler ratio. Detect: buffer level drifts beyond band. Telemetry: drift_ppm, resampler_ratio, buffer_level_error. Recover: PI controller adjusts ratio. Debug: drift estimate vs buffer-level vs ratio over time.
EncodedFrame payload is opaque to transport; no codec field is interpreted. Why: the deferred-codec seam. Where: media-transport packetizer. Detect: any access to payload internals (review/type-level). Telemetry: n/a. Recover: n/a. Debug: type boundary — payload is &[u8] + metadata only.
Denormal floats are disabled on audio-processing threads (FTZ/DAZ set). Why: denormals cause 10–100× slowdown → glitch. Where: RT thread init in media-dsp/media-rt. Detect: a denormal-stress test measuring per-block time. Telemetry: process_block_us p99. Recover: re-assert FTZ/DAZ. Debug: block-time spike correlated with low-amplitude tails.
Video frame presentation respects PTS; late frames are dropped, early frames wait. Why: smooth video + sync. Where: media-sync/video sink. Detect: present time vs PTS-mapped-to-master. Telemetry: video_frames_dropped, video_frames_repeated. Recover: drop/repeat per policy. Debug: PTS vs present-time scatter.
