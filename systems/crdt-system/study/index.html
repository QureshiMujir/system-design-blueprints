Mental Models & First Principles

  • MM1 — A CRDT is a join-semilattice; merge is the join. Predicts: any merge that is not commutative/associative/idempotent will diverge under reordering. Bug class without it: "works in tests, diverges in production under reordering." Applied: Phase 2, §7 I1–I3.
  • MM2 — Causality is a partial order, not a clock reading. Predicts: two events with no happens-before are concurrent, and concurrency is a first-class outcome, not an error. Bug class: forcing a total order (e.g. wall-clock LWW) silently drops one of two concurrent writes. Applied: Phase 1, Phase 4, §7 I9.
  • MM3 — A delete is the addition of a tombstone, not a subtraction. Predicts: you cannot truly remove information from a CRDT until everyone agrees it is safe (causal stability). Bug class: early GC resurrects deletes. Applied: Phase 3, §7 I4, FM-2.
  • MM4 — Observed-remove means "remove what I saw." Predicts: a concurrent add the remover never saw must survive (add wins). Bug class: 2P-Set semantics where re-adds silently fail. Applied: Phase 3, §8.2.
  • MM5 — Delta-state is "ship the join increment," and a delta is itself a CRDT. Predicts: merging deltas is associative, so gossip can re-ship freely. Bug class: treating a delta as a non-idempotent op breaks under duplication. Applied: Phase 7, §7 I11.
  • MM6 — Anti-entropy answers "what differs," gossip answers "spread what's new." Predicts: a system needs both — gossip for freshness, anti-entropy for completeness after churn. Bug class: push-only gossip leaks to late joiners. Applied: Phase 8, Phase 9, FM-6.
  • MM7 — The wire is hostile; decode is a parser, not a cast. Predicts: every byte sequence must map to either a value or a typed error, never a panic. Bug class: silent corruption from an unchecked cast. Applied: Phase 7, §8.4, §7 I7/I8.
  • MM8 — Recovery is a pure replay of an immutable log onto a checkpoint. Predicts: if append-order is preserved and merge is associative, recovery is deterministic and byte-identical. Bug class: mutating state in place during recovery yields non-reproducible state. Applied: Phase 10, §7 I13.
  • MM9 — Identifiers are forever; never reuse a ReplicaId. Predicts: dot uniqueness depends on stable ids; rotation corrupts the algebra. Bug class: convergence failures after a node restarts with a fresh-but-colliding id. Applied: §6 P12, §7 I5/I12.

Glossary · 55 terms · site-wide glossary

CRDT
Conflict-Free Replicated Data Type; a type whose merge is commutative, associative, idempotent, guaranteeing SEC.
CvRDT
Convergent (state-based) Replicated Data Type.
CmRDT
Commutative (operation-based) Replicated Data Type.
Delta-state CRDT
A state-based CRDT shipped at delta granularity (Almeida 2018).
Strong Eventual Consistency (SEC)
Replicas that observed the same updates converge; no conflicts at convergence.
Eventual consistency
Replicas converge eventually, without SEC's no-conflict guarantee.
Join-semilattice
A partial order with a least upper bound (join) for every pair; the algebraic structure of a CRDT.
Join / merge
The least-upper-bound operation; the CRDT's merge.
Commutativity / Associativity / Idempotence
The three merge laws (I1–I3).
Vector clock
A per-replica counter; the canonical causality primitive.
Version vector
Algebraically a vector clock; semantically "which dots have I observed."
Dotted version vector (DVV)
A version vector plus dots concurrent with the base (Almeida 2014).
Lamport timestamp
A (replica, counter) pair under local := max(local, incoming)+1; total order, partial causality.
Hybrid logical clock (HLC)
A (physical, logical, replica) triple with bounded skew (Kulkarni 2014).
Dot
A unique (replica, tick) identifier for one update event.
Tick
A monotonic per-replica counter; 1-indexed (Tick(0) = never observed).
ReplicaId
A stable, lifetime-unique replica identifier.
Tombstone
A record of a deleted element retained for causal correctness.
Causal stability
A dot observed by every known replica; precondition for GC.
Concurrency
Two events with no happens-before relation.
Happens-before
Lamport's partial-order causality relation.
Anti-entropy
Periodic catch-up sync; implemented via Merkle-tree diff.
Gossip
Randomised epidemic dissemination; push, pull, or push-pull.
Push-pull
Gossip that both sends fresh deltas and requests missed ones.
Merkle tree
A hash tree over the op log enabling O(log N) diff.
Op log
The append-only sequence of deltas a replica has applied.
G-Counter
Grow-only counter; per-replica map under per-key max.
PN-Counter
Increment/decrement counter; two G-Counters.
G-Set
Grow-only set; union merge.
2P-Set
Two-phase set; add-set plus permanent tombstone-set.
OR-Set
Observed-Remove Set; remove acts only on observed dots.
LWW-Register
Last-Writer-Wins Register; (timestamp, replica) tiebreak.
MV-Register
Multi-Value Register; preserves all concurrent writes.
RGA
Replicated Growable Array; default sequence CRDT (Roh 2011).
WOOT
Without Operational Transform; reference sequence CRDT (Oster 2006).
Logoot
Dense-rational position-identifier sequence CRDT (Weiss 2009).
Treedoc
A tree-structured sequence CRDT (Preguiça 2009).
YATA
Yjs's list CRDT algorithm.
Snapshot
A point-in-time encoded state checkpoint.
WAL
Write-Ahead Log; the durable append-only delta log (rank 69).
RTO / RPO
Recovery Time / Point Objective.
fsync discipline
The policy governing when WAL writes are flushed.
MVCC snapshot
A snapshot taken from a frozen view while appends continue.
Topology
The peer-connection structure (mesh / hub-and-spoke / hierarchy).
Fanout
The number of peers contacted per gossip round.
Backpressure
Bounding in-flight bytes to prevent overload.
Wire version
The u8 byte gating payload schema (P5).
Kind byte
The u8 identifying which CRDT a payload encodes.
Schema mismatch
A decode failure when the kind byte disagrees with the expected CRDT.
PhaseDeferred
The typed error / anchor marking a deferred surface.
Conformance suite
The byte-identity test harness gating Done/Sealed.
Property test
A randomized law-checking test (proptest).
Chaos test
A fault-injection (partition/churn/crash) test (Jepsen-style).
SEC theorem
Shapiro 2011's result that CRDTs converge under SEC.
libp2p
The default transport providing discovery, NAT traversal, authenticated channels.
