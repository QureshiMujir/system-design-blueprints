Exchange Ad-Call Ingress — untrusted external boundary; an SSP/exchange (or our own SSP) sends an OpenRTB BidRequest per impression opportunity over HTTP/JSON or protobuf. L7 LB + anycast routes to the nearest region to preserve RTT budget. All input is hostile: size-bounded, schema-validated, rate-limited.

rtb-net (Ingress + Request Builder) — terminates HTTP; OpenRtbDecoder parses/validates the ad call (size caps, required fields, enum ranges); BidRequestBuilder normalizes into the internal BidRequest; TargetingFilter computes the eligible campaign set (geo/device/category/daypart/blocklists). On the response path it serializes BidResponse (seatbid) and emits nurl/burl/lurl. Trust boundary: everything downstream trusts the validated BidRequest.

rtb-fanout (Latency-Bounded Bidder Client) — owns the tmax deadline clock. Fans out the BidRequest to N eligible DSP bidders concurrently (async RPC, #155 patterns), each with a per-bidder timeout strictly less than the global budget. Drops late responses, hedges to a backup bidder when a primary is slow, and trips circuit breakers on bidders that error/time out repeatedly. The PartialResultGate guarantees the auction proceeds with whatever bids arrived before the deadline. Concurrency boundary: this is the only place that awaits external I/O on the hot path.

Pre-Auction Filters — each returned Bid must pass, in order: reserve floor (rtb-reserve), pacing admission/shading (rtb-pacing), frequency-cap eligibility (rtb-freqcap), creative/category eligibility, and scoring (rtb-predict supplies pCTR → score). A bid that fails any filter cannot win. This is a synchronous, allocation-light pipeline.

rtb-auction (Mechanism Engine) — the deterministic core. Scorer computes score = bid × pCTR × quality; Ranker sorts; Allocator assigns slots (single or multi); ClearingPriceCalc computes payment per the selected mechanism (first-price, second-price/Vickrey, GSP, VCG). Pure function of (eligible scored bids, mechanism, reserves, seed) → AuctionResult. No I/O, no clocks, no randomness except an explicit tie-break seed.

rtb-net Response — encodes the winner(s) and clearing price into a BidResponse; attaches nurl (win notice), burl (billing notice), lurl (loss notice) URLs the exchange will call.

rtb-pacing / rtb-freqcap state — on a confirmed win, spend is incremented (budget) and the impression is counted (freq-cap); the pacing controller (PID / dual update) recomputes the shading multiplier or throttle probability against the target spend curve. Persistence boundary: counters live in-process but are reconciled to the distributed KV.

rtb-journal (Append-Only Auction Log) — every auction writes an AuctionRecord (request id, eligible bids, winner, clearing price, mechanism, reserves), plus async WinNotice/BillingEvent records when notices fire. Append-only, billing-reconcilable; ReconcileCursor tracks settled vs unsettled. Durability boundary: local WAL → object store.

Shared State Plane — distributed KV (#36) holds authoritative budget counters, freq-cap sketches, and model artifacts shared across stateless auction nodes; metrics (#133) collect win/fill/eCPM/pacing/timeout series; model store serves pCTR/win-rate models. Trust boundary: internal, mutually-authenticated.

8. Domain Model / Protocol

OpenRTB Object Model (internal normalized form)

BidRequest ::= id:Uuid | imp:[Imp] | site:Site? | app:App? | device:Device
             | user:User | tmax:u32(ms) | cur:[Currency] | at:AuctionType
             | bcat:[Category] | badv:[Domain] | test:bool | tmax_deadline:Instant

Imp        ::= id:ImpId | bidfloor:Micros | bidfloorcur:Currency
             | banner:Banner? | video:Video? | native:Native?
             | secure:bool | exp:u32? | pmp:Pmp?

BidResponse::= id:Uuid | seatbid:[SeatBid] | cur:Currency | nbr:NoBidReason?

SeatBid    ::= seat:SeatId | bid:[Bid]
Bid        ::= id:BidId | impid:ImpId | price:Micros | adid:AdId?
             | adm:AdMarkup? | nurl:Url? | burl:Url? | lurl:Url?
             | cid:CampaignId | crid:CreativeId | cat:[Category]
             | seat:SeatId | recv_at:Instant   -- arrival timestamp (internal)

at (AuctionType): 1 = FirstPrice, 2 = SecondPrice (OpenRTB); internal extends with GSP, VCG. All money fields are Micros (integer; 1 unit = 1e-6 currency). recv_at is the bid arrival timestamp used by the late-drop gate. nbr = no-bid reason (see table).

Auction Mechanism Semantics

score_i      = bid_i × pCTR_i × quality_i           -- ranking key (all mechanisms)
eCPM_i       = bid_i × pCTR_i × 1000                 -- reported value-per-mille
rank: sort bids by score desc; deterministic tie-break by (score, bid, seat, bid_id)
Mechanism Allocation Payment (winner) Truthful? Notes
FirstPrice top score wins (1 slot) pays own bid (≥ reserve) No Bidder must shade; revenue = highest bid
SecondPrice / Vickrey top score wins (1 slot) pays 2nd-highest effective bid (= 2nd score / own pCTR·q), clamped to reserve, ≤ own bid Yes (DSIC) Threshold payment = Myerson payment for single unit
GSP (k slots) top-k by score get slots 1..k slot-j winner pays (score_{j+1}) / (pCTR_j · quality_j) (min bid to keep position j); floor at reserve No Locally-envy-free equilibrium; basis of search ads
VCG (k slots) top-k by score get slots 1..k each winner pays the externality: total score others would have gained had this bidder been absent, converted to its own price units Yes (DSIC) Pay harm imposed on others; ≤ GSP payment typically

Single-unit second-price payment (threshold form)

winner = argmax_i score_i
let s2 = max score among losers (0 if none)
threshold_bid = s2 / (pCTR_winner × quality_winner)   -- min bid winner needed to still win
price = max(threshold_bid, reserve)                    -- clamp to reserve
assert price ≤ bid_winner                              -- IR (I2)

GSP multi-slot payment

ranked = [b_1, ..., b_n] by score desc; slots = 1..k (k ≤ #slots, ≤ n)
next_score(j) = score_{j+1}, defined for each filled slot j = 1..k; next_score(k) := 0
price_j = max(next_score(j) / (pCTR_j × quality_j), reserve_j)   -- min bid to hold slot j

VCG externality payment

welfare_without_j(j)     = max total score achievable by others over all slots if j absent
welfare_with_j_excluded(j) = total score of others in the actual allocation (j removed)
externality_score(j)     = welfare_without_j(j) − welfare_with_j_excluded(j)   -- per winner j
price_j = max(externality_score(j) / (pCTR_j × quality_j), reserve_j)   -- score→price units; IR: price_j ≤ bid_j

Reserve / Floor Semantics

Floor type Rule
Hard floor bid < floor ⇒ bid rejected (cannot win); clearing price ≥ floor
Soft floor (legacy) bid < floor ⇒ pay first-price (= bid); bid ≥ floor ⇒ pay second-price; discourages low bids without rejecting
Publisher floor floor set by the publisher/SSP for the impression
Exchange floor floor set by the exchange; effective floor = max(publisher, exchange, dynamic)
Myerson optimal reserve r* reserve where virtual value crosses zero: φ(r*) = 0, with φ(v) = v − (1−F(v))/f(v); F = value distribution
Dynamic per-impression floor r* adjusted by context features (predicted value distribution per segment)

Worked Myerson example: if values are Uniform[0, V], F(v)=v/V, f(v)=1/V, then φ(v)=v−(V−v)=2v−V; φ(r*)=0 ⇒ r* = V/2. Optimal reserve is half the max value regardless of bidder count.

Budget Pacing Semantics

Campaign: budget B over horizon [0,T]; target spend curve S*(t) (even: S*(t)=B·t/T)
Observed cumulative spend S(t); error e(t) = S*(t) − S(t)
Method Update Bid effect
Probabilistic throttling enter auction with prob p_t; p_t ← clamp(p_t + k·e(t)/B, 0, 1) unshaded bid, admitted w.p. p_t
Dual / multiplicative pacing μ_{t+1} = max(0, μ_t + η·(spend_rate − B/T)) (mirror-descent / MW) shade bid_shaded = value / (1 + μ)
PID controller u(t) = Kp·e + Ki·∫e dt + Kd·de/dt; map u→p_t or μ throttle or shade

μ is the Lagrange multiplier on the budget constraint of the LP max Σ value·x s.t. Σ spend·x ≤ B, 0≤x≤1; at optimum, bid in opportunity-cost units value − μ·price, i.e. shade by 1/(1+μ). Anti-windup: clamp integral term; freeze on budget exhaustion.

Frequency-Cap Semantics

cap: ≤ C impressions per (user_id, campaign_id) per window W (sliding)
exact: bucketed counters keyed (user,campaign,window_bucket) with TTL = W
probabilistic: CountMinSketch[(user,campaign)] += 1 on win; estimate ≥ true (one-sided)
              HyperLogLog for distinct reach; Bloom "already capped" fast-path
admit if estimate(user,campaign) < C

Worked Examples

Single-unit second-price (with pCTR)

Bids: A(bid=2.00, pCTR=0.10, q=1) score=0.20; B(bid=3.00, pCTR=0.05, q=1) score=0.15
reserve = 0.50 (price units)
Winner = A (score 0.20 > 0.15)
threshold_bid = score_B / (pCTR_A × q_A) = 0.15 / 0.10 = 1.50
price = max(1.50, 0.50) = 1.50 ; assert 1.50 ≤ 2.00 ✓  (A pays 1.50)

GSP 2-slot

Ranked by score: b1(score .30, pCTR .10), b2(score .20, pCTR .08), b3(score .12)
slot1 price = score_b2 / pCTR_b1 = .20/.10 = 2.00
slot2 price = score_b3 / pCTR_b2 = .12/.08 = 1.50

Pacing shade

value = bid×pCTR = 0.20 ; μ = 0.25 ; bid_shaded_value = 0.20/(1+0.25) = 0.16
(spend rate above B/T ⇒ μ rose ⇒ bids shaded down ⇒ spend slows)

Malformed: late bid

deadline t_d = req.recv + 90ms ; Bid C recv_at = t_d + 5ms
PartialResultGate: C.recv_at > t_d ⇒ DROP C ; C never enters auction (I5)

Malformed: below floor

floor=1.00; only bid A price-equivalent 0.80 ⇒ A rejected ⇒ NO_BID(BelowFloor, nbr=102)

Edge: tie on score

A and B equal score ⇒ tie-break by (score desc, bid desc, seat asc, bid_id asc) → deterministic winner (I6)
