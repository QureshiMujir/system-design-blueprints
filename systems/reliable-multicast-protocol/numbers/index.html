32. Back-of-Envelope Capacity Model

  • C1 — Reorder Buffer Packet Capacity. 512 MB ÷ 1400 B/packet = 536,870,912 / 1400 ≈ 383,479 packets nominal ceiling; with the ~40 B header (§8) included, 536,870,912 / 1440 ≈ 372,827 packets is the realistic per-receiver reorder-buffer capacity (§4, §15).
  • C2 — WAL Raw Retention Floor. 50,000,000 packets × 1440 B/record (payload + header) = 72,000,000,000 B = 72 GB raw WAL floor before the < 2.3x write-amplification budget is applied (§4, §18).
  • C3 — Sustainable Replay Window at Full Rate. 5 Gbps = 625,000,000 B/s ÷ 1400 B/packet ≈ 446,429 pkts/s; 50,000,000 ÷ 446,429 ≈ 112 s ≈ 1.9 minutes — far below the nominal 2-hour retention target (§4), so the 2h default is reachable only at throttled/average rates, not the sustained ceiling.
  • C4 — FD Budget vs. Stream Scaling. 4096 FD ÷ 3 FDs/stream (multicast recv + repair unicast + metrics) = 1365.3 ≈ 1365 max concurrent streams from the FD budget alone, vs. the 200-stream horizontal scaling target (§4) — 6.8x headroom.
  • C5 — Retransmit Amplification Ceiling. 1.5x × 5 Gbps sustained throughput = 7.5 Gbps combined data+repair bandwidth ceiling on a shared link (§4, §17).
  • C6 — WAL Disk Write Throughput Requirement. 2.3x × 625,000,000 B/s = 1,437,500,000 B/s ≈ 1.44 GB/s peak sustained disk write throughput required, driving the SSD-backed storage assumption (§4, §18).
  • C7 — Timer Wheel Memory Footprint. 5,000,000 timers × 17 B/slot (8 B expiration_tick + 8 B callback_ref + 1 B retry_count, §11) = 85,000,000 B ≈ 85 MB wheel memory footprint (§16).
  • C8 — Startup Step Budget. 5 s startup ceiling ÷ 20 bootstrap steps (§12.2) = 250 ms average budget per init step.
  • C9 — Suppression Window Sizing. 25 ms p99 repair-latency ceiling (§4) ÷ 2 = 12.5 ms suppression-window upper bound, keeping duplicate-NACK risk below the first repair's expected arrival (§17).
  • C10 — Membership Heartbeat Processing Floor. 50,000 receivers ÷ 10 s convergence target (§4, §20) = 5,000 receivers/s heartbeat-processing floor.
  • C11 — Availability Incident Budget. 99.95% availability = 0.05% × 8760 h/year = 4.38 h/year downtime budget; 4.38 h × 60 min/h ÷ 2 min RTO/incident (§4) ≈ 131 independent full-RTO incidents/year before breaching the budget.
  • C12 — Per-Core Throughput Budget. 5 Gbps ÷ 64 cores (§4) = 625,000,000 / 64 ≈ 9,765,625 B/s/core ÷ 1400 B/packet ≈ 6,975 pkts/s/core sustained data-rate floor, well inside the > 3,000,000 pkts/s/core decode target (§28 M1) — the gap absorbs retry/repair overhead.
