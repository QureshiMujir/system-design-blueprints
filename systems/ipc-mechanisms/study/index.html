32. Mental Models & First Principles

  • MM1 — A pipe is a bounded ring of pages, not an infinite stream. Predicts: writes beyond PIPE_BUF may interleave; a full buffer blocks or EAGAINs, it never silently grows. Bug class without it: assuming unbounded, always-atomic writes. Applies in §13.
  • MM2 — Shared memory shares bytes, not synchronization. Predicts: any concurrent write without an explicit futex/fence is a race, regardless of how "obviously fine" the access pattern looks. Bug class without it: torn reads, reordered writes, the entire T1 threat class. Applies in §15.
  • MM3 — Edge-triggered readiness is a stricter contract requiring full drain. Predicts: a consumer that doesn't drain to EAGAIN before the next wait misses events it thinks it should have gotten. Bug class without it: FM-6's missed-wakeup hang. Applies in §21.
  • MM4 — A file descriptor is a capability, not merely a name. Predicts: possessing the FD is the authority; passing it (§18) transfers that authority, which is why SCM_RIGHTS needs kernel-mediated refcounting instead of a userspace lookup table. Bug class without it: treating fd-passing as "just sending a number," which breaks the security model (T2, ADR-25). Applies in §18, §20.
  • MM5 — Backpressure is a protocol decision, not an implementation accident. Predicts: every unbounded producer eventually needs an explicit signal, or memory growth is inevitable. Bug class without it: T11's silent OOM vector. Applies in §22.
  • MM6 — Message-queue priority is a scheduling policy, not a delivery guarantee. Predicts: without an aging mechanism, low-priority messages can starve indefinitely under sustained high-priority load (this is correct-per-spec, not a bug). Bug class without it: assuming eventual delivery is guaranteed at every priority. Applies in §16, T7.
  • MM7 — A semaphore's count is state; a condition variable's wake is an event. Predicts: conflating the two (comparing a boolean instead of a counter) reintroduces the lost-wakeup race a generation counter exists to prevent. Bug class without it: FM-12- adjacent livelocks and hangs. Applies in §19.
  • MM8 — Every IPC channel has both a trust boundary and a crash boundary, and they are not the same line. Predicts: a peer can be fully trusted and still crash mid-operation (§17.9's EPIPE handling), or fully untrusted but never crash (§20's capability checks) — designing for only one of the two boundaries misses real failure modes. Applies in §17, §20, §24.

Reference Implementations

  • Linux kernel (torvalds/linux) — fs/pipe.c (page-list buffer), ipc/mqueue.c (priority-ordered mqueue), ipc/shm.c (SysV/POSIX shm), net/unix/af_unix.c (AF_UNIX + GC). Lesson: a page-list buffer never needs contiguous allocation. Pitfall: do not copy the SysV IPC integer-ID reuse ABI wart. Applied in §13, §14, §15, §16, §17, §18.
  • FreeBSD (freebsd/freebsd-src) — sys/kern/sys_pipe.c (direct-copy PIPE_DIRECTWRITE optimization), sys/kern/uipc_usrreq.c (independent AF_UNIX implementation). Lesson: a divergent pipe backing-store design is still POSIX-conformant. Pitfall: F_SETPIPE_SZ sizing knobs are not portable to FreeBSD. Applied in §13, §33.
  • seL4 (seL4/seL4) — libsel4/include/sel4/sel4_client.h, kernel IPC fastpath src/arch/x86/64/kernel/fastpath.c. Lesson: zero-buffering synchronous IPC eliminates an entire backpressure bug class. Pitfall: does not generalize to the buffered/async delivery this project targets. Applied in §20, §33, §36.
  • Android Open Source Project (platform/frameworks/native) — libs/binder/, kernel driver drivers/android/binder.c. Lesson: a single-copy transaction directly into the receiver's mapped buffer beats double-copy. Pitfall: Binder's driver-mediated model differs from this project's peer-to-peer sockets. Applied in §18, §33.
  • D-Bus (freedesktop/dbus) — dbus/dbus-transport-unix.c, dbus/dbus-sysdeps-unix.c. Lesson: a session/system broker centralizes routing and policy atop AF_UNIX with UNIX_FD fd-passing. Pitfall: the broker is a single point of contention under fan-out. Applied in §17, §33, §36.

RFCs / Specifications

  • POSIX.1-2017 (IEEE Std 1003.1-2017), System Interfaces volume — normative baseline for pipe(), mkfifo(), shm_open(), mq_open(), sem_open(), socketpair(), poll(), select(). Applied throughout §13–§22.
  • Linux man-pages project — pipe(7), mq_overview(7), shm_overview(7), unix(7), epoll(7), futex(2) — the de facto behavioral spec beyond bare POSIX. Applied in §13, §15, §17, §21.

ADR
Architecture Decision Record; a locked, rationale-carrying design decision (§9).
Ancillary data (cmsg)
control message attached to sendmsg/recvmsg, carrier of SCM_RIGHTS/SCM_CREDENTIALS.
Backpressure
an explicit signal to a producer that a bounded resource is near capacity (§22).
Binder
Android's kernel-driver-mediated single-copy IPC transport (§33).
Capability
an unforgeable, transferable reference bundling authority with designation (§20, MM4).
CapToken / CapSet
this project's unified capability object and per-process capability collection (§11).
CLOCK_MONOTONIC
a non-jumping clock source used for internal deadlines (ADR-20).
cmsg
see Ancillary data.
Condition variable (CondVar)
a wait/signal primitive paired with a mutex, generation-counter-based here to avoid lost wakeups (§19).
D-Bus
a broker-mediated message bus atop AF_UNIX (§33).
Deferred Features Register
the table (§37) anchoring every PhaseDeferred(...).
Differential testing
comparing this project's behavior byte-for-byte against a reference kernel (Linux) on a curated trace (§23, P14).
Edge-triggered
a readiness notification mode that fires only on a not-ready→ready state transition (§21, I8).
EPIPE
the error returned by a write to a pipe/socket with no remaining readers.
EAGAIN
the non-blocking-would-block return code.
FD (file descriptor)
a per-process integer indexing into the open-file table.
FD table
the per-process map from FD to open-file entry.
FIFO
a named pipe, rendezvoused via a filesystem path (§14).
FlowController
this project's backpressure enforcement object (§11, §22).
Futex
Linux's fast userspace mutex primitive; the kernel-assisted blocking mechanism underlying ipc-sync and ipc-shm (ADR-08).
Hysteresis (watermark)
the deliberate gap between a high and low watermark that prevents signal oscillation (§22.6).
Level-triggered
a readiness notification mode that fires whenever a handle remains ready (§21).
Mach port
a capability-typed message-passing IPC object in the Mach microkernel (§33).
mq / mqueue
POSIX message queue (§16).
Mqueue
this project's message-queue type (§11).
NUMA
non-uniform memory access; cross-node shared-memory latency penalty (§4).
Open-file entry
the per-system table entry an FD indexes into; multiple FDs across processes can reference one (§18).
PageList / PipeBuffer
the chained-page ring-buffer structure backing pipes (§8.1, ADR-23).
PIPE_BUF
the atomic-write size limit on pipes (4,096 B Linux; 512 B POSIX floor).
Pollable
the ipc-core trait every primitive implements for readiness (§11).
Priority inheritance (PI)
a mutex protocol that boosts a lock-holder's priority to prevent priority inversion; deferred here (§37).
Process group
the signal-delivery group SIGPIPE targets.
Rendezvous
the act of two processes meeting via a shared name (FIFO/shm/mq path) or synchronous call (seL4).
SCM_CREDENTIALS
the ancillary-data type carrying kernel-sourced SocketCreds.
SCM_RIGHTS
the ancillary-data type carrying passed file descriptors (§18).
seL4
a formally verified microkernel using synchronous rendezvous IPC (§33, §36).
Semaphore
a counting synchronization primitive, count never negative here (I11).
SIGPIPE
the signal sent to a process writing to a pipe/socket with no readers.
Splice / vmsplice
zero-copy data-movement syscalls between file descriptors (§13.7).
Thundering herd
many waiters waking on a single event meant for one (T8).
ToCToU
time-of-check-to-time-of-use race (T12).
Unix-domain socket
an AF_UNIX socket, in stream, dgram, or seqpacket form (§17).
Watermark
the high/low threshold pair driving backpressure signaling (§22).
WaitQueue
the kernel-side sleep/wake primitive underlying all blocking ops (§11).
Wake-one / wake-all
single- vs. multi-waiter wakeup discipline (P10, I9).
Working set (FD)
the design-target concurrent FD count per process (§4).
