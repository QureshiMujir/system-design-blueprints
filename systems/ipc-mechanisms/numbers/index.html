The one defining property: every operation that can block or allocate unboundedly must be capability-checked (I7) and watermark-guarded (I10) before it touches kernel state — this single property is what makes the five primitives composable under load instead of independently correct but jointly capable of exhausting memory or file descriptors.

34. Back-of-Envelope Capacity Model

  1. Max resident pipe pages/host = N_pipes × pages_per_pipe × PAGE_SIZE = 10,000 × 16 × 4 KiB = 640 MiB worst case (chained from §4's 10,000-object/process and 64 KiB-default-capacity rows).
  2. mq throughput ceiling/core = 1 / (t_enqueue + t_dequeue) = 1 / (500 ns + 500 ns) = 1M msgs/s/core; aggregate at 64 cores (independent queues) = 64M msgs/s/host (chained from §4's M2 row).
  3. Shm fan-out capacity = region_ceiling / typical_mapping_size = 1 GiB / 64 MiB = 16 concurrent large mappings per region budget (chained from §4's 1 GiB ceiling and §15.4's 64 MiB fixture size).
  4. FD budget/host = FDs_per_process × processes_per_host = 65,536 × 64 = 4,194,304 FDs/host (chained from §4's working-set-FD row).
  5. epoll wakeup budget/core = 1 / t_wake = 1 / 200 ns = 5M wakeups/s/core (chained from §4's M3 row).
  6. Socket buffer memory ceiling/process = buf_size × N_sockets = 208 KiB × 65,536 = 13.3 GiB worst case — the number that makes backpressure (ADR-21, §22) mandatory rather than optional (chained from §4's FD-budget row applied to sockets).
  7. Splice-vs-copy throughput ratio = bandwidth_splice / bandwidth_copy = 10 GB/s / 2 GB/s = 5× (chained from §4's M6/M1 rows).
  8. Capability-check overhead at max throughput = check_cost × ops_per_sec = 50 ns × 2,000,000/s = 100 ms/s = 10% of one core's budget at the mq throughput ceiling (chained from §4's M11 row and capacity-model row 2).
  9. Backpressure buffer ceiling = watermark_bytes × N_channels = 48 KiB (75% of 64 KiB default pipe capacity) × 10,000 = 480 MiB worst-case buffered in-flight data (chained from §4's pipe-capacity row and object-count row).
  10. Fuzz-canary coverage/30-day run = execs_per_sec × seconds_in_period = 50,000 × 2,592,000 = 129.6 billion mutated IPC sequences (chained from §23.4's fuzz- throughput acceptance criterion).
