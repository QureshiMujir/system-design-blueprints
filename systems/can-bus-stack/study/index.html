Mental Models & First Principles

The compressed insights an expert holds about CAN. Each: the model, what it predicts, the bug class you write without it, and where this blueprint applies it.

MM1 — The bus is a single shared wire whose state is a logical-AND, not a set of point-to-point links. Every node sees the same bit each bit-time: bus = AND(all drives), dominant (0) beats recessive (1). Predicts: a node can transmit and simultaneously read back what actually won, which is the whole basis of arbitration and error detection. Bug class without it: modeling the bus as per-node channels or using OR/dominant=1 — every arbitration outcome inverts and ACK breaks. Applied: §3.1, Phase 4 (medium.rs), Invariant 1.

MM2 — Arbitration is "lowest ID wins" because dominant overwrites recessive bit-by-bit, MSB-first. A node that drives recessive but reads dominant has lost and silently drops to RX; the winner never even notices contention. Predicts: zero collision loss, zero retransmission on arbitration, and that priority is hard-wired into the identifier value. Bug class without it: treating arbitration like CSMA/CD (back-off + retransmit) — you add collisions that physically cannot occur and mis-time the bus. Applied: §8.11 (arbitration walk-through), Phase 5.2 (bit-monitoring), Invariant 1.

MM3 — NRZ has no self-clock; bit stuffing is the clock. With no edges, receivers drift; inserting a complementary bit after 5 identical ones guarantees an edge at least every 6 bits so PLLs resync. Predicts: worst-case frame length is data-dependent (all-same payloads stuff most), and an intentional 6-identical-bit run is how an error frame screams to everyone at once. Bug class without it: sizing buffers for the unstuffed length, or not understanding why the error flag is exactly 6 dominant bits. Applied: §8.3, Phase 2.2 (stuff.rs), Invariant 2.

MM4 — Fault confinement is a distributed immune system with no central authority. Each node scores its own errors (TEC/REC); past thresholds it voluntarily softens (Error-Passive) then removes itself (Bus-Off). Predicts: a babbling node eventually self-ejects without any coordinator, but also that a victim can be pushed toward bus-off by externally injected errors. Bug class without it: using >128 instead of ≥128, or sharing one global counter — nodes flap states or never confine. Applied: §8.6, Phase 6.2 (counters.rs), Invariants 4–5.

MM5 — The error flag works by deliberately breaking the rules everyone else enforces. Six identical dominant bits violate the ≤5 stuffing rule, so every receiver simultaneously detects a stuff/form error and joins in — globalizing one node's local error into a bus-wide event. Predicts: errors are atomic across the bus (all nodes discard the same frame) and that a "soft" error-passive node uses 6 recessive bits it cannot force onto others. Bug class without it: stuffing the error flag (it never globalizes; errors stay local). Applied: Phase 6.2 (frames.rs), §8.5, Invariant 2.

MM6 — Time is counted in integer time quanta, and a bit is sampled once, near its end. NBT = (1 + Prop + PS1 + PS2) TQ; you sample between PS1 and PS2 (≈87.5%); SJW bounds how far you may stretch/shrink a bit to re-align on an edge. Predicts: timing errors are data-dependent and intermittent (they appear only when edge spacing stresses the sample point), and that oscillator tolerance is a budget you compute, not a hope. Bug class without it: float-second timing math with rounding drift, or sampling at bit-start — intermittent bit errors correlated with payload content. Applied: §8.4, Phase 3.2 (timing.rs), ADR 23.

MM7 — DLC is a 4-bit code, not a byte count — especially in CAN FD. Classical caps at 8; FD remaps codes 9–15 to 12/16/20/24/32/48/64 bytes. Predicts: using the raw DLC nibble as a length silently truncates or over-reads FD payloads, and the CRC width (17 vs 21) flips at the 16-byte boundary, not at a DLC code. Bug class without it: off-by-one length slicing that desyncs every field after data. Applied: §8.7 (DLC table), Phase 1.2 / Phase 7.2, Invariant 8.

MM8 — Layering is strict and downward-only: bits → frames → PDUs → services. can-phys knows bits, can-ctrl knows frames, can-isotp knows segmentation, can-uds knows services; each upper layer validates and never trusts the one below blindly. Predicts: you can swap the medium (virtual ↔ SocketCAN) behind one Transceiver trait without touching protocol code, and that a transport reaching into bit timing becomes untestable. Bug class without it: a diagnostic layer that depends on simulator internals — unportable, unfuzzable. Applied: §3, §6 principle 6, Phase 8.2 (can-hal), ADR 22.

MM9 — Determinism is a feature you engineer, not a property you hope for. No floats in decisions, no wall-clock reads in protocol logic, all randomness from a seeded RNG → every run replays bit-for-bit. Predicts: any failure is reproducible from a seed + trace, making conformance and arbitration races provable rather than flaky. Bug class without it: HashMap node iteration or thread RNG that makes replay diverge and turns conformance aspirational. Applied: §4.3, Phase 4.2 / Phase 12.2 (replay), ADR 21/24/28.

MM10 — ISO-TP and J1939 TP are different segmentation protocols that happen to share the link layer. ISO-TP uses SF/FF/CF/FC with mod-16 SNs and FC flow control; J1939 TP uses TP.CM/TP.DT with 1..255 SNs and (for BAM) no flow control at all. Predicts: you cannot route J1939 multi-packet through the ISO-TP engine, and STmin's 0xF1..0xF9 means 100–900 µs, not ms — a 10× pacing trap. Bug class without it: conflating the two transports, or misreading STmin units and over-delaying every transfer. Applied: §8.8 / §8.10, Phase 9.2 / Phase 11.2, principle 15.

Glossary · 48 terms · site-wide glossary

Dominant
Logical bus state 0; overrides recessive (wired-AND).
Recessive
Logical bus state 1; present only if all nodes drive recessive.
Arbitration
Non-destructive bitwise contention; lowest ID wins, losers revert to RX.
Bit stuffing
Inserting a complementary bit after 5 identical bits to maintain edges for sync.
Fixed stuff bit
CAN FD CRC-field stuff bit inserted at fixed positions regardless of value.
Stuff-bit count
CAN FD field (Gray + parity) giving the number of dynamic stuff bits, for receiver verification.
NRZ
Non-Return-to-Zero line coding; level held for the whole bit.
TQ (time quantum)
Smallest timing unit; bit time = integer number of TQ.
NBT
Nominal Bit Time = (1 + Prop + Phase1 + Phase2) TQ.
Sync_Seg / Prop_Seg / Phase_Seg1 / Phase_Seg2
The four segments composing a bit time.
Sample point
Position (between PS1 and PS2) where the bus level is read.
SJW
Synchronization Jump Width; max TQ a bit time may be lengthened/shortened to resync.
Hard sync
Restart of bit timing at Sync_Seg on a SOF/idle edge.
Resync
In-bit timing adjustment (≤SJW) on a recessive→dominant edge.
TEC / REC
Transmit / Receive Error Counter.
Error-Active
TEC<128 ∧ REC<128; sends active (dominant) error flags.
Error-Passive
TEC≥128 ∨ REC≥128; sends passive (recessive) error flags, extra TX suspend.
Bus-Off
TEC≥256; node detaches from TX until recovery.
SOF / EOF / IFS
Start-of-Frame / End-of-Frame (7 recessive) / Inter-Frame Space (≥3 recessive).
RTR / SRR
Remote Transmission Request / Substitute Remote Request (extended frames).
IDE
Identifier Extension bit (standard vs extended).
FDF / EDL
Flexible Data-rate Format / Extended Data Length bit (marks CAN FD).
BRS
Bit Rate Switch (CAN FD data-phase rate change).
ESI
Error State Indicator (CAN FD; set if transmitter is error-passive).
DLC
Data Length Code (4 bits; non-linear FD mapping to bytes).
CRC15 / CRC17 / CRC21
CAN CRCs: classical / FD ≤16 bytes / FD >16 bytes.
Error frame
6-bit error flag + 8-bit delimiter signaling a detected error.
Overload frame
Like an active error frame; requests inter-frame delay; no TEC/REC change.
ISO-TP
ISO 15765-2 transport: segmentation/reassembly over CAN.
SF / FF / CF / FC
SingleFrame / FirstFrame / ConsecutiveFrame / FlowControl (ISO-TP).
BS / STmin
Block Size / Separation Time minimum (ISO-TP flow control).
N_As..N_Cr
ISO-TP timing parameters (sender/receiver frame/wait timers).
N_PCI
Network Protocol Control Information (ISO-TP frame-type header).
UDS
ISO 14229 Unified Diagnostic Services.
SID
Service Identifier (UDS).
NRC
Negative Response Code (UDS).
P2 / P2\
UDS server response time / extended time after NRC 0x78.
suppressPosRsp
Sub-function bit 7 suppressing the positive UDS response.
J1939
SAE higher-layer protocol over 29-bit CAN.
PGN
Parameter Group Number (J1939 message identifier).
SPN
Suspect Parameter Number (J1939 signal within a PGN).
PDU1 / PDU2
J1939 destination-specific (PF<240) / broadcast (PF≥240) formats.
TP.CM / TP.DT
J1939 transport connection-management / data-transfer PGNs.
BAM
Broadcast Announce Message (J1939 broadcast multi-packet).
Address claiming
J1939 NAME-based contention for a source address.
Wired-AND
Bus logic where any dominant driver forces the bus dominant.
PhaseDeferred
Marker for features intentionally out of the current arc (e.g. SocketCAN).
Babbling idiot
A faulty node transmitting continuously, degrading the bus.
