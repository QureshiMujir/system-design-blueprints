Invariants — what must never be false (§7) · 12

Invariants — what must never be false
Item
Arbitration is deterministic; exactly one winner = lowest numeric ID (with RTR/IDE tie-break per spec). Why: priority bus correctness. Where: can-bus resolve + can-ctrl bit-monitor. Detect: >1 node still TX after arbitration field, or winner ≠ min-ID. Telemetry: arb_round, winner_id, losers. Recover: losers auto-revert to RX (normal). Debug: bit-trace of arbitration field across nodes.
Bit-stuffing roundtrip identity; ≤5 consecutive identical bits on the wire in stuff-eligible fields. Why: receiver clock recovery + spec rule. Where: can-phys stuffer/destuffer. Detect: 6th identical bit in a stuff-eligible region → stuff error. Telemetry: stuff_inserted, stuff_error. Recover: error frame + TEC/REC update. Debug: compare pre/post-stuff bit vectors; property test stuff∘unstuff.
CRC15/CRC17/CRC21 correctness and bit order. Why: integrity. Where: can-phys CRC + can-ctrl check. Detect: computed ≠ received CRC. Telemetry: crc_error, polynomial id. Recover: form error frame; sender retransmits. Debug: run known-answer vectors; verify MSB-first shift and seed.
TEC/REC transitions follow ISO 11898-1 exactly. Why: fault confinement. Where: can-err. States: Error-Active (TEC<128 ∧ REC<128), Error-Passive (TEC≥128 ∨ REC≥128), Bus-Off (TEC≥256). Detect: state vs counters mismatch (assert). Telemetry: tec, rec, ctrl_state, transition events. Recover: per-spec increments/decrements (TX error +8, RX error +1, success −1). Debug: replay error sequence; assert counter math each event.
Bus-off recovery only after 128 × 11 consecutive recessive bits. Why: spec-mandated cool-off. Where: can-err + can-ctrl. Detect: premature re-enable. Telemetry: recess11_count, busoff_recover. Recover: reset TEC=REC=0, re-enter Error-Active. Debug: count idle recessive runs in trace.
ISO-TP CF sequence numbers monotonic mod 16, no gaps; FF starts at 1. Why: ordered reassembly. Where: can-isotp RX. Detect: SN ≠ expected → abort (wrong sequence). Telemetry: isotp_sn_expected/got, isotp_abort. Recover: drop reassembly, signal upper layer. Debug: sequence diagram from frame log.
UDS positive response SID = request SID + 0x40; else 0x7F + SID + NRC. Why: protocol contract. Where: can-uds server/client. Detect: response SID mismatch. Telemetry: uds_sid, uds_nrc. Recover: client treats mismatch as protocol error. Debug: assert on every response build.
DLC ↔ length mapping exact (esp. CAN FD non-linear codes). Why: framing correctness. Where: can-frame Dlc type. Detect: length not in legal set; DLC code↔bytes mismatch. Telemetry: dlc_code, data_len. Recover: reject frame build (Result error). Debug: table-driven unit tests for all 16 codes.
IFS ≥ 3 recessive bits before a new transmission. Why: frame delimitation. Where: can-ctrl. Detect: SOF within <3 recessive bits → form/overload. Telemetry: ifs_violation. Recover: overload frame. Debug: inter-frame gap measurement in trace.
ACK slot driven dominant by at least one receiver iff frame valid. Why: delivery confirmation. Where: can-ctrl RX + can-bus. Detect: recessive ACK slot at sender with ≥1 healthy receiver → ACK error. Telemetry: ack_error. Recover: TEC+8, retransmit. Debug: per-node ACK-slot drive trace.
CAN FD stuff-bit count + parity correct; CRC delimiter present. Why: FD integrity. Where: can-fd + can-phys. Detect: stuff-count parity mismatch. Telemetry: fd_stuffcount, fd_form_error. Recover: form error frame. Debug: FD vector replay.
No frame exceeds its format's max length (8 classical / 64 FD). Why: buffer safety. Where: can-frame constructors. Detect: oversize at build. Telemetry: build-error counter. Recover: reject. Debug: fuzz oversize inputs.
