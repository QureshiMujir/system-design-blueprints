33. Mental Models & First Principles

  • MM1 — A page table is a memoized pure function. Translation is a deterministic (root, vaddr) -> phys computation (P1); the TLB is just a cache of that function's results. Predicts: any TLB bug is a cache-coherence bug (a stale cached result), never a translation-logic bug (the function computed the wrong answer) — the two are diagnosed completely differently. Bug class without it: chasing a "translation bug" in the walker when the actual defect is a missing shootdown. Applied in §8.1, §19.
  • MM2 — The VMA is the unit of intent; the PTE is the unit of mechanism. A mmap call expresses intent at VMA granularity; the page tables realize it at PTE granularity, lazily (demand paging). Predicts: intent-level races (two overlapping mmaps) are VMA-tree bugs (§15); mechanism-level races (a stale TLB) are PTE-level bugs (§19) — conflating the two layers when debugging wastes time in the wrong crate. Applied in §15, §8.4.
  • MM3 — Reference counting is the only truth for shared physical memory. No other bookkeeping (a comment, a convention) can substitute (P10). Predicts: every double-free/use-after-free bug in this subsystem traces to a refcount operation that was skipped, non-atomic, or double-counted — never to a "forgot to check" bug at a higher level. Applied in §18, I5, I7.
  • MM4 — TLB shootdown is a distributed-consensus problem with N=core- count replicas. The writer is a coordinator; peers are replicas; the IPI+ACK protocol is the consensus round (§8.3). Predicts: every stale-TLB bug is a broken happens-before edge, structurally identical to a distributed system losing a linearizability guarantee — the same debugging vocabulary (missing acknowledgment, split-brain-adjacent partial-ACK state) applies. Applied in §19, I3.
  • MM5 — Eviction policy is a bet on future access; the page-table walker is a statement about past access. The ACCESSED bit is backward-looking (Denning's working-set model, §5); the replacement policy's promotion/ demotion is a forward-looking bet built on that backward-looking signal. Predicts: thrashing occurs exactly when the bet is structurally wrong — a moving working-set boundary the sampling cadence (100 ms, §20.2) can't track. Applied in §20.
  • MM6 — Speculative execution respects architectural permission bits but not observable microarchitectural state. The CPU's architectural contract (a privilege check) is honored; the microarchitectural side-effects of the speculated-but-squashed path (cache-line residency) are not rolled back. Predicts every entry in the Meltdown/Spectre/MDS family (§25 T6/T7) — any security boundary relying solely on architectural checks without a microarchitectural-state argument is incomplete. Applied in §24, Threat Model (§25).
  • MM7 — Fragmentation is deferred cost, not eliminated cost. Buddy coalescing defers a hard fragmentation problem to the next high-order request rather than solving it at free time (§16). Predicts the "OOM despite free memory" failure mode (FM-2, §26) is not a bug but an inherent property of any power-of-two allocator under adversarial allocation-order patterns. Applied in §16, §26.
  • MM8 — An address space is a lazily-materialized promise. A VMA is a promise ("this range behaves as X"); PTEs materialize the promise one page at a time, on fault (demand paging, §17). Predicts: mmap "success" is a promise accepted, not memory reserved — a subsequent fault can still fail (OOM) even though the mmap call itself returned success. Applied in §17, §21.

Reference Implementations

  • Linux mm/ (mm/memory.c, mm/page_alloc.c, mm/vmscan.c, mm/huge_memory.c) — the production baseline; differential target. Lesson: decoupled allocation/replacement. Pitfall: do not copy mm/'s decade of #ifdef-driven arch conditionals verbatim. Applied in §16, §20, §24 (differential bucket).
  • FreeBSD sys/vm/ (vm_map.c, vm_object.c, vm_pageout.c) — contrasting VMA/object split. Lesson: vm_object decouples backing store from address-space mapping. Pitfall: FreeBSD's shadow-object chain for COW is elegant but adds indirection we intentionally avoid. Applied in §15, §34, §37.
  • xv6 (MIT teaching OS, kernel/vm.c) — the simplest correct paging implementation. Lesson: a page-table walker in under 200 lines. Pitfall: xv6 has no TLB-shootdown story (uniprocessor-oriented); do not copy that omission. Applied in §14, §19.
  • seL4 microkernel (libsel4, capability-typed page-table objects) — microkernel contrast. Lesson: page-table memory itself is a capability-tracked resource. Pitfall: capability-typed tables are a different architecture, not a drop-in optimization. Applied in §34, §37 alt 3.
  • Redox OS (kernel/src/memory/) — a Rust no_std VM implementation. Lesson: idiomatic Rust ownership applied to physical frames. Pitfall: Redox's frame allocator is a simpler bitmap, not buddy — do not copy the allocator, copy the ownership discipline. Applied in §1 (language rationale), §16.
  • Fuchsia Zircon (kernel/vm/, VMO — Virtual Memory Objects) — object- capability memory model. Lesson: VMOs decouple "a range of memory" from "where it's mapped", similar to FreeBSD's vm_object. Pitfall: full VMO semantics (resizable, clonable, pager-backed) are broader than this blueprint's VMA model; borrow the decoupling idea only. Applied in §15, §34.

Glossary (§39) · 54 terms · site-wide glossary

ASID
Address Space ID (aarch64); tags TLB entries by address space, analogous to x86's PCID.
buddy allocator
physical-page allocator using power-of-two block-pair (buddy) coalescing.
CLOCK / second-chance
page-replacement approximation of LRU via a circular access-bit sweep.
CLOCK-Pro
CLOCK extension tracking eviction history to distinguish resident vs. non-resident pages (Jiang & Zhang 2005).
COW (copy-on-write)
sharing pages with deferred copying until first write.
CR3
x86 register holding the physical address of the top-level page table.
CXL
Compute Express Link; tiered/pooled memory interconnect.
DAX (Direct Access)
bypassing the page cache for persistent-memory- backed file mappings.
demand paging
populating page-table entries only on access, not at mmap time.
dirty bit
PTE bit indicating the page was written since last clear.
EPT (Extended Page Table)
Intel's hardware-assisted nested page table for virtualization.
fallback list
NUMA cross-node allocation preference order, derived from the SLIT.
first-touch
NUMA allocation policy: place a page on the node of the CPU that first accesses it.
generation counter
a per-page-cache-entry counter bumped on truncate/invalidate, used to detect writeback races (§8.8).
GLOBAL bit
PTE bit exempting a mapping from TLB flush on PCID/ASID context switch.
huge page
a 2 MiB or 1 GiB mapping installed at a higher page-table level than the base 4 KiB leaf.
inactive list
page-replacement queue holding eviction candidates.
INVPCID
x86 instruction for PCID-tagged TLB invalidation without a full flush.
invlpg / TLBI
x86 / aarch64 instructions to invalidate a single TLB entry.
IPI (inter-processor interrupt)
an interrupt one CPU sends another, the delivery mechanism for TLB shootdown.
KASLR
kernel address space layout randomization.
KPTI
kernel page-table isolation (Meltdown mitigation).
KSM
kernel same-page merging; content-based page deduplication.
lazy TLB
skipping shootdown IPIs to a CPU not currently running under the affected address space.
LRU (least recently used)
the replacement-policy family this design's active/inactive queues approximate.
magazine
per-CPU array of pre-freed physical frames for the buddy allocator's hot path (Bonwick & Adams 2001).
MDS (Microarchitectural Data Sampling)
speculative-execution side-channel family leaking store/fill-buffer contents.
Meltdown
CVE-2017-5754; speculative load crossing the user/kernel boundary, leaked via cache timing.
MGLRU (Multi-Gen LRU)
Linux 6.1+ replacement policy generalizing active/inactive to multiple generations.
NUMA
non-uniform memory access; multi-node memory with node-dependent access latency.
NX / XD / PXN / UXN
no-execute PTE bit variants (x86 / aarch64).
OOM killer
mechanism for terminating processes when memory is exhausted beyond recoverable pressure.
page cache
in-memory cache of file contents, indexed by (inode, offset).
PCID (Process Context ID)
x86 TLB tag identifying an address space.
PFN (Page Frame Number)
a physical page's index (PhysAddr >> PAGE_SHIFT).
PML4
x86-64's top (level-4) page-table structure.
PTE (Page Table Entry)
a single translation-plus-permission record in a page table.
PendingSet
this design's per-CPU accumulator of not-yet-flushed TLB invalidations (§11, §19).
replacement policy
the algorithm selecting which resident page to evict under memory pressure.
RSS (Resident Set Size)
the subset of a process's virtual memory currently backed by physical frames.
second-chance
see CLOCK.
shootdown
the IPI-mediated protocol invalidating a translation across every CPU that may have cached it.
SLIT (System Locality Information Table)
ACPI table describing inter-NUMA-node access-latency distances.
Spectre
CVE-2017-5753/5715 family; speculative execution past a mispredicted branch or indirect call, leaked via cache timing.
SSBD (Speculative Store Bypass Disable)
mitigation for Spectre v4 (CVE-2018-3639).
swap-in / swap-out
fault-driven retrieval from, and eviction-driven write to, the swap backing store.
THP (Transparent Huge Pages)
opt-in automatic promotion of contiguous small pages to a huge-page mapping.
TLB (Translation Lookaside Buffer)
per-CPU hardware cache of recently used translations.
TSX Async Abort
CVE-2019-11135; MDS-adjacent leak via the TSX transactional-abort path.
VMA (Virtual Memory Area)
a contiguous virtual-address range with uniform protection/backing (VmAreaStruct, §11).
W^X (write XOR execute)
the invariant that no mapping is simultaneously writable and executable.
working set
the set of pages a process has referenced within a recent time window (Denning 1968).
writeback
flushing a dirty page-cache or anonymous-swap page to its backing store.
zswap
a compressed in-RAM pool absorbing swap-out traffic before any disk I/O.
