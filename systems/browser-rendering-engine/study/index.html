34. Mental Models & First Principles

Six compressed insights an expert holds; each predicts a class of bug you write without it.

ID Insight Predicts Bug class without it Applied in
MM1 A ComputedStyle is a value, not an object — cascading produces a new one, it never mutates safe sharing (I7) across siblings and across frames in-place "optimization" that corrupts every sharer's style silently §16, §7 (I7)
MM2 The pipeline is a lowering compiler: each stage's IR is strictly less general than the last (DOM → styled tree → boxes → fragments → pixels) a stage can never reach back upstream for "more information" crate importing its downstream neighbor to peek at data it should have carried forward §3, §11, §9 (ADR-02/13)
MM3 Layout is two constraint passes, not one: width is a top-down constraint, height is a bottom-up result why block layout cannot be single-pass and why intrinsic sizing needs its own bubbling pass trying to compute height before children's heights are known → placeholder/zero heights §17–18
MM4 The cascade is a total order over a finite tuple, not a graph or a priority queue any two declarations always have a defined winner — no "implementation-defined" case a comparator that isn't a strict weak ordering → nondeterministic ties, flaky reftests §8.3, §7 (I3)
MM5 Invalidation is a monotone lattice: a mutation can only raise the required work (Paint→Layout→Style), never lower it below what a smaller change would need why InvalidationKind variants are ordered, not independent flags conflating "needs paint" and "needs layout" as unordered bits → under- or over-invalidation §24, §7 (I9)
MM6 A Layer is a cache of "I already know how to draw this without redoing layout/paint" why composite-only updates are the entire performance case for a compositor promoting everything to a layer "for speed" without measuring, wasting the memory budget for no win §23, §6 (P9)
MM7 Determinism is a design constraint, not a testing convenience — it is what makes a reftest a test rather than a suggestion why floats are banned from layout math one nondeterministic stage poisons every downstream reftest with flakiness that looks like a real bug §4.4, §7 (I10)
MM8 An arena + typed index is "ownership without a borrow checker fight" — the index is the reference, and it never dangles because the arena never frees why trees here have none of Rc<RefCell<>>'s runtime-panic risk holding a raw &Node across a mutation that reallocates the arena → use-after-free-shaped bug in safe Rust §9 (ADR-03), §11

Glossary (§40) · 44 terms · site-wide glossary

Anonymous box
a synthesized LayoutBox (no DOM node) inserted to preserve the invariant that a box's children are uniformly block-level or inline-level (I4).
Atom
an interned string handle (Copy, pointer-equality) used for tag/attribute/keyword names to avoid repeated heap comparison.
Au (app unit)
the integer layout-geometry unit; 1 CSS px = 60 Au (ADR-04).
Bloom filter (ancestor)
a probabilistic pre-filter used by StyleCache to cheaply reject non-candidate style-sharing pairs before the exact-equality check (I7).
BoxKind
the enum classifying a LayoutBox's generated type (BlockContainer, InlineBox, Flex, Text, Replaced, anonymous variants).
BoxTree
the persistent, input-only tree of LayoutBoxes produced by box generation (§17).
Cascade
the algorithm resolving competing CSS declarations to one winner per property via origin, importance, specificity, and source order (I3, §8.3).
CascadeKey
the packed sort key (origin_importance, specificity, source_order) used to order matched declarations.
Canvas
the RGBA pixel buffer produced by render-raster.
ComputedStyle
the immutable, per-element resolved style value produced by cascade() (P7).
ComputedValue
a single resolved CSS value (length, color, keyword, etc.) inside a ComputedStyle.
CSSOM
the parsed CSS object model (StyleSheet/CssRule/StyleRule/Declaration) produced by render-css.
DirtyBits
the bitset (NEEDS_STYLE|LAYOUT|PAINT|COMPOSITE) marking the earliest stale lifecycle phase (§7 I1, I9).
DisplayItem
one paintable primitive (Rect, Border, Text, Image, clip push/pop) in a DisplayList.
DisplayList
the flat, ordered list of DisplayItems produced by build_display_list (I8).
DocumentLifecycle
the forward-only phase state machine (Loading…Composited) that render-engine drives (I1).
Fixed-point (rejected here)
an alternative integer-geometry representation (16.16) rejected in favor of the simpler Au scheme (ADR-04).
FormattingContext
the layout mode a box establishes for its in-flow children: Block (BFC), Inline (IFC), or Flex (FFC).
Foster parenting
the HTML tree-construction rule relocating mis-nested <table> content to before the table rather than inside it (§8.1).
Fragment
one piece of resolved geometry (Rect + content) produced by layout(); a single LayoutBox may produce multiple fragments (fragmentation, §21).
FragmentTree
the throwaway, per-layout tree of Fragments (ADR-10).
FrameScheduler
the component coalescing invalidations between frames into one lifecycle pass (§24).
GlyphRun
a sequence of pre-shaped glyphs with position/metrics, consumed by paint/raster.
Implied end tag
an HTML tree-construction rule that auto-closes certain open elements before inserting/closing another (e.g. <li> before a new <li>).
InsertionMode
the HTML tree-construction state machine's current mode (InBody, InTable, etc.).
InvalidationKind
the classification (Style/Layout/Paint/Composite) of what a mutation requires re-running (P5).
Layer
a promoted subtree with its own cached display items, transform, and opacity, enabling composite-only updates (P9).
LayerTree
the tree of Layers built by layerization (§23).
LayoutBox
one node of the BoxTree; carries a BoxKind and a ComputedStyleId.
LineBox
one line of inline content in an Inline Formatting Context, with a baseline and a list of GlyphRuns.
Margin collapsing
the CSS 2.2 rule merging adjoining vertical margins by the signed-max formula (I6).
Node
one entry in the DOM Arena; carries NodeData, parent/children, and DirtyBits.
PropertyId
the closed enum indexing the CSS property registry (name, initial value, inherited flag).
QuirksMode
the document-wide rendering mode (NoQuirks/LimitedQuirks/Quirks) selected from the DOCTYPE (§8.1.1).
RasterBackend
the trait abstracting pixel-fill operations (fill_rect, fill_path, blit_glyph) over Canvas.
Reftest
a differential test comparing this engine's rendered output to a reference image at a per-pixel tolerance (ADR-20).
Specificity
the (a,b,c) selector-strength tuple (id-count, class/attr/pseudo-class-count, type/pseudo-element-count) used in the cascade.
StackingContext
a nested paint-order grouping created by positioned/opacity/transform boxes with a z-index (§21).
StyleCache
the component sharing one ComputedStyle across elements with provably-equal cascade inputs (I7).
StyleInvalidator
the component mapping a DOM mutation to the minimal set of elements/ DirtyBits needing restyle (§24).
StyleSheet
the parsed CSS document (rules, origin) produced by render-css.
Tokenizer
the state machine converting a byte/character stream into a token stream (HTML or CSS).
Tree construction
the HTML algorithm consuming tokens to build the DOM via InsertionMode.
WPT (Web Platform Tests)
the cross-browser conformance test suite whose reftests validate this engine's layout/paint correctness (§25). ---
