34. Mental Models & First Principles

  • MM1 — A field element is a residue class, not a bit pattern; canonical form is a choice, not a given. Predicts: two different limb representations can be mathematically equal but byte-unequal. Bug class without it: comparing or serializing before full reduction. Applies in §13.
  • MM2 — The Montgomery ladder is a constant-shape state machine over two points, not a search. Predicts: every bit of the scalar does exactly the same work regardless of value. Bug class without it: early-exit "optimizations" that leak scalar bits via timing. Applies in §16.
  • MM3 — Completeness of an addition law is a group-theoretic property, not an implementation nicety. Predicts which curve forms need exceptional-input handling and which don't. Bug class without it: point-at-infinity crashes ported from Weierstrass-style code. Applies in §15.
  • MM4 — A cofactor is leftover group structure the protocol must actively fence off, not a rounding error. Predicts that any protocol skipping the [8]-factor or explicit small-order rejection is exploitable by an attacker supplying a low-order point. Bug class without it: small-subgroup confusion attacks (T4). Applies in §17, §21.
  • MM5 — Determinism converts a signer into a pure function; the entire nonce-reuse bug class becomes a type property, not a runtime risk. Predicts why RFC 8032 needs no nonce-misuse warning the way ECDSA does. Bug class without it: catastrophic key recovery from nonce reuse/bias (T2). Applies in §20.
  • MM6 — Strict vs. lax verification is a compatibility contract, not a strictness preference — it decides which byte strings count as "the same signature." Predicts cross-implementation malleability disputes years after an algorithm ships. Bug class without it: two verifiers disagreeing on the validity of the same bytes (T3). Applies in §21.
  • MM7 — Constant-time code is a property of the compiled artifact, not the source text; the optimizer is an adversary too. Predicts why compiler-fence review and compiled-artifact inspection (objdump) are mandatory, not optional. Bug class without it: an "obviously constant-time" function the compiler branches on anyway. Applies in §23.
  • MM8 — Conformance vectors encode institutional memory of past bugs; a passing test suite is a lower bound on correctness, not proof. Predicts why Wycheproof/Chalkias corpora keep growing and why passing them today doesn't certify tomorrow's discovered edge case. Bug class without it: false confidence, treating "green CI" as "formally verified." Applies in §24, §30.

5. Required Reading

Books

  • Hankerson, Menezes, Vanstone — Guide to Elliptic Curve Cryptography (Springer, 2004). Chs. 3 (point representations/projective coordinates), 3.3 (scalar-multiplication algorithms). Applied in §15 (Edwards point arithmetic), §17 (scalar multiplication).
  • Menezes, van Oorschot, Vanstone — Handbook of Applied Cryptography (CRC Press, 1996). Ch. 4 (finite fields), Ch. 14 (efficient implementation, modular reduction). Applied in §13 (field arithmetic), §14 (Barrett reduction mod L).
  • Aumasson — Serious Cryptography (No Starch Press, 2017). Ch. 11 (elliptic curves), Ch. 13 (EdDSA / Diffie-Hellman). Applied in §8 (Domain Model), §19 (X25519 protocol).
  • Wong — Real-World Cryptography (Manning, 2021). Chs. on key exchange and digital signatures. Applied in §19 (X25519 key agreement), §21 (Ed25519 verification).
  • Ferguson, Schneier, Kohno — Cryptography Engineering (Wiley, 2010). Ch. on implementation pitfalls and side channels. Applied in §23 (constant-time hardening).
  • Paar, Pelzl — Understanding Cryptography (Springer, 2010). Ch. 9 (elliptic curve cryptography). Applied in §13 (field arithmetic foundations).
  • Rosulek — The Joy of Cryptography (open textbook, 2021). Ch. on Diffie-Hellman / group-based cryptography. Applied in §8 (Domain Model, DH definition).

  • Bos, Costello, Naehrig (2015) — Selecting Elliptic Curves for Cryptography: An Efficiency and Security Analysis, J. Cryptographic Engineering. Applied in §2 (Why Build This), §9 (ADR curve-selection rationale).

Glossary (§40) · 54 terms · site-wide glossary

Field element
a residue class modulo p = 2²⁵⁵-19, represented as five radix-2⁵¹ limbs.
GF(2²⁵⁵-19)
the prime field underlying both Curve25519 and Edwards25519.
Radix-2⁵¹ representation
the unsaturated five-u64-limb encoding of a field element.
Limb
one u64 component of a field element's radix representation.
Carry propagation
normalizing limb values back into their canonical bit-width after an operation.
Twisted Edwards curve
the curve form -x²+y²=1+dx²y² used for Ed25519, with a complete addition law.
Montgomery curve
the curve form y²=x³+486662x²+x used for X25519's x-only ladder.
Birational map
the algebraic correspondence between Edwards25519 and Curve25519 point representations.
Cofactor
the ratio between a curve's full point-group order and its largest prime-order subgroup; 8 for both Curve25519 and Edwards25519.
Small-order point
a point whose order divides the cofactor rather than the prime L.
Eight-torsion subgroup
the 8 points of order dividing 8, the source of small-order-point attacks.
Extended projective coordinates
the (X:Y:Z:T) representation enabling complete Edwards addition.
Affine coordinates
the (x,y) representation obtained by dividing out the projective Z.
Point compression
encoding a curve point as 32 bytes (y-coordinate + sign bit).
Point decompression
recovering the full point from its compressed encoding.
Canonical encoding
a wire encoding whose integer value is strictly less than the field modulus or group order.
Non-canonical encoding
a wire encoding whose value is ≥ p or ≥ L, rejected in strict mode.
Scalar clamping
the X25519-specific bit-manipulation fixing the cofactor and MSB of a secret scalar.
Scalar field (mod L)
arithmetic modulo the prime group order L.
Barrett reduction
a fast modular-reduction technique using a precomputed reciprocal.
Montgomery ladder
the constant-time, fixed-iteration x-only scalar-multiplication algorithm for X25519.
Differential addition
the ladder's per-bit operation combining an addition and a doubling.
Constant-time
an execution property where control flow and memory access never depend on secret data.
Timing side channel
an information leak through an operation's execution time.
dudect
a statistical methodology (Welch's t-test) for detecting timing side channels.
Basepoint
the fixed generator point of the prime-order subgroup, u=9 (Montgomery) / B (Edwards).
Basepoint comb table
the precomputed table enabling fast fixed-base scalar multiplication.
Fixed-base scalar multiplication
multiplying a known, reused base point by a scalar.
Variable-base scalar multiplication
multiplying an arbitrary point by a scalar.
Double-scalar multiplication
computing [a]A+[b]B in one combined operation.
Straus's algorithm
the joint-sparse-form technique underlying double-scalar multiplication.
Signed non-adjacent form (NAF)
a signed-digit scalar encoding reducing table size.
Deterministic nonce
a per-signature random value derived purely from the secret key and message, never from an RNG.
RFC 8032
the IETF specification defining EdDSA (Ed25519/Ed448).
RFC 7748
the IETF specification defining X25519/X448.
EdDSA
the Edwards-curve Digital Signature Algorithm family.
X25519
the Diffie-Hellman key-agreement function over Curve25519.
Ed25519ph
the pre-hashed variant of Ed25519 for streamed messages.
Ed25519ctx
the context-string variant of Ed25519 for domain separation.
Strict verification
RFC 8032 section 5.1.7's canonical-encoding-enforcing verification mode.
Lax verification
a permissive verification mode accepting some non-canonical encodings.
Malleability (signature)
the property that a second, distinct valid encoding exists for the same signed message.
Cofactor-aware verification
the [8]-scaled verification equation closing small-subgroup attacks.
Batch verification
verifying many signatures simultaneously via one combined equation.
Wycheproof
Google's project providing adversarial cryptographic test vectors.
CAVP / ACVP
NIST's Cryptographic/Automated Algorithm Validation Programs.
Zeroize
the practice (and Rust crate) of overwriting secret memory on drop.
subtle crate
the audited Rust crate providing constant-time primitives.
Fault injection
inducing a hardware fault (voltage/clock glitch) to leak secret data.
LadderLeak
the 2020 paper demonstrating catastrophic key recovery from small nonce biases.
Ristretto / Decaf
cofactor-removal encodings presenting a clean prime-order group.
HACL\
* — a formally-verified cryptographic library produced by Project Everest.
Multi-scalar multiplication (MSM)
computing a linear combination of multiple scalar-point products efficiently.
HPKE
RFC 9180's Hybrid Public Key Encryption, one consumer of X25519.
