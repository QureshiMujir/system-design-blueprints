32. Mental Models & First Principles

MM1 — A diffusion model is one denoiser evaluated on a noise-level curriculum; the sampler is just an ODE/SDE integrator over that curriculum. Predicts: ε/x0/v/EDM targets are reparameterizations of the same denoiser (§8, P6), never separate models. Bug class without it: writing a separate backbone per prediction target (the exact violation P6/§16 guards against). Resolving §: §8, §16 (Phase 4).

MM2 — Preconditioning is variance bookkeeping, not modeling. c_skip/c_out/c_in exist purely to keep the network's effective input/output variance near 1 across noise levels spanning ~9 orders of magnitude (§4's defining property). Predicts why σ_data must be recomputed per dataset, never copied from a paper. Bug class without it: copying EDM's ImageNet constants onto CIFAR-10 (the exact §17 N.6 pitfall). Resolving §: §8, §17.

MM3 — EMA is a low-pass filter over the optimization trajectory, not a second model. Predicts sampling should prefer EMA once training has run past the decay's effective time constant, and that EMA-worse-than-raw early in a short run is expected, not a bug. Bug class without it: mis-diagnosing a too-short run's EMA underperformance as an implementation defect (13.6). Resolving §: §7 (I2), §13.

MM4 — Classifier-free guidance is an implicit, un-trained classifier-gradient extrapolation. Predicts over-saturation at high w as an extrapolation artifact, not a training-quality problem. Bug class without it: trying to "fix" over-saturated samples by retraining instead of tuning w or applying the rescale trick (14.6). Resolving §: §8, §14.

MM5 — Terminal SNR must be exactly zero for the reverse process's boundary condition to match training. Predicts washed-out unconditional generations under any nonzero-ᾱ_T schedule, independent of model capacity or training duration. Bug class without it: chasing a "sample quality" bug that is actually a schedule-boundary defect (16.6). Resolving §: §8, §16.

MM6 — Latent diffusion relocates the modeling problem; it does not create information. The VAE delegates high-frequency pixel detail to a separately-trained perceptual compressor; the scale-factor contract (P9, I8) is therefore load-bearing metadata, not an incidental constant. Bug class without it: treating a VAE scale mismatch as training instability rather than a metadata bug (18.6). Resolving §: §18, §34.

MM7 — Progressive distillation compresses the sampling trajectory, not the model's capacity. Predicts a quality cliff at very low NFE distinct from any capacity-limited quality ceiling — the teacher's capacity is unchanged, only how many ODE steps approximate its trajectory. Bug class without it: "fixing" a distillation quality cliff by enlarging the student (21.6). Resolving §: §21, §36.

MM8 — The training loop must not know which backbone or prediction target it drives — only the conversion layer and preconditioning object should. Predicts a backbone swap (U-Net→DiT) or target swap (ε→v) produces a zero-diff in diffuse/train/loop.py. Bug class without it: an isinstance branch coupling the training loop to one backbone, breaking P7 (20.4's machine- checkable acceptance criterion exists precisely to catch this). Resolving §: §11, §20 (P7).

Reference Implementations

  • NVlabs/edm — dirs training/, dnnlib/, file training/loss.py — lesson: preconditioning is a thin wrapper, not a network change — pitfall: do not copy its dataset-specific sigma_data constants uncritically, recompute per dataset. Applied in Phase 5.
  • openai/guided-diffusion — dir guided_diffusion/, files unet.py, gaussian_diffusion.py — lesson: classifier-guidance gradient hook lives outside the model — pitfall: learn_sigma doubles output channels, decide explicitly, don't inherit by accident. Applied in Phase 1, Phase 2.
  • CompVis/latent-diffusion — files ldm/models/autoencoder.py, ldm/modules/diffusionmodules/ — lesson: the VAE scale factor (0.18215 in Stable Diffusion's KL-VAE) is load-bearing, not a magic number — pitfall: a mismatched scale factor silently degrades FID with no error. Applied in Phase 6, N.6.
  • facebookresearch/DiT — files models.py, diffusion/ — lesson: AdaLN-Zero zero-inits the modulation so the block starts as identity — pitfall: naive (non-zero- init) AdaLN destabilizes early training. Applied in Phase 8.
  • huggingface/diffusers — dirs schedulers/, models/unets/, pipelines/ — lesson: the scheduler/model split is the reference version of the Preconditioning interface (P1) — pitfall: its scheduler objects carry mutable step state, must not be shared across concurrent sampling calls (contrast I13). Applied in §11, Phase 3, Phase 11.

Glossary (§38) · 52 terms · site-wide glossary

Forward process
the fixed Markov chain that progressively adds Gaussian noise to data (§8).
Reverse process
the learned Markov chain that progressively removes noise, the sampler's target (§8).
ᾱ_t (alpha-bar)
cumulative signal-retention coefficient at step t; x_t = sqrt(ᾱ_t)·x_0 + sqrt(1-ᾱ_t)·ε (§8).
SNR (signal-to-noise ratio)
ᾱ_t/(1-ᾱ_t); the single number governing a noise level's training-information content (§8).
Terminal SNR
the SNR at t=T; must be exactly zero for correct unconditional sampling (Lin et al. 2024, §16).
ε-prediction
the network predicts the added noise directly (Ho et al. 2020).
x0-prediction
the network's output is converted to a predicted clean image (§8).
v-prediction
a signal/noise-balanced reparameterization, v := α_t·ε − σ_t·x_0 (Salimans & Ho 2022).
EDM preconditioning
the c_skip/c_out/c_in/c_noise wrapper unifying prediction targets (Karras et al. 2022, §8).
NFE (number of function evaluations)
the count of backbone forward passes a sampler performs; the primary sampling-latency currency (§4).
Ancestral sampling
the original stochastic 1000-step DDPM reverse chain (Ho et al. 2020).
DDIM
deterministic, non-Markovian sampler enabling large step skips (Song, Meng & Ermon 2021).
DPM-Solver
a high-order ODE solver reaching near-parity quality in 10–20 steps (Lu et al. 2022).
Heun sampler
a 2nd-order predictor-corrector ODE integrator (Karras et al. 2022).
Classifier-free guidance (CFG)
sampling-time interpolation between conditional and unconditional predictions using one jointly-trained model (Ho & Salimans 2022).
Guidance scale (w)
the CFG interpolation strength; w=1 is unguided, w>1 amplifies conditioning (§8).
EMA (exponential moving average)
a read-only shadow copy of weights used for sampling (P4, I2).
Latent diffusion
running the diffusion process in a VAE's compressed latent space rather than pixel space (Rombach et al. 2022).
VAE scale factor
the per-checkpoint constant normalizing encoded-latent variance to ≈1 (P9, I8).
DiT patchify
splitting a latent tensor into a sequence of transformer input tokens (Peebles & Xie 2023).
Progressive distillation
halving sampler NFE per round by matching a frozen teacher's trajectory (Salimans & Ho 2022).
FID (Fréchet Inception Distance)
the primary sample-quality metric, comparing Inception feature statistics (Heusel et al. 2017).
CLIP score
image-text alignment metric using a CLIP embedding's cosine similarity.
Cosine schedule
a β_t schedule shaped to avoid over-weighting low-noise steps (Nichol & Dhariwal 2021).
Zero-SNR fix
forcing ᾱ_T=0 to eliminate terminal-SNR leakage (Lin et al. 2024).
c_skip/c_out/c_in/c_noise
the four EDM preconditioning coefficients (§8 table).
σ_data
the empirical per-dataset pixel-value standard deviation anchoring EDM preconditioning (§17).
AdaLN-Zero
zero-initialized adaptive layer-norm conditioning in DiT blocks (Peebles & Xie 2023).
Cross-attention conditioning
injecting text/class tokens as attention keys/values rather than pixel-concatenation (P12).
CFG-dropout
randomly replacing the conditioning signal with a null token during training to enable the unconditional branch CFG needs (Ho & Salimans 2022).
safetensors
a checkpoint format storing only flat tensor buffers, no arbitrary code execution on load (ADR-15).
Checkpoint lineage
the parent-checkpoint chain tracked across distillation rounds (§21).
FSDP (Fully Sharded Data Parallel)
a distributed strategy sharding optimizer state and gradients across ranks (ADR-16, Phase 10).
DDP (Distributed Data Parallel)
gradient all-reduce-based multi-GPU training (ADR-16).
Rank-0 aggregate
the pattern of computing a shared value (e.g. EMA update) on one rank and broadcasting it, avoiding divergent per-rank state (Phase 10).
All-reduce
the collective communication operation summing/averaging gradients across ranks.
Warmup
an initial LR ramp-up period during which EMA updates are suppressed (§8 state machine).
Grad-norm guard
the inline check skipping an optimizer step on a NaN/Inf loss (I9).
Sampler contract
the fixed shape/dtype output guarantee every registered sampler must satisfy (I13).
PreconditionMismatchError
raised when a checkpoint's preconditioning/schedule metadata disagrees with the requested load (§11, I3).
SamplerDivergenceError
raised when a sampler's trajectory numerically diverges, distinct from a contract violation (§11).
Patch token
one spatial unit of a patchified latent fed to a transformer block (Phase 8).
Backbone
the trainable denoiser network (U-Net or DiT) behind the DenoiserBackbone protocol (§11).
Denoiser
the function predicting a clean (or noise, or velocity) signal from a noisy input at a given noise level.
Score matching
estimating the gradient of the log data density, the theoretical ancestor of the diffusion reverse process (Song & Ermon 2019).
ELBO (evidence lower bound)
the variational training objective diffusion's simplified loss derives from (§8).
KL divergence
the statistical distance minimized between forward-process posteriors and the learned reverse process (§8).
Teacher / student
the frozen reference model and the trainable model in a distillation round (Phase 9).
Rescale trick
a guidance-output variance correction reducing over-saturation at high w (Lin et al. 2024).
Differential testing
comparing this codebase's output against a reference implementation (diffusers) on fixed seeds for numerical parity (Phase 11).
Soak test
a long-duration (24h) continuous run checking for leaks/degradation (Phase 11).
Fault injection
deliberately triggered failures (crash, NaN, OOM) verifying documented recovery paths (Phase 11).
