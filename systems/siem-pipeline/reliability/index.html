#InvariantWhyEnforced AtDetectionTelemetryRecovery
I1Events never appear committed out-of-order within a partition.Detection correlation and replay both assume monotonic order.Append sequencer, event-log.Offset-monotonicity checks on every append.wal_append_offset_gap_total.Partition truncation to last valid offset + replay.
I2Replay of an offset range produces byte-identical detection output across runs.Forensic reconstruction must be falsifiable/repeatable.replay-engine + detection-runtime shared execution path.Replay checksum comparison against prior run.replay_checksum_mismatch_total.Halt replay, emit invariant-violation event, manual root-cause.
I3Backward-incompatible schema changes are rejected at registration.Old normalization workers must keep functioning during rolling upgrade.schema-registry compatibility validator.Compatibility-check failure on registration RPC.schema_registration_rejected_total.Producer/operator resubmits an additive-only schema version.
I4Cross-tenant event visibility is prohibited at every read path.Multi-tenant SaaS legal/compliance boundary.Partition key includes tenant_id; RBAC middleware.Tenant-leak conformance fixture (api/tenant-leak.fixture).tenant_isolation_violation_total (paged at >0).Immediate query-path lockdown + incident declared.
I5Administrative actions always generate an audit event.Compliance requires a complete action trail.query-api audit middleware, synchronous write.Audit-log completeness scan (nightly job).audit_write_failures_total.Fail the admin action if the audit write fails (fail-closed).
I6Every queue in the pipeline has a finite bound; no unbounded buffering exists anywhere.Prevents OOM cascade from one slow consumer (P3).Bounded-channel wrapper in runtime-core.Queue-depth-vs-capacity ratio alert.queue_depth{stage} gauge.Admission shedding at the producing stage.
I7Per-worker detection state stays under the 8 GB RSS ceiling (§4).Bounds blast radius of one tenant's rule set (P8).State-eviction path, detection-runtime.RSS watermark sampled every 5 s.detection_worker_rss_bytes.Evict oldest windows, shed lowest-priority rules.
I8At most one node holds write-fencing authority for a given partition at any time.Prevents split-brain dual-writers during a network partition.Lease + quorum check, control-plane.Fencing-token mismatch on write attempt.fencing_token_conflict_total.Reject write, force re-election, re-fence.
I9Every WAL segment's checksum matches its declared CRC before it is served to any reader.Corruption must be caught before it propagates into detection or query.Segment reader, event-log.CRC mismatch on segment open.segment_checksum_failure_total.Isolate segment, truncate to last valid checksum.
I10Alert deduplication is idempotent under at-least-once delivery.Alert-router retries must never double-notify an analyst.Dedup-window keyed on (rule_id, evidence_hash).Duplicate-alert conformance fixture.alert_dedup_suppressed_total.No recovery needed — suppression is the intended outcome.
I11Enrichment subsystem failure or timeout never blocks or delays ingestion acknowledgment.Ingest availability (99.99%, §4) must not depend on third-party feed uptime.Enrichment timeout budget, async off-critical-path.Enrichment-timeout counter vs. ingest-ack latency correlation.enrichment_timeout_total.Event proceeds with enrichment_fields empty; backfill job later.
I12Detection timers use the logical/event-time clock, never wall-clock reads, inside rule evaluation.Required for P1 (determinism over convenience).Deterministic-timer abstraction, detection-runtime.Static lint forbidding SystemTime::now() inside rule crates.nondeterministic_timer_lint_violations (CI gate).Reject the build; no runtime recovery — this is a compile-time invariant.
