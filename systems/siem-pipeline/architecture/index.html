Subsystem Explanations

External Sources. Untrusted producers: syslog emitters, audit logs, cloud audit feeds, endpoint-telemetry forwarders, application logs, IDS streams. Ordering is not guaranteed; clocks are assumed skewed by up to the NTP drift budget in §4.

Ingest Gateway (§14). Terminates TLS, authenticates producers (token or mTLS), validates framing, enforces per-producer quotas, applies admission control (ADR-24), emits ingest metrics, and appends accepted payloads to the event log. This is the untrusted→trusted protocol boundary.

Durable Event Log (§13). Canonical source of truth. Every accepted event gets monotonic append ordering (I1), an immutable offset, WAL durability (fsync on the critical path, ADR-09), and replay capability. This is the persistence boundary — nothing downstream is authoritative.

Normalization Engine (§15). Converts arbitrary producer schemas into EventRecord.normalized via ECS-inspired mappings looked up against the Schema Registry; preserves the original payload (payload_ref) for forensic fidelity.

Enrichment Runtime (§16). Attaches GeoIP, ASN, IOC, and asset-inventory context asynchronously, off the ingest critical path — a failure here must never block ingestion (I11).

Detection Runtime (§17). Executes streaming rules against a DAG of window/join/correlation operators with bounded per-worker memory (I7) and deterministic replay (I2).

Replay Engine (§20). Deterministic reprocessing of historical offset ranges for forensic reconstruction, rule validation, and regression testing — reads the log directly, bypassing the live ingest path, and feeds the same Detection Runtime code path.

Alert Router (§19). Deduplicates, suppresses, routes, escalates, and rate-controls detection output before SOC-integration fanout (Slack/Jira/webhooks).

Query Storage (§18). Hot columnar store optimized for time-range scans, predicate pushdown, compressed storage, and high-cardinality filtering; rolls over into cold Archive Storage (immutable object-store segments) on the retention schedule in §4.

Query API Gateway (§19). The trust boundary for analyst access: authenticated queries, RBAC enforcement, audit logging, pagination, replay-invocation control.

Analyst UI / CLI. Search, alert triage, replay invocation, and operational diagnostics — consumes only the Query API Gateway, never storage directly.

Control Plane / Schema Registry / Telemetry Runtime (side plane, §21/§15/§24). Cross-cutting services every box above depends on via control RPC, never on the hot data path.
