Box paragraphs.

  • Process Model owns every cross-cut identity: the module table, the build-id index. Every other box queries it; none re-parses /proc/<pid>/maps independently (P4, I4).
  • Sample Acquisition is the only trust/concurrency boundary that runs inside a signal handler or a BPF verifier sandbox; it is lock-free and allocation-free on the producer side (P1, I1).
  • Unwinder and Symbolizer are pure, off-signal, and swappable behind one trait each (P5, P9); the aggregator never branches on which implementation ran (P5).
  • Sample Aggregator and Span Recorder are the two independent data-path halves that converge only at the operator surfaces and the continuous-profiling agent — they never call into each other (§3 diagram; a violation would be a P11 defect).
  • Continuous-Profiling Agent owns time: batching, compression, backpressure, upload retries (P8). Producers never block on it.
  • Operator Surfaces are the only human- or dashboard-facing boundary; every one of them is read-only against the ingestion server's query API except prof attach, which mutates kernel state (loads a BPF program) and is gated by CAP_PERFMON (I13, §22 T4).

Persistence boundary: the ingestion server's object store (§21.5). Protocol boundaries: OTLP/ HTTP+gRPC (§19), the pprof query API (§21.4), the W3C traceparent header (§8.2). Concurrency boundaries: the per-thread ring (§14.1, SPSC), the worker→exporter MPSC channel (§19.3).

8. Domain Model / Protocol / Data Model

8.1 The Sample record — internal producer→consumer protocol

Fixed-size, Copy, no heap pointers (P1, P10):

Sample {
  timestamp_ns : u64            // CLOCK_MONOTONIC or CLOCK_THREAD_CPUTIME_ID
  tid          : i32
  cpu          : u32
  kind         : SampleKind     // OnCpu | OffCpu | Allocation | Free | LockWait | LockAcquire
  stack_len    : u8             // 0..=127
  stack        : [u64; 127]     // raw instruction pointers, leaf-first
  value        : u64            // cycles | bytes | nanoseconds | 1
}

8.2 W3C Trace Context — traceparent grammar (EBNF)

traceparent   = version "-" trace-id "-" parent-id "-" trace-flags
version       = 2HEXDIG                      ; "00" only, others reserved
trace-id      = 32HEXDIG                     ; not all-zero
parent-id     = 16HEXDIG                     ; not all-zero
trace-flags   = 2HEXDIG                      ; bit 0 = sampled
tracestate    = list-member *( "," list-member )
list-member   = key "=" value

Malformed-input examples: version = "01" with extra fields → per spec, forward-compatible parse (ignore trailing fields); trace-id all-zero → reject, start a new root trace (I8); missing dashes → PropagationError::Format, treated as no incoming context (new root trace, never a crash).

8.3 DWARF CFI evaluation — state table (unwind one frame)

State Input Action Next State
FindFde rip binary-search per-module FDE index (§16.3) by rip range EvalCie on hit, Fail(NoFde) on miss
EvalCie CIE initial instructions seed UnwindTable with CIE defaults EvalFde
EvalFde FDE instructions up to rip apply DW_CFA_* opcodes, building the row for rip Recover
Recover UnwindTable row + current Registers compute parent cfa, ip, sp, bp per row rules Emit
Emit parent Registers push regs.ip to out; set regs = parent FindFde (next frame) or Done (ip == 0 or sp non-increasing, I7)
Fail(NoFde) — emit [unknown], increment prof_unwind_failures_total{cause=no_fde} (I7) Done

Malformed-input example: a .eh_frame truncated mid-FDE → EvalFde runs out of bytes → Fail(Truncated) → partial stack returned with [unknown] at the truncation point (fixture conformance/corpora/unwind/dwarf-truncated.bin, §16.9).

Causal ordering (I9): a child Span created via Tracer::start while a parent Context is active inherits trace_id and sets parent_span_id; child.start_ns ≥ parent.start_ns always, because start_ns is read from SystemTime::now() at Tracer::start and the parent must have already called start to be "current" (§11.6).

8.5 pprof wire schema (Google profile.proto, summarized)

Field Type Semantics
string_table repeated string index 0 must be "" (I10)
sample_type repeated ValueType e.g. ("cpu","nanoseconds"), ("alloc-objects","count")
sample repeated Sample location_id: repeated u64, value: repeated i64, label
location repeated Location id, mapping_id, address, line: repeated Line (inline-expanded, §17.4)
function repeated Function id, name (string-table idx), filename, start_line
mapping repeated Mapping memory_start/limit, file_offset, filename, build_id
period_type, period ValueType, i64 e.g. period = 10_000_000 ns for a 100 Hz profile

Malformed-input example: a decompressed body > 100 MiB (decompression-bomb guard, §22 T2) is rejected before protobuf parsing begins.

8.6 OTLP wire schema (trace, summarized)

ExportTraceServiceRequest { resource_spans: [ ResourceSpans { resource: Resource, scope_spans: [ ScopeSpans { spans: [ Span { trace_id: bytes[16], span_id: bytes[8], parent_span_id: bytes[8], name, start_time_unix_nano, end_time_unix_nano, attributes, events, status } ] } ] } ] }. trace_id/span_id are raw bytes on the protobuf wire (not hex) — the single most common interop bug (§19.9 Pitfall).

8.7 Worked example — one sample, end to end

SIGPROF fires at t=1000ns on tid=42 mid-compute_pi → handler pushes Sample{timestamp_ns:1000, tid:42, kind:OnCpu, stack_len:1, stack:[0x401234]} (I2) → worker drains ring → walk_fp (§16.2, frame pointers present) returns [0x401234, 0x401100, 0x400f00] → Symbolizer::resolve maps each IP to Frame{function:"compute_pi", file:"pi.rs", line:42} (§17.1) → StackTable::intern returns StackId(7) (§18.1) → Aggregator increments counts[StackId(7)] += 1 → at window close, ProfileBuilder::add_sample(StackId(7), 1) then finish() emits gzip pprof bytes (§18.4) validated by I10/I11.

8.8 Failure-path example

Same pipeline, but the module for 0x401234 has no build-id (Module::Anonymous, JIT page, §13.2) and /tmp/perf-<pid>.map is absent → Symbolizer::resolve returns Frame{function: "[unknown]", ...} (P7, I7) → the sample still counts in the aggregate (not dropped) → the pprof's Function.name string-table entry is "[unknown]", distinguishable in the flamegraph from a resolved frame, never conflated with a legitimately-named function.

Design principles (§6)

  • P1 — Async-signal-safety is a hard floor on the producer side. The SIGPROF handler calls only AS-safe libc functions, holds no lock the application might hold, and allocates nothing. Violating it deadlocks the sampled thread the instant a signal lands mid-malloc. Enforced by §26.6's fault-injection harness.
  • P2 — One overhead budget, audited every phase. ≤ 1% at 99 Hz (M1) is a merge-blocking gate, not an aspiration; the eBPF path is audited identically to the user-mode path.
  • P3 — Symbolization is offline by default. Agents ship (build-id, ip) tuples; resolution happens in the analysis tier. Violating it inflates agent RSS past M10 (§17.6).
  • P4 — Build-ids are the only durable module identity. Filenames/inodes/base addresses churn across deploys and containers; the GNU build-id does not. Every sample carries one.
  • P5 — One unwinder API, three implementations. FP, DWARF, kernel ORC behind one Unwinder trait (§11.10); the aggregator never branches on which ran. Violating it couples the aggregator to backend internals and breaks P5 at every call site touching it.
  • P6 — Determinism is the default. A fixed (seed, frequency, duration) tuple reproduces bit-identical pprof output on one binary/backend; cross-backend determinism is a narrower, separately-scoped guarantee (§25).
  • P7 — No silent fallbacks. An unwalkable frame emits [unknown] and increments a counter (I7); it never substitutes a wrong frame or crashes. Violating it produces plausible-looking but silently wrong profiles — the worst failure mode a profiler can have.
  • P8 — The exporter owns time, not the producers. Producers run flat-out; batching, compression, and backpressure live only in the exporter/agent tier (§19.3, §21.2).
  • P9 — Strings are owned by the symbolizer. No other module demangles or normalizes a symbol string; downstream code sees only an interned SymbolId (§11.4).
  • P10 — One arena per profile window, plus an interner arena. Sample/stack data lives in the window arena, freed at window end; symbol/build-id/module strings live in the interner arena, freed at shutdown. No per-sample malloc/free in steady state (M9, M10).
  • P11 — The Tracer trait is the SDK's only public surface. Application code depends on Tracer/Span/Context (§11.6), never on tonic/prost/OTLP internals directly.
  • P12 — OpenTelemetry compatibility is bytewise, not semantic. Exported traces validate against the OTLP protobuf schema and round-trip through the upstream opentelemetry-collector unmodified (§26.4, otlp.roundtrip).
  • P13 — Sampling backends present one Sample shape. User-mode and eBPF backends both emit Sample (§11.3); the aggregator, symbolizer, and exporter are backend-agnostic.
  • P14 — Fail closed on ambiguity, fail open on load. A malformed build-id or truncated frame fails closed (marks unknown, per P7); a saturated ring fails open (drops and counts, per I1) — the runtime never blocks the target application to preserve a sample.
