Per-box: Lifter — each machine instruction → explicit IR statements, including flag effects (the part beginners forget); memory accesses become typed loads/stores. CFG+Dominators — import #334's CFG, compute immediate dominators + dominance frontiers (Lengauer–Tarjan / Cooper-Harvey-Kennedy). SSA — place φ at dominance frontiers, rename to versioned values (Cytron). Data-flow — def-use chains, liveness, reaching defs; constant/copy propagation; dead-code elimination (esp. eliminating dead flag computations). Expression building — fold single-use SSA values into nested expressions; recover relational ops from cmp+flag+jcc patterns. Type recovery — generate size/sign/pointer constraints from usage, solve, assign types to stack slots + registers → variables. Structuring — turn the CFG into loops/conditionals/switch via dominators + interval analysis; emit goto only for genuinely irreducible regions. Emission — render the structured AST as readable pseudo-C with recovered names.

8. Domain Model

8.1 IR grammar (low register-transfer IR, SSA-able)

IrStmt  := Assign(Value, IrExpr) | Store(addr:IrExpr, val:IrExpr, size)
         | Branch(cond:IrExpr, t:Label, f:Label) | Jump(Label) | Call(target, args) | Ret(Option<IrExpr>)
         | Phi(Value, [(Value,Label)]) | Nop | Unknown(mnemonic)        // I9 fallback
IrExpr  := Val(Value) | Const(i128, size) | Load(addr, size)
         | Bin(op, IrExpr, IrExpr) | Un(op, IrExpr) | Cast(kind, IrExpr, to:Type)
         | Cmp(relop, IrExpr, IrExpr)
Value   := Reg(name, ssa_version) | Tmp(id) | StackSlot(off) | Flag(which, ssa_version)
op      := add|sub|mul|udiv|sdiv|and|or|xor|shl|lshr|ashr|...
relop   := eq|ne|ult| slt|ule|sle|...    ; recovered from flags + jcc (I1)

8.2 Flag modeling (the crux, I1)

x86 `cmp a,b` ⇒  ZF = (a-b)==0 ; SF = sign(a-b) ; CF/OF = borrow/overflow
   `jz L`     ⇒  Branch(ZF, L, fall)
fold (Phase 6):  cmp a,b ; jz L      →  Branch(Cmp(eq,a,b), L, fall)
            cmp a,b ; jl L      →  Branch(Cmp(slt,a,b), L, fall)   // SF≠OF
            test r,r ; jz L     →  Branch(Cmp(eq,r,0), L, fall)
dead flags after folding → eliminated by DCE (I11)

8.3 SSA + dominators (worked)

CFG:  B0 → {B1,B2} → B3        x defined in B1 and B2, used in B3
idom: idom(B3)=B0 ; DF(B1)=DF(B2)={B3}
φ:    B3: x3 = φ(x1:B1, x2:B2)   (placed at iterated DF of x's defs, I3)
rename: x@B1→x1, x@B2→x2, x@B3 use→x3

8.4 Structuring (Cifuentes intervals → high-level)

loop:    back-edge (n→h, h dom n) → natural loop {h..n}; pre-test→while, post-test→do-while
2-way:   block with two succs, common post-dominator m → if(cond){then}[else]{...}; join m
n-way:   jump-table block → switch(idx){ case k: ... }
seq:     single-succ chains → statement sequence
fallback: irreducible (no single header) → node-splitting or labeled goto (I8)

8.5 Worked example (function → pseudo-C)

asm (from #334):
  push rbp; mov rbp,rsp; mov [rbp-4],edi      ; param n → local
  cmp [rbp-4],0; jle .L2
  mov eax,[rbp-4]; imul eax,[rbp-4]           ; n*n
  jmp .L3
.L2: mov eax,0
.L3: pop rbp; ret
lift+SSA+fold+structure+type →
  int f(int n) {            // type recovered: param int, return int
      if (n > 0)            // cmp+jle folded → relational (I1), then-branch
          return n * n;     // imul idiom
      else
          return 0;         // xor/mov 0 idiom
  }

8.6 Malformed / hard-case examples

  • Unknown instruction from #334 ((bad)/unsupported) → IrStmt::Unknown → emitted as __unknown(/*opcode*/); analysis treats it as clobbering all (conservative, I9).
  • Indirect call (call rax) → Call(__indirect(rax), <unknown args>); arg recovery best-effort.
  • Irreducible CFG (overlapping loops, no single header) → node-split or localized goto L; (I8), still correct.
  • Self-reference via stack (recursion) → fine (per-function; call is opaque).
  • Optimized division-by-constant (multiply-by-magic + shift) → idiom-recognized → x / k (best-effort), else literal.
  • Variadic/odd calling convention → args under-recovered, flagged.
  • Tail call (jmp func) → return func(...); (best-effort) or goto/__tailcall.

Design principles (§6)

  • Lift semantics fully, including flags. Every instruction's effect on registers, memory, and EFLAGS is modeled explicitly; flag-defining ops + the consuming jcc are later folded into a relational. Violation: dropping flags → wrong conditionals (the #1 beginner bug).
  • SSA is the substrate. All analyses run on SSA; transforms preserve SSA + semantics. Violation: ad-hoc def-use → buggy propagation.
  • Semantics preservation is the invariant. Every transform (propagation, DCE, structuring) preserves observable behavior; validated against an emulator (Phase 2/11). Violation: "decompiled" code that doesn't match the binary.
  • Structure reducible graphs fully; goto only when forced. Reducible CFGs → goto-free loops/ifs; irreducible → minimal, localized gotos. Tradeoff: structuring complexity. Violation: goto-spaghetti output (useless) OR wrong structure (incorrect).
  • Determinism. Same input ⇒ same IR/AST/pseudo-C; ordered φ, ordered names, stable iteration. Violation: non-reproducible diffs.
  • Fixed-point analyses must converge. Monotone lattices + bounded iteration; every data-flow pass terminates. Violation: infinite analysis loop.
  • Type recovery is best-effort + conservative. Recover size/sign/pointer where constraints allow; default to int/void*/unknown rather than guess wrong. Violation: confidently-wrong types mislead the analyst.
  • Output is an approximation, labeled as such. Pseudo-C aids understanding; it is not a guaranteed recompile. Violation: false promise of correctness.
  • Never panic on real #334 input. Odd/partial CFGs, indirect jumps, unknown instructions → typed handling (__unknown() intrinsic), not a crash. Violation: one weird function kills the tool.
  • Idiom recovery over literal translation. Recognize compiler idioms (xor eax,eax→0, lea as arithmetic, test r,r; jz→if(!r), multiply-by-reciprocal→division). Violation: unreadable literal output.
  • Per-function isolation. Each function decompiles independently (arena-scoped); no global mutable state. Violation: cross-function corruption; no parallelism.
  • Layered + inspectable. Each stage (IR, SSA, post-DCE, structured AST) is dumpable. Violation: a black box no one can debug.
