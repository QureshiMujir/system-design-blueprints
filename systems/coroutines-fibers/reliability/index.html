Invariants — what must never be false (§7) · 17

#InvariantWhyEnforced AtDetectionTelemetryRecovery
I1Every live coroutine has exactly one owning stack allocation.Double-ownership means two coroutines write the same memory.StackHandle is !Clone, moved into CoroutineHeader (§11).Miri + loom on the allocator path (§14).helios_stack_allocs_total / helios_stack_frees_total parity.None — ownership types prevent it at compile time; debug builds abort loudly if the assumption is ever bypassed via unsafe misuse.
I2The saved-context pointer is null only in Ready or Done state.A switch to a null context is undefined behavior.resume() asserts state before switching (§16).Debug-assert + fuzz corpus ctx-null (§16.5).helios_ctx_switch_invalid_state_total.Panic in debug; Err(InvalidState) in release.
I3The guard page is PROT_NONE for the stack's full lifetime.Guard-page removal converts detected overflow into silent corruption.helios_stack::guard::install is the sole protection-bit writer (§14).Periodic conformance self-check reads mapping flags.helios_guard_page_check_failures_total.None at runtime (fail-fast); the conformance gate blocks release.
I4A Blocked coroutine is on exactly one wait list.Two wait lists produce a double-wake race.park() registers atomically on one list (§19–§20).Loom model-check at thread counts 2 and 3 (§21).helios_park_double_registration_total.Rejected at the type level — the wait-list token is !Clone, consumed on first park.
I5The context switch never touches the outgoing stack's x86-64 SysV red zone.Touching it after control leaves the frame corrupts data the compiler assumed untouched.The assembly routine only pushes/pops explicitly saved registers (§13).Two-reviewer CODEOWNERS review of every .s diff.None (compile-time/review contract).None — this is why the two-reviewer gate is mandatory.
I6Every CoroutineHeader hot section fits in one 64-byte cache line.A cache-missing header switch costs ~4× the M1 budget.#[repr(C, align(64))] (§11).const_assert!(size_of::<CoroutineHeader>() <= 64).N/A (compile-time).Build fails; no runtime path.
I7An observed Cancel signal is never silently dropped.Silent drop breaks structured concurrency's "children finish before parent returns" contract.yield_value/park check the flag before returning control (§22).Conformance fixture cancel-mid-yield (§22.5).helios_cancel_observed_total vs helios_cancel_signaled_total parity.Force-terminate after grace period; marked Panicked(CancelTimeout) (§22.6).
I8Work-stealing never steals a Pinned coroutine.Pinning exists for TLS/FFI-affinity correctness (P9); a steal silently violates it.The Chase-Lev steal path filters on the migratable bit (§19).Loom + fixture steal-respects-pin (§19.5).helios_steal_attempts_on_pinned_total (must be 0).None if I8 holds; a violation blocks release as a P0 defect.
I9The SIGSEGV handler never allocates.A fault inside malloc deadlocks a handler that itself calls malloc.Handler touches only a pre-allocated per-thread coroutine table (§18).Code review + a #[forbid(alloc)] custom lint on the handler module.N/A.None — a build/review-time contract, not a runtime one.
I10A pooled stack is zeroed before reuse.A reused stack carrying the prior occupant's data is a cross-coroutine confidentiality leak.pool::retire() zeroes before returning to the free list (§14).Fixture pool-no-leak diffs retired-then-reallocated content.helios_stack_zero_ns histogram (cost visibility).None needed — enforced unconditionally, no opt-out.
I11Exactly one coroutine is Running per OS worker at a time.Two "running" coroutines sharing one register file directly violates what a context switch means.The per-worker slot is a single atomically-swapped Option<CoroutineId> (§19).The replay harness asserts this at every recorded switch (I13).helios_worker_running_count gauge (must read 0 or 1).None — a violation indicates a scheduler defect, not a recoverable state.
I12A Done coroutine's stack is retired exactly once.Double-return corrupts the pool free list; double-munmap is UB.Drop for Coroutine is the sole retire call site; a retire flag prevents re-entry (§14, §16).Fixture no-double-retire; Miri on the isolated allocator path.helios_stack_double_retire_total (must be 0).None — caught pre-release by the fixture gate.
I13A recorded (seed, op-log) pair reproduces an identical schedule and interleaving on replay.Without this, a production race is unreproducible offline.The scheduler's steal-target choice and channel wake order are both seeded from one PRNG captured in the op-log (§19).Replay harness diffs two runs of one seed (conformance/corpora/replay/).helios_replay_divergence_total (must be 0 in CI).A divergence blocks release.
I14Every public API panic path is documented in its rustdoc.An undocumented panic silently violates a caller's catch_unwind contract.#![deny(clippy::missing_panics_doc)] at the crate root (§16 onward).cargo clippy --deny warnings in CI (ADR-18).N/A.Build fails; not a runtime concern.
I15A Fiber's switch_to never targets a stack currently Running on another worker.Two workers executing the same stack simultaneously is a direct memory-safety violation (aliased mutable stack).switch_to asserts the target's state before calling swap() (§17.2).Fixture switch-to-running-rejected.helios_fiber_switch_invalid_state_total.Err(TargetBusy) returned instead of switching.
I16The stack pool's per-size-class free-list length never exceeds its configured cap.An uncapped pool defeats the bounded-memory guarantee of §4/§34.pool::retire() checks the cap before retaining a stack (§14.2, ADR-21).Fixture pool-cap-eviction (§14.5).helios_stack_pool_len{class} gauge.Excess stacks are munmap'd immediately, not queued.
I17A helios-c-abi handle is never dereferenced by Rust code after its corresponding free call from C.The double-free/use-after-free shape the C-ABI boundary must prevent to uphold P13's embedder contract.The handle table marks a freed slot invalid before returning (§10 helios-c-abi).A C-side fixture exercising free-then-use.N/A (embedder-side).An error code returned to the C caller; no Rust-side panic across FFI (unwinding across FFI is UB).
