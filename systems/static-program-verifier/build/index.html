⬜ Phase 0 — Skeleton, workspace, and the "assert true verifies, assert false fails" smoke test §12

Objectives
  • Stand up spv Cargo workspace, 7 spv-* members (spv-syntax, spv-ast, spv-ivl, spv-vc, spv-smt, spv-verify, spv-cli), edition 2021, MSRV 1.78 pinned in rust-toolchain.toml.
  • Define type shells (variants present, bodies todo!()/trivial): Program/Decl/Method/Spec/Stmt/Expr/Type, IvlCmd, VcFormula, SmtTerm/SmtSort, SmtSolver trait + SmtResult/Model, VerifyResult/VError/VErrorKind/Counterexample, Reason. Error enums ParseErrorKind/TypeError.
  • One thin true path wired through all crates: hand-built assert true/assert false method -> desugar -> wp -> trivial VcFormula -> SmtTerm -> stub solver returns Unsat/Sat.
  • Ship smoke test: assert true ⇒ Verified; assert false ⇒ Failed([VError{kind: AssertionMightNotHold,..}]). Soundness invariant born here: a Sat model can NEVER map to Verified.
  • Wire CI (fmt/clippy -D warnings/build/test on MSRV+stable), Makefile, Dockerfile; spv-smt SmtSolver stub behind feature = "stub-solver"; scaffold Boogie/Dafny differential oracle (skipped if absent).

All 7 crates compile with shells; make smoke runs the two-method slice end-to-end.

⬜ Phase 1 — Source front end (lexer, parser, AST) §13

Objectives

  • Surface AST per spine: Program/Decl/Method/Function/Spec/Stmt/Expr/Type — methods w/ requires/ensures/modifies/decreases; stmts assert/assume/var/assign/if/while(+invariants+decreases)/call/return; exprs incl old(), Quant w/ Trigger, function Call, Field.

⬜ Phase 2 — Name resolution, type checker, spec well-formedness §14

Objectives
  • Resolve every Var(Atom)/Call(Atom,..)/Field(_,Atom) to a declaration; emit TypeError::Undeclared on miss; reject duplicate decls/params/locals.
  • Infer & check Type for every Expr; verify assignment/contract/operator typing; emit Mismatch{expected,got}/ArityMismatch.
  • Spec well-formedness: requires/ensures/invariants are Bool (NonBoolSpec); Old only in ensures (OldOutsideEnsures); modifies entries are assignable lvalues over Ref/Map state (BadModifies).
  • Produce a typed AST (every Expr annotated with its Type, every name carrying a DefId) consumed unchanged by spv-ivl/spv-vc.
  • Determinism: same input → byte-identical typed AST + first error; errors ordered by source Span.
Deliverable

resolve_and_check(&Program) returns TypedProgram (every Expr carries Type, every name a DefId) for well-formed input, else Vec<TypeError> with spans. spv-cli print-ast prints the typed AST showing inferred types and resolved DefIds. No code below spv-ast ever sees an unchecked AST.

Acceptance
  • Corpus: ≥ 40 well-typed programs → Ok, typed AST round-trips (print-ast stable, idempotent re-check).
  • ≥ 40 ill-typed programs → exact TypeError variant + span (golden-matched), one per seeded fault.
  • Every node in a typed AST has a non-None Type; every Var/Call/Field has a resolved DefId (debug-assert sweep).
  • All six TypeError variants exercised ≥ 3×; multi-error resync yields ≥ 2 errors on a doubly-broken file.
  • Throughput ≥ 50k AST nodes / s; resolve+typeck < 5 % of total verify wall-time on the Phase 13 suite.

⬜ Phase 3 — The logical expression language (FOL + old + quantifiers) §15

Objectives
  • Define a typed logical term layer LExpr (in spv-vc) and the predicate atom Pred embedded in VcFormula::Atom(Pred); provide translate_expr(&Expr, &TransCtx) -> LExpr and translate_formula(&Expr) -> VcFormula (boolean-typed Expr → formula; else → term).
  • Fix semantics for: Int arithmetic (+ - * / %, division/mod toward-zero, partiality of /0), Bool connectives (&& || ! ==> <==>), polymorphic equality == / != over Int/Bool/Ref/Map/Seq, ordering (< <= > >=).
  • Implement two-state old(e): bind every free program var in e to its pre-state version; legal only inside ensures (Phase 2 enforced) — translation assumes that invariant.
  • Implement quantifiers Quant(Forall|Exists, vars, triggers, body) → VcFormula::Forall/Exists with de-Bruijn-safe bound vars and trigger terms preserved verbatim for Phase 9 instantiation.
  • Translate pure-function calls Expr::Call(f, args) to uninterpreted applications LExpr::App(f, [..]); defining axioms are deferred to Phase 12 (this phase emits the symbol + sort only).
  • Establish the division-by-zero proof obligation hook: emit a side-condition DivisionByZero Pred so Phases 4/7 can assert it (this phase records, does not assert).
Deliverable

translate_formula / translate_expr in spv-vc producing VcFormula/LExpr for any well-typed Expr, exercised through spv print-vc --expr-only (a debug path that translates the first method's ensures conjunction and pretty-prints the resulting VcFormula). Round-trips for arithmetic, equality, ==>, forall/exists with triggers, and old() produce stable, deterministic FOL output. No IVL, no SMT yet.

Acceptance
  • 100% totality: every Phase-2-typed Expr in the conformance corpus translates without panic; property test (10k random well-typed Expr) yields no unreachable!.
  • old() correctness: in a method ensures r == old(x) + 1, the formula contains exactly one Var{x, Pre} and one Var{r, Cur} (asserted by an AST-walk test).
  • Quantifier de-Bruijn: forall i:Int :: forall j:Int :: a[i]==a[j] translates with inner refs at Bound(0)/Bound(1); no name appears in LExpr::Var.
  • Trigger fidelity: trigger term set preserved 1:1 (count + structure) into VcFormula::Forall.
  • DivOk obligations: a body with n syntactic //% ops registers exactly n Pred::DivOk entries.
  • Determinism: translating the same Expr twice produces byte-identical pretty-print (golden file).

⬜ Phase 4 — IVL core and straight-line desugaring §16

Objectives
  • Define IvlCmd = {Assume, Assert, Havoc, Assign, Seq, Choice} — the LOCKED six-constructor guarded-command core; immutable after construction.
  • Define Reason { kind: VErrorKind, span: Span } — every Assert carries why it exists + source span, so a later Sat model maps to the right VError.
  • Lower straight-line Stmt: Assign(LValue,Expr)→IvlCmd::Assign; Assert(Expr)→Assert(_, Reason{AssertionMightNotHold}); Assume(Expr)→Assume; VarDecl→optional Assign; Return→Seq([]) (contracts deferred).
  • Lower If(g, thn, els)→Choice([assume g; thn], [assume !g; els]) — nondeterministic choice with guarding assumes; both arms desugared recursively.
  • desugar_method(m: &Method) -> IvlCmd body skeleton: produce the loop-free/call-free body's IvlCmd; pre/post wrapping is a no-op stub here (Phase 5 fills it).
  • Invariant: lowering is semantics-preserving — {P} stmt {Q} holds iff {P} desugar(stmt) {Q} holds — verified later via wp; structurally, no Stmt path may drop an Assert.
Deliverable

Compilable spv-ivl such that any loop-free, call-free typed Method (from Phase 2 output) lowers via desugar_method to a fully-formed IvlCmd tree. spv print-ivl <file.spv> pretty-prints the tree for such methods; each lowered Assert shows its VErrorKind tag.

⬜ Phase 5 — Procedure contracts and modular verification §17

Objectives
  • Make desugar_method wrap a body as assume(requires) ; body ; assert(ensures) (each ensures its own Assert with a distinct Reason{PostconditionMightNotHold}) — close the open end left by Phase 4 (which produced only the straight-line body IvlCmd).
  • Lower Stmt::Call(outs, callee, args) to the modular triple assert(callee.requires[args]) ; havoc(callee.modifies ∪ outs) ; assume(callee.ensures[args, old↦pre, ret↦outs]) — caller sees the callee CONTRACT, never its body. This is what makes verification scale O(methods), not O(call-graph paths).
  • Frame all unmodified state: variables NOT in modifies ∪ outs keep their pre-call values across the call (no havoc, no fresh version) — frame condition is implicit (the un-havoced var is untouched), made explicit only later under DSA (Phase 8).
  • Snapshot old() at method entry and at call sites; substitute formal params/returns by actual args/out-LValues in both the precondition (asserted) and postcondition (assumed).
  • Detect direct/mutual recursion in the call graph and verify modularly WITHOUT inlining (no termination check yet — that is Phase 6 decreases).
Deliverable

desugar_method produces a complete IvlCmd for any method whose body contains calls (still no loops): pre/post-wrapped body with each Call replaced by its assert-pre / havoc-modifies / assume-post triple. spv print-ivl method.spv shows the contract triple at each call site. Cross-method verification is structurally enabled (VC for one method depends only on callee SIGNATURES).

Acceptance
  • A caller invoking a correct callee whose precondition the caller establishes → IVL contains exactly the asserts/havoc/assume of the contract, NO callee body commands (assert by AST node count: callee statements absent).
  • Callee with K-element modifies and M out-params → Havoc has |unique(K∪M)| Vars; every other in-scope var omitted (frame check via diff against pre-call var set).
  • ensures count → equal count of distinct Assert nodes at method tail, each carrying PostconditionMightNotHold; requires count at call → equal PreconditionOfCallMightNotHold asserts.
  • old(x) in callee ensures resolves to the pre-Havoc snapshot Var, verified by name match in printed IVL.
  • Determinism: desugar_method byte-identical across runs (stable snapshot/var naming); golden print-ivl diff = 0.
