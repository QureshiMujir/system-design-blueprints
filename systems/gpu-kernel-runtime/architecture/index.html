Host Runtime API — exposes CUDA-like host semantics: launch configuration, device allocation, stream/event control, synchronization; the only surface client code calls (P3, ADR-02).

Virtual Driver / Command Queue — accepts host API calls as dispatch packets on a per-stream command buffer, submits them to queues in enqueue order (I9, I12); models the DMA engine as an explicit-latency copy (ADR-17).

Grid Scheduler — owns block dispatch, warp formation, occupancy accounting (I15), divergence-mask bookkeeping (I13), and barrier rendezvous (I3); the single component that must "think in warps" (MM1).

Memory Manager — implements the five memory spaces (§8), unified virtual addressing, host↔device transfer, and the coalescing-accounting model (MM4) that drives bandwidth telemetry.

Execution Backend — the CPU interpreter that steps one warp-instruction at a time per active lane (P1, P2); the only component that actually "executes" IR.

PTX-like IR Layer — canonical kernel representation; every frontend (only gpu-parser today) lowers into it (P5); the verifier (I7) is the single gate between untrusted kernel source and the scheduler/emulator.

Profiler / Instrumentation — first-class observability (P9): timeline traces, occupancy metrics, and memory-bandwidth statistics consumed by gpu-cli.

Kernel-Language Grammar (EBNF, illustrative subset)

kernel_decl   = "kernel" ident "(" param_list ")" "{" block+ "}" ;
param_list    = [ param { "," param } ] ;
param         = ident ":" type ;
type          = "u32" | "f32" | "ptr" state_space ;
state_space   = "global" | "shared" | "const" | "local" ;
block         = label ":" instr* terminator ;
label         = ident ;
instr         = mnemonic operand_list ;
terminator    = "bra" ident | "bra.uni" ident | "ret" | "bar.sync" int ;
operand_list  = [ operand { "," operand } ] ;
operand       = register | immediate | address ;
register      = "r" digit+ | "p" digit+ ;
address       = "[" register [ "+" immediate ] "]" ;

Worked Example — Vector-Add Warp Trace

Kernel vecadd(a: ptr global, b: ptr global, c: ptr global), launched with gridDim=(1,1,1), blockDim=(32,1,1) (exactly one warp, no divergence):

Step Instruction Effect (all 32 lanes active, mask=0xFFFFFFFF)
1 ld.global.u32 r1, [a + tid*4] each lane loads its a[tid]
2 ld.global.u32 r2, [b + tid*4] each lane loads its b[tid]
3 add.u32 r3, r1, r2 each lane computes a[tid]+b[tid]
4 st.global.u32 [c + tid*4], r3 each lane stores its c[tid]
5 ret warp retires, block completes

Coalescing classification (I14): step 1/2/4 access base + tid*4 — a unit-stride, 32-lane pattern — classified Coalesced (single memory transaction per warp).

Malformed-Input Example

Kernel source declaring ld.global.u32 r1, [a] where a is declared ptr shared in the parameter list: the parser accepts the syntax (structurally valid), but the IR verifier (I7) rejects it at lowering time — ld.global on a shared-space pointer is a state-space mismatch, raised as GpuError::StateSpaceMismatch, not silently reinterpreted as a global address.

Failure-Path Example

A kernel with two divergent branches whose reconvergence points are not the same immediate-dominator block (a verifier bug or a hand-crafted adversarial IR sample, T1) reaches the scheduler. I13's dominator-tree check at verify time is the intended gate; if it is bypassed (fuzzing target, §20), the scheduler's mask-restoration logic executes lanes that should remain masked, corrupting shared-memory state — this is FM-2, and the only way to have caught it earlier is the differential fixture corpus (P14).
