Genome Store — content-addressed (BLAKE3) persistence for every genome ever created, mutated, or archived, backed by RocksDB (ADR-05); dedupes structurally identical genomes and is the join point for lineage queries (I11). Mutation Engine — applies the operator catalogue (§8) to a parent genome, always producing a syntactically valid, then type-checked, candidate (P5, I7) before it can enter a job. Fitness Compiler — parses a .gns fitness spec once per run into an immutable evaluation plan (I13) that the sandbox executes against each candidate's compiled WASM module. Sandbox Pool — the trust boundary: every candidate genome is compiled to a WASM module and instantiated under Wasmtime fuel/memory metering (ADR-02/ADR-03), OCI+gVisor as the fallback path for legacy-target or native-code evaluation. Scheduler — turns a generation's candidate list into backpressured, idempotently-keyed evaluation jobs dispatched across the worker fleet (P6, ADR-21). Population/Archive Store — holds the current generation, the MAP-Elites behavior-space grid (§20), and the lineage DAG (I11) that makes every genome reproducible (I3). Selection Engine — implements the selection/replacement state machine (§8) that turns evaluated fitness into the next generation's parent set. Telemetry — every box above emits named metrics/traces/logs (§26) before, not after, functional behavior is declared correct (P11).

8. Domain Model

Genome IR grammar (EBNF):

genome      ::= expr ;
expr        ::= literal | var-ref | call | if-expr | let-expr ;
literal     ::= int-lit | float-lit | bool-lit ;
var-ref     ::= identifier ;
call        ::= "(" identifier expr* ")" ;
if-expr     ::= "(" "if" expr expr expr ")" ;
let-expr    ::= "(" "let" "(" binding+ ")" expr ")" ;
binding     ::= "(" identifier expr ")" ;
identifier  ::= letter (letter | digit | "-")* ;
int-lit     ::= digit+ ;
float-lit   ::= digit+ "." digit+ ;
bool-lit    ::= "true" | "false" ;

Typed AST node table:

Node Arity Type Signature Notes
IntLit 0 () -> Int terminal
FloatLit 0 () -> Float terminal
BoolLit 0 () -> Bool terminal
VarRef 0 () -> τ (bound type) terminal, resolved against enclosing Let/param scope
Call N (τ1..τN) -> τ_ret resolved against the primitive-function signature table (§11)
If 3 (Bool, τ, τ) -> τ both branches must unify to the same τ
Let 2 (bindings, body) binds N (id, τ) pairs then body: τ_body scoped; shadowing forbidden

Mutation-operator catalogue:

Operator Arity (parents) Type-Preservation Locality Expected Fitness Δ
Point Mutation 1 strict (same-τ replacement only) local (single node) small, ±ε
Subtree Mutation 1 strict (type-compatible subtree swap) non-local (depth-bounded) moderate, variance-heavy
Hoist Mutation 1 strict (promotes a well-typed subtree to root iff root τ matches) non-local often negative (usually shrinks toward a weaker partial solution)
Shrink Mutation 1 strict (replaces subtree with a minimal same-τ terminal) non-local negative on average, positive on size-adjusted fitness (§21)
Permutation 1 strict (reorders type-commutative Call arguments only) local negligible, ±ε
Size-Fair Mutation (Langdon & Poli 2002) 1 strict non-local, size-matched replacement low-variance, controls bloat

Crossover semantics: subtree crossover (Koza 1992) selects one crossover point per parent such that the two subtrees share type τ; if no type-compatible pair exists within the configured depth-search budget, crossover degrades to cloning parent A — it never emits an ill-typed genome (P5). Depth-limited to the run config's max_depth (§11 RunConfig).

Fitness DSL (.gns) grammar (EBNF):

spec        ::= objective+ constraint* ;
objective   ::= "objective" identifier weight case+ ;
weight      ::= "weight" float-lit ;
case        ::= "case" identifier input expected tolerance? ;
input       ::= "input" "(" value* ")" ;
expected    ::= "expect" value ;
tolerance   ::= "tolerance" float-lit ;
constraint  ::= "constraint" identifier "max-fuel" int-lit
              | "constraint" identifier "max-memory" int-lit ;
value       ::= int-lit | float-lit | bool-lit ;

Evaluation semantics: each objective compiles to a weighted sum over its case list; each case invokes the candidate's compiled WASM export with input, compares the sandbox's returned value to expected within tolerance (default 0 for exact match; a nonzero tolerance is required for Float objectives, per the float-reduction-order pitfall in §21 N.6), and contributes weight × pass_fraction; constraint rows are hard ceilings enforced by the sandbox (I8), not scored — a breach maps to the worst-penalty constant (I4) regardless of objective score.

Worked .gns example:

objective fib_correct
  weight 1.0
  case fib_0 input(0) expect 0
  case fib_1 input(1) expect 1
  case fib_10 input(10) expect 55
constraint bounded max-fuel 200000
constraint bounded max-memory 4194304

Selection/replacement state machine:

State Trigger Action Next State
INIT run start seed initial population from RNG stream (I1) EVALUATING
EVALUATING population admitted (I6) dispatch eval jobs via scheduler (§19) AWAIT_RESULTS
AWAIT_RESULTS all jobs settled or backpressure timeout collect fitness (P3) SELECTING
SELECTING fitness collected tournament / age-based selection (Real et al. 2019) picks parents BREEDING
BREEDING parents chosen apply mutation (§15) / crossover (§17) per configured rates (P12) TYPE_CHECK
TYPE_CHECK offspring produced reject ill-typed (I7), fallback-operator retry REPLACING
REPLACING offspring type-checked replace population per replacement policy (generational or steady-state) ARCHIVING
ARCHIVING population replaced update MAP-Elites archive (I9) + lineage DAG (I11) ADVANCING
ADVANCING archive updated checkpoint if boundary reached (§22), increment generation counter (I12) EVALUATING or TERMINATED
TERMINATED termination criterion met (generation ceiling, fitness target, operator-requested stop) final checkpoint, emit summary telemetry —

Sandbox execution contract: input = (compiled WASM module bytes, compiled fitness plan, resource ceilings from .gns constraint rows intersected with run-config defaults §4, a deterministic RNG substream for any stochastic primitive); output = SandboxResult { per-case pass/fail + values, fuel consumed, peak memory, wall-clock, exit taxonomy ∈ {Ok, Trap, FuelExhausted, MemoryExceeded, WallClockTimeout, HostError} }; the sandbox never returns partial host state beyond this result record (P10).

Worked end-to-end generation: SELECTING's parent list feeds BREEDING, which applies the configured operator-rate table; TYPE_CHECK discards roughly 2–5% of offspring in steady state (I7 telemetry); REPLACING merges surviving offspring into the next generation per the replacement policy (§16); ARCHIVING writes MAP-Elites cells whose behavior descriptor improved (I9) and appends lineage edges (I11); ADVANCING increments the generation counter (I12) and returns to EVALUATING.

Malformed-genome example: (call-undefined-fn 1 2) — call-undefined-fn is absent from the primitive-function signature table (§11); the type-checker rejects at ingest (I5), incrementing genesis_typecheck_reject_total with reason UnknownIdentifier.

Malformed-.gns example: an objective block whose case input arity does not match the candidate export signature is rejected at fitness-compile time (I13's well-formedness pass), never at evaluation time — a bad spec fails once per run, not once per candidate.

Failure-path example: a candidate whose WASM module traps mid-evaluation (integer overflow, out-of-bounds access) yields SandboxResult.exit = Trap; the fitness compiler's penalty mapping (I4) assigns the worst-defined fitness for every remaining unexecuted case, and TYPE_CHECK/REPLACING proceed unaffected — one crashing candidate never halts the generation (P13).
