Core schema & types (§11)

ExpertId(u32)
  ownership: Copy; no heap
  mutation: immutable after construction
  concurrency: Send+Sync; safe to share across threads
  persistence: serialized as u32 le in wire/checkpoint formats
  compatibility: repr(transparent); stable ABI
  invariant: value < num_experts; violated => MoeError::InvalidExpertId

TokenIdx(u32)
  ownership: Copy; no heap
  mutation: immutable after construction
  concurrency: Send+Sync
  persistence: serialized as u32 le
  compatibility: repr(transparent); stable ABI
  invariant: value < n_tokens in current dispatch batch

CapacityFactor(f32)
  ownership: Copy
  invariant: finite, > 0.0; typical range [0.5, 2.0]
  failure: NaN/Inf/<=0 => MoeError::InvalidCapacityFactor at construction
  persistence: stored in MoeConfig JSON as "capacity_factor": float
DType enum
  variants: F32, BF16, F16, I8 (quantized expert weights)
  ownership: Copy
  concurrency: Send+Sync
  serialization: lowercase string in JSON config ("f32", "bf16", …)
  constraint: GateLogits always F32 regardless of model dtype
  constraint: GEMM backend must support requested dtype or return MoeError::UnsupportedDtype

Device enum
  variants: Cpu { num_threads: usize }, Cuda { ordinal: u32 }
  ownership: Clone (cheap)
  concurrency: Send+Sync; ordinal identifies CUDA device, not a stream
  failure: Cuda ordinal >= device count => MoeError::DeviceNotFound at init
  persistence: not serialized in checkpoints; runtime configuration only
Layout struct
  fields: offset: usize, strides: SmallVec<[usize; 4]>
  ownership: Clone; no heap for rank<=4 (SmallVec inline)
  mutation: immutable after tensor view creation; new Layout per slice/transpose
  concurrency: Send+Sync (no interior mutability)
  invariant: strides.len() == shape.len(); offset + sum(dim_i * stride_i) < storage_len
  failure: violated stride invariant => MoeError::LayoutViolation (detected in debug mode)
  serialization: not persisted; reconstructed from shape + contiguity assumption on load
  rejected alt: single stride-free contiguous-only design — needed for transpose/slice in dispatch
Tensor struct
  fields:
    dtype: DType
    shape: SmallVec<[usize; 4]>   // rank-0..4 inline; heap for rank>4 (rare)
    device: Device
    layout: Layout
    storage: Arc<ArenaBlock>       // ref-counted block in TensorArena
  ownership: Arc-shared; cloning a Tensor is a view (zero-copy); exclusive mutation requires Arc::make_mut or unique handle
  mutation semantics:
    - Tensor is logically immutable (functional pipeline)
    - in-place ops require caller to hold only Arc reference count == 1 (checked at runtime in debug)
    - DispatchPlan scatter writes into pre-allocated output Tensor owned by dispatch stage
  concurrency:
    - multiple readers: safe (Arc)
    - concurrent writers: forbidden; enforced by &mut Tensor in all write APIs
    - cross-thread send: Tensor: Send+Sync because ArenaBlock: Send+Sync
  persistence: not directly serialized; weights loaded via ExpertWeights loader
  compatibility: shape/dtype/layout are public stable fields; ArenaBlock internals opaque
  failure modes:
    - shape mismatch in GEMM -> MoeError::ShapeMismatch { expected, got }
    - wrong device -> MoeError::DeviceMismatch
    - storage freed before last view dropped -> impossible (Arc prevents it)
  pitfall: aliased views to same storage with overlapping writes -> UB if both &mut; API prevents by requiring unique Arc

TensorArena struct
  purpose: bump-allocate storage blocks; reclaim whole arena per forward pass
  fields: blocks: Vec<Box<[u8]>>, bump_ptr: usize, device: Device
  ownership: owned by MoeLayer; passed by &mut into gate/dispatch/expert/combine stages
  mutation: &mut required; not Send (pinned to one thread/stream)
  lifecycle: reset() at forward-pass start reclaims all blocks O(1)
  failure: out-of-memory -> MoeError::ArenaOom { requested_bytes }
  invariant: all Tensors allocated from arena become invalid after reset(); callers must not retain Arc refs across reset boundary
  pitfall: forgetting reset() -> arena grows unboundedly; telemetry tracks arena high-water mark
GateLogits struct
  fields:
    logits: Tensor    // shape [n_tokens, num_experts], dtype F32
    n_tokens: usize
    num_experts: usize
  ownership: produced by moe-gate; consumed once by top-k selection; not cloned
  mutation: immutable after construction; gate module writes, router reads
  concurrency: single-threaded within gate stage; passed by value to router
  invariant: logits.shape == [n_tokens, num_experts]; dtype == F32
  serialization: not persisted; recomputed each forward pass
  failure: shape mismatch at construction -> MoeError::ShapeMismatch
RoutingDecision struct
  fields:
    decisions: Vec<[(ExpertId, f32); K]>   // K = top-k; per-token expert assignments + softmax weights
    n_tokens: usize
    k: usize
  ownership: produced by moe-gate router; consumed by moe-dispatch; single owner, passed by value
  mutation: immutable after construction
  concurrency: Send (passed across stage boundary)
  invariant:
    - decisions.len() == n_tokens
    - for each token: sum of K weights == 1.0 (softmax-over-topk normalized); assert in debug
    - ExpertId values < num_experts
    - weights >= 0.0 (post-softmax)
  tie-break: equal logits broken by ascending ExpertId (routing determinism invariant)
  serialization: not persisted; debug-serializable to JSON for conformance fixtures
  failure: invalid ExpertId -> MoeError::InvalidExpertId; weight sum != 1.0 -> MoeError::RoutingWeightError (debug only)
DispatchPlan struct
  fields:
    perm: Vec<u32>                 // permutation: perm[i] = original TokenIdx for dispatched slot i
    per_expert_counts: Vec<u32>    // len = num_experts; count of tokens routed to each expert (post-drop)
    dropped: BitSet                // bit i set iff TokenIdx(i) was dropped (capacity overflow)
    capacity: Capacity             // computed = ceil(capacity_factor * n_tokens * k / num_experts)
    n_tokens: usize
    num_experts: usize
  ownership: produced by moe-dispatch plan stage; consumed by scatter and a2a stages; single owner
  mutation: immutable after plan construction; scatter reads perm; gather uses per_expert_counts
  concurrency: Send; used across thread boundary between plan and scatter steps
  invariants:
    - perm.len() == sum(per_expert_counts) (total dispatched slots, not counting duplicates for k>1)
    - per_expert_counts[e] <= capacity for all e (capacity invariant)
    - dropped.len() == n_tokens
    - dropped tokens not present in perm (token conservation)
    - non-dropped tokens appear exactly k times in perm across all expert slots
  serialization: debug-serializable (JSON) for conformance fixtures; not persisted in checkpoints
  failure:
    - per_expert_counts[e] > capacity -> MoeError::CapacityOverflow (should never reach construction; caught in plan step)
    - perm contains TokenIdx >= n_tokens -> MoeError::InvalidTokenIdx
  pitfall: perm uses u32 indices; n_tokens up to ~64K safe; assert n_tokens <= u32::MAX at layer init
CombineBuffer struct
  fields:
    data: Tensor            // shape [n_tokens, d_model], dtype = model dtype; accumulator for combine step
    gate_weights: Tensor    // shape [n_tokens, k], dtype F32; normalized weights for weighted sum
    dropped_mask: BitSet    // mirrors DispatchPlan::dropped; dropped tokens get residual passthrough
  ownership: allocated in TensorArena per forward pass; consumed by combine step to produce output Tensor
  mutation: data written by combine gather; gate_weights read-only after dispatch plan
  concurrency: single-threaded combine (or partitioned by token range, non-overlapping writes)
  invariant:
    - data.shape[0] == n_tokens; data.shape[1] == d_model
    - gate_weights.shape == [n_tokens, k]
    - for each non-dropped token: sum over k of gate_weights[t, :] == 1.0 (softmax-normalized, inherited from RoutingDecision)
    - dropped token slots in data: written with residual input (passthrough); gate_weights unused for those tokens
  failure: d_model mismatch vs input tensor -> MoeError::ShapeMismatch
  pitfall: zero-initialize data before combine scatter to avoid accumulating garbage from prior forward pass
ExpertWeights struct
  fields:
    w_in:  Tensor    // shape [d_ff, d_model] for this rank's expert shard
    w_out: Tensor    // shape [d_model, d_ff] for this rank's expert shard
    expert_id: ExpertId
    ep_rank: u32     // which EP rank owns this expert shard
    dtype: DType
  ownership: loaded once at init; Arc-shared into expert FFN kernels; not cloned per forward pass
  mutation: immutable during forward pass; re-loaded only on weight hot-swap (future phase)
  concurrency: Send+Sync (Arc<Tensor> storage is read-only during forward)
  sharding invariant: expert e lives on EP rank (e.value % world_size); w_in/w_out contain only this rank's slice
  persistence: loaded from safetensors layout; key format "experts.{expert_id}.w_in" / "experts.{expert_id}.w_out"
  compatibility: shape [d_ff, d_model] is canonical regardless of EP sharding; sharding expressed via Layout offset/stride
  failure: missing key in checkpoint -> MoeError::WeightLoadError; shape mismatch -> MoeError::ShapeMismatch
  pitfall: d_ff may differ per expert in heterogeneous MoE; validate per-expert shape at load time
AuxLossState struct
  fields:
    importance: Vec<f32>    // len = num_experts; sum of softmax weights routed to each expert (for importance loss)
    load:       Vec<f32>    // len = num_experts; fraction of tokens routed to each expert (for load-balance loss)
    z_logits:   Vec<f32>    // len = num_experts; log-sum-exp of gate logits per expert (for z-loss)
    n_tokens:   usize
    num_experts: usize
  ownership: produced by moe-gate alongside RoutingDecision; consumed by backward to compute aux gradients
  mutation: written once during gate forward; read during backward; not modified between
  concurrency: single-threaded within gate; passed by value to loss computation
  invariant:
    - importance.len() == load.len() == num_experts
    - sum(load) ~= k (each token routes to k experts; floating point tolerance 1e-4)
    - importance[e] >= 0 for all e
  serialization: not persisted; recomputed each forward pass; logged to telemetry per step
  failure: num_experts mismatch -> MoeError::DimensionMismatch
EpGroup struct
  fields:
    rank:       u32
    world_size: u32
    transport:  Arc<dyn Transport>
  ownership: Arc-shared across moe-comm and moe-sched; initialized once at runtime startup
  mutation: immutable after init; transport is a trait object with interior mutability for connection state
  concurrency: Send+Sync; multiple stages may hold Arc<EpGroup>
  invariant:
    - rank < world_size
    - expert e lives on rank (e.value % world_size); enforced at weight load and dispatch plan construction
    - all ranks in EpGroup must agree on world_size (checked during transport handshake)
  persistence: not serialized; reconstructed from env vars (MOE_EP_WORLD_SIZE, MOE_EP_RANK) at startup
  failure:
    - rank >= world_size -> MoeError::InvalidEpRank
    - transport init failure -> MoeError::CommInitError(String)
  pitfall: world_size=1 (single-rank) still requires EpGroup; all-to-all becomes a no-op memcpy in InProc transport

Transport trait (object-safe)
  methods:
    fn all_to_all(&self, send: &[u8], send_counts: &[usize], recv: &mut [u8], recv_counts: &[usize]) -> Result<(), MoeError>
    fn all_reduce_sum_f32(&self, buf: &mut [f32]) -> Result<(), MoeError>
    fn barrier(&self) -> Result<(), MoeError>
  variants:
    InProcTransport  -- uses crossbeam channels; world_size <= logical cores; for tests + single-node sim
    MultiProcTransport -- shims MPI_Alltoallv / NCCL all-to-all; activated when MOE_EP_WORLD_SIZE > 1 && feature="mpi"
  invariant: all_to_all byte counts must be symmetric across ranks (EP consistency invariant); validated in debug mode
  failure: bytes miscount -> MoeError::A2aCountMismatch { rank, expected, got }
  rejected alt: hard-coding MPI directly in moe-comm -> breaks single-node tests; Transport trait decouples
MoeConfig struct
  fields:
    num_experts:     u32          // total experts across all EP ranks
    k:               u32          // top-k; 1 <= k <= num_experts
    capacity_factor: CapacityFactor
    ep_size:         u32          // EP world_size; must divide num_experts
    d_model:         usize
    d_ff:            usize
    dtype:           DType
    activation:      ActivationKind  // SwiGLU | ReLU | GeLU
    noisy_gate:      bool
    expert_choice:   bool
    aux_loss_coeff:  f32
    z_loss_coeff:    f32
    shared_expert:   bool
  ownership: Arc-shared; loaded once from JSON config file; immutable during training/inference run
  mutation: immutable after construction; modifying requires re-init of MoeLayer
  concurrency: Send+Sync
  serialization: serde JSON; all fields required except optional aux/z loss coefficients (default 0.0)
  invariants:
    - 1 <= k <= num_experts
    - ep_size divides num_experts
    - capacity_factor.0 > 0.0
    - expert_choice XOR noisy_gate (cannot both be true)
  failure: constraint violation at deserialization -> MoeError::ConfigError(String)
MoeLayer struct
  fields:
    config:    Arc<MoeConfig>
    ep_group:  Arc<EpGroup>
    experts:   Vec<Arc<ExpertWeights>>   // only this rank's local experts (len = num_experts / ep_size)
    gate_proj: Tensor                     // W_g: shape [d_model, num_experts]; gate linear projection
    shared_expert: Option<Arc<ExpertWeights>>
    arena:     TensorArena               // per-layer arena; reset each forward call
    telemetry: Arc<TelemetrySink>
  ownership: owned by caller (model runtime or moe-cli); not cloned
  mutation: &mut Self required for forward() (arena reset is mutating); weight fields immutable
  concurrency: not Send (TensorArena pinned to caller thread); wrap in Mutex<MoeLayer> for multi-thread callers
  lifecycle: ::new(config, ep_group, weights, telemetry) -> Result<Self, MoeError>; drop releases arena + weights Arc
  public API:
    fn forward(&mut self, input: &Tensor, train: bool) -> Result<(Tensor, Option<AuxLossState>), MoeError>
  invariants:
    - input.shape == [n_tokens, config.d_model]
    - output.shape == input.shape (token conservation)
    - train=false: AuxLossState returned as None; aux/z loss not computed
  failure modes:
    - input shape violation -> MoeError::ShapeMismatch
    - arena OOM -> MoeError::ArenaOom
    - comm failure -> MoeError::CommError(Box<dyn Error>)
    - GEMM FFI error -> MoeError::GemmError(String)
MoeError enum (non_exhaustive)
  variants:
    ShapeMismatch       { expected: SmallVec<[usize;4]>, got: SmallVec<[usize;4]> }
    DimensionMismatch   { context: &'static str, expected: usize, got: usize }
    InvalidExpertId     { id: u32, num_experts: u32 }
    InvalidTokenIdx     { idx: u32, n_tokens: u32 }
    InvalidCapacityFactor(f32)
    CapacityOverflow    { expert_id: ExpertId, count: usize, capacity: usize }
    RoutingWeightError  { token_idx: usize, weight_sum: f32 }
    DeviceMismatch      { expected: Device, got: Device }
    DeviceNotFound      { ordinal: u32 }
    UnsupportedDtype    { dtype: DType, context: &'static str }
    LayoutViolation     (String)
    ArenaOom            { requested_bytes: usize, available: usize }
    WeightLoadError     (String)
    ConfigError         (String)
    GemmError           (String)
    CommInitError       (String)
    CommError           (Box<dyn std::error::Error + Send + Sync>)
    A2aCountMismatch    { rank: u32, expected: usize, got: usize }
    InvalidEpRank       { rank: u32, world_size: u32 }
  traits: std::error::Error, Display, Debug, Send, Sync
  ownership: heap-allocated message strings only in leaf variants; others are Copy-friendly
  conversion: From<std::io::Error> -> MoeError::WeightLoadError; From<serde_json::Error> -> MoeError::ConfigError
  serialization: not persisted; logged via tracing::error! with structured fields at error site
  invariant: no variant captures raw pointers or non-Send types
  pitfall: CommError boxes dyn Error to avoid pulling comm-crate types into moe-core; keep moe-core dep-free
TelemetrySink trait (object-safe)
  methods:
    fn record_expert_utilization(&self, step: u64, utils: &[f32])  // utils[e] in [0,1]
    fn record_drop_rate(&self, step: u64, rate: f32)
    fn record_routing_entropy(&self, step: u64, entropy: f32)
    fn record_stage_latency(&self, step: u64, stage: StageName, nanos: u64)
    fn flush(&self)
  implementations: NullSink (tests/benches), LogSink (tracing-based), MetricsSink (prometheus-compatible counters)
  concurrency: &self (shared ref); interior mutability behind Mutex or atomic counters
  ownership: Arc<dyn TelemetrySink> passed to MoeLayer at construction

StageName enum
  variants: Gate, Dispatch, A2aSend, ExpertGemm, A2aRecv, Combine
  ownership: Copy

TelemetryReport struct
  fields:
    step:              u64
    expert_utils:      Vec<f32>     // len = num_experts; utilization per expert
    drop_rate:         f32          // fraction of tokens dropped this step
    routing_entropy:   f32          // H = -sum p_e log p_e over expert routing distribution
    stage_latencies_ns: HashMap<StageName, u64>
    aux_loss:          Option<f32>
    z_loss:            Option<f32>
  serialization: serde JSON + CSV (for bench output); all fields public
  ownership: value type; produced by TelemetrySink::flush aggregation; not stored long-term in runtime
Stream enum (moe-sched)
  variants:
    CpuThread { handle: Arc<ThreadPool> }
    CudaStream { ptr: *mut c_void, device: u32 }   // opaque CUDA stream handle; unsafe Send impl
  ownership: Arc-shared between overlap coordinator and individual stages
  concurrency:
    CpuThread: Send+Sync (ThreadPool is Arc-wrapped)
    CudaStream: Send via unsafe impl; single consumer per stream enforced by scheduler
  failure: CudaStream creation failure -> MoeError::DeviceNotFound

DoubleBufferState enum (moe-sched)
  variants: Idle, CommActive { buf_idx: u8 }, ComputeActive { buf_idx: u8 }, BothActive
  transitions:
    Idle -> CommActive(0) on a2a launch
    CommActive(i) -> BothActive on compute launch
    BothActive -> ComputeActive(i^1) on comm completion
    ComputeActive(i) -> Idle on compute completion
  ownership: owned by OverlapCoordinator; not Send (single scheduler thread)
  invariant: buf_idx in {0,1}; compute and comm never write same buffer index simultaneously
  failure: invalid state transition -> debug_assert! + MoeError::SchedulerStateError (in release: log + continue)
fn compute_capacity(capacity_factor: CapacityFactor, n_tokens: usize, k: u32, num_experts: u32) -> Capacity
  formula: ceil(capacity_factor.0 * (n_tokens * k as usize) as f32 / num_experts as f32)
  return type: Capacity(usize)
  invariants:
    - result >= 1 (minimum 1 token slot per expert regardless of factor)
    - if capacity_factor == inf (large float) -> capacity = n_tokens * k (no dropping; dense equivalent)
  failure: overflow usize on extreme inputs -> MoeError::CapacityOverflow guard before computation
  determinism: pure function; same inputs -> same output; no RNG

Capacity(usize) newtype
  ownership: Copy
  compatibility: repr(transparent); used in DispatchPlan and CombineBuffer size assertions
