3. Architectural Overview

3.1 System diagram

    annopt CLI : build | optimize | search | diagnose | tune | bench
        |                  |                 |              |
        v                  v                 v              v
    ann-build         ann-optimize       ann-search     RecallHarness
    HnswBuilder       GraphDiagnostics   greedy_search  (recall@k vs
    VamanaBuilder ->  occlusion_prune    beam_search     exact KNN)
    select_neighbors  degree_rebalance   SearchContext
    robust_prune      connect_components VisitedSet/heaps
        |             reverse_edge_repair    |
        |  builds         CostModel/Autotuner|  reads
        v                 ^   |              v
    ann-graph : Graph / Layer / AdjacencyList / NeighborList / CsrGraph / EntryPoint
        |  vectors + distances                 |  persist / mmap / PQ
        v                                       v
    ann-core : VectorStore · Metric · SIMD DistanceKernel · DistanceCounter
                                               ann-store : on-disk graph · mmap · ProductQuantizer · DeleteSet
 TRUST BOUNDARY ........ untrusted: vector data (dim/NaN/Inf), query vectors, build params
                         (adversarial m/R/L/alpha/ef). Validated/clamped at ann-cli + ann-core/ann-build edges.

                         immutable CsrGraph = Send+Sync, N concurrent readers (search), zero locks.

  • Data flow: vectors → ann-build (mutable Graph) → ann-optimize (passes over Graph) → freeze to CsrGraph → ann-search (read-only) / ann-store (persist). RecallHarness scores every stage against exact KNN.
  • &mut direction: flows downward through build/optimize only; search and persistence take & (shared). The freeze Graph → CsrGraph is the one-way gate between writer-world and reader-world.

3.2 Per-box responsibilities

ann-core — substrate. Owns VectorStore (row-major Vec<f32>, dim fixed at construction), VectorId(u32), Metric{L2,InnerProduct,Cosine}, Distance(f32), the scalar+SIMD DistanceKernel trait, DistanceCounter, DataType (f32 primary; f16/i8 for compression). In: raw vector data + Metric. Out: O(1) slice access &[f32] per VectorId, distance scalars. Invariant: every distance respects "smaller = closer" — IP/Cosine stored as negated/1−sim so all heaps order ascending = nearest first; every queried slice's dim equals store dim. Every later phase computes distances only through this layer, so DistanceCounter is the single cost ground truth (Phase 11 CostModel, Phase 13 gates). std.

ann-graph — central graph store, two forms. Mutable build form: AdjacencyList (Vec<NeighborList> indexed by VectorId), NeighborList (SmallVec ids+dists, sorted asc, capped at R), Layer, Graph{layers,entry_point,max_degree,metric,kind}, kind ∈ GraphKind{Hnsw{m,m_max0,ef_construction,ml}, Vamana{r,alpha,l}}. Immutable optimized form: CsrGraph{offsets,edges,entry_point}. In: edges from builders/optimizer. Out: neighbor iteration; (de)serialization. Invariant: NeighborList stays sorted+capped (len ≤ M_max0/R); layers[0] holds all nodes (HNSW); CsrGraph is frozen, never mutated. Phases 2–10 mutate Graph; Phase 5+ search the CsrGraph. std.

ann-build — construction. Owns HnswBuilder, VamanaBuilder, select_neighbors_heuristic (Algorithm 4: keep e iff d(e,q) < d(e,r) ∀ selected r; keep_pruned backfills to M), robust_prune (pop closest p*, add p→p*, drop v where alpha·d(p*,v) ≤ d(p,v), until |out|==R), level assignment (L ~ ⌊−ln(U)·ml⌋, ml=1/ln M), medoid computation, BuildParams{m,m_max0,ef_construction,alpha,r,l,seed}. In: VectorStore + BuildParams. Out: a mutable Graph. Invariant: out-degree never exceeds M_max/R after pruning; bidirectional links consistent; seed makes builds deterministic (differential testing vs hnswlib/DiskANN). Phases 3–4 (HNSW), Phase 6 (Vamana two-pass alpha=1 then 1.2–1.4); Phase 10 reuses single-node insert. Depends on ann-core, ann-graph.

ann-optimize — project center. Owns GraphDiagnostics, PruneStrategy{RobustPrune{alpha}, HeuristicSelect{keep_pruned}, RelativeNeighborhood}, pruning passes occlusion_prune/degree_rebalance/reverse_edge_repair, repair connect_components/nsg_spanning_repair/reselect_entry_point, CostModel, Autotuner (bisection over ef + grid over alpha/R/L → Pareto frontier), RecallTarget, TuneResult. In: a built Graph + VectorStore + diagnostic query sample. Out: an optimized Graph + tuned SearchParams. Invariant — the OPTIMIZER GUARANTEE: passes only improve-or-preserve recall@k at fixed ef on the diagnostic sample (no silent regression); degree never exceeds R; every node remains reachable from entry_point after connect_components. Phases 7–9 (diagnose/prune/repair), Phase 11 (cost/tune). Depends on ann-core, ann-graph, ann-search — it calls search to measure what it optimizes.

ann-search — query engine. Owns greedy_search(&Graph, q, ep, ef, ctx), beam_search(&CsrGraph, q, params, ctx), SearchContext{VisitedSet, candidate heap, result heap}, SearchParams{k,ef,beam_width}, RecallHarness, filtered+batch search. Algorithm: working list W size ef seeded with EP; expand closest-unexpanded, push unvisited neighbors, retain best ef; stop when closest-unexpanded farther than worst in W; return top-k. In: &Graph/&CsrGraph (shared) + query slice + SearchParams. Out: Vec<SearchResult>. Invariant: VisitedSet is a versioned bitset reset in O(1) per query; readers never mutate the graph (& only → safe N-way parallel search). Phase 5 builds this; ann-optimize and RecallHarness call it. Depends on ann-core, ann-graph.

RecallHarness — ground-truth scorer (in ann-search). Owns ground_truth: Vec<Vec<VectorId>> = exact brute-force KNN. In: VectorStore + held-out/self-query sample S + k. Out: estimated recall@k, mean distance-computations, expected-hops proxy (path length to convergence). Invariant: ground truth is computed by exact scan (no approximation), so it is the unbiased reference; recall = |result ∩ truth| / k. Phase 0 introduces it as the baseline; Phases 5/7/11/13 score against it; it is the arbiter for both the optimizer guarantee and the Phase 13 regression gates.

ann-store — persistence + compression. Owns the on-disk CsrGraph format, mmap_graph loader, ProductQuantizer{m_subspaces,ksub,codebooks} (asymmetric distance), Tombstone/DeleteSet{BitVec}, DiskANN-style beam-search-with-rerank. In: a frozen CsrGraph + VectorStore + path. Out: on-disk artifact; MappedGraph (zero-copy). Invariant: on-disk format is version-tagged + checksummed; mmap_graph is the sole file→memory ingress (trust-boundary chokepoint); deletes are logical (DeleteSet) until consolidation. Phase 12 builds it; Phase 10 consumes DeleteSet for tombstone/lazy-relink. Depends on ann-core, ann-graph.

annopt CLI — operator surface, the annopt binary. Subcommands map 1:1 to crates: build→ann-build, optimize/tune→ann-optimize, search→ann-search, diagnose→GraphDiagnostics, bench→RecallHarness+CostModel. In: CLI args + on-disk vectors/graph. Out: graph artifacts, diagnostic reports, recall/latency tables, the Pareto frontier. Invariant: every adversarial arg (m, R, L, alpha, ef, dim) is validated/clamped at this edge before reaching builders; the CLI orchestrates only — no algorithm logic lives here. Exercised end-to-end in the Phase 0 smoke test and Phase 13 conformance benchmarks. Depends on all crates. std.

8. Domain Model — Vectors, Metrics, and the Navigable Graph

The heart of the spec. Defines the four nouns the whole system manipulates: vectors, metrics/distances, the navigable graph (HNSW layers + Vamana flat), and the diagnostics/optimizer view over that graph. Every later phase (## 12–## 25) speaks in these terms.

8.1 Vector + Metric Model

VectorStore — ann-core. Row-major, contiguous, single allocation.

pub struct VectorId(pub u32);             // dense, 0..len; index into store + adjacency
pub struct VectorStore { dim: usize, data: Vec<f32>, len: u32 } // data.len() == dim*len
Fact Value / rule
Layout row i = data[i*dim .. (i+1)*dim]; slice fetch O(1), cache-line-aligned base
VectorId range 0 ..= len-1; VectorId(v) >= len ⇒ OutOfBounds
Alignment base ptr 64-byte aligned (AVX-512); dim need not be lane-multiple — kernels tail-handle
Mutability append-only at build; immutable + Sync during search (multi-reader, lock-free)
DataType f32 primary (search hot path); f16 storage-halving; i8 scalar-quant for on-disk PQ path only

Metric + Distance + convention. All ordering is "smaller = closer, nearest-first" everywhere — heaps, NeighborList, pruning. IP/Cosine are converted to a distance so the invariant holds globally.

pub enum Metric { L2, InnerProduct, Cosine }
pub struct Distance(pub f32);   // monotone in true distance; comparison-only for IP/Cosine
Metric Stored Distance Note
L2 ‖a−b‖² (squared, no sqrt) sqrt unneeded — monotone; saves 1 op/comp
InnerProduct −⟨a,b⟩ (negated) larger sim ⇒ smaller Distance; not a true metric (no triangle ineq)
Cosine −⟨â,b̂⟩, vectors L2-normalized at insert reduces to IP on unit vectors

DistanceKernel contract — ann-core:

pub trait DistanceKernel { fn distance(&self, a: &[f32], b: &[f32]) -> Distance; }
  • Pre: a.len() == b.len() == dim; both finite (NaN/Inf rejected at ingest, never reach kernel).
  • Determinism: fixed (a,b,Metric,dim) ⇒ identical result across SIMD/scalar within tolerance; differential tests gate |simd − scalar| ≤ 1e-5·‖·‖.
  • Side effect: each call bumps DistanceCounter (AtomicU64) — the per-query budget unit the CostModel/Autotuner optimize against.

8.2 The Navigable Graph as a Formal Object

G = (V, E), directed. V = {VectorId(0..len)}. E ⊆ V×V. out(v) = adjacency of v; invariant |out(v)| ≤ R (R = max_degree, = M_max0 on HNSW layer 0). Edge (u→v) caches Distance(u,v); NeighborList sorted ascending.

pub struct NeighborList { ids: SmallVec<[VectorId; R]>, dists: SmallVec<[Distance; R]> } // sorted asc, capped R
pub struct AdjacencyList { neighbors: Vec<NeighborList> }   // index = VectorId; mutable build form
pub struct Layer { adjacency: AdjacencyList, level: u8 }

HNSW = stack of Layers. layers[0] = base = all nodes; layers[ℓ] ⊂ layers[ℓ−1] (nested). Level assignment per insert:

L = floor(-ln(U) * ml),   U ~ Uniform(0,1],   ml = 1 / ln(M)

Geometric-tail: P(level ≥ ℓ) = exp(−ℓ/ml); expected layers ≈ ln(len)/ln(M). Entry at entry_point = highest node. Degree caps: M (build target), M_max (ℓ≥1), M_max0 = 2M (ℓ=0).

Vamana/DiskANN = single flat graph (no layers), entry = medoid (argmin Σdist, sampled). Uniform cap R; build list L; occlusion relaxation alpha ∈ [1.2,1.4].

pub enum GraphKind { Hnsw{m,m_max0,ef_construction,ml}, Vamana{r,alpha,l} }
pub struct Graph { layers: Vec<Layer>, entry_point: VectorId, max_degree: u32, metric: Metric, kind: GraphKind }

AdjacencyList ↔ CsrGraph duality. Build = mutable AdjacencyList (per-node SmallVec, push/prune cheap). Optimize finalizes → immutable CSR: cache-dense, zero per-node alloc, mmap-friendly.

pub struct CsrGraph { offsets: Vec<u32>, edges: Vec<VectorId>, entry_point: VectorId }
// out(v) = edges[offsets[v] .. offsets[v+1]];  offsets.len()==len+1;  edges.len()==Σ|out(v)|
AdjacencyList (build)              CsrGraph (search/disk)
 node0: [3,7,1]                    offsets: [0,3,5,8,...]
 node1: [0,4]            ── CSR ─▶ edges:   [3,7,1, 0,4, ...]
 node2: [5,2,6]                    entry_point: medoid/top
 (alloc per node, mutable)         (2 flat Vecs, immutable, Sync)

8.3 Construction Algorithms (pseudo-code)

HNSW insert (HnswBuilder, Phase 3–4):

insert(q):
  L = floor(-ln(rand()) * ml);  ep = entry_point
  for ℓ in top_level .. L+1:          # descend, greedy ef=1
     ep = search_layer(q, {ep}, ef=1, ℓ).nearest
  for ℓ in min(L,top_level) .. 0:     # connect on each owned layer
     W = search_layer(q, {ep}, ef_construction, ℓ)
     N = select_neighbors_heuristic(W, M, extend=true, keep_pruned)
     add_bidirectional(q, N, ℓ)
     for r in N: if |out(r,ℓ)| > M_max(ℓ): out(r,ℓ)=select_neighbors_heuristic(out(r,ℓ), M_max(ℓ), ..)
     ep = W.nearest
  if L > top_level: top_level=L; entry_point=q

search_layer (inner best-first, also the search-engine kernel):

search_layer(q, seeds, ef, ℓ):
  visited=seeds;  C=min-heap(seeds by d(·,q));  W=max-heap(seeds, cap ef)
  while C nonempty:
     c = C.pop_nearest()
     if d(c,q) > W.worst: break               # closest unexpanded ≥ worst kept ⇒ stop
     for e in out(c,ℓ):
        if e in visited: continue
        visited.add(e)
        if d(e,q) < W.worst or |W|<ef: C.push(e); W.push(e); if |W|>ef: W.pop_worst()
  return W                                     # ef nearest

select-neighbors heuristic (Algorithm 4) — diversity, not naive nearest-M:

select_neighbors_heuristic(cands_sorted_by_d_to_q, M, extend, keep_pruned):
  R=[]; discarded=[]
  for e in cands:                       # nearest-first
     if |R|==M: break
     if forall r in R: d(e,q) < d(e,r): R.push(e)   # keep iff closer to q than to any kept r
     else: discarded.push(e)
  if keep_pruned: while |R|<M and discarded: R.push(discarded.pop_nearest())  # backfill
  return R

Vamana robust_prune + two-pass build (VamanaBuilder, Phase 6):

robust_prune(p, V, alpha, R, store):     # V = visited pool from greedy_search(p)
  V.remove(p); out(p)=[]
  while V nonempty:
     p* = argmin_{v in V} d(p,v);  out(p).push(p*)
     if |out(p)| == R: break
     V.retain(|v| alpha * d(p*,v) > d(p,v))    # occlude v if p* dominates (relaxed by alpha≥1)
  return out(p)

build_vamana:
  init random R-regular graph; medoid = sampled_argmin Σ d
  for alpha in [1.0, alpha_final]:           # pass1 tight; pass2 alpha∈[1.2,1.4] long-range
     for p in random_perm(V):
        V = greedy_search(medoid, p, L).visited
        out(p) = robust_prune(p, V, alpha, R)
        for j in out(p): add j→p; if |out(j)|>R: out(j)=robust_prune(j, out(j)∪{p}, alpha, R)

8.4 Search Algorithm (pseudo-code)

pub struct SearchParams { k: u32, ef: u32, beam_width: u32 }   // invariant ef >= k
pub struct SearchContext { visited: VisitedSet, candidates: BinaryHeap<Reverse<(Distance,VectorId)>>, results: BinaryHeap<(Distance,VectorId)> }

beam_search(CsrGraph) = search_layer over flat CSR with ef/beam_width; greedy_search(Graph) walks HNSW layers top→0 (ef=1 above, ef=ef_search at layer 0), returns top-k. VisitedSet = versioned bitset: per-query epoch:u32; "visited" iff stamp[id]==epoch; reset = epoch+=1 ⇒ O(1) across queries (no clear). Stop: closest unexpanded farther than worst-of-ef ⇒ monotone search path terminates.

8.5 Optimizer Model (ann-optimize, project center)

pub struct GraphDiagnostics {
  mean_out_degree: f32, out_degree_hist: [u32;64], min_in_degree: u32, orphan_count: u32,
  connected_components: u32, unreachable_from_ep: u32, navigability_score: f32, estimated_recall_at_10: f32 }
Field Meaning / red flag
orphan_count in-degree 0 → unreachable; must be 0 after repair
unreachable_from_ep BFS from EP misses them → recall ceiling < 1
connected_components >1 ⇒ disconnected; connect_components reduces to 1
navigability_score sampled expected-hops proxy (lower = more navigable)
estimated_recall_at_10 sampled queries vs exact KNN (RecallHarness)

Passes (Phase 8–9): occlusion_prune(g,strat,store) (RobustPrune/RNG/heuristic edge thinning); degree_rebalance(g,R) (cap to R via heuristic re-select); reverse_edge_repair(g,min_in_degree) (add reverse edges to lift low/zero in-degree nodes); connect_components(g,store) (link unreachable subgraphs to EP component via nearest cross-edges); reselect_entry_point(g,store)→VectorId (medoid/centrality).

Optimizer guarantee (LOCKED invariant): every pass MUST (1) not regress estimated_recall_at_k at fixed ef on the diagnostic sample, (2) keep |out(v)| ≤ R ∀v, (3) leave every node reachable from entry_point after connect_components. Violation ⇒ pass rejected, graph rolled back.

8.6 Worked Example — 6 nodes in 2-D

Points: A(0,0) B(1,0) C(0,1) D(5,5) E(6,5) F(5,6). Clusters {A,B,C} {D,E,F}. L2² from B(1,0), M=2:

cand sorted by d(·,B):  A(1)  C(2)  D(41)  E(50)  F(52)
Selection out(B) Why
naive nearest-M {A, C} both intra-cluster → B reaches {D,E,F} only via A/C; long path
heuristic (Alg.4) {A, D} A kept (nearest); C occluded (d(C,B)=2, not closer to B than to A); D kept (d(D,B)<d(D,A)) → long-range edge

Heuristic trades a redundant short edge (C, reachable via A) for a long-range edge to the far cluster → navigable across clusters at degree 2.

Search query q(0.5,0.5), EP=A, ef=2, k=1. out: A→{B,C}, B→{A,D}, C→{A,F}:

step  expand  push(unvisited)   W(best-2)         dist_comps
 0    seed A                    [A:0.5]            1
 1    A       B(0.5),C(0.5)     [A:0.5,B:0.5]      3
 2    B       D(40.5)           [A:0.5,B:0.5]      4   D worse than worst
 3    C       F(60.5)           [A:0.5,B:0.5]      5
stop: closest unexpanded D(40.5) > W.worst(0.5)
result top-1 = A (true NN of q; A,B tie) ; recall@1 = 1.0 ; dist_comps ≈ 5

8.7 Malformed / Adversarial Inputs → Error

Input Detected at Error
zero vectors (len==0) build EmptyStore — no medoid, no EP
dim mismatch (query.len ≠ dim) search/insert DimensionMismatch{expected,got}
NaN/Inf in a vector ingest validation NonFiniteValue{id,component} — NaN breaks heap ordering; rejected pre-kernel
R == 0 BuildParams validate InvalidDegree — no edges, graph trivially disconnected
ef < k SearchParams validate EfBelowK{ef,k} — cannot return k from ef-list
disconnected (components>1) diagnose/optimize Disconnected{components} → triggers connect_components; surfaced if repair off
self-loop v→v build/insert assert SelfLoop{id} — wastes a degree slot, d=0 trap; forbidden invariant

8.8 HNSW Descend-then-Search (sequence)

Query q,k,ef            greedy_search        search_layer        Store/Kernel
   |  search(q,k,ef) ------> |                    |                   |
   |                         | ep=entry_point     |                   |
   |        for ℓ=top..1     |-- search_layer(ef=1,ℓ) -->|            |
   |                         |                    |-- d(c,q) -------->| (++DistanceCounter)
   |                         |<-- nearest ep -----|                   |
   |        ℓ=0              |-- search_layer(ef=ef_search,0) -->|    |
   |                         |                    |-- expand/visit/heap
   |                         |<-- W (ef nearest) -|                   |
   |<-- top-k SearchResult --|                    |                   |

Descend cheaply (ef=1) through sparse upper layers to land near q, then spend the ef budget only on the dense base layer — why mean_dist_comps ≈ ef · mean_out_degree · (1 + hop_factor) stays small relative to recall.
