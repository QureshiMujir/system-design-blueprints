Threat Model

Scope: adversarial + accidental failure across the spine's three boundaries. Subject = the ANN index/optimizer, not auth/transport (out of scope; assume caller-side ACLs). Adversary classes: (A) untrusted vector/query supplier feeding the ann-index API; (B) concurrent caller mix (many readers || one writer); (C) operator/tooling driving annox; (D) attacker with read/write access to the on-disk IndexFile or its directory. Asset = index integrity (recall correctness, no corruption, no panics, bounded resource use) + availability of the search hot path.

Rules: every value crossing a boundary is validated/sanitized exactly once at the named point; downstream crates (ann-graph/search/optimize/quantize) assume validated inputs and may use checked-only-in-debug indexing on the hot path. The in-memory graph — not the mmap file — is authoritative; open() reconstructs and re-validates.

26.2 Threat catalog

Each: vector → mitigation → detection → telemetry → recovery. T-IDs referenced by Failure Modes / Operational Readiness.

T1 — Algorithmic-complexity DoS (parameter blow-up)

Vector: caller sets ef_search, M, max_degree, ef_construction, dim, or order huge → O(ef * degree) search / O(N*efC) build explodes; one query starves all readers. Mitigation: reject at API against spine hard caps — dim<=4096, max_degree<=512, ef_search<=4096, order<=2^31; clamp beam_width<=ef_search; per-search wall-clock budget; visited-set cap = order. Detection: bounds check before allocation; counter of clamped/rejected calls. Telemetry: rejected_param_total{param}, search_latency p99, frontier_pop_count histogram. Recovery: return Err(ParamOutOfRange{param,max}); no partial state. Fixture: ef_search=u32::MAX, dim=1<<20.

T2 — Adversarial graph topology (slow-search inputs)

Vector: crafted/clustered vectors → degenerate graph (long paths, hub nodes) inflating frontier pops far beyond recall target; or insert order chosen to maximize degree churn. Mitigation: DegreeBound caps out-degree at M/M0; RobustPrune(alpha) + RNG occlusion keep diameter low; ConnectivityRepair bounds path length; per-search visited cap aborts pathological traversals. Detection: pop_count > k_factor * ef_search anomaly; degree-distribution skew at consolidate. Telemetry: avg/p99 hops-to-converge, max degree observed, hub_node_count. Recovery: LayoutReorder + EdgePrune pass; abort offending query with budget Err, index unharmed.

T3 — Malformed / out-of-spec input (NaN, Inf, dim mismatch, subnormals)

Vector: NaN/Inf vector poisons distances (NaN compares false → breaks heap ordering, ranks everywhere/nowhere); wrong dim reads OOB; -0.0/subnormals skew metrics; zero-norm vector under Cosine → divide-by-zero. Mitigation: validate(v): len==dim, all finite (reject NaN/Inf), Cosine norm>epsilon (else Err ZeroNorm); normalize on ingest for Cosine. Detection: is_finite scan (SIMD) per inserted/queried vector at the API. Telemetry: rejected_nonfinite_total, zero_norm_total, dim_mismatch_total. Recovery: Err(InvalidVector{reason}); never enters graph/storage. Fixture: f32::NAN, f32::INFINITY, all-zero under Cosine, dim=dim-1/dim+1.

T4 — Memory exhaustion (OOM via allocation)

Vector: build of huge N, oversized PQ codebooks (m_subksub_dim), or many concurrent SearchStates each holding visited+heaps → unbounded heap. Mitigation: pre-flight memory estimate (N*(M24 + dim*4) ≈ spine model) checked vs a configured budget before build; SearchState pooled + reused (zero steady-state alloc per spine); PQ params bounded (k<=256, m_sub<=dim). Detection: estimator vs budget gate; allocator high-water counter. Telemetry: rss_bytes, searchstate_pool_inflight, build_peak_bytes. Recovery: Err(BudgetExceeded{need,have}) before allocating; no torn build. Fixture: order near 2^31, dim 4096, concurrency=1024.

T5 — Disk / inode exhaustion (DiskANN sectors, snapshots)

Vector: repeated save()/snapshot or large IndexFile + DiskANN sector layout fills volume mid-write → truncated file. Mitigation: write to temp + fsync + atomic rename (no in-place mutation of live file); snapshot retention cap; estimate file size before write; bounded sector count = order. Detection: pre-write free-space check; short-write/ENOSPC propagated as Err. Telemetry: disk_free_bytes, snapshot_count, last_save_bytes. Recovery: failed save leaves prior IndexFile intact (rename is atomic); in-memory graph still authoritative. Fixture: ENOSPC injection on temp write.

T6 — Panic on adversarial input (availability)

Vector: any panic (index OOB, unwrap on None, integer overflow on offsets/ids, slice misalign) aborts the process → one bad request kills all readers. Mitigation: API surface is Result-only (no unwrap/expect/panic! in ann-index public paths); checked arithmetic for offsets/CSR indices/VectorId↔NodeId; debug-mode bounds asserts, release-mode pre-validated invariants. catch_unwind firewall at the request boundary as defense-in-depth. Detection: continuous fuzzing (cargo-fuzz) of build/search/insert/delete + parser of IndexFile bytes; #[deny] on arithmetic overflow in CI. Telemetry: panic_caught_total (must stay 0), fuzz corpus crash count. Recovery: catch_unwind → Err(Internal), request fails, server lives. Fixture: fuzz targets per public fn; corpus seeded with T3/T7 cases.

T7 — Persistence / state corruption (untrusted IndexFile bytes)

Vector: attacker or bit-rot supplies IndexFile with bogus offsets, out-of-range NodeIds, degree>cap, cyclic/garbage CSR, wrong dim → open() builds a graph that reads OOB or loops forever. Mitigation: file header = magic + format-version + dim + order + metric + per-section CRC32C; open() validates header, bounds-checks every CSR offset/neighbor id (< order), enforces degree<=max_degree, rejects version mismatch; treat mmap region as untrusted (no transmute of unvalidated structs). Detection: CRC mismatch, offset/id range check, monotonic-offset check on CSR. Telemetry: open_crc_fail_total, open_reject_total{reason}, format_version. Recovery: refuse to open (Err(CorruptIndex{section})); fall back to last good snapshot; rebuild from source vectors as last resort. Fixture: flip CRC byte, offset past neighbors.len(), NodeId==order.

T8 — Torn writes / partial persistence (crash mid-mutation)

Vector: crash during save()/consolidate()/sector update leaves IndexFile half-written or tombstones applied without neighbor-list rewrite → inconsistent on next open(). Mitigation: atomic publish (temp+fsync+rename); never mutate live file in place; consolidate() stages new neighbor lists then swaps; tombstones are append-only until consolidation; recovery log / generation counter in header. Detection: open() generation/CRC + consistency pass (entry_point valid, no neighbor → deleted node). Telemetry: recovery_invoked_total, dangling_neighbor_total at open, generation. Recovery: roll forward to last complete generation; re-run consolidate idempotently. Fixture: kill -9 mid-consolidate, mid-save.

T9 — Concurrency hazards (reader/writer races)

Vector: writer mutates adjacency while readers traverse → data race / use-after-free of freed Neighbors; lost update on bidirectional link + prune; ABA on node slot reuse after delete. Mitigation (spine concurrency model): searches read-only over an immutable/epoch-protected graph; single writer with fine-grained per-node locks; epoch-based reclamation defers freeing of replaced adjacency until no reader holds the epoch; lock ordering by NodeId to prevent deadlock; CSR frozen form immutable. Detection: TSan/loom/Miri in CI on mutation primitives; assert no reader observes a half-linked node. Telemetry: epoch_lag, lock_wait_p99, reclamation_backlog. Recovery: writer backpressure if reclamation backlog grows; readers never block writer correctness. Fixture: loom model of insert||search, delete-then-insert ABA, concurrent prune of shared neighbor.

T10 — Connectivity / unreachability attack (silent recall loss)

Vector: adversarial delete/insert/prune sequence orphans live nodes from the entry point → searches silently miss them (recall drops, no error); approximation (PQ/Bloom in repair) wrongly declares a node reachable. Mitigation: connectivity invariant — every live node reachable from entry_point; ConnectivityRepair runs reachability BFS and reconnects orphans after deletes/prunes; approximations may add false positives in candidacy but must NEVER make a live node permanently unreachable (exact reachability check governs repair). Detection: periodic/post-consolidate reachability BFS; recall canary vs brute-force oracle on a held-out query set. Telemetry: orphan_count, unreachable_live_total (alert if >0), canary_recall@10. Recovery: ConnectivityRepair pass; if canary recall < target, EdgePrune/Diversify rerun or rebuild. Fixture: delete entry-point neighborhood; prune to disconnect a cluster.

T11 — Quantization / plan poisoning (recall + cost integrity)

Vector: stale or adversarially trained PQ/SQ codebooks (drifted distribution) make ADC distances wrong → search returns far vectors as near (poisoned ranking); ParamTune fed manipulated gt/queries picks SearchParams that look good but underperform in prod. Mitigation: PqCode/codebook versioned + bound to index generation (reject mismatched codebook); always full-precision rerank of top candidates (ADC only narrows, never finalizes); tune_for_recall uses brute_force_knn-derived ground truth, not caller-supplied rankings; Pareto points recorded with the gt hash they were measured against. Detection: codebook_version mismatch; rerank disagreement rate (ADC top-k vs reranked top-k) anomaly; gt hash check. Telemetry: rerank_overturn_rate, codebook_version, tune_gt_hash. Recovery: re-train PQ (pq_train) on current data; re-tune; reject mismatched codebook at open(). Fixture: codebook from a different distribution; gt with injected wrong neighbors.

T12 — Supply-chain risk (dependencies)

Vector: malicious/vulnerable transitive crate in the SIMD/mmap/CLI deps; yanked or typosquatted dependency. Mitigation: minimal dependency surface (core no_std+alloc); cargo-deny (deny.toml) bans by advisory (RUSTSEC), enforces license allow-list, denies duplicate/unknown sources, pins git deps; Cargo.lock committed; SIMD via std::arch intrinsics (no FFI). Detection: cargo deny check in CI (advisories+bans+licenses+sources); cargo-audit on schedule. Telemetry: CI deny/audit pass/fail, dependency count, MSRV (1.78) drift check. Recovery: pin/replace/remove offending crate; vendored fallback for critical path. Fixture: deny.toml with a known-bad advisory id (CI must fail).

T13 — Operator / configuration mistakes

Vector: wrong Metric vs how vectors were embedded (L2 vs Cosine) → garbage recall; mismatched build vs query dim; overwriting a good index via annox build; running optimize passes with bad alpha (<1) degrading graph; deleting wrong snapshot. Mitigation: Metric + dim + format-version persisted in IndexFile header and checked at every search/insert; annox refuses build over an existing file without --force; alpha validated alpha>=1 (RobustPrune); destructive CLI ops require confirmation; PassReport surfaces recall_before/after so a harmful pass is visible. Detection: header mismatch Err; PassReport recall_after < recall_before flag; pre-op dry-run/inspect. Telemetry: config_mismatch_total, pass recall delta, destructive_op_total. Recovery: refuse mismatched search; revert pass (graph snapshot before optimize) / restore snapshot. Fixture: build L2 then query Cosine; alpha=0.5; build over existing file.

26.4 Residual risks & assumptions

  • Trusts the OS for mmap page integrity and fsync durability; bit-rot beyond CRC granularity (within a CRC'd section) is undetectable until re-validation.
  • Single-node model (spine non-goal: no sharding) → no defense against a host-level compromise; assumes caller authenticates/authorizes (auth out of scope).
  • Timing side-channels on distance/recall not addressed (not a confidentiality target).
  • Approximate recall is inherent: ANN may miss true neighbors even with no adversary; only the connectivity invariant (T10) bounds worst-case silent loss, not statistical recall — covered by canary gates, not a hard guarantee.
