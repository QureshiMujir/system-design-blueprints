4. System Constraints

Hard, measured envelope for the annopt binary / ann-* crates. Single-node, in-process Rust library; all budgets are per-machine, per-core where stated. Reference workload unless noted: SIFT1M analog (N=1,000,000, dim=128, f32), single x86-64 host, AVX2 baseline, post-optimize CsrGraph, HNSW m=16/m_max0=32/ef_construction=200. Targets are Phase 13 acceptance/regression gates, not aspirations. NO network/RPC, NUMA, sharding, replication, or distributed budget (§3 non-goals); no GPU.

4.2 Hard safety / DoS caps (enforced once at the API trust boundary)

Cap Limit Failure / rationale
max dim 4096 bounds kernel temp + alignment → Err(DimTooLarge)
max out-degree (R / m_max0) 512 NeighborList SmallVec spill bound; CSR u32 offsets safe
max ef 4096 bounds candidate/result heaps + VisitedSet; caps per-query work
max HNSW layers 16 ml=1/ln(M), L~floor(-ln(U)·ml); clamp tail
max graph order 2^31 VectorId(u32) domain; 1 bit reserved
NaN / Inf vector rejected breaks Distance ordering / heap invariants → Err(NonFinite)
dim mismatch rejected q.len() ≠ dim → Err(DimMismatch)

All checked once at ingress (build/insert/search); hot path (greedy_search/beam_search) assumes validated inputs, no re-checks.

4.3 CPU / cache / SIMD assumptions

  • ISA: x86-64 AVX2+FMA primary; AArch64 NEON secondary; scalar fallback mandatory + differentially tested (Phase 1). Runtime feature dispatch (DistanceKernel); AVX-512 detected, not assumed.
  • Cache: 64 B line; dim-128 f32 vector = 512 B = 8 lines, 32-byte aligned. CsrGraph adjacency contiguous (edges[offsets[v]..offsets[v+1]]) → prefetch-friendly; R=32 neighbor list = 128 B = 2 lines, co-resident.
  • Search is memory-latency bound, not FLOP bound (pointer-chasing descent + beam); tail = cache + branch misses (no allocator, no GC) → p99 < 1 ms achievable and gated.
  • VisitedSet = versioned bitset, O(1) reset/query, zero per-query alloc.
  • Float: IEEE-754 binary32; SIMD reductions not bit-identical to scalar (reassociation) → differential test asserts |Δ| ≤ rel 1e-5, ordering-stable.

4.4 Concurrency envelope

  • Readers: unbounded concurrent searches over immutable CsrGraph; each owns its SearchContext → lock-free, near-linear scaling (≥7× on 8 cores).
  • Writer: single logical writer; insert into optimized graph uses per-node neighbor locks; delete = lazy Tombstone/DeleteSet (no structural lock); consolidation runs under live readers (epoch-deferred frees).
  • Build: parallel HnswBuilder/VamanaBuilder across cores; invariant = same connectivity guarantees as serial build, data-race-free (Rust Send/Sync).

Back-of-Envelope Capacity Model

Six to twelve numbers derived step by step from §4 constraints. All formulas shown; all numbers at the reference workload (N=1,000,000, dim=128, R=32, m=16, m_max0=32, ef=64) unless stated.

1. Raw vector RAM

vectors_bytes = N × dim × 4 B
             = 1,000,000 × 128 × 4
             = 512,000,000 B  ≈  488 MB

2. CSR edge bytes (CsrGraph)

edges_bytes   = N × R × 4 B            (VectorId u32 per edge)
             = 1,000,000 × 32 × 4
             = 128,000,000 B  ≈  122 MB

offsets_bytes = (N+1) × 4 B  ≈  4 MB   (u32 prefix-sum array)

total_csr     ≈  126 MB

3. Total in-memory index (full-precision HNSW)

total_mem = vectors_bytes + edges_bytes + offsets_bytes + upper_layers
          ≈ 488 + 122 + 4 + ~10      (upper layers sparse: ~2% nodes × dim×4 each)
          ≈ 624 MB   ≈  1.22 × raw-vector-bytes   (within §4 ceiling of 1.3×)

4. PQ compression (DiskANN path)

pq_code_bytes = N × m_subspaces × 1 B  (1 byte/subspace, ksub=256)
             = 1,000,000 × 16 × 1
             = 16,000,000 B  ≈  15 MB

codebook_bytes = m_subspaces × ksub × (dim/m_subspaces) × 4 B
              = 16 × 256 × 8 × 4
              = 131,072 B  ≈  128 KB

pq_total_vs_raw = 16 MB / 488 MB  ≈  3%   (≈ 32× compression on vectors alone)

5. Distance computations per query

CostModel: mean_dist_comps ≈ ef × mean_out_degree × (1 + hop_factor)

At ef=64, mean_out_degree=28 (typical HNSW M=16/M_max0=32 after pruning), hop_factor≈0.3:
mean_dist_comps ≈ 64 × 28 × 1.3  ≈  2,330   (within §4 ceiling of 2,500)

6. Build time estimate (HNSW SIFT1M)

per_insert_dist_comps ≈ ef_construction × M_max0 × hops_per_layer
                      ≈ 200 × 32 × 1.4  ≈  8,960  dist-comps/insert

total_build_comps = N × per_insert  ≈  8.96 × 10⁹

kernel_throughput: AVX2 f32 L2 dim=128  ≈  5 GFLOP/s
dist_comp_flops = 2 × dim = 256 FLOPs

dist_comps_per_second = 5×10⁹ / 256 ≈  19.5M dist-comps/s

build_time_s = 8.96×10⁹ / 19.5×10⁶ ≈  460 s  (≈ 7.7 min)
  — matches §4 target: ≥ 5,000 vec/s/core → 1M / 5000 = 200 s minimum; 460 s is
     a realistic single-thread estimate at ef_construction=200, R=32, dim=128.

7. Search QPS estimate

p50_us  ≈  mean_dist_comps × kernel_ns / 1000
        = 2,330 × (256 FLOP / 5×10⁹ FLOP·s⁻¹) × 10⁶ µs/s
        = 2,330 × 51 ns / 1000  ≈  119 µs

QPS_1core = 1 / p50_us × 10⁶  ≈  8,400 QPS   (§4 floor ≥ 2,000 ✓)
QPS_8core ≈ 8 × 8,400 × 0.875  ≈  58,800 QPS  (≥ 7× factor ✓)

8. VisitedSet memory

visited_bytes = ceil(N / 8)  =  125,000 B  ≈  122 KB
  — fits in L2/L3 cache even at N=1M; O(1) reset via generation counter avoids
    a 122 KB memset per query (saves ~10–30 µs at high QPS).

9. mmap cold-start budget

pages_on_search_path = ef × mean_out_degree  ≈  64 × 28 = 1,792 neighbor reads
each_neighbor_vector  = dim × 4 = 512 B  (one cache-line span: 8 × 64 B)
pages_faulted_cold ≈  1,792 × 1 page fault @ ~10 µs/fault  ≈  18 ms
  — but with MADV_RANDOM neighbors come from the hot working set after warm-up;
    warm steady-state p50 returns to ~119 µs, cold first-query up to ~20 ms.
    Phase 12 target: mmap open < 200 ms (§4 ✓).

10. Optimizer pass cost

occlusion_prune (per node): candidate pool V = R neighbors + 1-hop = R + R² ≈ 1,056 pairs
dist_comps_prune = N × R² ≈ 1M × 1024 ≈ 10⁹  dist-comps total

At 19.5M dist-comps/s: prune_time ≈ 10⁹ / 19.5×10⁶ ≈ 51 s
  — within §4 ceiling: < 30 s for the simpler passes (degree_rebalance < 1 s;
    occlusion_prune 30–60 s; acceptable); with rayon parallelism on 8 cores → ~7 s.

11. PQ LUT memory (search critical path)

distance_table_bytes = m_subspaces × ksub × 4 B
                     = 16 × 256 × 4 = 16,384 B  =  16 KB
  — fits in L1 cache (typically 32–64 KB); PQ beam-search becomes compute-bound
    (LUT lookups) rather than memory-latency-bound (random vector reads).

12. Consolidation cost

tombstone_trigger  = 0.2 × N = 200,000 deleted nodes
consolidation_work ≈ N × R  =  32M edge rewrites + N vector copies
at_memory_bandwidth = 32M × 4 B × 2 (read+write) / 50 GB·s⁻¹  ≈  5 s
  — §4 target: consolidation ≤ 2× build_cost/edge_touched ✓
    (build = 460 s / 32M edges ≈ 14 µs/edge; consolidation ≈ 5 s / 32M ≈ 0.16 µs/edge ✓)
