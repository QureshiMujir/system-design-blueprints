30. Mental Models & First Principles

  • MM1 — Determinism Is a Total Order, Not a Property You Test For. Compressed insight: replay determinism (I2) is only real if every scheduling decision is derivable from a single total order over (tick, shard, sequence); predicts that any "mostly deterministic" system will eventually diverge; the bug class you write without it: hidden nondeterminism from wall-clock or hash-map iteration order (§13.6, §16.6); applies in §13.
  • MM2 — A Shard Is a Trust Boundary, Not a Performance Optimization. Compressed insight: sharding (P10) exists to make cross-shard mutation structurally impossible, and the throughput gain is a side effect; predicts that any "just add a shared cache" request is a correctness regression, not a performance one; the bug class without it: silent cross-shard data races; applies in §13.
  • MM3 — A Queue's Capacity Is a Correctness Parameter. Compressed insight: bounded queues (P2, I4) are not a memory-tuning knob, they are what makes backpressure (P8) exist at all; predicts that "just make the queue bigger" masks a design bug instead of fixing it; the bug class without it: unbounded memory growth mistaken for a tuning problem; applies in §14.
  • MM4 — Logical Time and Wall-Clock Time Must Never Silently Merge. Compressed insight: P9 is violated the instant any code path reads Instant::now() on a path that affects a scheduling or fault decision; predicts intermittent, load-dependent replay divergence; the bug class without it: "it only happens under load" nondeterminism bugs; applies in §16.
  • MM5 — A WAL Entry Logged After Its Effect Is Not an Audit Trail. Compressed insight: I7/I8 exist because "log it eventually" is equivalent to "don't log it" for forensic purposes; predicts that any perf optimization reordering log-then-apply is a correctness regression; the bug class without it: unreconstructable incidents; applies in §18.
  • MM6 — Tail Latency Is a Fan-Out Problem, Not an Average Problem. Compressed insight (Dean & Barroso 2013): p99 latency is dominated by the slowest contributor across a fan-out, not the typical contributor; predicts that barrier synchronization (§19) will be bottlenecked by one straggler shard, not the average shard; the bug class without it: optimizing the average case while the p99 budget (§4) keeps failing; applies in §19.
  • MM7 — A Lease Without an Expiry Is a Lock Without a Timeout. Compressed insight: I10 only prevents split-brain if every lease has a bounded lifetime independent of the holder's cooperation; predicts that a crashed-but-not-detected worker will eventually hold a permanently-stale lease without expiry; the bug class without it: split-brain (FM-8); applies in §19.
  • MM8 — Observability Is Part of the System, Not a View Onto It. Compressed insight (P5): a metric or span that is missing is itself a failure mode (FM-11), not a documentation gap; predicts that "we'll add telemetry later" always ships an unobservable blind spot first; the bug class without it: production incidents with no forensic trail; applies in §21.

5. Required Reading

Books

  • Computer Networks — Tanenbaum & Wetherall (2010), ch. 5–6: routing and congestion-control fundamentals; applied in §15 and §17.
  • TCP/IP Illustrated, Volume 1 — Stevens (1994), ch. 17–21: packet lifecycle and TCP retransmission semantics; applied in §17.
  • Designing Data-Intensive Applications — Kleppmann (2017), ch. 8–9: distributed coordination and replication under partition; applied in §19.
  • Systems Performance — Gregg (2nd ed., 2020), ch. 6 and 10: CPU/scheduler flamegraph methodology; applied in §28.
  • The Linux Programming Interface — Kerrisk (2010), ch. 20 and 61: epoll, namespaces, and socket semantics; applied in §20.
  • Operating Systems: Three Easy Pieces — Arpaci-Dusseau & Arpaci-Dusseau (2018), ch. 4–7: scheduling and synchronization primitives; applied in §13.
  • Network Algorithmics — Varghese (2004), ch. 3–5: packet-processing architecture and hashed data structures; applied in §14.
  • High Performance Browser Networking — Grigorik (2013), ch. 2: latency and transport behavior under real networks; applied in §17.

Papers

  • "BBR: Congestion-Based Congestion Control" — Cardwell et al., 2016, ACM Queue: bandwidth/RTT-probing model → informs the transport-models pacing algorithm; applied in §17.
  • "Data Center TCP (DCTCP)" — Alizadeh et al., 2010, SIGCOMM: ECN-marked shallow-queue congestion signal → informs queue-discipline thresholds; applied in §14.
  • "The Tail at Scale" — Dean & Barroso, 2013, CACM: tail-latency amplification under fan-out → informs the p99 scheduling-budget derivation; applied in §28.
  • "MapReduce: Simplified Data Processing on Large Clusters" — Dean & Ghemawat, 2004, OSDI: worker-failure detection and re-execution → informs the orchestrator worker-lease design; applied in §19.
  • "Time, Clocks, and the Ordering of Events in a Distributed System" — Lamport, 1978, CACM: logical clocks → informs the virtual-clock monotonic-tick guarantee; applied in §13.
  • "Hashed and Hierarchical Timing Wheels" — Varghese & Lauck, 1987, SOSP: O(1) timer scheduling → informs the event-scheduler timing-wheel core; applied in §13.
  • "The Design and Implementation of a Next-Generation Network Simulator (ns-3)" — Henderson et al., ns-3 project documentation, 2008: event-scheduler and packet-abstraction layering → informs packet-engine and event-runtime separation; applied in §14.
  • "The Datacenter as a Computer" — Barroso, Clidaras & Hölzle, 2013, Morgan & Claypool: warehouse-scale infrastructure failure patterns → informs the failure-mode taxonomy; applied in §23.
  • "The eXpress Data Path: Fast Programmable Packet Processing" — Høiland-Jørgensen et al., 2018, CoNEXT: XDP/eBPF fast-path design → informs the eBPF probe integration; applied in §20.

Reference Implementations

  • ns-3 — study src/core/model/simulator.cc: deterministic event-scheduler API shape; pitfall: do not copy its single-threaded scheduler core, it will not hit the 15M events/sec §4 target; applied in §13.
  • Mininet — study mininet/net.py: Linux network-namespace host wiring; pitfall: do not copy its Python-process-per-host model, it does not scale past a few hundred nodes; applied in §20.
  • tc/netem — study kernel net/sched/sch_netem.c: delay/loss/corruption distribution implementation; pitfall: do not copy its single-queue-per-qdisc assumption into multi-flow fairness code; applied in §14.
  • OMNeT++ — study src/sim/cscheduler.cc: modular event-scheduler interface separating message and event queues; pitfall: do not copy its signal/listener pattern, it hides ownership and breaks I3; applied in §13.
  • Mahimahi — study mahimahi/src/packet/: trace-driven link emulation via record/replay shells; pitfall: do not copy its process-per-shell isolation, it does not compose with distributed coordination; applied in §17.
  • Tokio — study tokio/src/runtime/scheduler/: work-stealing async task scheduling; pitfall: do not adopt work-stealing for the deterministic scheduler core, it breaks replay determinism (I2); applied in §13.

RFCs / Specifications

Glossary (§36) · 42 terms · site-wide glossary

Event Tick
the logical scheduler timestamp; the unit of time in virtual-time mode (§13).
Replay WAL
the append-only, checksummed deterministic event log written by replay-engine (§18).
Queue Discipline
the packet dequeue algorithm (tail-drop, RED) applied at a link (§14).
Congestion Window
the sender's in-flight-byte limit, adjusted by CUBIC/BBR (§17).
Scheduler Shard
an independent, single-threaded event-execution partition (§13, P10).
Topology Manifest
the immutable, hash-stable compiled network graph (§15, I5).
Packet Descriptor
the immutable, single-owner packet metadata struct (§11, I3).
Fault Epoch
a window of time during which one or more faults are active (§16).
Deterministic Replay
exact bit-for-bit reproduction of a prior execution from its seed and WAL (I2).
Timing Wheel
the O(1) hierarchical timer-scheduling structure (Varghese & Lauck 1987, §13).
Flow State
transport-layer connection metadata: congestion window, RTT estimate, retransmit timers (§11, §17).
Barrier Sync
the distributed logical-time alignment primitive enforcing I9 (§19).
Packet Amplification
extra copies of a packet introduced during processing; must be zero under P7.
Namespace Adapter
the Linux network-namespace integration layer (§20).
Replay Divergence
a detected mismatch between two replays of the same seed (I2, FM-1).
Virtual Clock
the logical/accelerated/paused time source decoupled from wall clock (P9, §13).
Manifest Hash
the Merkle-style hash over a compiled topology's nodes/links/routes (§15).
Worker Lease
the time-bounded, exclusive right to own a shard's execution (§11, I10).
Fault Rule
a declarative selector/trigger/action/duration tuple in the fault DSL (§11, §16).
RED (Random Early Detection)
a probabilistic pre-capacity queue-dropping discipline (§14).
Tail-Drop
a simple bounded-FIFO queue-dropping discipline (§14).
SACK
Selective Acknowledgment, a TCP extension for non-cumulative ACKs (RFC 9293, §17).
RTO
Retransmission Timeout, the timer governing when an unacknowledged segment is resent (§17).
CUBIC
the default congestion-control algorithm modeled in transport-models (§17).
BBR
Bottleneck Bandwidth and RTT, a congestion-control algorithm modeled as an alternative (§17).
XDP
eXpress Data Path, the kernel fast-path used for eBPF packet mirroring (§20).
eBPF
extended Berkeley Packet Filter, the kernel-level probe mechanism used in §20.
PCAP
the packet-capture file format used for live-capture export (§20).
OpenTelemetry Span
a distributed-trace unit correlating a subsystem's entry/exit (§21).
Cardinality Guard
the metrics-pipeline component rejecting unbounded label sets (§21, §4).
WAL Segment
a fixed-size, checksummed, rotated unit of the replay WAL (§18, I11).
Snapshot
a periodic, schema-versioned full-state serialization for crash-only recovery (P4).
Shard Isolation
the principle that no mutable state crosses a scheduler-shard boundary (P10).
Backpressure
the discipline of bounding every channel and shedding load explicitly (P8).
Admission Control
rejecting new work at the boundary rather than queueing it unboundedly (§22, T6).
Split-Brain
two coordinators simultaneously believing they hold leadership (§19, FM-8).
Leader Election
the quorum-based protocol selecting a single active coordinator (§19).
Quorum
the majority threshold required for a coordinator election to be valid (§19).
Barrier Epoch
the monotonically increasing counter identifying a distributed barrier round (§19, I9).
Trace Correlation
pivoting a live trace span to its corresponding WAL epoch and tick range (§21).
Schema Version
the explicit version tag on every persisted format, enforced by I12 (P14).
Un-defer Trigger
the documented condition under which a deferred feature (§35) is reconsidered.
