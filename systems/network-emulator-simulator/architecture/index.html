Control plane (scenario-runner, topology-compiler, orchestrator): compiles scenarios into immutable, hash-stable execution plans; never processes a packet; the only path from control plane to runtime worker is the gRPC config/seed/barrier channel (a queue with backpressure, ADR-21 §9). Scenario DSL: declares topologies, traffic generators, failure timelines, timing semantics, observability directives; compiles to a plan whose hash is the replay key (I2, §7). Topology Compiler: validates the graph (cycle detection, connectivity), allocates deterministic node/link IDs, emits an immutable manifest (I5, §7). Simulation Coordinator: runtime registration, shard partitioning, deterministic seed propagation, distributed barrier sync (§19) — the trust boundary between control plane and workers. Virtual Clock: the concurrency boundary anchor — every worker thread reads one logical tick source; decouples simulation time from wall time (Lamport 1978, applied in §13). Event Scheduler: the persistence-adjacent boundary — every dequeue is a potential WAL write; hierarchical timing wheel (Varghese & Lauck 1987) bounds enqueue/dequeue to O(1). Packet Engine: the protocol boundary — parses wire bytes into PacketDescriptor (§11), applies queue discipline, fault injection, and congestion accounting in a fixed pipeline order. Fault Engine: a rule table evaluated per tick against scheduler events; durably logs every injected fault (I7, §7). Transport Models: TCP/UDP/QUIC behavior state machines consuming packet-engine output. Replay Engine: the durability boundary — every scheduler decision, fault injection, and RNG draw is appended to a checksummed WAL (I8, §7) before being visible to metrics. Metrics Pipeline: cardinality-guarded Prometheus export; the observability boundary all subsystems must cross (P5, §6). Storage Engine: persists manifests, WAL segments, snapshots, metrics segments; the only subsystem allowed direct disk I/O outside the WAL append path. External Interfaces: the kernel boundary — TAP/TUN and tc/eBPF are the only components that touch real kernel network state; PCAP/Prometheus/gRPC are the only components external tooling may reach.

8. Domain Model — Network Simulation Entities & Protocol State

Node — represents a host, router, switch, or endpoint. Fields: node_id (u32, stable post-compile per I5), role (enum: Host, Router, Switch, Endpoint), interfaces (Vec<InterfaceId>), routing_table (RouteTable, mutable only via TopologyMutation events), scheduler_binding (ShardId, assigned at compile time).

Link — represents a directed edge between two nodes. Fields: link_id (u32), source / target (NodeId), bandwidth_bps (u64), latency_distribution (LatencyModel), jitter (JitterModel), drop_policy (DropPolicy), corruption_policy (CorruptionPolicy). Immutable after topology-compiler emits the manifest (P11).

Packet — the unit of simulation. Fields: packet_id (u128), flow_id (u128), protocol (enum: TCP, UDP, QUIC), sequence_number (u64), timestamp (logical tick, u64), payload_descriptor (opaque byte-range reference, never a copy — P7), checksum (u32), flags (bitset). Exactly one mutable owner at all times (I3).

Flow — transport-layer connection state, one instance per (source, dest, protocol, ports) tuple. Owns congestion-window state, RTT estimator state, and retransmission-timer state (see transport-models, §17).

Event — the scheduler's unit of work. Variants: PacketIngress, QueueEnqueue, QueueDequeue, LinkTransmit, PacketDrop, FaultInject, Timeout, Retransmit, TopologyMutation. Every event carries a logical tick (I1) and a shard-local sequence number.

Packet lifecycle state machine:

CREATED --> QUEUED --> TRANSMITTING --> DROPPED
                              |
                              +--> CORRUPTED
                              |
                              +--> DELIVERED

Transitions are emitted as Event variants above; DROPPED and CORRUPTED are terminal and both increment fault-domain-tagged counters (I7). Only DELIVERED reaches the metrics pipeline as a successful-delivery sample.

Replay sequence: Scenario -> topology-compiler -> event-runtime scheduler -> replay-engine WAL -> replay snapshot. Every arrow is a durable, checksummed boundary (I8, I11) — a replay can resume from any snapshot without re-deriving upstream state.

Failure example — malformed packet checksum: packet-engine parser rejects the packet on checksum mismatch; a packet.checksum_invalid counter increments; a trace span is emitted with the flow ID and offending byte offset; a replay marker is persisted to the WAL before the packet is dropped (I7); the fault domain (link or node) is tagged for blast-radius analysis (§23). This sequence is the canonical example referenced by the malformed-checksum fixture family in §14.5.
