Per-box detail:

  • re-cli / host app. Entry boundary. Loads rule DSL text, issues assert/retract/modify on the session, drives fire/fire_all, requests introspection (agenda, trace, DOT). Trust boundary: all rule text and facts are untrusted input and pass through validation (Phase 2 semantic checks, Threat Model resource limits).
  • re-parser. Lexes + parses rule DSL into Rule AST. Pure, deterministic, no side effects. Emits structured diagnostics with spans. Rejects malformed rules (unbound RHS variables, type errors) before they reach the network builder.
  • NetworkBuilder (compiler). Compiles a set of Rules into a ReteNetwork: creates alpha nodes per constant test, beta/join nodes per inter-condition join, negation/terminal nodes; shares nodes whose test/join is identical across rules. One-shot per rule-set version; incremental rule add/remove in Phase 13.
  • WorkingMemory (re-facts). Authoritative fact store keyed by FactId; produces a Wme per asserted fact; maintains fact-type index for fast alpha routing; modify = retract+assert (preserving identity where possible). Owns fact lifetimes.
  • ALPHA NETWORK. Intra-condition (single-pattern) constant tests. Routes each incoming Wme to the AlphaMemory(ies) whose constant constraints it satisfies. Alpha memories store the set of WMEs passing those tests. Right activation source for join nodes.
  • BETA NETWORK. Inter-condition joins. JoinNodes combine a token (partial match from the parent BetaMemory, left activation) with a WME (from an AlphaMemory, right activation), testing inter-condition variable bindings; matches produce new Tokens stored in the child BetaMemory. NegationNodes implement negated/existential conditions. Tokens are parent-chained partial matches.
  • TERMINAL NODES. One per production rule. A token reaching a terminal node represents a full LHS satisfaction → constructs an Activation (rule + matched fact tuple + bindings) and posts it to the agenda; retraction of any contributing token retracts the activation.
  • AGENDA (re-agenda). Ordered set of pending activations. Ordered by ConflictResolutionStrategy (salience → recency/specificity/order). Holds the refraction set to prevent re-firing on an unchanged fact set. O(log n) insert/pop via priority structure.
  • ConflictResolutionStrategy. Decides next-to-fire among equally-salient activations: recency (LEX/MEA), specificity, rule load order. Pluggable, deterministic.
  • RECOGNIZE-ACT CYCLE (re-engine). The driver: select highest-priority activation, execute its RHS actions; RHS may assert/retract/modify facts → propagate through the network → update agenda → repeat until agenda empty (quiescence) or a fire limit hits. Enforces refraction and termination guard.
  • TruthMaintenance / TMS (re-engine). Tracks WM-support: facts logically asserted by a rule's RHS are justified by the firing activation's matched facts. When the justification's support is retracted, the justified fact is auto-retracted (cascade). Maintains the support/justification graph.
  • re-observe. Cross-cutting. DOT export of the network, structured per-cycle firing trace, agenda + memory snapshots, metrics counters (WMEs, tokens, activations, cycles, propagation cost).
  • BACKWARD-CHAIN SOLVER. Goal-driven inference reusing Fact/Pattern/unification. Given a goal pattern, finds rules whose RHS could produce it and recursively proves their LHS subgoals against WM and other rules; supports query answering distinct from the forward recognize-act loop.

8. Domain Model

8.1 Rule / Condition / Fact / Action grammar (EBNF)

program        = { rule | template | fact_decl } ;
template       = "deftemplate" ident "(" slot { "," slot } ")" ;
slot           = ident [ ":" type ] [ "=" literal ] ;
type           = "int" | "float" | "str" | "bool" | "sym" ;

rule           = "rule" string_lit [ "salience" int_lit ]
                 "when" lhs "then" rhs "end" ;
lhs            = { condition } ;
condition      = pattern
               | "not" pattern                         (* negation *)
               | "exists" pattern                      (* existential *)
               | "not" "(" pattern { pattern } ")"     (* NCC: negated conjunction *)
               | binding ;
binding        = var "<-" pattern ;                    (* bind matched fact to var *)
pattern        = ident "(" [ constraint { "," constraint } ] ")" ;
constraint     = slot_test | var_bind ;
slot_test      = ident op value ;                      (* intra: const test if value is literal *)
var_bind       = ident ":" var ;                       (* bind slot to var; join if var seen before *)
op             = "==" | "!=" | "<" | "<=" | ">" | ">=" | "in" | "matches" ;
value          = literal | var | expr ;
expr           = value { arith_op value } ;             (* simple arithmetic predicate *)
arith_op       = "+" | "-" | "*" | "/" ;
var            = "?" ident ;

rhs            = { action } ;
action         = "assert"  pattern
               | "retract" var
               | "modify"  var "(" slot_assign { "," slot_assign } ")"
               | "logical" "assert" pattern              (* justified/TMS assertion *)
               | "print" expr
               | "halt" ;
slot_assign    = ident "=" value ;

literal        = int_lit | float_lit | string_lit | bool_lit | symbol ;
ident          = letter { letter | digit | "_" } ;

Lexical: // line comment; /* block */; identifiers ASCII; numeric literals decimal; strings double-quoted with \ escapes; vars prefixed ?.

8.2 RETE network structure (conceptual)

ROOT
 ├─ ObjectTypeNode(Person) ── AlphaNode(age>=18) ── AlphaMemory A1
 │                            AlphaNode(age>=65) ── AlphaMemory A2
 ├─ ObjectTypeNode(Adult)  ── AlphaMemory A3
 │
 │  Dummy top BetaMemory B0 (single empty token)
 │        │ left
 │        ▼
 │  JoinNode J1 (B0 ⨝ A1)            right: A1            → BetaMemory B1 (tokens: <Person p, age>=18>)
 │        │ left
 │        ▼
 │  TerminalNode T(R1)  ← B1                              → Activation(R1, {?p})
 │
 │  JoinNode J2 (B?(Adult) ⨝ A2)     right: A2            → BetaMemory B2
 │        ▼
 │  TerminalNode T(R2)  ← B2                              → Activation(R2, {?p})
  • ObjectTypeNode (OTN): first-level discriminator on fact type; shared across all rules referencing that type.
  • AlphaNode: one constant test; chained; outputs to an AlphaMemory (set of passing WMEs).
  • Dummy top BetaMemory: holds a single empty token so the first JoinNode has a "left" input.
  • JoinNode: parent = a BetaMemory (left/token side), right = an AlphaMemory (WME side). On left activation (new token), probe right AlphaMemory for WMEs satisfying join tests → emit tokens. On right activation (new WME), probe parent BetaMemory for tokens → emit tokens.
  • BetaMemory: stores tokens (partial matches) produced by a JoinNode; feeds the next JoinNode's left input and/or a TerminalNode.
  • NegationNode: like a JoinNode but emits a token only when no matching WME exists (negative join); maintains a match counter per token.
  • TerminalNode: end of a rule's join chain; token here ⇒ full match ⇒ Activation.

8.3 Working memory, tokens, agenda

  • WorkingMemory: FactId → Fact; per-type index Type → {FactId}; each live fact has exactly one Wme{ id, fact_id, type }.
  • Token: a partial match = parent-chained list (parent_token, wme); conceptually the tuple of facts matched by conditions 1..k. Stored in a BetaMemory. Carries (or recomputes) variable bindings.
  • Activation: { rule_id, token (the full fact tuple), bindings, salience, recency_tag }. Lives on the agenda until fired or retracted.
  • Agenda: priority structure over activations + refraction set keyed by (rule_id, fact-tuple-signature).

8.4 Worked example trace

Rules:

deftemplate Person(age:int)
rule "R1-adult"  salience 10  when ?p <- Person(age:?a, ?a >= 18)            then logical assert Adult(of:?p) end
rule "R2-senior" salience 20  when Adult(of:?p)  Person(of:?p, age:?a, ?a>=65) then logical assert Senior(of:?p) end

Fact script: assert Person(age=70) then fire_all, later retract <that Person>.

State transitions:

Step Op Network effect Agenda after WM after
1 assert Person(age=70) → Wme W1 OTN(Person)→AlphaNode(age>=18) passes→A1 += W1; AlphaNode(age>=65) passes→A2 += W1 — {Person:W1}
2 J1(B0 ⨝ A1) right-act W1 token Tk1=(∅,W1) → B1; TerminalNode(R1) → Activation Act1(R1,{?p=W1}) [Act1(sal10)] {Person:W1}
3 fire Act1 RHS: logical assert Adult(of=Person:W1) → Wme W2; justification J(Act1)→Adult; refraction adds (R1,W1) [] (then re-match) {Person:W1, Adult:W2}
4 propagate W2 OTN(Adult)→A3 += W2; J2 left from Adult side, right A2 has W1 (age>=65) → token Tk2 → B2 → TerminalNode(R2) → Act2(R2,{?p}) [Act2(sal20)] {Person:W1, Adult:W2}
5 fire Act2 RHS: logical assert Senior(of=Person:W1) → W3; justification J(Act2)→Senior; refraction (R2,...) [] {Person:W1, Adult:W2, Senior:W3}
6 quiescent agenda empty — 3 facts
7 retract Person W1 A1 -= W1, A2 -= W1; J1 retract Tk1 → B1 -= Tk1 → retract Act1 (already fired, removed from refraction); TMS: Adult W2 justified by Act1 → support gone → auto-retract W2 cascade —
8 cascade W2 OTN(Adult) A3 -= W2; J2 retract Tk2 → Act2 retract; TMS: Senior W3 justified by Act2 → support gone → auto-retract W3 — {} empty

Result: retracting the single Person fact cascades through TMS to remove Adult and Senior — invariants I3 (retraction consistency) and I8 (WM-support) demonstrated.

8.5 Engine state-transition table

Current state Event Next state Action
Idle assert/retract/modify Matching propagate WME deltas through network
Matching propagation done, activations exist AgendaPopulated activations posted; conflict resolution orders them
Matching propagation done, no activations Quiescent nothing to fire
AgendaPopulated fire / fire_all Firing pop highest-priority activation; check refraction
Firing RHS asserts/retracts Matching re-enter match (recognize-act)
Firing RHS completes, agenda non-empty, more to fire AgendaPopulated next activation
Firing agenda empty Quiescent recognize-act loop ends
Firing fire_limit hit / halt action Halted emit termination diagnostic
Quiescent assert/retract/modify Matching resume
any fatal invariant violation Aborted snapshot + telemetry + abort

8.6 Malformed / failure examples

  • Unbound RHS variable: rule when Person(age:?a) then assert Adult(of:?p) end — ?p never bound in LHS → parser/semantic reject (Phase 2), error E-UNBOUND-RHS-VAR with span.
  • Type mismatch: Person(age:?a, ?a >= "old") — comparing int slot to string → E-TYPE-MISMATCH.
  • Cyclic assert/retract loop: rule "loop" when Person(age:?a) then retract ?p; assert Person(age=?a) end (re-asserts identical fact) → recognize-act never quiesces → termination guard (I7) trips at fire_limit, emits offending rule.
  • Join explosion (over-broad pattern): rule when Order(?x) Order(?y) Order(?z) end with N orders → N³ tokens → fan-out tripwire (I11) warns/aborts; diagnostic names join J and token count.
  • Negation flicker: not Person(age>100) toggling as facts cross the boundary → match-counter on negation node must be exact or activation flickers; covered by Phase 5 conformance.
  • Dangling token after buggy retract: if a JoinNode forgets a back-ref, retract leaves a token referencing a dead WmeId → I3/I4 detection aborts with the dangling TokenId.
