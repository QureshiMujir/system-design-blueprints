Invariants — what must never be false
AttributeDetail
StatementFor any two keys a < b (memcmp) in the tree, in-order traversal visits a before b.
WhyKeys are order-preserving bytes (P2); inner-node children are visited in key-byte order; Node4/Node16 maintain sorted keys[].
EnforcedNode4/Node16 add_child inserts at sorted position; Node48/Node256 iterate child_index/children array in ascending byte order during traversal.
DetectionProperty test: collect all keys via range(..), assert `windows(2).all(
Telemetryartdb stats reports key count; differential test against BTreeMap::iter() checks full ordering.
RecoveryNot recoverable at runtime; indicates structural corruption — tree must be rebuilt.
DebuggingEnable RUST_LOG=debug; dump tree via artdb viz; compare child-key arrays at each node level.
