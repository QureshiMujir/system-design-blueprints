⬜ Phase 1 — ROBDD core (unique table, reduction, ite) §13

Objectives
  • Node table: (level: u32, low: Bdd, high: Bdd) arena indexed by Bdd(u32); two reserved terminals.
  • Unique table: hashcons on (level,low,high) → no duplicate node (R2); construction-time check low==high → return low → no redundant test (R1).
  • ite(f,g,h) = THE primitive; not/and/or/xor/imp/bdd_true/bdd_false/ithvar all reduce to it (and to constants).
  • Computed cache keyed (f,g,h) → ite amortized O(|f|·|g|·|h|); without it, exponential.
  • Canonicity invariant: fixed total var order + R1 + R2 ⇒ structural handle equality iff function equality; prove via property tests. GC/cache/quantification deferred to Phase 2.

⬜ Phase 2 — BDD operations for model checking (quantification, relational product, GC) §14

Objectives
  • Implement on BddManager: restrict, exists, forall, and_exists, rename, satcount, node_count, plus GC (ref_inc/ref_dec/gc) and to_dot. All in crate smv-bdd (no_std + alloc).
  • and_exists = single fused recursion (AND ⊗ ∃) — never and then exists, because the unquantified conjunction can blow up by orders of magnitude.
  • All ops memoized in the computed cache; cache key tagged by op so distinct ops sharing operands never collide.
  • GC reclaims dead nodes without breaking the canonicity invariant; live Bdd handles survive verbatim (same u32) iff the manager does not compact, or are remapped iff it does.
  • Quantification + relational product property-tested against brute-force truth tables for ≤16 vars.

⬜ Phase 4 — Boolean encoding of finite-domain variables §16

Objectives
  • Encoder in smv-model: allocate per-var VarEncoding { levels, ty } covering Boolean (1 bit), Enum(atoms) / scalar (ceil(log2 |atoms|) bits + out-of-range invariant), Range(lo,hi) (ceil(log2 (hi-lo+1)) bits, offset lo).
  • Interleaved present/next level layout s0 s0' s1 s1' … per encoded bit → small trans BDDs (Phase 5/6 dependency); produce present: VarMap, next: VarMap.
  • compile_expr(&Expr) -> Bdd over present levels; Next(e) recurses with the present→next VarMap. Case → right-fold nested ite. Arithmetic/relational BinOp → ripple-carry/comparator BDD circuits.
  • Decode: cube_to_state(&Bdd) -> StateAssignment inverts the encoding; round-trip is total over in-range valuations.
  • Invariant: encoding is injective per var; padding codes (Enum/Range whose count is not a power of two) are excluded by the out-of-range constraint, surfaced into EncodedFsm.invar.

⬜ Phase 5 — Building the symbolic FSM (init + transition relation) §17

Objectives
  • Build EncodedFsm { present, next, init, trans, invar, fairness, ap } for any well-typed SmvModule — the single FSM artifact all checkers consume.
  • init = conj of init(x):=e predicates AND all INVAR AND default-init for unconstrained vars (full domain); over present vars only.
  • trans = conj of next(x):=e relations AND TRANS clauses AND next-state INVAR(next) AND functional-totality for unconstrained vars; relates present↔next.
  • Functional vs relational unification: next(x):=e → x' ↔ enc(e); TRANS expr → arbitrary relation; both fold into the same trans.
  • Conjunctive partitioning: store trans as Vec<TransPart> (per-var/per-clause partial relations + each part's quantifiable cube), NEVER materialize the monolith — image (Phase 6) quantifies part-by-part.
  • fairness: Vec<Bdd> = one state-set Bdd per FAIRNESS/JUSTICE constraint, for Emerson-Lei (Phase 10/12).
  • Forward ap (atomic-prop → Bdd) from DEFINE/named props for smv-logic binding.
Deliverable

⬜ Phase 6 — Symbolic reachability and the fixpoint framework §18

Objectives
  • Img(S) = (exists present.(trans AND S))[next->present] via and_exists over partitioned trans + early-quantification schedule; pre-image is the dual (quantify next).
  • Reachable = lfp Z. init OR Img(Z), iterated to BDD-handle convergence (new == prev, O(1)).
  • Frontier simplification: image only the new frontier (reached AND not prev), not the whole set; preserves least fixpoint.
  • Factor a generic Fixpoint framework (lfp/gfp, monotone step, convergence test) reused unchanged by CtlChecker::check (Phase 7) — single iteration engine, no duplication.
  • NON-GOAL here: CTL/LTL semantics (Phases 7/10), counterexamples (Phase 8). This phase = reachability + the engine only.

Root cause: support analysis off-by-one. Fix: a present var is eliminable at cluster i only if absent from S and from all clusters > i. Debug: compare partitioned Img to monolithic on small models.
  • Disjunctive partition on synchronous model — disjunctive Img is correct only for disjoint-source (interleaving) transitions; applying to synchronous product double-counts or drops. Root cause: wrong PartKind. Fix: choose Disj only for explicitly asynchronous composition; default Conj.
  • Fairness ignored ⇒ spurious liveness pass/fail — omitting fairness makes AF/EG use the full transition relation, yielding NuSMV-mismatching verdicts on models with FAIRNESS/JUSTICE. Root cause: forgot to relativize. Fix: thread EncodedFsm.fairness into every fixpoint; empty fairness ⇒ trivially-fair (no change).
  • Completeness threshold too small — using reachability diameter d for a liveness property (needs recurrence diameter rd ≥ d) reports safe while a longer lasso cex exists. Root cause: wrong diameter for property class. Fix: safety→d, liveness/general→rd. Debug: cross-check with BDD verdict on the same model.

Pitfalls
  • Oracle parsing fragility → NuSMV cex format differs nuXmv vs NuSMV and across versions; root cause: scraping free text. Pin version in scripts/oracle.sh, parse structured -- specification lines; debug by dumping captured stdout to target/oracle/<id>.txt on mismatch.

  • Truth-table test blows up → property test with n > 20 vars → 2^n table OOM. Cap fuzz/proptest at n ≤ 16 (64 Ki rows); larger functions validated only by differential, not brute force.
  • Reorder test false alarm → comparing Bdd handles before/after sifting fails because indices change; only truth tables / function identity are invariant under reorder, not raw u32. Snapshot truth tables, not handles.
  • Fuzz finds a real canonicity break that "passes" → if assert_canonical() is debug-only and fuzz builds release, silent corruption (the GRAVEST class). Build fuzz targets with debug_assertions=true (in fuzz/Cargo.toml profile) so canonicity asserts fire.
