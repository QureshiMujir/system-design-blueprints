4. System Constraints

Library-internal constraints for the sel-* workspace. No process/server boundaries: this is an in-process library consumed by a host. Quantified ceilings, throughput floors, latency targets, hard caps (DoS), and recovery semantics below are normative.

4.2 Complexity Caps (DoS Bounds)

Untrusted selector strings + untrusted trees → every recursive/unbounded dimension MUST be hard-capped at parse time; exceeding a cap returns ParseError, never a panic or unbounded work.

Dimension Cap Failure Why
Combinator depth (complex selector length) 1024 Components ParseErrorKind::UnexpectedToken bound backtracking work in matches_selector
:has() nesting depth 4 BadPseudo relational match is O(subtree) per level; nesting multiplies subtree walks
:is() / :where() / :not() argument count 256 selectors EmptySelector/UnexpectedToken forgiving lists still allocate one Selector each
Functional pseudo nesting (any) 32 BadPseudo bound parser recursion → no stack overflow on untrusted input
An+B coefficient magnitude fits i32 BadNthExpression reject overflowing literals

MatchingContext.nesting_level tracks runtime relational/logical recursion; :has() forward/backward matching (Phase 11, ## 23) consults it against the depth cap and bails to false rather than recurse without bound.

4.3 CPU / Cache Assumptions and Out-of-Scope Budgets

CPU/cache: hot path (matches_selector RTL loop + BloomFilter lookup) sized to L1/L2. AncestorHashes (12 B) = one cache line; BloomFilter (4096 B) L1-resident across a query_selector_all sweep. No SIMD; no hot-path atomics; Specificity is a one-integer compare. No false negatives: FP costs only a slow path.

Out-of-scope (N/A): NUMA/thread affinity (caller concern); network/disk/RPC (no I/O on parse or match); GC pauses (Rust ownership, no runtime); std only in sel-dom/sel-cli.

4.5 Recovery & Availability

  • Parsing never panics. Every malformed / oversized / unsupported input → ParseError { ParseErrorKind } (UnexpectedToken, EmptySelector, DanglingCombinator, BadPseudo, UnsupportedPseudo, BadAttributeSelector, UnclosedBlock, BadNthExpression, NamespaceUnknown). No unwrap/panic!/unreachable! reachable from untrusted input on parse or match paths.
  • Matching never panics: a parsed Selector is already validated; matches_selector is total over any E: Element tree.
  • API boundary: query_selector / query_selector_all / closest surface invalid input as SyntaxError (non-forgiving top level); valid-but-unmatchable → Ok(None) / Ok(vec![]).
  • Availability invariant: a malformed selector can never take down the host. Worst case = bounded ParseError or bounded-work false; no crash, no hang, no unbounded allocation.
  • Fuzzing (Phase 13, ## 25) enforces the no-panic and bounded-work invariants on parse / roundtrip / match corpora.
