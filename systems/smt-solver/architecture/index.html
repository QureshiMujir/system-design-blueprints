3. Architectural Overview

3.1 System Diagram

   SMT-LIB 2.6 script (file / stdin)  ──  smtsolve REPL  [smt-cli]
                  |  commands: set-logic, declare-fun, assert, check-sat, push/pop, get-model/value/unsat-core, exit
   ===TRUST BOUNDARY=== untrusted text · unbounded term size / paren nesting
                  v
   smt-parse : Parser -> Command stream · CommandContext (assertion stack, push/pop, symbol table)
                  |  TermRef assertions (well-sorted)
                  v
   smt-types : TermBank — hash-consed Term DAG, Sort checking      <==== shared by ALL crates ====>
                  |  Boolean skeleton (TermRef)                                       ^
                  v                                                                    |
   smt-sat : Tseitin CNF · SatCore (CDCL, reused from #277) · AtomMap (BoolVar<->atom)|
        |  assigned theory literals (down)            theory propagations / conflicts (up)
        v                                                                    ^
   smt-core : DPLL(T) loop · TheoryManager · Nelson-Oppen equality bus ------+
        |                    |                       |
        v                    v                       v
   smt-theory:  euf(CC)   arith(Simplex + B&B)   bv(BitBlaster)     (each impl TheorySolver)
                  |  interface equalities · sat + partial assignment
                  v
   smt-model : ModelBuilder · evaluate (get-value) · UnsatCore
   --------------------------------------------------------------------------------
   Concurrency boundary: SINGLE-THREADED core — theory solvers share the SAT trail synchronously.
   Persistence boundary: NONE at runtime (stdin/stdout REPL); optional proof / unsat-core text export.

3.2 Box Responsibilities

smt-types — Term DAG + Sorts. Owns TermBank (arena + HashMap<TermKind, TermRef>), Term, TermRef(u32), Sort, SortRef(u32), Symbol(u32) interner, Value, Logic. Key invariant: hash-consing => structural equality == handle equality. Referenced by: every phase.

smt-parse — Parser + CommandContext. Owns SExpr, Command, Parser, CommandContext, ParseError. Key invariant: the trust boundary — all size/nesting/sort checks happen here. Referenced by: Phase 1 (§13); Phase 12 (§24) push/pop scoping.

smt-sat — Tseitin + reused SatCore + AtomMap. SatCore is the reused project-277 CDCL engine (NOT re-derived). tseitin() introduces a fresh BoolVar per non-atomic subformula; theory atoms become leaf BoolVars in AtomMap. Key invariant: AtomMap is a bijection. Referenced by: Phase 3 (§15); Phase 4 (§16)'s DPLL(T) loop.

smt-core — DPLL(T) loop + TheoryManager. Owns TheorySolver (trait), TheoryConflict, TheoryPropagation, TheoryManager, CheckResult, check_sat(). Key invariant: TheorySolver push/pop depth tracks the SAT trail exactly. Referenced by: Phase 4 (§16); all theory phases.

Nelson-Oppen equality bus (in smt-core / TheoryManager). Purifies mixed terms; theories exchange entailed interface equalities to fixpoint. Key invariant: share only equalities over interface variables; UNSAT if any theory rejects. Referenced by: Phase 9 (§21).

smt-theory::euf — CongruenceClosure. Union-find with proof forest + e-graph of App nodes; merge, are_equal, explain_eq. Key invariant: classes closed under congruence; explanations are minimal asserted-literal subsets. Referenced by: Phase 5 (§17); feeds N-O bus (§21).

smt-theory::arith — Simplex + branch-and-bound. General-form Tableau over BigRational, basic/nonbasic vars, Bound per var. Exact BigRational — never floating point (soundness). LIA = LRA + B&B. Referenced by: Phases 6–7 (§18–19).

smt-theory::bv — BitBlaster. Maps each width-w BvTerm bit to a BoolVar; lowers each BvOp to structural clauses emitted into the shared SatCore (eager bit-blasting). Referenced by: Phase 8 (§20).

smt-model — ModelBuilder + evaluate + UnsatCore. On Sat: per-theory model contributions combined; evaluate(t, model) -> Value. On Unsat: UnsatCore extracts the subset of named assertions in the final conflict. Referenced by: Phases 10–11 (§22–23).

8. Domain Model — SMT-LIB, the Term DAG, and DPLL(T)

8.1 SMT-LIB 2.6 surface grammar (EBNF)

script        ::= command* ;
command       ::= "(" "set-logic"   logic ")"
                | "(" "set-option"  ":" keyword attr-value ")"
                | "(" "set-info"    ":" keyword attr-value ")"
                | "(" "declare-sort" symbol numeral ")"
                | "(" "declare-fun"  symbol "(" sort* ")" sort ")"
                | "(" "define-fun"   symbol "(" sorted-var* ")" sort term ")"
                | "(" "assert" term ")"
                | "(" "check-sat" ")"
                | "(" "push" numeral ")"
                | "(" "pop"  numeral ")"
                | "(" "get-model" ")"
                | "(" "get-value" "(" term+ ")" ")"
                | "(" "get-unsat-core" ")"
                | "(" "exit" ")" ;
logic         ::= "QF_UF" | "QF_LIA" | "QF_LRA" | "QF_BV"
                | "QF_UFLIA" | "QF_AUFLIA" | symbol ;
sort          ::= "Bool" | "Int" | "Real"
                | "(" "_" "BitVec" numeral ")"
                | symbol
                | "(" "Array" sort sort ")"
                | "(" symbol sort+ ")" ;
sorted-var    ::= "(" symbol sort ")" ;
term          ::= spec-const
                | qual-ident
                | "(" qual-ident term+ ")"
                | "(" "let" "(" var-binding+ ")" term ")"
                | "(" "forall" "(" sorted-var+ ")" term ")"
                | "(" "exists" "(" sorted-var+ ")" term ")"
                | "(" "!" term attr+ ")" ;
qual-ident    ::= ident | "(" "as" ident sort ")" ;
ident         ::= symbol | "(" "_" symbol index+ ")" ;
var-binding   ::= "(" symbol term ")" ;
spec-const    ::= numeral | decimal | hexadecimal | binary | string-lit | "true" | "false" ;
numeral       ::= "0" | [1-9] [0-9]* ;
decimal       ::= numeral "." [0-9]+ ;
hexadecimal   ::= "#x" [0-9a-fA-F]+ ;
binary        ::= "#b" [01]+ ;
symbol        ::= simple-symbol | "|" /[^|\\]*/ "|" ;
simple-symbol ::= ( letter | special ) ( letter | digit | special )* ;
keyword       ::= ":" simple-symbol ;

Lexer tokens: ( ) numeral decimal hex #x binary #b symbol keyword string. Comments ; ... \n. Whitespace = space/tab/CR/LF only.

8.2 The Sort system + well-sortedness

Sort enum (LOCKED): Bool | Int | Real | BitVec(u32) | Uninterpreted(Symbol) | Func(Box<[SortRef]>, SortRef) | Array(SortRef, SortRef). Sorts are hash-consed (SortRef) like terms; equality = SortRef identity.

Term form Operand sorts Result sort Error on violation
BoolLit(b) — Bool —
IntLit/RealLit/BvLit(bits) — Int/Real/BitVec(width) —
Var(s) (arity-0 decl) — declared result sort UnknownSymbol
App(f, [a₁..aₙ]) f: Func([σ₁..σₙ], τ), sort(aᵢ)=σᵢ τ ArityMismatch / SortMismatch
Not(t) sort(t)=Bool Bool SortMismatch
And/Or([..]) every operand Bool, n≥1 Bool SortMismatch
Eq(a,b) sort(a)=sort(b) (any) Bool SortMismatch
Distinct([a₁..aₙ]) all same sort, n≥2 Bool SortMismatch
Ite(c,t,e) c:Bool, sort(t)=sort(e) sort(t) SortMismatch
Arith(op,[..]) all Int or all Real; * linear-only numeric / Bool SortMismatch
Bv(op,[..]) widths match per op rule BitVec(w') / Bool SortMismatch
Array select(a,i) a:Array(κ,ν), sort(i)=κ ν SortMismatch

Linearity check: Arith::Mul well-sorted only if ≤1 operand is non-constant. BitVec width is part of the sort.

8.3 The Term DAG + hash-consing

TermBank = arena (Vec<Term>) + HashMap<TermKind, TermRef> for de-duplication. intern(kind) -> TermRef: compute sort, look up kind; hit → return existing TermRef; miss → push, insert, return fresh. Maximal structural sharing: identical subterms share one node.

Why canonicity is load-bearing:

  • TermRef identity ⇒ syntactic equality in O(1) — no recursive walk.
  • Memory bounded by distinct subterms; deeply nested SMT-LIB collapses. Target: ≥2M intern/sec, ≤40 B/node amortized.
  • AtomMap keyed by TermRef: each theory atom maps to exactly one BoolVar.

TermKind variants partition into: Boolean-structural (Not,And,Or,Implies,Ite over Bool) → Tseitin-encoded; theory atoms (Eq,Distinct, Arith comparisons, Bv predicates) → leaves handed to TheorySolvers; theory terms (App,Var,IntLit,RealLit,BvLit,Arith arithmetic, Bv ops) → interpreted inside theory solvers; quantifiers (Forall,Exists) → stub.

8.4 The DPLL(T) protocol (state machine)

Lazy SMT: SatCore (reused project-277 CDCL) decides a Boolean assignment over theory atoms (abstracted as BoolVar via AtomMap); the TheoryManager checks T-consistency of the assigned theory literals.

   set-logic / assert ...           check_sat(ctx)  [smt-core: DPLL(T) loop]
            |                                |
   tseitin(skeleton) ──▶ SatCore (CNF) , AtomMap (BoolVar<->atom TermRef)
            |
            v
   ┌──────────────────────────── DPLL(T) main loop ────────────────────────────┐
   │  (1) SatCore: BCP/unit-prop to fixpoint over current decision level        │
   │        ├─ propositional conflict ─▶ analyze/learn/backjump (project-277)   │
   │        └─ fixpoint reached, partial assignment A of theory literals        │
   │  (2) for each literal newly assigned in A:                                 │
   │        TheorySolver::assert_lit(atom, polarity)                            │
   │          └─ Err(TheoryConflict{core}) ─▶ goto (5)                          │
   │  (3) TheoryManager::check(final_check=false)  (+ Nelson-Oppen eq bus)      │
   │        ├─ Ok(props: Vec<TheoryPropagation>) ─▶ feed each as implied lit    │
   │        │      to SatCore (reason = explain(lit)); goto (1)                 │
   │        └─ Err(TheoryConflict{core}) ─▶ goto (5)                            │
   │  (4) all vars assigned & no props:  check(final_check=true)                │
   │        ├─ Ok([]) ─▶  SAT  (build model; ready for get-value/get-model)     │
   │        └─ Err(conflict) ─▶ goto (5)                                        │
   │  (5) T-conflict: learn theory lemma  ¬(l₁∧…∧lₖ) = ⋁¬lᵢ  over core;       │
   │        add clause to SatCore; backjump; if at level 0 ─▶ UNSAT; else (1)   │
   └───────────────────────────────────────────────────────────────────────────┘

Invariants: Soundness of lemmas (every TheoryConflict.core is jointly T-inconsistent); Trail synchrony (push/pop mirror SatCore decision levels); Termination (each learned theory lemma is new over finitely many atoms).

8.5 Worked example 1 — QF_UF (unsat)

(set-logic QF_UF)
(declare-sort U 0) (declare-fun a () U) (declare-fun b () U) (declare-fun c () U)
(declare-fun f (U) U)
(assert (= a b)) (assert (= b c)) (assert (not (= (f a) (f c))))
(check-sat)
Atom (TermRef) BoolVar Asserted polarity
Eq(a,b) p₁ true
Eq(b,c) p₂ true
Eq(f(a),f(c)) p₃ false

SatCore picks p₁=T, p₂=T, p₃=F. EUF CongruenceClosure:

assert_lit(Eq(a,b),T):  merge(a,b)      classes: {a,b} {c} {f(a)} {f(c)}
assert_lit(Eq(b,c),T):  merge(b,c)      classes: {a,b,c} {f(a)} {f(c)}
   congruence:  f(a),f(c) with a~c  =>  pending merge(f(a),f(c))
                                        classes: {a,b,c} {f(a),f(c)}
assert_lit(Eq(f(a),f(c)),F):           are_equal(f(a),f(c)) == true  -> CONFLICT

explain_eq(f(a),f(c)) walks the proof forest: f(a)=f(c) ⇐ congruence ⇐ a=c ⇐ {a=b, b=c}. Conflict core = { Eq(a,b), Eq(b,c), ¬Eq(f(a),f(c)) }. Theory lemma ¬p₁ ∨ ¬p₂ ∨ p₃ added; at decision level 0 ⇒ unsat.

8.6 Worked example 2 — QF_LRA (unsat)

(set-logic QF_LRA)
(declare-fun x () Real) (declare-fun y () Real)
(assert (<= (+ x y) 2)) (assert (>= x 1)) (assert (>= y 2))
(check-sat)

Simplex general form: introduce slack s = x + y (a basic var).

Var lo hi role
s = x+y — 2 basic
x 1 — nonbasic
y 2 — nonbasic

x=1, y=2 ⇒ s = 3. But hi(s)=2 ⇒ s violates upper bound. Every nonbasic in its row is at its lower bound and cannot decrease ⇒ no pivot restores feasibility ⇒ infeasible row. Conflict: { x≥1, y≥2, x+y≤2 }. Theory lemma negates these ⇒ unsat. Arithmetic is exact BigRational for soundness.

8.7 Worked example 3 — QF_LIA branch-and-bound (mini)

(set-logic QF_LIA)
(declare-fun x () Int)
(assert (<= (* 2 x) 3)) (assert (>= (* 2 x) 1))
(check-sat)

LRA-relaxation: feasible, e.g. x = 0.5. Integrality check: x is Int but q = 1/2 ∉ ℤ ⇒ branch: x ≤ 0 OR x ≥ 1.

  • Branch x≤0: combined with 2x≥1 ⇒ infeasible ⇒ prune.
  • Branch x≥1: with 2x≤3 ⇒ x=1, integral ⇒ sat, model x=1.

8.8 Malformed / edge inputs → ParseError

Input Defect ParseError
(assert (= a b) missing ) / EOF mid-S-expr UnbalancedParens
(assert (and x 1)) 1:Int where Bool required SortMismatch
(assert (p q)) p undeclared unknown function/const symbol UnknownSymbol
(set-logic QF_FOO) logic not in Logic enum UnsupportedLogic
(assert (f a b)) f:Func([U],U) 2 args, arity 1 ArityMismatch
(assert (bvadd x y)) x:BitVec(8), y:BitVec(16) width mismatch SortMismatch
(assert (* x y)) both vars nonlinear Mul SortMismatch
#xZZ bad hex digit in BvLit LexError
(pop 3) at stack depth 1 underflow pop UnbalancedParens

Edge-case policy: recursion-depth guard on term (iterative S-expr parse) and an interning cap; on breach emit ParseError::LexError/UnbalancedParens rather than overflow the stack.
