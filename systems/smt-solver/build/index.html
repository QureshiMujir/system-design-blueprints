⬜ Phase 0 — Skeleton, term/sort shells, and the "(check-sat) => sat" smoke test §12

Objectives

Stand up Cargo workspace + all 7 smt-* crate skeletons; define smt-types shells (Sort, TermKind, Term, TermRef/SortRef/Symbol, TermBank, Value, Logic); smt-parse SMT-LIB 2.6 lexer + S-expr reader + command-loop stub; smt-core trivial check_sat returning Sat. Smoke: (set-logic QF_UF)(assert true)(check-sat) => prints sat. Wire CI + Makefile + Dockerfile.

Deliverable

smtsolve solve smoke.smt2 prints sat; cargo build --workspace + cargo test -p smt-parse -p smt-cli green; CI passes fmt+clippy+test on Linux+macOS.

Acceptance
Check Target
Build cargo build --workspace 0 warnings (-D warnings)
Smoke echo '(set-logic QF_UF)(assert true)(check-sat)' | smtsolve solve - → exactly sat\n, exit 0
Lint cargo clippy --workspace --all-targets -D warnings clean
CI green on stable 1.78 + nightly fmt; <2 min wall

⬜ Phase 2 — Term DAG, hash-consing, and sort checking §14

Objectives
  • TermBank.intern(TermKind) -> TermRef: structural hashing => same TermRef for structurally-equal TermKinds (INV-CANON).
  • Sort system: Sort { Bool, Int, Real, BitVec(w), Uninterpreted(Symbol), Func, Array }; SortRef also hash-consed.
  • Well-sortedness checker: assign every TermRef a SortRef at intern time; reject ill-sorted with ParseError::SortMismatch / ArityMismatch (INV-SORT).
Deliverable

TermBank interns a full SMT-LIB term DAG with O(1) structural-equality via TermRef; sort-checker rejects ill-sorted terms with the exact ParseError. parse_script now emits real TermRef assertions (no stub identity). Inspectable: --dump-dag prints node count + hash-cons hit rate.

Acceptance
  • Canonicity: intern(k) == intern(k.clone()) for ≥10k random well-sorted terms (property test).
  • intern ≥ 2M terms/sec on degree-≤3 nodes; arena ≤ 32 B/Term + sort (SC-7).
  • Every ill-sorted fixture returns the exact ParseError variant; zero false rejects on well-sorted corpus.

⬜ Phase 3 — Boolean skeleton, Tseitin CNF, and the reused CDCL SatCore §15

Objectives
  • Integrate the project-277 CDCL engine as-is as smt-sat::SatCore (vendored, NOT re-derived; cross-link #277; ADR-06).
  • Implement tseitin() (P11): walk Term DAG → abstract each theory atom to one BoolVar; introduce fresh BoolVar per non-atomic subformula; emit defining CNF clauses.
  • Build AtomMap: BoolVar ⇄ atom TermRef bijection (INV-ATOMMAP).
  • For QF Boolean drive a pure propositional check-sat → sat/unsat.
Deliverable

smtsolve decides pure-propositional QF formulas: (assert (or p (not q)))(check-sat) → sat/unsat via the reused #277 SatCore. AtomMap exposes the BoolVar↔atom bijection. Inspectable: --dump-cnf prints clause + var counts.

Acceptance
  • 100% agreement with the #277 reference solver on ≥500 random QF Boolean formulas.
  • Tseitin CNF size linear: ≤ 4·(#subformula nodes) clauses (SC-3); aux-var count = distinct non-atomic TermRefs.
  • AtomMap bijective: atom(intern_atom(t))==Some(t); aux vars return None (INV-ATOMMAP).
  • Throughput ≥ 200k Tseitin nodes/sec encoding (M11).
Fixtures
File Expected
prop_sat.smt2 ((or p (not q))) sat
prop_unsat.smt2 ((and p (not p))) unsat
shared_sub.smt2 (DAG-shared subformula) clause count ≤ 4·nodes (no blowup)
false.smt2 ((assert false)) unsat (Phase-0 verdict now flips)
Pitfalls
  • Aux vars leak into AtomMap → Phase 4 queries a non-atom var, panics; fix: atom_of=None for fresh.
  • Not allocates a var → doubles var count; fix: fold Not into Lit sign, no new var.
  • Misclassified atom (Eq over Bool args treated as atom) → wrong abstraction; Eq:Bool is the iff connective, not a theory atom.

⬜ Phase 4 — The DPLL(T) protocol (theory-solver interface) §16

Objectives
  • Build smt-core DPLL(T) orchestrator: check_sat main loop coupling the reused project-277 CDCL SatCore to one or more TheorySolvers — lazy SMT (B3, P1).
  • Define TheorySolver trait + TheoryConflict, TheoryPropagation, CheckResult, TheoryManager.
  • Validate end-to-end with a trivial theory (AllIndependent): exercises the loop without theory-reasoning confounds.
Deliverable

check_sat runs the full lazy DPLL(T) loop over the reused SatCore + TheoryManager, validated with the AllIndependent trivial theory. T-conflicts produce learned lemmas; T-propagations enter the SAT trail with a reason. Inspectable: --trace-dpllt dumps each decision/propagation/conflict.

Acceptance
  • Phase-3 propositional suite passes unchanged with trivial theory active (0 regressions).
  • Injected fake conflict: loop emits theory lemma ¬a, backjumps, returns unsat iff a forced.
  • Injected fake propagation: SAT trail shows a@reason=Theory; final result sat.
  • push/pop lockstep asserted: theory push count == SAT decision-level bumps at every check (INV-TRAIL).
  • 50k-clause Boolean instance: trivial-theory overhead < 5% vs Phase-3 bare SAT.
Fixtures
File Expected
trivial_sat.smt2 (AllIndependent, satisfiable skeleton) sat, model present
forced_conflict.smt2 (theory forces ¬a, a required) unsat via theory lemma
lockstep.smt2 (deep push/pop trace) theory_depth == decision_level at every check
Pitfalls
  • Wrong backjump level → infinite re-derivation loop; fix: add lemma at 2nd-highest level in core (P1 backjump rule).
  • Stale theory literals after backjump → trail desync; debug: assert theory_depth == sat.decision_level() (INV-TRAIL).
  • Final-check skipped → declaring Sat without check(final=true) → misses theories needing model-completion (INV-CONFLICT).
