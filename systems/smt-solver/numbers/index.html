4. System Constraints

Hard rules, quantified budgets, and adversarial guarantees. All targets assume a single core, x86-64, release build (opt-level=3, LTO thin), Rust 1.78, std-only.

4.2 Time / decidability

  • Worst case unbounded. QF fragments are NP-hard+ (QF_BV NP-complete; QF_LIA NP-complete). With quantifiers SMT is undecidable → e-matching stub may not terminate.
  • Resource budget (--timeout, --max-mem, --max-conflicts) → on exhaustion check_sat returns CheckResult::Unknown, never a wrong sat/unsat.
  • Budget checked at safe points: SAT decision boundary, theory check entry, branch-and-bound node, Nelson-Oppen round.

4.3 Arithmetic soundness

LRA/LIA use BigRational exact arithmetic — never f32/f64. Floating point would make Simplex feasibility/conflict unsound. Cost: rational num/den grow with pivot chains; bounded by problem, not unbounded precision drift. GCD-normalize after pivots, never approximate.

4.4 Adversarial input limits (DoS surface = untrusted SMT-LIB text at smt-parse)

Limit Default cap Enforcement
Max paren nesting 10_000 Parser depth counter → ParseError::UnbalancedParens
Max term DAG nesting 100_000 iterative (no recursive drop/print) → bounded stack
Max asserted formulas 10_000_000 CommandContext counter
Max BvVec width 4_096 sort check → ParseError::SortMismatch/reject
Max symbol length / count 1 MB / 10M interner cap
  • Term construction is iterative (explicit worklists) — no native recursion on attacker-controlled depth ⇒ no stack overflow.

4.5 Concurrency, persistence, platform

  • Single-threaded core. Theory solvers share the SAT trail synchronously; no locks, no async.
  • No persistence at runtime. stdin/stdout REPL only; optional proof/core export to file (Phase 11).
  • Zero global init. Every arena/interner/solver lives in CommandContext; constructing it is the only startup cost.

4.6 Recovery & availability

  • Parsing never panics on malformed/hostile input → every failure is a typed ParseError.
  • Solving honors the budget → exhaustion yields Unknown, not a panic and not a crash.
  • No unwrap/panic! on input-derived paths; debug_assert! only for internal invariants.
  • Availability guarantee: adversarial SMT-LIB can never crash, hang unboundedly, or corrupt the host — it can only time out (Unknown) or return a typed error.

4.7 Determinism

Same input + same flags ⇒ identical output and identical model/core. No wall-clock or RNG in the search. Timeout-induced Unknown is the only nondeterministic outcome.
