4. System Constraints

Dimension Target
Memory ceiling (engine) configurable; default 4 GiB; per-operator reservation; spill before 90%
Per-operator spill threshold reservation exhausted → spill in ≤1 batch; never grow unbounded
Throughput (scan→filter→agg, SF=10) ≥ 200 M rows/s aggregate across 8 cores (int columns)
Re-optimization decision latency p50 ≤ 1 ms, p95 ≤ 10 ms, p99 ≤ 50 ms per stage boundary (excludes re-plan search)
Re-plan search per stage p95 ≤ 50 ms (bounded memo, single stage only)
Stage scheduling overhead ≤ 1% of stage wall-time
Startup (CLI cold) ≤ 150 ms to first morsel dispatched
Shutdown drain in ≤ 2 s; spill files unlinked; no orphan FDs
Concurrency scales to physical cores; default = num_cpus; morsel ≈ 100K rows
CPU/cache hot loops cache-resident batches (≤ L2 per morsel column slice); branch-light filters
NUMA per-node morsel queues; local-first scheduling; steal across nodes last
FD budget ≤ 256 open spill+shuffle FDs; segment coalescing to stay under
Storage amplification (spill) ≤ 1.5× spilled bytes vs logical (compression off by default)
Recovery time objective (shuffle-file loss) recompute producing stage; bounded by that stage's runtime
Availability single process; crash = restart query from scratch (no mid-query durability)
Replan thrash budget ≤ 1 replan event per stage per input edge (NO-OSCILLATION invariant)
Determinism identical (plan, stats trace) ⇒ identical plan-version sequence + results

Scaling assumptions: single node, 8–128 cores, 32 GiB–1 TiB RAM, NVMe spill. Horizontal scaling deferred (the exchange operator is the seam). Vertical scaling: morsel parallelism + work-stealing; coalescing right-sizes post-shuffle parallelism to avoid tiny-task overhead.
