Frontend Fixture Layer. Converts declarative YAML fixtures (crates/parser_fixture) into validated internal IR; intentionally excludes a production parser to isolate solver complexity from syntax concerns. This is the only external trust boundary — all fixture input is schema-validated before crossing into type_ir (T1).

Type IR Layer. Defines interned, immutable structural representations for every load-bearing entity: types, trait references, obligations, predicates, binders, substitutions, universes. This layer owns the persistence boundary for stable hashing and snapshot serialization (I1, I12); every later layer depends on its determinism.

Canonicalization Layer. Transforms solver inputs into canonical form for memoization and query reuse: universe indexing, de Bruijn shifting, existential-variable abstraction, region erasure. Incorrect canonicalization breaks cache correctness globally (P2, T4).

Solver Engine. Core recursive evaluator: obligation queues, candidate selection, projection normalization, ambiguity handling, cycle detection, fixed-point convergence. The concurrency boundary is query-level parallelism only (§20) — recursive evaluation inside one query context remains deterministic and single-threaded (P1).

Unification Engine. Maintains equivalence constraints between type variables, projections, placeholders, and inference variables; owns occurs checks, snapshot rollback, region compatibility, substitution application (I4).

Incremental Query Layer. Maintains the dependency graph between trait queries and source-program items; owns invalidation propagation, stable hashing, memoized reuse, replay support, deterministic recomputation (§18).

Persistence + Telemetry Layer. Exports traces, proof trees, structured diagnostics, query statistics, replay artifacts, performance counters — the protocol boundary to the outside world (OTLP over localhost, on-disk snapshot format). Enables deterministic debugging and postmortem analysis (§19, §24).

8. Domain Model — Types, Goals & Obligations

Core type lattice:

  • Type
    • Scalar(ScalarType)bool, integer widths, char, unit
    • Tuple(Vec<TypeId>)fixed-arity product
    • Ref(Mutability, TypeId)&T / &mut T
    • Projection(ProjectionType)<T as Trait>::Assoc
    • Param(ParamId)generic parameter, unbound
    • Infer(InferVarId)inference variable, query-local
    • Placeholder(PlaceholderId)universally quantified skolem

Trait reference:

TraitRef { trait_id: TraitId, substitution: Substitution }

Goal states:

State Meaning
Pending not yet evaluated
Evaluating recursively active (on the ancestor stack)
Proven evidence assembled, proof node emitted
Ambiguous insufficient evidence, no contradiction
Error contradiction — no candidate can succeed

Obligation lifecycle:

Pending -> Canonicalized -> CandidateAssembly -> Unification
        -> NestedObligations -> FixedPoint -> {Proven | Ambiguous | Error}

Sequence example (goal T: Iterator against impl<T: Clone> Iterator for Vec<T>):

Input Goal:        T: Iterator
Candidate Search:  impl<T: Clone> Iterator for Vec<T>
Generated Obligation: T: Clone
Nested Solve:       prove T: Clone
Result:             Proven

Malformed example (self-referential blanket impl, the canonical cycle fixture):

impl<T> Foo for T where T: Foo

Expected outcome: recursive cycle detected at the ancestor-stack check (I5); ambiguity emitted, not an infinite loop; proof graph truncated with a cycle marker node.

Projection normalization state machine:

State Transition Failure
Unresolved candidate lookup missing impl → NoSolution
Evaluating recursive projection cycle → ambiguity (I2)
Normalized substitution apply invalid projection shape → Error

EBNF sketch of the declarative fixture surface consumed by crates/parser_fixture (not a real language grammar — a minimal stand-in sufficient to drive the solver):

fixture      ::= impl_decl* trait_decl* goal_decl
trait_decl   ::= "trait" ident generics? supertrait* assoc_decl*
impl_decl    ::= "impl" generics? trait_ref "for" type where_clause?
where_clause ::= "where" bound ("," bound)*
bound        ::= type ":" trait_ref
goal_decl    ::= "goal" bound
