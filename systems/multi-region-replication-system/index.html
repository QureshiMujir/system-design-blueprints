3.2 Subsystem Descriptions

Admin Control Plane. Operator-facing HTTP/gRPC surface for topology changes, replication policy updates, failover initiation, audit retrieval, and compatibility validation. Logically isolated from the replication data path (§6 P12): a control-plane traffic spike must never starve WAL writes or transport sends. Trust boundary: mutual-TLS-authenticated operator identity; no anonymous access.

Cluster Membership Service. Owns cluster epochs, region metadata, peer liveness, topology generations, and capability negotiation, backed by a small Raft metadata log (ADR-19). Persistence boundary: metadata log is the only durable store for topology; membership changes serialize through epoch transitions (§7 I2) to prevent split-brain routing.

Replication Coordinator. Authoritative orchestrator for stream progression, ack aggregation, retry coordination, replay sequencing, and failover-state transitions. Concurrency boundary: one actor per StreamId, no cross-stream shared mutable state, so stream planners never contend on a global lock.

WAL Subsystem. Append-only persistence with deterministic segment ordering, checksum validation, fsync-policy enforcement, replay-cursor tracking, and single-segment corruption isolation. Persistence boundary: nothing is externally acknowledged before an fsync return (§6 P9, §7 I1/I3).

Replication Scheduler. Controls pacing, batching, congestion adaptation, retry windows, inflight quotas, and per-region fairness. Owns the credit-based backpressure queue (§6 P2, §7 I6) that is the system's only defense against unbounded memory growth under WAN stalls.

Snapshot Manager. Large-state synchronization via checkpointed, chunked, resumable snapshots with per-chunk checksum validation and garbage collection of superseded manifests. Persistence boundary: a snapshot is atomic-or-absent (§7 I5) — no partially-visible snapshot is ever exposed to a restore path.

Transport Runtime. Encrypted WAN transport: framing, retransmission, multiplexed replication streams, compression negotiation, connection recovery. Protocol boundary: QUIC/TLS 1.3 (ADR-06, ADR-17); this is the only subsystem that touches raw sockets.

Remote Replica Runtime. Receives ordered mutations, validates stream continuity, persists replicated WAL entries, coordinates replay application, tracks remote durability acknowledgments. Trust boundary: every inbound frame is checksum- and epoch-validated (§7 I2/I3) before it is queued.

Storage Engine Adapter. Delegation boundary — abstraction letting an independent storage engine consume replicated operations while preserving its own transactional semantics; this system never interprets the payload above the WAL frame.

Queue. The scheduler's inflight-quota queue and the transport's bounded send queue are the two load-bearing queues in the diagram; both reject writes past a configured capacity (§7 I6) rather than growing unboundedly.

8. Domain Model — Replication Protocol & Entities

8.1 Core Entities

Entity Description
RegionId globally unique region identifier, stable across the cluster's lifetime
ReplicaId node-level replication identity, unique within a region
StreamId identifies one ordered replication stream (one per source-partition-to-region pair)
EpochId monotonically increasing topology generation number (§7 I2)
WalSequence monotonic per-stream WAL offset, the ordering key for §7 I1
SnapshotId immutable snapshot identifier, opaque outside the snapshot manager
TransactionId mutation transaction boundary marker used by the replay apply queue

8.3 Replication State Machine

State Description
INIT connection initialized, no capability negotiated yet
HANDSHAKE capability and protocol-version negotiation in progress
STREAMING active replication, frames flowing under scheduler control
BACKPRESSURED remote capacity exceeded, sender throttled by credit (§7 I10)
SNAPSHOT_SYNC snapshot transfer underway, WAL streaming paused for this stream
REPLAYING remote is applying buffered WAL entries via the replay engine
DEGRADED partial regional outage, stream alive but lag exceeds §4 budget
FAILED unrecoverable stream failure, awaiting operator or failover FSM action

8.4 Replication Sequence (nominal path)

Client Write -> WAL Append -> Checksum Validation -> Replication Scheduler
   -> Transport Send -> Remote WAL Persist -> Ack Aggregation
   -> Visibility Commit

8.5 Failure Path Example

Region-link interruption sequence: inflight window saturates (§7 I10) → scheduler transitions the affected streams to BACKPRESSURED → sustained saturation past the lag budget (§4) transitions to DEGRADED → if lag exceeds the snapshot-preferable threshold, the coordinator initiates SNAPSHOT_SYNC fallback rather than an unbounded WAL catch-up → snapshot completes, stream transitions to REPLAYING, then back to STREAMING once the replay cursor catches the live WAL tail.

8.6 Malformed Packet Handling

A malformed frame (bad magic, checksum mismatch, unparseable length) triggers, in order: checksum rejection at the transport layer (§7 I3) → peer-strike counter increment (§6 P10) → transport disconnect once the strike threshold is exceeded → structured audit log entry naming the peer, frame offset, and rejection reason, queryable via the admin audit API (§1 Admin Control Plane).
