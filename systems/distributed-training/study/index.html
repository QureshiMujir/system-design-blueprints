34. Mental Models & First Principles

  • MM1 — A collective is a distributed state machine, not an RPC. Predicts that a timed-out all-reduce leaves ranks in unknown, not synchronized, state. Bug class without it: assuming a timed-out collective "mostly happened" and proceeding. Applies in §11 CollectiveOp, §22 Phase 10.
  • MM2 — Sharding trades memory for a de-refresh dance. Predicts that once parameters are really sharded (ZeRO-3), prefetch becomes necessary, not optional. Bug class without it: a naive ZeRO-3 forward that stalls on every module's all-gather. Applies in §18 Phase 6.
  • MM3 — Bit-exactness is a compiler-level discipline, not a testing afterthought. Predicts every reduction order must be fixed at design time, not patched in later. Bug class without it: a correctness suite bolted on after the fact that can never actually pass. Applies in §12 Phase 0, I1 (§7).
  • MM4 — The pipeline bubble is a scheduling problem, not a hardware problem. Predicts 1F1B vs. GPipe is about instruction ordering, not about faster links. Bug class without it: throwing more bandwidth at a bubble that instruction reordering would have fixed for free. Applies in §19 Phase 7.
  • MM5 — Communication volume is conserved across ZeRO stages; only shard residency changes. Predicts ZeRO-2/3's memory wins cost no extra bandwidth. Bug class without it: an engineer expects ZeRO-3 to also cut network load and mis-diagnoses a bandwidth-bound run. Applies in §17 Phase 5, §18 Phase 6, P14 (§6).
  • MM6 — Topology is a graph the planner must consult, never assume. Predicts TP placed across hosts silently tanks throughput. Bug class without it: a working correctness test that is mysteriously 5–10x slow in production. Applies in §6 P2, §20 Phase 8.
  • MM7 — Failure detection has three independent clocks that must be strictly ordered. Predicts a race between NCCL timeout, hang detector, and rendezvous failure-detection if misordered. Bug class without it: the rendezvous tears down the world while NCCL is still trying to recover. Applies in §23 Phase 11.
  • MM8 — Determinism is a global property, not a per-op property. Predicts one non-deterministic kernel anywhere breaks the entire bit-exact chain. Bug class without it: chasing a "flaky" test that is actually a single mis-flagged CUDA kernel. Applies in §12.6 Pitfalls, §13.6 Pitfalls.

Reference Implementations

  • Megatron-LM (megatron/core/parallel_state.py, tensor_parallel/, pipeline_parallel/schedules.py). Lesson: column-/row-parallel operator placement and 1F1B scheduling. Pitfall: parallel_state's global-singleton pattern does not compose with multiple concurrent meshes. Applied in §14, §19.
  • DeepSpeed (deepspeed/runtime/zero/stage_1_and_2.py, stage3.py, partition_parameters.py). Lesson: contiguous-gradient bucketing. Pitfall: bucket size is version-coupled to NCCL buffer reuse in ways that are easy to copy wrong. Applied in §16, §17, §18.
  • PyTorch FSDP (torch/distributed/fsdp/_flat_param.py, _runtime_utils.py). Lesson: flatten-then-shard parameter layout. Pitfall: per-module wrap order is load-bearing and easy to invert. Applied in §18, §35.
  • Colossal-AI (colossalai/zero/, colossalai/shardformer/). Lesson: a cleaner re-implementation clarifies which DeepSpeed choices are essential vs. historical. Pitfall: its shardformer model-registration pattern hides per-architecture logic implicitly. Applied in §11 (shardformer), §35.
  • NCCL (nccl/src/transport/, collectives/, graph/). Lesson: ring-vs-tree algorithm selection by topology. Pitfall: topology auto-detection can mis-classify partial fat-tree fabrics. Applied in ADR-14 (§9), §22 Phase 10.
  • Horovod (horovod/torch/). Lesson: ring-all-reduce as a simple Python API with tensor fusion. Pitfall: default per-tensor all-reduce hurts small-tensor throughput without fusion tuning. Applied in §13 Phase 1, §35.

Glossary (§40) · 44 terms · site-wide glossary

AllReduce
collective that combines values across ranks and returns the result to all.
AllGather
collective that gathers distinct per-rank values into a full copy on every rank.
ReduceScatter
collective that reduces across ranks and scatters distinct shards to each rank.
Ring All-Reduce
bandwidth-optimal all-reduce over a ring topology, 2(N-1)/N data moved per rank.
Tree All-Reduce
all-reduce over a tree topology; lower latency at small message sizes or large N.
Data Parallelism (DP)
replicate the model, shard the data, synchronize gradients.
Tensor Parallelism (TP)
shard a weight matrix's dimension across ranks within one layer.
Pipeline Parallelism (PP)
shard model depth across ranks, pass activations/gradients between stages.
ZeRO
Zero Redundancy Optimizer; progressive sharding of optimizer state (stage 1), gradients (stage 2), parameters (stage 3).
Micro-batch
the smallest unit of forward/backward the trainer schedules.
Gradient Accumulation
summing gradients over multiple micro-batches before an optimizer step.
1F1B
one-forward-one-backward pipeline schedule (PipeDream), minimizing bubble vs. GPipe.
Bubble (pipeline)
the idle-time fraction while the pipeline fills/drains.
Weight Stashing
keeping historical weight versions so a pipelined backward uses the same weights its forward used.
Column-Parallel Linear
a Linear layer sharded along its output dimension.
Row-Parallel Linear
a Linear layer sharded along its input dimension.
Sequence Parallelism
sharding the sequence dimension of activations between TP collectives.
Activation Checkpointing
discarding activations during forward and recomputing them during backward to save memory.
Selective Recomputation
checkpointing only the cheap-to-recompute, memory-heavy activations.
Mixed Precision Training
computing forward/backward in reduced precision (fp16/bf16) with an fp32 master copy.
Loss Scaling
scaling the loss to keep fp16 gradients within representable range.
Process Group
a named, typed handle to a subset of world ranks that participate in collectives together.
Mesh
the mapping of (dp_rank, tp_rank, pp_rank) coordinates to world ranks.
Topology
the physical description of hosts, GPUs, NUMA nodes, and link bandwidths.
Shard
a partition of a tensor or state assigned to one rank.
Reduce-Scatter/All-Gather Duality
the wire-level equivalence between an all-reduce and a reduce-scatter followed by an all-gather.
Prefetch (ZeRO-3)
issuing the next module's parameter all-gather during the current module's compute.
Comm-Compute Overlap
issuing a collective on a separate CUDA stream so it runs concurrently with unrelated compute.
Bucket (gradient)
a fixed-size buffer that batches multiple parameters' gradients into one collective.
Backpressure
bounding the number of in-flight collectives to prevent host memory bloat.
Elastic Training
dynamically changing world size on worker failure/join without restarting from scratch.
Rendezvous
the coordination protocol by which workers agree on membership and world size.
Re-sharding
reconstructing sharded state under a different mesh shape than it was saved under.
MFU (Model FLOPs Utilization)
achieved FLOPs/s divided by peak hardware FLOPs/s.
Bit-Exactness
the property that two runs produce byte-identical outputs given identical inputs and configuration.
NVLink
NVIDIA's high-bandwidth intra-node GPU interconnect.
InfiniBand (IB)
a high-bandwidth, low-latency inter-node network fabric common in GPU clusters.
NCCL
NVIDIA Collective Communications Library, the GPU collective backend.
Gloo
a CPU-capable collective communications backend used as a fallback.
Hang Detector
a subsystem that flags ranks making no step progress within a soft timeout.
Straggler
a rank that is anomalously slow, delaying every collective it participates in.
Shardformer
the module-tree pass that rewrites nn.Linear/nn.Embedding into their tensor-parallel equivalents.
Vocab-Parallel Cross-Entropy
a cross-entropy computation that avoids materializing the full vocabulary-sized logit tensor on every rank.
Deterministic Mode
a PyTorch execution mode that forces deterministic kernel selection at a throughput cost.
