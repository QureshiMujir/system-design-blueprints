32. Back-of-Envelope Capacity Model

  1. Raw bytes/sample = sizeof(ts:i64) + sizeof(value:f64) = 8 + 8 = 16 B/sample (excludes series-id, amortized via chunking) — baseline for M5.
  2. Gorilla-compressed bytes/sample ≈ 1.37 B/sample (Pelkonen et al. 2015's reported production figure, §5) → compression ratio = 16 / 1.37 ≈ 11.7×, clearing the M5 floor of 8×.
  3. Disk/day for N series at 15s scrape interval = N × (86400/15) × 1.37 B = N × 5760 × 1.37 B ≈ N × 7,891 B/day. At the §4 ceiling N = 5,000,000: ≈ 5,000,000 × 7,891 B ≈ 39.5 GB/day raw-tier.
  4. Disk for 15-day raw retention (§4) = 39.5 GB/day × 15 ≈ 592 GB raw-tier steady state, before accounting for compaction's transient write-amplification overhead (§29).
  5. Memory per active series (head) — from M7's ≤ 400 B target: at N = 5,000,000, head-block memory ≈ 5,000,000 × 400 B ≈ 2 GB, exactly matching the §4 head ceiling — confirming the 5,000,000-series ceiling is memory-derived, not arbitrary.
  6. WAL write throughput required = ingestion rate × avg WAL record size. At M1's 400,000 samples/sec and an estimated 24 B/record (ts+value+overhead before framing): 400,000 × 24 B ≈ 9.6 MB/s sustained WAL write bandwidth — well within NVMe sequential-write capability, confirming M4's fsync-latency target is achievable.
  7. (cont'd numbering continues below as distinct derived quantities)
  8. Chunks per 2-hour block (ADR-05's ~120 samples/chunk, 15s interval): a 2-hour block holds 7200/15 = 480 samples/series → 480/120 = 4 chunks/series/block.
  9. Postings-list size for one label value at 100,000-series cardinality (ADR-08, sorted delta-varint, ~1.5 B/entry average after delta-encoding at this density): 100,000 × 1.5 B ≈ 150 KB per label-value postings list — confirms M6's ≤1ms lookup target is achievable (single sequential scan of a 150 KB buffer).
  10. Compaction I/O amplification factor (O'Neil et al. 1996's leveling cost, ADR-09's 2h→2d→2w scheme, 3 levels): each level rewrites its full input once → amplification ≈ 3× total bytes written vs. raw ingestion bytes, informing M8's throughput floor (must exceed 3× ingestion rate to avoid FM-3's backlog).
  11. Downsample storage reduction (5m tier vs. raw 15s): bucket ratio = 300s/15s = 20× fewer samples/series in the 5m tier → 5m-tier disk cost ≈ raw-tier / 20 ≈ 2 GB/day at the same N = 5,000,000, justifying the long-tail retention economics of ADR-23's tiering.
  12. Query fan-out for a 24-hour range query (§4's block duration = 2h raw): 24h / 2h = 12 raw blocks touched minimum per matched series, before any rollup- tier substitution — this is the concrete number MM8 and §19.7's benchmark target against.
