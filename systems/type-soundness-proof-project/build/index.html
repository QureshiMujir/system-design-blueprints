Objectives

⬜ Phase 3 — Inductive rule engine (type checker + derivation checker) §15

Objectives
  • Reify STLC typing as Rule data (T-Var, T-Abs, T-App, T-True, T-False, T-If, T-Zero, T-Succ) — premises + conclusion as Judgments over Term/Type.
  • Executable bidirectional checker: infer(ctx, e) -> Result<Type, TypeError> (synthesize) + check(ctx, e, T) -> Result<(), TypeError> (analyze) on de Bruijn Term.
  • Derivation tree + check_deriv(d, rules) -> Result<(), DerivError>: each node's (premises, conclusion) unifies against a named Rule, subtrees recurse, leaves close.
  • Agreement theorem (testable): infer(ctx,e)=Ok(T) ⟺ ∃ valid Derivation with conclusion Has-Type(ctx,e,T). Soundness + completeness of infer w.r.t. the rules.
  • Context = de Bruijn typing env (Vec<Type>, index 0 = innermost binder), threaded through binder crossings consistently with tsp-term::shift.

  2. check_deriv validates a hand-built Derivation tree against rules(); rejects malformed trees with precise DerivError.
  3. Property test infer ⟺ check_deriv: for generated well-typed terms (Phase 11 Generator preview / hand fixtures), the infer-produced type has a check_deriv-valid Derivation, and vice-versa.

⬜ Phase 4 — Small-step operational semantics (the stepper) §16

Objectives
  • Implement pub fn step(e: &Term) -> Option<Term> in tsp-rules — call-by-value (CBV) small-step; Some(e') = one step taken, None = value-or-stuck. Define the reduction relation as two disjoint rule classes: computation (beta E-AppAbs, E-IfTrue, E-IfFalse) firing on redexes, and congruence/search (E-App1, E-App2, E-If) descending into a unique evaluation-context hole.
  • Pin the value predicate is_value (from tsp-term, Phase 1) as the single arbiter of "done": step never reduces under is_value and never recurses past a value's structure. Make stuck terms detectable + distinguishable from values: step(e)==None && !is_value(e) ⇒ stuck (the configuration progress forbids for well-typed closed e).
  • Keep step and the declared step Rules/check_deriv in lockstep: a separate step_relates(e,e') driver builds the Derivation and asserts check_deriv accepts it — the executable/relational bridge tested in 4.4. (Optional, property-tested) determinism: step is a partial function, so the --> relation is deterministic — at most one e'.
Deliverable

cargo run -p tsp-cli -- step <prog.tm> (subcommand step from section 10) prints the CBV reduction trace e0 --> e1 --> ... --> vn (or ... STUCK at ek) for an object program, one term per line, terminating at a value, a stuck term, or fuel. Library-level: tsp_rules::{step, eval} plus is_stuck/is_normal, with step provably (by test) agreeing with check_deriv on the declared step Rules. The Phase 0 smoke goal step((lam:Bool.0) true) == Some(true) now runs through real step.

Acceptance

  • step(App(TmTrue, TmFalse)) == None && !is_value(App(TmTrue,TmFalse)) ⇒ classified is_stuck (non-function applied).

Pitfalls
  • Fuzz oracle gap — without a reference checker, a too-weak oracle (only "no panic") misses false-acceptances. Root cause: silent unsoundness has no crash. Mitigation: the re-check law + a curated ill-typed corpus that fuzzing mutates; treat any Ok on a known-ill-typed mutant as a hard failure. Debug: minimize with cargo fuzz tmin, print the KTerm + the accepting infer_type path.
  • Non-deterministic counterexamples — unseeded Generator/Shrinker makes broken/*.expected flaky. Root cause: RNG + nondeterministic shrink order. Fix: pin --seed, make Shrinker order total/deterministic; assert the minimal term, not the first found.
  • Coverage illusion from trivial proofs (corpus checks proofs but never exercises whnf/equal conversion branches because proofs are built already-reduced): include fixtures requiring beta/eta conversion at check_type; gate on llvm-cov branch %, not line %.
  • Pretty-print drift (byte-exact diffs break when the de Bruijn printer changes spacing): freeze + unit-test the canonical printer; conformance diffs the structural AST when the printer version bumps. Stack overflow ≠ caught error (adversarial deep KTerm overflows the native stack before DepthLimit fires): thread a depth counter through infer_type/whnf, fuzz with small stack (RUST_MIN_STACK), CI under a 64 MB stack.
  • Bench measuring the wrong thing (Criterion times include LangDef parse or proof construction, not kernel infer_type): pre-build the KTerm in iter_batched setup so only infer_type is in the timed routine. equal non-termination on ill-formed input (definitional equality loops on a cyclic/ill-typed KTerm reached via mutation, since whnf/equal assume well-formedness): a fuel/step budget in equal turns exceeding it into KernelError::ConvBudget, never a hang.
