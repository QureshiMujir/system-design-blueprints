   TRUST BOUNDARY: all in one address space; user code = operator/observer/effect
   closures (untrusted-for-correctness, trusted-for-memory). CONCURRENCY BOUNDARY:
   one logical runtime is single-threaded; Async scheduler hands work to host loop.

Box: Observable<T>. Cold producer; lazy — nothing runs until subscribe. Holds an on_subscribe closure invoked per subscriber (cold) or a shared upstream (hot, via Subject). Returns a Subscription. Boundary: every subscription is an independent producer instance for cold sources. Owns nothing globally; lifetime tied to its subscribers.

Box: Operator chain. Built by lift: each pipeable operator wraps an upstream Observable and returns a new one whose subscribe installs an intermediate Operator observer that transforms/filters/multiplexes emissions before forwarding downstream. Pure structural composition; no scheduling decisions except where operator semantics require (e.g. observeOn). Boundary: operator state is per-subscription, never shared across subscribers of a cold source.

Box: Observer<T> sink. Terminal consumer. Wrapped by a grammar guard enforcing next* (error|complete)?: after a terminal, further on_next/terminals are dropped (and asserted in debug). On terminal, triggers teardown. Boundary: the grammar guard is the single chokepoint that makes the observable contract a runtime invariant, not a convention.

Box: ReactiveGraph / Runtime. The signal-side authority. Owns the NodeId table, each node's Rank/Height (topological order), dependency-set (upstream) and observer-set (downstream), and node state {Clean, Check/MaybeDirty, Dirty, Computing}. Auto dependency tracking: while a Computed/Effect runs, reads register dynamic edges. Boundary: all signal mutation flows through the runtime so propagation can be ordered and batched.

Box: Propagation Engine (glitch-free). On Signal::set, marks downstream dirty/Check, then within the current Batch, recomputes affected nodes in rank order (or push-pull: mark dirty, pull on demand in topo order), guaranteeing each node recomputes at most once per batch with a consistent input snapshot. This box implements the project's central property. Boundary: a Batch/Transaction is the glitch barrier — no observer sees intermediate state.

Box: Scheduler. Decides when queued work runs. Immediate (synchronous, reentrant-guarded), Queue (trampoline — drains a work queue to bound recursion), Async (defers to host microtask/timer), AnimationFrame (stub hook), Test (virtual-time clock; deterministic). subscribeOn controls where subscription happens; observeOn controls where emissions are delivered. Boundary: schedulers are the only place wall-clock/async enters; everything else is deterministic given a scheduler.

Box: Subscription / Teardown registry. Tracks active subscriptions; teardown is idempotent and frees all resources (inner subscriptions, timers, buffers). State machine {Idle, Subscribed, Unsubscribed, Errored, Completed}. Boundary: this registry is where leak detection observes whether every subscription reached a terminal/disposed state.

Box: Disposal & Leak Tracking. Wraps observers as Weak where appropriate (e.g. multicast subscribers), auto-disposes inner subscriptions on terminal, and in debug builds asserts the live-subscription count returns to baseline after a pipeline completes. Boundary: the only component allowed to reach across push/signal sides for cleanup; hosts the interop bridges.

Box: Backpressure. Implements Reactive Streams: Publisher.subscribe(Subscriber), Subscription.request(n) demand accounting, bounded buffers, overflow strategies {drop, latest (keep-newest), buffer (until bound), error}. Boundary: the only path with explicit demand; push operators that cross into a bounded Subscriber must honor demand or apply an overflow policy.

Box: Observability / TestKit. Marble-string parser (--a--b--c|), TestScheduler with virtual clock, propagation tracer (per-batch node recompute log), leak asserts, metric counters (emissions, recomputes, batches, glitches-detected-should-be-zero). Boundary: read-only over the runtime except for the Test scheduler which replaces the clock.

8. Domain Model

8.1 Observable emission grammar (EBNF)

stream        = emission* terminal? ;
emission      = "next" "(" value ")" ;
terminal      = error | complete ;
error         = "error" "(" err ")" ;
complete      = "complete" ;
(* hard rule: nothing may follow a terminal on the same stream *)
(* legal:   next next complete | next error | complete | error | (empty) *)
(* ILLEGAL: next complete next | complete complete | error next *)

Marble alphabet (TestKit parser): - = 1 virtual frame (no emission); a..z/0..9 = next(value); | = complete; # = error; () = synchronous group in same frame; space = ignored. Subscription marble: ^ = subscribe point, ! = unsubscribe point.

8.2 Signal-graph model

Node kinds:  Signal (root, externally writable, no deps)
             Computed (derived; deps tracked dynamically; memoized; pull)
             Effect (leaf; deps tracked; side-effecting; push)

Edges:       dependency edge  dep -> dependent  (dependent reads dep)
             observer edge    dep -> observers   (reverse, for invalidation)

Per node:    NodeId (dense index), Rank/Height (u32, topo order),
             state {Clean, Check, Dirty, Computing}, value cache (Computed/Signal),
             dep_set (current run's reads), observer_set, generation stamp.

Rank rule:   rank(node) = 1 + max(rank(dep) for dep in dep_set), Signals rank 0.
             Re-ranked lazily when dynamic deps change (see §10).

State-transition table — Computed node:

From Event To Action
Clean a dependency changed (direct) Dirty enqueue for recompute (or mark, if lazy)
Clean a transitive dependency might have changed Check verify deps before recompute
Check all deps verified Clean & unchanged Clean skip recompute (push-pull cutoff)
Check some dep actually changed Dirty proceed to recompute
Dirty recompute begins Computing clear dep_set; run; re-track deps
Computing recompute ends, value changed Clean mark observers Dirty/Check
Computing recompute ends, value unchanged Clean do NOT propagate (I11)
any dependency cycle detected Errored emit cycle path (I6)

State-transition table — Subscription:

From Event To Notes
Idle subscribe() Subscribed run on_subscribe; register teardown
Subscribed on_next Subscribed grammar guard passes value
Subscribed on_complete Completed run teardown (I2)
Subscribed on_error Errored run teardown; propagate err
Subscribed unsubscribe() Unsubscribed run teardown
Completed/Errored/Unsubscribed any signal (same) dropped (I1); debug-assert
Unsubscribed unsubscribe() Unsubscribed idempotent no-op (I2)

8.3 Worked examples (ASCII marble diagrams)

map(x => x+1):
  src:    --a--b--c|        (a=1,b=2,c=3)
  out:    --2--3--4|

filter(odd):
  src:    --1--2--3--4|
  out:    --1-----3---|

scan((acc,x)=>acc+x, 0):
  src:    --1--2--3|
  out:    --1--3--6|

merge:
  s1:     --a-----c--|
  s2:     -----b-----d|
  out:    --a--b--c--d|     (interleave by arrival; per-source FIFO kept)

concat:
  s1:     --a--b|
  s2:           --c--d|      (s2 not subscribed until s1 completes)
  out:    --a--b--c--d|

combineLatest:
  s1:     --1-----3----|
  s2:     ----a-----b--|
  out:    ----1a--3a-3b-|    (emits only after BOTH produced; pairs latest)
              ^ first emission waits for s2's first value (PITFALL)

zip:
  s1:     --1--2--3|
  s2:     ----a----b----c|
  out:    ----1a---2b---3c|  (pairwise by index)

switchMap(x => inner(x)):
  src:      --x-------y----|
  inner(x): --x1--x2--x3|
  inner(y):           --y1--y2|
  out:      ---x1--x2--y1--y2|  (inner(x) UNSUBSCRIBED when y arrives — PITFALL if not)

mergeMap (concurrent inners kept):
  out:      ---x1--x2-x3/y1--y2|  (all inners alive)

concatMap (inners queued):
  out:      ---x1--x2--x3--y1--y2|

exhaustMap (drop new while inner active):
  out:      ---x1--x2--x3------|  (y dropped because inner(x) still active)

Diamond / glitch-freedom (signal side):

   A          A := 1
  / \         B := A + 1     (rank 1)
 B   C        C := A * 10    (rank 1)
  \ /         D := B + C     (rank 2)
   D

set A = 2:
  WRONG (depth-first push):  D recomputes after B (=3, C still 11) -> 14 (GLITCH),
                             then again after C (=20) -> 23.  Two fires, one wrong.
  RIGHT (rank-ordered batch): mark B,C,D dirty; recompute rank1 {B=3,C=20};
                             recompute rank2 {D=23}.  D fires ONCE, value 23.

Design principles (§6)

  • Glitch freedom is non-negotiable. No Computed/Effect ever observes a partially-updated input set. Tradeoff: topological ordering/batching → some propagation latency vs naive depth-first push. Operationally: a glitch is a P0 bug; the tracer counts glitches_detected and it must stay 0. Violation: diamond D fires twice or with one stale input → cascading wrong derived state, double side effects.
  • Each reactive node recomputes at most once per batch. Corollary of (1) plus dirty de-duplication. Tradeoff: must track a per-batch "already computed" generation. Violation: redundant recompute → wasted CPU and, if effects are involved, duplicated side effects (double network calls).
  • The Observable grammar is a runtime invariant, not a convention. Emissions obey next* (error|complete)?; nothing after a terminal. Enforced centrally by the grammar guard. Violation: an operator leaking on_next after on_complete → downstream state corruption, "impossible" values.
  • Teardown is total and idempotent. Every Subscription::unsubscribe frees all owned resources exactly once; second call is a no-op. Tradeoff: bookkeeping per subscription. Violation: leaked inner subscriptions in switchMap → unbounded memory + zombie side effects.
  • Cold by default, hot by explicit multicast. A bare Observable re-runs its producer per subscriber; sharing requires a Subject/share. Tradeoff: predictability vs accidental duplicate work. Violation: assuming a cold source is shared → duplicated HTTP/side effects per subscriber.
  • Determinism via the scheduler boundary. All async/wall-clock enters only through a Scheduler; the Test scheduler makes time virtual and reproducible. Tradeoff: operators thread a scheduler rather than calling setTimeout directly. Violation: a hidden sleep/timer → flaky, non-reproducible tests.
  • Bounded recursion via explicit work queues. Long operator chains and deep propagation use an explicit queue/trampoline, never native recursion. Tradeoff: queue-management overhead. Violation: synchronous Immediate scheduler recursing through a 1e6-length chain → stack overflow crash.
  • Backpressure honored or explicitly dropped. Where demand exists (Reactive Streams), producers respect request(n); where it cannot (hot push into bounded sinks), an explicit overflow policy applies. Tradeoff: complexity of demand accounting. Violation: ignoring demand → unbounded buffer growth → OOM.
  • Ownership makes lifetimes explicit. Strong edges keep producers alive while subscribed; Weak edges (multicast observers) prevent reference cycles; Drop performs teardown. Tradeoff: Rc/RefCell runtime cost vs GC convenience. Violation: a strong cycle Signal↔Computed → leak that never drops.
  • Push and pull are unified, not duplicated. One graph; effects are pushed (must run), memos are pulled (recompute on demand). Tradeoff: a single state machine serves both. Violation: two divergent engines → glitches at the seam (an effect reading a not-yet-pulled memo).
  • Equality cutoff stops needless propagation. A Computed whose new value equals the old (by configurable PartialEq) does not propagate to its dependents. Tradeoff: store previous values + an equality call. Violation: omitting cutoff → a constant-valued recompute storms the whole subgraph.
  • Reentrancy is scheduled, never recursive. Setting a signal inside an effect schedules a follow-up batch (or joins the current one) rather than recursing. Tradeoff: a "current vs next batch" decision. Violation: naive recursion → infinite loop / stack overflow on self-referential effects.
  • Cycles are detected and reported, never silently looped. A dependency cycle (A→B→A) is detected at propagation time and either errors or resolves to a defined fixpoint policy. Tradeoff: detection cost (coloring/generation check). Violation: undetected cycle → infinite recompute loop, frozen runtime.
  • Observability by default. Every batch, recompute, emission, subscription transition, and overflow is countable/traceable. Tradeoff: counter overhead (compiled out in release where possible). Violation: a silent runtime → unfalsifiable glitch/leak claims.
  • Per-stream FIFO ordering preserved. Within a single source/operator, emissions retain order; combination operators define ordering explicitly. Tradeoff: schedulers must be order-preserving queues. Violation: reordered emissions → scan/reduce produce wrong aggregates.
