3. Architectural Overview

3.2 Subsystem Descriptions

dret-cli — entry point; parses subcommand (record, replay, dump, pack, ps); validates arguments; constructs RecordSession or ReplaySession; owns process lifetime; propagates exit codes. Trust boundary: the only component with direct user input; validates paths and permissions before delegating.

dret-record (supervisor loop) — forks tracee under PTRACE_TRACEME; installs seccomp-BPF filter; drives the waitpid(2) event loop; dispatches each stop (syscall entry, syscall exit, signal-delivery, clone, exec, death) to dret-syscall / dret-sched / dret-time / dret-mem for annotation; writes each TraceFrame to dret-trace. Data in: ptrace stops (waitpid status words). Data out: TraceFrame stream to dret-trace. Concurrency boundary: single OS thread in the supervisor; tracee threads are individually stopped and resumed under PTRACE_CONT or PTRACE_SYSEMU. Does not hold any GFDs that the tracee will inherit.

TRACEE process [thread 1..N] — the untrusted program under observation. Constrained by seccomp-BPF to emit SECCOMP_RET_TRACE on a selected syscall subset. Never modified in memory by the recorder except for vsyscall page patching (Phase 10). Each thread has a separate ptrace attachment, a separate Ticks counter, and a separate TraceWriter stream segment.

dret-sched — implements the single-logical-CPU abstraction during recording. Maintains a run-queue of (TaskId, Ticks, state) tuples. At each SchedPoint it picks the next thread deterministically (by TaskId, breaking ties by ticks). Records SchedSwitch events so replay can apply identical switch order. Intercepts futex FUTEX_WAIT/WAKE to record the total ordering of futex operations. On replay, enforces I6: exactly one task runnable at any instant.

dret-syscall — owns the x86-64 syscall ABI table (syscall number → name, arg types, pointer-range effects, return semantics). At syscall-entry stop: reads rax (nr), rdi/rsi/rdx/r10/r8/r9 (args); classifies pointer args; computes MemRange list for args that name memory written by the kernel. At syscall-exit stop: reads rax (ret) and reconstructs errno. Returns SyscallRecord for dret-record to serialize. Pure decode logic; no OS calls beyond ptrace register reads.

dret-time — manages one perf_event_open file descriptor per tracked task, configured for PERF_COUNT_HW_BRANCH_INSTRUCTIONS (retired conditional branches). Reads counter via ioctl PERF_EVENT_IOC_RESET/ioctl at each ptrace stop. Provides read_ticks(tid) → Ticks. Implements overcount/skid correction: after a hardware overflow interrupt, adjusts the Ticks value backward by the measured skid. The Ticks value is the sole addressing mechanism for positions in the trace; it must be monotonically non-decreasing per task (I2).

dret-mem — reads tracee memory via /proc/pid/mem pread(2) after each syscall-exit stop, for ranges named in MemRange list from dret-syscall. Produces MemDelta { range, bytes_ref } written into data.log via DataRef. Manages COW page snapshots for Checkpoint: on checkpoint request, reads all dirty pages since last checkpoint, hashes each page, stores (MemRange, PageRef) list. On replay, provides pwrite(2) injection of recorded page contents.

dret-trace — the persistence layer. events.log: fixed-size framed records (EventId u64, tid u32, ticks u64, kind u8, regs[144 bytes], data_ref u64, crc32 u32). data.log: variable-length payloads at DataRef offsets (memory snapshots, checkpoint dirty pages). mmap.log: address-space change records (mmap/munmap/mremap/brk/exec). ckpt/: one directory per checkpoint, named by EventId. All writes are append-only; fsync at checkpoint boundaries (P7). Forward-compatible: unknown field tags skipped by older readers (P8).

dret-replay — reads TraceReader; re-execs the same binary under ptrace PTRACE_SYSEMU; at each PTRACE_SYSEMU stop, injects the recorded syscall result (write rax = ret; pwrite memory effects into tracee via /proc/pid/mem; call PTRACE_SETSIGINFO for recorded signals). Consumes events in strict EventId order (I3). Enforces I4: injected ret == recorded ret. Enforces I5: no real syscall executes during injection. After each event, delegates to dret-divergence for register/tick/mem-hash comparison.

dret-divergence — compares (RecordedRegs, Ticks, touched-page SHA-256) from replay execution vs stored values in TraceFrame. On first mismatch, emits DivergenceReport and aborts replay (P6). Provides bisect mode: binary search on EventId range to find first divergent event. Used in Phase 12 to validate the entire replay pipeline against a conformance corpus.

dret-gdb — listens on a TCP port for GDB remote serial protocol connections. Maps gdb 'c' (continue) → replay-forward; 's' (step) → replay single event; 'bs' (reverse-step) → seek to (event_id − 1) via checkpoint rewind + replay-forward; 'bc' (reverse-continue) → binary-search backward for watchpoint/breakpoint hit. Exposes register reads ('g'), memory reads ('m'), and breakpoints ('Z0') as views into the current replay position. Has no write-back path to the trace; all mutations are in replay session state only.

8. Domain Model

8.1 Core Entities and Relationships

  • RecordSession
  • 1──* TaskRecord { TaskId, Tid, initial_regs, entry_ticks }
  • 1──* TraceFrame { EventId, Ticks, TaskId, EventKind, RecordedRegs, DataRef }
  • 1──1 AddressSpace (per-process snapshot, updated on mmap/munmap/brk)
  • 1──N Checkpoint (periodic; anchored to EventId boundary)
  • TraceFrame
    • ├── Syscall → SyscallRecord { nr, args[6], ret, mem_effects: Vec<MemDelta>, errno }
    • ├── Signal → SignalRecord { signo, si_code, deterministic: bool, delivery_ticks }
    • ├── SchedSwitch → SchedPoint { tid, ticks }
    • ├── RdtscTrap → { recorded_tsc: u64 }
    • ├── CpuidTrap → { leaf, subleaf, eax, ebx, ecx, edx }
    • ├── PatchVsyscall → { page_addr, slot }
    • ├── Exec → { path_ref: DataRef, argv_ref: DataRef, envp_ref: DataRef }
    • ├── Exit → { tid, exit_code }
    • └── Checkpoint → { checkpoint_id: u64, event_id: EventId }
  • Checkpoint
    • ├── regs_per_task: Map<TaskId, RecordedRegs>
    • ├── dirty_pages: Vec<(MemRange, PageRef)>
    • ├── fd_table: Vec<FdRecord>
    • ├── mmaps: Vec<MmapEntry>
    • └── brk: u64

8.2 EventKind Taxonomy

EventKind Source trap Recorder action Replayer action
Syscall PTRACE_SYSCALL stop (exit) record nr, args, ret, mem_effects PTRACE_SYSEMU; inject ret + mem writes
Signal(sync) SIGSEGV/SIGFPE/SIGILL fault record signo, si_code, regs at fault re-raise at same rip; no tick pinning
Signal(async) SIGINT/SIGUSR1/… delivered async pin to (tid, delivery_ticks) step to delivery_ticks, PTRACE setsiginfo
SchedSwitch tick-budget exhausted record (old_tid, new_tid, ticks) force same switch at same ticks
RdtscTrap CR4.TSD=1 or seccomp SIGSEGV record GPR snapshot + tsc value inject recorded eax:edx
CpuidTrap seccomp or UD#; leaf/subleaf record four output regs inject recorded eax/ebx/ecx/edx
PatchVsyscall vsyscall page rip intercept record slot; rewrite to int 0x80 path same patch applied on replay binary
Exec PTRACE_EVENT_EXEC record path + argv + envp verify replayed exec matches
Exit PTRACE_EVENT_EXIT record exit_code; close task entry expect same exit code
Checkpoint periodic / forced flush dirty pages; snapshot fd_table restore for seek/reverse ops

8.3 Ticks (RCB) State Machine per TaskId

States: UNBORN → RUNNING → BLOCKED → RUNNABLE → RUNNING → … → DEAD
Transitions:
  UNBORN     --[clone/exec trap]--> RUNNING    (Ticks reset to 0 at exec)
  RUNNING    --[syscall entry]----> RUNNING    (ticks read at PTRACE stop)
  RUNNING    --[tick budget 0]----> BLOCKED    (SchedSwitch emitted; another task scheduled)
  BLOCKED    --[sched grant]------> RUNNABLE   (new tick budget assigned)
  RUNNABLE   --[PTRACE_CONT]------> RUNNING
  RUNNING    --[exit trap]---------> DEAD
  • Ticks are read via ioctl(PERF_EVENT_IOC_RESET) / read() on the per-task perf fd at every PTRACE stop.
  • Ticks(RCB) is monotonic non-decreasing within a TaskId (I2); wrapping to zero only at exec.
  • The scheduler grants a tick_budget from SchedPoint.ticks to the next SchedSwitch ticks; it uses PERF_EVENT_IOC_RESET + overflow signal to preempt at the exact boundary.

8.4 Trace-on-Disk Layout

TRACE_DIR/
  header.json          — { version, arch, record_pid, start_time_ns, task_count }
  events.log           — append-only; fixed-stride frames or length-prefixed if variable
  data.log             — variable-length blobs; DataRef = byte offset
  mmap.log             — AddressSpace deltas (mmap/munmap/mremap/brk) in order
  checkpoints/
    ckpt_<event_id>/
      regs.bin         — per-task RecordedRegs (fixed layout)
      pages.bin        — dirty pages: (addr:u64, len:u32, data_ref:u64) per entry
      fd_table.bin     — FdRecord list
      mmap_snapshot.bin— full AddressSpace at this checkpoint

events.log frame wire layout (little-endian):

 0       4       8      12      16      24      32      40     48     56     64
[magic:4][len:4][crc:4][eid:8][tid:4][ticks:8][kind:1][pad:3][regs:N][dref:8][tag-fields...]
  • magic = 0x44524554 ("DRET")
  • len = total frame byte count including header
  • crc = CRC-32C over bytes [12..len]
  • eid = EventId (u64, strictly +1 from prior)
  • ticks = Ticks at this event
  • regs = RecordedRegs (17 × u64 = 136 bytes for GPRs + rip + rflags + fs_base + gs_base + orig_rax)
  • dref = DataRef into data.log (0 if no payload)
  • tag-fields = kind-specific payload if small enough to inline (max 32 bytes); else DataRef

data.log blob entry:

[len:4][crc:4][payload:len]
  • Blobs are referenced only by DataRef offset; no reverse index in data.log itself.
  • TraceReader builds an in-memory EventId→offset index on first open; checkpointed to events.idx after pack.

mmap.log entry:

[eid:8][kind:1 (Map|Unmap|Remap|Brk)][addr:8][len:8][prot:4][flags:4][offset:8][path_ref:8]

8.5 RecordedRegs Layout

Field Width Notes
rax u64 return value at syscall exit
rbx–r15 u64×13 general-purpose
rip u64 instruction pointer at stop
rflags u64 including TF (trap flag) state
fs_base u64 TLS base; captured via PTRACE_GETREGSET
gs_base u64 alternate TLS / per-cpu (user-space only)
orig_rax u64 syscall number at entry stop

Total: 17 × 8 = 136 bytes. Stored verbatim in each TraceFrame.

8.6 SyscallRecord Semantics

SyscallRecord {
  nr:          u32,                  // syscall number (x86-64 ABI)
  args:        [u64; 6],             // rdi, rsi, rdx, r10, r8, r9 at entry
  ret:         i64,                  // rax at exit (negative = -errno)
  errno:       i32,                  // decoded errno or 0
  mem_effects: Vec<MemDelta>,        // each region kernel wrote into tracee
}
MemDelta { range: MemRange, bytes_ref: DataRef }
  • Pointer args classified by dret-syscall ABI table: IN (read by kernel), OUT (written by kernel), INOUT, or SCALAR.
  • Only OUT/INOUT ranges with non-zero len produce MemDelta entries.
  • mem_effects captured by reading /proc/pid/mem at the PTRACE syscall-exit stop, before PTRACE_CONT.
  • On replay: write each MemDelta.bytes into tracee address range.addr via PTRACE_POKEDATA or /proc/pid/mem pwrite.

8.7 Signal Determinism Model

Signal class Examples Determinism strategy
Synchronous SIGSEGV, SIGFPE, SIGILL Caused by exact rip/instruction; replays without pinning
Async hardware SIGALRM, SIGIO Pinned to (tid, delivery_ticks); replayer steps to that tick
Async software kill(2), tkill, tgkill Same; sender tid + ticks also recorded (I8)
SIGCHLD child state change Pinned; note: pid remapping required on replay
  • SignalRecord.deterministic == true for sync signals (no tick injection needed).
  • SignalRecord.deterministic == false requires replayer to single-step tracee until Ticks == delivery_ticks, then inject via PTRACE_SETSIGINFO + PTRACE_CONT.
  • Nested signals: recorded in event order; replayer re-queues in same order.

8.8 Scheduler Serialization Semantics

RunQueue (replay):
  - ordered list of (TaskId, tick_budget)
  - head task = currently running
  - tail tasks = blocked at PTRACE stop

SchedSwitch event:
  { prev_tid, next_tid, prev_ticks, next_ticks_start }
  • All threads held at PTRACE stops except the running one (I6).
  • Tick budget = next_switch.ticks - current.ticks; perf overflow at budget end causes SIGTRAP.
  • Futex record: futex(2) exit recorded with {uaddr, op, ret}; replayer injects at same position, unblocking waiter at the recorded ticks.
  • sched_setaffinity called in tracee's namespace to pin to CPU 0; supervisor ignores the call during replay (injects ret=0).

8.9 Checkpoint Model

Checkpoint creation triggers:
  - Every K events (default K=50,000; tunable)
  - Before exec, exit, and dlopen (mandatory)
  - Forced by CLI: `dret pack --checkpoint-interval`

Seek semantics:
  target_event_id E:
    1. Find largest Checkpoint C where C.event_id <= E
    2. Restore: write C.regs_per_task, C.dirty_pages, C.mmaps, C.fd_table into replay process
    3. Replay-forward from C.event_id to E consuming events in order
    4. On reverse-step: seek(E-1); on reverse-continue: seek(last watchpoint hit before E)
  • I7: Checkpoint is always placed on an event boundary; C.event_id points to the TraceFrame emitted immediately before the snapshot.
  • Dirty pages: union of all pages written since prior Checkpoint; stored as (addr, PageRef→data.log).
  • FdRecord: { fd, kind: File|Pipe|Socket|Epoll|…, path_or_peer, flags, offset }. Sockets recorded as closed/unrestorable on replay if not AF_UNIX.

8.10 Address-Space Model

AddressSpace {
  segments: Vec<Segment { addr, len, prot, flags, offset, MmapProvenance }>,
  brk:      u64,
}
MmapProvenance: { path: Option<DataRef>, build_id: Option<[u8;20]>, inode: u64, dev: u64 }
  • Updated on every mmap/mmap2/munmap/mremap/brk/mprotect syscall exit.
  • On replay: mmap calls with MAP_FIXED to reproduce layout (I10); file-backed mappings resolved from packed trace or host filesystem by build-id.
  • ASLR disabled in tracee via personality(ADDR_NO_RANDOMIZE) at record and replay start.
  • [vvar]/[vdso] pages: vsyscall patch applied at exec (PatchVsyscall event); vDSO remapped to supervisor-controlled page on replay.

8.11 Replay Injection Semantics

Sequence per Syscall event during replay:

1. PTRACE_SYSCALL → stop at syscall entry
2. Read syscall nr from orig_rax; verify == recorded nr (else DivergenceReport)
3. PTRACE_SYSEMU → tracee does not execute syscall; stops again at entry
4. Set rax = SyscallRecord.ret in tracee regs via PTRACE_SETREGS
5. For each MemDelta: pwrite /proc/pid/mem at range.addr with bytes from data.log
6. Verify RecordedRegs (I9): read regs; hash vs stored; on mismatch → DivergenceReport
7. PTRACE_CONT
  • PTRACE_SYSEMU replaces both entry and exit stops with a single combined stop; replayer uses the exit-equivalent position.
  • errno encoded in rax as -(errno) per Linux x86-64 ABI; replayer sets rax directly.
  • write(2), read(2), pread(2): inject ret + any OUT buffers; actual file I/O suppressed.

8.12 RdtscTrap and CpuidTrap Injection

Trap Mechanism Record Replay injection
RDTSC / RDTSCP CR4.TSD=1 via seccomp-BPF SIGSEGV or ptrace UD read eax:edx + rcx (rdtscp) PTRACE_SETREGS eax:edx[:rcx]; skip instr
CPUID seccomp BPF traps to supervisor record leaf, subleaf, 4 outputs PTRACE_SETREGS; advance rip by 2
gettimeofday(vDSO) vsyscall page rewrite + PatchVsyscall event recorded as Syscall nr=96 injected as normal SyscallRecord
clock_gettime(vDSO) same recorded as Syscall nr=228 injected as normal SyscallRecord
  • On replay: rip advanced past the faulting instruction length (RDTSC=2, CPUID=2 bytes).
  • CPUID masking: replayer applies a feature mask table to prevent tracee from detecting host CPU differences; recorded leaf/subleaf values win.

8.13 Divergence Detection State Machine

States: CLEAN → DIVERGED → ABORTED
Transitions:
  CLEAN    --[event E: regs match + ticks match + mem_hash match]--> CLEAN
  CLEAN    --[event E: any mismatch]-----> DIVERGED (emit DivergenceReport)
  DIVERGED --[--strict mode]--> ABORTED  (replay process killed)
  DIVERGED --[--lenient mode]--> CLEAN   (resync regs; continue; increment mismatch_count)
  • Default mode: --strict (P6: fail closed).
  • DivergenceReport { event_id, kind: RegMismatch|TickMismatch|MemHashMismatch, expected, actual, task_id }.
  • mem_hash: xxhash3 of pages touched by syscall mem_effects at exit stop (record side) vs identical pages post-injection (replay side).

8.14 gdbserver RSP Interaction Model

GDB client <──RSP over TCP/Unix──> dret-gdb stub <──> ReplaySession
  • Supported packets: ?, g/G, m/M, c/s, vCont, qXfer:features, Z0/Z1 (sw/hw breakpoint), Z2/Z3/Z4 (watchpoints via mem-delta scan).
  • Reverse packets: bc (reverse-continue), bs (reverse-step) — mapped to checkpoint_seek(event_id - 1) + replay-forward.
  • Thread list: qfThreadInfo returns all recorded TaskIds; Hg<tid> selects focus task.
  • Watchpoints on replay: no hardware DR registers; replayer re-runs from nearest checkpoint scanning for writes to watched address range; first hit = watchpoint event.
  • No side effects: M (memory write) during replay session updates only the replayer's tracee; does not persist to trace (P2).

8.15 Worked Example — Normal Syscall Record/Replay

Record side:

tracee calls: read(fd=3, buf=0x7fff1000, count=4096)
PTRACE_SYSCALL entry stop: orig_rax=0, rdi=3, rsi=0x7fff1000, rdx=4096
  → record args; continue tracee
PTRACE_SYSCALL exit stop:  rax=512 (bytes read)
  → record SyscallRecord{ nr=0, args=[3,0x7fff1000,4096,0,0,0], ret=512, errno=0 }
  → read /proc/pid/mem at [0x7fff1000, 512): capture 512 bytes → data.log offset D1
  → MemDelta{ range={0x7fff1000,512}, bytes_ref=D1 }
  → emit TraceFrame{ eid=42, tid=T1, ticks=8103, kind=Syscall, dref=DataRef(D0) }
     where D0 = serialized SyscallRecord pointing to D1

Replay side:

event 42: PTRACE_SYSEMU stop; orig_rax=0 ✓
  → set rax=512 via PTRACE_SETREGS
  → pwrite /proc/pid/mem at 0x7fff1000 ← 512 bytes from data.log[D1]
  → read regs; compare vs RecordedRegs stored in frame 42 → match (I9)
  → PTRACE_CONT
  → ticks after event = 8103 ✓ (I2 monotonic)

8.16 Malformed/Failure-Path Example — EventId Gap

Scenario: recorder killed between writing frame 99 and frame 100; data.log has partial blob.

TraceReader open:
  scan events.log frames: frames 0–99 valid CRC; frame 100 truncated (len field reads 0xFFFFFFFF)
  → detect: eid[99]+1 != eid[100] — gap detected
  → mark trace as TRUNCATED_AT(99)
  → TraceReader.last_valid_event_id() = 99

Replay attempt to event 150:
  → ReplaySession::seek(150) → error: TraceError::TruncatedTrace { last_valid: 99 }
  → CLI prints: "trace truncated at event 99; replay available up to event 99"

P7 (crash-only recorder): prefix 0..99 is valid and replayable.

8.17 Edge Cases

Edge Case Handling
fork + exec in child PTRACE_EVENT_FORK creates new TaskId; Exec event resets Ticks to 0 for that TaskId
vfork with parent blocked Parent PTRACE stop held until child exec/exit; recorded as vfork event pair
Large mmap anonymous region AddressSpace updated; dirty-page tracking deferred until first write fault (COW)
mmap(MAP_FIXED) over existing mapping Old segments removed from AddressSpace; new segment inserted
Signal during syscall (EINTR) Signal recorded before interrupted-syscall retry; replay delivers signal first
ptrace(2) by tracee Supervisor intercepts; returns EPERM (tracee cannot have its own sub-tracee)
seccomp already installed by tracee Supervisor detects on exec; emits warning; compatibility depends on seccomp filter chain
Ticks skid (hardware overcount) dret-time applies skid correction: step backward by 1–4 ticks, re-measure
Nested clone (thread → thread) Each clone creates new TaskId; tick counter initialized from perf_event_open at clone
execve with O_CLOEXEC fds FdRecord marks cloexec fds as closed at exec boundary in Checkpoint
CPUID with unknown leaf All four output registers recorded verbatim; no semantic interpretation needed
Very long mem_effects (>1 MB write) Chunked into 4 KB MemDelta entries; DataRef chain; no single blob exceeds 1 MB
