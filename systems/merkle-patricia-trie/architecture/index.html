Secure Trie / Coordinator — owns mutation orchestration and the mandatory keccak256(key) boundary (ADR-16); single-writer, snapshot-isolated readers (ADR-22).

Path Encoder — nibble conversion, hex-prefix compact encoding, odd/even parity flag management (§8, I3).

Hashing Engine — node RLP serialization, embedded-vs-hashed decision at the 32-byte threshold (I2, ADR-19), deterministic Keccak-256 root computation.

Proof Engine — inclusion/exclusion proof capture and stateless verification; treats proofs as a first-class output (P5), not a derived afterthought.

Node Graph — the canonical authenticated structure: branch (17-slot), extension (compressed shared path), leaf (terminal), and the NodeRef embedded-vs-hash duality.

RLP Serialization Layer — consensus-critical canonical codec; rejects any non-minimal length prefix (I10) rather than merely warning.

Journal / Snapshot Layer — append-only WAL, O(1) checkpoint markers (not full data copies, MM8), and crash-safe replay.

Storage Backend — backend-agnostic (P7) content-addressed persistence behind the NodeStore trait; in-memory for tests, RocksDB for production (ADR-05).

Pruning / GC — reference-counted mark-and-collect gated on all live snapshot roots (I4, I13, P12).

8. Domain Model / Protocol / Data Model

Node Types

Node Shape Semantics
Branch 17-slot list: 16 child NodeRef slots (nibble 0–F) + 1 optional value fan-out point
Extension (compact_path, child NodeRef) compresses a shared nibble run with a single child
Leaf (compact_path, value) terminal key/value pair
Empty zero-length RLP (0x80) canonical empty subtree

Hex-Prefix (Compact) Encoding — Flag Nibble

Node Kind Path Nibble-Length Parity Flag Nibble (high nibble of first byte)
Extension even 0x0
Extension odd 0x1
Leaf even 0x2
Leaf odd 0x3

If the path length is odd, the first data nibble is packed into the low nibble of the flag byte; otherwise a 0x0 padding nibble fills that slot (Yellow Paper Appendix C).

Key Processing Pipeline (secure trie)

raw_key (arbitrary bytes)
   -> keccak256(raw_key)              [ADR-16, I9]
   -> 32-byte hash
   -> nibble expansion (64 nibbles)   [§13 Path Encoder]
   -> trie traversal (branch/ext/leaf) [§15]

Node Embedding Rule (I2, ADR-19)

Condition Storage
len(canonical_rlp(node)) < 32 embed inline as NodeRef::Embedded(bytes)
len(canonical_rlp(node)) >= 32 store keccak256(canonical_rlp(node)), NodeRef::Hash(h)

Worked Example — Insertion Producing an Extension

Insert "dog" -> hash1, then "do" -> hash2 (raw-key mode, illustrative nibbles):

Step Nibble Path Structural Result
1 [6,4,6,f,6,7] ("dog" nibbles, illustrative) single Leaf at root
2 [6,4,6,f] ("do" nibbles, illustrative) shares prefix [6,4,6,f]... shared-prefix Extension created, Branch below it separates the two values

Result: an Extension node covering the shared nibble run, pointing at a Branch node whose value slot holds hash2 ("do") and whose nibble-6 (illustrative) child leads to a Leaf holding hash1 ("dog").

State-Transition Table — insert(root, key, value)

Current Node at Path Key Relationship Transition
Empty — replace with new Leaf
Leaf(p, v) key path == p replace value in place
Leaf(p, v) key path shares prefix with p split into Extension/Branch (as above)
Extension(p, child) key path shares all of p recurse into child with remaining path
Extension(p, child) key path diverges within p split Extension at divergence point
Branch(children, value) path exhausted set/replace value slot
Branch(children, value) path continues recurse into children[nibble]

Malformed-Input Example

Input RLP byte 0xb9 0x00 0x1f ... (long-string prefix claiming length 0x001f = 31, which fits the short-string range < 56) is rejected by I10: a canonical encoder would never emit a long-string prefix for a 31-byte payload, so the decoder treats this as TrieError::NonCanonicalRlp rather than silently accepting a decodable-but-non-minimal encoding.

Failure-Path Example

A node fetched from storage decodes successfully but its recomputed hash does not match the NodeRef::Hash that pointed to it (storage bit-rot, T4). The Hashing Engine (§14) raises TrieError::HashMismatch; the caller must treat the subtree as untrusted and trigger WAL/snapshot recovery (§19) rather than proceeding with a possibly-corrupted value.

Inclusion Proof Structure

Proof.nodes = [ encoded_node_root, encoded_node_1, ..., encoded_node_leaf ]

Verification (I8) recomputes the root by hashing encoded_node_leaf up through each parent's NodeRef slot to encoded_node_root, and compares against the claimed root.
