I12Lock order: fuses(read) → NV(read) → verify → NV(commit) ; never NV-commit before Accept.Avoid premature monotonic bump.sbpki-ab commit gating.Out-of-order commit = bug assert.Roll back attempt counter.
I13Cert validity window respected (notBefore ≤ now ≤ notAfter) with explicit clock source.Path-validation correctness.sbpki-x509 + injected clock.EXPIRED/NOT_YET_VALID codes.Reject; re-issue cert.
