3.2 One paragraph per box

  • Signal Intake: the only untrusted entry. Normalizes raw feedback (ACK ranges, SACK blocks, ECN CE counts, RTT samples, time) into typed AckEvent/SackEvent/EcnEvent/LossEvent/RttSample. Enforces monotonic time, rejects ACKs beyond SND.NXT, caps SACK block counts, detects ACK-division/optimistic-ACK (§Threat Model). Trust boundary: everything downstream assumes validated input.
  • Shared Sender Core: owns mechanism, not policy — cwnd (bytes), bytes_in_flight, packet conservation, app-limited detection, send-quantum/TSO abstraction, and the delivered/delivered_time bookkeeping feeding the rate estimator. Calls the active module's hooks; never embeds algorithm-specific logic.
  • Estimators: SRTT/RTTVAR (RFC 6298), windowed min-RTT filter (BBR RTprop), and the RateSample delivery-rate estimator (Cheng/Cardwell: delivered, interval_us, is_app_limited). Pure functions of validated input + prior state; deterministic.
  • Module Registry: name → constructor map; constructs per-connection module state; supports hot-swap (replace active module mid-connection while preserving CcState invariants). Equivalent to tcp_register_congestion_control.
  • Algorithm Module: one active dyn CongestionControl per connection. Implements on_ack/on_loss/on_ecn/cwnd_event/pacing_rate/ssthresh/on_rtt_update/undo. Pure policy; reads estimators + CcState, writes cwnd/ssthresh/pacing intent.
  • Pacer: token-bucket; pacing_rate = gain × BtlBw (or cwnd/SRTT fallback); produces inter-packet spacing and a burst budget; capped by cwnd. Decides send/hold. Deterministic given tick + state.
  • ccx-sim Event Queue: fixed-tick discrete-event core; total ordering of simultaneous events by (time, seq, kind); single seeded PRNG (Pcg64) for loss/reorder. Reproducibility guarantee lives here.
  • Bottleneck Link: one link with bandwidth (bytes/tick) and one-way propagation delay; serialization + propagation modeled as scheduled events.
  • Queue Discipline: DropTail | RED | CoDel | FQ-CoDel; decides enqueue/drop/mark and dequeue order; emits drops (loss) and CE marks (ECN) back into Signal Intake via feedback.
  • ccx-metrics: consumes the event stream; computes throughput/goodput, queue occupancy, RTT p50/p95/p99, loss rate, Jain fairness, convergence time, coexistence; emits the run report.
  • Run report + golden trace: the verifiable artifacts. The cwnd/ssthresh trace is byte-comparable to a committed golden file; the JSON report feeds regression gates.

8. Domain Model (signals, state machines, control equations)

8.1 Signal types (engine inputs) — EBNF / shape

Signal      = AckEvent | SackEvent | EcnEvent | LossEvent | RttSample | TimeTick | AppWrite | SendQuery
AckEvent    = { acked_bytes:u64, cum_ack:u64, now_us:u64 }            -- newly cumulatively acked
SackEvent   = { blocks:[ (start:u64,end:u64) ; ≤4 ], now_us:u64 }     -- selective acks
EcnEvent    = { ce_count:u64, ect_count:u64, now_us:u64 }             -- AccECN-style counters
LossEvent   = { lost_bytes:u64, kind: Rto|FastRetx|RackTlp, now_us:u64 }
RttSample   = { rtt_us:u64, is_retrans:bool, now_us:u64 }             -- Karn: drop if is_retrans
TimeTick    = { now_us:u64 }                                         -- sim/transport clock advance
AppWrite    = { bytes:u64 }                                          -- app-limited detection
SendQuery   = { now_us:u64 } -> SendDecision                          -- pacer asks: send how much?

8.2 Decision types (engine outputs)

SendDecision = { send_bytes:u64, next_send_us:u64 }   -- paced; 0 ⇒ hold until next_send_us
CcSnapshot   = { cwnd:u64, ssthresh:u64, pacing_rate_bps:u64, state:CaState, min_rtt_us:u64, srtt_us:u64, btlbw_bps:u64 }

8.4 RTT estimation (RFC 6298 + min-RTT filter)

on first sample:   SRTT = R ; RTTVAR = R/2
subsequent:        RTTVAR = (1-β)·RTTVAR + β·|SRTT - R|        β=1/4
                   SRTT   = (1-α)·SRTT   + α·R                 α=1/8
                   RTO    = SRTT + max(G, K·RTTVAR)            K=4, G=clock granularity
Karn:              ignore R from retransmitted segments (RttSample.is_retrans ⇒ drop)
min-RTT (RTprop):  windowed min over last W (default 10 s); refresh forces sample (BBR PROBE_RTT)

All α,β,K applied in fixed-point (α=1/8 ⇒ shift; β=1/4 ⇒ shift). RTO bounded [200 ms, 60 s] (config).

8.5 Loss-signal model (shared with loss-recovery layer)

Engine consumes LossEvent from a loss detector (dupack-threshold / SACK / RACK-TLP time-based / RTO). It does not implement RFC 8985 itself (that is the transport/224's job) but defines the contract: kind ∈ {FastRetx, RackTlp, Rto}, lost_bytes, monotonic now_us. Modules react via on_loss. DSACK / spurious detection arrives as an undo signal triggering CongestionControl::undo.

8.6 ECN / AccECN model

ECT(0)/ECT(1)/CE codepoints (RFC 3168); CE feedback as a counter (ce_count) per EcnEvent. DCTCP semantics (RFC 8311) use the fraction of CE-marked bytes. AccECN full negotiation (separate ECT0/ECT1/CE counters, ACE field) is PhaseDeferred("FINAL_BLUEPRINT §8.6"); Phase 8 implements the classic single-CE-counter path sufficient for DCTCP.

8.7 Delivery-rate estimator (Cheng/Cardwell rate-sample)

Per sent packet store PacketMeta { delivered_at_send:u64, delivered_time_us:u64, is_app_limited:bool, size:u64, sent_us:u64 } in a bounded ring. On ACK:

rs.delivered      = C.delivered - pkt.delivered_at_send         -- bytes delivered in the interval
rs.interval_us    = max( C.now_us - pkt.delivered_time_us ,     -- ack-rate interval
                         pkt.sent_us_of_latest - pkt.sent_us )  -- send-rate interval; take max
rs.is_app_limited = pkt.is_app_limited
delivery_rate_bps = rs.delivered * 1e6 / rs.interval_us         -- fixed-point µs

is_app_limited set when the app had < cwnd bytes to send and inflight < cwnd (don't let idle gaps depress BtlBw). BtlBw = windowed-max of delivery_rate over ~10 RTTs (BBR).

8.8 Control equations per algorithm

NewReno (RFC 5681/6582):

slow start:   cwnd += SMSS per ACK (or += acked, ABC)              until cwnd ≥ ssthresh
cong-avoid:   cwnd += SMSS·SMSS/cwnd per ACK   (≈ +1 SMSS / RTT)
loss(FR):     ssthresh = max(FlightSize/2, 2·SMSS); cwnd = ssthresh (+3 SMSS infl. during recovery)
RTO:          ssthresh = max(FlightSize/2, 2·SMSS); cwnd = 1·SMSS; → slow start

CUBIC (RFC 9438):

W_cubic(t) = C·(t − K)^3 + W_max          C = 0.4 (fixed-point), t = time since last reduction
K          = cbrt( W_max·(1−β_cubic)/C )  β_cubic = 0.7
on loss:    W_max = cwnd; cwnd = cwnd·β_cubic ; recompute K
TCP-friendly region: W_est = W_max·β + 3·(1−β)/(1+β)·(t/RTT); cwnd = max(W_cubic, W_est)
fast convergence:  if W_max < W_last_max → W_max·=(1+β)/2 (yield to new flows)

Cube root via integer Newton iteration (no libm); C and β_cubic in Q16.16.

BBR v1 (Cardwell):

model:      BtlBw = max filter(delivery_rate, 10 RTT); RTprop = min filter(rtt, 10 s)
BDP         = BtlBw · RTprop
pacing_rate = pacing_gain · BtlBw ; cwnd = cwnd_gain · BDP (cwnd_gain=2)
STARTUP:    pacing_gain = cwnd_gain = 2/ln2 ≈ 2.885 ; exit when BtlBw plateaus (3 rounds <25% growth)
DRAIN:      pacing_gain = 1/2.885 ; drain queue until inflight ≤ BDP
PROBE_BW:   8-phase gain cycle [5/4, 3/4, 1,1,1,1,1,1] ; one RTT each
PROBE_RTT:  every 10 s if min-RTT not updated: cwnd = 4 pkts for max(200 ms,1 RTT) to re-measure RTprop

Vegas (delay-based):

expected = cwnd / BaseRTT        (BaseRTT = min RTT)
actual   = cwnd / RTT            (current sample)
diff     = (expected − actual)·BaseRTT     -- in packets
if diff < α:  cwnd += 1   (per RTT)
if diff > β:  cwnd −= 1
else:        cwnd unchanged          α=2, β=4 packets

DCTCP (ECN-fraction):

F        = fraction of CE-marked bytes this window
α        = (1−g)·α + g·F            g = 1/16
on marks: cwnd = cwnd·(1 − α/2)     -- proportional, gentler than Reno halving
no marks: behave like Reno cong-avoid

8.9 Worked example (NewReno, ASCII timeline)

t=0   IW: cwnd=10·SMSS, SS
t=1RTT 10 acked → cwnd=20  (SS doubling)
t=2RTT 20 acked → cwnd=40
...   queue fills at bottleneck (DropTail)
t=k   3 dupacks → FastRetx: ssthresh=cwnd/2=... ; cwnd=ssthresh; RECOVERY
      partial acks deflate cwnd, retransmit holes (RFC 6582)
t=k+  full ack → CA: cwnd += SMSS²/cwnd per ack (≈ +1/RTT sawtooth)

Design principles (§6)

  • Mechanism/policy separation is sacred. Shared Sender Core owns cwnd accounting, bytes-in-flight, pacing math, rate estimation; the Module owns only policy (how to change cwnd/ssthresh/gain). Tradeoff: more indirection per ACK. Operational: a buggy module cannot corrupt accounting invariants. Violation: if a module mutates bytes_in_flight directly, packet conservation (INV-3) breaks and fairness measurements become meaningless.
  • Determinism over convenience. Same (seed, scenario, build) ⇒ byte-identical trace. No floats in the control core, no wall-clock, no hashmap iteration order, no thread races in a single connection. Tradeoff: fixed-point math is fiddlier. Operational: every bug is reproducible from a seed; CI diffs traces. Violation: float FMA drift makes a CUBIC trace differ across CPUs → conformance is impossible.
  • The vtable is the contract. CongestionControl hooks, their argument types, and call ordering are a stable ABI; modules and transports depend on it. Tradeoff: hard to evolve. Operational: versioned via CC_ABI_VERSION; additive-only within a major. Violation: reordering on_ack vs on_rtt_update silently changes every algorithm's behavior.
  • Signals in, decisions out — nothing else crosses the boundary. Modules never do I/O, never read the clock directly (they get now), never allocate on the hot path. Tradeoff: richer context must be passed explicitly. Operational: modules are trivially unit-testable and fuzzable. Violation: a module reading the real clock breaks determinism (P2).
  • Bounded resource usage. Per-conn memory ≤ 1 KiB + bounded sent-history ring; no unbounded SACK scoreboard growth. Tradeoff: ring eviction logic. Operational: 10⁴ flows fit in 8 GiB. Violation: unbounded scoreboard → OOM under SACK-reordering attack.
  • Backpressure via pacing, not bursting. Sender shapes output to pacing_rate; cwnd is a cap, not a license to burst. Tradeoff: pacing adds a timer per send. Operational: avoids standing queues / bufferbloat. Violation: cwnd-only sends create line-rate bursts that overflow shallow queues (loss, RTT spikes).
  • Observability by default. Every cwnd change, state transition, loss/ECN event, and rate sample is traceable (event log) without code changes. Tradeoff: trace volume. Operational: golden traces are the conformance medium; incidents are post-hoc replayable. Violation: silent cwnd changes can't be conformance-tested.
  • Replayability first. A run is fully described by (scenario.toml, seed, build hash). Inputs (ack/sack/ecn streams) can be captured and replayed against a module in isolation. Tradeoff: must log inputs. Operational: a field bug from a real transport replays offline. Violation: nondeterministic inputs ⇒ unreproducible bugs.
  • Stable, additive ABI. New hooks default to no-op; new fields appended; never reorder/repurpose. Tradeoff: deprecated fields linger. Operational: old modules keep working across minor versions. Violation: breaking the FFI vtable silently UB-crashes C transports.
  • Integer/fixed-point everywhere in control math. Bytes in u64, time in u64 µs, rates in bytes/sec u64, gains in Q16.16; all multiply/divide via checked/saturating helpers with documented rounding. Tradeoff: precision/rounding care. Operational: no overflow, no NaN, no platform drift. Violation: cwnd * gain overflow wraps cwnd to near-zero → stall.
  • Fail safe, not silent. Invalid signals (ACK beyond SND.NXT, time going backward) are rejected and counted; the connection degrades to conservative behavior (e.g., treat as no-ack) rather than trusting bad input. Tradeoff: dropped legitimate edge inputs. Operational: ack-division/optimistic-ack attacks bounded. Violation: trusting optimistic ACKs inflates cwnd → congestion collapse / DoS.
  • One active algorithm per connection; hot-swap is explicit and invariant-preserving. Swap copies/clamps shared state, resets module-private state, never violates cwnd ≥ min, bytes_in_flight ≤ cwnd-window semantics. Tradeoff: swap is a defined operation, not free. Operational: A/B algorithms on live flows. Violation: swapping mid-recovery without resetting recovery state double-reduces cwnd.
  • Conformance is golden-trace, not assertion-only. Each algorithm's behavior is pinned by a committed cwnd/state trace over a canonical scenario; any drift fails CI. Tradeoff: traces must be regenerated intentionally on real changes. Operational: prevents accidental behavior regressions. Violation: refactors silently change CUBIC's curve.
  • Simulator realism is explicit and documented. Link/queue/loss models are simplifications with stated assumptions (fluid vs packet, no jitter unless configured). Tradeoff: not a packet-accurate ns-3 clone. Operational: results interpreted with documented caveats. Violation: over-claiming "real-world" fairness from an idealized model.
  • Time is injected, monotonic, and µs-quantized. No component reads Instant::now() except the (testable) clock source; sim drives a virtual clock. Tradeoff: clock threading through APIs. Operational: determinism + replay. Violation: hidden time reads ⇒ nondeterminism + clock-skew bugs.
