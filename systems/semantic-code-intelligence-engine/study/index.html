Mental Models & First Principles

These compressed expert insights predict failure modes and guide design. Every cited § resolves to a real heading in this blueprint.

MM1. An interned id is a compressed equality witness, not a persistent identifier. A SymbolId(u32) is a dense index into an append-only arena built during one index run. Two separate runs may assign different ids to the same declaration. The invariant is: same arena → same id; different arenas → compare by Moniker, never by SymbolId. Without this model, you write code that persists raw SymbolId values to disk and observes silent wrong navigation after reindex. Applied in: §11 (Interned, SymbolId stability contracts), Phase 1 i6, Phase 10 id-remapping on encode, Cross-repo linking I10.

MM2. The firewall is the only thing that makes incremental recompute fast. Salsa's red-green model is not about caching — it is about stopping propagation the moment a derived value is unchanged. Without the firewall (equality check on output), every file edit cascades to a full re-resolve. The bug you write without it: missing the durable-equality comparison after a re-execute, so green queries are marked red unnecessarily. Applied in: §8.8 (red-green query model), Phase 11 scie-incremental firewall design, I5.

MM3. A scope tree is a data structure for precedence, not just for lookup. The scope chain encodes which binding wins when two scopes bind the same name. The contract is: innermost visible binding wins. Hoisting is the only exception: some declarations are pre-inserted at function scope before inner scopes are walked. Without this model, you build a flat symbol table and miss shadowing or hoisting, producing wrong go-to-definition. Applied in: Phase 4 (scie-scope), §8.4 (scope state model), I7.

MM4. A Moniker is a pure function of namespace location, not of memory. Moniker.descriptor must be derivable by any process from the source text alone — no arena addresses, no thread-local state, no map-iteration order. This is the content-addressed property. Without it, monikers are non-deterministic across runs, cross-repo go-to-definition silently fails, and the incremental cache key is corrupt. Applied in: Phase 1 (moniker construction), Phase 3 (descriptor synthesis), P1, I1.

MM5. Unknown is a valid TypeRef; wrong is never valid. Bounded inference must have an explicit floor: when the type cannot be determined with certainty, return TypeRef::Unknown. A non-Unknown TypeRef must be sound (correct). This prevents speculative inference from causing wrong member navigation. The bug class: trying to infer the type of a generic parameter and returning a plausible-but-wrong concrete type. Applied in: Phase 9 (scie-type), P9, I9.

MM6. The index is the only API surface; the pipeline is an implementation detail. Producing correct query results without going through the serialized index couples the query server to a specific pipeline version, breaks incremental merge, and prevents external tools. Every result must be derivable from decode(on-disk-shard). Without this model, you start serving query results from in-memory pipeline state and discover that hot-reload and multi-replica deployment require non-trivial state synchronization. Applied in: Phase 10 (scie-index), Phase 6 (Document assembly), P2.

MM7. Occurrence sort order is a correctness invariant, not a style preference. Binary search over Document.occurrences for position-to-symbol lookup requires that the occurrence list is sorted by (start_line, start_col). Any out-of-order occurrence causes silent wrong results (the binary search terminates early or lands on the wrong entry). The bug you write without this model: appending definition occurrences after reference occurrences without re-sorting. Applied in: Phase 6 (DocumentBuilder sort step), Phase 13 (position-to-occurrence binary search), I3.

MM8. Cross-repo linkage requires exact package identity, not approximate. Two packages named serde at versions 1.0.193 and 1.0.200 are distinct packages with potentially incompatible APIs. Linking on name alone produces phantom go-to-definition landing on a removed or renamed symbol. Exact (scheme + manager + name + version + descriptor) equality is the correct join key. Applied in: Phase 12 (scie-xrepo), I10, ADR-28.

MM9. Parallelism is safe only at file granularity in the indexing pipeline. The scope tree, symbol extraction, and intra-file resolution are pure functions of one file's CST. Multiple files can be processed concurrently without coordination. The project symbol table is built after all per-file passes complete (two-phase discipline). Without this model, you parallelize the cross-file pass over a partially-built table and observe non-deterministic resolution results. Applied in: Phase 7 (two-pass discipline), Phase 8 (pass B parallelism), ADR-09.

MM10. Determinism is a property of algorithm, not of hardware. FxHashMap with a fixed seed, sorted output before serialization, deterministic CST traversal order — these are the levers. A HashMap with a random seed will produce different output byte-for-byte on identical inputs. The bug class: using HashMap iteration order to assign SymbolId values, then discovering that CI occasionally fails with a byte-diff. Applied in: Phase 1 (FxHashMap interner), Phase 10 (sorted encode), I6, I8, P6.

Glossary · 42 terms · site-wide glossary

Ambiguous
ResolutionResult::Ambiguous(Vec<SymbolId>) — reference name matched multiple definitions with equal precedence; scie-resolve emits this rather than picking arbitrarily. Counted under P10 observability.
Binding
Binding { name: Interned, symbol: SymbolId, decl_range: Range } — a name-to-symbol mapping inserted into a Scope at declaration time (Phase 4). Shadowing occurs when an inner scope inserts a binding with the same name.
Call Hierarchy
Navigation query (Phase 13) traversing CodeGraph.calls edges: incoming callers and outgoing callees for a given SymbolId. Exposed via scie-query and the LSP callHierarchy subset.
Code Graph
CodeGraph { def_of, refs_of, impls, calls } — reverse index from definitions to all reference sites; built in Phase 8 by scie-graph. Invariant I4 requires every refs_of edge to have a corresponding def_of node or external moniker.
CST (Concrete Syntax Tree)
Full-fidelity parse tree produced by tree-sitter, preserving whitespace and error nodes. scie-syntax wraps tree-sitter's typed cursor over the CST; downstream layers consume a typed AST cursor derived from it.
Declaration
An occurrence with SymbolRole::Definition; the site where a name is introduced. Emitted by scie-symbol (Phase 3) and entered as a Binding in the scope tree.
Def-Map
Internal structure in scie-resolve mapping a module path to the SymbolId of its declaration; enables cross-file import resolution (Phase 7). Analogous to rust-analyzer's def-map.
Dependency Edge (DepEdge)
A tracked link from a memoized query output to each input query it consumed. When an input is invalidated, scie-incremental traverses DepEdges to mark derived queries stale. Core to invariant I5.
Descriptor
The per-symbol portion of a Moniker encoding the name's path within its package (e.g., TypeName#methodName()). Follows the SCIP descriptor grammar. Invariant I1 requires the descriptor to be a pure function of source location.
Determinism
Invariant I8: encode(model) is byte-identical for identical inputs regardless of map iteration order or arena allocation addresses. Enforced by sorted occurrences, stable interning order, and canonical serialization in scie-index.
Document
Document { file: FileId, lang, occurrences, symbols, scopes } — the SCIP per-file unit assembled in Phase 6. The primary serialization atom; scie-index encodes/decodes documents.
Dotted Access
Member expression a.b.c; resolved in scie-type (Phase 9) by looking up TypeRef of a, then finding field/method b in its symbol's member table, repeating for c. Returns Unknown when the chain is uncertain.
External Symbol
A symbol declared in a dependency not present in the current index. Represented as ResolutionResult::External(Moniker); linked to a foreign repo's index by scie-xrepo on exact moniker equality (invariant I10).
FileId
FileId(u32) — interned integer handle for a file path. Cheap equality, map key; remapped deterministically during serialization (invariant I6). Interned in scie-core.
Firewall
The incremental-recompute property: when a query result is unchanged, downstream queries are not re-executed. Implemented in scie-incremental via durable equality short-circuit. Ensures Phase 11 efficiency.
Hover
Navigation query returning SymbolInformation.signature + docs for the symbol at a source position. Synthesized in scie-type (Phase 9) and served by scie-query (Phase 13).
Idempotent Reindex
Full reindex of identical source yields identical monikers and occurrence sets. Required by invariant I1; verified in Phase 14 conformance tests.
Incremental Recompute
The strategy (Phase 11, scie-incremental) where only queries whose inputs changed since the last Revision are re-evaluated; unchanged results are returned from cache without re-execution.
Interned / Interning
Converting strings and paths to dense Interned(u32) handles via an arena table in scie-core. Enables O(1) equality, compact storage, and deterministic serialization. Governed by invariant I6.
LSIF
Language Server Index Format — Microsoft's predecessor to SCIP; a JSON graph of vertices (ranges, result sets, monikers) and edges. scie-index references its shape but targets SCIP's more compact representation.
Moniker
Moniker { scheme, package: PackageId, descriptor } — globally stable symbol identifier. Scheme identifies the ecosystem (e.g., rust); PackageId identifies the crate/version; descriptor encodes the declaration path. Invariant I1.
Name Resolution
The process (Phases 5 and 7) of binding each identifier occurrence to a SymbolId by walking the scope chain (intra-file) or the project symbol table (cross-file). Results are `Resolved
Occurrence
Occurrence { range, symbol: SymbolId, roles: SymbolRole } — one mention of a symbol at a source range. The atomic record in a Document; sorted and non-overlapping per role (invariant I3).
PackageId
PackageId { manager, name, version } — identifies the package providing a symbol's definition. Part of Moniker; used by scie-xrepo for version-aware cross-repo resolution.
Position / Range
Position { line: u32, col: u32 } — zero-based, UTF-16 or byte-indexed per LSP convention. Range { start, end } — half-open span. Invariant I3 requires ranges to be well-formed.
Precision / Recall
Resolution quality metrics emitted by scie-query (P10): precision = fraction of resolved references that are correct; recall = fraction of all references that are resolved. Reported in Phase 14.
Red-Green Algorithm
