Per-box.

  • parse — DIMACS for pure SAT; an SMT-LIB 2 reader that builds typed terms (sorts, function symbols) and runs the command loop (set-logic, declare-fun, assert, check-sat, push, pop, get-*). It is the only component that touches untrusted text; everything downstream sees validated structures.
  • preprocess/inprocess — simplifies CNF before and during search: Tseitin encoding of non-clausal formulas, unit propagation at top level, pure-literal elimination, subsumption + self-subsuming resolution, bounded variable elimination (BVE), blocked-clause elimination (BCE). Reduces the search space the core must explore.
  • smt frontend — maps each theory atom (e.g. x + y ≤ 3) to a fresh Boolean variable, hands the Boolean skeleton to the SAT core, and routes the truth assignments of those atoms to the right theory via the combination router.
  • CDCL SAT core — the engine. decide picks the next literal by activity (VSIDS); BCP propagates unit clauses via two-watched literals; on conflict, analyze computes a 1-UIP learnt clause and the backjump level; the clause DB stores learnt clauses with LBD scores and periodically deletes low-value ones.
  • trail — the assignment stack with decision levels and per-literal reasons; the single source of truth for the current partial model; backjumping pops it.
  • DPLL(T) theory layer — each theory implements a uniform trait. The core asserts theory literals as it assigns their Boolean proxies; theories detect inconsistency (check), deduce implied literals (propagate), and explain conflicts/propagations as clauses the core can learn.
  • EUF — congruence closure over an e-graph: union-find of terms with a signature table so that a=b ⟹ f(a)=f(b). Produces equality explanations.
  • LRA/LIA — a Simplex tailored for satisfiability (general simplex with bound constraints) for reals; branch-and-bound + Gomory cuts on top for integers.
  • Bit-Vectors — bit-blasting: compile each BV operation to a propositional circuit and hand it to the SAT core; the cheapest correct route to QF_BV.
  • Arrays — lazy instantiation of read-over-write and extensionality axioms.
  • combine (N-O) — exchanges entailed equalities over shared variables between theories; purifies mixed terms so each theory sees only its own symbols.
  • results — SAT yields a full model (Boolean + theory values); UNSAT yields a DRAT proof (SAT) and/or an unsat core (subset of assumptions/assertions).

Boundaries. Trust: only parse consumes untrusted input. Concurrency: single-threaded Phase 0 (portfolio parallelism deferred — Stretch Goals). Persistence: none — solving is in-memory; proof trace streams to a file. Protocol: SMT-LIB 2 textual command/response is the external contract.

8. Domain Model / Source Language / Protocol

8.1 Propositional layer (SAT)

Var     = u32 (1..N)
Lit     = packed u32: (var << 1) | sign        # sign 0 = positive, 1 = negative
lbool   = True | False | Undef
Clause  = [Lit]   (len ≥ 1; unit, binary special-cased)
CNF     = conjunction of Clauses
Assign  : Var -> lbool   (derived from trail)

DIMACS:

p cnf <numVars> <numClauses>
1 -2 3 0          # clause (x1 ∨ ¬x2 ∨ x3), 0 terminates
-1 2 0

8.2 First-order layer (SMT) — terms + sorts

Sort ::= Bool | Int | Real | (BitVec n) | (Array Sort Sort) | <uninterpreted>
Term ::= const | var
       | (f t1..tn)            # uninterpreted or theory function
       | (= t u) | (distinct ..)
       | (and ..)|(or ..)|(not t)|(=> ..)|(ite c t u)
       | (+ ..)|(- ..)|(* ..)|(<= ..)|(< ..)   # arithmetic
       | (bvadd ..)|(bvand ..)|(bvshl ..)|(concat ..)|(extract i j t) # BV
       | (select a i) | (store a i v)          # arrays

SMT-LIB 2 command protocol (state machine):

(set-logic QF_LRA)
(declare-fun x () Real) (declare-fun y () Real)
(assert (<= (+ x y) 3))
(assert (>= x 2))
(push 1)
  (assert (>= y 2))
  (check-sat)        ; → unsat   (x≥2 ∧ y≥2 ∧ x+y≤3 impossible)
  (get-unsat-core)   ; → (a2 a3 ...)
(pop 1)
(check-sat)          ; → sat
(get-model)          ; → ((x 2.0) (y 1.0))
(exit)

8.3 Boolean abstraction

Each theory atom A (e.g. (<= (+ x y) 3)) is assigned a fresh Boolean variable bA. The SAT core searches over {bA}; when it assigns bA=true, the smt frontend asserts A into the arithmetic theory; bA=false asserts ¬A. The theory's job: decide if the conjunction of asserted atoms is T-satisfiable.

8.5 Worked example — EUF conflict

Assert: a=b, b=c, f(a)≠f(c).

  • CC merges {a,b}, then {a,b,c}; signature of f(a) and f(c) collide ⇒ f(a)=f(c) derived.
  • f(a)≠f(c) now contradicts ⇒ T-conflict.
  • explain: (a=b ∧ b=c) ⟹ f(a)=f(c), so learnt clause ¬(a=b) ∨ ¬(b=c) ∨ (f(a)=f(c)) (in atom proxies). Combined with asserted f(a)≠f(c) ⇒ UNSAT.

8.6 Malformed / failure-path examples

  • DIMACS clause without terminating 0 → parse error (line, expected 0).
  • SMT-LIB (check-sat) before (set-logic) → error per spec.
  • BV op on mismatched widths (bvadd #b01 #b001) → sort error.
  • (get-model) after unsat → error (no model).
  • Division by zero in LIA/LRA term → guarded ((/ x 0) is uninterpreted per SMT-LIB, not an error).
  • Integer overflow in coefficient → use arbitrary-precision rationals in arithmetic (no machine overflow).

Design principles (§6)

  • Correctness over speed, always. A faster wrong answer is worthless. Every optimization must preserve the answer; SAT models are self-checked, UNSAT proofs externally checkable. Violation: a watcher bug that drops a unit clause → wrong SAT → silent, catastrophic.
  • The trail is the single source of truth. The current partial assignment, decision levels, and reasons live only on the trail; backjumping is a trail truncation. Tradeoff: every data structure must be reconstructible from / consistent with the trail. Violation: a theory caching state that desyncs from the trail produces phantom conflicts.
  • Two-watched literals: lazy, not eager. Track only two unassigned watches per clause; never scan a clause unless a watch is falsified. Tradeoff: subtle invariants on backtrack. Violation: eager BCP is O(clauses) per assignment — solver crawls.
  • Learn from every conflict (1-UIP). Each conflict yields exactly one asserting clause at the first unique implication point; this is what makes CDCL escape exponential blowup. Violation: weaker learning (e.g. decision-cut) loses propagation power; no learning = DPLL = exponential.
  • Theory lemmas are just clauses. A T-conflict or T-propagation is explained as a clause over existing atoms and handed to the SAT core, which learns it like any other. Tradeoff: explanations must be valid + minimal. Violation: an unsound explanation teaches the core a false fact → wrong UNSAT.
  • Backtrackable theory state. Every theory supports push/pop matching the SAT core's decision levels in O(Δ). Violation: full rebuild on backtrack makes incremental + DPLL(T) intolerably slow.
  • Determinism by construction. No wall-clock, no address-order, no hash-iteration-order influences a decision; a seed fixes any randomness. Tradeoff: must order tie-breaks explicitly. Violation: non-determinism makes bugs unreproducible and conformance flaky.
  • Bounded resources, graceful "unknown". Time, conflict, and memory budgets are first-class; on exhaustion return unknown, never crash or lie. Violation: OOM-killed mid-solve loses the run; returning sat on timeout is a soundness bug.
  • Explanations are minimal. Conflict clauses and theory explanations are reduced (self-subsumption, minimization) so learnt clauses are short and reusable. Tradeoff: minimization CPU. Violation: bloated learnt clauses fill memory and slow BCP.
  • Incrementality is core, not bolted-on. push/pop, assumptions, and assertion levels are designed in from Phase 0 (the SMT loop and many clients are inherently incremental). Violation: a solve-once architecture forces full restarts per query — useless for verification loops.
  • Lazy theory checking. Call full theory check at fixpoint of Boolean propagation, not on every literal; use cheap propagate continuously. Tradeoff: later conflict detection. Violation: eager full checks dominate runtime.
  • Separate Boolean abstraction from theory semantics. The SAT core never knows what an atom means; the theory layer never sees Boolean search. This clean seam is what makes new theories pluggable. Violation: leaking theory knowledge into the core makes both unmaintainable.
  • Arena allocation, index references. Clauses live in a contiguous arena; references are 32-bit offsets, not pointers — cache-friendly and relocatable for compaction. Violation: pointer-chasing clause objects thrash cache and fragment memory.
  • Reproducible proofs. The DRAT trace exactly reflects the learnt clauses in order; it must check against DRAT-trim. Violation: a proof that doesn't check means the UNSAT claim is unsubstantiated.
